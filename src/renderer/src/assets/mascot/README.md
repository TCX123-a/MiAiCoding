# assets/mascot —— 大肥鱼立绘投放目录

**这个目录现在（还）是空的，这不是错误。** 空的就全部显示虚线占位框；
丢进来一张，界面里立刻换成真图（开发模式有热更新，存进去就变）。

> 📖 **要出图的话，看 [docs/13 的 §7 出图工单](../../../../../docs/13-图片资产需求清单.md)** ——
> 那张表列着要出几张、叫什么名字、什么情绪。本文件只讲**怎么放**。

---

## 一、命名：`姿态_两位编号.png`

```
busy_01.png   busy_02.png   …   busy_10.png
```

- 编号**从 `01` 起、一律两位**：`busy_1.png` ❌、`busy1.png` ❌、`Busy_01.png` ❌
- **姿态名必须是下面 10 个之一**，差一个字符就查不到图，**界面直接空一块**
- 不用中文名、不用空格、**不要放子文件夹**

### 10 个姿态名

```
welcome    好奇打招呼     首页欢迎卡、侧栏 Logo
expect     期待、指向前方  空状态「你的第一课在这里」
proud      骄傲、拍肚皮    错题本清空
think      歪头思考       搜索无结果、课文不存在
yay        小庆祝、比心    答对、输出区「跑通了」
soothe     温柔不责备     答错、编译运行报错
milestone  狂喜、鲸跃     人生第一次跑通代码、挑战通关奖励
busy       忙碌、深潜     加载等待、环境检测中、输出区「运行中」
remind     提醒但不掐     复习到期
guide      当向导        环境安装引导
```

### 半身版：姿态名后面加 `-head`

侧栏 Logo 只有 48px，**全身图缩到 48px 只剩一个蓝点，认不出是谁** ——
那个位置要用半身构图单独出一张，名字多一个 `-head`：

```
welcome_01.png          ← 全身版，给首页那张大欢迎卡（112px）
welcome-head_01.png     ← 半身版，给侧栏左上角 Logo（48px）
```

**规则是自动的**：32px / 48px 的位置先找 `-head` 版，**没有就退回用全身版**，
界面不会空一块。所以你只给 `welcome` 出半身版也行，别的姿态照旧。

> 目前**只有 `welcome` 需要半身版**（侧栏 Logo 是唯一的小档位常驻位）。

### 只放一张、懒得编号？`busy.png` 也认

不带编号的写法算「第 1 张」。这是留给「先丢一张试试」的宽容路径 ——
但**正式出图请一律带编号**，两种写法混在一个目录里，人自己会记不清第几张是哪张。

### 同一个姿态放好几张 = 图池轮换

```
busy_01.png   busy_02.png   busy_03.png   …
```

- 只有 1 张 → 占位框上显示「80 × 80」，永远用那张
- 加到 3 张 → 占位框上变成「80 × 80 · 2/3」，**开始每次触发换一张**
- **丢进去就生效**，不用改代码、不用重启

> 目前**只有四个位置会轮换**（输出区的运行中 / 跑通 / 报错，和挑战通关奖励）——
> 它们每次触发都换一张脸，所以每个要 10 张。其余位置（空状态、Logo）是长期停在那儿的，
> **每个 1 张就够**，出 10 张也没人看得见第 2 张。清单见 docs/13 §7。

## 二、硬性要求

| 项 | 要求 | 为什么 |
|---|---|---|
| **格式** | **透明底 PNG** | 落位点全在卡片底/彩色底上。白底图贴上去是一个刺眼的白方块，边缘一圈白 |
| 尺寸 | 512 × 512 | 与 LoRA 出图规格一致（SD1.5 的硬上限，见 docs/11 §7.1） |
| 构图 | 见下 | ⚠️ **这条最容易踩** |

### 构图分两种，不能混用

| 用在哪 | 构图 | 提示词改法 |
|---|---|---|
| `m` / `l` / `xl` 档（80px 以上） | **全身** `full_body` | 保持 docs/11 §6.1 原样 |
| `xs` / `s` 档（32 / 48px） | **半身/头像**，且文件名加 `-head` | 把 `full_body` 换成 `upper body` 或 `portrait`，其余不动 |

## 三、出图流程

```
按 docs/13 §7 的工单逐姿态出图（512×512，白底）
  → 人工筛选（合格率约 1/3~1/2，多抽）
  → ComfyUI RemoveBackground_SET 节点 + BiRefNet 直出透明底
  → 按上面的命名放进本目录
```

> ⚠️ 出图前先确认 BiRefNet 模型已就位（docs/11 §8.5 记录：模型文件当时尚未下载）。
> 没有它就去不掉白底。

### 挑图嫌一张张点开太慢？

把装满图的文件夹拖到**「拼对比图.bat」**上（桌面上有快捷方式，本体在
[`scripts/图片工具/`](../../../../../scripts/图片工具/)），会拼成一张大图：

- 每张左上角有**编号**，你挑的时候报编号就行
- **透明底显示成棋盘格** —— 一眼就能看出哪张忘了去白底（白底会显示成纯白块）
- 拼好的图叫 `<文件夹名>_对比图_01.jpg`，就放在那个文件夹里，会自动弹出来
- 超过 48 张会自动分页；打不开的坏图会画成红卡片，不会让程序崩

## 四、放进来之后

**什么都不用改。** 组件会自己检测到文件并切换成 `<img>`。
全项目十几个调用点一行都不动 —— 这正是把形象收口到 `MiMascot.vue` 的目的。

> ⚠️ **「丢进去就生效」只在开发模式（`npm run dev`）成立。**
> 图片是在**打包时**登记进程序的，打包成 exe 之后再往这个目录丢新图不会出现，得重新打包。
> 这是故意的：图定稿后基本不会再动，而运行时读目录要额外开一套本地文件读取。

完整规格见 [docs/13-图片资产需求清单.md](../../../../../docs/13-图片资产需求清单.md)。
