# assets/sounds —— 音效投放目录

> 🔄 **2026-09-15 改版**：**这个目录不再是"必须的"了。**
>
> 除了猫叫和鸭叫，其余 **7 个场合的声音由程序当场算出来**（`lib/sfx-synth.ts`），
> 不需要音频文件、不占体积、也**不会因为文件缺失而哑掉**。
>
> 所以现在这个目录只管一件事：**要不要把某个合成音换成你自己找的素材**。
> 放进来 → 自动顶掉合成音；不放 → 合成音照常响。**两种情况都是完好的**，
> 没有"静默"这个状态了（只有猫叫和鸭叫这两格，缺文件才是真没声）。

**目录里没有文件不是错误。** 界面照常能点、能跑、能学，一个错误框都不弹。
丢进来一个，那个场合立刻换成你的素材；丢进来三个，三个都进抽签池。
（这条对每个场合都成立，不是"整个目录要么全有要么全无"。）

> 当前状态（2026-09-15）：**猫咪 3 段 + 鸭子 1 段已经放好了**，
> 也就是说上表里两组标志为「🐾 要像动物」的都在用主人的素材。
> 其余 7 个场合用的是程序算出来的音。

> 🎯 **一句话**：把文件按下面的名字丢进本目录，**重开一次 `npm run dev`**，就生效了。
> 不用改代码、不用改配置、不用告诉我。

完整路径 = 本目录：`src/renderer/src/assets/sounds/`（在仓库根目录下按这个相对路径找）。

## 一、要放哪些文件

一共 **9 个场合**。其中 **2 个是「必须有素材」的**（要像动物叫，合成做不出来），
另外 7 个**今天已经有声音了**（程序算的），放素材只是"换成你更喜欢的"。
「点猫咪」那一格要放 **3 段**（每次点击随机抽一段），所以最多是 **12 个文件**。

| 文件名（主干） | 什么时候响 | 今天的状态 | 建议时长 |
|---|---|---|---|
| **`cat-click-1`**<br>**`cat-click-2`**<br>**`cat-click-3`** | **点猫咪贴图**（首页欢迎卡那只猫头，V1-40 起有触发点）<br>**每次随机抽一段**，所以三段都放上才有效果 | 🐾 **要像动物 → 必须有素材**<br>（已放好） | 0.3 – 1.5 秒 |
| **`duck-click`** | **点大肥鱼立绘**（十几个位置都会响） | 🐾 **要像动物 → 必须有素材**<br>（已放好） | 0.3 – 0.8 秒 |
| `click` | 普通点击（按钮、开关、行内小控件） | 🎹 已在响（合成的） | 0.05 – 0.25 秒 |
| `nav` | 切换课程 / 换页 / 换语言 | 🎹 已在响 | 0.1 – 0.4 秒 |
| `answer-right` | **练习答对一题**（清脆上扬的"叮"） | 🎹 已在响 | 0.2 – 0.6 秒 |
| `answer-wrong` | **练习答错一题**（温和下沉的一声） | 🎹 已在响 | 0.3 – 0.8 秒 |
| `lesson-complete` | **学完一课** | 🎹 已在响 | 1.5 – 3 秒 |
| `chapter-complete` | 做完一章的练习 | 🎹 已在响 | 1.5 – 3 秒 |
| `challenge-complete` | 完成每日挑战 | 🎹 已在响 | 2 – 4 秒 |

> ⚠️ **答对 / 答错这一对是"功能音"，换素材要小心**：学员要靠它们
> **不看屏幕就知道刚才那题对没对**。所以两个必须**一听就分得开** ——
> 建议答对用**往上走**的、答错用**往下走**的，别选两个都是"叮"一声的。
> 合成的那一对是按这个原则做的（答对在高音区往上跳五度，答错在低音区往下掉三度）。

### 猫咪为什么是三段，而且必须是三个不同的名字

主人要的是「同一只猫连叫两声不该一模一样」，所以 `meow` 这个场合的池子里有 **3 个**候选，
每次点击**随机抽一个**。

- **三段都放** → 随机生效，连点两下听到的是两声不同的猫叫。
- **只放一段** → 也完全可用，只是每次都响同一个（池子里有几个算几个，**不是**"缺了就报错"）。
- **三段写成同一个主干**（比如都叫 `cat-click`）→ 功能看着是好的，有声音、不报错，
  但**随机没了**，而且没人会去数池子里有几个。所以名字必须不一样。

> 抽签只在**已经解码完成**的候选里进行。开机那一瞬间还没解完的会被跳过 ——
> 否则会变成"三分之一的点击没声音"，而那看起来像"有一段音频文件是坏的"。

### 关于那七个合成音

**一个都不放也全都有声音** —— 这是设计，不是"半成品"。想换成自己的素材再放。

如果只打算换一两个，**优先顺序建议**：
1. `chapter-complete`（练习收工，缺了会显得"做完没反应"）
2. `click`（用得最多，但也是最容易被听烦的一个 —— **宁缺毋滥**）
3. `nav`、`answer-right`、`answer-wrong`

> 题外话：`click` 是最容易"听两天就想关掉"的音效。**合成的那一版已经刻意做得很轻**，
> 而且设置页里有关掉音效的总开关。真觉得吵，**关掉开关比换素材省事**。

### 两个刻意不加音效的地方（不是漏了）

| 位置 | 为什么不出声 |
|---|---|
| **滚动代码 / 滚动课文 / 滚动列表** | 滚动是**连续动作**，一秒能触发几十次。给它配音效的话，要么叠成噪音、要么被节流掐成"咔、咔、咔"的断续声 —— 两种都难听。**滚动的反馈是画面动，不是声音。** |
| **在代码框里打字** | 键盘已经有声了（用户自己的键盘）。每一键再叠一个音，等于把打字变成打电报。**这个决策是刻意保留的。** |

## 二、硬性要求

| 项 | 要求 | 为什么 |
|---|---|---|
| **文件名** | **必须【全小写】**、用**短横线**连接 | ⚠️ **最容易踩的一条，见下** |
| **格式** | `mp3` / `ogg` / `wav` / `m4a` 四种都认 | 不用为了它转格式，你手上是什么就放什么 |
| **采样率** | 任意（44.1k / 48k 都行） | 播放器会自己处理 |
| 声道 | 单声道或立体声都行 | — |
| **不要放** | 子文件夹、中文名、空格、`.flac` / `.aac` | 放了**不会报错**，只会"没声音" |

### ⚠️ 文件名必须全小写 —— 这条错了完全不报错

代码是按**字符完全相等**去认文件的，而且**大小写敏感**：

| 文件名 | 结果 |
|---|---|
| `cat-click-1.mp3` | ✅ 认得 |
| `Cat-Click-1.mp3` | ❌ **认不出**，点了猫咪没声音，**且没有任何提示** |
| `cat_click_1.mp3` | ❌ 下划线不认，只认短横线 |
| `cat-click.mp3` | ❌ 少一个编号就不认（少了它 → 池子里只剩两段） |
| `cat-click-1-2.mp3` | ❌ 多一个字就不认 |
| `catClick1.mp3` | ❌ 驼峰不认 |
| `cat-click-1.MP3` | ✅ **扩展名的大写没问题**（这个不敏感） |

**只认文件名主干的大小写，扩展名随便。** 这条在 Windows 上尤其阴 —— 资源管理器里
看起来一切正常，代码那边就是找不到。

### 同一个名字给了多种格式会怎样

按 `mp3 → ogg → wav → m4a` 的顺序挑**靠前的那个**，其余忽略。
所以「去年导的 wav + 今年导的 mp3」同时躺在目录里，**响的会是 mp3**。
不想有这个悬念就去把不用的删掉。

### 响度：请尽量调到一致

不同来源的音效，**响度几乎不可能一致** —— 一只猫叫的录音可能是通关音乐的十倍响。
全部原样播出来，结果是"有的听不见、有的吓一跳"。

**建议**：所有文件都往 **峰值 -3 dB / 平均 -16 LUFS 左右**靠（Audacity 里用
「响度标准化」Effect → Loudness Normalization，选 LUFS，填 -16 就是两下点击）。

> 如果调完还是觉得某个音太大/太小，**告诉我**，我改一行数字就行，**不用你重新导出文件**。
> 两处：`lib/sfx.ts` 里的 `SFX_GAIN`（**整个场合**一起调）和 `SFX_BASE_GAIN`
> （只调**某一个文件**）。

**为什么需要两张表**：`SFX_GAIN` 一个场合只有一个数，所以它只能修"这个场合整体偏响"。
而"点猫咪"有**三段**随机抽 —— 如果其中一段轻一半，表现是**三分之一的点击明显小声**，
另外两次正常。一个数补不了这种"同一个场合内部不齐"：调大了，另外两段反而炸。
所以另有一张 `SFX_BASE_GAIN` 按**文件名**索引，两张表**相乘**。

### 开头别留静音（这条比响度更要紧）

代码会自动跳过开头的静音（最多看前 0.4 秒，跳的时候留 5 毫秒余量）。
但**能一开始就剪干净更好**：点击音效里，开头每多 100 毫秒的空白，
用户感受到的就是"点完过一会儿才响"。这个模块整套用 `AudioBufferSourceNode`
而不是 `<audio>`，为的就是消掉这个延迟 —— 而**素材里的静音是架构消不掉的**。

### 时长为什么有上限

代码里对每个场合有**最短重触发间隔**（连点保护）：

| 场合 | 最短间隔 |
|---|---|
| `click` | 55 毫秒 |
| `nav` | 90 毫秒 |
| `cat-click-*` / `duck-click` | 260 毫秒 |
| `answer-right` / `answer-wrong` | 320 毫秒 |
| `lesson-complete` | 700 毫秒 |
| `chapter-complete` | 1.1 秒 |
| `challenge-complete` | 1.4 秒 |

一个音效**明显长于**它那一行的间隔时，快速连点会叠成一片：第二声会在第一声还没放完时
就插进来（这是**故意的** —— 同一个 `<audio>` 元素连续播两次会打断第一次，
而连点猫咪时"打断"听起来像卡了一下）。

信噪比提醒：**点击音超过 0.25 秒就会开始"拖"**。它是全应用听得最多的一个音，
短、轻、干脆 —— 这三个词比"好听"重要得多。

## 三、放进来之后

**重开一次 `npm run dev`**（开发模式下 Vite 会自己发现新文件，有时热更新就够，
但重开一次最保险）。然后点一下侧栏那只猫、点一下大肥鱼、做完一节课。

> ⚠️ **「丢进去就生效」只在开发模式（`npm run dev`）成立。**
> 音频是在**打包时**登记进程序的，打包成 exe 之后再往这个目录丢新文件不会出现，得重新打包。
> 这是故意的：素材定稿后基本不会再动，而运行时读目录要额外开一套本地文件读取。

### 没声音怎么自查

按这个顺序查，**每一步都能独立确认**：

1. **设置页 → 音效开关是不是关的**（关着的话代码第一行就返回了）
2. **文件名是不是全小写、主干有没有拼错**（对着上面那张表逐字符看）
3. **扩展名是不是那四个之一**（`.flac` / `.aac` / `.m4b` 都不认）
4. **重开过 dev 了吗**
5. 还不行就告诉我，我去看解码有没有失败

> 「解码失败」是**静默**的：文件坏了、格式不被支持，结果都是"这个音效不响"，
> 而不是弹一个错误框 —— 那比没声音本身更烦人。这也是上面这张自查表存在的理由。

## 四、代码在哪

| 想改什么 | 改哪 |
|---|---|
| 文件名主干（比如想把 `cat-click-1` 改成 `meow-1`） | `src/renderer/src/lib/sfx.ts` 的 `SFX_FILES` |
| 认哪些扩展名、优先级 | 同上，`SOUND_EXT_PRIORITY` |
| **整个场合**太响/太轻 | 同上，`SFX_GAIN`（改数字即可，不用动音频文件） |
| **某一个文件**太响/太轻 | 同上，`SFX_BASE_GAIN`（按文件名索引） |
| 跳过开头静音的判据 | 同上，`ONSET_SCAN_MAX_SEC` / `findOnset()` |
| 多久内不重复响 | 同上，`SFX_THROTTLE_MS` |
| 哪个按钮响哪个音 | `src/renderer/src/lib/sfx-wire.ts` 的 `NATURALLY_CLICKABLE`，或给元素加 `data-sfx="none"` 静音 |

（如果有）也要跟着改 —— 否则你按旧名字放文件，什么都不会发生，而代码那边一个字都不报错。
