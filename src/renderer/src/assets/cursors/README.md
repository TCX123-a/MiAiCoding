# assets/cursors —— 猫爪鼠标指针投放目录

**目录里一张图都没有，这不是错误。** 那时全站用系统手型（`pointer`）——
界面一个像素都不差、一个错误框都不弹。丢进来一张，鼠标立刻变猫爪。
（两张各自独立：只放一张也完全可用。）

> 当前状态（2026-09-15）：**两张都放好了**，由主人给的两张 2048×2048 大图
> 经 `scripts/图片工具/make_cursor.py` 转换而来。转换流程和踩过的坑见第五节。

> 🎯 **一句话**：放两个文件进来，**重开一次 `npm run dev`**，鼠标就是猫爪了。
> 不用改代码、不用改配置、不用告诉我。

完整路径 = 本目录：`src/renderer/src/assets/cursors/`（在仓库根目录下按这个相对路径找）。

## 一、要放哪些文件

一共 **2 张**，一松一按：

| 文件名 | 什么时候显示 | 必需? |
|---|---|---|
| **`cat-claw.cur`**（或 `.png`） | 鼠标**平时**的样子 | 建议 |
| **`cat-claw-click.cur`**（或 `.png`） | 鼠标**按下去**那一瞬间的样子 | 可选 |

只放一张也完全可用：**放哪个哪个变猫爪，没放的那个还是系统手型**。
「只放一半」是完好的中间状态，不是半成品。

### 按下那张做成什么样

真实世界里猫踩下去是**攥住**（趾头往掌心收、掌垫摊平），
不是"整只爪等比缩小"。

> 整只缩小读起来是**"离你更远了"** —— 正好是"按下该有的感觉"的反面。
> 想要"捏紧了"的感觉，就**让趾头往回收，掌垫留在原地别动**。

## 二、`.cur` 还是 `.png`？—— 推荐 `.cur`

两种都认，但**强烈推荐 `.cur`**，理由不是画质：

| | `.cur`（推荐） | `.png` |
|---|---|---|
| 热点（"落点"）从哪来 | **文件自带**，浏览器按文件里的走 | 代码里写死一个：`11 7` |
| 图多大、热点在哪 | **你自己定，代码一个字不用改** | 必须凑成 32×32、爪子对准 (11,7) |
| 想改热点 | 在**你自己的编辑器里**改，存盘即可 | **要来找我改代码** |

**热点 = 鼠标的"落点"。** 它错了不会报错，只会让所有点击**整体偏一截** ——
表现为"点小按钮时总觉得差一点点没点到"，而这种感觉几乎没人会归因到指针上。

> ⚠️ 现在这对 `.cur` 里烘的热点也是 **`11 7`** —— 和 `.png` 那条路**故意取同一个值**。
> 两处不一样的话，"用 png"和"用 cur"会得到两种手感，而这种差异**没有任何界面能看出来**。
> 想让 `.cur` 用别的位置，去 `scripts/图片工具/make_cursor.py` 改 `HOTSPOT` 再重跑一次；
> 想让 `.png` 用别的位置，改 `cursor-assets.ts` 的 `PAW_HOTSPOT`。**改一处要想起另一处。**
>
> 换算成图上的说法：(11,7) 落在**左上那个肉垫的左侧**，压在实处 —— 不是空白。

### 用 `.png` 的话：热点是 `11 7`

- 图必须是 **32×32**（别的尺寸也能跑，但热点坐标是按 32×32 定的，会偏）
- **爪尖要落在 (11, 7) 这个点上** —— 从左上角往右 11 像素、往下 7 像素
- 也就是说：图形**不要居中**，要**偏左上**摆，让爪尖压住 (11,7)

> 那个 `11 7` 写在 `src/renderer/src/lib/cursor-assets.ts` 的 `PAW_HOTSPOT` 里，
> 想改随时说。

## 三、硬性要求

| 项 | 要求 | 为什么 |
|---|---|---|
| **文件名** | **必须全小写**，短横线连接，一个字符都不能差 | ⚠️ 见下 |
| **格式** | `.cur`（推荐）或 `.png`，**带透明通道** | 不透明的话指针是一个**方块**，把下面的字全挡住 |
| **尺寸** | 32 × 32（标准）。最大别超 64 × 64 | 见下 |
| **两帧热点必须一致** | 用 `.cur` 时两个文件里存的热点值要一样 | 见下 |
| **不要放** | 子文件夹、中文名、空格、`.ico` / `.svg` / `.bmp` | 不会报错，只会"没生效" |

### ⚠️ 文件名必须全小写 —— 这条错了完全不报错

| 文件名 | 结果 |
|---|---|
| `cat-claw.cur` | ✅ 认得 |
| `Cat-Claw.cur` | ❌ 认不出，鼠标还是系统箭头，**且没有任何提示** |
| `cat_claw.cur` | ❌ 下划线不认，只认短横线 |
| `cat claw.cur` | ❌ 空格不行 |
| `cat-claw-normal.cur` | ❌ 多一个字就不认（`cat-claw-click` 是**唯一**例外，它是另一个位置的名字） |
| `cat-claw.CUR` | ✅ **扩展名的大写没问题** |

**只认文件名的大小写，扩展名随便。** Windows 上尤其阴：资源管理器里看着一切正常，
代码那边就是找不到。

### 尺寸为什么是 32×32

- **32×32** 是 Windows 的标准指针尺寸，和系统箭头一样大，混在一起最自然
- 图比 32 大，系统会**缩着画** —— 缩小后的猫爪细节会糊，而且边缘发灰
- **超过 128×128 浏览器会直接拒收**，退回系统 `pointer`，**同样一声不吭**
- 所以：按 32×32 出图，或者 64×64 出图后自己缩到 32

### 两帧热点必须一致

用 `.cur` 的时候，浏览器按**每个文件各自存的**热点去定位。两个文件热点不一样的话：

**按下的瞬间指针会跳一下** —— 而且因为形状也变了、边缘也跟着挪，
看起来会像是"点偏了"，很难联想到是指针的问题。

### 两种格式同时存在会怎样

**`.cur` 优先**。所以「试完 png 忘了删旧的」不会出意外，跟着 `.cur` 走。

## 四、四种刻意保留的、不带猫爪的位置（不是漏了）

| 位置 | 手型 | 为什么保留 |
|---|---|---|
| 三栏拖宽窄的**分界线** | `col-resize` / `row-resize` | 它携带的信息比主题重要：这里能拖 |
| **禁用**状态的按钮、锁着的课 | `not-allowed` | 「这里点不动」必须一眼看出来 |
| 代码**正在运行**时 | `progress` | 「它在忙，别重复点」 |
| 草稿课、不可用的运行按钮 | `default` | 刻意做成"这里不能点"（和"能点但没做"区分开） |

### 还有一个刻意保留的：代码框里是 **I 型光标**

在编辑器和输入框里，鼠标是**竖线 I 型**而不是猫爪。**这是刻意的，不要改：**

- I 型是全世界通用的「这里能输入文字」信号，换掉它会让打字这件事变得犹豫
- 猫爪压在代码上会**挡住字符**，而代码是逐字符读的

> 同一处的**输入插入符**（闪烁的那条竖线）已经换成了小鱼干，那个保留、不改头型。

## 四点五、这两张 `.cur` 是怎么来的（换图时照做）

主人给的是两张 **2048×2048** 的 AI 出图（白底白猫爪），不能直接用。转换脚本：

```bash
python scripts/图片工具/make_cursor.py <松开图.png> <按下图.png> [输出目录]
python scripts/图片工具/make_cursor.py --check <松开图.png> <按下图.png>   # 只量不写
```

**换图时重跑一遍就行**，不用手工抠。它会打出每一步量到的数，改了哪个数、为什么，都在
脚本里写着。三个必须知道的点：

### ① 白猫爪画在白背景上 —— 不能按"颜色差"抠

实测背景是暖白 `(252,251,247)`、猫爪的毛是 `(254,246,233)`：**肉眼看不出区别**。
红通道差 2、绿通道差 5，都在噪声里。唯一稳定的差别在**蓝通道**。
所以判据用的是**黄度** `(R+G)/2 - B`：背景 0~5，毛 15~24，中间隔着一整个数量级。

> 用"接近背景色就透明"的色键在这里**必错**，而且两种错法都不报错：
> 阈值小了抠不干净（边缘一圈脏），大了把整只爪子吃掉。

### ② 右下角那行「豆包AI生成」是**裁掉的**，不是涂掉的

原图右下角有水印（实测 `x[1691,2015] y[1935,2010]`）。它和爪子的 **x 范围有重叠**
（爪子到 x=1776），但 **y 完全不重叠**（爪子只到 y=1712）。
所以裁到爪子的包围盒，水印**自然落在框外** —— 不需要任何涂抹或修补。

⚠️ **这两张能这么办是运气，不是通则。** 换图时若水印和爪子有重叠，
脚本会**当场报警**（`⚠️ 水印 … 和裁框有重叠`）—— 那时得先手工擦掉再跑。

### ③ 两帧必须共用一个裁框

按各自的包围盒分别裁、各自缩到 32×32，会让两帧的**缩放比不一样** ——
松开和按下之间整只爪子突然胖一圈或跳一下，看起来像"指针歪了"。
脚本取**两个包围盒的并集**再裁成正方形，两帧的几何关系原样保留。

> 顺带一提，"按下"那张本来就更摊开一点 —— 那是素材自己的效果，
> 共用裁框不会把它抹平，反而正是要保住的东西。

## 五、放进来之后

**重开一次 `npm run dev`**，然后把鼠标移到任意一个按钮上。

怎么确认「按下的那张」也生效了：**按住鼠标左键别松**，看指针有没有变成攥住的姿势。

> ⚠️ **「丢进去就生效」只在开发模式（`npm run dev`）成立。**
> 图片是在**打包时**登记进程序的，打包成 exe 之后再往这个目录丢新文件不会出现，
> 得重新打包。这是故意的：素材定稿后基本不会再动，而运行时读目录要额外开一套本地文件读取。

### 没生效怎么自查

1. **文件名对着上面那张表逐字符看**（大小写！短横线！）
2. **扩展名是不是 `.cur` / `.png`**（`.svg` / `.ico` / `.bmp` 都不认）
3. **重开过 dev 了吗**
4. 如果是 `.png`：**尺寸是不是 32×32、爪尖在不在 (11,7)**
5. 还不行就告诉我，我去看文件有没有被浏览器拒收

还有一个**迷惑性强**的情况要先说清楚：如果放进去之后**全站的"手型"（能点的那种手）
突然都消失了**，那多半不是猫爪图的问题，而是拼出来的 `cursor` 值少了个关键字 ——
这是本项目踩过的一个深坑，原因和防护写在 `src/renderer/src/styles/cursor.css`
开头那段长注释里。真遇到了告诉我，我改一行就好。

| 重新抠图（换了素材图） | `python scripts/图片工具/make_cursor.py <松开> <按下>`，先加 `--check` 量一遍 |
| 某个位置**不要**猫爪 | 那个组件的 CSS 里，把 `var(--mi-cursor, pointer)` 改回 `pointer`，一行、就地改 |

改文件名的话，**这份 README 里的名字要一起改** —— 否则你按旧名字放文件，
什么都不会发生，而代码那边一个字都不报错。
