## 钩子：写到手酸的「加三个数」

本喵的鱼干账本最近很热闹：有时候一天只有两条鱼干进账，有时候五条，有时候七条。本喵就写了好几个招式 —— 「加两个数」一个、「加三个数」一个、「加四个数」又一个。它们长得几乎一模一样，只是口袋里多塞了几个名字。

写到第四个的时候本喵烦了：**能不能只写一张图纸，来几条鱼干就量几条？**

上一阶段本喵学过**模板（会量体裁衣的图纸）**：给图纸留一个空位，来什么就裁什么。可那张图纸一次只留**一个**空位 —— 今天要的是「**来几样都行**」。C++ 给这种图纸留了个特别的写法：一个**省略号** `...`。这一课就来看看这个省略号能替本喵省下多少行喵。

## 一、先说那个省略号：一包东西

```cpp
#include <iostream>
using namespace std;

template <typename... Args>
int countAll(Args... args) {
    return sizeof...(args);
}

int main() {
    cout << countAll() << endl;
    cout << countAll(1) << endl;
    cout << countAll(1, 2, 3) << endl;
    cout << countAll("小鱼干", 2, 3.5, "猫粮") << endl;
    return 0;
}
```

```text
0
1
3
4
```

拆开看这两行：

- `template <typename... Args>` 是**图纸上留的那个空位**，只是这次留的是**一包**：`Args...` 念作「来多少样都行，全装进这一包」。名字叫 `Args` 还是别的都行，前面的三个点才是要紧的。
- `Args... args` 是**把这包东西原样收下**。收下来的名字叫 `args`（本课后面都叫它**一包东西**）。
- `sizeof...(args)` 念作「**这包里装了几样**」。注意那三个点在括号**里面** —— 写成 `sizeof(args)` 就问不出样数了。

它替本喵省掉了什么？上面四个印出来的数分别是 `0`、`1`、`3`、`4`：**空手来也收、一样也收、四样也收**，而图纸只写了一张。包里装的东西还能**各不相同**（字、整数、小数混着来都行）—— 这就是「量体裁衣」这四个字最爽的地方。

## 二、把一包东西合起来

包里装的是数的时候，本喵想全加起来：

```cpp
#include <iostream>
using namespace std;

template <typename... Args>
int addAll(Args... args) {
    return (args + ...);
}

int main() {
    cout << addAll(1, 2, 3) << endl;
    cout << addAll(4, 5) << endl;
    return 0;
}
```

```text
6
9
```

`(args + ...)` 这一句念作「**把包里每一样挨个用 `+` 串起来**」—— 三个点站在哪一边，就决定了往哪边走：

- `(args + ...)` 从**头**一样一样加下去：`1 + 2 + 3`。
- 换成 `(... + args)` 是从**尾**加起。加法左右都不讲究，两个写法答案一样；换上 `-` 这种讲究先后的算子，两个写法就**不一样了**。

那要是包是空的呢？本喵把 `addAll()` 也印一下试试：

```cpp
#include <iostream>
using namespace std;

template <typename... Args>
int addAll(Args... args) {
    return (args + ...);
}

int main() {
    cout << addAll() << endl;
    return 0;
}
```

翻译官喵当场犯难：

```text
main.cpp:6:18: error: fold of empty expansion over operator+
```

念作「**这一串是空的，我没法把它们串起来**」。它说的是实话：一样东西都没有的时候，`+` 不知道该拿谁跟谁加。要收空手来的包，就**在末尾垫一个底**：

```cpp
#include <iostream>
using namespace std;

template <typename... Args>
int addAll(Args... args) {
    return (args + ... + 0);
}

int main() {
    cout << addAll(1, 2, 3) << endl;
    cout << addAll() << endl;
    return 0;
}
```

```text
6
0
```

`(args + ... + 0)` 比刚才多了最后那个 `+ 0`：意思是「**串完之后再拿 `0` 加一下**」。包里满满的时候它一点不影响结果（加 0 嘛）；包是空的时候，它就当了那个「一样东西都没有」的答案。

::: warn 小心喵
**垫的那个底，得是这件事的「空答案」。** 加法的空答案是 `0`；要是往包里全乘起来（`(args * ... * 1)`），垫的就该是 `1` —— 垫 `0` 的话，再多的数乘下来也全变成 `0` 了。写之前先问自己一句：**一样都没有的时候，这件事该给出什么？**
:::

## 三、先点名一个，剩下的打包

有时候头一样东西要单独拿出来对待，剩下的才打包：

```cpp
#include <iostream>
using namespace std;

template <typename T, typename... Rest>
void firstThenRest(T first, Rest... rest) {
    cout << "头一个：" << first << endl;
    cout << "后面还有 " << sizeof...(rest) << " 个" << endl;
}

int main() {
    firstThenRest("小鱼干", 1, 2.5, "猫粮");
    firstThenRest("只有它一个");
    return 0;
}
```

```text
头一个：小鱼干
后面还有 3 个
头一个：只有它一个
后面还有 0 个
```

图纸上先写了 `T first` 占住**头一个**，后面才是那一包 `Rest... rest`。喂进去的东西按顺序站好：第一位进了 `first`，后面的全进包里。第二回只喂了一样，包里就是**空的**（`sizeof...(rest)` 给出 `0`）—— 空包在这里不闹脾气，因为本喵没去串它，只是问了问它有几样。

这个「先点名一个、剩下的打包」的形状，是很多现成招式都在用的写法：一刀切下头一个，剩下的再原样传给下一轮。

## 四、印东西也一样

`+` 能串，`<<` 也能串 —— 一包东西可以挨个印出来：

```cpp
#include <iostream>
using namespace std;

template <typename... Args>
void printAll(Args... args) {
    (cout << ... << args);
    cout << endl;
}

int main() {
    printAll("小鱼干 ", 3, " 条");
    printAll("猫粮", " 和 ", "毛线球");
    return 0;
}
```

```text
小鱼干 3 条
猫粮 和 毛线球
```

`(cout << ... << args)` 念作「**把包里每一样依次递给 `cout`**」：先印第一样，印出来的东西接着当左边，再印第二样…… 一圈下来就串成了一整句。最后那个 `cout << endl;` 是另起一行用的，跟这一包没关系。

::: tip 猫咪提示
`(args + ...)` 和 `(cout << ... << args)` 是同一个形状，区别只是**中间站的是哪个符号**。看着这套写法，本喵第一反应是「这也行？」，可真跑起来它就是这么老实：包里几样，就串几下。
:::

## 五、混着喂的坑

量体裁衣最省事的地方是「来什么裁什么」，可它也有个不声不响的坑：

```cpp
#include <iostream>
using namespace std;

template <typename... Args>
int addAll(Args... args) {
    return (args + ...);
}

int main() {
    cout << addAll(1, 2, 3) << endl;
    cout << addAll(1, 2.5) << endl;
    return 0;
}
```

```text
6
3
```

第二行印的是 `3`，可 `1 + 2.5` 明明是 `3.5`。毛病出在图纸上写的那个 `int`：包里算出来的是 `3.5`，**交回去的时候按图纸写的裁成整数**，小数点后面那截就没了。

::: warn 小心喵
**图纸上写什么形状，交回来就是什么形状。** 混着小数的场面，要是把交回来的形状写成 `int`，那半条鱼干就悄悄没了 —— 而且**不报错、不提醒**，只有一个看起来「差不多」的数。要小数就换成 `double`，拿不准就自己先真跑一遍看看印出来是什么。
:::

## 一句话对照表

| 想干什么 | 写什么 |
|---|---|
| 说明这次来的是一包东西 | `template <typename... Args>` |
| 把这包东西原样收下 | `Args... args` |
| 数一数包里装了几样 | `sizeof...(args)` |
| 把包里每一样用 `+` 串起来 | `(args + ...)` |
| 串完再垫一个底 | `(args + ... + 0)` |
| 把包里每一样递给 `cout` | `(cout << ... << args)` |
| 先点名一个，剩下的打包 | `template <typename T, typename... Rest>` |

## 小任务

1. 写一张图纸 `countAll`，喂它 0 样、3 样、5 样东西，看看印出来的数对不对得上。
2. 把第二节那个 `(args + ...)` 换成 `(... + args)` 跑一遍 —— 加法两边不讲究先后，印出来的数应该一样。
3. 试着写一个「把包里每一样乘起来」的图纸，想想**空包**的时候该垫什么底（提示：想想 `1` 和 `0` 谁是乘法的空答案）。
4. 把第五节的图纸改成交回 `double`，再跑一遍 `addAll(1, 2.5)` —— 这回印出来的是多少？
