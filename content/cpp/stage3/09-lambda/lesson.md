## 钩子：上一课说好的「塞进排排坐里」

上一课结尾本喵留了个话头：要把招式塞进「给小鱼干排排坐」那件活儿里。今天就是它 —— **lambda 表达式**，本喵管它叫「**顺手就能用的小招式**」。

它治的是一个很具体的麻烦：有些招式**只用一次**，可为了用它，本喵得先给它起个名字、写到别的地方去，回头还得跑一趟才找得着。lambda 的办法很干脆：**当场写、当场用、不用起名字。**

## 一、先看那件麻烦事

「给小鱼干排排坐」这件事本喵干不了，得告诉它**谁该排在前面**。最老实的写法是专门写一个具名招式，摆在一边备用：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

bool biggerFirst(int a, int b) {
    return a > b;
}

int main() {
    vector<int> v = {3, 1, 4, 1, 5};
    sort(v.begin(), v.end(), biggerFirst);
    for (int x : v) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

```text
5 4 3 1 1
```

`biggerFirst` 这个名字，本喵这一辈子**只用了那一次**（`sort` 那一行），之后再没碰过。

招式本身只有一行 —— 「谁大谁站前面」。可名字、投喂口、外面那圈括号，一样都不能少。这就是今天要省的力气喵。

::: tip 猫咪提示
排排坐那件活儿要的「谁该站前面」不是一个数，而是**一段判断**：喂进去两条、叼回来「是的」或者「不是的」。所以它要的不是一个数，是一段小招式。本喵以前只能给它一个起了名字的招式，今天开始可以**当场喂一段**。
:::

## 二、同一件事，就地写

lambda 的样子是这样：把上面那段具名招式**整段搬进那一行**，然后把**头上的名字删掉**，换成一对方括号：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {3, 1, 4, 1, 5};

    sort(v.begin(), v.end(), [](int a, int b) {
        return a > b;
    });

    for (int x : v) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

```text
5 4 3 1 1
```

两段的输出**一模一样**，因为干的本来就是同一件事。对着这一行，四件东西就认全了喵：

| 那一截 | 是什么 |
|---|---|
| `[]` | **包裹** —— 本喵能从外面往里头带东西的地方（这一节先留空） |
| `(int a, int b)` | **投喂口** —— 和具名招式长得一模一样，谁该站前面就看它 |
| `{ return a > b; }` | **身子** —— 招式本身 |
| 那一行**前面没有名字** | 这就是 lambda：**没名字**的小招式，写完就地用掉 |

::: tip 猫咪提示
三截里只有 `[]` 是本喵没见过的。认 lambda 的办法就是**先找那副方括号** —— 它一冒头，后面跟着的就是「谁都能当场写的小招式」。投喂口和身子那两截，跟本喵平时写招式**一个字都没差**。
:::

## 三、外面的东西，不写就看不见

上面那个 `[]` 是空的，说明这段小招式**靠自己活着** —— 只碰喂进来的东西。可要是本喵想用外面那个 `limit` 呢？直接写是不行的：**不写进方括号，小招式里就看不见它**，翻译官喵会当场拦下来。

要带就得写在方括号里，像这样：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {3, 1, 4, 1, 5};
    int limit = 3;

    int n = count_if(v.begin(), v.end(), [limit](int x) {
        return x > limit;
    });

    cout << "比 " << limit << " 大的有 " << n << " 个" << endl;
    return 0;
}
```

```text
比 3 大的有 2 个
```

`[limit]` 干的事就一句：**把外面那个 `limit` 揣一份带进来**。带进来的是**一份副本**，所以小招式里怎么用都行、也**改不动**外面那一个。本喵只读它，这样最省心。

顺带认一下 `count_if`：它挨个拿过去，把小招式喂进去问一句「这个算不算」，算的就把手里的数加一。最后叼回来「一共有几个算」 —— 上面那 2 个，就是 4 和 5。

## 四、要改外面那个，就得共用同一个

上一节那种带法是「揣一份」。可要是本喵想让**外面那个数跟着涨**呢？比如亲手数一数有几个合格的。这时候带进来的不能是副本，得是**同一个**：方括号里加一个 `&`。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {3, 1, 4, 1, 5};
    int limit = 3;
    int count = 0;

    for_each(v.begin(), v.end(), [&count, limit](int x) {
        if (x > limit) {
            count++;
        }
    });

    cout << "比 " << limit << " 大的有 " << count << " 个" << endl;
    return 0;
}
```

```text
比 3 大的有 2 个
```

方括号里带了两个名字，带法却不同喵：

- `&count` —— **共用同一个**。小招式里 `count++`，外面那个 `count` 跟着涨，所以它最后是 2；
- `limit` —— **揣一份**。小招式只读它，不需要共用，揣一份最安全。

两种带法能混在一栏里写，本喵挑的办法只有一句话：**「我要改它吗？」** 要改就加 `&`，只读就不加。

::: warn 小心喵
`&` 共用的那个名字**必须比小招式活得久**。要是共用一个已经没了的名字，那就是拿着一块作废的门牌去开门 —— 第七课那套「用完就还仓库」在这儿格外要紧。

这条规矩今天还不咬人，等本喵把 lambda **存起来、回头再拿出来跑**的时候它就会咬 —— 那时候先记住一句话：**共用出去的东西，别让它先死。**
:::

## 五、什么时候写它

本喵的经验是看两件事：

- **用几次**：只用一次、又很短 → lambda，当场写当场用；要用好几次、或者得想半天才读得懂 → 老老实实起个名字，写在外头更好读；
- **跟谁搭伙**：要跟排排坐、挨个数、一个个过一遍这类活儿搭伙 → lambda 最顺，因为「谁该站前面」「算不算数」这种判断**只有那一处用得上**，为它起名字纯属多余。

还有一条顺手的好事：lambda 里**用外面的货**这件事，是写在方括号里给读的人看的。一眼扫过去就知道这段小招式**碰了外头的哪些东西** —— 具名招式没这个本事，它要用外面的东西，本喵得把整段读完才看得出来。

## 一句话对照表

| 想干什么 | 写什么 |
|---|---|
| 就地写一段小招式 | `[](int a, int b) { return a > b; }` |
| 把外面的东西带进来（只读它） | `[limit](int x) { return x > limit; }` |
| 带进来，还要改外面那个 | `[&count](int x) { count++; }` |
| 两种带法混着写 | `[&count, limit](int x) { ... }` |
| 跟排排坐搭伙 | `sort(v.begin(), v.end(), 小招式)` |
| 「没名字」这件事 | 那一行前面没有名字，写完就丢掉，不用管它 |
