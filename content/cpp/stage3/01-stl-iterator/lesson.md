## 钩子：碗数是钉死的，可鱼干天天在变多

前面几课里，本喵存一堆小鱼干只有一个办法：摆一**排钉死的猫粮碗** —— 摆的时候就得说清楚「要几格」，说完就再也改不了。想多存一条？没地方放；想少存几条？空碗还占着地方，本喵看着就心疼。

可猫粮天天在变啊喵：今天大肥鱼送来三条，明天送来八条。本喵真正需要的是**会自己长大的储物柜**。

好消息是：C++ 早就替本喵备好了整整一仓库现成的家当，行话叫 **STL**（念作「三个字母」就行）。今天本喵先带你把这片仓库逛一遍，看清楚它装了哪三样东西；再把最重要的那一样学扎实 —— **怎么一格一格地走完一个柜子**。

## 一、STL 地图：三样家当

STL 这个仓库里，能拿出来用的家当分成三堆：

| 家当 | 是干什么的 | 本喵的叫法 |
|---|---|---|
| **柜子** | 装东西的地方 —— 会自己长大、自己缩小的各种储物柜 | 容器 |
| **爪子** | 指着柜子里某一格的「一指就到的牌子」，能从这格挪到下一格 | 迭代器 |
| **招式** | 现成的干活本领：排排坐、找东西、整柜换货…… | 算法 |

三样里，**柜子和爪子今天就要用**；现成招式是后面某一课的正题（今天只在最后远远看一眼）。

这三样的关系很像本喵收拾鱼干的全套流程：柜子负责装、爪子负责指着「现在这一格」、招式的活是「把这些柜子搬来搬去地折腾」。**爪子是把柜子和招式缝在一起的那根线** —— 所以它今天是主角。

## 二、第一只柜子：会自己长大的 `vector`

本喵先把最常用的那只柜子请出来，它叫 `vector`（念「维克特」）。

请柜子的规矩和以前一样：开头写一句 `#include`，把 `vector` 借出来。然后就可以照下面这样用了：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);
    v.push_back(5);
    cout << v.size() << endl;
    cout << v[0] << endl;
    return 0;
}
```

```text
3
3
```

逐句拆开看：

1. **`vector<int> v;`** —— 开一只柜子，起名叫 `v`。名字后面那对**尖括号**里写的是 `int`，意思就是「这只柜子里只放整数」。这句一念完，柜子是**空的** —— 空的没关系，它会自己长大。
2. **`v.push_back(3);`** —— 往柜子**最后面塞一格**，塞进去的是 `3`。（`push_back` 念作「扑许·拜克」，字面意思就是「从后面推」。）
3. **`v.size()`** —— 问「柜子里现在有几格」。塞了三条，所以印出 `3`。
4. **`v[0]`** —— 报编号取货，**编号从 0 数起**，和上一阶段那排猫粮碗一模一样。

和那排钉死的猫粮碗比一比：`push_back` 是本课最舒服的一件事 —— **不用事先说好要几格**。塞一条它就长一格，塞一百条就长一百格。

::: tip 猫咪提示
`vector` 就是「会自己长大的储物柜」，学名**容器**。它比那排钉死的猫粮碗多给的东西不止一样：`push_back` 能随时加、`size()` 能随时问、还能整柜一起递给别人。**今天先记住这三个动作：开柜子、塞一格、问几格。**
:::

## 三、爪子：`begin()` 和 `end()`

柜子有了，现在的问题是**怎么一格一格地走**。

报编号当然也行（`v[0]`、`v[1]`、`v[2]`……），可本喵得自己数到几才停 —— 万一柜子里有三百格呢？本喵想要的是**一只爪子**：它指着「现在这一格」，本喵喊一声「挪」，它就自己挪到下一格。

C++ 给的正是一对这样的爪子：

- **`v.begin()`** —— 一只指着**第一格**的爪子；
- **`v.end()`** —— 一只指着**最后一格的后面一格**的爪子。

`end()` 这句要停下来多想一秒喵：它指的**不是最后一格**，而是最后一格**再往后一格** —— 那一格是**不存在**的，它更像柜子尽头站着的一个「到此为止」的看门猫。为什么要这样？因为这样一来，「走完了没有」就有了一个特别干脆的判据：**爪子挪到和 `end()` 站在一起，就是走完了**。

这两只爪子合起来，就是本喵走柜子的标准姿势：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);
    v.push_back(5);

    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << endl;
    }
    return 0;
}
```

```text
3
8
5
```

拆开看这跑法：

- **`auto it = v.begin()`** —— 起一只叫 `it` 的爪子，一开始指着第一格。（`auto` 是「你自己看着办，名字替我写上」；不写它也成，只是那一长串名字本喵懒得敲。）
- **`it != v.end()`** —— 只要爪子**还没走到看门猫那儿**，就继续跑。
- **`*it`** —— 把爪子指着的**那一格里的货**取出来。**那颗小星星读作「指着的那一格」**，少了它，取到的就不是货了（下面有现成的报错）。
- **`++it`** —— 把爪子**挪到下一格**。

### 最容易摔的一跤：少了那颗小星星

`it` 和 `*it` 长得只差一个字符，可意思差着一整格货：`*it` 是「指着的**那一格**」，`it` 是「**牌子本身**」—— 牌子不是一个用来印的整数，翻译官喵不认。本喵拿下面这段真跑过一遍，它当场就把本喵拦下了：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);

    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << it << endl;
    }
    return 0;
}
```

```text
main.cpp:11:14: error: no match for 'operator<<' (operand types are 'std::ostream' {aka 'std::basic_ostream<char>'} and '__gnu_cxx::__normal_iterator<int*, std::vector<int> >')
      11 |         cout << it << endl;
```

念作：**「`<<` 的右半边要的是一个能印的东西，你递过来的是一张 `__gnu_cxx::__normal_iterator` —— 也就是『爪子』。爪子印不出来。」** 看到 `no match for 'operator<<'`，先低头看 `<<` 右边那一坨：**该有的星星是不是漏了。**

## 四、走柜子的三套姿势

同一件事（把柜子从第一格走到最后一格），C++ 里有三套写法。本喵建议你这样记：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);
    v.push_back(5);

    cout << "用爪子：" << endl;
    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << endl;
    }

    cout << "用新写法：" << endl;
    for (int x : v) {
        cout << x << endl;
    }

    cout << "报编号：" << endl;
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << endl;
    }
    return 0;
}
```

```text
用爪子：
3
8
5
用新写法：
3
8
5
报编号：
3
8
5
```

**第二套写法**长得像念咒：`for (int x : v)` 念作「**把 `v` 里的货，一格一格地交给 `x`**」。这一套最短、最不容易写错，日常用得最多。

**第三套**就是报编号 —— 它和上一阶段那排猫粮碗的走法一样。注意这里有个细节：`v.size()` 给的格数，所以编号跑到 `v.size() - 1` 就是最后一格了，条件是 `i < v.size()`，别写成 `<=`。

三套怎么挑？本喵的经验是：

| 想干什么 | 用哪套 |
|---|---|
| 只把每一格拿出来看看、算一算 | `for (int x : v)` —— 最短最省事 |
| 要边看边改柜子里的货 | 用爪子那套，星星前面加一个 `&` |
| 要的是编号（比如「第几格最大」） | 报编号那套 |
| 要往中间插、要删中间的格 | 爪子那套（收在后面某一课） |

### 一个不吵不闹的坑：`int x` 改的是副本

上面那张表第二行那句「星星前面加一个 `&`」，是本课最值钱的一个细节。先看**没有** `&` 的时候会发生什么：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(1);
    v.push_back(2);
    v.push_back(3);

    for (int x : v) {
        x = x * 2;
    }

    for (int x : v) {
        cout << x << endl;
    }
    return 0;
}
```

```text
1
2
3
```

**柜子里的货一个都没变。** 本喵拿最啰嗦的那档念叨（`-Wall`）真跑过一次，翻译官喵**一个字都没说**：编得过、跑得完、结果悄悄地不对。

原因是这套新写法里，`x` 拿到的是**那一格货的一份副本** —— 像本喵从柜子里把鱼干捞出来放在旁边看。改副本，柜子里那份纹丝不动。

要让改动真的落回柜子里，写 `for (int &x : v)` —— 星星前面多一个 `&`，意思是「**这个 `x` 就是柜子里那一格本人**，不是副本」。同一份 `main`，只改这一个字符，再跑一次：

```text
2
4
6
```

**一字之差，从「改了白改」变成「真改动了」。** 这类坑不报错、不警告，只能靠自己记住：**要动柜子里的货，名字前面写 `&`。**

::: warn 小心喵
`end()` 那一格**是不存在的**，千万别去取货（`*v.end()` 是错的）。它唯一的用处就是当那个「到此为止」的路标。本喵的判别口诀是：**爪子和 `end()` 站在一起时，柜子就已经走完了** —— 那时候不该再取货，该收工了。
:::

## 五、本喵今天记住的三句话

::: tip 猫咪提示
1. **STL 有三样家当**：柜子（容器）、爪子（迭代器）、现成招式（算法）。今天用的是前两样。
2. **`vector` 是会自己长大的储物柜**：`v.push_back(x)` 往后塞一格、`v.size()` 问几格、`v[i]` 报编号取货（编号从 0 起）。
3. **走柜子的标准姿势**：`for (auto it = v.begin(); it != v.end(); ++it)` —— `*it` 是那一格的货、`++it` 是挪到下一格；嫌啰嗦就用 `for (int x : v)`，**要改货就写 `for (int &x : v)`**。
:::

| 本喵写下的 | 它的意思 |
|---|---|
| `vector` 后面尖括号里写 `int`、再起名 `v` | 开一只只放整数的柜子（一开始是空的） |
| `v.push_back(3);` | 往柜子最后面塞一格，塞的是 `3` |
| `v.size()` | 柜子里现在有几格 |
| `v[0]` | 报编号取货，**编号从 0 数起** |
| `v.begin()` | 指着**第一格**的爪子 |
| `v.end()` | 指着**最后一格的后面一格**的爪子（那格不存在，是路标） |
| `for (auto it = v.begin(); it != v.end(); ++it)` | 从第一格走到走完为止 |
| `*it` | 爪子**指着的那一格里的货** |
| `++it` | 把爪子挪到下一格 |
| `for (int x : v)` | 一格一格地看每一份**副本** |
| `for (int &x : v)` | 一格一格地**直接动柜子里的货** |

## 小任务

1. 把本课第二节那段柜子代码的 `cout << v[0]` 改成 `cout << v[v.size() - 1]`，真跑一次 —— 印出来的是不是最后塞进去的那条？
2. 在第三节那段爪子的代码里，把 `++it` 那一句**删掉**，真跑一次。会发生什么？（提示：爪子一直指着第一格，于是跑圈永远走不完 —— 自己动手看一看，比本喵讲一百遍都清楚。）
3. 把第四节那段「改副本」的代码里的 `int x` 改成 `int &x`，真跑一次，看看输出从 `1 2 3` 变成什么。
4. 用 `push_back` 塞**五个**数进柜子，然后用报编号那套写一句 `cout`，把它们的**总和**印出来。
5. 想一想：为什么 `end()` 指的偏偏是「最后一格的**后面**一格」，而不是最后一格本人？试着用屁股想一想：要是它指着最后一格，跑圈的条件该写成什么？（提示：那样就得写成「还没到最后一格**或者**刚到最后一格」—— 两种条件拼在一起，比现在这一句麻烦得多。）
