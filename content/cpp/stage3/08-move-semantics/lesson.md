## 钩子：上次那句「打招呼搬家」，到底搬了什么

前面「智能指针」那一课本喵说过一件事：牌子不许复制，想换主人得**打招呼**（`move(a)`），搬完旧牌子就空手了。当时本喵只说了个大概，今天把盖子掀开看：

**那个招呼本身，一个字节都没搬。**

真的把货挪过去的是图纸上的另一条路 —— 一条专门给「马上要扔的东西」准备的近路。今天本喵要讲的就是这条路：它叫**移动语义**，而那条近路的路牌叫**右值引用（搬家的名分）**。

## 一、把两件事摆在一起看：抄一份，还是搬过去

先请一张图纸，它同时画了**两条路**：一条是老老实实抄一份，一条是把货直接搬走。两条路各印一句，好让本喵看清走的是哪条。

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Box {
    string goods;
    Box(string g) : goods(g) { cout << "装好 " << goods << endl; }
    Box(const Box& other) : goods(other.goods) { cout << "拷贝一份 " << goods << endl; }
    Box(Box&& other) : goods(move(other.goods)) { cout << "搬走 " << goods << endl; }
};

int main() {
    Box a("鱼干");
    Box b = a;
    Box c = move(a);
    cout << b.goods << " / " << c.goods << endl;
    return 0;
}
```

```text
装好 鱼干
拷贝一份 鱼干
搬走 鱼干
鱼干 / 鱼干
```

对着 `main` 里那两行看喵：

- `Box b = a;` → 印的是 **`拷贝一份`**。因为 `a` 是个**活着的名字**，本喵后面还要用它（最后一行就拿它印了字），所以只能老老实实再抄一份出来。
- `Box c = move(a);` → 印的是 **`搬走`**。本喵打了招呼：这份不要了。于是货直接过到新盒子里，**一份都不用抄**。

两条路在图纸上是**两行**：`Box(const Box& other)` 是「抄一份」那条，`Box(Box&& other)` 是「搬过去」那条。多出来的那两个 `&` 就是那条近路的路牌。

## 二、打招呼本身什么都没做

那么多出来的 `&&` 到底是什么意思？本喵先把「打招呼」这一半单独跑一遍。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "好长好长的一条鱼干";
    string b = move(a);
    cout << "b 拿到：" << b << endl;
    cout << "a 还剩几个字：" << a.size() << endl;
    return 0;
}
```

```text
b 拿到：好长好长的一条鱼干
a 还剩几个字：0
```

`move(a)` 那句话**没搬任何东西** —— 它只是把 `a` 的**名分**从「本喵还要用」改成了「马上要扔」。真的把货挪过去的是上面那条 `&&` 的路。

所以第六课那句话现在读起来就通了：**宣告之后，旧的那块牌子就不能再用了** —— 第二行 `a 还剩几个字：0` 就是证据，它只剩个空壳。

::: warn 小心喵
「搬过的名字里还剩什么」这件事**没有保证**喵：本喵这台机器上它是空的，换个类型、换台机器都不一定。规矩只有一条 —— **搬过的名字，就当它已经空了**：别拿它取货，要用就重新装一次货（`a = "新鱼干";`）。
:::

## 三、省下来的到底是什么：仓库还是同一间

「搬家」听起来像是把货一件件挪过去，其实不是。看一眼这个：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> a = {1, 2, 3};
    int* before = a.data();
    vector<int> b = move(a);
    cout << "b 现在有几件：" << b.size() << endl;
    cout << "a 现在有几件：" << a.size() << endl;
    cout << "仓库还是同一间吗：" << (b.data() == before ? "是" : "不是") << endl;
    return 0;
}
```

```text
b 现在有几件：3
a 现在有几件：0
仓库还是同一间吗：是
```

最后那个「**是**」是这一课最值钱的一句话喵：**三件货一件都没抄**，搬过去的只是「这间仓库归谁」这件事。名字从 `a` 换到了 `b`，仓库还是那间。

这也是为什么搬家比拷贝快得多：抄一份要照着货的件数一件件来，搬家**只改一个归属** —— 不管你搬的是三件还是三百万件，它就那一下。

::: tip 猫咪提示
`vector` 身上有两样东西：装着数据的**那间仓库**，和「仓库在哪」这个**归属**。拷贝那条路会连货一起抄一间新仓库出来；搬家那条路只把归属过个手，仓库原封不动。本喵第六课讲的那块会自己还仓库的牌子也是同一个道理 —— 所以它快。
:::

## 四、只画了「拷贝」那条路，打招呼也白搭

那条 `&&` 的路是图纸上**另外画出来**的，不是白送的。要是本喵偷懒只画了拷贝那条，会怎样？

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Box {
    string goods;
    Box(string g) : goods(g) { cout << "装好 " << goods << endl; }
    Box(const Box& other) : goods(other.goods) { cout << "拷贝一份 " << goods << endl; }
};

int main() {
    Box a("鱼干");
    Box b = move(a);
    return 0;
}
```

```text
装好 鱼干
拷贝一份 鱼干
```

本喵明明打了招呼（`move(a)`），它还是**老老实实抄了一份**。原因不复杂：图纸上只有「抄一份」那条路，那个「马上要扔」的招呼**没地方用**，于是它退回去走了拷贝那条 —— 程序照样对，就是白费了力气。

这就是移动语义要看**两个东西**的原因：光有招呼没用，图纸上得有那条近路；光有近路也不够，得有人打招呼（或者东西本来就马上要死）才会走上去。

## 五、用武之地：往篮子里放

搬家最常派上用场的地方，是本喵已经用不上的那份货要放进篮子的时候：

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<string> basket;
    string s = "好长好长的一条鱼干";
    basket.push_back(s);
    basket.push_back(move(s));
    cout << basket[0] << " / " << basket[1] << endl;
    cout << "s 还剩几个字：" << s.size() << endl;
    return 0;
}
```

```text
好长好长的一条鱼干 / 好长好长的一条鱼干
s 还剩几个字：0
```

两句话放进篮子的是同一份货喵，可走的路不一样：

- `basket.push_back(s);` —— `s` 本喵还要用，只能**抄一份**放进去；
- `basket.push_back(move(s));` —— 本喵打招呼「这份不要了」，于是**搬**进去，一个字都不用抄。

篮子看起来没变（两件货都好好地躺在里头），差别在第三行：`s` 已经被搬空了。

::: tip 猫咪提示
什么时候该写 `move`？本喵的经验是一句话：**「这份货我接下来还要用吗？」** 不用了 —— 比如它马上要出作用域、或者你已经把它当垃圾了 —— 就写 `move`。还要用就老老实实放着，别为了快一点把自己的货搬空。
:::

## 一句话对照表

| 想干什么 | 写什么 |
|---|---|
| 抄一份（老名字还能用） | `Box b = a;`（走 `const Box&` 那条路） |
| 把货搬过去（老名字变空壳） | `Box b = move(a);`（走 `Box&&` 那条路） |
| 在图纸上开一条搬家的近路 | `Box(Box&& other) : goods(move(other.goods)) { ... }` |
| 把不要的货放进篮子 | `basket.push_back(move(s));` |
| 搬完的旧名字 | **当它已经空了** —— 别取货，要用就重新装 |
