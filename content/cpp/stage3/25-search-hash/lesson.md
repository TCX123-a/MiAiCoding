## 钩子：在七只鱼干里找一只

鱼塘边摆着一排贴着编号的小碗，本喵要找编号 13 的那只。今天本喵教你两种找法，它们花掉的力气差得挺多。先看第一种，最憨也最稳：**从第一只开始，一只一只挨着看**，看到对上的就停，看到最后一只还没对上就答「没有这一只」。

七只碗里找最末尾那只（正好是 13），挨着看要**比 7 次** —— 最后一只才中。可要是找编号 1 的那只呢？**1 次**就中，运气好到爆。所以「挨着看」的力气，全看你要找的那只**站在多后面**喵。

## 第二种找法：每次都往中间砍

鱼塘边这些碗有一个好脾气：**编号是从小到大摆好的**。有了这个前提，本喵就能用第二种找法了 —— **先看正中间那只**：

- 中间那只**比我要找的小** → 那它左边那些更小，全是白看的，整半边**砍掉**，只在右半边接着找；
- 中间那只**比我要找的大** → 左边那半边才有戏，右边整半边**砍掉**。

每比一次，就有一半的碗被排除掉。七只碗最多比 3 次（7 砍成 3、3 砍成 1），一千只碗也只要 10 次 —— 因为它每次都砍一半喵。

```cpp
#include <iostream>
#include <vector>

std::vector<int> fish = {1, 3, 5, 7, 9, 11, 13};

/* 挨着看：从第一只开始一只只比，答「比了几次」；没找到就答负数 */
int line_find(int target) {
    int tries = 0;
    for (int i = 0; i < fish.size(); i++) {
        tries++;
        if (fish[i] == target) {
            return tries;
        }
    }
    return -tries;
}

/* 砍一半：每次先看正中间那只 */
int half_find(int target) {
    int lo = 0;                     /* 还有戏的那一段，头一只的位子 */
    int hi = fish.size() - 1;       /* 还有戏的那一段，最后一只的位子 */
    int tries = 0;

    while (lo <= hi) {              /* 段里还有碗，就接着找 */
        int mid = (lo + hi) / 2;    /* 正中间那只的位子 */
        tries++;
        if (fish[mid] == target) {
            return tries;
        } else if (fish[mid] < target) {
            lo = mid + 1;           /* 中间那只太小，左边整半边砍掉 */
        } else {
            hi = mid - 1;           /* 中间那只太大，右边整半边砍掉 */
        }
    }
    return -tries;                  /* 段里一只都不剩了，就是没有这一只 */
}

int main() {
    std::vector<int> targets = {13, 1, 6};
    for (int i = 0; i < targets.size(); i++) {
        int t = targets[i];
        int a = line_find(t);
        int b = half_find(t);
        std::cout << "找 " << t << "：挨着看 " << (a < 0 ? -a : a) << " 次" << (a < 0 ? "没找到" : "")
                  << "，砍一半 " << (b < 0 ? -b : b) << " 次" << (b < 0 ? "没找到" : "") << "\n";
    }
    return 0;
}
```

```text
找 13：挨着看 7 次，砍一半 3 次
找 1：挨着看 1 次，砍一半 3 次
找 6：挨着看 7 次没找到，砍一半 3 次没找到
```

三行一起看，你就明白该喊哪一招了喵：

- **找 13**：挨着看要 7 次，砍一半只要 3 次 —— 队伍越长，砍一半越占便宜。
- **找 1**：挨着看只要 1 次就中，砍一半还是老老实实比 3 次。**碗少、要找的又正好在前面的时候，挨着看反而快。**
- **找 6**：碗里压根没有 6，两招都得把该看的地方看完，最后照样答「没找到」。

「砍一半」这个词听着含糊：**到底砍掉了什么、还剩哪几只？** 下面拿找 13 那一次，把 `lo`、`hi`、`mid` 三个位子一步一步摆出来。盯着「还有戏的一段」那一栏看它怎么越缩越短喵。

::: warn 小心喵
砍一半有个**铁打的前提：碗必须已经从大到小（或者从小到大）排好**喵。这一课开头本喵特意先说「编号是从小到大摆好的」，就是为了这个。要是碗是乱摆的，你看到中间那只比目标大，凭什么断定左边全比目标小？左半边里完全可能藏着一只 13 —— 这一砍就把要找的那只砍掉了，程序会认真地告诉你「没有这一只」，而它明明就躺在那儿。所以：**碗没排好，先回去喊上一课学的那两招把碗理整齐**。
:::

## 更好的办法：按编号算门牌号

砍一半虽快，但它总得「比一比」。有没有办法**一步跳到位**、一次都不比？有 —— 前提是编号本身有形状。本喵的鱼干仓库有 10 个格子，编号是 0 到 99。那就定个规矩：

```text
格子号 = 编号 ÷ 10 的余数
```

编号 7 进第 7 格，编号 23 进第 3 格，编号 5 进第 5 格。这一手有个名字叫**按编号算门牌号（哈希）**：拿到编号**算一下**就知道它住哪一格，不用一只只问过去喵。

麻烦在于：编号 17 算出来也是第 7 格，可第 7 格已经被编号 7 占了。这叫**撞车**。本喵的规矩是：撞了车就**往后挪一格**，还撞就再挪 —— 找到第一个空格住下。找的时候也照同一个规矩走一遍：先到算出来的那格敲门，不是它就往后挪，挪到一个**压根没住过东西**的空格，就说明没有这一只。

```cpp
#include <iostream>
#include <vector>

const int SLOTS = 10;

std::vector<int> shelf(SLOTS, 0);
std::vector<int> used(SLOTS, 0);

/* 按编号算门牌号：编号除以 10 的余数 */
int slot_of(int id) {
    return id % SLOTS;
}

void put(int id) {
    int slot = slot_of(id);
    while (used[slot]) {
        slot = (slot + 1) % SLOTS;     /* 撞车了，往后挪一格 */
    }
    shelf[slot] = id;
    used[slot] = 1;
}

/* 答：比了几次才找到；一次都没比就返回 0 */
int find(int id) {
    int slot = slot_of(id);
    int tries = 0;
    while (used[slot]) {
        tries++;
        if (shelf[slot] == id) {
            return tries;
        }
        slot = (slot + 1) % SLOTS;     /* 不是它，照同样的规矩往后挪 */
    }
    return 0;
}

int main() {
    put(7);
    put(23);
    put(17);
    put(5);

    std::cout << "找 17：比了 " << find(17) << " 次\n";
    std::cout << "找 5：比了 " << find(5) << " 次\n";
    std::cout << "找 99：比了 " << find(99) << " 次\n";
    return 0;
}
```

```text
找 17：比了 2 次
找 5：比了 1 次
找 99：比了 0 次
```

三行结果正是这一手的脾气喵：

- **找 5** 只比 1 次 —— 算出来第 5 格，一敲门就是它；
- **找 17** 比了 2 次 —— 算出来第 7 格，可那格住着 7，往后挪一格才找到 17（就是那次撞车的代价）；
- **找 99** 比了 **0** 次 —— 第 9 格压根没住过东西，连门都不用敲：**没有这一只**。

最后那一行最妙：**空格本身就是「这里没有」的证据**。这也是哈希和「挨着看」最大的不同 —— 挨着看必须把该看的地方全看完，才敢下「没有」的结论；哈希只要撞见一个空地，立刻收工喵。

::: tip 猫咪提示
今天记住三句话：**挨着看**最稳，但力气看运气（要找的在最后面就惨了）；**砍一半**每比一次砍掉一半，快得多，但**碗必须已经排好**；**算门牌号**能一步跳到位，撞车了往后挪一格，撞见空格就是「没有这一只」。

写给学过 C 的猫：今天这两招，C++ 都替你备了现成的。上一课那种「挑一只、短的站左边」的活，`std::sort` 一行就干完；今天这种「按编号算门牌号 + 撞车往后挪」的活，前面讲过的 `std::map`（有编号的收纳柜）就是它 —— 你只管 `m[7] = ...`、`m.count(7)`，算门牌号和挪位子它自己在底下办。**先自己写一遍，才知道它替你干了多少活**喵。
:::
