## 钩子：本喵不是记性好，是牌子记着

上一课大肥鱼问本喵：「那间仓库，你是怎么记住要还的？」

本喵愣了一下才答上来：**不是本喵记着，是牌子记着**。牌子一出生就把仓库认在自己名下，走出花括号的时候自己还回去 —— 本喵从头到尾没写过一句「该还了」。

大肥鱼点点头说：那你已经会那条**黄金法则**了，只是还没给它起名字。它学名叫 **RAII（资源获取即初始化）**，本喵管它叫**「进门就领、出门就还」**。

这条法则比「会自己还的牌子」大得多：**凡是「用完必须还」的东西，它都管** —— 不止是内存，还有打开的门、借来的账本、临时换掉的状态。

## 一、先看看「手写开关」漏在哪

上一课的仓库换成了**库房门**：进门要推、出门要关。本喵先用手写的写法来一遍 —— 两个招式，一个开一个关，进了门自己记着喊。

```cpp
#include <iostream>
#include <string>
using namespace std;

void openDoor(string who) { cout << "推开 " << who << endl; }
void closeDoor(string who) { cout << "关上 " << who << endl; }

void work(bool early) {
    openDoor("库房门");
    if (early) {
        return;
    }
    cout << "取了鱼干" << endl;
    closeDoor("库房门");
}

int main() {
    work(false);
    cout << "--- 提前出门那一趟 ---" << endl;
    work(true);
    cout << "收工" << endl;
    return 0;
}
```

```text
推开 库房门
取了鱼干
关上 库房门
--- 提前出门那一趟 ---
推开 库房门
收工
```

第二趟又是老毛病喵：门**推开了**，`关上` 一次都没印。原因和上一课一模一样 —— 那句 `if (early) { return; }` 把 `closeDoor` 整个跳过去了。

::: warn 小心喵
「关门」这件事的危险程度和内存不一样：仓库忘了还，程序还能跑完；**门忘了关**，第二只猫一推就推不开了（真实世界里的文件、锁、连接，全都在这一档）。所以这条法则必须刻进骨头喵。
:::

## 二、黄金法则：领在出生证上，还在死亡证明上

RAII 三个字母是 Resource Acquisition Is Initialization 的缩写，直译过来是**「资源的获取就是初始化」**。念着拗口，拆开看只有两句话：

- **领**资源这件事，写进**出生招式（构造函数）**里 —— 牌子一出生就把门推开；
- **还**资源这件事，写进**收尾招式（析构函数）**里 —— 牌子一死就把门关上。

本喵把「库房门」也做成一块这样的牌子：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Door {
    string who;
    Door(string w) : who(w) { cout << "推开 " << who << endl; }
    ~Door() { cout << "关上 " << who << endl; }
};

void work(bool early) {
    Door d("库房门");
    if (early) {
        return;
    }
    cout << "取了鱼干" << endl;
}

int main() {
    work(false);
    cout << "--- 提前出门那一趟 ---" << endl;
    work(true);
    cout << "收工" << endl;
    return 0;
}
```

```text
推开 库房门
取了鱼干
关上 库房门
--- 提前出门那一趟 ---
推开 库房门
关上 库房门
收工
```

对着上一节那版看一眼就懂了喵：**都是提前出门，一个漏、一个不漏**。

差别只有两处，都在 `Door` 这块牌子里：`Door(...)` 是**出生时**干的事（推门），`~Door()` 是**死去时**干的事（关门）。本喵的 `work` 里再没出现过「关」这个字 —— 可它照样关上了。**领和还都被写进了牌子的生死里，中间那条路上怎么走，就没有漏的机会了。**

::: tip 猫咪提示
记号别记错喵：`~` 念作「析构」，`~Door()` 就是「Door 这块牌子死的时候要做的事」。C++ 会在牌子**离开它出生的那片花括号**时自动喊它一声，本喵不用手动叫。
:::

## 三、作用域就是生命线

为什么牌子知道该什么时候死？因为在 C++ 里，**那些不带 `new` 的局部家伙就活在那片花括号里**：花括号开始，它出生；花括号结束，它死亡。这件事有个正式说法叫**作用域**，牌子的**生命周期**就是它。

所以「提前出门也不漏」根本不是什么特殊照顾 —— `return`、`break`、抛异常、甚至只是花括号走到头，**这些路的终点都是「走出花括号」**，牌子一律在那儿等着还东西。

看一个更细的例子：门里面的门。

```cpp
#include <iostream>
using namespace std;

struct Door {
    string who;
    Door(string w) : who(w) { cout << "开 " << who << endl; }
    ~Door() { cout << "关 " << who << endl; }
};

int main() {
    Door outer("大门");
    {
        Door inner("里屋");
        cout << "在里屋翻鱼干" << endl;
    }
    cout << "回到大门" << endl;
    return 0;
}
```

```text
开 大门
开 里屋
在里屋翻鱼干
关 里屋
回到大门
关 大门
```

盯住顺序喵：**后开的先关**（`里屋` 在 `大门` 前面关掉）。这就是叠盘子 —— 后放上去的先拿下来。C++ 的规矩是「谁后出生，谁先死」，所以里屋那块牌子先走，大门那块才走。

这一条有个很实在的用处：**只要把牌子请进一层花括号，就等于给这件事划了一个「只管这么长」的圈** —— 圈的尽头自动收摊。

## 四、不只是内存：领的东西可以是一个「状态」

黄金法则最讨喜的地方是：**「资源」这两个字不限于仓库**。借来的账本、打开的文件、临时改掉的设置，凡是「用完得还原」的东西，都能做成牌子。

本喵写了个小活儿：有些话要小声说，说完就得恢复正常。手写的写法得记着在每条出门的路上喊一次「恢复」，本喵换成牌子来拿：

```cpp
#include <iostream>
using namespace std;

bool loud = true;

struct Quiet {
    bool old;
    Quiet() : old(loud) {
        loud = false;
        cout << "（小声说话）" << endl;
    }
    ~Quiet() {
        loud = old;
        cout << "（恢复说话）" << endl;
    }
};

void say(const char* s) {
    if (loud) {
        cout << s << endl;
    } else {
        cout << "……" << endl;
    }
}

int main() {
    say("大肥鱼早");
    {
        Quiet q;
        say("大肥鱼早");
    }
    say("大肥鱼早");
    return 0;
}
```

```text
大肥鱼早
（小声说话）
……
（恢复说话）
大肥鱼早
```

牌子 `q` 出生时把 `old`（**原来的**那个值）记在手心里，然后把自己需要的样子换上；死的时候把 `old` 还回去。中间那句 `say("大肥鱼早")` 印的是 `……`，出了花括号又正常了。

这套「**先记住旧样子，出门再换回来**」的写法，本喵后面讲文件、讲锁的时候还会用 —— 它们全都是同一块牌子，只是领的东西不一样。

## 五、回头看：上一课那位帮手就是这条法则的一张脸

上一课请牌子那句话，是 `unique_ptr<Fish> p = make_unique<Fish>("大肥鱼");`。把这句话拆开，正好是黄金法则的两半喵：`make_unique` 在**出生招式里**把仓库租下来（领），`unique_ptr` 的**收尾招式**把仓库还回去（还）。所以「走出花括号就自己还」不是牌子的什么小聪明，是**顺序**：领写进出生招式、还写进收尾招式、生死交给作用域。

同一张脸本喵还会在别处见到：

- `shared_ptr` —— 数着人头，最后一根手指松开时还；
- 文件流 —— 打开的文件在牌子死时自己关（后面有一课专门讲它）；
- 锁 —— 进了屋子锁上门，出门自己开（本喵在「好几只猫一起干活」那一阶段会正式见到它）。

::: tip 猫咪提示
判断一段代码「像不像 RAII」有个一秒钟的办法：**找 `new` / 打开 / 上锁的地方，看那个「还」是不是一个字都不用写。** 要是还得在每条出门的路上手动补一句，那就不是这张脸喵。
:::

## 一句话对照表

| 想干什么 | 写什么 |
|---|---|
| 领资源 + 记上「要还」 | 写在**出生招式**里（`Door(string w) { ... }`） |
| 还资源 | 写在**收尾招式**里（`~Door() { ... }`） |
| 什么时候还 | 牌子走出它出生的那片**花括号**（作用域结束） |
| 提前出门 / 抛异常也不漏 | 一个字都不用写 —— 那些路的终点都是「走出花括号」 |
| 只让某一段生效 | 把牌子请进一层花括号，圈的尽头自动收摊 |
| 临时换状态，出门还原 | 在出生招式里**先记下旧值**，收尾招式里换回去 |
