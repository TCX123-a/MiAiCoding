## 钩子：本喵天天伺候的不是数字，是字

上一课那只柜子装的是数字。可本喵的日常其实全在跟**字**打交道：猫名、口令、一条大肥鱼的收货单、大肥鱼写在便签上的「今天想吃三顿」……

这些在 C++ 里住在一只叫 `string` 的柜子里 —— 本喵叫它**一串小鱼干的项链（学名：字符串）**。

上一阶段本喵已经会「戴上一串字」和「把它整串印出来」了。今天要把这条项链玩出花来，一共五招：

| 想干什么 | 用哪一招 |
|---|---|
| 问长短 | `s.size()` / `s.empty()` |
| 接长 | `s += t;` / `s = s + t;` |
| 找东西 | `s.find(t)` |
| 剪一段 | `s.substr(从哪儿起, 要几颗)` |
| 和数字互相变 | `stoi(...)` / `to_string(...)` |

请项链的规矩和上一课请柜子一样：开头写一句 `#include`，把 `string` 借出来（它其实和 `vector` 住在同一个仓库里，所以本喵这两个月都在 STL 里打转喵）。

## 一、问长短：`size()` 和 `empty()`

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "cat";
    cout << s.size() << endl;
    cout << s[0] << endl;
    cout << (s.empty() ? "空的" : "有货") << endl;

    string zh = "小鱼干";
    cout << zh.size() << endl;
    return 0;
}
```

```text
3
c
有货
9
```

逐句看：

1. **`s.size()`** —— 这条项链**有几颗珠子**。`"cat"` 是 3 颗，所以印 `3`。（上一课问柜子几格也是 `size()` —— 同一个招式名，本喵很喜欢这种整齐。）
2. **`s[0]`** —— 报编号取一颗，**编号从 0 数起**。取出来的是一**颗**珠子（一个字母），不是一整串。
3. **`s.empty()`** —— 「**是不是空的**」。空给真、不空给假。本喵拿它当眼色用，印出「有货」。（顺带一说：问「有几颗」和问「空不空」，C++ 两条都有现成的，别自己数。）
4. **`zh.size()`** —— 同样的问法，可这回印出来的是 **9**。

**9 是哪儿来的？** `"小鱼干"` 明明只有**三个字**。

这里藏着 C++ 里一条很值钱的真相：**`size()` 报的是「格数」，不是「字数」**。这一串字在肚子里是用一种「**一个中文字占 3 格**」的写法存着的（行话叫 UTF-8，本喵懒得展开）。三个字 × 3 格 = 9 格，一点不错。

这条真相有两个后果：

- **别拿 `size()` 数「几个字」** —— 中英混着写的时候，它给你的是格数，不是字数。
- **中文字别用报编号去取** —— `zh[1]` 取到的是「小」这个字的**第二个格子**，不是「鱼」。取一半的字，印出来就是一坨乱码。

::: warn 小心喵
本喵的规矩：**报编号取珠子，只拿英文和数字那种「一颗珠子占一格」的字来玩。** 中文字当**一整块**看，要就整块要，别从中间切。这条规矩在下面「剪一段」那节还会再救你一次。
:::

## 二、接长：`+` 和 `+=`

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "喵";
    s += "呜";
    cout << s << endl;

    string t = s;
    t + "!";
    cout << t << endl;

    t = t + "!";
    cout << t << endl;
    return 0;
}
```

```text
喵呜
喵呜
喵呜!
```

三段，三种命：

- **`s += "呜";`** —— **把右边的接在自己尾巴上**。`s` 真的变长了，印出 `喵呜`。
- **`t + "!";`** —— 接**是**接了，可接出来的新项链**没人收**，当场就被扔掉。印出来的 `t` 还是老样子 `喵呜`。
- **`t = t + "!";`** —— 把接好的新项链**重新戴回 `t` 身上**，这回才印出 `喵呜!`。

**这是本课最不吵不闹的一个坑。** `t + "!";` 这样单独写一句，**编得过、也跑得完完整整** —— 只是你白接了。本喵拿最啰嗦的那档（`-Wall`）拿着**这段一模一样的代码**真跑过一遍，翻译官喵**确实开口了**，就一句：

> `warning: ignoring return value of '... std::operator+(...)', declared with attribute 'nodiscard' [-Wunused-result]`

（中间那一长串是这个招式连名带姓的全称，本喵省成了 `...`。）

看清楚它说的是 `warning` 不是 `error` —— **它拦都没拦**，程序照样编出来、照样跑完。它只是提醒你一句「接出来的东西没人收」。所以别指望翻译官喵替你抓这一条：它念它的，`t` 还是老样子，**这一条得你自己认出来。**

所以只有两条路，挑一条照着写：

| 目的 | 写法 | 结果 |
|---|---|---|
| 想**改自己**（最常用） | `s += t;` | `s` 变长 |
| 想**接出新的**（原来的不动） | `s = s + t;` | 接完有人收，才不白接 |

「有人收」和「没人收」差在哪儿，光看这张表看不出来 —— 本喵把这段放慢，一步一步走给你看：

## 三、找：`find` 给的是**编号**，不是「有没有」

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "catfishcat";
    cout << s.find("fish") << endl;
    cout << s.find("cat") << endl;
    if (s.find("dog") != string::npos) {
        cout << "找到啦" << endl;
    } else {
        cout << "没有喵" << endl;
    }
    return 0;
}
```

```text
3
0
没有喵
```

- **`s.find("fish")`** —— 在 `"catfishcat"` 里找 `"fish"`，它从**第 3 颗**开始，所以给你 `3`。
- **`s.find("cat")`** —— `"cat"` 正好在开头，**从第 0 颗**开始，所以给你 `0`。
- **找不到时**，它给的不是 `-1`，而是一个特别的记号：**`string::npos`**（念「恩·泡斯」）—— 意思就是「查无此物」。

**关键就在这儿**：`find` 给的是**编号**（第几颗开始），所以「有没有」这件事必须拿它跟 `npos` 比。本喵在学员的代码里见过最多的一种写法是这样的：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "喵喵鱼";
    string t = "喵";
    if (s.find(t) > 0) {
        cout << "找到啦" << endl;
    } else {
        cout << "没有喵" << endl;
    }
    return 0;
}
```

```text
没有喵
```

`"喵"` 明明就在**开头第一颗**躺着，这段却印出「没有喵」—— 因为它把「编号 0」当成「没找到」了。**编号 0 是合法的编号**（就是打头第一颗），这就是 `> 0` 错的地方。

::: warn 小心喵
判断「有没有」只有一种正确写法：**`!= string::npos`**。

- `s.find(t) > 0` ✗ —— 漏掉「正好在开头」这一种。
- `s.find(t) >= 0` ✗ —— 更糟，这个眼色**永远为真**（编号不可能小于 0，`npos` 也不是负数）。
- `s.find(t) != string::npos` ✓ —— 唯一不管位置在哪儿都对的一种。
:::

顺带记一句：**`find` 只告诉你「从第几颗开始」**。要是同一串字里出现了好几回，`find` 给你的是**头一回**那个位置 —— 想找下一回，得在后面某一课学的别的招（今天先知道有这回事就行）。

## 四、剪一段：`substr(从哪儿起, 要几颗)`

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "catfishcat";
    cout << s.substr(0, 3) << endl;
    cout << s.substr(3, 4) << endl;

    string zh = "小鱼干项链";
    cout << zh.substr(0, 3) << endl;
    cout << zh.substr(3, 6) << endl;
    return 0;
}
```

```text
cat
fish
小
鱼干
```

- **`s.substr(0, 3)`** —— 从**第 0 颗**起，要 **3 颗** → `cat`。
- **`s.substr(3, 4)`** —— 从**第 3 颗**起，要 **4 颗** → `fish`。

两个投喂口都是整数，**顺序千万别对调**：前面那个是「**从哪儿起**」，后面那个是「**要几颗**」。

中文那串也一样，**按格数剪**：`zh.substr(0, 3)` 正好剪出「小」一个字（3 格）；`zh.substr(3, 6)` 剪出「鱼干」两个字（3 + 3 格）。看到了吧 —— **剪的时候也得按 3 格一个字的规矩来**，剪出 2 格那种半截的字，印出来就是乱码。

本喵还试过一个写反的手滑版本：拿 `"小鱼干项链"` 写 **`substr(3, 0)`** —— 「从第 3 颗起，要 0 颗」。真跑一遍，它**不报错、不念叨**，只安安静静印出一个**空行**。这类「合法但没意义」的投喂，翻译官喵是**不会提醒**你的，只能靠自己把两个投喂口的顺序背熟。

::: tip 猫咪提示
`substr` 念「萨布·斯特」，字面意思就是「**下面那一段**」。记忆口诀：**先站定位置，再数要几颗** —— 和本喵捞鱼干一样，先伸手到盆里，再决定抓几条。
:::

## 五、一串字 ↔ 真正的数字：`stoi` 和 `to_string`

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "12";
    string b = "7";
    cout << a + b << endl;
    int total = stoi(a) + stoi(b);
    cout << total << endl;
    cout << to_string(total) + "条" << endl;
    return 0;
}
```

```text
127
19
19条
```

- **`a + b`** —— 两串字接起来，得到 `"127"`，**这不是加法**！加号在这一串字身上是「接长」，不是「相加」。
- **`stoi(a) + stoi(b)`** —— `stoi` 念「艾斯·吐·艾」，把一串字**翻成真正的整数**。12 + 7 = 19，这才是加法。
- **`to_string(total)`** —— 反过来，把整数**翻成一串字**，这样才能跟别的字接在一起（`to_string(19) + "条"` → `19条`）。

两个方向都要认清楚：

| 从哪到哪 | 用哪招 | 念作 |
|---|---|---|
| 一串字 → 整数 | `stoi("12")` | 把「一二」翻成 12 |
| 整数 → 一串字 | `to_string(19)` | 把 19 翻成「一九」 |

那要是本喵偷懒，想跳过 `stoi`、直接把这串字塞进一个整数格子呢？翻译官喵当场拦下：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "12";
    string b = "7";
    int total = a + b;
    cout << total << endl;
    return 0;
}
```

```text
main.cpp:8:19: error: cannot convert 'std::__cxx11::basic_string<char>' to 'int' in initialization
    8 |     int total = a + b;
```

念作：**「你要把一个『一串字』装进一个整数格子里 —— 这两样东西不能直接倒过去，中间得先过一趟 `stoi`。」** 看到 `cannot convert`，先找 `=` 两边是不是**类型对不上**：一边是项链，一边是整数格子。

## 六、整串比大小：`==` 和 `<`

一串字也能直接比，比出来的结果是「真 / 假」（印出来是 1 / 0）：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "apple";
    string b = "banana";
    cout << (a == b) << endl;
    cout << (a < b) << endl;
    cout << (a < "apples") << endl;
    return 0;
}
```

```text
0
1
1
```

- **`a == b`** 给 `0`（假）—— 两串不一样。
- **`a < b`** 给 `1`（真）—— 比法是**一颗一颗地比**：第一个字母 `a` 比 `b` 小，胜负当场就定了，后面看都不用看。
- **`a < "apples"`** 给 `1`（真）—— `apple` 是 `apples` 的**开头那一段**，一颗一颗比到底都一样，这时候**短的算小**。

::: tip 猫咪提示
`==` 用在两串字身上是**真的逐颗比对**（和整数的 `==` 一样靠谱）；本喵在另一门语言课上说过那里有坑，**C++ 这边没有这个坑**，放心用。
:::

## 七、本喵今天记住的三句话

::: tip 猫咪提示
1. **问长短**：`s.size()` 给**格数**（一个中文字占 3 格！）、`s.empty()` 问空不空、`s[i]` 报编号取**一颗**（只拿英文数字玩）。
2. **接长和找**：`+=` 改自己、`+` 造新的（**单独占一行的 `+` 就是白接**）；`find` 给的是**编号**，判断「有没有」只能写 `!= string::npos`。
3. **剪和换**：`substr(从哪儿起, 要几颗)` **顺序不能反**；`stoi` 把一串字翻成整数、`to_string` 把整数翻成一串字。
:::

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `string s = "cat";` | 戴上一条叫 `s` 的项链 |
| `s.size()` | 项链有**几格**（中文一个字占 3 格） |
| `s.empty()` | 是不是空的 |
| `s[0]` | 报编号取第 0 颗（只取一颗） |
| `s += t;` | 把 `t` 接在自己尾巴上，`s` 真的变长 |
| `s = s + t;` | 接出一条新项链，再戴回 `s` 身上 |
| `s + t;`（单独一行） | 接完没人收 —— **白接**，翻译官喵只念一句 `警告` |
| `s.find(t)` | `t` 从**第几颗**开始；找不到给 `string::npos` |
| `s.find(t) != string::npos` | 判断「有没有」的唯一正确写法 |
| `s.substr(3, 4)` | 从第 3 颗起，要 4 颗 |
| `stoi("12")` | 把一串字翻成整数 12 |
| `to_string(19)` | 把整数 19 翻成一串字 |
| `"apple" < "apples"` | 一位一位比，一样长的那段之后**短的算小** |
