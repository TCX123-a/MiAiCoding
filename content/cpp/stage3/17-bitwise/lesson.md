## 钩子：一排只有两档的小开关

本喵的猫窝墙上装了一排小开关，每个只有两档：**灭**（0）和**亮**（1）。要开哪盏灯，就把对应的开关拨上去；想知道哪盏灯亮着，就挨个瞄一眼。

你多半没想到：整数在机器里就是这么一排开关喵。本喵写个 `6`，机器记下来的其实是 `00000110` —— 从右往左数，第 2 格和第 1 格亮着，2 的 2 次方加上 2 的 1 次方，正好是 6。**6 只是这排格子的读数，格子本身才是它的样子。**

今天本喵不只让你看这排格子，还要教你在上面**动手脚**：想留哪几格、想按灭哪几格、想整排挪一挪 —— C++ 里都有现成的招。它叫**位运算**，是这门语言里最贴近机器那一层的手艺喵。

## 一、先把那排格子画出来

C++ 的标准工具箱里有个现成的「格子打印机」：`std::bitset<8>`。尖括号里那个 `8` 是「只画最低 8 格」。

```cpp
#include <iostream>
#include <bitset>

int main() {
    std::cout << "6 的格子 = " << std::bitset<8>(6) << std::endl;
    std::cout << "3 的格子 = " << std::bitset<8>(3) << std::endl;
    std::cout << "255 的格子 = " << std::bitset<8>(255) << std::endl;
    return 0;
}
```

```text
6 的格子 = 00000110
3 的格子 = 00000011
255 的格子 = 11111111
```

一格不多、一格不少，8 格一字排开。`6` 那行从右往左数，只有第 2、1 格亮着；`3` 亮的是第 1、0 格；`255` 把 8 格全点亮 —— 8 格最多也就读到 255，再大的数就得再要格子喵。

往后本喵还会直接写 `0b10110110` 这种形状：`0b` 是「后面这串是一排格子，不是十进制」的记号，读它就和读 `bitset` 印出来的东西一样顺。

## 二、六种拨法：与、或、异或、取反、左移、右移

位运算一共六招。下面这段把每一招都拨一遍，左边是格子图、右边是读数：

```cpp
#include <iostream>
#include <bitset>

int main() {
    int a = 6;
    int b = 3;
    std::cout << "a        = " << std::bitset<8>(a) << std::endl;
    std::cout << "b        = " << std::bitset<8>(b) << std::endl;
    std::cout << "a & b    = " << std::bitset<8>(a & b) << "  = " << (a & b) << std::endl;
    std::cout << "a | b    = " << std::bitset<8>(a | b) << "  = " << (a | b) << std::endl;
    std::cout << "a ^ b    = " << std::bitset<8>(a ^ b) << "  = " << (a ^ b) << std::endl;
    std::cout << "~a       = " << std::bitset<8>((unsigned char)~a) << std::endl;
    std::cout << "a << 1   = " << std::bitset<8>(a << 1) << "  = " << (a << 1) << std::endl;
    std::cout << "a >> 1   = " << std::bitset<8>(a >> 1) << "  = " << (a >> 1) << std::endl;
    return 0;
}
```

```text
a        = 00000110
b        = 00000011
a & b    = 00000010  = 2
a | b    = 00000111  = 7
a ^ b    = 00000101  = 5
~a       = 11111001
a << 1   = 00001100  = 12
a >> 1   = 00000011  = 3
```

一格一格对着看，六招就都清楚了：

- **`a & b`（按位与）：两边都亮的格子才留。** 逐格对一遍，只有第 1 格是 a、b 两边都亮着的，剩下每一格至少有一边灭着 —— 所以只剩 `00000010`，读出来是 2。
- **`a | b`（按位或）：有一边亮就留。** a 亮的第 2、1 格，b 亮的第 1、0 格，全拢过来就是 `00000111`，读出来是 7。
- **`a ^ b`（按位异或）：两边不一样才留。** 第 2 格 a 亮 b 灭、第 0 格 a 灭 b 亮 —— 这两格不一样，留下；第 1 格两边都亮、是一样的，灭掉。得到 `00000101`，读出来是 5。
- **`~a`（按位取反）：整排翻个面，亮变灭、灭变亮。** 它是**单目**的，只盯一个人写，所以是 `~a` 而不是 `a ~ b`。
- **`a << 1`、`a >> 1`（左移、右移）：整排一起挪格子。** 左移一格右边补 0，`00000110` 挪成 `00001100`，正好是 12；右移一格左边补 0，挪成 `00000011`，是 3。

::: tip 猫咪提示
`~a` 那一行外面套了一层 `(unsigned char)`，不是本喵多打的喵。`int` 的格子其实不止 8 格（第四节本喵会当场量给你看：是 32 格），而 `~a` 是把**这 32 格全翻个面**，翻完最低 8 格上面还压着一串 1。套一层 `(unsigned char)` 就是「只要最低 8 格」，正好够本喵这排在屏幕上画得下。
:::

::: warn 小心喵
最容易记错的一条：**`^` 不是「几次方」。** 有人一看 `2 ^ 3` 就念成「2 的 3 次方」，那是完全另一回事 —— 这里 `^` 是异或，`2 ^ 3` 是逐格看两边不一样才留，答案是 1，不是 8。

还有一条：**`&` 和 `|` 长得很像「两个都要」和「有一个就行」**，这两兄弟最容易写反。写 `&` 的时候心里念「两边都亮才留」，写 `|` 的时候念「有一边亮就留」，念出声就不容易写反喵。
:::

## 四、拿一排格子当权限牌

位运算最常用的地方，是**用一排格子同时记好几件事**。本喵给猫猫乐园做了张三样权限的牌：能不能领小鱼干、能不能晒太阳、能不能睡猫窝。给每样分一盏灯，就不会互相打架：

```cpp
#include <iostream>
#include <bitset>

int main() {
    const unsigned char CAN_FISH = 1u << 0;
    const unsigned char CAN_SUN  = 1u << 1;
    const unsigned char CAN_NAP  = 1u << 2;

    unsigned char cat = CAN_FISH | CAN_NAP;

    std::cout << "整张牌 = " << std::bitset<8>(cat) << std::endl;
    std::cout << "能领小鱼干吗？" << ((cat & CAN_FISH) ? "能" : "不能") << std::endl;
    std::cout << "能晒太阳吗？" << ((cat & CAN_SUN) ? "能" : "不能") << std::endl;
    std::cout << "能睡猫窝吗？" << ((cat & CAN_NAP) ? "能" : "不能") << std::endl;

    cat = cat | CAN_SUN;
    std::cout << "拨开晒太阳 = " << std::bitset<8>(cat) << std::endl;

    cat = cat & ~CAN_NAP;
    std::cout << "按灭睡猫窝 = " << std::bitset<8>(cat) << std::endl;
    return 0;
}
```

```text
整张牌 = 00000101
能领小鱼干吗？能
能晒太阳吗？不能
能睡猫窝吗？能
拨开晒太阳 = 00000111
按灭睡猫窝 = 00000011
```

`1u << 0`、`1u << 1`、`1u << 2` 就是「第 0 格亮」「第 1 格亮」「第 2 格亮」—— 也就是 1、2、4 三盏各占一格的灯。把这三招记牢，权限牌就活了：

- **想一次拨开好几盏**：用 `|` 把它们拢起来（`CAN_FISH | CAN_NAP` 就是「能领小鱼干 + 能睡猫窝」）。
- **想查一盏灯亮不亮**：用 `&` 拿那盏灯去问一声 —— 结果不是 0 就是「亮着」。牌上写着 `00000101`，所以问「晒太阳」那盏（`00000010`）得到 0，印「不能」。
- **想拨开一盏**：用 `|` 把那盏灯并进来。
- **想按灭一盏**：用 `& ~那盏灯` —— 先让那盏灯单独亮一下，再整排翻面（`~` 就干这个），于是它变成「除了这一格，别的全亮」，拿它去 `&`，正好只把那一格按灭、别的格子一个不动。

那么，只想读出**最低 4 格**组成的那个数呢？还是拿一个掩码去 `&`：

```cpp
#include <iostream>
#include <bitset>

int main() {
    std::cout << "int 有 " << sizeof(int) * 8 << " 格" << std::endl;

    unsigned int x = 0b10110110;
    std::cout << "x        = " << std::bitset<8>(x) << std::endl;
    std::cout << "x & 15   = " << std::bitset<8>(x & 15) << "  = " << (x & 15) << std::endl;
    std::cout << "x >> 4   = " << std::bitset<8>(x >> 4) << "  = " << (x >> 4) << std::endl;
    return 0;
}
```

```text
int 有 32 格
x        = 10110110
x & 15   = 00000110  = 6
x >> 4   = 00001011  = 11
```

本喵要的是**最右边那 4 格**：`15` 的格子是 `00001111`（最低 4 格全亮、上面全灭），拿它去 `&`，正好只把那 4 格留下来 —— 得到 `00000110`，也就是 6。同一个 `x`，要是拿 `x >> 4` 去要，挪回来的是**高的那 4 格**（11），正好要错。

这也就是「掩码」这个名字的来历：**一串专门用来挑格子的 0/1，就像一块盖上去的筛子。** 想要哪几格，就把掩码那几格写成 1；不想要的全写 0。

## 五、两个天天用得到的小技巧

两个小形状，本喵几乎每星期都要用一次：

```cpp
#include <iostream>

int main() {
    for (int i = 0; i <= 4; i++) {
        std::cout << i << " 是" << ((i & 1) ? "奇数" : "偶数") << std::endl;
    }

    unsigned int x = 0b10110100;
    for (int n = 7; n >= 0; n--) {
        std::cout << "第 " << n << " 位是 " << ((x >> n) & 1);
        if (n % 4 == 0) {
            std::cout << std::endl;
        } else {
            std::cout << "  ";
        }
    }
    return 0;
}
```

```text
0 是偶数
1 是奇数
2 是偶数
3 是奇数
4 是偶数
第 7 位是 1  第 6 位是 0  第 5 位是 1  第 4 位是 1
第 3 位是 0  第 2 位是 1  第 1 位是 0  第 0 位是 0
```

- **看奇偶：`i & 1`。** 最低那格就是「1」这一档 —— 别的格子都是 2 的整数倍，只有最低格代表那个 1。所以最低格亮着就是奇数、灭着就是偶数。`& 1` 正好只留下这一格。
- **看第 n 格：`(x >> n) & 1`。** 先用右移把第 `n` 格挪到最低位上，再用 `& 1` 把它单拎出来。上面那段从第 7 格一路看到第 0 格，`x` 是 `10110100`，读出来的一串 1/0 和格子图一模一样。

::: tip 猫咪提示
`(x >> n) & 1` 这个形状里的**括号不能省**，往后你会经常看到它。省了会怎样？这一节最后一段本喵真跑给你看喵。
:::

## 六、左移右移：整排一起挪，就是乘 2 除 2

挪格子和乘除法有个很整齐的对应：**整排往左挪一格 = 乘 2，挪两格 = 乘 4，挪 n 格 = 乘 2 的 n 次方**；往右挪就是反过来除。跑一遍就看出来了：

```cpp
#include <iostream>

int main() {
    unsigned int x = 5;
    std::cout << "5 左移 1 格 = " << (x << 1) << std::endl;
    std::cout << "5 左移 3 格 = " << (x << 3) << std::endl;
    std::cout << "40 右移 3 格 = " << (40u >> 3) << std::endl;

    int y = -8;
    std::cout << "带符号的 -8 右移 1 格，本机给的是 " << (y >> 1) << std::endl;

    unsigned int same = (unsigned int)y;
    std::cout << "同一串格子当无符号读是 " << same << std::endl;
    std::cout << "它右移 1 格 = " << (same >> 1) << std::endl;
    return 0;
}
```

```text
5 左移 1 格 = 10
5 左移 3 格 = 40
40 右移 3 格 = 5
带符号的 -8 右移 1 格，本机给的是 -4
同一串格子当无符号读是 4294967288
它右移 1 格 = 2147483644
```

前两行对上号了：5 挪一格是 10、挪三格是 40，正是乘 2 和乘 8。第三行反过来：40 往右挪三格变 5，正是除以 8（除不尽时余数直接丢掉，因为挤出去的那几格就是没了）。

::: warn 小心喵
**后三行说的是另一件事，别只看那个 `-4`。**

「挪出去补什么」这一条，**无符号数**身上是完全定死的：左边右边空出来的格子一律补 0，谁来算都一样，本喵上面那个 `4294967288` 右移一格得到 `2147483644`，就是「左边补 0」的结果。

可**带符号的负数**就不一样了：负数那串格子的最高位本来就代表符号，往右挪的时候补 0 还是补 1，老标准里是「交给每一台机器自己定」。本喵这台给的是 `-4` —— **这是一台机器的读数，不是一条能带走的结论**。换一版标准、换一种机器，它就可能不一样。

所以本喵的规矩是：**要挪格子，就用 `unsigned`。** 想处理一个负数，先把它当成无符号读出来（`(unsigned int)y` 就是干这个），在那串格子上动手，最后再决定怎么解释它。把「负数右移补什么」当结论记下来，是这一课最容易留下的坑喵。

还有一条更硬的：**别把格子挪出去太远。** 一排 32 格的数，你让它挪 40 格，标准里直接说这事「没定义」—— 不是「结果没用」，是「程序整个都不作数了」。挪多少格要心里有数，别让它超出这排格子的宽度。
:::

## 七、`<<` 在 C++ 里有两副面孔

这一节是本课 C++ 专属的一道坎。看这段代码：

```cpp
#include <iostream>

int main() {
    std::cout << (1 << 2 + 3) << std::endl;

    int x = 4;
    if (x & 1 == 0) {
        std::cout << "x 是偶数" << std::endl;
    } else {
        std::cout << "x 是奇数" << std::endl;
    }
    return 0;
}
```

```text
32
x 是奇数
```

两个结果都不是本喵想要的，而且各错各的：

- **第一行印 32，不是本喵以为的 7。** 本喵写的是 `1 << 2 + 3`，心里读的是「1 左移 2 格得 4，再加 3 得 7」。可 `+` 的优先级**比** `<<` **高**：它先把 `2 + 3` 算成 5，再算 `1 << 5`，于是印出 32。**在 C++ 里，移位比加减法松。** 想按自己的意思算，括号得自己加：`(1 << 2) + 3`。
- **第二行印「x 是奇数」，可 `x` 是 4、明明是偶数。** 因为 `==` 的优先级**比** `&` **高**，这一行被读成了 `x & (1 == 0)`：先算 `1 == 0` 得 0（灭），再算 `x & 0` 得 0 —— 于是走了 `else` 那一支。想让它干正事，括号必须自己加上：`(x & 1) == 0`。

**这两个形状，翻译官喵其实都出声了。** 本喵真跑过这一段，它留了两句原话：

```text
main.cpp:4:26: warning: suggest parentheses around '+' inside '<<' [-Wparentheses]
main.cpp:7:15: warning: suggest parentheses around comparison in operand of '&' [-Wparentheses]
```

它看得清清楚楚（`suggest parentheses` 就是「加个括号吧」）。**可它只是出声，没把本喵拦下** —— 程序照样被编了出来，交到手里，跑出来的还是本喵没想要的那个结果。

而 `<<` 在 C++ 里还有**第二副面孔**：它不只是「左移」，还是往屏幕印东西那个箭头（`std::cout << 6`）。两副面孔撞在同一行里，就不是警告了，是当场拦下：

```cpp
#include <iostream>

int main() {
    int a = 6;
    int b = 3;
    std::cout << a & b;
    std::cout << std::endl;
    return 0;
}
```

```text
main.cpp:6:20: error: no match for 'operator&' (operand types are 'std::basic_ostream<char>' and 'int')
```

翻译官喵的原话是「本喵这儿没有一条 `&` 能用在这两样东西上」。它读这一行的读法是：`<<` 比 `&` 紧，所以先把 `a` 塞进 `std::cout`，**塞完的那个东西变成了屏幕本身**，再拿屏幕去 `&` 一个整数 —— 当然没这种招。想印与出来的结果，括号一加就完事：`std::cout << (a & b) << std::endl;`。

::: warn 小心喵
**「位运算比加减乘除松、比 `==` 紧」这两句话，值得你抄在手心上。** 这一节两个例子都是它咬出来的：`1 << 2 + 3` 咬一口，`x & 1 == 0` 再咬一口。

本喵的办法很笨但很管用：**凡是拿不准优先级的地方，直接加括号。** 括号不要钱，猜错了要命。`(x & 1) == 0`、`(1 << 2) + 3`、`std::cout << (a & b)` —— 这么写，读你代码的人和翻译官喵都不用去翻优先级表喵。
:::

::: tip 猫咪提示
今天收五句话：

1. **整数就是一排 0/1 格子**，读数只是那排格子的意思；`std::bitset<8>` 能把格子直接印出来。
2. **与、或、异或是逐格挑**：`&` 两边都亮才留、`|` 有一边亮就留、`^` 不一样才留。
3. **`~` 整排翻面，`<<` `>>` 整排一起挪**，挪一格就是乘 2 除 2；要挪就用 `unsigned`，负数的右移别当结论。
4. **掩码就是「想要哪几格就写 1」** 的一串 0/1：查权限 `x & 灯`、拨开 `x | 灯`、按灭 `x & ~灯`、看奇偶 `x & 1`。
5. **位运算的优先级很松**（比加减乘除松、比 `==` 紧），拿不准就加括号 —— 忘了加，轻则警告、重则当场编不过。
:::
