## 钩子：一只碗装不下

上一课本喵发鱼干，用的是这样一只碗：

```cpp
int fish = 3;
```

一只碗里躺一条鱼干。可今天主人一口气报了三个数：「3 条、5 条、2 条，你给本喵记在哪儿？」

开三只碗行不行？勉强行 —— 起三个名字 `fish1`、`fish2`、`fish3`，一个一个去喂。可要是三十条呢？三百条呢？本喵的爪子会先断掉。

电脑早就替本喵想好了：**它能把一堆小格子焊成一整排，只起一个名字。** 今天本喵要给你看的就是这种柜子，而且是**两种**：

1. 一种是**一排贴编号的猫粮碗（数组）** —— 开店时就得说死几格，之后一格都改不了；
2. 另一种是**一串小鱼干的项链（字符串）** —— 想串多少串多少，会自己长大。

它俩长得像、脾气却完全不同。**它俩的取舍**，就是今天这堂课真正要教给你的东西。

## 第一种柜子：一排贴编号的猫粮碗

先把三个数摆进去，再一格一格取出来看看：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish[3] = {3, 5, 2};
    cout << fish[0] << endl;
    cout << fish[1] << endl;
    cout << fish[2] << endl;
    return 0;
}
```

```text
3
5
2
```

盯着一行行读：

- **`int fish[3]`** —— 方括号里那个 **3** 说的是「本喵要**三**格」。这是**开店时要说的数**，一说定就写在脸上了。
- **`= {3, 5, 2}`** —— 大括号里是每一格**开门时先放什么**。三个数，正好三格，一个不多一个不少。
- **`fish[0]`** —— 取第 **0** 格。方括号里夹的不是「鱼干数」，是**格子的编号**。

### 编号是从 0 起的

上面那段印出来是 3、5、2，可本喵写的是 `fish[0]`、`fish[1]`、`fish[2]` —— **编号从 0 开始，不是从 1。** 所以：

| 本喵写 | 拿到的是 |
|---|---|
| `fish[0]` | 第一格，3 |
| `fish[1]` | 第二格，5 |
| `fish[2]` | **第三格**，2 |

三格的碗，最靠后的那一格是 `fish[2]`。**`fish[3]` 不是第四格，它已经跑出这一排外面去了** —— 这件事后面还要专门说一次，是本课最要紧的坑。

### 给某一格换货

一排碗开好了，里面的货当然能一格一格改：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish[3] = {3, 5, 2};
    fish[1] = 8;

    for (int i = 0; i < 3; i++) {
        cout << "第 " << i << " 格有 " << fish[i] << " 条喵" << endl;
    }
    return 0;
}
```

```text
第 0 格有 3 条喵
第 1 格有 8 条喵
第 2 格有 2 条喵
```

`fish[1] = 8;` 这一行，把第二格的 5 换成了 8，别的格子一动不动。

再瞪大眼睛看下面那个跑圈：`for (int i = 0; i < 3; i++)`，圈里的 `i` 领到的是 0、1、2 —— **正好就是这个柜子的格子编号**。所以 `fish[i]` 会一格一格地走完整排，一格不落。

上一课学的跑圈，和今天这个柜子，是天生的一对：**上一课教你怎么一圈一圈地重复，这一课教你在第几圈去开第几格。**

### 这一排碗是钉死的

现在说这节课最要紧的一句话：

> **开店时说几格，它就永远几格。**

说 3 格，跑起来就是 3 格。**它不会自己长到 4 格，也不会缩回 2 格。** 想多装一条鱼干？办法只有一个：**重新开一排更大的碗，再把旧的货一格格搬过去。**

要是开店的时候忘了说几格呢？翻译官喵当场翻脸：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish[];
    fish[0] = 3;
    cout << fish[0] << endl;
    return 0;
}
```

```text
main.cpp:5:9: error: storage size of 'fish' isn't known
```

翻译官喵这句话的意思是：**`fish` 该占多大地方，本喵不知道。**

要划一排格子，**先得知道一共有几格** —— 方括号里那个数是它的地盘大小，少了它，本喵没法给你安排。看到 `storage size ... isn't known`，第一件事就是回头看方括号里是不是空着喵。

::: warn 小心喵
**写超了，翻译官喵一声不吭。**

上面说了，3 格的碗最后是 `fish[2]`。那本喵偏要去摸 `fish[3]`（其实是第四格，可这排碗根本没有第四格）会怎样？

**不报错，也不警告** —— 程序照样跑完，只是摸出来的那个数**谁也说不准**。

它不拦你，这是 C++ 最不讲情面的一面：它把「你该自己数清楚」这件事，**全交给了你**。所以跑这个柜子的时候，眼色要拿**格数**卡死（3 格就写 `i < 3`，写 `i <= 3` 就已经越过去了）。这一脚踏空，程序不会喊疼，只会默默地给你一个假的数。
:::

## 第二种柜子：一串小鱼干的项链

一排碗是给「一条一条的鱼干」用的。可本喵还想存名字、存句子 —— 那得请出第二种柜子：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "大肥鱼";
    cout << name << "喵" << endl;

    name = name + "，今天也要好好吃饭";
    cout << name << endl;
    return 0;
}
```

```text
大肥鱼喵
大肥鱼，今天也要好好吃饭
```

`string` 这种柜子专门装字。头一次见它，盯三处：

- **`string name = "大肥鱼";`** —— 一把钥匙开一个柜子，里面串着一整串字。
- **`name = name + "，今天也要好好吃饭";`** —— 用 `+` 把两串接到一起，再把接好的**放回原来那个柜子**。
- **它自己变长了。** 一开始屋里是「大肥鱼」三个字，接完变成了一长串 —— **本喵一句都没说「要几格」**。

这就是它和那排碗最大的不同：

| | 一排贴编号的猫粮碗 | 一串小鱼干的项链 |
|---|---|---|
| 开店时要说几格吗 | **要说**，说死 | **不用说**，自己看着办 |
| 后来还能变长吗 | 不能，一格都长不了 | 能，串多少是多少 |
| 怎么念开机咒 | 一行 `iostream` | 本喵习惯写**两行**：先 `iostream`，再 `string` |

::: tip 猫咪提示
**两行开机咒是本喵的习惯，也请你养成这个习惯。**

有的翻译官会顺手帮你把 `string` 一起带进来，所以你只写前面那行也能跑。可这不是规矩，是运气 —— 换个翻译官、换台电脑，运气就不一定还在了。**规规矩矩写两份，最省心。**
:::

### 项链的常用招式

项链身上带着几招现成的把式，随叫随到：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "大肥鱼";
    string b = "大肥鱼";
    string c = "小黄鱼";
    string word = "miai";

    cout << (a == b) << endl;
    cout << (a == c) << endl;
    cout << a.size() << endl;
    cout << word.size() << endl;
    return 0;
}
```

```text
1
0
9
4
```

一个一个说：

- **`a == b`** —— 问「两串一模一样吗」。答 `1` 就是**一样**，答 `0` 就是**不一样**。注意它比的是**内容**：字一样、顺序一样，才算一样。
- **`.size()`** —— 问「这串上一共占了几格」。**写法是名字后面跟一个点，再跟 `size()`，那对小括号别忘了。**
- 上面 `a` 和 `b` 都是「大肥鱼」，所以第一句是 1；`a` 和 `c` 不一样，第二句是 0。

最后两个数最值得停一下：`word` 是 `"miai"` 四个字母，问出来是 **4**，正好对得上；可 `a` 是「大肥鱼」三个字，问出来却是 **9**。

**为什么？因为一个中文字要占好几个格子。** `.size()` 数的是「占了几格」，不是「有几个字」。三个中文字占 9 格，所以答 9。

顺着这个往下推一件事：**中文的项链，别去按编号揪单个格子。** 写成 `a[0]`，揪下来的只是某个中文字的一小片，印出来是乱糟糟的一小块，根本不是完整的字。本喵的规矩是：

> **中文的项链，整串地拼接、整串地比较；想一个一个字拆开看，请用英文字母的项链。**

### 拿跑圈把项链也走一遍

上一课那个「挨个走一遍」的省事跑圈，对项链照样管用：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "miai";

    for (char c : word) {
        cout << c << "-" << endl;
    }
    return 0;
}
```

```text
m-
i-
a-
i-
```

读法还是上一课那一句：**「把 `word` 里面的每一格，挨个叫它一声 `c`，然后做下面大括号里的事。」**

只有一处小改动：上一课走那排碗，括号里写的是 `int one`；这一回走的是字母串，写的是 **`char c`**。

规律很简单：**那排东西里装的是什么，前面就写什么。** 碗里装的是数，写 `int`；一串字母里装的是字母，写 `char`。名字 `one`、`c` 随你起，它只在那对小括号里活着。

## 两种柜子摆一起

把两位主角请到同一段里，看它们各走各的：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int fish[3] = {3, 5, 2};
    string word = "miai";

    for (char c : word) {
        cout << c << "-" << endl;
    }

    for (int one : fish) {
        cout << "这条是 " << one << " 喵" << endl;
    }
    return 0;
}
```

```text
m-
i-
a-
i-
这条是 3 喵
这条是 5 喵
这条是 2 喵
```

两个跑圈先后排着，谁也不碍谁。这一段其实没什么新东西，就是把你今天学的一起摆出来给你看一眼 —— **它俩住在一个屋里，各干各的活。**

### 什么时候用哪个

| 想问的问题 | 记这个 |
|---|---|
| 我要存的是一堆**鱼干（数）**，而且**一开始就知道几条** | 用**一排贴编号的猫粮碗** |
| 我要存的是一串**字**，长度随时会变（一边拼一边加） | 用**一串小鱼干的项链** |
| 我要挨个走一遍 | 两个都用 `for (类型 名字 : 柜子)` |
| 我忘了项链上有几个字 | 问它 `.size()` |
| 我忘了那排碗有几格 | **没人能帮你问** —— 得你自己记着 |

最后一行是本喵最想让你记住的：**项链会自己数自己，那排碗不会。** 所以开碗的时候，本喵**一定**在心里默默念一遍那个数。

## C++ 特有的一跤：两根光溜溜的字符串拼不起来

最后给你看一个 C++ 独有的跟头。新手最爱这么写：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    cout << "三文鱼" + "秋刀鱼" << endl;
    return 0;
}
```

```text
main.cpp:6:22: error: invalid operands of types 'const char [10]' and 'const char [10]' to binary 'operator+'
```

报错里那句 `invalid operands ... to binary 'operator+'`，翻译官喵的意思是：**`+` 左右这两样东西，本喵没法拿来拼。**

为什么拼不了？因为在 C++ 里，光溜溜夹在双引号里的那串字，**还不算一根项链** —— 它只是「一小块摆在那儿的字」，本喵连它一共占几格都还没定。而 `+` 这种拼法，翻译官喵只认**真的项链**（也就是 `string` 那种柜子）。

所以规矩是这一条：

> **`+` 的两边，至少得有一边是真项链。**

照着这条改，立刻就通了：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string tail = "秋刀鱼";
    cout << "三文鱼" + tail << endl;
    return 0;
}
```

```text
三文鱼秋刀鱼
```

右边那根是真项链了，`+` 就认。左半边还是光溜溜的字没关系 —— 一边是真的就够。

顺带一句：两块光溜溜的字**挨着印**是没问题的，`cout << "三文鱼" << "秋刀鱼"` 照样印出来。**拦你的从来不是「两块字挨在一起」，而是「拿 `+` 去拼它俩」。**

::: tip 猫咪提示
本课五次总结，一句话一个：

1. **`int fish[3] = {3, 5, 2};`** —— 一排贴编号的猫粮碗，方括号里的 3 就是格数，**开店时说死**。
2. **编号从 0 起** —— 三格是 `fish[0]`、`fish[1]`、`fish[2]`，**`fish[3]` 已经越界了**。
3. **`string name = "大肥鱼";`** —— 一串小鱼干的项链，**会自己长大**，用 `+` 往后接。
4. **`.size()` 数的是格子数，不是字数** —— 三个中文字问出来是 9。
5. **`+` 两边至少一边得是真项链** —— 两块光溜溜的字拼不起来。
:::

::: warn 小心喵
这一课最贵的三跤，一条一条记牢：

1. **越界不报错。** 3 格的碗去摸 `fish[3]`，翻译官喵不吭声，跑出来是个谁也说不准的数。**眼色自己拿格数卡死。**
2. **开店时忘了说几格。** `int fish[];` 会被当场拦下，报 `storage size ... isn't known`。
3. **`+` 两边都是光溜溜的字。** 报 `invalid operands`，改成「一边先装进项链」就好。
:::

6. 想想看：本喵要说「今天发的鱼干一共几条」，那个数该用一排碗装，还是用一根项链装？为什么喵？
