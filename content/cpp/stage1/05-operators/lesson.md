## 钩子：只会复读、不会算账的点单机

本喵的点单机现在会听话了，可大肥鱼发现它还有个毛病：

「本喵今天喂了 7 条，分给 2 只猫，一只几条？」

点单机把「7」「2」原样念了一遍，然后就愣在那儿了。

「它只会复读，不会算账。」大肥鱼叹气。

会算账这件事，C++ 的写法跟你学过的别家**大差不差**——加号还是加号，括号还是括号。但里头埋着几个 C++ 特有的坑，尤其是那个**整数除法**，本喵见过太多猫在这儿摔跤。今天一次讲清喵。

## 算术：五件常用的家伙

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 3 + 5 << endl;
    cout << 10 - 4 << endl;
    cout << 6 * 7 << endl;
    cout << 10 / 4 << endl;
    cout << 10 % 4 << endl;
    return 0;
}
```

```text
8
6
42
2
2
```

| 运算符 | 干什么 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `3 + 5` | `8` |
| `-` | 减 | `10 - 4` | `6` |
| `*` | 乘 | `6 * 7` | `42` |
| `/` | 除 | `10 / 4` | `2` ← 先别急，下面细说 |
| `%` | 取剩下的那点零头 | `10 % 4` | `2` |

最后那个 `%` 的名字叫「取余」：**10 除以 4 商 2、余 2**，它把余数交给你。你在别处学过它，今天先记住它的脾气（后面还有一条）喵。

### 整数除法：`10 / 4` 为什么不给 2.5

本喵单独把这条拎出来讲，因为它**不报错**，是最容易让人摔跤的一个坑。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 5 / 2 << endl;
    cout << 5 / 2.0 << endl;
    cout << 5.0 / 2 << endl;
    cout << 5 % 2 << endl;
    return 0;
}
```

```text
2
2.5
2.5
1
```

看出来了吗？同样是 5 除以 2：

- `5 / 2` 得 `2`——**两边的货都是整数，它就按整数算**：除完把小数那截直接剁掉（不是四舍五入，是**剁掉**）；
- `5 / 2.0` 得 `2.5`——**只要有一边带着小数点，它整句都按小数算**。

所以想让除法给你小数，**得先让参与运算的那件货变成小数**——要么自己写上小数点（`2.0`），要么把你写的那间屋先改成装小数的牌（`double`）。这一条比什么都重要喵。

还有更隐蔽的一种摔法：**算了半天是整数，最后才装进小数的屋**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int total = 7;
    int cats = 2;
    double each = total / cats;
    cout << each << endl;
    return 0;
}
```

```text
3
```

本喵心里想的是「7 条分给 2 只猫，一只 3.5 条」，容器也挑了装小数的 `double`，可屏幕上还是 `3`。

毛病出在**顺序**上：`total / cats` 是**先算的**——两件货都是整数，这一步老老实实按整数算，得到 `3`；算完之后，那个 `3` 才被搬进装小数的屋，变成 `3.0`。**先剁掉，再变小数**，小数点后面那半截早就没了。

记住这句：**要让哪一步出小数，就得在那一步之前把货变成小数**。

那半截小数点是在**哪一拍**丢的，本喵拆成一步一步，走给你看：

所以想让除法给你小数，得**在算之前**就把货变成小数：要么自己写上小数点（`total / 2.0`），要么用 `static_cast<double>(total)` 先把它转过去。**顺序是这件事的全部** —— 迟一拍变小数，那半截就再也找不回来了喵。

### `%` 只认整数

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 5.0 % 2 << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:5:17: error: invalid operands of types 'double' and 'int' to binary 'operator%'
```

`operator%` 是「取余这件家伙」，`invalid operands` 是「**这两件货它不收**」：小数不能取余。

道理也简单：取余问的是「除完还剩几个整的」，小数除出来那点零头本来就是个小数，谈不上「剩几个」。所以 `%` 两边**都必须是整数**喵。

## 比较：答案只有「真」和「假」

比较这一门和你在别处学的形状一样，只有一点要适应：**它的答案印出来是 `1` 和 `0`**（你在仓库那一课见过——C++ 把「真」印成 1、「假」印成 0）。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << (3 > 2) << endl;
    cout << (3 < 2) << endl;
    cout << (5 >= 5) << endl;
    cout << (5 == 5) << endl;
    cout << (5 != 5) << endl;
    return 0;
}
```

```text
1
0
1
1
0
```

- `>`、`<` 就是大小；
- `>=`、`<=` 是「大于等于」「小于等于」；
- `==` 是「**相等吗**」——留神是**两个**等号喵！一个等号那是搬运（把货搬进屋里），两个等号才是问「一不一样」。这一对是新手最常见的笔误，而且**写错了常常不报错**，只是答案全错；
- `!=` 是「不相等」——英文 not 的头一个字母加上等号。

### 那一小句，得拿括号圈起来

上面每句外面都套了一对圆括号，这不是本喵爱漂亮，是**必须的**。要是省掉：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 3 > 2 << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:5:19: error: invalid operands of types 'int' and '<unresolved overloaded function type>' to binary 'operator<<'
```

这行报错看着吓人，本喵替你翻成人话：**「你到底是让本喵印东西，还是让本喵比大小？」**

毛病出在**谁先动手**上：`<<` 的力气比 `>` 大，所以它先看见 `2 << endl`（把 `2` 和「换行暗号」凑成了一对），还没轮到比较。想让它先比大小，就得用括号把比较那一小句圈起来——`cout << (3 > 2) << endl;`，括号就是那句「**先算这里**」喵。

## 逻辑：`且`、`或`、`不`

比较能得出「真/假」，那几件「真/假」还能再凑起来：

```cpp
#include <iostream>
using namespace std;

int main() {
    bool hasFish = true;
    bool hasMoney = false;
    cout << (hasFish && hasMoney) << endl;
    cout << (hasFish || hasMoney) << endl;
    cout << !hasMoney << endl;
    return 0;
}
```

```text
0
1
1
```

- **`&&`**（两个和号）读作「**且**」：两边都为真才算真。这里「有小鱼干」为真、「有钱」为假，所以是假（`0`）；
- **`||`**（两根竖线）读作「**或**」：有一边为真就算真；
- **`!`**（一个叹号）读作「**不**」：把真变假、把假变真。`!hasMoney` 就是「不有钱」——本来 `false`，翻过来成了真。

`&&` 和 `||` 也各要一对括号，理由和刚才一样喵。

## 转换：货从一间屋搬进另一间

不同的屋子装不同的货，把货搬家的时候要「转一下」，C++ 有**两种转法**：一种是你没说话它自己转的，一种是你明确要求的。

### 自己转：隐式转换

```cpp
#include <iostream>
using namespace std;

int main() {
    double d = 5;
    int i = 3.9;
    cout << d << endl;
    cout << i << endl;
    return 0;
}
```

```text
5
3
```

本喵把整数 `5` 搬进了装小数的屋，屏幕上是 `5`——小数点后面没有东西，因为本来就是整整 5。这种「**小的装进大的**」它自己就办了，安安全全，不用你说话。

但反过来那次搬家出事了：`3.9` 搬进装整数的屋，变成了 `3`。**又剁了一刀**——和整数除法一个脾气，**剁掉，不四舍五入**。

这种「**大的装进小的**」叫**窄**下去：明明装不下那么多，它会丢掉一部分，而且**不吭声、不报错**。所以往后往小屋里搬货之前，先问问自己：**我是不是真的要丢掉那半截喵？**

### 自己说了算：`static_cast`

想让搬家听你的，用这一招：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 5;
    int cats = 2;
    cout << fish / cats << endl;
    cout << static_cast<double>(fish) / cats << endl;
    double avg = 3.9;
    cout << static_cast<int>(avg) << endl;
    return 0;
}
```

```text
2
2.5
3
```

- 第一行是刚才那个坑的原样：两件都是整数，`5 / 2` 剁成 `2`；
- 第二行本喵加了一招：`static_cast` 后面跟一对**尖括号**，尖括号里写**你想变成什么样**（这里是「变成小数」），后面再跟一对圆括号，圆括号里是**要搬的是哪件货**。于是 `fish` 先变成了小数 `5.0`，接着 `5.0 / 2` 就按小数算，得到 `2.5`；
- 第三行是反过来的用法：把 `3.9` 明确地转成整数，得到 `3`。

`static_cast` 这个名字拆开看就是「**明确地转一下**」（cast 是「投、掷」的意思）。它的好处是**你说了算**：本喵一眼就能看出「这里本喵故意要丢掉小数」，而不是糊里糊涂被它偷偷剁了一刀喵。

::: tip 猫咪提示
今天记住五件事：

1. **算术**：`+ - * / %` 五件家伙，`%` 两边都必须是整数；
2. **整数除法会剁**：`5 / 2` 是 `2`，**只要有一边带小数点才是小数**——而且要在**算之前**就把货变成小数；
3. **比较**：答案印出来是 `1`/`0`，`==` 是两个等号（一个等号是搬运！），比较那一小句**要套括号**；
4. **逻辑**：`&&` 且、`||` 或、`!` 不，也要括号；
5. **转换**：小的装进大的它自己办；大的装进小的会**悄悄剁掉**，想自己说了算就用 `static_cast`。
:::

::: warn 小心喵
这一课里最需要提防的，是那些**不报错**的坑——它们不会给你一段红字，只会给你一个不对的答案：

- `5 / 2` 得到 `2`（本喵想要 2.5）；
- `double each = total / cats;` 得到 `3`（本喵想要 3.5）；
- `int i = 3.9;` 得到 `3`（不是 4，它不四舍五入）。

三个坑的根子是同一个：**C++ 看货牌办事，两边都是整数就按整数算**。

所以往后你算完账，如果数字「差不多但就是不对」，第一件事是回头看看那步运算的**两件货是不是都挂着整数牌**，而不是去怀疑 `cout` 坏了喵。
:::
