## 钩子：翻车有两种

前面十二课翻的所有车，都是**开演之前**翻的：分号忘了、名字写错了、大括号没配平 —— 翻译官喵一眼就看出不对，**根本不让它开演**，还顺手把出错的第几行第几列指给你。

可还有另一种车，是**开演之后**才翻的。它翻的时候翻译官喵一句警告都没有 —— 因为**开演的时候它完全没错**。

举两个例子喵：

- 本喵要把一串小鱼干变成整数，可那串东西**根本不是数字**；
- 本喵要从第 10 颗的位置上拿小鱼干，可那串东西**只有 4 颗**。

这两件事在开演的时候都合法，只有真跑到那一句才知道要翻车。本喵真跑过第一种，屏幕上最后是这两行：

```text
terminate called after throwing an instance of 'std::invalid_argument'
  what():  stoi
```

看到了吗？程序里那句要打印的话**一个字都没印出来**，程序当场就停了 —— 后面哪怕还有一百句，也不会再跑。

（这两行是本喵在这台机器上跑出来的原话。别的机器上措辞可能略有不同，但意思一样：**有人扔了一辆没猫接的车，机器只好就地停下。**）

那怎么接住这种车？今天教两样东西：`try` 和 `catch`。它俩合起来就是一句话：

> **「这一段你来跑；要是翻了车，本喵在这儿接着。」**

## 一、先自己扔一辆车出来

要学接车，最快的办法是先自己扔一辆。看这一段：

```cpp
#include <iostream>
using namespace std;

int main() {
    try {
        throw 42;
    } catch (int e) {
        cout << "接住了 " << e << endl;
    }
    cout << "程序还在跑喵" << endl;
    return 0;
}
```

```text
接住了 42
程序还在跑喵
```

一句一句看喵：

- **`try { ... }`** —— 一对大括号圈出「要盯着跑的那一段」。这是铺在地上的一块**软垫**。
- **`throw 42;`** —— **扔出去**。意思是「本喵不干了，这活儿交给上级」。本喵往上一扔的是个数字 `42`。
- **`catch (int e) { ... }`** —— **在软垫上接住**。括号里写的是「接什么样的车」：这里写 `int`，意思是「扔出来的是整数，本喵就接」；接住的那件东西装进 `e` 里，接下来就能用了。
- 最要紧的是**最后那句 `程序还在跑喵` 也印出来了**。`throw` 把 `try` 里剩下的话全都打断了（所以剩下那句是 `catch` 接的手），可**整个程序没停**，`try` 后面的话照跑不误。

`try`、`catch`、`throw` 三个名字都是英文小写，念起来就是它们的字面意思：**试**、**接住**、**扔**。

## 二、真·从一堆字里挖数字

现在来真的。这个招式叫 `stoi`，念作「s-to-i」，是 string to int 的缩写 —— **把一串小鱼干读成一个整数**：`stoi("42")` 就是数字 `42`。（别的语言里干这活的招式写法不一样，那是下一阶段的事喵。）

可要是那串东西根本不是数字呢？

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    try {
        int n = stoi("喵");
        cout << n << endl;
    } catch (const invalid_argument& e) {
        cout << "这不是数字喵：" << e.what() << endl;
    }
    return 0;
}
```

```text
这不是数字喵：stoi
```

- **`stoi("喵")`** —— 那串东西不是数字，所以 `stoi` 自己就**扔一辆车**出来。它扔的车上挂着 `invalid_argument` 这块牌子，意思是「**你给的料不对**」。
- **`catch (const invalid_argument& e)`** —— 括号里写的正是「本喵接那种挂着 `invalid_argument` 牌子的车」。`const` 和 `&` 是它的标准写法，今天就照着抄（那个 `&` 就是上一课那块牌子喵，意思是「别复印，本喵要接住原车」）。
- **`e.what()`** —— 车上贴着的一句说明。这里印出来是 `stoi`（意思：「问题出在 `stoi` 这一句上」）。

注意 `cout << n << endl;` 那一句**没印出东西** —— 车一扔出来，`try` 里剩下的话就全部作废，直接跳到接车的 `catch` 里。

## 三、越界：从没有的那颗拿鱼干

第二种翻车，翻的是「越界」：

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    string word = "miai";
    cout << word.at(1) << endl;

    try {
        cout << word.at(10) << endl;
    } catch (const out_of_range& e) {
        cout << "越界喵：" << e.what() << endl;
    }
    return 0;
}
```

```text
i
越界喵：basic_string::at: __n (which is 10) >= this->size() (which is 4)
```

- **`word.at(1)`** —— 第 1 号位置上的那颗小鱼干。这一串从 **0** 数起，所以 1 号是第二个字母 `i`。这一句好好的，印出来了。
- **`word.at(10)`** —— 这一串只有 4 颗，第 10 颗**根本不存在**，于是 `at` 扔出一辆挂着 `out_of_range` 牌子的车（意思是「**超出范围**」）。
- 车上那句说明里数字都告诉你了：`(which is 10) >= this->size() (which is 4)` —— 你要的是第 10 颗，而这一串只有 4 颗。

（顺带说一句：`at` 是**带软垫版的取法**；第一课那种用方括号 `word[10]` 的取法越界时**不扔车** —— 本喵真跑过，`string word = "miai"; word[10];` 编译期 **0 字节**、一声不吭就编过了。可「不扔车」**不等于「安静」**：跑起来它当场断气，退出码 **127**，屏幕上甩出一句 `Assertion '__pos <= size()' failed.`（441 字节），一个结果都没印出来。不扔车的坏处正是**接不住** —— `try` / `catch` 在这儿一点用没有，程序直接就没喵。）

## 四、自己甩一辆车

`stoi` 和 `at` 扔的车是它们扔的，本喵自己也能造一辆。办法就是 `throw` 一个**带说明的车**：

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

int countFish(int n) {
    if (n < 0) {
        throw runtime_error("鱼干数不能是负数喵");
    }
    return n * 2;
}

int main() {
    try {
        cout << countFish(3) << endl;
        cout << countFish(-1) << endl;
        cout << "这一句不会印出来" << endl;
    } catch (const runtime_error& e) {
        cout << "接住了：" << e.what() << endl;
    }
    return 0;
}
```

```text
6
接住了：鱼干数不能是负数喵
```

- **`throw runtime_error("鱼干数不能是负数喵");`** —— 自己造一辆车，车上贴一句话。`runtime_error` 是「**跑起来以后出的错**」这种牌子（用它得先在开头写一句 `#include`，把 `stdexcept` 借出来 —— 本喵已经写在上面了）。
- 第一次喊 `countFish(3)` 好好的，印出 `6`；第二次给了个 `-1`，招式里就 `throw` 了 —— 你数数看，`这一句不会印出来` 果然**没印出来**，直接被 `catch` 接住，印出车上那句话。

这里有个很值得记住的点：**招式里一个 `try` 都没有。** 扔车的在招式里，接车的在喊它的那一层 —— **扔车的和接车的不用是同一层**。招式只管「这事不对，本喵扔上去」，谁接它，是喊它那位的事。

## 五、兜底的那一辆：`catch (...)`

要是本喵压根不知道会翻出什么样的车呢？那就铺一张**什么都接**的软垫：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    try {
        throw string("猫粮碗打翻了");
    } catch (const string& e) {
        cout << "接到一串字：" << e << endl;
    } catch (...) {
        cout << "不管是什么，先接住再说喵" << endl;
    }

    try {
        throw 7;
    } catch (const string& e) {
        cout << "这一句接不到" << endl;
    } catch (...) {
        cout << "不管是什么，先接住再说喵" << endl;
    }
    return 0;
}
```

```text
接到一串字：猫粮碗打翻了
不管是什么，先接住再说喵
```

- 第一段扔的是一串字，第一个 `catch` 要的正是「一串字」，接住了 → 印 `接到一串字：猫粮碗打翻了`。
- 第二段扔的是数字 `7`，第一个 `catch` 只要一串字，**接不住**，就往下落到兜底那个 `catch (...)` → 印 `不管是什么，先接住再说喵`。
- **`catch (...)` 里那三个点念作「什么都行」**，它是最后一道软垫，什么车都接。规矩是：**兜底那一个必须排在最后** —— 前面的先挑，挑剩下的才轮到它，写在前面就把后面的全抢光了。

（第二段里那个 `这一句接不到` 没印出来 —— 说明 `catch` 是**从上往下挑第一个对得上的**，一个车只被一个 `catch` 接走。）

## 六、没翻车的时候，软垫就当没铺

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    try {
        int n = stoi("7");
        cout << n + 1 << endl;
    } catch (const invalid_argument& e) {
        cout << "这一句不会印出来" << endl;
    }
    return 0;
}
```

```text
8
```

`stoi("7")` 好好的，一点没翻车，`catch` 里那句一个字都没印 —— **软垫只是备着，不用最好**。这正是可以放心给整段活铺软垫的原因：顺利的时候，它不花你一分钱。

## 常见翻车表

| 车上挂的牌子 | 什么时候来 | 你会在哪儿撞上它 |
|---|---|---|
| `std::invalid_argument` | 给的料根本不对 | `stoi("喵")` —— 那串东西不是数字 |
| `std::out_of_range` | 越界了 | `一串字.at(10)` —— 那串只有 4 颗 |
| `std::runtime_error` | 跑起来以后出的错 | 本喵自己 `throw` 出来的（车上贴一句话） |
| 那三个点 `...` | 什么都接 | 兜底软垫，**排在最后** |

::: tip 猫咪提示
五件小抄，一句话一件：

1. **`try { ... }`** —— 铺软垫：这一段要盯着跑。
2. **`throw 某某;`** —— 扔车：本喵不干了，扔给上级。
3. **`catch (什么样 e) { ... }`** —— 接车：括号里写接什么样的车。
4. **`e.what()`** —— 车上贴的那句说明。
5. **`catch (...)`** —— 什么都接，排在最后。
:::

::: warn 小心喵
**本课最大的一个坑：不是所有的翻车都叫异常，`catch` 也不是万能的。**

本喵真跑过这样一段：

```text
int a = 10;
int b = 0;
cout << a / b << endl;
```

屏幕上**什么都没有**，程序当场就没了 —— 铺多少层 `catch` 都没用。因为这件事不是「有人扔了一辆车」，是**机器自己烧了保险丝**，直接停机。**这种翻车接不住，只能提前防**（动手之前先看一眼除数是不是 0 喵）。

另外两条：

1. **别把一大段活全塞进一个 `try` 里。** 铺得太长，出了事你根本不知道该从哪儿查 —— 软垫要铺在你**真的会翻的那几句**周围。
2. **`catch` 括号里写的牌子对不上，就是接不住。** 上面第二段那个 `这一句接不到` 就是活例子：来的是数字，你只接一串字，车就从你手边过去了（要是外面还有兜底，它就落到兜底那儿）。
:::

## 小抄表

| 写法 | 念作 | 干什么 |
|---|---|---|
| `try { ... }` | 铺软垫 | 这一段要盯着跑 |
| `throw 42;` | 扔一辆车 | 把这件麻烦交给上级 |
| `throw runtime_error("说明");` | 自己造一辆带说明的车 | 车上贴一句话给接车的人看 |
| `catch (int e) { ... }` | 接数字那种车 | 括号里写接什么样子的 |
| `catch (const invalid_argument& e) { ... }` | 接「料不对」那种车 | 标准写法，照抄 |
| `catch (...) { ... }` | 什么都接 | 兜底软垫，**排最后** |
| `e.what()` | 车上的说明 | 印出来给猫看 |
