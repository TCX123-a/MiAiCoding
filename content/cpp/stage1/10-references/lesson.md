## 钩子：招式够不着外面那只碗

第 9 课的小任务 5 里，本喵卖了个关子，今天先把答案交给你。做第一个实验：**把一整排碗递进招式里，让招式改一格。**

```cpp
#include <iostream>
using namespace std;

void changeFirst(int bowls[]) {
    bowls[0] = 99;
}

int main() {
    int fish[3] = {3, 5, 2};
    changeFirst(fish);
    cout << fish[0] << endl;
    return 0;
}
```

```text
99
```

招式里改的是 `bowls[0]`，外面那排 `fish` 的**第一格真的变了**。好，记住这个现象，一会儿解释。

现在把递过去的东西**换成一整排里的一只碗**（单独一只），同样的思路再来一次：

```cpp
#include <iostream>
using namespace std;

void addOne(int n) {
    n = n + 1;
}

int main() {
    int fish = 3;
    addOne(fish);
    cout << fish << endl;
    return 0;
}
```

```text
3
```

咦？招式里明明白白写着 `n = n + 1;`，外面那只碗却**一动不动**，还是 3。

原因一句话就能说完：

> **把一只碗递给招式的时候，翻译官喵默认会「照原样复印一份」再递进去。**

招式里那个 `n` 是**一张复印件**，跟外面那只 `fish` 半点关系都没有。你在复印件上涂涂改改，原件当然不动 —— 而且**翻译官喵一个字都不会提醒你**，程序照跑，结果静悄悄地不对。

今天本喵要教你一个特别轻的工具，只加一个小符号，就能把「复印件」换成「直接摸到原碗」。它叫**猫爪指向牌的温柔版（引用）**。

## 第一件事：给同一只碗再挂一个名字

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    int& other = fish;

    other = 10;
    cout << fish << endl;
    cout << other << endl;
    return 0;
}
```

```text
10
10
```

盯住新冒出来的那一行：

```text
int&  other = fish;
```

- **装数的名字后面紧贴着一个小小的 `&`** —— 这就是「温柔版」的记号。它说的是：`other` **不是一只新碗**，它是**给 `fish` 那只碗再挂上的第二个名字**。
- 本喵改的是 `other`，可印出来 `fish` 也变成 10 了 —— **因为它俩根本就是同一只碗，只是挂着两个名字。**
- 这种「同一只碗的第二个名字」，有个说法叫**别名**。

::: tip 猫咪提示
`other` 不是一个「指向 `fish` 的牌子」，**它就是 `fish`**。所以：

- 印 `other` 和印 `fish`，出来的东西一模一样；
- 改 `other` 就是改 `fish`，`other = other + 1;` 也是给 `fish` 加 1；
- 一根魔杖，两个名字，一只碗。就这么简单喵。
:::

「两个名字、一只碗」这件事到底怎么走，本喵拆成一步一步给你看 —— 盯紧「一共几只碗」那一栏：

写下这一行的时候有个动作是**固定**的：`int& other = fish;` —— **`=` 后面必须当场跟上它绑的是哪只碗**。这件事为什么重要，下一节你就知道了。

## 让招式直接摸到那只碗

回到开头那个「加了 1 却纹丝不动」的实验。本喵现在**只改一个地方** —— 在那份料上多写一个 `&`：

```cpp
#include <iostream>
using namespace std;

void addOne(int& n) {
    n = n + 1;
}

int main() {
    int fish = 3;
    addOne(fish);
    cout << fish << endl;
    return 0;
}
```

```text
4
```

**只多了一个 `&`，结果从 3 变成了 4。**

把两版摆在一起，区别一眼就看出来：

| 招式那一头怎么写 | 招式里的 `n` 是什么 | 招式改得动外面吗 |
|---|---|---|
| `void addOne(int n)` | 一张**复印件** | 改不动，白改 |
| `void addOne(int& n)` | 外面那只碗的**另一个名字** | 改得动，一改就到位 |

最舒服的一点是：**喊的时候一个字都不用改。** 两版在 `main` 里都是同一句 `addOne(fish);` —— 变的只是**招式那头怎么接这份料**。写了 `&`，意思就是「别复印了，本喵要直接摸原件」。

这也顺手解释了开头那个实验：**一整排碗整份递过去的时候，翻译官喵天生就不复印**，招式摸到的就是外面那一排，所以你什么都不用写。可**单独一只碗默认是复印的** —— 想让它也摸到原件，就得自己写上那个 `&`。

至于「为什么一整排就天生不复印」，那是下一课的主角，今天先按下不表喵。

### 再来一个：对调两只碗

对调两只碗里的东西，是「必须摸到原件」最经典的一例：本喵得借一只临时碗，把两边的货你来我往地倒一遍。

```cpp
#include <iostream>
using namespace std;

void swapTwo(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3;
    int y = 8;
    swapTwo(x, y);
    cout << x << endl;
    cout << y << endl;
    return 0;
}
```

```text
8
3
```

两样料都写上 `&`，招式里那一套「借临时碗、你来我往」才**真的对调到外面那两只碗上**。

那要是两个 `&` 都漏了呢？

```cpp
#include <iostream>
using namespace std;

void swapTwo(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3;
    int y = 8;
    swapTwo(x, y);
    cout << x << endl;
    cout << y << endl;
    return 0;
}
```

```text
3
8
```

招式里**确实对调了**，可以对调的是两张复印件 —— 外面那两只碗一根毛都没动，印出来还是 3 和 8。

::: warn 小心喵
**这种「改了却什么都没发生」的错，翻译官喵不会报错。**

程序能跑、语法全对、屏幕上还老老实实印出两个数，只是那两个数是**没改过的**。它不像别的错误那样跳出来咬你一口 —— 它静静地待着，等你自己发现。

所以每写完一招「本该改动外面」的招式，本喵都干一件事：**在 `main` 里把它改过的那只碗印出来看看到底变了没。** 这一眼，比什么都值。
:::

## 和「硬邦邦的那一版」有什么不一样

C++ 里还有一种家伙，学名叫**硬邦邦的那一版（指针）**。它跟本喵今天教的温柔版有点像 —— 两样都跟「别处的某只碗」有关 —— 可脾气差得远。

今天你只要先记住三条：

| | 温柔版（`&` 那一版） | 硬邦邦的那一版 |
|---|---|---|
| 开张的时候 | **必须当场绑好**，不能先空着 | 可以先空着，以后再挂 |
| 绑好之后 | **一辈子不换**，绑谁就是谁 | 想换就换，今天指这只、明天指那只 |
| 用的时候 | 跟普通名字一样，直接写 | 每次用都得多写一个小记号 |

第二条最容易摔，本喵给你看个实验：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int& r = a;

    r = b;
    cout << a << endl;
    cout << b << endl;
    return 0;
}
```

```text
2
2
```

`r = b;` 这一句，看着特别像「把 `r` 改绑到 `b` 上去」—— **不是。**

温柔版**一旦绑好就一辈子不换**，所以这一句真正干的事是：**把 `b` 的值抄进 `r` 那只碗**。而 `r` 就是 `a`，于是 `a` 也成了 2。

本喵再给你看一个反面例子：要是有人想说「先摆一根空的，以后再绑」，翻译官喵当场翻脸。

```cpp
#include <iostream>
using namespace std;

int main() {
    int& r;
    int fish = 3;
    r = fish;
    cout << r << endl;
    return 0;
}
```

```text
main.cpp:5:10: error: 'r' declared as reference but not initialized
```

`declared as reference but not initialized` 的意思是：**「你说这是个温柔版，可你没说它绑的是哪只碗。」**

看到 `not initialized` 那几个字，就回头看那一行：**`=` 后面有没有当场跟上它要绑的那只碗？** 写成 `int& r = fish;` 那样，才有一根能用的喵。

（至于第三行那条「用的时候要多写个小记号」，下一课那位正式登场时你会看得清清楚楚。）

## 什么时候该用它

| 本喵想干的事 | 料那头怎么写 |
|---|---|
| 招式只是**看看**那份料，不动它 | 什么都不加（`int n`） |
| 招式要**改外面那只碗** | 料上写 `&`（`int& n`） |
| 招式要用一大份东西，又不想每喊一次就复印一大份 | 料上写 `&`（只看不改也一样能省） |
| 递过去的是一整排碗 | **天生就不复印**，什么都不用加 |

最后一行是今天最省事的一条：**一整排碗本来就摸得到原件，不用你操心。**

::: tip 猫咪提示
本课五次总结，一句话一个：

1. **递一只碗进招式，默认是复印一份** —— 招式里改了也传不出来，而且不报错。
2. **料上写 `&`（`int& n`）就变成「直接摸原件」** —— 喊的那一头一个字都不用改。
3. **`int& other = fish;`** —— 给同一只碗再挂一个名字，改哪个都是改那只碗。
4. **开张时必须当场绑好，绑好就一辈子不换** —— `r = b;` 不是改绑，是把 `b` 的值抄进 `r`。
5. **一整排碗天生就不复印** —— 这是它和单独一只碗最不一样的地方。
:::
