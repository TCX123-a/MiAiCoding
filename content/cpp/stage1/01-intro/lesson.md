## 钩子：大肥鱼推来的新锅铲

本喵的点单铺最近生意好，大肥鱼一天要游过来三趟。可它每次点完单，本喵都得一样样摆出来——「三条小鱼干」「一碗水」「一把猫草」——**摆一样写一句**，少写一样它就不肯走，尾巴还拍水花。

「要是有一口锅，能自己把这些都记着就好了。」本喵蹲在灶台边叹气。

大肥鱼甩着尾巴，从鱼塘那头推来一把崭新的锅铲，亮得能照出本喵的耳朵：「换这把吧。它叫 **C++**。」

## C++ 是什么：名字里那对加号

C++ 这个名字念作「C 加加」。那两个加号的意思很直白：**在 C 的基础上，又给你加了几样东西**。

这一课本喵要一路拿 **C** 来对照着讲——C 是 C++ 的上一辈，拿它当尺子量，最能看出 C++ 换掉了什么、又留下了什么。你在 C 那边见过的东西，本喵就直接拿来比；要是你还没碰过 C，也不要紧，凡是提到它的地方，本喵都会顺手说清它在讲什么喵。

所以第一件让你松口气的事是：

> **在 C 那里学会的那套规矩，一个字都不用重学。**

「整本翻完再开演」的脾气、花括号圈地盘、每句末尾的分号、`main` 那扇大门——全都照旧。C++ 不是另一门陌生的语言，它是 C 的升级版，是同一个翻译官喵后来学会的新手艺。

那它加了什么呢？加了几样**替你省心的家伙**。本喵先卖个关子，等第一份程序跑通了，马上带你看它们喵。

## 第一份 C++ 程序：还是那句你好

先看成品。这份程序一共七行，本喵真跑过：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "你好，喵！" << endl;
    return 0;
}
```

```text
你好，喵！
```

和 C 那份摆在一起比一比，你会发现：**骨架一模一样**。请档案管理员、那扇叫 `main` 的大门、花括号、末尾的分号、收工时报的平安——一个都没变。

真正换掉的只有两处，本喵带你逐行看过去喵。

### 第一行：请的是另一位管理员

C 请的是档案室里管投喂和叼回的那位，C++ 请的是一位叫 `iostream` 的管理员。

它的名字拆开看很好记：**i-o** 就是「叼进来、念出去」；末尾那几位是「流动的管子」。所以往后你在 C++ 里念话、听话，都是请这位管理员来帮忙。

### 第二行：一句新面孔

```cpp
using namespace std;
```

这一行是 C++ 独有的，本喵下面单独讲它，先记住它**必须写在 `main` 外面、最上面那几行**。

### 第三到六行：大门、念话、收工

`int main() {` 还是那扇大门：电脑一跑你的程序，就直奔它的花括号里第一行，别的句子都得等它喊。

接下来那句是本课的重头戏：

```cpp
cout << "你好，喵！" << endl;
```

`cout` 是 C++ 的念话招式（念作「C-out」，out 就是「出去」）。它和 C 的老招式干同一件事，但**怎么用**完全换了样子——它是一根管子，不是一对括号。

`endl` 是换行的暗号，作用和你见过的那个 `\n` 一样：让光标跳到下一行去。它自己不会被念出来。

最后 `return 0;` 报平安，半个花括号收工。**分号一个都不能少**，这条规矩和 C 一样严。

### `cout` 是一根管子：一件一件往里塞

看清楚 `<<` 这个符号：两条水流朝一个方向汇过去，形状就是「**塞进去**」。

所以你念一样东西，就「塞」一次。想多念几样，接着塞就是了，塞几样都行——**不用记任何格式符**（这是 C++ 比 C 省心的第一处，你在 C 里念一个数字得先想清楚它该配哪种占位符，这里不必）。

还有个小脾气要提前说：这根管子**很老实，塞什么念什么，不会自己替你垫空格**。你要是想让两个词中间空一格，那个空格得**自己写进引号里**。（等会儿本喵念那行「柜子里有 3 条小鱼干」时，引号里末尾那个不起眼的空格就是干这个用的喵。）

想多念一句，就多写一行：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "喂猫手册第一条：拿起小鱼干" << endl;
    cout << "喂猫手册第二条：放进碗里" << endl;
    return 0;
}
```

```text
喂猫手册第一条：拿起小鱼干
喂猫手册第二条：放进碗里
```

顺序就是从上往下写的顺序：谁写在前面，谁先出声。这一条和你学过的别处一模一样，不用重新记喵。

### 那句 `using namespace std;` 到底管什么

这是本课唯一的新面孔，本喵打个比方你就懂了。

C++ 把它的家伙什**按门牌收进一口口柜子里**（这种柜子的正式名字叫「命名空间」）。念话招式的大名其实叫 `std::cout`——前面那半截 `std::` 就是柜子的门牌，告诉你「这家伙住在 std 柜子里」。

每次喊它都要报一遍门牌，太啰嗦了。于是有了这一句：

```cpp
using namespace std;
```

它的意思是「**把 std 这口柜子的门打开**」。门一开，柜子里的东西就可以直接喊短名字：`cout`、`endl`，都不用再报门牌。

当然，你也可以不开门，每次都老老实实报门牌。**两版跑出来一模一样**：

```cpp
#include <iostream>

int main() {
    std::cout << "你好，喵！" << std::endl;
    return 0;
}
```

```text
你好，喵！
```

::: tip 猫咪提示
两版都行，但**一份稿子要一条心**：要么上面开了柜门、底下全用短名字，要么一次都不省、处处报门牌。最怕的是前两句喊 `cout`、后两句又写 `std::cout`——这样翻得过去，可读起来像是两只猫写的喵。
:::

## 比 C 多给的三样：终于不用自己管了

现在来看那两行 `using` 底下藏着的好东西。本喵只给你尝一口，它们各自都有专门的一课。

**第一样：一串字会自己长大。**

在 C 里，一串字得提前数好能装多少，装不下就得自己动手搬家。C++ 里不用：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string bowl = "猫粮碗";
    bowl = bowl + "里的小鱼干";
    cout << bowl << endl;
    return 0;
}
```

```text
猫粮碗里的小鱼干
```

看见没？本喵压根没说「这个碗能装几个字」，开头只有「猫粮碗」三个字，后来又往里接了一截，它自己就长长了。**你只管往里放，够不够是它的事**——这就是 C++ 里那串字（本喵管它叫「项链」）的脾气喵。

要接东西，用的是加号 `+`，看形状就像把两截项链串到一起。

**第二样：一排碗会自己长大。**

C 里最让本喵头疼的就是「一排碗」：要提前报数，多一个都塞不进，还得自己数着别越界。C++ 给你一排会自己长大的碗：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> box;
    box.push_back(3);
    box.push_back(5);
    box.push_back(8);
    cout << "柜子里有 " << box.size() << " 条小鱼干" << endl;
    cout << "头一条是 " << box[0] << endl;
    return 0;
}
```

```text
柜子里有 3 条小鱼干
头一条是 3
```

一步一步看：先摆一个空柜子，然后往里放一条、又一条、再一条。`push_back` 就是「**从后面推一条进去**」，放几条它就自己撑大几格；`.size()` 是问它「现在里面有几条」。

留神最后那行 `box[0]`：**它数东西是从 0 开始的**——头一条的编号是 0，不是 1。这个怪脾气你先记住，后面有专门一课讲它。

**第三样：耳朵也是现成的。**

`cout` 负责把字念出去，`cin`（念作「C-in」，in 就是「进来」）负责把字叼进来——你敲的字它能接住，塞进仓库里存着。这一条也是一行就办、不用记格式符，本喵留到讲投喂与叼回那一课再细说。

三样加在一起，就是 C++ 想让你感觉到的那句话：**「这些烦人的活儿，交给它就行。」**

## 写坏了会怎样：三张翻车现场

最后，本喵故意写坏三处，把翻译官喵的原话抄给你看。**这三处正是 C++ 新手最常踩的坑**，看完你就认得它们了喵。

### 一、忘了请管理员出场

第一行整个没写，只留了柜门那一句：

```cpp
using namespace std;

int main() {
    cout << "你好，喵！" << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:4:5: error: 'cout' was not declared in this scope
main.cpp:1:1: note: 'std::cout' is defined in header '<iostream>'; this is probably fixable by adding '#include <iostream>'
```

最后那半句是翻译官喵难得的体贴：`this is probably fixable by adding`——「**加上这一行大概就修好了**」。它连该补哪一行都替你写出来了，就是上面报错原文里被单引号夹着的那一句。

（顺便说一句：就算你写了 `using namespace std;`，柜门开了，可柜子里压根没有 `cout` 这件东西——因为它的来历写在 `iostream` 里，你没请那位管理员，它就没进过门。）

### 二、忘了打开柜门

反过来，管理员请了，柜门忘了开：

```cpp
#include <iostream>

int main() {
    cout << "你好，喵！" << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:4:5: error: 'cout' was not declared in this scope; did you mean 'std::cout'?
```

盯着最后那半句 `did you mean 'std::cout'?`——翻译官喵在猜你的心思：「你是想喊 `std::cout` 吧？」这时候你只要把柜门那句 `using namespace std;` 补上，或者照它说的把门牌报全，就好啦。

### 三、忘了分号

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "开饭啦喵" << endl
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:5:31: error: expected ';' before 'return'
```

`expected ';' before 'return'` 是「**在 `return` 前面，本喵期待一个分号**」。它连你在第 5 行、第 31 个字符那儿漏的都知道——所以看报错时先看那两个数字，比一行行猜快得多喵。

::: warn 小心喵
这三种错各有各的脸，记熟它们能省你不少时间：

- **`was not declared` + 提到加 `iostream`** → 管理员没请；
- **`was not declared` + `did you mean 'std::cout'?`** → 柜门没开；
- **`expected ';'`** → 分号漏了。

还有一条更要紧的：**这三种错，程序一行都不会跑**。C++ 和 C 一样是「整本翻完再开演」的脾气，第一句写得再对，只要后面翻不过去，屏幕上就是一个字都没有。所以「什么都没输出」的时候，别急着怀疑那句念话，先回头看看有没有报错喵。
:::

::: tip 猫咪提示
今天记住四件事：

1. `#include` 请的是管理员，C++ 请的是 `iostream`；
2. `using namespace std;` 是**打开柜门**，开了门才能直接喊 `cout`、`endl`；
3. `cout` 是**管子**：`<<` 塞一样，要念几样就塞几样，换行用 `endl`；
4. 每句末尾的**分号**一个都不能少，`return 0;` 收工报平安。

再顺手记住 C++ 给你的三样好东西：**会自己长大的项链、会自己长大的碗、现成的耳朵**。
:::

## 小任务

1. 把第一段代码一字不差地敲进编辑器，跑一遍，看看屏幕上是不是那句「你好，喵！」。
2. 把引号里的字换成「本喵会写 C++ 啦」，末尾再加一句 `cout << "第二句" << endl;`，跑一跑，看看两行是怎么排的。
3. 故意把第二行 `using namespace std;` 删掉，再跑一次——报错里有没有出现 `did you mean`？把你看到的原话抄在手边。
4. 把柜门那句补回去，再故意删掉末尾一个分号，看看报错说的是第几行第几个字符。对照着课文比一比，是不是能一眼认出是哪张脸喵。

下一课，本喵要带你去看那两件事是怎么发生的：**你敲下的这几行字，中间到底过了几道工序，才变成屏幕上那句你好**——顺便还有一条新手最冤枉的坑：改了稿子忘了重翻喵～ 🐾
