## 钩子：大肥鱼心里那个数

今天开工第一台**自己会玩的机器**：猜数字。

规矩你肯定玩过：本喵心里想一个 1 到 100 之间的数，你来猜；每猜一个，本喵只回你一句话 —— **「太小啦喵」「太大啦喵」或者「猜中啦喵」**，直到你猜中为止。

听起来简单，可真要写成程序，你会撞上三个新问题：

1. **本喵心里那个数，程序从哪儿来？** 总不能让写程序的人自己挑一个吧 —— 那玩两遍就没意思了。
2. **你不知道要猜几次。** 运气好一次就中，运气不好得十几回 —— 前面学的 `for` 圈要你事先说好跑几圈，这活儿它干不了。
3. **猜中以后得收工**，不能再傻乎乎地接着问。

这三件事一个一个解，解完就能装成整台机器。开始喵。

## 一、让机器自己想一个数

C++ 里有个招式叫 `rand()`，念作「random」——**它每次喊都会吐一个不太小的整数出来**。要它吐得动，开头得写一句 `#include`，把 `cstdlib` 借出来。

直接喊它有个小毛病：**每次开演都吐同样一串数。** 本喵跑给你看：

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    srand(1);
    for (int i = 0; i < 5; i++) {
        cout << rand() % 100 + 1 << endl;
    }
    return 0;
}
```

```text
42
68
35
1
70
```

先看 `srand(1);` 这一句喵：`srand` 是「**下种子**」—— 念作 s-rand，意思是「本喵给这台机器一颗种子，它照着这颗种子吐数」。**同一颗种子，吐出来的那一串永远一模一样**；这就是为什么上面那五行你每次跑都是这五个数。

（这五行是本喵在这台机器上跑出来的。**换成别的机器、别的库，同一颗种子吐出来的可能不是这五个数** —— 但「同一颗种子、同一串数」这条规矩到处都一样。）

再看 `rand() % 100 + 1` 这一截：

- **`rand() % 100`** —— `%` 是第 05 课学的「取余」，一个数除以 100 剩下的那点。不管 `rand()` 吐出来多大多小，`% 100` 的结果一定落在 `0` 到 `99` 之间。
- **`+ 1`** —— 把范围挪一格，变成 `1` 到 `100`。

合起来就是「**从 1 到 100 里随便挑一个**」——正是本喵心里那个数。

::: tip 猫咪提示
`srand` 那句你可能会问：为什么非得钉一颗种子？

因为**种子一样、数就一样**，本喵才能把跑出来的结果原样贴给你看，你也才能对着屏幕一行一行核对。这叫**钉住运气**。

真玩的时候当然不能钉 —— 第五节本喵教你怎么让种子每次都换一个喵。
:::

## 二、猜的次数说不准，那就别数圈数

第二个问题：**你猜几次，谁也不知道。**

`for` 圈是我们最熟的那个圈，可它的开头就写着「跑几圈」。要是写成「跑 3 圈」，运气不好就得中途停；写成「跑 20 圈」，猜中了它还在傻问。

所以这回用另一种圈 —— **第七课那种不讲圈数的圈**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int target = 42;
    int picks[4] = {10, 50, 25, 42};
    int i = 0;

    while (true) {
        int guess = picks[i];
        i = i + 1;
        cout << "本喵报 " << guess << endl;
        if (guess == target) {
            cout << "猜中啦喵" << endl;
            break;
        }
    }
    return 0;
}
```

```text
本喵报 10
本喵报 50
本喵报 25
本喵报 42
猜中啦喵
```

三个关键点喵：

- **`while (true)`** —— 第七课本喵提过它，还说过「本喵故意不给能跑的示例，因为它一跑起来就停不下来」。**今天它配上 `break`，能停了**，可以放心跑。念作「**一直转下去，直到有人喊停**」。
- **`break;`** —— 猜中了就喊停，从圈里跳出来。这就是「收工」两个字。
- **`int picks[4] = {10, 50, 25, 42};`** 和 `int guess = picks[i];` —— 这一排是**替身**。

### 为什么要替身？

因为你跟着本喵在这儿跑的时候，**键盘是敲不进去的** —— 机器不会停下来等你输入。所以要教「反复猜」这件事，本喵就**先把你要猜的那几个数写成一排**，让机器自己一格一格往下报：先报 10、再报 50、再报 25、最后报 42。

`i` 是「报到第几格了」，每报一格就 `i = i + 1;`。`picks[i]` 就是第 `i` 格上那个数 —— 一排碗加编号取货，第 08 课学的老手艺。

（真坐在键盘前面玩的那一版在第五节，那才是给你自己玩的。）

## 三、三条岔路：`check` 招式

现在把「本喵回你哪句话」这件事单独拆成一招。为什么拆？因为**它是一件事，就该有个名字** —— 第九课那套「一招只干一件事」的老规矩，越到项目里越值钱。

```cpp
#include <iostream>
#include <string>
using namespace std;

string check(int guess, int target) {
    if (guess < target) {
        return "太小啦喵";
    } else if (guess > target) {
        return "太大啦喵";
    } else {
        return "猜中啦喵";
    }
}

int main() {
    cout << check(10, 42) << endl;
    cout << check(50, 42) << endl;
    cout << check(42, 42) << endl;
    return 0;
}
```

```text
太小啦喵
太大啦喵
猜中啦喵
```

- 这一招的**料**是两个整数（`guess` 是猜的，`target` 是本喵心里那个），**叼回来的是**一串小鱼干（也就是一句话）—— 所以招式名前面写 `string`。
- 三条岔路正好对应三句话，一条不多一条不少。
- 注意这一招**自己不印任何东西**，它只负责**报信**：把该说的话叼回来，印不印、什么时候印，是喊它那位的事。

::: tip 猫咪提示
「只报信、不印字」这一条，看着像小事，其实是**招式好不好用的分水岭**：

- 本喵想把它印在屏幕上 → `cout << check(...)`；
- 本喵想把这句话再加工一下（比如前面加个「第 3 次：」）→ 直接拼；
- 本喵想测试它 → 不用盯着屏幕看，比一比叼回来的话对不对就行。

招式里一旦写死了 `cout`，上面三件事它就只能干第一件了喵。
:::

## 四、把三条岔路塞进圈里

零件齐了，装起来：

```cpp
#include <iostream>
#include <string>
using namespace std;

string check(int guess, int target) {
    if (guess < target) {
        return "太小啦喵";
    } else if (guess > target) {
        return "太大啦喵";
    } else {
        return "猜中啦喵";
    }
}

int main() {
    int target = 42;
    int picks[4] = {10, 50, 25, 42};
    int i = 0;

    while (true) {
        int guess = picks[i];
        i = i + 1;

        cout << "本喵报 " << guess << "：" << check(guess, target) << endl;

        if (guess == target) {
            break;
        }
    }
    return 0;
}
```

```text
本喵报 10：太小啦喵
本喵报 50：太大啦喵
本喵报 25：太小啦喵
本喵报 42：猜中啦喵
```

看那句最长的：`cout << "本喵报 " << guess << "：" << check(guess, target) << endl;`

它是前面几课学过的东西**串起来**的：先印一段字，再把 `guess` 印上去，再接一句 `check` 叼回来的话。**没有任何新东西**，只是零件多了几个 —— 项目课的味道就是这个喵。

## 五、拆成一整局：`play` 招式

到这儿机器能跑了，可它还是「摊在地上」的：想再玩一局就得把那一大段全抄一遍。收工之前，本喵把它折成招式：

```cpp
#include <iostream>
#include <cstdlib>
#include <string>
using namespace std;

string check(int guess, int target) {
    if (guess < target) {
        return "太小啦喵";
    } else if (guess > target) {
        return "太大啦喵";
    } else {
        return "猜中啦喵";
    }
}

int play(int target, int picks[], int n) {
    int i = 0;
    while (i < n) {
        int guess = picks[i];
        i = i + 1;

        cout << "本喵报 " << guess << "：" << check(guess, target) << endl;

        if (guess == target) {
            return i;
        }
    }
    return 0;
}

int main() {
    srand(1);
    int target = rand() % 100 + 1;
    int picks[4] = {10, 50, 25, 42};

    int used = play(target, picks, 4);
    cout << "答案是 " << target << "，一共猜了 " << used << " 次喵" << endl;
    return 0;
}
```

```text
本喵报 10：太小啦喵
本喵报 50：太大啦喵
本喵报 25：太小啦喵
本喵报 42：猜中啦喵
答案是 42，一共猜了 4 次喵
```

这一折，折出来四样东西，一样一样看喵：

1. **`play` 收三样料**：本喵心里那个数（`target`）、那一排替身（`picks[]`）、还有这一排有几格（`n`）。
   —— 注意**一排碗递进招式的时候，格数得自己另外报**：上一课本喵讲过，一整排碗的名字交出去的是第一只碗的门牌号，招式并不知道这一排有多少格。这就是 `n` 为什么非得跟着一起来，也是圈里那句 `while (i < n)` 的依据：替身还有，就接着报。
2. **猜中了不写 `break;`，直接 `return i;`** —— 第九课学的「把战利品叼回来」。这一招叼回来的是**猜了几次**，正是 `main` 想要的那个数字。
3. **万一替身报完了还没猜中**，圈一结束就落到最后那句 `return 0;` —— 叼回来一个 `0`，意思是「一次也没猜中」。**招式必须每条路都有战利品叼回来**，这条兜底的路也别忘了。
4. **`int used = play(target, picks, 4);`** —— 喊一局，把「猜了几次」装进 `used`。
5. **`srand(1);` 挪到了 `main` 一开头**，`target` 是**当场抽**的：以后想换个数，改种子就行，招式一行都不用动。

（顺带一句：`play` 的圈里没有 `break` —— 因为 `return` 一出，整个招式当场收工，比「跳出圈」还干脆。下一节的「小任务」里本喵会问你：要是把它换回 `break`，会发生什么喵？）

## 六、真机版：自己敲数字来玩

上面那台机器是**本喵替你猜**。你想要的那一版，是**你自己在键盘上敲**。这就是投喂口 `cin` 上场的地方 —— 它长得跟第 04 课一模一样：

```text
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    srand(1);
    int target = rand() % 100 + 1;
    int guess = 0;
    int used = 0;

    cout << "本喵想了一个 1 到 100 的数，来猜猜看喵～" << endl;
    while (true) {
        cout << "猜一个数喵：";
        if (!(cin >> guess)) {
            cout << endl << "投喂口空了，本喵先收工喵" << endl;
            break;
        }
        used = used + 1;
        if (guess < target) {
            cout << "太小啦喵" << endl;
        } else if (guess > target) {
            cout << "太大啦喵" << endl;
        } else {
            cout << "猜中啦喵！一共猜了 " << used << " 次" << endl;
            break;
        }
    }
    return 0;
}
```

这一段**要敲键盘**，所以本喵没法在这儿现场跑给你看。本喵把种子钉成 `1`、自己按顺序敲了 `10`、`50`、`25`、`42`，那一次的屏幕是这样的：

```text
本喵想了一个 1 到 100 的数，来猜猜看喵～
猜一个数喵：太小啦喵
猜一个数喵：太大啦喵
猜一个数喵：太小啦喵
猜一个数喵：猜中啦喵！一共猜了 4 次
```

四句话喵，把这一版和前面那版对一对：

- **`cin >> guess`** 就是第 04 课的投喂口：本喵问「猜一个数喵：」，你就敲一个数进去，它把那个数装进 `guess` 里。
- **`if (!(cin >> guess))`** 是第 04 课那根**保险绳**：万一投喂口空了（没人往里喂东西了），别让程序傻等或者乱转，直接收工。
- **猜完一次，`used = used + 1;`** —— 自己数着猜了几次。
- **`srand(1)` 要换掉。** 真玩的时候把它换成 `srand(time(0));`（还得在开头加一句 `#include`，把 `ctime` 借出来）—— `time(0)` 是「**现在几点**」，每次开演的时间都不一样，于是种子每次都不一样，本喵心里那个数自然也就每局都换。**要是你还留着 `srand(1);`，那每局都是同一个 42，玩两遍就没意思了喵。**

::: warn 小心喵
这一节的两个坑，都是本喵踩过的：

1. **`srand` 一句只能下种一次**，而且要在最开头。把它塞进圈里，每猜一次就重新下一颗种子 —— 种子一样、第一个数就一样，你会碰上一台「怎么猜都猜不中」的机器。
2. **`cin >> guess` 那句不能顺手删掉那根保险绳。** 真在键盘前面玩的时候，玩到一半想按 Ctrl+C 或者输入没了，圈就靠它落地收工；没了它，机器会拿着上一次猜的那个数空转，屏幕上刷得停不下来。
:::

## 小抄表

| 写法 | 念作 | 干什么 |
|---|---|---|
| 开头 `#include` 一句 `cstdlib` | 把 `rand`、`srand` 借出来 | 抽数要先写这一句 |
| `srand(1);` | 下种子 | 钉住运气，同一个种子吐同一串数 |
| `rand()` | 吐一个整数 | 每次喊都吐一个不太小的整数 |
| `rand() % 100 + 1` | 从 1 到 100 随便挑一个 | `%` 把结果压进 0 到 99，`+ 1` 挪到 1 到 100 |
| `while (true) { ... }` | 一直转，直到有人喊停 | 不知道要转几圈的时候用它 |
| `break;` | 喊停 | 从圈里跳出来 |
| `return i;` | 把战利品叼回来、当场收工 | 在招式里，它比 `break` 还干脆 |
| `if (!(cin >> guess))` | 保险绳 | 投喂口空了就收工（第 04 课那根） |
| `srand(time(0));` | 每次换一颗种子 | 真玩的时候用（还要 `#include` 把 `ctime` 借出来） |

::: tip 猫咪提示
装一台机器，本喵走的是这四步 —— 以后你自己开工也照这个节奏：

1. **把大活儿拆成小零件**（算范围、判大小、数次数），一件一件单独跑通；
2. **每个零件都拆成一招**（`check` 就是「报信」那一招），一招只干一件事；
3. **零件串起来装上**（第四节那句最长的 `cout`），先跑通再收拾；
4. **折成招式**（`play`），让主流程只剩下「下种子 → 抽数 → 喊一局 → 印结果」四行。
:::

## 小任务

1. 把第一段里的 `srand(1);` 改成 `srand(2);`，跑一次 —— 那一串数变了没有？（这就是「换一颗种子」的意思。）
2. 把第二段里的替身数列改成 `{50, 25, 12, 42}`，跑一次，看看报了哪几个数、一共报了几次。
3. 把第三段里 `check(10, 42)` 改成 `check(42, 10)`，先猜猜印什么，再跑一遍对答案。
4. 把第五段里 `int picks[4] = {10, 50, 25, 42};` 改成 `{42, 10, 50, 25}`，跑一次 —— 「一共猜了」几次？
5. 自己写一局：把 `play` 的替身数列换成五个数，最后一个才是 42，看看它会不会自己停下来。
6. 留一问给你：把 `play` 里那句 `return i;` 换成 `break;`，跑一次。`main` 里那句「一共猜了」印出来是几？想想为什么会变成那个数喵？
