## 钩子：大肥鱼的一百圈

本喵的好朋友「大肥鱼」——那条圆滚滚的蓝色大鱼——今天要在鱼塘里游圈锻炼。它的规矩是：**游一圈，本喵喂一条小鱼干。** 一圈一条，一百圈就是一百条。

要是本喵老老实实写一百行「喂一条」，爪子都敲断啦。电脑最擅长「同一套动作重复很多遍」，本喵居然在替它干！

这种活儿，术语表里叫**绕鱼干跑圈（循环）**。今天本喵要把它在 C++ 里学扎实，一共五件事：

1. **`for`** —— 圈数数得清的时候，三件家当挤在一行里；
2. **`while`** —— 数不清圈数，只能凭眼色停；
3. **`do-while`** —— 先干一圈再问话；
4. **`break` 和 `continue`** —— 跑到一半想变卦的两招；
5. **范围 `for`** —— 一整排东西挨个走一遍的省事形状（初识，认个脸就好）。

## `for`：三件家当挤在一行

先看最省心的一种：本喵**明明白白知道**要发 3 条。

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 0; i < 3; i++) {
        cout << "绕第 " << i + 1 << " 圈喵" << endl;
    }
    return 0;
}
```

```text
绕第 1 圈喵
绕第 2 圈喵
绕第 3 圈喵
```

`for` 最有 C++ 气质的地方，就是**三件家当全挤在那一对小括号里，用两个分号隔开**：

```text
for ( 起手 ; 眼色 ; 收尾 )
```

盯着一行行读：

- **起手 `int i = 0;`** —— 圈还没开始跑之前，先做这一件事：造一只装「现在是第几圈」的仓库 `i`，先洗成 **0**。它**整趟只做一次**。
- **眼色 `i < 3;`** —— 每一圈**开场前**都瞄一眼：答真才跑这一圈，答假就收工。
- **收尾 `i++;`** —— 每一圈**跑完之后**做这一件事。`i++` 是 C++ 的省事写法，意思就是「把 `i` 加 1」，跟 `i = i + 1` 一模一样。

跟着数一遍：起手 `i` 是 0 → 瞄一眼 0 比 3 小，答真 → 印「绕第 1 圈喵」→ 收尾让 `i` 变成 1 → 1 比 3 小，答真 → 印第 2 圈 → `i` 变 2 → 印第 3 圈 → `i` 变 3 → 3 比 3 小吗？答假，圈停了。屏幕上正好三行喵。

**三件家当的时机记牢，跑圈就再也没有秘密**：起手只做一次、眼色每圈做一次（**在循环体之前**）、收尾每圈做一次（**在循环体之后**）。

### `i` 是从 0 开始数的

别急着往下看，先盯着 `i` 看它每圈领到了什么：

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 0; i < 3; i++) {
        cout << i << endl;
    }
    cout << "跑完啦" << endl;
    return 0;
}
```

```text
0
1
2
跑完啦
```

两个要紧的地方：

- **`i` 领到的是 0、1、2，不是 1、2、3。** 因为起手写的是 `int i = 0`，它**从 0 起**。所以想印「第 1 圈」，得自己写 `i + 1`（上面那段就是这么干的）。
- **最后那句 `cout << "跑完啦"` 只印了一遍，没跟着跑三遍。** 因为它在大括号**外面** —— 圈里的活儿跑完了，才轮得到它。

想让 `i` 从 1 数到 3，就把起手改成 `int i = 1`、眼色改成 `i <= 3`。写法随你，只要三件家当对得上就行。

### 小碗累加：跑圈最常干的活

跑圈最常干的一件事，是「把每一圈领到的东西攒起来」。攒东西得先备一只小碗：

```cpp
#include <iostream>
using namespace std;

int main() {
    int total = 0;
    for (int i = 1; i <= 4; i++) {
        total = total + i;
    }
    cout << total << endl;
    return 0;
}
```

```text
10
```

跟着念一遍：小碗 `total` 先洗成 **0**；第一圈 `i` 领到 1，碗里变成 0＋1＝1；第二圈领到 2，碗里 1＋2＝3；第三圈 3＋3＝6；第四圈 6＋4＝**10**。四圈跑完，把碗端出来印一下——这就是「求 1 到 4 的和」喵。

::: tip 猫咪提示
**数得清圈数用 `for`，只能凭眼色停用 `while`**——这是本喵的小口诀。`for` 的圈数开跑前就定好了（眼色什么时候答假，开跑时就看得出来），跑满自动收工；`while` 不问圈数，每一圈都要重新瞄一眼眼色。
:::

## `while`：只能凭眼色停的时候

有些活儿事先数不清——比如碗里还剩几条鱼干，本喵懒得数，只认一条规矩：**「碗里还有，就接着发。」**

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    while (fish > 0) {
        cout << "碗里还有 " << fish << " 条喵" << endl;
        fish--;
    }
    cout << "发完啦" << endl;
    return 0;
}
```

```text
碗里还有 3 条喵
碗里还有 2 条喵
碗里还有 1 条喵
发完啦
```

`while` 的读法是：**每跑一圈之前，先看一眼小括号里的眼色：答「真」才继续跑，答「假」就收工。** 它的小括号里只有眼色这一件家当，起手和收尾都得你自己在圈里安排。

跟着念一遍：`fish` 是 3 → 3 比 0 大，答真 → 发一条、`fish` 变成 2；2 比 0 大 → 又发一条、`fish` 变成 1；1 比 0 大 → 再发一条、`fish` 变成 0；第四次瞄一眼——0 比 0 大吗？答假，圈停了。屏幕上正好三条喵。

### 让眼色有机会变假

上面那段里最要紧的是哪一行？不是 `while`，也不是 `cout`，而是那句 **`fish--;`**（`--` 是 `++` 的反面，意思是「减 1」）——它每跑一圈就把眼色往前挪一格，让 `fish` 早晚有一天变成 0。

漏了它会怎样？`fish` 永远是 3，眼色永远答真，圈就永远停不下来——代码会一路跑到你硬把窗口按掉。这种圈，本喵管它叫**停不下来的圈**，是新手最常撞的一堵墙。

最典型的一种长相是 `while (true)`——`true` 是个永远不变的值，眼色永远是真。所以本喵**故意不给能跑的示例**：它一跑起来就得强行关窗口，界面会卡死喵。

::: warn 小心喵
写完任何一个 `while`，都停下来问自己一句：**圈里有没有一句代码，能让那个眼色早晚变成假？** 那个数要越跑越小（或者越跑越大），不能原地踏步。这一问，能救你一台电脑喵。
:::

## `do-while`：先干一圈，再问眼色

`for` 和 `while` 都是**开场先问**：眼色答假，圈里的活儿一下都不干。可有些活儿天生要求「不管怎样，第一遍必须干完再说话」。

C++ 为此准备了老三 `do-while`。把它和 `while` 摆在一起，区别一眼就看出来：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 0;

    while (fish > 0) {
        cout << "while 这边：碗里有鱼干喵" << endl;
    }

    do {
        cout << "do-while 这边：本喵先干了一圈喵" << endl;
    } while (fish > 0);
    return 0;
}
```

```text
do-while 这边：本喵先干了一圈喵
```

`fish` 是 0，两边问的都是「比 0 大吗」，答案都是假。可 `while` 那边**一句话都没印**，`do-while` 那边却印了一句：

- **`while`** —— 先问，答假就一圈都不跑。
- **`do-while`** —— 先干一圈，**干完才**回头看眼色。

写 `do-while` 有两个固定动作，本喵都帮你圈出来：

1. 家当的顺序倒过来：先写 `do { ... }`，把要干的活儿包进去，**最后**才写 `while (眼色);`。
2. **`while (眼色)` 后面那个分号，一个都不能少。** 少了它，翻译官喵当场翻脸。

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 0;
    do {
        fish = fish + 1;
    } while (fish < 3)
    cout << fish << endl;
    return 0;
}
```

```text
main.cpp:8:23: error: expected ';' before 'cout'
```

最后那句的意思是：**在本喵等着一个分号的地方，冒出来的是 `cout`。** 看到 `expected ';'` 三个字，往上找那个漏掉的分号 —— `do-while` 的尾巴上是它最容易漏的地方喵。

## `break` 与 `continue`：跑到一半变卦

`for`、`while`、`do-while` 三个兄弟都是「跑满就收工」。可有时候本喵想半路变卦：要么**提前收工**，要么**这一圈不干了、直接跳下一圈**。C++ 给了两个词管这件事。

### `break`：提前收工

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 4) {
            break;
        }
        cout << i << endl;
    }
    cout << "收工喵" << endl;
    return 0;
}
```

```text
1
2
3
收工喵
```

眼色本来是 1 跑到 10。可跑到 `i` 是 4 那一圈时，`if (i == 4)` 先问一句（`==` 问的是「两边一样吗」），答真，就撞上了 `break`——**`break` 一撞上就收工**：剩下的圈数全部作废，程序跳到圈外，接着往下跑。所以只印出 1、2、3，然后直接轮到圈外那句「收工喵」喵。

上一课你在 `switch` 里见过 `break`，那次它的活是「把路封住」。今天在圈里，它的活是「提前散场」——**同一个词，两处都在说「到此为止，别再往下走了」。**

### `continue`：这一圈不干了，直接跳下一圈

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;
        }
        cout << i << endl;
    }
    cout << "跑完喵" << endl;
    return 0;
}
```

```text
1
2
4
5
跑完喵
```

同样是跑到 `i` 是 3 那一圈撞上 `continue`，脾气却完全不同：**`continue` 只是「这一圈剩下的活儿不干了」，圈本身还在跑。** 所以 3 没被印出来，4、5 照常跑完，最后是圈外那句「跑完喵」。

一句话分清它俩：

| 关键词 | 撞上以后会怎样 |
|---|---|
| `break` | 圈**停了**，剩下的圈数全部作废，跳到圈外 |
| `continue` | 圈**没停**，只是这一圈剩下的活儿跳过去，马上开始下一圈 |

两个词多半都和 `if` 搭伙——先问一句眼色，答真才变卦。所以它们总是和「看鱼干眼色行事」一起出现喵。

## 范围 `for` 初识：一整排东西，挨个走一遍

跑圈还有一种特别顺手的形状。本喵先把东西摆成一排：

```cpp
int fish[3] = {3, 5, 2};
```

这一行说的是「摆一排三个猫粮碗，里面分别放着 3、5、2」。**这一排碗本身**（一排贴编号的猫粮碗）是下一课的主角，今天你只要记住**怎么挨个走过它**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish[3] = {3, 5, 2};

    for (int one : fish) {
        cout << "这条是 " << one << " 喵" << endl;
    }
    return 0;
}
```

```text
这条是 3 喵
这条是 5 喵
这条是 2 喵
```

这个形状读作：**「把 `fish` 那一排里的每一样，挨个叫它一声 `one`，然后做下面大括号里的事。」**

它和你刚学的 `for (int i = 0; i < 3; i++)` 差在哪儿？

| 形状 | 你操心什么 |
|---|---|
| `for (int i = 0; i < 3; i++)` | 自己数：起手、眼色、收尾三件家当全得写对 |
| `for (int one : fish)` | 不用数：一排里有几样，它就跑几圈，跑完自己停 |

- **`one` 这个名字随你起**，它只在这对括号里活着。
- **那排东西是空的，圈就一圈都不跑**；有三样就跑三圈 —— 圈数是它自己数出来的，不用你写。
- 三件家当**一件都不用写**，两个分号也不见了 —— 这就是它省事的地方。

::: tip 猫咪提示
今天五次总结，一句话一个：

1. **`for (起手; 眼色; 收尾)`** —— 三件家当挤在一行，**两个分号**隔开；三件各跑各的次数：起手一次、眼色每圈一次、收尾每圈一次。
2. **`while (眼色)`** —— 每圈开场先瞄一眼；圈里必须有一句代码让眼色早晚变假，否则圈停不下来。
3. **`do-while`** —— 先干一圈再问眼色；`while (眼色)` 尾巴上那个分号千万别漏。
4. **`break` 收工、`continue` 跳一圈** —— 两个都常和 `if` 搭伙。
5. **`for (int one : 一排东西)`** —— 不用数圈数，挨个走一遍。
:::

::: warn 小心喵
跑圈最容易摔的三处：

1. **`for` 的三件家当之间写成了逗号。** C++ 只认分号，写成逗号翻译官喵会指着那一行说 `expected ';'`。
2. **`while` 里忘了让眼色变化。** 圈停不下来，只能强行关窗口。
3. **`do-while` 尾巴上漏了分号。** 报错会提到它下面那一行，别被引错方向 —— 往上找 `do` 那一段的收尾。
:::

## 小任务

1. 把第一个 `for` 里的 3 改成 5，数数屏幕上出现几行。
2. 写一段「求 1 到 10 的和」：先备小碗 `int total = 0;`，再跑 `for (int i = 1; i <= 10; i++)`，每一圈把 `i` 加进碗里，最后印出来看看是不是 55。
3. 把 `while` 那段里的 `fish--;` 那一行**先注释掉**（在行首加 `//`），跑之前想清楚会发生什么 —— 想明白了再决定要不要跑（它会停不下来，得强行关窗口喵）。
4. 把 `do-while` 那段的 `int fish = 0;` 改成 `int fish = 5;`，猜猜两边各印几行，再跑一遍对答案。
