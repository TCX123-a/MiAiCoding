## 钩子：一整排碗为什么天生不复印

上一课本喵留了两条尾巴：

1. **一整排碗递进招式，招式改得动外面** —— 本喵只说了「它天生就不复印」，没交代为什么；
2. 那张三条对比表里的另一位主角，本喵说「它下一课正式登场」。

现在把两条并成一条：**因为一整排碗递出去的时候，交的其实不是「一整排碗」，而是「第一只碗摆在哪儿」这句话。**

「碗摆在哪儿」这件事，今天就要被拎出来单独看。它在猫咪世界里叫**猫爪指向牌**，正式名字是**指针（猫爪指向牌）**。

## 一、每只碗都有门牌号

鱼塘边那排碗不是随手扔在地上的：每只碗都摆在架子上一个固定的位置，**都有自己的门牌号**。

平时你只管报名字取碗（写 `fish` 就行），从来不用操心它在哪儿。可要是你想把「**fish 在哪儿**」这件事本身拿在手里，就得先把它**问出来**。问的写法，是在名字前面加一个 `&`：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 5;
    int* p = &fish;

    cout << (p == &fish) << endl;
    cout << *p << endl;

    *p = 99;
    cout << fish << endl;
    return 0;
}
```

```text
1
5
99
```

一行一行看喵：

- **`&fish`** —— 把 `fish` 那只碗的门牌号问出来。
- **`int* p = &fish;`** —— 把门牌号记在一块牌子上，这块牌子叫 `p`。整句念作：「`p` 是一块指向装整数的碗的牌子。」
- **`p == &fish`** 印出 `1` —— 牌子上写的内容，和 `fish` 的门牌号**一模一样**。
- **`*p`** 印出 `5` —— 顺着牌子走到那只碗跟前，看里面装的是几。这一步叫「顺牌子」。
- **`*p = 99;`** —— 顺着牌子**放**东西进去。所以最后印 `fish`，出来是 `99`：**你那只碗真的被改了。**

一句话：**`&` 是问门牌号，`*` 是顺着门牌号走到碗跟前。**

这五行是本课的心脏，本喵把它拆成一格一格给你看喵。「门牌号」和「5」这两个值要分清楚：一个说的是**碗摆在哪儿**，一个说的是**碗里装着什么**。

## 二、牌子的三条脾气

上一课本喵摆过一张三条对比表，说「硬邦邦的那一版」和温柔版有三处不同。今天把答案交给你，一条一条跑给你看。

**第一条：可以先空着，以后再指。** 空牌子写成 `nullptr`，念作「null-ptr」，意思是「谁也没指」：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int* p = nullptr;

    p = &a;
    cout << *p << endl;

    p = &b;
    cout << *p << endl;
    return 0;
}
```

```text
1
2
```

**第二条：想换就换。** 上面这一段里，`p` 先指 `a`、后指 `b`，两次顺牌子拿到的数不一样 —— 牌子上的门牌号被**改写**了。温柔版绑好就是一辈子不换，牌子不这样：`p = &b;` 就是真的改指 `b`（这一点和上一课那句 `r = b;` 正好相反，别记混喵）。

**第三条：用的时候多写一个小记号。** 温柔版用起来跟普通名字一样（直接写 `other`），牌子每次都得写 `*p`。上面那段你已经写了两回。

顺带一个容易摔的：**`*` 只管紧挨着它的那一个名字。**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1, b = 2;
    int *p, q;

    p = &b;
    q = 7;
    cout << a << " " << *p << " " << q << endl;
    return 0;
}
```

```text
1 2 7
```

`int *p, q;` 里**只有 `p` 是牌子**，`q` 是一只普普通通的碗 —— 所以下面能直接写 `q = 7;`。想一次开两块牌子，得老老实实写两遍：`int *p, *q;`。

## 三、仓库不够用？现租一间

到这儿为止，牌子指的都是**已经开好的碗**（`&fish`）。可有时候本喵事先不知道要装几样东西，碗在哪儿开好呢？

派上用场的是「现要现租」：用 `new` **当场租**一块地方出来，租完给你一块指向它的牌子。这种临时租来的地方，叫**现要现租的仓库（动态内存）**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = new int(7);
    *p = *p + 1;
    cout << *p << endl;
    delete p;
    return 0;
}
```

```text
8
```

- **`int* p = new int(7);`** —— 现租一间装整数的屋子，里面先摆个 `7`，把开门的牌子交给 `p`。注意这一句里**没有 `&`**：屋子是新租的，门牌号不用向谁去问。
- **`*p = *p + 1;`** —— 顺着牌子把 `7` 拿出来、加一、放回去。
- **`delete p;`** —— **把租来的屋子还回去。** 借了要还，这是租仓库的规矩。

租一整排也可以：

```cpp
#include <iostream>
using namespace std;

int main() {
    int* box = new int[3];
    box[0] = 3;
    box[1] = 5;
    box[2] = 2;

    for (int i = 0; i < 3; i++) {
        cout << box[i] << endl;
    }
    delete[] box;
    return 0;
}
```

```text
3
5
2
```

`new int[3]` 是「租一排三间」，还的时候写成 `delete[] box;` —— **后面那对方括号别忘了**：租一排、还一排，账才对得上。

::: warn 小心喵
租来的屋子有三条规矩，一条都不能漏：

1. **借了要还。** 用完不 `delete`，那间屋子就一直挂在你名下，程序跑得越久，能用的地方越少。
2. **还了就不能再顺着进去。** `delete p;` 之后再写 `*p = 1;`，等于摸进一间已经退租的屋子 —— 翻译官喵**不会拦你**（那句话语法上一点毛病都没有），可里面住的是谁就说不准了。
3. **没指过任何地方的牌子，绝对不许顺。** 写 `int* p;` 就马上 `*p = 1;`，那扇门后面是什么完全没人知道。本喵把两段都真跑过一遍，翻译官喵**两段都放行** —— 它只念一句 `警告`，拦都没拦：

> `warning: 'p' is used uninitialized [-Wuninitialized]`

顺着它**读**一下（`cout << *p;`），屏幕上印出一个 `0`；顺着它**放**东西（`*p = 1;`），程序**当场就没了**（本机实测：整个进程被系统掐掉，退出码 `139`，屏幕上连一行字都没印出来）。那个 `0` 一点意义都没有，换段程序、换一天，它就是别的什么了。**这才是最坏的地方 —— 它拦得那么轻，你事后根本不知道是哪一行把程序送走的。那不是「能用」，那是运气。**
:::

## 四、牌子与一排碗

现在回到开头那个谜。

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish[3] = {3, 5, 2};
    int* p = fish;

    cout << *p << endl;
    cout << *(p + 1) << endl;
    cout << p[2] << endl;
    return 0;
}
```

```text
3
5
2
```

盯住 `int* p = fish;` 这一句 —— **右边那一排碗的名字，自己就充当了门牌号**，而且充当的正是**第一只碗**的门牌号。于是：

- **`*p`** —— 第一格，也就是 `3`。
- **`*(p + 1)`** —— 顺着牌子往前走一格，第二格。
- **`p[2]`** —— 第三格。牌子也能用方括号，`p[2]` 和 `fish[2]` 拿到的是同一格。

上一课那条「一整排碗天生不复印」，到这儿就彻底拆开了：**整排碗递出去的时候，交出去的是第一只碗的门牌号。** 招式里拿着这块牌子，当然改得动你本人的碗。不是 C++ 在照顾你，是它把门牌号交了出去。

（还有一件顺手要记住的：**牌子只装得下一个门牌号**，它只记得「这一排从哪儿开始」。这一排有几格，它不知道 —— 得你自己记着。这跟上一课那句「那排碗有几格，没人能帮你问」是同一件事喵。）

### 招式接牌子

上一课的 `addOne` 走的是温柔版，今天给它配一个牌子版的兄弟，放在一起对答案：

```cpp
#include <iostream>
using namespace std;

void addOneRef(int& n) {
    n = n + 1;
}

void addOnePtr(int* p) {
    *p = *p + 1;
}

int main() {
    int a = 3;
    int b = 3;

    addOneRef(a);
    addOnePtr(&b);

    cout << a << endl;
    cout << b << endl;
    return 0;
}
```

```text
4
4
```

两招干的是同一件事，喊起来也长得像 —— **区别只在料那一头**：一个写 `int& n`，一个写 `int* p`；而且牌子版喊的时候得自己把门牌号递过去（`addOnePtr(&b)`）。忘了那个 `&` 会怎样？第五节的摔法二就是它。

对答案的时间到了。把上一课那张表补齐最后一行：

| | 温柔版（`int& n`） | 猫爪指向牌（`int* p`） |
|---|---|---|
| 开张的时候 | 必须当场绑好，不能先空着 | 可以先空着（`nullptr`），以后再指 |
| 绑好之后 | 一辈子不换 | 想换就换 |
| 用的时候 | 跟普通名字一样，直接写 `n` | 每次多写一个小记号：`*p` |
| 喊它的时候 | 直接递名字：`addOneRef(a)` | 递门牌号：`addOnePtr(&b)` |

## 五、三个最容易摔的地方

**摔法一：把普通的碗当牌子顺。**

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 5;
    cout << *fish << endl;
    return 0;
}
```

```text
main.cpp:6:13: error: invalid type argument of unary '*' (have 'int')
```

顺着走的前提是**它得是块牌子**。`fish` 是一只装整数的碗，`*fish` 等于拿着一个数字去敲门。翻译官喵这句话的意思是：「**这颗星用错地方了** —— 你给本喵的是个 `int`，不是牌子。」

**摔法二：忘了问门牌号。**

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 5;
    int* p = fish;
    cout << *p << endl;
    return 0;
}
```

```text
main.cpp:6:14: error: invalid conversion from 'int' to 'int*' [-fpermissive]
main.cpp:6:14: note: possible fix: take the address with '&'
```

左手要的是门牌号，右手给的是一只碗里的数（`5`），两边对不上 —— `invalid conversion from 'int' to 'int*'` 就是「从『一个整数』换不成『一块牌子』」。

这一回翻译官喵格外贴心：**改法它直接写在下面那一行了** —— `possible fix: take the address with '&'`，意思是「补个 `&` 取门牌号试试」。看到这两行，就去那只碗前面加一个 `&` 喵。

**摔法三：跟一个孤零零的数字要门牌号。**

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = &5;
    cout << *p << endl;
    return 0;
}
```

```text
main.cpp:5:15: error: lvalue required as unary '&' operand
```

门牌号只有**碗**才有。`5` 是个孤零零的数字，没摆在架子上，哪来的门牌号？`lvalue required` 的意思就是「**这里得放一只碗**」。

## 小抄表

| 写法 | 念作 | 干什么 |
|---|---|---|
| `&fish` | 问门牌号 | 问出来那只碗摆在哪儿 |
| `int* p = &fish;` | 招牌子、记门牌号 | `p` 指向 `fish` 那只碗 |
| `*p` | 顺牌子 | 看那只碗里装的是几 |
| `*p = 99;` | 顺着放东西 | 把 `99` 放进那只碗（原件真的变） |
| `int* p = nullptr;` | 先空着 | 谁也没指，以后再指 |
| `new int(7)` | 现租一间 | 租一间装整数的屋子，里面先摆 `7` |
| `new int[3]` | 现租一排 | 租一排三间 |
| `delete p;` / `delete[] p;` | 退租 | 租一间还一间、租一排还一排 |
| `int* p = fish;` | 一排碗的名字当门牌号 | 指的就是第一只碗 |

::: tip 猫咪提示
本课六次总结，一句话一个：

1. **`&` 问门牌号，`*` 顺牌子** —— 一个记号两副面孔，看它站在哪边。
2. **招牌子要写清楚它指的是什么碗** —— `int* p` 是「指向装整数的碗的牌子」。
3. **牌子可以先空着（`nullptr`）、可以改指、每次用都得写 `*`** —— 这三条正好和温柔版相反。
4. **`new` 是现租、`delete` 是退租** —— 租一排要写 `delete[]`。
5. **一排碗的名字就是第一只碗的门牌号** —— 这就是它「天生不复印」的全部秘密。
6. **借了要还；还了不许再顺着进去；没指过的牌子不许顺。**
:::

::: warn 小心喵
这一课最贵的三条，一条一条记牢：

1. **野牌子不许顺。** 它**只警告、不拦** —— 顺着读给你一个假 `0`，顺着写当场把程序送走。正因为拦得这么轻，才最坏。
2. **`delete` 之后牌子上的门牌号还在**，可那间屋子已经还回去了。
3. **`*` 只管紧挨着它的那一个名字** —— `int *p, q;` 里 `q` 是普通的碗。
:::
