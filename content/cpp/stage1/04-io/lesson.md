## 钩子：只会念稿的点单机

本喵的点单机修好了，可它只有**一张嘴**：你让它念「你好，喵！」它念得很溜，可大肥鱼站在它面前报了名字，它一句都不理。

「它听不见。」大肥鱼说，「只会念稿，不会听话。」

本喵今天就要给它装上一只**耳朵**。在「投喂与叼回」那一课你已经见过这个道理了：程序跟外面打交道靠两个方向的口子——**投喂**（东西从外面进来）和**叼回**（东西送出去给你看）。C++ 给这两个口子各准备了一根管子：

- **`cout`**：往外的出水管，管把东西**塞出去**；
- **`cin`**：往里的进水管，管从外面**叼回来**。

上一课你已经把管子往外塞过好几回了，今天本喵把另一根接上喵。

## 先复习一句：`cout` 很老实，不会替你垫空格

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "你好" << "小橘" << endl;
    cout << "你好" << " " << "小橘" << endl;
    return 0;
}
```

```text
你好小橘
你好 小橘
```

两行只差中间那一件货：第一行塞的是两截字，紧贴着出来了；第二行本喵多塞了一件 `" "`——**一对引号里夹着一个空格**，于是中间空出一格。

再记一遍这条脾气：**管子塞什么念什么，缝要留多宽，得你自己写进引号里**喵。

顺着这个脾气，把一件件货塞成一句完整的话就很简单了：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "小橘";
    int fish = 3;
    cout << name << " 今天吃了 " << fish << " 条小鱼干" << endl;
    return 0;
}
```

```text
小橘 今天吃了 3 条小鱼干
```

留神那两种货是怎么排排坐的：一串字、一个整数、又一串字，全都往同一根管子里塞，它按顺序念出来。**整数不用你操心格式**——你上一课给它挂了 `int` 的牌子，它自己知道该怎么念。

## 「流」是什么：两根管子里的水

本喵说的「管子」，正式名字叫**流**（英文 stream）。这个名字取得挺贴切：数据像水一样，**一样样顺着管子流过去**。

```text
你敲键盘 ——投喂——→  【cin 进水管】  →  程序  →  【cout 出水管】 ——叼回——→  屏幕
```

流有个好处：**它是「一样接一样」的**。你不用提前说「这次要送三样东西」，接着塞、接着叼就行，管子里顺次排着队。C++ 里这两根管子还有个共同点：**管子两边接的是什么，牌子上一看就知道**——上一课学的那些货牌，在这里就派上大用场了喵。

## `cin`：把耳朵接上

给程序装耳朵，喊的是 `cin`（念作「C-in」，in 就是「进来」）。它的箭头和 `cout` 正好相反：**`>>` 是往回流**，把外面的东西叼进屋。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    if (!(cin >> a >> b)) {
        a = "小橘";
        b = "喵";
    }
    cout << "第一口叼到：" << a << endl;
    cout << "第二口叼到：" << b << endl;
    return 0;
}
```

```text
第一口叼到：小橘
第二口叼到：喵
```

本喵往投喂口里填的是 `小橘 喵` 这一行，它却叼回来**两口**——这就是 `cin >>` 的第一个脾气：

> **`cin >>` 遇到空格就停下。**

它读的是「一样东西」，不是「一整行」。中间那个空格就是它的**停止线**：第一口叼到空格前头的 `小橘`，第二口再从停止线后头接着叼 `喵`。所以两个连着的 `>>` 要你喂两样东西，从前往后一样样分。

::: warn 小心喵
上面那段代码里，本喵多写了几行你还没学过的东西。本喵把它单挑出来给你看：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    if (!(cin >> a >> b)) {
        a = "小橘";
        b = "喵";
    }
    cout << a << b << endl;
    return 0;
}
```

这是本喵给课文里每一段**要听话的稿子**系的一条**保险绳**，本喵给你解释：

- `cin >> a >> b` 是「从管子里叼两口货」。**管子里空空的时候它叼不到东西**，会摆出一张「没读到」的脸色。
- `if (!(cin >> a >> b))` 读作：「**先叼一口试试；脸色不对的话**……」
- 大括号里那两行是备用方案：本喵提前备好一份货（`小橘`、`喵`），叼不到就用它顶上。

系上这条绳子，这段代码**有没有人喂都能平平安安跑完**。至于「看脸色分岔」这套本事，等讲到「看鱼干眼色行事」那一课本喵再细说，今天照着抄就行喵。

反过来说：**你自己写的时候不必系它**。在练习场里先把投喂口填好，直接写 `cin >> a;` 也是好的。
:::

### 练习场里的投喂口在哪儿

打开「**▶️ 运行代码**」那一页，工具栏上有一个框，上面写着「**程序要你输入什么吗？（不需要就留空）**」——那个框就是投喂口。要喂的东西写在里面，点运行，程序里的 `cin` 就会把那一行叼走。

它要几口，你就喂几样；一口都不喂，本喵的保险绳会替你顶上。程序跑到投喂口会**停下来等你**——屏幕上半天没动静，不是坏了，它是在等你喵。

### 读数字：牌子写好了，它自己会认

`cin` 有一件比别家省心的事：**它知道你要读的是数字，不用你动手转换**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    if (!(cin >> a >> b)) {
        a = 3;
        b = 5;
    }
    cout << a << " + " << b << " = " << a + b << endl;
    return 0;
}
```

```text
3 + 5 = 8
```

本喵往投喂口里填的是 `3 5` 两样，它直接叼进两间 `int` 屋，还当场把加法算了出来。

这就是 C++ 把活儿揽过去的地方：**牌子（`int a, b;`）已经说清了屋里装的是整数，`cin` 照牌子收货**。你在一串字那一门语言里学过的「先摘数字再算」那一步，这里不用做喵。

## `getline`：叼一整行

要是想连名字里的空格一起叼走呢？上面那个脾气就不够用了。换一件工具：`getline`。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string line;
    if (!getline(cin, line)) {
        line = "小橘 喵";
    }
    cout << "整行叼到：" << line << endl;
    return 0;
}
```

```text
整行叼到：小橘 喵
```

一样是 `小橘 喵`，这回它**整行都叼走了**，中间的空格原样保留。

`getline` 和 `cin >>` 的分工记住这一句就够：

| 工具 | 叼什么 |
|---|---|
| `cin >>` | 一样东西，**遇空格就停** |
| `getline(cin, ...)` | **一整行**，一直叼到换行 |

## 两个一起用：一个不吭声的坑

现在把两件工具凑到一段稿子里，来看一个**不报错**的坑。本喵的投喂口里填的是两行：第一行 `7`，第二行 `大肥鱼`：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int fish;
    string name;
    if (!(cin >> fish)) {
        fish = 7;
    }
    getline(cin, name);
    if (name.empty()) {
        name = "（空空的）";
    }
    cout << "小鱼干 " << fish << " 条" << endl;
    cout << "名字是 " << name << endl;
    return 0;
}
```

```text
小鱼干 7 条
名字是 （空空的）
```

数量叼对了，名字却是空空的——**本喵明明喂了「大肥鱼」啊**。

问题出在管子里那点没人要的**残渣**：

1. `cin >> fish` 只认「一样东西」，它在读到 `7` 后面的那个**换行**时就停下来了；
2. 可它**没把那个换行拿走**——换行还留在管子里；
3. `getline` 一开口，先叼到的东西正是那个换行。**它确实叼到了「一整行」，只不过这一行是空的**，所以 `name` 里什么都没有；
4. 而 `大肥鱼` 还排在管子后面，压根没轮到它。

这四步是**怎么一步一步走**的，本喵拆开演给你看 —— 投喂口里填的是两行：`7`，下一行 `大肥鱼`：

管子里剩下的那点**残渣**看不见，可它一步一步都在那儿 —— 混着用的时候垫一句 `cin.ignore();`，丢掉的正是那个换行；丢完再开口，`getline` 叼到的才是真正的第二行（课文里那份「正常」的版本，加的就是这一句）。

想让它正常，得把管子里那点残渣**先吃掉**：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int fish;
    string name;
    if (!(cin >> fish)) {
        fish = 7;
    }
    cin.ignore();
    if (!getline(cin, name)) {
        name = "大肥鱼";
    }
    cout << "小鱼干 " << fish << " 条" << endl;
    cout << "名字是 " << name << endl;
    return 0;
}
```

```text
小鱼干 7 条
名字是 大肥鱼
```

多出来的那一行 `cin.ignore();` 就是「**把管子里剩着的那一个字符丢掉**」——丢掉的正是那个捣乱的换行。丢完再开口，`getline` 叼到的就是真正的第二行。

::: tip 猫咪提示
这个坑最坏的地方是：**它不报错**。屏幕上照样出字，数量还是对的，你要是没留意那个空名字，程序会一路带着错跑下去。

记住这条口令：**`cin >>` 和 `getline` 混着用的时候，中间垫一句 `cin.ignore();`**。它俩分工不同——一个只认「一样东西」、还把换行留在管子里，一个专吃「一整行」。本喵往后写这种一问一答的稿子，都会顺手垫上它喵。
:::

::: tip 猫咪提示
「投喂与叼回」这一课，记住四句话就够用啦：

1. **`cout`** 是出水管：`<<` 塞一样、念一样，缝要自己写进引号里，换行用 `endl`；
2. **`cin`** 是进水管：`>>` 往回流，遇空格就停，读数字不用你转换；
3. **`getline`** 叼一整行，一直叼到换行；
4. **两个混用要垫 `cin.ignore();`**，把留在管子里的残渣吃掉。

还有一句要紧的：程序跑到投喂口会**停下来等你**——这不是卡住了喵。
:::
