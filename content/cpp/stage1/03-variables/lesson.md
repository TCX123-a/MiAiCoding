## 钩子：大肥鱼的账本

大肥鱼游到窗口：「本喵今天喂了本喵几条小鱼干？」

本喵张口就愣住了——喂过，可喂了几条？想不起来。本喵只好把每一条货都记在一张纸上，可纸一会儿就找不到了，数字还越写越乱。

「你得给每条货**盖一间小屋**。」大肥鱼甩甩尾巴，「门上挂块牌子写名字，屋里装着货。本喵想用的时候，喊一声牌子上的名字，它就自己开门把货递出来。」

于是本喵动手盖屋。这一课要盖的，就是这些装数据的小屋喵。

## 第一间屋：先说清装什么，再挂牌子

```cpp
int fish = 3;
```

这一行里三样东西，各干各的活：

- **`int`** 是第一块牌子要报的东西——**这间屋装什么货**。`int` 说的是「装整数」；
- **`fish`** 是屋子的**名字**，挂门上用的；
- **`3`** 是真正放进屋里的**货**。

中间那个 `=` 不是数学里的等号，本喵下面单独讲它。末尾的分号还是那句老规矩：**一句说完要打句号**。

跑一下看看，本喵喊一声 `fish`，它就把货递出来：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    cout << fish << endl;
    return 0;
}
```

```text
3
```

这一套「先说装什么、再起名字」的规矩，你在 C 那边已经学过一遍了，**一个字都不用重学**。真正的差别在于：C++ 给你准备的货牌，比 C 那边多、也比 C 那边省心喵。

## 五张常用的货牌

本喵一口气盖五间屋，每间装的东西都不一样：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int fish = 3;
    double price = 2.5;
    char grade = 'A';
    bool hungry = true;
    string name = "大肥鱼";

    cout << fish << endl;
    cout << price << endl;
    cout << grade << endl;
    cout << hungry << endl;
    cout << name << endl;
    return 0;
}
```

```text
3
2.5
A
1
大肥鱼
```

一行行对过去喵：

- **`int`**：装整数，`3`。
- **`double`**：装小数，`2.5`。C++ 里小数默认用 `double` 这张牌——它装得下更多位小数，比 C 那边常用的那张牌容量大一倍。
- **`char`**：装**单个字符**，`'A'`。门牌上要留神：它用的是**单引号**，而且是**一个**字符，多一个都不行。
- **`bool`**：只会点头摇头的屋，装「真」或「假」。它印出来是 `1`——这一条下面本喵单独说，它是 C++ 的一个小脾气。
- **`string`**：装一串字，`"大肥鱼"`。**这是 C++ 给的那条会自己长大的项链**（上一课见过），它比 C 那边省心得多：你不用提前数「这串字最多几个」，它自己会撑大。

### `bool` 只会点头摇头：印出来是 1 和 0

`bool` 是一个只会说「真」和「假」的屋。C++ 里这两个值写成 `true` 和 `false`，**全是小写**——别写成大写开头的样子，那在 C++ 里不是那个意思，翻的时候就报错。

那它印出来是什么样？上面那段里 `hungry` 装的是「真」，屏幕上是 `1`。要是装「假」，印出来就是 `0`。

记住这个脾气：**C++ 把「真」当 1 印、「假」当 0 印**。所以往后你看到屏幕上冒出来一个孤零零的 `1`，先想想是不是哪间 `bool` 屋被念出来了喵。

### 门口那个 `=`：是搬运，不是等号

再看一眼那段的第一行：`int fish = 3;`——这行里的 `=`，读法应该是「**把右边的货搬进左边这间屋**」，**不是**数学课上那个「左右一样大」的等号。

这句话不是本喵啰嗦，是因为下面这种事在数学里根本不成立，在 C++ 里却天经地义：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish;
    fish = 3;
    fish = fish + 1;
    cout << fish << endl;
    return 0;
}
```

```text
4
```

一行行读：先盖屋挂牌（`int fish;`），再把 3 条搬进去（`fish = 3;`），最后那句是「**把屋里现有的货拿出来、加一条、再搬回去**」——所以屋里从 3 变成了 4。

右边那句 `fish + 1` 里的 `fish`，读的是**屋里现在装着的东西**；算完的结果再原样搬回同一间屋。数学里的 `fish = fish + 1` 是胡说八道，这里的 `=` 是**动作**，不是**相等**喵。

## 名字怎么起

牌子上的名字不能乱写，C++ 有三条规矩：

1. 只能用**字母、数字、下划线**这三样拼；
2. **不能拿数字开头**——`fish1` 行，`1fish` 不行；
3. 不能跟别人已经占用的名字撞车，比如 `int`、`cout`、`main` 这些。

撞上第二条的时候，翻译官喵的话是这样的：

```cpp
#include <iostream>
using namespace std;

int main() {
    int 3fish = 3;
    cout << 3fish << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:5:9: error: expected unqualified-id before numeric constant
```

`expected unqualified-id before numeric constant` 这句话不好读，本喵替你翻：**「名字的位置上，本喵看到一个数字，这不是个能用的名字。」**它卡在第 5 行的第 9 个字符——正是 `3` 所在的地方。

还有一条不成文的小规矩：**大小写不一样就是两间屋**。`fish`、`Fish`、`FISH` 在 C++ 眼里是三间不同的屋。本喵的建议是起名一律用小写字母加下划线（像 `max_fish` 这样），省得回头自己认错喵。

## 贴了封条的屋：`const`

有些货装进去就不该再动了，比如「碗最多能装十条鱼」这件事。你可以给这间屋**贴一道封条**：

```cpp
const int maxFish = 10;
```

开头的 `const` 就是那张封条，意思是「**这屋的货，装好就不许再换了**」。谁要是想再搬一次：

```cpp
#include <iostream>
using namespace std;

int main() {
    const int maxFish = 10;
    maxFish = 20;
    cout << maxFish << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:6:13: error: assignment of read-only variable 'maxFish'
```

`read-only` 就是「**只读**」：能看，不能改。翻译官喵连是哪间屋都点名了——`'maxFish'`。

这道封条很有用：万一本喵哪天手滑写了个 `maxFish = 20`，它会当场拦住，而不是让程序跑到一半按错的数算下去。

## 货装错了：翻译官喵的原话

最后这个坑，是 C++ 比 C 更较真的地方。本喵拿装整数的屋去装一串字：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    fish = "三条小鱼干";
    cout << fish << endl;
    return 0;
}
```

```text
main.cpp: In function 'int main()':
main.cpp:6:12: error: invalid conversion from 'const char*' to 'int' [-fpermissive]
```

`invalid conversion` 是「**这个转换不成立**」。牌子上写的是装整数，你塞进去的是一串字，它直接拦下来，不给你「先跑起来再说」的机会。

::: tip 猫咪提示
今天记住五间屋和两条规矩：

1. **五张货牌**：`int` 装整数、`double` 装小数、`char` 装单个字符（单引号）、`bool` 装真/假（印出来是 1 和 0）、`string` 装一串字（会自己长大）；
2. **`=` 是搬运**：把右边的货搬进左边那间屋，不是数学的等号；
3. **名字**：字母、数字、下划线，不能拿数字开头，大小写算两回事；
4. **`const`** 是封条：贴上了就不许再搬货。

还有一句最要紧的：**盖了屋就先装货**。空屋的事本喵下面就说喵。
:::

::: warn 小心喵
**一间没装货的屋，里面到底有什么？** 本喵真跑过一次：盖好屋、不装货、直接念出来：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish;
    cout << fish << endl;
    return 0;
}
```

屏幕上冒出来一个莫名其妙的数字。本喵先后跑过两次：一次是 `32759`，一次是 `32758`——**连它自己都拿不准**。

不过翻译官喵这次**会**提醒你一句，原话是 `warning: 'fish' is used uninitialized [-Wuninitialized]`。注意它只是**警告**：编译照样过，程序照样跑，照样印出那个莫名其妙的数字。所以「它说话了」不等于「它替你拦住了」—— 这条警告你**自己**得当真喵。

所以请千万记住：**这个数字不是规矩，是运气**——换台电脑、换个位置，它就变了，没有任何道理可讲。

所以别去记这个数，记住它的教训就够：**开屋之后第一件事就是装货**。要是一间屋你打算拿到手就先放着、晚点再装，那也行——但**在装货之前，千万别去念它**喵。
:::
