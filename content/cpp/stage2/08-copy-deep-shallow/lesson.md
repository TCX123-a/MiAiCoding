## 钩子：盒子里的东西不在盒子里

本喵画了一只 `FishBox`（小鱼干盒子）。到这一课为止，本喵画过的盒子，格子都是**长在盒子里**的 —— 放一个数进去，数就在那只盒子里。

可本喵第一阶段教过另一种做法：仓库不够用时，可以**现要现租一间**（`new`），手里只留一张写着地址的牌子（`int* p`）。盒子里的那一格从此装的**不是小鱼干，而是一张牌子**。

所有麻烦都是从这里开始的喵。今天这一课要讲清楚：**当盒子里装的是牌子，照抄一只盒子会发生什么。**

## 一、会租仓库的盒子

先看一只规规矩矩的盒子，从头到尾：

```cpp
#include <iostream>
using namespace std;

class FishBox {
    int* p;
public:
    FishBox(int v) {
        p = new int(v);
        cout << "租下一格仓库，放进 " << *p << " 条" << endl;
    }
    ~FishBox() {
        cout << "归还这一格仓库" << endl;
        delete p;
    }
    int get() const { return *p; }
    void set(int v) { *p = v; }
};

int main() {
    FishBox a(3);
    cout << "a 这一格是 " << a.get() << " 条" << endl;
    return 0;
}
```

```text
租下一格仓库，放进 3 条
a 这一格是 3 条
归还这一格仓库
```

- **出生招式里干的活是「租」**：`p = new int(v);` —— 先租下一间只能装一个整数的仓库，把 `v` 放进去，再把地址记在 `p` 那一格里。
- **收尾招式里干的活是「还」**：`delete p;` —— 盒子要走的最后一刻，把它租过的那间仓库交回去。
- **一租一还，配成一对。** 这是本喵第一阶段讲「现要现租的仓库」时定下的规矩：**谁租的谁还，租一次还一次。**

这段代码跑得干干净净。问题出在下一步。

## 二、`FishBox b = a;` 这一句，翻译官喵偷偷替本喵干了什么

现在本喵照抄一只：

```text
FishBox a(3);
FishBox b = a;        // 照抄一只
b.set(99);            // 只改 b
cout << a.get() << endl;   // a 会变成几？
```

本喵原来以为：`b` 是 `a` 的复印件，改 `b` 跟 `a` 没关系。

**错了。** 本喵在本机真跑过这一段：**两行都印出了 99。** 本喵只改了 `b`，`a` 跟着一起变了。

原因是这样的：本喵**没有**给这张图纸写「照抄的时候该怎么做」，翻译官喵不会干等着 —— 它会**偷偷替本喵补一份照抄招式**。而它补出来的那一份，做的是最直白的事：

> **把对方那一格里的东西，原样抄进本喵这一格里。**

盒子里的那一格装的是什么？**是牌子的地址。** 所以照抄出来的 `b`，拿到的是**同一间仓库的地址** —— 两只盒子里装的是**两张写着同一个门牌号的牌子**。`b.set(99)` 改的是那间屋里的东西，`a` 拿着同一张牌子，当然也看到了 99。

### 更凶的还在后面：收尾的时候撞车

本喵接着往下跑，程序在最后那一刻**当场倒下**了。

本机实测的样子是：两行输出**照印不误**，然后进程直接断气 —— **退出码 `3221226356`**（Windows 记的是「堆损坏」），而且**一个字都没留给本喵**。

为什么？**两只盒子在收尾的时候，都去归还同一间仓库。** 第一只盒子把仓库交回去，第二只盒子拿着早就交掉的牌子，又去交了一遍 —— 翻译官喵当场就翻了脸。

**这一课最该记住的就是这件事：这个坑不会给你报错。** 程序前半段跑得好好的，输出也全对，然后在你说不定已经离开电脑的时候才倒下。你要是哪天撞上「程序跑着挺好，一结束就崩」，回来翻翻这一课喵。

## 三、深拷贝：本喵自己写一份照抄招式

翻译官喵补的那一份太直白了，本喵要自己写一份**聪明点的**：照抄的时候，**别抄牌子，另租一间、把里面的东西搬过去**。

```cpp
#include <iostream>
using namespace std;

class FishBox {
    int* p;
public:
    FishBox(int v) { p = new int(v); }

    FishBox(const FishBox& other) {
        p = new int(*other.p);
    }

    ~FishBox() { delete p; }

    int get() const { return *p; }
    void set(int v) { *p = v; }
};

int main() {
    FishBox a(3);
    FishBox b = a;
    b.set(99);
    cout << "a 那一格现在是 " << a.get() << " 条" << endl;
    cout << "b 那一格现在是 " << b.get() << " 条" << endl;
    return 0;
}
```

```text
a 那一格现在是 3 条
b 那一格现在是 99 条
```

这一回改 `b` 跟 `a` 没关系了 —— **两只盒子各有一间自己的仓库**。这个「另租一间、把内容搬过去」的做法，本喵叫它**深拷贝**；翻译官喵原来补的那种「只抄牌子」的叫**浅拷贝**。

本喵一行一行拆这份照抄招式：

- **`FishBox(const FishBox& other)`** —— 招式名和图纸**同名**，这就是「照抄招式」的身份标志。塞进来的料是**另一只同款盒子**。
- **那个 `&` 是「不必还的名字」，不能省。** 它说的是「本喵只是借看一下对方这只盒子，不要为它再造一只」。**这一条是死规矩** —— 为什么，下一节本喵用真实报错告诉你。
- **`const` 放在最前面**：本喵只读对方，不改它。照抄本来就不该把原件改样。
- **`p = new int(*other.p);` 这一句是全课的精华**：右边的 `other.p` 是对方那间仓库的地址，`*other.p` 是**那间屋里装的东西**（3），`new int(3)` 是**本喵自己另租一间、把 3 放进去**。租好之后地址记进本喵自己的 `p` 一格。
  - 请注意 `new` 这个字**一个都不能少**：写成 `p = other.p;` 就又变回浅拷贝了喵。
- **两只盒子各还各的**：`a` 还它自己租的那间，`b` 还它自己租的那间，谁也不撞谁。

## 四、`=` 那一手也得本喵自己管

还有一只漏网的：**两只盒子都已经生出来了**，本喵想把一只的内容放进另一只：

```cpp
FishBox a(3);
FishBox b(7);
b = a;              // 这一句走的是「赋值」，不是照抄招式
```

这一句**不会**去叫照抄招式 —— 因为 `b` 早就生出来了，本喵不是要造新盒子，是要**把 `a` 的内容放进 `b` 已有的那间仓库里**。翻译官喵同样会偷偷给一份直白的，而那份直白的做的事还是「抄牌子」，同样会撞车。

所以这一步也得自己写：

```cpp
#include <iostream>
using namespace std;

class FishBox {
    int* p;
public:
    FishBox(int v) { p = new int(v); }
    FishBox(const FishBox& other) { p = new int(*other.p); }
    ~FishBox() { delete p; }

    FishBox& operator=(const FishBox& other) {
        *p = *other.p;
        return *this;
    }

    int get() const { return *p; }
    void set(int v) { *p = v; }
};

int main() {
    FishBox a(3);
    FishBox b(7);
    b = a;
    a.set(50);
    cout << "a 那一格现在是 " << a.get() << " 条" << endl;
    cout << "b 那一格现在是 " << b.get() << " 条" << endl;
    return 0;
}
```

```text
a 那一格现在是 50 条
b 那一格现在是 3 条
```

- **`FishBox& operator=(const FishBox& other)`** —— 上一课的定制符号又上场了：`=` 也是能定制的一手。左边是本喵自己、右边塞进 `other`，和 `operator+` 一个路子。
- **`*p = *other.p;` 搬运的是「内容」，不是牌子。** `b` 那间仓库早就租好了，本喵直接把 3 搬进去覆盖掉原来的 7 —— 所以 `b` 变成 3。
- ⚠️ **这里千万不能写 `p = new int(*other.p);`** —— 那样会**另租一间新的**，原来那间旧仓库的地址被覆盖掉，**再也没人还它了**（漏了一间屋）。**照抄招式要新租，赋值不用新租，这是两者最大的区别喵。**
- **`return *this;`** 把本喵自己叼回去，好让 `b = a = c;` 这种连着一路写。行尾那个 `&` 说的也是同一件事：叼回去的是本喵自己，不是复印件。
- 改 `a` 不影响 `b`：`a.set(50)` 之后 `b` 还是 3，因为两只盒子各有各的仓库喵。

### 照抄招式 vs 赋值：一张表分清楚

| | 照抄招式 | 赋值那一手 |
|---|---|---|
| 什么时候被叫起来 | **造一只新盒子**的时候（`FishBox b = a;`） | **两只都已经活着**的时候（`b = a;`） |
| 要不要新租仓库 | **要**，因为本喵还没有仓库 | **不要**，仓库早就租好了，搬内容就行 |
| 里面那一句长什么样 | `p = new int(*other.p);` | `*p = *other.p;` |
| 行尾要不要 `&` 和 `return *this;` | 不用 | 要 |

**记住一条就够了：只要盒子里装着「现要现租的仓库」，这两手都得本喵自己写。** 写了照抄招式不写赋值，`b = a;` 照样会撞车；两样都写，才算把盒子管好了喵。

## 五、本喵摔的这一跤：照抄招式的料漏了「不必还的名字」

```cpp
#include <iostream>
using namespace std;

class FishBox {
    int* p;
public:
    FishBox(int v) { p = new int(v); }

    FishBox(const FishBox other) {
        p = new int(*other.p);
    }

    ~FishBox() { delete p; }
    int get() const { return *p; }
};

int main() {
    FishBox a(3);
    FishBox b = a;
    cout << b.get() << endl;
    return 0;
}
```

```text
main.cpp:9:5: error: invalid constructor; you probably meant 'FishBox (const FishBox&)'
```

念作：「**这个照抄招式写坏了；你大概想要的是 `FishBox (const FishBox&)` 喵。**」

**报错里那句「你大概想要的」就是正确答案** —— 翻译官喵把本喵漏掉的那个 `&` 直接补给它看了。为什么非有不可？想一想：照抄招式塞进来的料是**按值**的，那翻译官喵就得**先替本喵造一份这个料的复印件** —— 而造复印件又要叫一次照抄招式……**没完没了。** 所以它干脆在翻译阶段就把这事拦下来。**这是一条不需要记的死规矩，翻译官喵替你守着。**

::: tip 猫咪提示
今天记住六句话：

1. **盒子里装着「现要现租的仓库」时，照抄和赋值都会出大事** —— 因为抄的是牌子，不是仓库。
2. **翻译官喵偷偷补的那份只会「抄牌子」**（浅拷贝），结果两只盒子共用一个仓库：改一只、另一只跟着变。
3. **更凶的一半是收尾撞车**：两只盒子归还同一间仓库，程序结束时倒下，**而且一个字报错都不给你**。
4. **照抄招式的写法**：`FishBox(const FishBox& other)` —— 名字和图纸同名，料是另一只同款盒子、带 `&` 和 `const`，里面 `new` 一间新的（深拷贝）。
5. **赋值的写法**：`FishBox& operator=(const FishBox& other)` —— 料同样带 `&`，里面**只搬内容、不新租**，最后 `return *this;`。
6. **两手都得自己写**，缺一个都留着撞车。
:::

::: warn 小心喵
- **漏了 `new` 就等于白写。** `p = other.p;` 看着挺像那么回事，可它抄的还是牌子 —— 深拷贝和浅拷贝的差别就在这一个 `new` 上。
- **赋值那一手千万别新租仓库**：`p = new int(...)` 会把旧仓库的地址冲掉，那间屋再也没人还了。
- **喊招式的时候也会偷偷照抄。** 本喵写 `void show(FishBox b)` 这种塞料按值的招式，每喊一次就要照抄一只盒子！**只想看看、不想抄一份的时候，料的写法要换成「不必还的名字」**：`void show(const FishBox& b)`。这一条和第二、三节讲的是同一件事，只是它藏在你不注意的地方喵。
- **自己给自己赋值（`a = a;`）在本课这种写法下是安全的**（`*p = *other.p` 里两边本来就是同一格，抄自己不会坏）。但要是哪天的赋值招式里写了「先还掉再租」，那种写法就必须先判一下「是不是同一只」，否则一交回去就没了。
:::

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `FishBox(int v) { p = new int(v); }` | 出生招式：**租**下一间仓库 |
| `~FishBox() { delete p; }` | 收尾招式：**还**掉自己租的那间 |
| `FishBox b = a;` | 照抄一只 —— 叫的是**照抄招式**，不是赋值 |
| `FishBox(const FishBox& other) { p = new int(*other.p); }` | 自己写的照抄招式（**深拷贝**）：另租一间、把内容搬过去 |
| 翻译官喵偷偷补的那一份 | 只抄牌子（**浅拷贝**）—— 两只盒子共用一个仓库 |
| `b.set(99);`（浅拷贝下） | 改的是**共用的那间仓库**，所以两只盒子一起变 |
| `FishBox& operator=(const FishBox& other) { *p = *other.p; return *this; }` | 赋值那一手：**只搬内容、不新租** |
| `error: invalid constructor` | 照抄招式的料漏了那个 `&`，翻译官喵连正确写法都替你写出来了 |
