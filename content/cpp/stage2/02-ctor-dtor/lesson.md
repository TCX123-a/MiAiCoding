## 钩子：刚出生的猫，格子里还空着

上一课本喵画好了 `Cat` 这张图纸，照它生出来的猫自带一格名字、一格鱼干数。可上一课末尾本喵留了一句话没解决：**刚生出来的猫，名字那一格是空的，装数的格子更是「谁也没说」。**

于是本喵只能这么养猫：

```text
Cat c1;
c1.name = "小橘";
c1.fish = 3;
Cat c2;
c2.name = "狸花";
c2.fish = 1;
```

两只猫还凑合。可要是三十只呢？每生一只，本喵都得弯下腰往两格里塞东西；**漏塞一格，那只猫就带着一个说不准的数到处跑**（上一课说过：没人放过东西的格子不要读，读出来是什么全看运气）。

猫咪世界里当然有省事的办法：**让图纸自己规定「出生那一刻先干什么」。** 这道规矩写在图纸里，每次生猫都自动跑一遍 —— 它叫**出生招式（构造函数）**；它还有成对的另一半，管猫走的时候那一趟：**收尾招式（析构函数）**。

## 一、出生招式：生猫那一刻自动跑的那一招

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    Cat(string n, int f) {
        name = n;
        fish = f;
    }

    void show() const {
        cout << name << " 有 " << fish << " 条小鱼干" << endl;
    }
};

int main() {
    Cat c1("小橘", 3);
    Cat c2("狸花", 1);
    c1.show();
    c2.show();
    return 0;
}
```

```text
小橘 有 3 条小鱼干
狸花 有 1 条小鱼干
```

看 `main` 里那两行：`Cat c1("小橘", 3);` —— **生猫的时候直接把料一起喂进去了**，本喵一行都没多写。图纸上多出来的那一招，就是这一切的关键：

- **招式名和图纸名一个字都不差。** 图纸叫 `Cat`，这一招就叫 `Cat`。这是它唯一的「认领暗号」—— 翻译官喵只要在图纸里看见一个跟图纸同名的招式，就知道「这是出生那一刻要跑的规矩」。
- **它脑袋上不写「叼回什么」。** 你看它的开头：`Cat(string n, int f)` —— 前面**不写** `void`、不写 `int` —— 因为出生不是喊它去干活，压根不存在「叼回来什么」这件事。
- **没人喊它，它自己跑。** `Cat c1("小橘", 3);` 这一句里，真猫一落地，出生招式**立刻**被喊了一次：`n` 收到 `小橘`、`f` 收到 `3`，两格就装好了。
- **两个投喂口是有先后的**：`n` 先接住 `"小橘"`，`f` 再接住 `3`。喂料的顺序得跟脑袋上的顺序对上，这是第一阶段学招式时就已经定下的规矩。

一句口诀先记住：**招式名跟图纸同名、脑袋上不写叼回什么、生猫那一刻自动跑。**

::: warn 小心喵
出生招式**不能**写 `void`！本喵当初想：「招式都爱在脑袋上写个返回类型，那本喵也写一个总没错吧」—— 结果翻译官喵当场拦下：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;

    void Cat(string n) {
        name = n;
    }
};

int main() {
    Cat c1("小橘");
    cout << c1.name << endl;
    return 0;
}
```

```text
main.cpp:9:5: error: return type specification for constructor invalid
```

念作：**「出生招式头上不许写叼回什么喵。」** 报错里那个 `constructor` 说的就是出生招式。看到它，就去把脑袋上那个 `void`（或者 `int`、`string`）**删掉** —— 它的脑袋上除了收什么料，别的什么都不该有。
:::

## 二、出生清单：在大括号之前就把格子装好

上面那一招的肚子里是两行「先接住料、再塞进格子」。同样一件事，还有更利索的写法：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    Cat(string n, int f) : name(n), fish(f) {}

    void show() const {
        cout << name << " 有 " << fish << " 条小鱼干" << endl;
    }
};

int main() {
    Cat c1("大胖", 5);
    c1.show();
    return 0;
}
```

```text
大胖 有 5 条小鱼干
```

脑袋后面多了那一小段：` : name(n), fish(f)` —— 它叫**出生清单（初始化列表）**，念作「**用 `n` 去装 `name`、用 `f` 去装 `fish`**」。

- 它在**大括号里那几行之前**执行。也就是说：真猫刚落地的瞬间，东西**已经在格子里了**，而不是「先空着一会儿、再塞进去」。
- 一格一件事，中间用逗号隔开；清单写完再写那对大括号，肚子里可以什么都不写 —— 于是整招缩成了 `Cat(string n, int f) : name(n), fish(f) {}` 这么一行。
- **有些格子不用清单就装不进去**：本喵给格子加了「出生以后再也不许改」的封印（`const int fish;`）之后，就只能靠清单装。

::: warn 小心喵
**带封印的格子（`const`）只能靠出生清单装。** 本喵试过把它放在肚子里塞：

```cpp
#include <iostream>
using namespace std;

class Cat {
public:
    const int fish;

    Cat(int f) {
        fish = f;
    }
};

int main() {
    Cat c1(3);
    cout << c1.fish << endl;
    return 0;
}
```

```text
main.cpp:6:15: note: 'const int Cat::fish' should be initialized
main.cpp:9:14: error: assignment of read-only member 'Cat::fish'
```

翻译官喵一共说了两句：上面那句 note 是「**这一格该在出生清单里装好**」，下面那句 error 是「**这是只读的格子，不许赋值**」。所以看到 `read-only member`，就去把这一格从肚子里挪到清单上 —— 写成 `Cat(int f) : fish(f) {}` 就通了喵。
:::

### 清单的写法，不决定装东西的先后

本喵刚学这一手的时候以为「清单里谁写在前面，谁就先装」。真跑过一次才知道**不是**：装的先后只看**图纸上格子的先后**。本喵把清单写反过一次，翻译官喵当场念叨：

`main.cpp:7:9: warning: 'Cat::weight' will be initialized after [-Wreorder]`

⚠️ 这三种 `[-Wreorder]` 的字样本喵是在**本机真跑出来的**，它说的是「你清单里的顺序跟图纸上格子的顺序对不上」。**但它只出声、不拦你** —— 程序照跑，数字照样装对。所以别把它当耳旁风：看见 `reorder`，要么把清单顺序理顺，要么干脆别在清单里搞跨格子的花样喵。

## 三、几套出生法：同一张图纸，想怎么生就怎么生

图纸上可以挂**不止一套**出生招式：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    Cat() : name("无名"), fish(0) {}
    Cat(string n) : name(n), fish(0) {}
    Cat(string n, int f) : name(n), fish(f) {}

    void show() const {
        cout << name << "：" << fish << " 条" << endl;
    }
};

int main() {
    Cat a;
    Cat b("小橘");
    Cat c("狸花", 3);
    a.show();
    b.show();
    c.show();
    return 0;
}
```

```text
无名：0 条
小橘：0 条
狸花：3 条
```

图纸上写了三套：不带料的、只带名字的、两样都带的。翻译官喵**看你喂了几样料、喂的是什么**，就去挑对得上的那一套 —— 这正是第一阶段「同名多招」的老套路，只不过现在它管的是「怎么出生」。

- `Cat a;` —— 一样料都没喂 → 跑 `Cat()` 那套：名字默认「无名」、条数 0。**这就是「刚出生别空着」的正解**：上一课那只名字格空空的猫，从此有救啦。
- `Cat b("小橘");` —— 喂了一根项链 → 跑 `Cat(string n)` 那套。
- `Cat c("狸花", 3);` —— 一根项链加一个数 → 跑两样都带的那套。

**只要料的分量或者种类不一样，几套出生法就能同时挂在一张图纸上**，本喵不用给它们起三个名字。

## 四、收尾招式：猫走的时候，自动跑的那一趟

有出生就有离开。本喵给图纸再添一笔 —— 招式名前面多一个小波浪号 `~`：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;

    Cat(string n) : name(n) {
        cout << name << " 出生啦" << endl;
    }
    ~Cat() {
        cout << name << " 睡着啦" << endl;
    }
};

int main() {
    Cat a("小橘");
    {
        Cat b("狸花");
        cout << "里屋现在有两只" << endl;
    }
    cout << "里屋空了" << endl;
    return 0;
}
```

```text
小橘 出生啦
狸花 出生啦
里屋现在有两只
狸花 睡着啦
里屋空了
小橘 睡着啦
```

三件事，一件一件看喵：

1. **出生招式按 `main` 里生猫的先后跑**：小橘先生出来，狸花后生出来，所以先印小橘那行。
2. **里屋那对大括号一结束，里屋里的狸花就被收走了** —— 谁**走出**自己所在的那对大括号，谁就被自动收走。本喵一句都没喊 `~Cat()`，它自己跑的。
3. **倒着收**：狸花先走，小橘后走（小橘住在外面的屋子里，得等 `main` 结束才走）。这就像一摞叠起来的猫粮碗 —— **最后放上去的，最先被拿走**。

**两个「自动」就是这一段的全部价值**：走到生猫那一行，出生招式自己跑；走出那对大括号，收尾招式自己跑 —— 本喵一次都没喊过它们。哪只猫归哪对大括号管，它就在哪个 `}` 上被收走。

那收尾招式到底有什么用？今天的猫身上没什么好收拾的，所以看着像走过场。等本喵讲到「临时租来的仓库」那一课你就知道了：**借来的东西，必须在猫走的时候还回去** —— 收尾招式就是放那句「还回去」的地方。今天先把它什么时候跑记牢就够了喵。

## 五、本喵今天记住的三句话

::: tip 猫咪提示
1. **出生招式**：招式名跟图纸名一字不差，脑袋上**不写叼回什么**，`Cat c1("小橘", 3);` 那一刻自动跑。
2. **出生清单**：脑袋后面写 ` : name(n), fish(f)`，它在**大括号之前**就把格子装好；带封印的格子只能这么装。清单的**写法**不决定装填顺序，图纸上格子的先后才决定。
3. **收尾招式**：名字是 `~图纸名`，**走出那对大括号时自动跑**；同一段里几只猫，倒着收。
:::

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `Cat(string n, int f) { ... }` | 出生招式：生猫那一刻自动跑，脑袋上不写叼回什么 |
| `Cat c1("小橘", 3);` | 生一只猫，同时把两样料喂给出生招式 |
| `Cat(string n, int f) : name(n), fish(f) {}` | 出生清单：在大括号之前就把格子装好 |
| `const int fish;` | 带封印的格子，只能靠出生清单装 |
| 图纸上挂三套 `Cat(...)` | 几套出生法，按料的分量 / 种类挑一套 |
| `~Cat() { ... }` | 收尾招式：走出大括号时自动跑，几只猫倒着收 |
