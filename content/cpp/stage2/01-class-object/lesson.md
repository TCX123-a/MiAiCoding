通用课里本喵走过两条路：把一件事拆成一条流水线，或者拆出几个角色（《两条路》）；后来《起个名字就是抽象》又教了一手 —— 给最会变的那一小截起个名字。今天这两手要合到一处用：**把「一只猫该有什么、会什么」整个起成一个名字、画成一张图纸** —— 画一次，往后照它生猫。

这一手，是往后所有课的起点喵。

## 钩子：三只猫，三份账，本喵抄到手软

猫窝里住了三只猫：小橘、狸花、大胖。本喵要给每只都记两样东西 —— 它叫什么、今天吃了几条小鱼干。

用前面学的家伙什，本喵得这么写：

```text
int fish1 = 3;    string name1 = "小橘";
int fish2 = 1;    string name2 = "狸花";
int fish3 = 5;    string name3 = "大胖";
```

三只猫还凑合。可要是三十只、三百只呢？本喵的爪子会先断掉 —— 而且最气人的是：**这三套东西长得一模一样，本喵只是在抄自己。**

更麻烦的是，本喵还想让每只猫都会一招「报个数」。三只猫就得写三招几乎一样的招式，以后想改一句话，三个地方都得改。这哪是写程序，这是抄书喵。

上一课本喵画过一张「卡片图纸」（那个 `struct`），它让名字和数目住在同一张卡上。今天本喵要把这门手艺往前推一大步：**画一张图纸 —— 图纸上不光有几栏家常，还能写上这只猫会的招式。** 照着它，想生几只猫就生几只。

这一手在猫咪世界里叫**猫猫图纸（类）**，照图纸生出来的每一只叫**根据图纸生出来的真猫（对象）**。

## 一、本喵的猫猫图纸，第一次动笔

摊开纸笔，本喵先画一只最普通的猫：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    void meow() {
        cout << "本喵是" << name << "，今天吃了 " << fish << " 条小鱼干喵" << endl;
    }
};

int main() {
    Cat c1;
    c1.name = "小橘";
    c1.fish = 3;
    c1.meow();
    return 0;
}
```

```text
本喵是小橘，今天吃了 3 条小鱼干喵
```

这一小块里干了**两件事**：先画图纸，再照图纸生一只真猫。一行一行看喵：

- **`class Cat { ... };`** —— 画图纸的口令。`class` 就是「本喵要画一张图纸」，`Cat` 是这张纸的名字。**大括号闭合以后别忘了那个分号** —— 这一条上一课在卡片图纸上说过，换成 `class` 还是它。
- **`public:`** —— 一行小标签，意思是「下面这几样，图纸外面也够得着」。**今天先照抄**，它的来龙去脉本喵留到第 4 课专门讲，今天你只要记得：**图纸里每样东西，都得站在某一行这样的标签下面。**
- **`string name;`** —— 图纸上的第一栏家常：**每只照它生出来的猫，都自带一格名字。** 这一行是本喵在纸上画的「格子」，不是真的在哪儿开了一个。
- **`int fish;`** —— 第二栏家常：每只猫自带一格鱼干数。
- **`void meow() { ... }`** —— 图纸上画的一招。它的写法和第 9 课学的招式一模一样，只差一件事：**它画在图纸的大括号里面**。所以招式里那句 `name`、`fish`，说的是**「本喵自己」那两格** —— 不用写任何前缀，抬眼就看得见。

## 二、照图纸生一只真猫

图纸最下面那三行，就是生猫和使唤猫：

```cpp
Cat c1;              // 照图纸生一只真猫，给它起名叫 c1
c1.name = "小橘";     // 把 "小橘" 放进它的名字那一格
c1.fish = 3;         // 把 3 放进它的鱼干那一格
c1.meow();           // 让这一只自己施展 meow 这一招
```

（这几行只是把上面完整程序里的同一段抄出来看，单独跑不了，所以没给输出喵。）

- **`Cat c1;`** —— 照图纸**真的生出一只猫**来，本喵给它起个临时称呼叫 `c1`。这一句在 C++ 里**就是生猫的全部动作** —— 不像有些语言还得喊一声 `new Cat()`，C++ 的写法更短：**写上图纸名，跟一个名字，猫就站在你跟前了。**
- **`c1.name`** —— 点号是从这只猫身上够到某一格的办法。念作「`c1` 这只猫的 `name` 那一格」。够到之后，它就跟普通的一只碗没两样，能放能取。
- **`c1.meow()`** —— 让**这一只**施展那一招。**先说哪只猫，再喊招式名** —— 和上一阶段学的喊招式，只多了前面那一段「哪只猫」。它念出来的自然是用**自己**的名字和自己的鱼干数。

## 三、图纸不是猫

这句话本喵要单独拎出来说 —— 它是新手第一个跟头：

> **`class Cat { ... };` 画完，碗边一只猫都没有。**

图纸上写的每一行，说的都是「凡是照它生出来的猫，长什么样、会什么」。可图纸自己不会叫、不会吃鱼干，也**不占任何一格** —— 它只是画在那儿。真正让世界多一只猫的，是 `Cat c1;` 那一句。

这也是上一课那张卡片图纸教过你的同一件事：**图纸画了不做卡片，手里就没东西用。**

## 四、生两只：各带各的格子

图纸画一次就够，想生几只生几只。本喵再生一只，看看它俩的账会不会串：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;
};

int main() {
    Cat c1;
    Cat c2;
    c1.name = "小橘";
    c1.fish = 3;
    c2.name = "狸花";
    c2.fish = 1;

    c1.fish = c1.fish + 2;
    cout << c1.name << " 的账上是 " << c1.fish << " 条" << endl;
    cout << c2.name << " 的账上是 " << c2.fish << " 条" << endl;
    return 0;
}
```

```text
小橘 的账上是 5 条
狸花 的账上是 1 条
```

本喵只给小橘加了 2 条，狸花**一点没跟着变**，还是它自己那 1 条。

- **图纸只有一张**，画完就那样，生多少只猫都不会把它用旧。
- **格子是每只猫各带一份的**。照图纸生一只，它就带着自己那一套 `name` 和 `fish`，和别的猫谁也不碰谁。
- 所以 `c1.fish = c1.fish + 2;` 动的是**小橘那一格**，跟狸花半点关系都没有喵。

## 五、刚生出来的猫，格子里是什么

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
};

int main() {
    Cat c1;
    cout << "刚出生，名字是【" << c1.name << "】" << endl;
    return 0;
}
```

```text
刚出生，名字是【】
```

刚生出来的猫，名字那一格**本来就是空的** —— 一串小鱼干的项链，没人往里放东西的时候就是空的一串（所以印出来两个方括号之间什么都没有，不是印出「空」这两个字）。

那 `int` 那一格呢？**没人往里放过东西之前，那格里是什么谁也没说。** 所以本喵在上面这段里**一个字都没去读** `fish` —— 读一个没人放过的格子，你拿到的是一个说不准的东西，跟运气差不多。

想让它一出生就带着名字、带着鱼干数？那就是下一课的正题：**让图纸在生猫的那一刻，自动把格子摆好**。今天先记住：**没用过 `=` 放东西的格子，不要读。**

## 六、本喵今天摔的两跤

**第一跤：图纸末尾那个分号忘了。**

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;
}

int main() {
    Cat c1;
    c1.name = "小橘";
    cout << c1.name << endl;
    return 0;
}
```

```text
main.cpp:9:2: error: expected ';' after class definition
```

翻译官喵这句话的意思是：**「图纸画到这儿该收尾了，本喵在等一个分号喵。」** 看到 `expected ';' after class definition`，别去怀疑图纸里的哪一行 —— **直接看图纸大括号后面那一个字符**。

**第二跤：够一格图纸上根本没有的家常。**

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;
};

int main() {
    Cat c1;
    c1.name = "小橘";
    c1.weight = 4;
    cout << c1.name << endl;
    return 0;
}
```

```text
main.cpp:14:8: error: 'class Cat' has no member named 'weight'
```

念作：**「`Cat` 这张图纸上，没有叫 `weight` 的那一格喵。」**

本喵想给猫记体重，可图纸上压根没画这一栏 —— 图纸上没有的东西，真猫身上当然也没有。**先回图纸加一栏，再回来写这一句**，顺序就是这样喵。

::: tip 猫咪提示
今天记住五句话：

1. **`class 图纸名 { ... };`** —— 画一张图纸，大括号后面那个分号别丢。
2. **图纸里先写家常（几格），再写招式。** 招式里那句 `name`、`fish`，说的是本喵自己那两格。
3. **`Cat c1;` 就是照图纸生一只真猫**，C++ 不用喊 `new`；点号够到它自己的格子：`c1.name`。
4. **图纸只有一张，格子是每只猫各带一份**，改一只不动另一只。
5. **没人放过东西的格子不要读** —— 名字那一格是空的，装数的格子是什么谁也没说。
:::

::: warn 小心喵
- **图纸 ≠ 猫。** 只写 `class Cat { ... };` 而没写 `Cat c1;`，碗边一只猫都没有。
- **图纸末尾的分号**是本课最贵的一个字符，报 `expected ';' after class definition` 就是它。
- **`public:` 那一行今天先照抄**，缺了它图纸外面够不着里面的格子。
:::

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `class Cat { ... };` | 画一张叫 `Cat` 的猫猫图纸（**大括号后面别忘分号**） |
| `public:` | 「下面这几样，图纸外面也够得着」—— 今天先照抄 |
| `string name;` / `int fish;` | 图纸上的两格家常，每只真猫自带一套 |
| `void meow() { ... }` | 图纸上画的一招，招式里直接用 `name`、`fish` 就是自己那两格 |
| `Cat c1;` | 照图纸生一只真猫，C++ 不必写 `new` |
| `c1.name = "小橘";` | 把东西放进 `c1` 这一只的名字格 |
| `c1.meow();` | 让 `c1` 自己施展那一招 |
| `c1` 和 `c2` | 两只真猫，格子各带各的，改一只不动另一只 |
