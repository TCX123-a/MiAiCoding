## 钩子：下载页上两个按钮，选哪个喵？

哪天你跟着教程去下载 Java，多半会撞见一排按钮：一个写着 **JDK**，一个写着 **JRE**，旁边还到处飘着 **JVM** 三个字母。三兄弟名字长得像，脾气可差远了——点错一个，要么多背一大包用不上的家什，要么少带一件马上要用的工具喵。

不怪你眼花：**它们三个本来就是一家人，还是一家套一家那种**。今天本喵把家谱摊开画给你看：谁住谁家里、装哪个才不亏、以及怎么一句话问出「这台电脑到底装了什么」。

02 课你见过的**念稿员**，就在这一家坐着呢——先跟它打个招呼。

## 老朋友 JVM：住在这台电脑里的念稿员

02 课那位把通用话念给电脑听的老朋友，叫 **JVM**（Java 虚拟机）——你可以先按它的活儿记：**念稿员**。

它的本事就一条：认 `.class`，**从 main 那一行开始，一行一行念给电脑听**。不挑地方是它最大的优点——同一份通用话，在这台电脑上念是这几句，搬到别的系统上念还是这几句，「一次写好，哪儿都能跑」的底气就在它身上。

今天要补的一课是：**这位念稿员不是空气**——它得被「装」进电脑里才能住下。把它连同它要用的家什打包到一起，就是下面第一个名字。

## JRE：念稿要用的整套家什

**JRE** 拆开看：J 是 Java，R 是 Runtime（运行），E 是 Environment（环境）——合起来就是「**运行环境**」，本喵叫它**运行套装**。

跑一份稿子，光有念稿员可不够，JRE 把「念稿」需要的东西整套装好：

- 中间坐着那位**念稿员 JVM**；
- 旁边是**一大柜基础图纸**——`String`、`Math`、`System` 这些你天天用的家伙什，念稿念到它们，伸手就有；
- 外头再配好**接线**——让 `java` 这条口令在命令窗口里喊得应。

所以**只想跑**别人做好的程序？装 JRE 就是最小的一套：好，通用话递过来就能念。

## JDK：把造稿的家伙什也塞进来

可是想**自己写**呢？光会念不够，还得会**翻稿**。**JDK** 里那个 D 是 Development（开发）——**开发工具箱**。它的做法很干脆：**在 JRE 外面再套一层**，把造稿的家伙什全塞进去：

- **`javac` 打头**——02 课陪你走完两趟活的翻稿工具，就住这儿；
- 一整套**配套工具**（打包的、看文档的……本课先混个脸熟，往后一课课认识）；
- 里面**照旧装着整套 JRE**——念稿那一套，一样不缺。

关键在最后一条：JDK 和 JRE **不是并列的两包**，是**一层套一层**——JDK 里装着 JRE，JRE 里才住着 JVM。

## 套娃图：一层套一层

口说无凭，画出来看：

```text
JDK（开发工具箱）
├─ javac 等造稿工具
└─ JRE（运行套装）
   ├─ 基础图纸库（String、Math……）
   └─ JVM（念稿员——从 main 开始念通用话）
```

从里往外读：**JVM 住在 JRE 里，JRE 住在 JDK 里**。于是下载页那道选择题有了省事答案——**写程序就装 JDK，装它一个，里外三层全到手**；只跑现成程序，JRE 才够用。

让程序把这三行关系念给你听（还是老两步：先翻，再念）：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("JDK 里套着 JRE");
        System.out.println("JRE 里套着 JVM");
        System.out.println("三层箱子，一层套一层喵");
    }
}
```

```text
JDK 里套着 JRE
JRE 里套着 JVM
三层箱子，一层套一层喵
```

## 版本怎么看：两条报名口令

装了东西，总得验个货。看版本不用翻箱倒柜——**给命令加一对小翅膀 `-version`** 就行。

问**造稿**那一套：

```text
javac -version
```

它回话特别短，一行就完：

```text
javac 21.0.12.1
```

问**念稿**那一套，是给 `java` 加同一对小翅膀：

```text
java -version
```

这回一回三行，本机实况长这样：

```text
openjdk version "21.0.12.1" 2026-08-18 LTS
OpenJDK Runtime Environment Temurin-21.0.12.1+1 (build 21.0.12.1+1-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.12.1+1 (build 21.0.12.1+1-LTS, mixed mode, sharing)
```

先只看**头一行**：`openjdk version "21.0.12.1"`——念稿套装也有版本号，还和翻稿工具报的那个数**一模一样**。不是巧合：一套箱子里配出来的两件工具，版本本来就配套。（`Temurin` 是本机装的这一家的名字，换台电脑可能写着别家，认数字那一段就好喵。）

两条口令摆一起，对照着记：

| 口令 | 问的是谁 | 回话长什么样 |
|---|---|---|
| `javac -version` | 造稿那一套（翻稿工具） | 一行：`javac 21.0.12.1` |
| `java -version` | 念稿那一套（念稿员带队） | 三行，头一行 `openjdk version "21.0.12.1"` |

### 尾巴：两套版本对不上会怎样

概念级说一段：造稿工具和念稿套装**各有各的版本**。稿子是哪一版翻出来的，通用话上就带着哪一版的记号——送到一台念稿套装太旧的电脑上，老念稿员认不出新记号，会**在运行那一步**当场翻脸。注意坏的位置：翻稿那一步在你自己电脑上早就成功了，**账是记在后一步上的**。所以有句老话：目标机器装什么版本，翻稿就用什么版本。多个版本怎么装、怎么切换，往后讲「环境」的课再逛喵。

::: tip 猫咪提示
套娃口诀背一句：**JVM 最里，JRE 居中，JDK 最外**；装最外面的 JDK，里里外外三层全到手。反过来不成立——只有 JRE 的电脑上，`javac` 是不在家的喵。
:::

::: warn 小心喵
两条报名口令就差一个字母：`javac -version` 问**造稿**，`java -version` 问**念稿**。喊混了它们谁都不会报错——照样回话，只是你手里拿到的是另一边的版本号，自己把自己骗了喵。
:::

## 小任务

1. 在命令窗口敲 `javac -version`，记下翻稿工具的版本号；
2. 再敲 `java -version`，对照头一行的数字——和上一条一样吗？
3. 把课文里那段「三层箱子」的小程序存成 `Main.java`，翻一遍、念一遍；
4. 脑筋急转弯：一台**只装了 JRE** 的电脑上敲 `javac -version`，会发生什么？（提示：先想它住在谁家。答案本喵不写，等你自己说出来喵。）
