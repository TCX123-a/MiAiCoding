## 钩子：只会复读、不会算账的点单机

猫咪食堂门口那台点单机，前几天刚学会张嘴（`System.out.println`）和听话（`Scanner`）。可昨天大肥鱼来买小鱼干，出事了：它晃着圆滚滚的身子说「小鱼干一条 3 元，本鱼要 5 条」——点单机张嘴就念「3」「5」，然后就没了下文。

**它只会复读，不会算账**喵。

要让机器算账，就得给它添两样东西：**表达式**和**运算符**。学完这一课，点单机就从复读机升级成会算账的猫猫掌柜啦 🐟。

## 表达式：一张能算出结果的单子

先认最大方的那个词：**表达式**，就是**一段能算出结果的式子**——比如 `3 + 5`。

Java 见到表达式，会**当场把它算出来**。算出来的结果和别的值一样能用：能喂给 `System.out.println` 印出来，也能装进小鱼干仓库里存着。所以下面这两行都成立：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(3 + 5);
        int total = 3 + 5;
        System.out.println(total);
    }
}
```

```text
8
8
```

第一行把算式的结果直接印出来，第二行把结果装进 `total` 这间仓库、第三行再印一次——所以屏幕上出现两个 `8`。**算式不是摆设，它是会出结果的**喵。

那算式里那个**动作符号**叫什么呢？就叫**运算符**。`3 + 5` 里，`3` 和 `5` 是原料，中间的 `+` 是动作——本喵管它叫**锅铲**：原料下锅，锅铲一翻，出来一道菜。今天要认四把锅铲：**算术、比较、逻辑**，还有管排队次序的**优先级**；路上还会撞见 `+` 的一个兼职喵。

## 算术：`+` `-` `*` `/` `%`

| 运算符 | 干什么 | 例子 |
|---|---|---|
| `+` | 加起来 | `7 + 2` 得 `9` |
| `-` | 减去 | `7 - 2` 得 `5` |
| `*` | 乘起来 | `7 * 2` 得 `14` |
| `/` | 除 | `7 / 2` 得 `3`（零头被扔掉，下面细说） |
| `%` | 取余（除完还剩多少） | `7 % 2` 得 `1` |

先提醒两句：**乘号是键盘上的星号 `*`，不是 `×`**；除号是**斜杠 `/`，不是 `÷`**。翻译官喵只认键盘上那两个符号。

```java
public class Main {
    public static void main(String[] args) {
        int a = 7;
        int b = 2;
        System.out.println(a + b);
        System.out.println(a - b);
        System.out.println(a * b);
        System.out.println(a / b);
        System.out.println(a % b);
    }
}
```

```text
9
5
14
3
1
```

前四行都好懂，只有第四行 `a / b` 印出来的 `3` 值得停下来看一眼：7 除以 2 明明是 3.5 呀？**零头去哪儿了喵？**

### `/` 的怪脾气：两边都是整数，零头直接扔掉

这是本课第一个大坑，本喵单独开一节讲。Java 不是不会算小数，它是**看两边是什么料**再决定怎么切：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(7 / 2);
        System.out.println(7 / 2.0);
        System.out.println(7 % 2);
    }
}
```

```text
3
3.5
1
```

- `7 / 2`：两边都是**整数料**，Java 说「那本喵就按整份数给你」——装满 3 份，剩下那半个被**扔掉**，印出 `3`。这条和数学课上不一样，摔过的人能从猫窝排到鱼塘喵。
- `7 / 2.0`：右边那个数**带了小数点**，这一锅就按小数来算，老老实实印出 `3.5`。想让除法保留零头，两边**至少有一边要写成带小数点的样子**。
- `7 % 2`：`%` 不看商，只看**除完还剩多少**。7 条鱼干每袋装 2 条，装满 3 袋，还剩 `1` 条——印出 `1`。

一句话记住这一对：**`/` 管「装满几整份」，`%` 管「剩多少零头」**。

`%` 特别擅长一件事——**分单双**。一个数 `% 2` 得 `0`，说明它能被 2 分干净，是双数；得 `1` 就是单数。往后判断一个数是奇是偶，全指望它喵。

### 加一的小快捷：`++`

跑圈的时候经常要「把这个仓库里的数加一」，Java 备了个省事的写法：

```java
public class Main {
    public static void main(String[] args) {
        int fish = 3;
        fish++;
        System.out.println(fish);
    }
}
```

```text
4
```

`fish++` 就是 `fish = fish + 1` 的缩写——**仓库里原来的数加一，再装回去**。两个加号要挨着写，中间不能有空格，也不能写成 `fish += 1` 之外的花样（本喵后面讲跑圈时每圈都要用它一下）。

## `+` 的兼职：把东西接成一串

`+` 除了加法，还有第二个身份：**只要两边有一边是项链（一串小鱼干），它就不做加法，而是把两样东西接成更长的一串**。

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("一共 " + 3 + " 条喵");
        System.out.println(3 + 5 + " 条喵");
        System.out.println("一共 " + 3 + 5);
        String name = "小橘";
        System.out.println(name + " 有 5 条喵");
    }
}
```

```text
一共 3 条喵
8 条喵
一共 35
小橘 有 5 条喵
```

- 第一行：`"一共 "` 是项链，接上 `3`，再接上 `" 条喵"`——所以是「一共 3 条喵」。**数字被接成了字**。
- 第二行：`3 + 5` 两边都是数字，先老老实实算成 `8`，再跟项链接起来——印出 `8 条喵`。
- 第三行：`"一共 " + 3` 已经接成一串了，后面再遇到 `5` 就**接着往下接**，于是印出 `一共 35`——不是 `一共 8`！这就是 `/` 那条「看料下锅」的同一个脾气：**`+` 从左边开始一样一样地处理，碰到项链之后，后面的全变成接字**。
- 第四行：项链和仓库都能接，中间本喵还留了个空格，所以「小橘 有 5 条喵」。

上面第 2、3 行只差一个位置，印出来的东西却差得远 —— 本喵把这两行拆开，一步一步走给你看：

::: warn 小心喵
`+` 的兼职只对它自己开放。别的锅铲不认项链：`"3" - 1` 这种写法翻译官喵直接拒绝。

还有一条更早就要记住的：Java 是**认死理**的——一间仓库说好装什么，就只装什么。`int fish = "3";` 会被当场拦下，因为右边那串字不是整数料。

两条都以「编译期就红」收场，跑都跑不起来——这正是 Java 的脾气：**能拦的错，绝不留到跑的时候**喵。
:::

下面是这两条的真实报错原话，本喵特地在自己的机器上撞了一遍，你照着认个脸：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("3" - 1);
    }
}
```

翻译官喵当场就不干了：

```text

        System.out.println("3" - 1);
                               ^
  first type:  String
  second type: int
1 error
```

`bad operand types` 就是「这两样料，这把锅铲没法伺候」。它还好心把两边的料名报了出来：一边是 `String`（项链），一边是 `int`（整数），配不上。

另一条长这样：

```java
public class Main {
    public static void main(String[] args) {
        int fish = "3";
        System.out.println(fish + 1);
    }
}
```

```text

        int fish = "3";
                   ^
1 error
```

`incompatible types` 是「两边的料对不上」，后面那半句说得很直白：**项链没办法变成整数**。看到 `cannot be converted to` 就知道是「这边变不成那边」，回头看看是不是把一串字塞进了装数字的仓库喵。

## 比较：答案只有 `true` 和 `false`

接下来这把锅铲不忙着算数，它专门**问问题**。

就像本喵拿天平称两堆小鱼干，称完只有一个答案：左边多、右边多、还是一样多。Java 里比较出来的答案也只有两块牌子——`true`（真）和 `false`（假），两个词**通通小写**，一个字母都不能大写。

| 运算符 | 问的是什么 |
|---|---|
| `>` | 左边比右边大吗 |
| `<` | 左边比右边小吗 |
| `>=` | 左边大于**或等于**右边吗 |
| `<=` | 左边小于**或等于**右边吗 |
| `==` | 两边**一样**吗 |
| `!=` | 两边**不一样**吗 |

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(3 > 2);
        System.out.println(3 < 2);
        System.out.println(5 >= 5);
        System.out.println(5 == 5);
        System.out.println(5 != 5);
    }
}
```

```text
true
false
true
true
false
```

一眼看下来，输出里只有 `true` 和 `false` 轮流出现——这就是比较运算符的脾气：**它不问出「几」，只问出「成不成立」**。

念的时候也要留神：**一个等号 `=` 是动作，两个等号 `==` 才是发问**。

- 一个等号 `=`：把右边的东西**装进**左边的仓库。`fish = 3` 是「把 3 装进去」。
- 两个等号 `==`：问一句「两边一样吗」，问出来的是一块真假牌子。

### 项链比一样不一样，要用 `.equals()`

这是本课最值钱的一条，也是 Java 新手摔得最惨的一条：**两串字比「一样不一样」，不能用 `==`，要用 `.equals()`**。

```java
public class Main {
    public static void main(String[] args) {
        String a = "雨";
        String b = new String("雨");
        System.out.println(a == b);
        System.out.println(a.equals(b));
        System.out.println(a.equals("晴"));
    }
}
```

```text
false
true
false
```

两串字**看着一模一样**，可 `a == b` 印出来是 `false`。为什么？因为这两个符号问的根本不是同一件事：

- **`==` 问的是「你俩是不是同一个东西」**——像问两只猫「你是她本人吗」。`a` 和 `b` 是两串各写各的字，长一样但**不是同一个东西**，所以答 `false`。在别处遇到从别的地方取回来的字，`==` 也常常给你一个**莫名其妙的 `false`**：屏幕上的字明明一样，程序却说你不一样，而它一个错都不报，最费眼神喵。
- **`.equals(...)` 问的是「你俩内里长得一样吗」**——像把两串项链并排摊开，一颗一颗对过去。所以 `a.equals(b)` 答 `true`。

写法要注意：**项链的名写在前头，点一个点，再写 `equals`，把要比的那一串放进小括号里**——`a.equals(b)`。第三行 `a.equals("晴")` 问的是「`a` 和「晴」一样吗」，不一样，答 `false`。

::: warn 小心喵
两句话背下来，往后能省你半天抓虫的功夫：

1. **比数字大小的用 `==`**（还有 `>` `<` `>=` `<=` `!=`）。
2. **比两串字一不一样，一律 `.equals()`**。看到 `==` 两边是 `String`，立刻改掉。

还有个容易看走眼的地方：`a == b` 有时候也会**碰巧**印出 `true`（比如两串字都是同一个字面量写出来的）。「碰巧」两个字就是不能靠的意思——规矩照旧，**比两串字一律用 `.equals()`**，别去赌那一次运气喵。
:::

## 逻辑：把好几块牌子拼起来

一块牌子只回答一个问题，那「**鱼干够** 而且 **客人带够了钱**」这种规矩怎么写？

Java 给了三把**逻辑**锅铲，它们不跟数字打交道，专门**把真假牌子拼起来**：

- **`&&`**（而且）：两边**都**是真的，结果才是真。只要有一只猫没点头，就是假。
- **`||`**（或者）：两边**有一个**是真的，结果就是真。有一边点头就成。
- **`!`**（不）：把牌子**翻个面**——真的变假，假的变真。

```java
public class Main {
    public static void main(String[] args) {
        boolean hasFish = true;
        boolean hasMoney = false;
        System.out.println(hasFish && hasMoney);
        System.out.println(hasFish || hasMoney);
        System.out.println(!hasMoney);
        System.out.println(3 > 2 && 5 > 4);
    }
}
```

```text
false
true
true
true
```

一行行看：鱼干有（`true`），钱没带够（`false`）。

- `hasFish && hasMoney`：一个真一个假，「而且」要求两边都真，所以是 `false`——今天不卖。
- `hasFish || hasMoney`：有一边是真的，「或者」就满足了，所以是 `true`。
- `!hasMoney`：把 `false` 翻个面，得到 `true`（「**没**带钱」这件事是真的）。
- 最后一行：逻辑锅铲的两边最常放的正是**比较算出来的牌子**，这样一句话就能问两件事——`3 > 2` 真、`5 > 4` 也真，两边都点头，`true` 喵。

注意写法：`&&` 和 `||` 都是**两个符号挨着写**，`!` 只有一个、贴在牌子的前面。输成中文的「且」「或」，或者只写一个 `&`，都不是本喵说的意思。

## 优先级：谁先动手

最后一把锅铲管的不是计算，是**次序**。

厨房里做菜有先后：先切菜、再下锅，顺序乱了菜就毁了。算式里也一样——Java 不是从左到右傻算，它按**优先级**排队，谁级别高谁先动手。今天认的规矩，从高到低：

1. **括号 `( )`**——级别最高，谁被括号围起来谁先算。
2. **`!`**
3. **`*` `/` `%`**——乘除这一档
4. **`+` `-`**——加减这一档
5. **比较**：`>` `<` `>=` `<=` `==` `!=`（项链比一样不一样用 `.equals()`，它是个动作，不排队）
6. **`&&` → `||`**——逻辑这一档，`&&` 排得更紧

**同一档里，从左往右排队**喵。

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(2 + 3 * 4);
        System.out.println((2 + 3) * 4);
        System.out.println(3 > 2 + 5);
        System.out.println(2 + 5 > 3);
    }
}
```

```text
14
20
false
true
```

一模一样的数字，只因为多了一对括号，答案就从 `14` 变成 `20`：

- 第一行：乘除排在加减前面，所以先算 `3 * 4` 得 `12`，再算 `2 + 12` 得 `14`。
- 第二行：括号级别最高，先把 `2 + 3` 算成 `5`，再乘 `4` 得 `20`。
- 三四行：比较排在加减**后面**，所以两边都是**先算完数、再问问题**——`3 > 7` 是假、`7 > 3` 是真。
- 逻辑锅铲排在最后：`3 > 2 && 5 > 4` 是先把两块牌子比出来，再做「而且」。

::: tip 猫咪提示
今天记住这六句话，运算符就拿下大半啦：

1. **表达式 = 会算出结果的式子；运算符 = 中间的锅铲。**
2. **算术**：`+` `-` `*` `/` `%`；**两边都是整数时 `/` 会扔掉零头**，想要小数就让一边带上小数点。
3. **`/` 管装满几份、`%` 管剩多少零头**；`% 2` 还能分单双。
4. **比较**：`>` `<` `>=` `<=` `==` `!=`，答案只有 `true` / `false` 两块小写牌子。
5. **`+` 碰到项链就改行「接字」**；两串字比一样不一样，**用 `.equals()` 不用 `==`**。
6. **逻辑**：`&&` 要两边都真、`||` 有一边真就行、`!` 翻个面；**拿不准先加括号**——括号不花钱，还能让读代码的猫一眼看懂你想先算哪一步。
:::

## 小任务

先别急着跑，**每一行都先在心里猜一个数**，再去 Java 里对答案——猜错了才是最赚的，那说明有个地方你还没想清楚喵～

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(137 / 10);
        System.out.println(137 % 10);
        System.out.println(8 % 2);
        System.out.println(8 % 3);
        System.out.println(1 + 2 == 3);
    }
}
```

1. 前两行：本喵有 137 条小鱼干，每袋装 10 条——能装满几袋、还剩几条？
2. 中间两行：`8 % 2` 和 `8 % 3` 各是几？哪一个说明 8 是双数？
3. 最后一行 `1 + 2 == 3`：先算谁、后算谁？它会印出一个数，还是一块牌子？
4. 试着改一改：把 `System.out.println(2 + 3 * 4);` 加一对括号改成 `(2 + 3) * 4`，猜猜答案从几变成几，再跑一遍看看猜对没有。
5. 再玩一个：把 `String a = "雨";` 那段的 `new String("雨")` 改写成 `"雨"`，跑一遍看看 `a == b` 变成什么了。本喵提前打个招呼：这一回它会印出 `true`——因为这两串字**碰巧**是同一个东西。碰巧不算数，规矩照旧：比两串字一律用 `.equals()` 喵。
