## 钩子：本喵最常使唤的那串东西

从小到大，本喵使唤得最多的家伙不是数字，是**一串字**：「你好喵～」「小橘」「小鱼干到手喵」，还有你敲进键盘的每一个名字。

这串东西本喵爱叫它**大鱼缸**：缸里摆着一串小鱼干，一条挨着一条，摆好之后就**焊住**了 —— 谁也不能伸手进去把其中一条抠出来换掉。想改？只能照着这只缸**再做一只新的**。

它的正式名字是**一串小鱼干的项链（字符串）**，代码里的记号是 `String`。今天这一课，本喵要把这只缸的脾气一次讲透：怎么数它、怎么看它、怎么接它，还有 Java 里最著名的那个坑 —— **两串看起来一模一样的字，比出来却说不像**喵。

## 一、先摆一只缸

```java
public class Main {
    public static void main(String[] args) {
        String fish = "小鱼干";
        System.out.println(fish);
        System.out.println(fish.length());
        System.out.println(fish.charAt(0));
        System.out.println(fish + "到手喵");
        System.out.println("本喵有 " + 3 + " 条");
    }
}
```

```text
小鱼干
3
小
小鱼干到手喵
本喵有 3 条
```

一行一行看：

- **`String fish = "小鱼干";`** —— 摆一只叫 `fish` 的缸，里面装着「小鱼干」三条。**双引号**是这串字的边界：引号本身不算内容，就像昨天讲的打印一样。
- **`fish.length()`** —— 缸里**有几条**。三条，所以是 `3`。注意它**带一对小括号**，是要你喊一声才给的活儿（一排碗的 `.length` 就没括号，那是 Java 里最爱绊人的一处不一致，`11` 那课里已经撞过喵）。
- **`fish.charAt(0)`** —— 掏**第 0 条**出来。编号和 `11` 那课的一排碗一样，**从 `0` 数起**：`charAt(0)` 是「小」，`charAt(1)` 是「鱼」，`charAt(2)` 是「干」。
- **`fish + "到手喵"`** —— 两串接成一串，印出「小鱼干到手喵」。
- **`"本喵有 " + 3 + " 条"`** —— 数字和字符串接起来也行，印出「本喵有 3 条」。`+` 碰到这串东西就改行「接字」，这一手昨天在算式里见过喵。

## 二、常使唤的几招

缸身上挂着一堆现成的招式，随喊随用：

```java
public class Main {
    public static void main(String[] args) {
        String s = "  Fish  ";
        System.out.println(s.trim());
        System.out.println(s.trim().toUpperCase());
        System.out.println(s.trim().substring(0, 2));
        System.out.println(s.contains("is"));
        System.out.println(s.indexOf("s"));
    }
}
```

```text
Fish
FISH
Fi
true
4
```

| 招式 | 它干什么 | 这一段的例子 | 结果 |
|---|---|---|---|
| `.length()` | 缸里有几条 | `s.length()` | `8`（两个空格 + Fish + 两个空格） |
| `.trim()` | 把两头的空白掐掉 | `s.trim()` | `Fish` |
| `.toUpperCase()` | 全变成大写 | `s.trim().toUpperCase()` | `FISH` |
| `.substring(a, b)` | 从 `a` 号掏到 `b` 号**之前** | `s.trim().substring(0, 2)` | `Fi` |
| `.contains(x)` | 里面有没有这一小串 | `s.contains("is")` | `true` |
| `.indexOf(x)` | 这一小串在第几号 | `s.indexOf("s")` | `4` |
| `.equals(x)` | 两缸内里一样不一样 | `s.trim().equals("Fish")` | `true` |

两处要盯紧喵：

- **`substring(0, 2)` 掏到的是 `Fi`，不是 `Fis`** —— 后面那个编号是「**掏到它之前为止**」，`2` 号那颗**不算**。所以掏两颗珠子，写的是 `substring(0, 2)`：`0` 号、`1` 号，正好两颗。这一条**永远差一个**，是本课最好摔的地方。
- **招式可以串着喊**：`s.trim().toUpperCase()` 是先把两头空白掐掉、拿到的结果再全变大写。前一招叼回来的战利品上，接着喊下一招 —— 一条链子从左往右读下来就行。

`indexOf` 印出来的是 `4`，本喵拆给你看：这一串是「空、空、`F`、`i`、`s`、`h`、空、空」，编号从 `0` 数：空是 `0`、空是 `1`、`F` 是 `2`、`i` 是 `3`、`s` 是 `4`。找的是**一模一样**的一小串，所以大小写也算差别喵。

## 三、`+` 是接珠子：小心算式的先后

`+` 在这门语言里有两个身份：**数字身上是加号，缸身上是接珠子的线**。一句话里两者混着用的时候，它**从左往右**一个一个算过去 —— 顺序一样，结果可能完全不同：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(1 + 2 + "喵");
        System.out.println("喵" + 1 + 2);
    }
}
```

```text
3喵
喵12
```

- **第一句**：先算 `1 + 2`，两边都是数字，老老实实做加法得 `3`；再碰上 `"喵"`，改用接珠子的线 —— 印出 `3喵`。
- **第二句**：`"喵"` 在最前面，`+` 一登场就是接珠子 —— 把 `1` 变成一颗珠子接上去，再把 `2` 变成一颗珠子接上去，印出 `喵12`。**它没有做加法**，两个数字是被当成字一个一个字接上去的。

**规律一句话：从左往右算，碰到缸就改行接珠子。** 想让数字先加完再接，就给它俩加一对小括号，写成 `(1 + 2) + "喵"`。

::: tip 猫咪提示
接珠子这件事，还有一句要记：**只要 `+` 的两边**有一边是这串字，另一个不管是什么（数、牌子、另一串字），都会被接上去。所以 `"本喵有 " + 3 + " 条"` 才印得出「本喵有 3 条」喵。
:::

## 四、比一样不一样：`.equals(...)`

这一条是 Java 新手摔得最惨的一处，本喵上几课提过一次，今天要撞给你看个明白：

```java
public class Main {
    public static void main(String[] args) {
        String a = new String("小鱼干");
        String b = new String("小鱼干");
        System.out.println(a == b);
        System.out.println(a.equals(b));
    }
}
```

```text
false
true
```

两缸里的字**一模一样**，可 `a == b` 印出来是 `false`。

原因在 `==` 问的问题上：它问的是「**你俩是不是同一只缸**」，而不是「你俩里面的字一样不一样」。本喵上面是 `new String(...)` **各自做了一只新缸**，两只缸当然不是同一只 —— 于是 `false`。

`a.equals(b)` 问的才是「**内里长得一样吗**」，一颗一颗对过去，`true`。

**规矩就一句：拿两串字比一样不一样，一律 `.equals(...)`，别用 `==`。** 另外提一句：写成 `String a = "小鱼干";`（不用 `new`）的时候，`a == b` 有时候**会碰巧**印出 `true`。碰巧不算数 —— 别去赌那一次运气，规矩照旧喵。

## 五、缸是焊住的：招式不改原缸，只给你做新缸

```java
public class Main {
    public static void main(String[] args) {
        String s = "小橘";
        s.toUpperCase();
        System.out.println(s);
        String t = s.replace("橘", "狸");
        System.out.println(s);
        System.out.println(t);
        s = "大胖";
        System.out.println(s);
    }
}
```

```text
小橘
小橘
小狸
大胖
```

- 第二行那句 `s.toUpperCase();` 喊完了，**`s` 里的字一点没变**，第三行照旧印「小橘」。全变成大写的招式**叼回来了一只新缸**，本喵没接住它，它就飘走了。
- `s.replace("橘", "狸")` 同理：它做了一只新缸「小狸」，本喵把它接住、起名叫 `t` —— 所以 `s` 印出来还是「小橘」，`t` 才是「小狸」。
- 最后那句 `s = "大胖";` **能改**，但看清楚它是怎么改的：这是把牌子 `s` 从「小橘」那只缸上摘下来，**重新挂到「大胖」那只新缸上**。改的是牌子，不是缸。
- **缸里的珠子一旦摆好就焊死了，谁都改不动一颗。** 想接住招式做出来的新缸，就得**用牌子把它接住**，像 `String t = s.replace(...)` 这样喵。

「焊住」这三个字光看代码是看不出来的。本喵把它拆成一步一步，盯住**牌子往哪儿挪**：

::: warn 小心喵
三个最爱摔的地方，一口气记下来：

- **`s.toUpperCase();` 这样喊完不接住，等于白喊。** 缸没变、牌子也没变，屏幕上什么都看不出来 —— 这种错**不报错、不提醒**，只能靠你自己记住：这串东西的招式**不改原件，只叼回新的**。
- **`substring(a, b)` 的 `b` 是「掏到它之前为止」**，多写一个就多掏一颗。掏三颗写 `substring(0, 3)`，不是 `substring(0, 4)`。
- **比两串字一律 `.equals(...)`**；看到两串字中间夹着 `==`，立刻改掉。
:::

## 六、编号越界：编译一声不吭，跑起来才炸

编号从 `0` 数起，那要是一个不留神报了**超出缸里珠子数**的编号呢？本喵拿一只只有一颗珠子的缸试一试：

```java
public class Main {
    public static void main(String[] args) {
        String s = "鱼";
        System.out.println(s.charAt(3));
    }
}
```

```text
Exception in thread "main" java.lang.StringIndexOutOfBoundsException: Index 3 out of bounds for length 1
	at Main.main(Main.java:4)
```

第一行念起来是：**「编号 3 越界了，这只缸只有 1 颗珠子喵。」** 第二行是出事地点：`Main.java` 的第 4 行。这一条和 `11` 那课一排碗的越界是同一个脾气：

| 本喵写的 | 什么时候出问题 | 出什么样 |
|---|---|---|
| `s.charAt(3)`（编号越界） | **翻译官一声不吭，跑起来才炸** | 一句 `StringIndexOutOfBoundsException`，程序当场断气 |
| `"鱼".charAt(0)`（缸只有一颗） | 正常 | 掏出「鱼」 |

所以掏珠子之前，心里先数一遍：**合法的编号是 `0` 到「珠子数减一」**。缸里有几颗，喊一句 `.length()` 就问到了喵。

## 一句话对照表

| 本喵写下的 | 它干了什么 |
|---|---|
| `String s = "小鱼干";` | 摆一只缸，装着「小鱼干」三条 |
| `s.length()` | 缸里有几条（`3`） |
| `s.charAt(0)` | 掏第 `0` 条（「小」），编号从 `0` 数起 |
| `s.substring(0, 2)` | 掏 `0` 号到 `2` 号**之前**（`Fi`） |
| `s.trim()` / `s.toUpperCase()` | 掐掉两头空白 / 全变大写 —— **不留原件，另做新缸** |
| `"本喵有 " + 3 + " 条"` | 接珠子：`+` 有一边是缸，就把另一样接上去 |
| `a.equals(b)` | 两缸内里一样不一样 |
| `a == b` | 两样是不是同一只缸 —— **比字符串千万别用它** |

::: tip 猫咪提示
今天记住四句话：

1. **缸里摆着一串珠子，珠子**从 `0` 号数起，`.length()` 问几颗。
2. **掏珠子用 `charAt`，连着一小段用 `substring(a, b)`** —— `b` 是「掏到它之前」。
3. **`+` 有一边是缸，就改行接珠子**，一句话从左往右算，`(1 + 2) + "喵"` 和 `1 + 2 + "喵"` 一个意思、`"喵" + 1 + 2` 是另一个意思。
4. **缸是焊住的**：招式不改原件、只叼回新缸；比两串字一律 `.equals(...)`。
:::

## 小任务

1. 把第一节那只缸抄进练习场，把 `fish.charAt(0)` 依次改成 `1`、`2`，把印出来的三条珠子排一排看看；再改成 `3` 跑一遍，把小本本上记下那句炸出来的原话喵。
2. 摆一只缸 `String s = "  小橘喵  ";`，用 `.trim()` 把空白掐掉、接住它，再印一遍（应该印出 `小橘喵`）—— 不接住直接印，看看是不是什么都没变。
3. 拿 `.length()` 和圈配一配：写一个圈，从 `0` 号走到「珠子数减一」，把每颗珠子单独印一行（提示：圈里的眼色要和 `.length()` 比大小）。
4. 试一个 `String a = new String("喵");` 和 `String b = "喵";`，把 `a == b` 和 `a.equals(b)` 都印出来，看看这两句各印什么喵。
5. 把 `1 + 2 + "喵"` 改成 `1 + (2 + "喵")`，猜一猜这次印什么，再跑一遍对答案。
