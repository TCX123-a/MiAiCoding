## 钩子：本喵画的第一张猫猫图纸

前面这些课，本喵的牌子和招式全都写在 `main` 那一间屋子里。可本喵家里养着一群猫：小橘、狸花、大胖……每只都有自己的名字、自己今天吃了几条鱼干、自己那声「喵～」的腔调。要是每只猫都得在 `main` 里从头写一套牌子加一套招式，本喵的爪子会写断的喵。

今天本喵要学的是**画图纸**：图纸只画一次，照着它想生几只真猫就生几只。这门手艺的正式名字叫**猫猫图纸（类）**；照着一张图纸生出来的每一只，叫**根据图纸生出来的真猫（对象）**。

原来本喵写的东西，是「一只猫一份账」；从今天起，是「一张图纸一窝猫」喵。

## 一、图纸长什么样

本喵先把图纸画出来：

```java
class Cat {
    String name;
    int fish;

    void meow() {
        System.out.println(name + "：喵～本喵今天吃了 " + fish + " 条小鱼干");
    }
}

public class Main {
    public static void main(String[] args) {
        Cat c = new Cat();
        c.name = "小橘";
        c.fish = 3;
        c.meow();
    }
}
```

```text
小橘：喵～本喵今天吃了 3 条小鱼干
```

一行一行拆：

- **`class Cat { ... }`** —— 这一整块就是图纸，名字叫 `Cat`。**图纸不是猫**：它只是画着「一只猫长什么样」，自己不会叫、也不会吃鱼干。
- **`String name;` 和 `int fish;`** —— 图纸上写的两样**随身家当**：每只真猫生出来时都自带这两样，一个装名字、一个装今天吃了几条。**它们后面都没有小括号**，那是「摆东西的牌子」的写法，不是招式。
- **`void meow() { ... }`** —— 图纸上画的一招。写法就是 `12` 那课学的招式，**只差一样：前面没有 `static`**。
- **`Cat c = new Cat();`** —— 在 `main` 里**照着图纸生了一只真猫**，再拿一块叫 `c` 的牌子挂住它。`new` 就是「照图纸生一只」这个动作。
- **`c.name = "小橘";`** —— 给**这一只**真猫挂上名字。注意前面顶着 `c.`：动的是 `c` 挂着的那一只。
- **`c.meow();`** —— 让**这一只**真猫喊一嗓子。它喊的时候，用的是**自己**的名字和自己记的鱼干数。

图纸和 `main` 都写在同一个文件里，是能跑起来的：本喵在练习场里就是这么写的喵。（`public class` 那个名字要和存盘的文件名对上，这条规矩练习场会替你办 —— 见第七节。）

## 二、照着一张图纸，生一窝真猫

图纸画一次就够，想生几只就生几只：

```java
class Cat {
    String name;
    int fish;

    void eat(int n) {
        fish = fish + n;
    }
}

public class Main {
    public static void main(String[] args) {
        Cat c1 = new Cat();
        c1.name = "小橘";
        Cat c2 = new Cat();
        c2.name = "狸花";

        c1.eat(3);
        c2.eat(1);
        c1.eat(2);

        System.out.println(c1.name + " 吃了 " + c1.fish + " 条");
        System.out.println(c2.name + " 吃了 " + c2.fish + " 条");
    }
}
```

```text
小橘 吃了 5 条
狸花 吃了 1 条
```

`c1` 和 `c2` 是**两只不同的真猫**，各自带着自己的一套随身家当：

- `c1.eat(3)` 和 `c1.eat(2)` 加的是**小橘自己**的鱼干数：3 加 2，账上有 5 条。
- `c2.eat(1)` 加的是**狸花自己**的：狸花只吃了 1 条，小橘那两顿**一点没算到它头上**。
- 所以最后印出来：小橘 5 条、狸花 1 条。**图纸只画了一份，家当是每只猫各自带一套** —— 这就是画图纸最值钱的地方。

招式 `eat` 里那句 `fish = fish + n;` 用的是**谁喊就动谁**的家当：`c1.eat(3)` 动的是 `c1.fish`，`c2.eat(1)` 动的是 `c2.fish`。这一手能成立，全靠 `eat` 前面**没有 `static`**——第六节接着说这笔账喵。

## 三、出门之前，先看看图纸上的默认值

真猫生出来的时候，自带的牌子**不是空的**：

```java
class Cat {
    String name;
    int fish;
}

public class Main {
    public static void main(String[] args) {
        Cat c = new Cat();
        System.out.println(c.fish);
        System.out.println(c.name);
    }
}
```

```text
0
null
```

一只刚生出来、什么都没挂的猫：装数码的牌子默认是 `0`，装一串字的牌子默认是 `null`。

`null` 念「呐儿」，意思是**「里面什么都没有」**。它不是空字符串、也不是 0 —— 本喵要是没给猫挂名字就喊它，屏幕上印出来的就是 `null` 这四个字母喵（下一课会讲怎么在出生那一刻就把名字挂好）。

## 四、只写 `Cat c;` 还不算生了猫

本喵刚开始画图纸的时候，最爱忘的一件事：

```java
class Cat {
    String name;
}

public class Main {
    public static void main(String[] args) {
        Cat c;
        System.out.println(c.name);
    }
}
```

```text
Main.java:8: error: variable c might not have been initialized
        System.out.println(c.name);
                           ^
1 error
```

原话念起来是：**「牌子 `c` 可能还没装东西喵。」**

`Cat c;` 只是「本喵打算要一只 `Cat`」这个念头，**真猫还没生出来**。生猫的动作是 `new Cat()` —— 少了它，`c` 这块牌子就一直空着，翻译官一眼看出来，当场拦下，不让它带着这个窟窿往下跑。

**规矩：`Cat c = new Cat();` —— 牌子和 `new`，一口气写完。**

## 五、`static` 的老账：招式要跟着真猫走

`12` 那课学会自己写招式的时候，本喵发现 `main` 前面必须顶着 `static`，当时没细说为什么。现在可以还账了：

```java
class Cat {
    String name;

    void meow() {
        System.out.println("喵～");
    }
}

public class Main {
    public static void main(String[] args) {
        Cat.meow();
    }
}
```

```text
Main.java:11: error: non-static method meow() cannot be referenced from a static context
        Cat.meow();
           ^
1 error
```

念起来是：**「`meow()` 这一招不是 `static` 的，站在 `static` 的地方喊不动它喵。」** 两边都解释一下：

- `meow()` 是画在图纸上、**跟着每一只真猫走**的招式：它要动的是「**这一只**猫」的名字（名字撞了怎么办？谁喊就动谁）。可 `Cat.meow()` 这么喊，等于「连猫都没有就先喊一声」—— 它想动谁的名字，翻译官根本不知道。
- `main` 前面那个 `static` 是**另一层**意思：它不跟着任何一只真猫走，电脑一开演就直接从它开始，**不需要先有一只猫**。本喵站的这块地方是 `static` 的，所以喊不动一只不存在的猫的招式。

正路只有一条：**先生一只真猫，再让这只猫自己喊**。

```java
Cat c = new Cat();
c.name = "小橘";
c.meow();
```

`c.meow()` 和 `Cat.meow()` 差一个字，意思差得远：前者是「**小橘**，叫一声」，后者是「**猫这个种类**，叫一声」—— 后者连是谁都没说清，翻译官当然不答应喵。

## 六、`new Cat()` 背后那一手：构造方法初识

还有一个疑问没解：本喵在图纸里**一个招式都没写**，凭什么 `new Cat()` 就能生出一只猫来？

`new Cat()` 里那对小括号，喊的是**和图纸同名的一招** —— 术语里叫**构造方法**。它的脾气和别的招式不一样：

- 它在**真猫出生那一刻**跑一遍，负责把这只新猫收拾好（挂名字、记鱼干数这些开场活儿）。
- 它**没有 `void` 那一截**打头，名字还必须和图纸同名 —— 这两条是死规矩，写错了翻译官会翻脸（下一课本喵会当面撞给你看）。

**你一个都不写的时候，Java 会送你一个空手招式**：不喂料、也不干活，就等着 `new Cat()` 这么喊它 —— 所以上面那些例子里，本喵一次构造方法都没写，猫照样生得出来喵。

等本喵想让猫**一出生就带着名字**，写成 `new Cat("小橘")` 这样，就得自己动笔画这一手了。那是下一课的正题。

## 七、人名和文件名的小规矩

还有一条规矩要交代：**`public class` 的名字，必须和存盘的文件名一模一样。**

本喵真的拿电脑试过一次：把一只 `public class Cat` 存进名叫 `Main.java` 的文件里，翻译官的原话是：

`Main.java:1: error: class Cat is public, should be declared in a file named Cat.java`

念起来是「**`Cat` 是对外公开的图纸，就该住在名叫 `Cat.java` 的文件里喵**」。

这条规矩练习场**替你办好了**：它会先看你的代码里有没有 `public class`，有的话就按那个名字存盘，再拿去翻译。所以本喵课文里把图纸 `Cat` 和 `Main` 写在一个文件里，它存出来的就是 `Main.java` —— 你大概率一辈子也遇不上这句错喵。（要是哪天你写了个 `public class`、文件名却对不上，就是这一条在拦你。）

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `class Cat { ... }` | 画一张叫 `Cat` 的图纸 —— **图纸不是猫**，只是画着猫长什么样 |
| `String name;` / `int fish;` | 图纸上写的随身家当，每只真猫自带一套 |
| `void meow() { ... }` | 图纸上画的一招，**跟着每只真猫走**（前面没有 `static`） |
| `Cat c = new Cat();` | 照图纸生一只真猫，拿牌子 `c` 挂住它 |
| `c.name = "小橘";` | 给 `c` 挂着的**这一只**挂名字 |
| `c.meow();` | 让**这一只**自己做招式 |
| `c1` 和 `c2` | 两只不同的真猫，家当各带各的 |
| 刚生出来没挂东西 | 数码 `0`、一串字 `null` |
| 只写 `Cat c;` | 还没生猫 → `variable c might not have been initialized` |
| `Cat.meow();` | 没有猫就喊招式 → `non-static method ... cannot be referenced from a static context` |
| `new Cat()` | 照图纸生猫，同时喊一声和图同名的那一招（构造方法） |

::: tip 猫咪提示
今天记住三句话：

1. **图纸只画一次，真猫想生几只生几只**；每只真猫**自带一套**家当，谁喊招式就动谁的。
2. **先 `new` 再使唤**：`Cat c = new Cat();` 一口气写完，`Cat c;` 什么都不算。
3. **招式前面没有 `static`，就跟着真猫走**；`main` 前面有 `static`，它不跟任何真猫走 —— 想在 `main` 里用，就先生一只猫出来。
:::

::: warn 小心喵
三个最爱摔的地方：

- **图纸 ≠ 真猫**。`Cat` 不是猫，`new Cat()` 生出来的才是；图纸写好了不会自己叫。
- **`Cat.meow()` 这种喊法一律不行**（招式前面没有 `static` 的时候），要写成「牌子.招式()」，比如 `c.meow()`。
- **`null` 会一路传下去**：没挂名字的猫印出来是 `null`，不是一个字也没有；后面拿 `null` 的字去算，会炸出新花样（这门毛病本喵在第三阶段「Optional 与空值处理」那一课专门收拾它喵）。
