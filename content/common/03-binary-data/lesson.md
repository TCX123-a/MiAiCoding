## 钩子：本喵的鱼塘只有两格水

本喵有一口奇怪的鱼塘：水深只有两档——**满**和**空**。没有半满，也没有三分之一满。

听起来简陋得可怜？可电脑那口鱼塘就是这么简陋喵。它脑子里有千千万万个小格子，每一格只有两种状态：**通电**、**不通电**。写成数字，就是 `1` 和 `0`。

于是问题来了：这么两格水，怎么装得下「3 条小鱼干」、装得下「你好」、装得下本喵的名字？今天本喵就把这个魔术拆开给你看喵～

## 一格水就是一个「比特」

那个小格子，正式的名字叫**比特**（bit）。它只装得下 `0` 或者 `1`，别的什么都不行。

一格太少，什么都装不下。所以电脑把 **8 个格子捆成一组**，这一组叫一个**字节**（byte）：

```text
1 个比特：0
1 个字节：0 1 1 0 1 0 0 1      ← 8 个比特排成一排
```

8 个格子能排出多少种花样？每格两种可能，8 格就是 2×2×2×2×2×2×2×2 = **256 种**。从 0 数到 255 的整数，一个不落都能装下；英文字母的大小写、数字、标点，也全都够用喵。

## 只有 0 和 1，怎么数到 11？

我们平时用的是十进制：数到 9 就进位，写成 10。电脑的鱼塘只有两格水，所以它**数到 1 就得进位**：

```text
十进制      二进制
0           0
1           1
2           10         ← 满一格，进一位
3           11
4           100        ← 又满了，再进一位
5           101
```

二进制写起来长、念起来拗口，可规矩和十进制**一模一样**，只是「满几进位」不一样喵。10 在十进制里是十，在二进制里是二——同一个写法，两个意思，别混啦。

## 文字怎么装进去？给每个字编个号

数字好办，文字怎么办？

答案是：**给每个字编一个号**。「喵」这个字的编号是 55B5，电脑存「喵」的时候，存的其实就是这个号。这套「字 ↔ 号」的对照表，就叫**编码**。

那要占几个格子呢？跑一下就知道喵：

```python
print(len("喵".encode("utf-8")))
print(len("A".encode("utf-8")))
```

```text
3
1
```

一个汉字要 **3 个字节**（24 个格子），一个英文字母只要 **1 个字节**（8 个格子）。所以同样一句话，中文比英文占地方——这下你明白为什么短信按字数算钱的时候，中文总是更贵了吧喵～

## 四只翻译官喵都认 `0b`

写代码的时候，想直接用二进制写一个数，就在前面加 `0b`。四门语言都认这个前缀，因为它们说的本来就是同一件事：

```compare
c::
#include <stdio.h>

int main() {
    int n = 0b1011;
    printf("%d\n", n);
    return 0;
}

cpp::
#include <iostream>

int main() {
    int n = 0b1011;
    std::cout << n << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int n = 0b1011;
        System.out.println(n);
    }
}

python::
n = 0b1011
print(n)
```

```text
11
```

四份代码都写着 `0b1011`，跑出来都是 `11`——因为在哪门语言里，它指的都是同一个数喵。语言换来换去，底下的鱼塘是同一口。

那这四格水到底是**怎么数出 11 来的**？本喵把 `0b1011` 摊开，一格一格数给你看：


**数格子就两件事**：从右边数起，每往左一格分量翻一倍（1、2、4、8……）；通着电的格子把它的分量加进来，空着的格子一分不加。四格是这个规矩，8 格的一整个字节也是这个规矩喵。

::: tip 猫咪提示
今天只记三句话：**电脑只有 0 和 1 两种状态**；**8 个 0/1 捆成一个字节**；**文字靠「编号」存，那张对照表叫编码**。别的都忘了也没关系，这三句是地基喵～
:::

::: warn 小心喵
别去背 55B5 这种编号表！那是几万个字，背到下辈子也背不完，而且查一下就有。你要记住的是**「文字也是数字，只是编过号」**这个道理，不是那串号本身喵。
:::
