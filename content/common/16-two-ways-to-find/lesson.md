## 钩子：一千零二十四页的字典

本喵的字典有 1024 页，里面夹着一条写着自己名字的小鱼干。要把它翻出来，两只猫又吵起来了：

- **橘猫**：「从第 1 页开始，一页一页往下翻，总能翻到！」
- **狸花猫**：「我直接翻到中间那页看一眼，然后就知道该往前翻还是往后翻了。」

两只都说得头头是道。这一课就来看：这两种翻法各叫什么、各有什么讲究，还有——**狸花猫那一手，藏着一个前提到你未必想过**喵。

## 翻法一：一页一页往下翻

一页一页往下翻，正式的名字叫**线性查找（一页一页往下翻）**。

它有一个大好处：**不挑东西**。字典是排好的也好、乱成一团的也好，它都能翻到——因为它是挨个儿看过去的，谁也不跳过。

它的代价也写在脸上：**要翻多少页，全看你要找的东西在第几页**。运气最好时第 1 页就翻到，运气最差时得翻完 1024 页。本喵按最差情况算账（上一课的老规矩：数次数，不看运气）：

> 一页一页翻，最多翻 **1024** 次

## 翻法二：掐中间翻

狸花猫那一手，正式的名字叫**二分查找（掐中间翻）**。它的做法是：

1. 先掐到**正中间**那页看一眼。
2. 是它 → 收工。
3. 要找的排在它**后面** → 前面那半本**整片扔掉**，只在后半本里继续掐中间。
4. 要找的排在它**前面** → 后半本整片扔掉。

每看一眼就扔掉一半。1024 页够扔几次喵？

> 1024 → 512 → 256 → … → 2 → 1，**只够扔 10 次**

一页一页翻最多 1024 次，掐中间翻最多 10 次——**一百倍的差距**。

## 那个前提：字典得先是排好的

现在说狸花猫藏在袖子里的那一手。

掐中间翻之所以管用，全靠一件事：**字典的页是按顺序排好的**——前面的都比中间那页靠前，后面的都比它靠后。

要是字典乱着放呢？你翻开中间看到「猫」，可你要找的「鱼」到底在它前面还是后面——**你一点都不知道**。不知道往哪边走，那一半就扔得毫无道理，扔错了就永远找不到了。

所以二分有一个**硬前提**：

::: warn 小心喵
**东西必须先是排好的，掐中间翻才成立。**

乱着放的字典、没排过的一排碗，只能一页一页翻（线性查找）。这也正是下一课「排排坐的三条路」要紧的地方——**排好，是后面很多巧办法的地基**；下一课就专门讲讲怎么排喵。
:::

## 6 只碗：掐中间，三眼就中

拿一排排好的碗试试手：`[3, 7, 9, 12, 20, 31]`（从小到大），本喵要找 **12**。

| 看第几眼 | 还剩下几只碗 | 中间那只是 | 下一步 |
|---|---|---|---|
| 第 1 眼 | 0~5 号，6 只 | 2 号碗：**9** | 9 比 12 小 → 0、1、2 号整片扔掉 |
| 第 2 眼 | 3~5 号，3 只 | 4 号碗：**20** | 20 比 12 大 → 4、5 号扔掉 |
| 第 3 眼 | 3~3 号，1 只 | 3 号碗：**12** | 就是它，收工！ |

三眼就中。同样找 12，一页一页翻得看 4 只碗（3、7、9、12）——**六只碗的时候，两种翻法差不多**（一个 3 次、一个 4 次）。碗少的时候显不出本事，这是上一课刚说过的老话喵。

把账算大一点，让机器念一遍：

```python
pages = 1024
layers = 0
while pages > 1:
    pages = pages // 2
    layers = layers + 1
print("一页一页翻，最多 1024 次")
print(f"掐中间翻，最多 {layers} 次")
```

```text
一页一页翻，最多 1024 次
掐中间翻，最多 10 次
```

## 四位翻译官喵，数一数翻了几页

一页一页翻要翻几次？让四位翻译官喵各数一遍（这一排排好的碗里找 12）：

```compare
c::
#include <stdio.h>

int main() {
    int bowls[6] = {3, 7, 9, 12, 20, 31};
    int looks = 0;
    for (int i = 0; i < 6; i++) {
        looks++;
        if (bowls[i] == 12) break;
    }
    printf("一页一页翻，翻了 %d 次\n", looks);
    return 0;
}

cpp::
#include <iostream>

int main() {
    int bowls[6] = {3, 7, 9, 12, 20, 31};
    int looks = 0;
    for (int i = 0; i < 6; i++) {
        looks++;
        if (bowls[i] == 12) break;
    }
    std::cout << "一页一页翻，翻了 " << looks << " 次" << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int[] bowls = {3, 7, 9, 12, 20, 31};
        int looks = 0;
        for (int i = 0; i < 6; i++) {
            looks++;
            if (bowls[i] == 12) break;
        }
        System.out.println("一页一页翻，翻了 " + looks + " 次");
    }
}

python::
bowls = [3, 7, 9, 12, 20, 31]
looks = 0
for i in range(6):
    looks = looks + 1
    if bowls[i] == 12:
        break
print(f"一页一页翻，翻了 {looks} 次")
```

```text
一页一页翻，翻了 4 次
```

四段念出来是同一句：翻到 12 用了 **4 次**（3、7、9、12）。换成掐中间翻只要 3 眼——六只碗上确实差不多；**一百倍的差距，要等字典厚到 1024 页才显出来**喵。

::: tip 猫咪提示
拿到「在一堆东西里找一个」的活儿，先问两句话：

1. **这堆东西排好了吗？** 排好了 → 掐中间翻（二分查找）；没排 → 只能一页一页翻。
2. **翻法贵不贵？** 数最差情况下要翻几次，别数运气好的那一次。

顺带记住这个手感：**每次砍掉一半**——上一课的狸花猫用的也是这一手喵。
:::

::: warn 小心喵
两个坑，都跟「一半」有关：

- **没排好就掐中间**：扔错了半边，找的东西就永远找不回来了。二分的前提绝不是可选项。
- **边界糊了**：本喵这里掐中间后是 `left = mid + 1`，不是 `left = mid`——因为中间那只**已经看过了**，再看一遍就是白费一趟，写错还会绕不出圈。第一次学二分的人，几乎都在这儿绕过圈喵。
:::
