## 钩子：大肥鱼听不听得懂喵？

想象一下：本喵的好朋友大肥鱼——那条圆滚滚的蓝色大鱼——正躺在鱼塘边晒太阳。本喵想让它翻个身，拍拍它：「大肥鱼，翻个身喵～」它「扑通」一声翻了过去。

现在把「大肥鱼」换成电脑。电脑和猫不一样：只听得懂**指令**——一条条写得清清楚楚的动作说明。把这些指令攒成清单，就是**程序**；写下清单的你，就是**程序员**喵。

一句话总结：**编程，就是把你想让电脑做的事，写成电脑看得懂的指令清单。**

## 程序：给电脑的行动手册

程序就是一份行动手册。电脑执行时，从上到下一条条照做，绝不偷懒，也绝不自作主张。

来看一份「喂猫手册」：

```text
1. 拿起小鱼干
2. 走到猫粮碗旁边
3. 把小鱼干放进碗里
4. 喊一声：开饭啦喵！
```

电脑执行程序就是这样，一步接一步，这就是最基本的形态——**顺序执行**。往后本喵还会教它自己选路（看鱼干眼色行事）、重复干活（绕鱼干跑圈），别急喵～

空口说「一条条照做」还是太抽象，本喵把这份手册放慢，一步一步走给你看：

## 电脑只懂 0 和 1，怎么办？

电脑的脑子其实很死板：只认识 0 和 1 组成的机器语言。要是让你直接写 010101……大概会像被踩了尾巴一样跳起来。

于是人类发明了**编程语言**——长得像英语，写起来舒服多啦。可电脑读不懂代码呀！这时候**编译器（翻译官喵）**出场：你写好代码，它负责翻成电脑能听懂的机器语言。还有一种**解释器（翻译官喵）**，边读代码边马上执行。

记住分工：**你负责写代码，翻译官喵负责传话，电脑负责干活。** 以后学 C、C++、Java、Python，天天打交道喵～

## 四只翻译官喵一起说「你好」

同一个「打印你好」的小任务，四种语言写出来长这样，只需要看个眼熟、感受下气质，不用背喵～

```compare
c::
#include <stdio.h>

int main() {
    printf("你好，喵！\n");
    return 0;
}

cpp::
#include <iostream>

int main() {
    std::cout << "你好，喵！" << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        System.out.println("你好，喵！");
    }
}

python::
print("你好，喵！")
```

瞧，Python 一行就搞定，C 语言要「铺床叠被」准备半天。气质不同，做的都是同一件事——**打印一句话**喵。

## 先认一个最小的招式：`print`

上面四段代码都在干同一件事：让电脑**念一句话**出来。四门语言喊这个招式的方式不一样，今天只认最省事的那个——Python 的 `print`：

```python
print("喵！")
```

```text
喵！
```

拆开看，它是三样东西拼起来的：

1. **`print`** —— 招式的名字，意思是「把东西印出来」。名字得**一个字母都不差**地写对：写成中文的「打印」，翻译官喵不认识这个名字，会告诉你「找不到」。
2. **一对小括号 `( )`** —— 投喂的口子。想让电脑念什么，就把它塞进这对括号里。
3. **一对引号 `" "`** —— 圈出这句话的**边界**。引号里的内容电脑原样念出来，而**引号本身不念**。

所以 `print("喵！")` 打出来的就是 `喵！` 这两个字符，前后没有引号喵。

那要是漏了引号呢？写成 `print(喵！)`，电脑会把 `喵！` 当成一个**名字**去找——仓库里压根没有叫这个名字的东西，它只好报错。**加不加引号，就是「一句话」和「一个名字」的分界**：引号里的是内容，引号本身不是内容。这一条往后天天要用，先记住喵。

::: tip 猫咪提示
今天只记住三件事：**编程 = 写指令清单**；**程序 = 电脑的行动手册**；**翻译官喵 = 替你传话**。以后每学一个新词，本喵都先讲个小故事，再告诉你它本来的名字喵～
:::
