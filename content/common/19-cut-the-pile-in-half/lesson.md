## 钩子：两根鱼干，怎么切成一样长

本喵今天有两根小鱼干，一根长 **1071** 毫米、一根长 **462** 毫米。本喵想把它俩都切成**一样长的小段**，一根不许剩，而且**每段尽可能长**。

每段切多长喵？

这个问题老得掉渣——两千多年前的猫就在算了。它有个拗口的名字叫**最大公约数**，本喵管它叫「两根鱼干能切出的最长尺子」：**能同时把 1071 和 462 都量尽的那把最长尺子，有多长。**

答案是 21 毫米。可本喵关心的是：**老祖宗是怎么算出来的？** 这一课要拜见两位老祖宗——一位用「减」，一位用「除」，说到底是同一招喵。

## 老祖宗一号：大的减小的

中国古代的《九章算术》里记着一招**更相减损术**，做法朴素得可爱：

> 两根都还没一样长？**拿长的减去短的**，把结果顶替长的。一直减到两根一样长——那个数就是答案。

本喵拿 1071 和 462 走一遍：

| 长的 | 短的 | 减一次之后 |
|---|---|---|
| 1071 | 462 | 1071 - 462 = 609 |
| 609 | 462 | 609 - 462 = 147 |
| 462 | 147 | 462 - 147 = 315 |
| 315 | 147 | 315 - 147 = 168 |
| 168 | 147 | 168 - 147 = 21 |
| 147 | 21 | 147 - 21 = 126 |
| 126 | 21 | 126 - 21 = 105 |
| 105 | 21 | 105 - 21 = 84 |
| 84 | 21 | 84 - 21 = 63 |
| 63 | 21 | 63 - 21 = 42 |
| 42 | 21 | 42 - 21 = 21 |

减到两根都是 21，收工。**答案 21 是对的**——可你数数看，减了 **11 次**。短的那根是 21，长的 147 里能装 7 个 21，它就这么一次一份地减了 7 次，太磨爪子了喵。

## 老祖宗二号：一次减到底

两千三百年前，古希腊的欧几里得换了个想法：**既然「一次减一份」要减好多次，那干脆一次把它减到底——剩下的那点数，不就是余数吗？**

于是这一招变成：

> 用大的**除以**小的，留下**余数**；然后把「小的」和「余数」凑成新的一对，接着除。除到**余数是 0** 为止——那时候，除数就是答案。

还是那两根鱼干，走一遍：

| 这一步算 | 商 | 余数 | 换成哪一对 |
|---|---|---|---|
| 1071 ÷ 462 | 2 | **147** | 换成（462, 147） |
| 462 ÷ 147 | 3 | **21** | 换成（147, 21） |
| 147 ÷ 21 | 7 | **0** | 余 0！收工 |

**三步**就出了答案 21。上一招减了 11 次，这一招 3 次——差别在哪喵？看第一行：`1071 - 462` 要减 **2 次**才到 147，而 `1071 ÷ 462` 一次就把「能减的全减掉」，直接得到 147。**除法不过是「一次减到底」的偷懒写法**，两招算的是同一笔账。

## 为什么「减小的」管用

看一个具体例子就明白了喵：假设有一把尺子能同时量尽 1071 和 462——它每一下量出的长度都一样，两根鱼干都由整数个「一下」拼成。

那么从这个等式看：

> 1071 - 462 = 609

1071 能拆成整数个「一下」，462 也能拆成整数个「一下」——那它俩的差 609，**当然也是整数个「一下」**。所以：**新的那对数（462 和 609）照样能被这把尺子量尽**——不过换了一对数字，尺子的长度一点没变。

一直换下去，数字越来越小，可尺子始终没变；等两根短到一样长，那把尺子的长度就摆在脸上了。**这就是老祖宗的招为什么管用**喵。

## 落到代码上

```python
a = 1071
b = 462
while b != 0:
    r = a % b
    a = b
    b = r
print(a)
```

```text
21
```

`a % b` 就是「a 除以 b 剩下的那点数」（余数）。圈里干的事就三下：**算余数 → 短的变成长的 → 余数变成新的短的**。等 `b` 变成 0（除尽了），`a` 里装的就是那把最长尺子喵。

## 老祖宗还有别的招式

课标里点名的不止欧几里得一位喵。顺手认个脸熟：

- **割圆术**（中国的刘徽、祖冲之）：算不出圆的周长？那就往圆里塞正多边形——六边形、十二边形、二十四边形……**边数一圈一圈翻倍**，多边形越来越像圆。祖冲之算到一万两千多条边，把圆周率夹在 3.1415926 和 3.1415927 之间。这一手，跟本喵这个「一对数字越换越小、但尺子不变」的套路，是同一个味道：**摸不到真东西，就一圈一圈逼近它**。
- **秦九韶的算法**：算一个层层嵌套的式子的值，一位祖先传下来一层套一层的算法，比老老实实一项一项算省下大把力气。

老祖宗留下的这些招，如今还活在每一台电脑里——它们不靠机器快，靠的是**想法巧**喵。

## 四位翻译官喵，同一把尺子

```compare
c::
#include <stdio.h>

int main() {
    int a = 1071;
    int b = 462;
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    printf("1071 和 462 的最长尺子是 %d\n", a);
    return 0;
}

cpp::
#include <iostream>

int main() {
    int a = 1071;
    int b = 462;
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    std::cout << "1071 和 462 的最长尺子是 " << a << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int a = 1071;
        int b = 462;
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        System.out.println("1071 和 462 的最长尺子是 " + a);
    }
}

python::
a = 1071
b = 462
while b != 0:
    r = a % b
    a = b
    b = r
print(f"1071 和 462 的最长尺子是 {a}")
```

```text
1071 和 462 的最长尺子是 21
```

四段是同一个套路：**算余数、短的顶上来、余数接上去**——四位翻译官喵的写法几乎一个字不差。两千多年前的招，今天照样能用喵。

::: tip 猫咪提示
1. **「算多少遍」是可以数的**（上一课的老规矩）：减法是「一次减一份」，欧几里得是「一次减到底」——同一笔账，一个笨、一个巧。
2. **两数越换越小，答案却不变**：这是老祖宗招式里的「把问题变小」（上一课的规矩）——招式能停下来，靠的就是数字一直在变小，最后归零。
:::

::: warn 小心喵
两个坑：

- **顺序别换**：得是 `a = b` 先、`b = r` 后。要是先写了 `b = r` 再写 `a = b`，那就是拿新的 b 去顶替 a，两个仓库里会装成同一个数——「排排坐的三条路」那一课换碗那个坑，换了个地方又出现了喵。
- **余数是 0 不等于没答案**：看到「余 0」别以为算出错了——恰恰相反，那是收工的信号，这时候 a 里装的 21 才是答案。倒是要小心一开始就写错：**要是 b 一上来就是 0**，圈一次都不进，答案是 a 本身（「任何数和 0 的最长尺子，就是它自己」）——这个边界值，值得自己动手试一遍喵。
:::
