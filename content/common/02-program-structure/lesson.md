## 钩子：光说「搭个猫窝」是搭不起来的

本喵想给大肥鱼搭个猫窝。要是只丢给它一句话——「你去搭个猫窝」——它准会歪着脑袋看本喵半天：搭哪儿？用什么搭？先钉哪块板子喵？

可要是把话拆成这样一条条往下排：

```text
1. 找一块 30 厘米见方的木板
2. 把木板钉在墙角，离地半米
3. 铺上一条旧毛巾
4. 把大肥鱼抱进去
```

它就能一路做到底，不用再问一句。**这就是程序的样子：把一件事拆成一条条按顺序排好的动作说明。**

上一课我们说「程序 = 指令清单」。今天本喵带你把这本清单翻开，看看一份**完整的**清单到底由哪几块拼起来喵～

## 第一块：指令得**排好队**

电脑读程序，是从上往下**一条都不跳**地读。所以指令排队的顺序，就是事情发生的顺序。

```python
print("拿起小鱼干")
print("走到猫粮碗旁边")
print("把小鱼干放进碗里")
print("开饭啦喵！")
```

```text
拿起小鱼干
走到猫粮碗旁边
把小鱼干放进碗里
开饭啦喵！
```

把第二行和第三行调个个儿，程序照样跑得起来——只是变成「人还没到碗边，小鱼干就先飞过去了」。**电脑不会替你检查顺序合不合理，它只会照着做。**

这四条指令到底是怎么一条接一条走完的？本喵把它拆成一步一步，走给你看：


**电脑的读法就这一条**：一条做完了才轮到下一条，中间不跳、不抢，也不回头。所以那四行代码换了顺序，屏幕上那四行字也跟着换顺序 —— 「指令排队的顺序，就是事情发生的顺序」，说的就是这件事喵。

## 第二块：总得有个门——**入口**

猫窝不能没有门，程序也一样：得有一个明确的**入口**。电脑从这扇门进去，然后一条条往下做，做完就收工。

四门语言里，这扇门长得不太一样：

```text
C / C++    int main() { ... }                          门叫 main
Java       public static void main(String[] args) { ... }   门也叫 main，但裹得厚些
Python     从文件第一行开始跑，不用写门
```

Python 是个特例喵：它没有那扇明晃晃的门，**第一行就是入口**。别的语言都得先找到门，才肯开工——门写错了，翻译官喵会直接说「找不到入口」，一行都不给你跑。

## 第三块：一条指令 = 一句**话**

清单里的每一条，写进代码就叫一条「语句」。语句和中文的句子一样，得有东西收尾：

- **C / C++ / Java**：每条语句结尾要写一个分号 `;`
- **Python**：每条语句独占一行，靠**换行**收尾

少写一个分号，翻译官喵会当场拦下来，指着那一行告诉你「这里少了个东西」。这是新手最常见的第一个报错，撞上了不用慌喵。

## 第四块：写给猫看的便条——**注释**

有些话你并不想让电脑做，只是想写给自己看：这块是干嘛的、当时为什么这么写。那就写成**注释**。电脑读到注释**直接跳过**，当它不存在：

```python
# 这一行是注释，电脑看都不看
print("只有这行会被执行")   # 行尾也能挂一句注释
```

```text
只有这行会被执行
```

注释不干活，但它是最省事的备忘方式。三个月后你回来翻这段代码，全靠它救命喵～

## 四只翻译官喵，同一个猫窝

同一个「打印三行喂猫流程」的小程序，四种语言写出来长这样。这回留意两件事：**门在哪儿**、**每条语句怎么收尾**喵～

```compare
c::
#include <stdio.h>

int main() {
    printf("拿起小鱼干\n");
    printf("放进碗里\n");
    printf("开饭啦喵！\n");
    return 0;
}

cpp::
#include <iostream>

int main() {
    std::cout << "拿起小鱼干" << std::endl;
    std::cout << "放进碗里" << std::endl;
    std::cout << "开饭啦喵！" << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        System.out.println("拿起小鱼干");
        System.out.println("放进碗里");
        System.out.println("开饭啦喵！");
    }
}

python::
print("拿起小鱼干")
print("放进碗里")
print("开饭啦喵！")
```

```text
拿起小鱼干
放进碗里
开饭啦喵！
```

四份代码长得差挺多，可干的是同一件事，打印出来的字**一模一样**喵。差别全在刚才那两块上：C 要写 `int main()` 才有门、Java 的门裹了三层、Python 连门都省了；至于收尾，C/C++/Java 条条带分号，Python 全靠换行。

::: tip 猫咪提示
今天记住四块就够：**指令要排队**、**程序要有入口**、**语句要有收尾**、**注释是写给猫看的**。四门语言的门和收尾写得不一样，但那四块骨头是一样的喵～
:::

::: warn 小心喵
别急着背 `main` 外面那一圈括号和关键字！现在只要认得「**这行是门**」就够了。写多少遍自然会记住，死记硬背反而容易吓着自己喵。
:::
