## 钩子：本喵的猫饭，煮成了一锅黑炭

本喵照着清单煮猫饭：烧水、放小鱼干、等三圈、盛出来。结果端上桌的是一锅黑炭喵。

清单是本喵自己写的，每一步看着都对，可结果就是不对。这时候最没用的做法是**盯着锅生气**；第二没用的是**把整锅倒掉重来**。真正管用的只有一个：**顺着痕迹，把那只捣乱的小虫找出来**。

程序里的「小虫」也一样。它们有个名字，叫 **bug**；把虫子揪出来这件事，术语表里叫**调试（抓虫）**。

## 什么是 bug：虫子有三种脾气

虫子不是只有一种。本喵把它们分成三窝喵：

| 虫子的脾气 | 长什么样 | 本喵怎么发现它 |
|---|---|---|
| **不让本喵开工的** | 翻译官喵当场翻脸，甩你一段红字 | 连运行都点不下去，一眼就看见了 |
| **半路掀桌子的** | 程序跑到一半，突然停住报错 | 屏幕上会留下它掀桌的地方 |
| **最阴的：不吭声的** | 程序跑得欢，答案却是错的 | **它不报错，得本喵自己看出来** |

第三窝最麻烦，因为它跟前两窝不一样：**没有红字提醒你**。你让它算十只猫的小鱼干，它交给你一个 8，看着像跑通了，其实是它接错了 —— 本喵在讲「投喂与叼回」那一课就撞上过这样一只虫子（`"3"` 接 `"3"` 变成 `33`，程序一声没吭）喵。

所以抓虫的第一句口诀是：**「跑通了」不等于「对了」。**

## 第一步：二分排查 —— 一次砍掉一半

虫子藏在哪儿？本喵手上是一段一百行的代码，不知道哪一行出的问题。

最笨的办法是从第一行开始一行行看。聪明的办法叫**二分排查**喵：

1. 先看**正中间**那一行：跑一跑前半截，看结果对不对。
2. 前半截就不对 → 虫子在前半截，**后半截五十行一次砍掉**。
3. 前半截是对的 → 虫子在后半截，前半截那五十行也不用看了。
4. 剩下五十行，再砍一半，剩二十五行……一百行砍七次，就只剩一行了。

这跟本喵找偷吃的小猫一模一样：先在猫爬架中间那层看一眼，听见上面有动静，下面半边就不用翻了喵。

**为什么是「砍一半」而不是「一行行看」**：一行行看，一百行最坏要看一百次；砍一半，七次就到。**每砍一次，可疑的地方就少一半** —— 这是抓虫最省力的一招。

## 第二步：插一句 print，让程序自己说话

知道虫子藏在哪一小段了，可它到底怎么错的？这时候本喵请出 `print` 喵。

本喵想算 1 + 2 + 3，程序交上来的却是 3。它不报错，本喵也没看出哪儿歪了 —— 那就**让程序自己把话说明白**：在关键的地方插一句 `print`，把中间的结果念出来。

```python
total = 0
for i in range(1, 3):
    total = total + i
    print("第", i, "圈：total =", total)
print(total)
```

```text
第 1 圈：total = 1
第 2 圈：total = 3
3
```

看出不对劲了吗喵：本喵心里念的是「跑**三**圈」，可屏幕上**只念了两圈**！第三圈压根没跑，`total` 也就停在 3。

虫子露头了 —— 它就住在 `range(1, 3)` 那个 `3` 上喵。`range(1, 3)` 的意思是「从 1 数起，数到 3 就停，3 不算」，所以 `i` 只拿到 1 和 2。把它改成 `range(1, 4)`，第三圈就回来了：

```python
total = 0
for i in range(1, 4):
    total = total + i
    print("第", i, "圈：total =", total)
print(total)
```

```text
第 1 圈：total = 1
第 2 圈：total = 3
第 3 圈：total = 6
6
```

三圈齐了，`total` 一路跑到 6 —— 虫子抓住了，也修好了喵。

（顺带记一句：`print` 里**逗号的位置会各垫一个空格**，所以念出来才是 `第 1 圈：total = 1` 这个样子，不是本喵手滑多敲了空格。）

**插 `print` 的诀窍**：别乱插，要插在**「本喵以为这里应该变成某个数」的地方**。心里先写一句「跑到这儿应该是 6」，跑出来却是 3 —— 虫子就住在这两句 `print` 中间喵。

## 第三步：讲给大肥鱼听

本喵还有一招，专门对付那种「怎么看都看不出错」的虫子：**把代码从头讲一遍 —— 讲给大肥鱼听。**

```text
【本喵】大肥鱼你听好喵：这一行是「把 i 从 1 数到 3」。
【大肥鱼】……（吐了个泡泡）
【本喵】这一行是「把 i 攒进 total 里」。
【大肥鱼】……（又吐了个泡泡）
【本喵】等一下！！「数到 3」到底算不算 3 呀？
```

讲着讲着，本喵自己就卡住了 —— **卡住的那一句，就是虫子住的地方**。大肥鱼一个字都没说，可它那双圆眼睛就是最好的抓虫工具喵。

（这一招在外面有个更出名的名字：对着桌上的一只**橡皮鸭**讲。本喵喜欢讲给大肥鱼听，因为它听得懂猫话。）

::: tip 猫咪提示
抓虫三步走，背下来就是你的了喵：

1. **先二分** —— 把可疑的地方一次次砍半，先弄清虫子住在哪一小段；
2. **再插 `print`** —— 让程序把中间结果自己念出来，虫子就现形了；
3. **最后讲给大肥鱼听** —— 一句一句讲「本喵以为它在干什么」，卡住的那句就是虫子。

还有一句口诀要记牢：**「跑通了」不等于「对了」** —— 最阴的虫子一声不吭喵。
:::

::: warn 小心喵
`print` 是抓虫的工具，不是装饰品。虫子抓到、修好之后，那些插进去的 `print` 记得**收干净** —— 不然交上去的程序会莫名其妙多出一堆字，下一个看它的人（或者三天后的你自己）又得抓一次虫喵。

还有一点：**别一上来就改代码**。先看清虫子住在哪儿，再动手；东改一处西改一处，虫子没抓到，新虫子倒是养了一窝喵。
:::

## 四位翻译官喵一起插 print

同一件事：绕三圈，每一圈把当前的总数念出来。四位翻译官喵写出来长这样，看个眼熟就行喵：

```compare
c::
#include <stdio.h>

int main() {
    int total = 0;
    for (int i = 1; i <= 3; i++) {
        total = total + i;
        printf("第 %d 圈：total = %d\n", i, total);
    }
    return 0;
}

cpp::
#include <iostream>

int main() {
    int total = 0;
    for (int i = 1; i <= 3; i++) {
        total = total + i;
        std::cout << "第 " << i << " 圈：total = " << total << std::endl;
    }
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int total = 0;
        for (int i = 1; i <= 3; i++) {
            total = total + i;
            System.out.println("第 " + i + " 圈：total = " + total);
        }
    }
}

python::
total = 0
for i in range(1, 4):
    total = total + i
    print(f"第 {i} 圈：total = {total}")
```

```text
第 1 圈：total = 1
第 2 圈：total = 3
第 3 圈：total = 6
```

四段跑出来**一模一样**喵。你会发现一个有意思的地方：C、C++、Java 都写 `i <= 3`（从 1 数到 3，**算** 3），Python 却写 `range(1, 4)`（从 1 数起，到 4 就停）—— 一个说「数到几」，一个说「数到几之前停」。**这两个数的差一，正是本喵刚才那只虫子最爱藏的地方**喵。
