## 钩子：出门前，先看一眼天

本喵今天想出门晒太阳，先趴到窗边往外瞄一眼：天色亮堂堂的，那就空着手出门；要是黑压压的，就叼上伞再走。这一眼，本喵管它叫**看眼色**。

电脑也天天在看眼色喵。同一个猫粮碗，有鱼干的时候要开吃，空的时候要跑去找大肥鱼——**先看一眼，再决定走哪条路**。这招在编程里就叫**看鱼干眼色行事（条件判断）**，是本喵今天要教你的看家本领。

## if：先问一句，再决定做不做

看鱼干眼色行事的最小写法长这样：

```python
fish = 3

if fish > 0:
    print("碗里还有鱼干，开吃喵")
else:
    print("碗空了，去找大肥鱼喵")
```

```text
碗里还有鱼干，开吃喵
```

就三件事，拆开看：

1. **眼色**：`fish > 0`。这是本喵要问电脑的一句话——「碗里的数比 0 大吗？」
2. **为真走的路**：`if` 下面缩进的那一句。眼色答「真」，才轮到它上场。
3. **为假走的路**：`else` 下面缩进的那一句。眼色答「假」，就改走这里。

Python 有两条死规矩：眼色后面那个**冒号 `:`** 一个都不能少；行首的**缩进**（那几格空白）也不能乱——电脑就是靠缩进分清「哪句话归哪条路管」的喵。

还有一条不是死规矩、但顶重要的：**`else` 那条路可以不写**。不写的话，眼色答「假」就**什么都不做**，眼睛一闭直接跳到这个眼色管不着的地方，继续往下跑。所以光杆一个 `if` 是很常见的写法——本喵今天先写全，让你看清两条路各自长什么样，往后你会经常只写 `if` 喵。

这三件事到底谁先谁后，本喵拆成一步一步，走给你看：

**记住这两拍**：电脑先把眼色**算成一个答案**（真或者假），**再**拿这个答案去挑路；挑中的那条走完，另一条路从头到尾**一行都没碰**。

## 真与假：电脑只有两种脸色

本喵问的是「比 0 大吗」，电脑可不会答「大概吧」「看心情」，它只答两种：**真**或者**假**。

| 写 | 本喵问的话 | 什么时候答「真」 |
|---|---|---|
| `>` | 左边比右边大吗 | 左边确实更大 |
| `<` | 左边比右边小吗 | 左边确实更小 |
| `>=` | 大于，或者等于吗 | 满足其中一个就算 |
| `==` | 两边一样吗 | 一模一样才算 |
| `!=` | 两边不一样吗 | 只要不一样就算 |

这两个脸色，本喵可以当场喊出来给你看：

```python
fish = 3

print(fish > 0)
print(fish == 5)
```

```text
True
False
```

`True` 就是真，`False` 就是假。它们是电脑的两种脸色，也是往后每节课都要打招呼的老朋友喵。

## 四只翻译官喵一起看眼色

同一个「碗里还有鱼干吗」的小判断，四门语言写出来长这样：

```compare
c::
#include <stdio.h>

int main() {
    int fish = 3;
    if (fish > 0) {
        printf("碗里还有鱼干喵\n");
    } else {
        printf("碗空了喵\n");
    }
    return 0;
}

cpp::
#include <iostream>

int main() {
    int fish = 3;
    if (fish > 0) {
        std::cout << "碗里还有鱼干喵" << std::endl;
    } else {
        std::cout << "碗空了喵" << std::endl;
    }
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int fish = 3;
        if (fish > 0) {
            System.out.println("碗里还有鱼干喵");
        } else {
            System.out.println("碗空了喵");
        }
    }
}

python::
fish = 3

if fish > 0:
    print("碗里还有鱼干喵")
else:
    print("碗空了喵")
```

看出来了吗：C、C++、Java 都要把眼色**包在一对括号里**，而 Python 不用括号，改用冒号加缩进。气质不同，做的都是同一件事喵。

::: tip 猫咪提示
记住三步就够啦：**问一句**（写出眼色）、**选一条**（走 if 那条路还是 else 那条路）、**动手做**（缩进里那几句话）。写代码之前先用中文在心里念一遍「如果……就……，否则就……」，念顺了，代码自然就写出来了喵～
:::

::: warn 小心喵
最容易摔跤的地方是 `=` 和 `==` 分不清：`=` 是「把右边装进左边的罐子」，`==` 才是「两边一样吗」。问眼色的时候写成单个等号，电脑会当场犯难，甩你一段报错喵。
:::
