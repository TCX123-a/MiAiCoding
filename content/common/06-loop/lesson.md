## 钩子：一百条小鱼干，难道要写一百行？

本喵要请全鱼塘的猫吃小鱼干，一共 **100 条**。一条一条写「放一条」「再放一条」，得写一百行，爪子都要敲酸了喵。

更气猫的是：这一百行**一模一样**，只有「第几条」不一样。电脑最擅长「同一个动作重复很多遍」——本喵居然在替它干！

于是前辈猫传下一招：**叫电脑自己数圈**，术语表里管它叫**循环（绕鱼干跑圈）**——今天的主角喵。

## 把「重复」交给电脑

绕鱼干跑圈说白了就一句话：**同一套动作只写一遍，让电脑替你跑很多遍。**

跑一圈 = 做完一次动作；跑三圈 = 同一个动作做三次。写代码时只要说清两件事：

1. **要跑几圈**，或者**跑到什么地步就停**；
2. **每一圈里做什么**。

剩下的数数活儿全归电脑管喵。而「跑到什么地步就停」这一条，靠的正是昨天学的**看鱼干眼色行事**。

## for：数得清圈数的时候

先看最省心的一种：本喵**明明白白知道**要发 3 条。

```python
for i in range(3):
    print("发一条小鱼干喵")
```

```text
发一条小鱼干喵
发一条小鱼干喵
发一条小鱼干喵
```

拆开读：

- **`range(3)`**：数出三个数——0、1、2。
- **`for i in range(3)`**：每圈领一个数装进 `i` 这只小鱼干仓库，再跑一遍缩进里的话。

`for` 的脾气是「**心里有数**」：圈数开跑前就定好，跑满就收工。想报出自己是第几圈，就把 `i` 喊出来：

```python
for i in range(3):
    print("第", i + 1, "圈喵")
```

```text
第 1 圈喵
第 2 圈喵
第 3 圈喵
```

这里有两个小机关，都值得多看两眼：

- **`i` 是从 0 开始数的**，想显示「第 1 圈」就得写 `i + 1`。
- **`print` 用逗号隔开的东西，电脑会在中间垫上一个空格再印出来**。所以 `"第"`、`i + 1`、`"圈喵"` 三样拼出来是 `第 1 圈喵`——逗号的位置上各有一个空格，不是 `第1圈喵`。这条规矩往后天天用得上（本喵在「小鱼干仓库」那一课讲 `print` 时也是靠它拼出来的喵）。

## while：数不清圈数的时候

有些活儿本喵**事先数不清**：碗里还剩几条鱼干，本喵懒得数，只认一条规矩——「碗里还有，就接着发。」

这时候用 `while`：**每跑一圈之前先看一眼眼色，答「真」才继续跑。**

```python
fish = 3

while fish > 0:
    print("碗里还有，发一条喵")
    fish = fish - 1
```

```text
碗里还有，发一条喵
碗里还有，发一条喵
碗里还有，发一条喵
```

跟着念一遍：`fish` 是 3 → 发一条、`fish` 变 2；2 比 0 大 → 又发一条、`fish` 变 1；再发一条、`fish` 变 0。第四次瞄时眼色终于答「假」，圈停了，正好三条喵。

`while` 的圈数**不是提前定死的**，每一圈都由眼色现算——那句 `fish = fish - 1` 正是**让圈能停下来**的关键喵。

## 停不下来的圈：小心这一跤

`while` 有个危险的脾气：**只要眼色一直答「真」，它就一直跑下去。**

要是手滑漏掉 `fish = fish - 1`，`fish` 就永远是 3，眼色永远答「真」——代码会一路喊到你硬把窗口按掉。这种圈，术语表里叫**死循环（停不下来的圈）**。

所以本喵**故意不给能跑的示例**——它一跑起来就得强行关窗口。记住那句判据：**动手写圈之前先问自己，眼色有没有机会变成「假」？**

## 四只翻译官喵一起跑圈

同一个「发三条小鱼干」的活儿，四门语言写出来是这样：

```compare
c::
#include <stdio.h>

int main() {
    for (int i = 0; i < 3; i++) {
        printf("发一条小鱼干喵\n");
    }
    return 0;
}

cpp::
#include <iostream>

int main() {
    for (int i = 0; i < 3; i++) {
        std::cout << "发一条小鱼干喵" << std::endl;
    }
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 3; i++) {
            System.out.println("发一条小鱼干喵");
        }
    }
}

python::
for i in range(3):
    print("发一条小鱼干喵")
```

四段的骨架一模一样：**先定圈数，再写每圈的动作**。差别在括号里那排小格子——C、C++、Java 要自己写全「起步、眼色、往前迈一步」，Python 一句 `range(3)` 全包了喵。

::: tip 猫咪提示
口诀：**数得清圈数用 `for`，只能凭眼色停用 `while`**。`for` 跑满就收工，`while` 每圈前先瞄一眼眼色。两种跑法干的是同一件事——**同一套动作重复很多遍**喵～
:::

::: warn 小心喵
`while` 里那句**让眼色往前挪**的代码一个字都不能漏（比如 `fish = fish - 1`）。漏了它，眼色永远答「真」，圈就停不下来。写完检查一句：**每跑一圈，我那个数真的变小了吗？**
:::
