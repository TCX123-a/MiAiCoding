## 钩子：有两招，你没喊，它们自己就跑了

上一课是**《从租仓库到请猫入住——malloc 与 new 的分水岭》**。那节课上你看见了一个现象：`new` 一只猫的时候，图纸里**有一招自己跑了一遍**；`delete` 的时候，**另一招又自己跑了一遍** —— 本喵当时说「机制留到下一课」喵。

今天就是「下一课」。本喵把这两招请上台，看看它们叫什么名字、画在图纸的哪一行、什么时候开工。

先记住它们的名字：管出生的那一招，叫**出生招式（构造函数）**；管离开的那一趟，叫**收尾招式（析构函数）**。往后四门语言里你都会撞见它们 —— 不过丑话说在前面：**C 里两招全没有**，得自己手写、自己记得喊；Java 和 Python 只有前一半；四门里两样齐全的，是接住你这门老手艺的 C++ 喵。

## 一张图纸，看完整只猫的一生

先整个看一遍。本喵的猫这回身上多带一样东西：一间**现租的零食仓库**（上一课的老朋友 —— 搬家时租、走时还的那间）：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
    string name;      // 名字格
    int* snacks;      // 一张猫爪指向牌，指着那间现租的仓库
public:
    Cat(string n, int s) : name(n), snacks(new int(s)) {
        cout << name << " 出生啦，租好一间零食仓库" << endl;
    }
    ~Cat() {
        delete snacks;
        cout << name << " 走啦，仓库还回去" << endl;
    }
};

int main() {
    Cat c1("小橘", 3);
    return 0;
}
```

```text
小橘 出生啦，租好一间零食仓库
小橘 走啦，仓库还回去
```

**两行字都不是 `main` 里喊出来的**：第一行是出生那一招自己印的（第 19 行生猫那一刻），第二行是离开那一招自己印的（`main` 走到头那一刻）。图纸上多出来的 `Cat(...)` 和 `~Cat()`，就是上一课本喵说的「自己会跑的两招」喵。

下面把两招拆开，一招一招看。

## 出生招式：生猫那一刻自动跑的那一招

图纸里那个**跟图纸同名**的招式（图纸叫 `Cat`，它就叫 `Cat`），就是出生招式。它有三条认领暗号：

1. **名字跟图纸一个字都不差。** 这是它唯一的名字 —— 翻译官喵就靠这一条认出「这个招式是出生那一刻要跑的规矩」。
2. **脑袋上不写叼回什么。** 看它的开头 `Cat(string n, int s)` —— 前面**不写** `void`、不写 `int`，光秃秃一个名字。生猫不是喊它去干活，压根没有「叼回来什么」这回事。
3. **生猫那一刻自己跑。** `Cat c1("小橘", 3);` 这一行里，真猫一落地，它**当场跑了一遍** —— 本喵一个字都没喊它。

它脑袋后面还跟着一小段：`: name(n), snacks(new int(s))` —— 这叫**出生清单（初始化列表）**，念作「用 `n` 装 `name`、用 `new int(s)` 装 `snacks`」。清单干两件事：

- 它在**大括号里那几行之前**就执行：真猫落地的瞬间，格子**已经装好了**，不是先进门再收拾；
- 「顺手要办的事」也能在清单里一次办完 —— `snacks(new int(s))` 就是当场现租一间仓库、把 `s` 放进去。

同一张图纸上，出生招式还可以**挂好几套**：`Cat()` 不带料、`Cat(string n)` 只带名字、`Cat(string n, int s)` 两样都带。翻译官喵看你喂了几样料、喂的是什么，挑对得上的那一套跑 —— 这就是行话里的**同名多招（重载）**，这套本事往后语言线会专门讲；今天先认它在图纸上管「怎么出生」的这一面喵。

## 收尾招式：走的时候自动收的那一趟

给图纸再添一笔 —— 招式名前面多一个小波浪号 `~`：`~Cat()`。它跟出生招式是成对的：

- **名字 = `~` + 图纸名**，脑袋上同样不写叼回什么；
- 它干的活是**把借来的东西还回去**：`delete snacks` —— 上一课 `free` 的接班活，就落在这里。

**它什么时候跑？** 两个时刻，全是自动的：

- 猫**走出它所在的那对大括号**时 —— 招式的、`main` 的，凡是括住它的那对括号，说到就到；
- 对 `new` 出来的那只猫，喊 `delete` 的时候。

还有一条不太起眼的规矩：同一段里养了一窝猫，收尾的次序是**倒着的** —— 最后生出来的，最先走。像一摞叠起来的猫粮碗，最后放上去的那只，最先被拿走喵。

猫身上要是没借着东西，这一招可以整个不写（翻译官喵送你一个空的）。可只要像现在这样 —— 猫手里捏着租来的仓库，**这一招就非写不可**：不写它，翻译官喵不会报错，仓库就静静地漏在外面，账再也收不回来。

## 三个高频写错，当场诊断

**错法一：给出生招式脑袋上写个返回类型。**
有人想：别的招式脑袋上都写个叼回什么，本喵写一个总没错吧 —— 于是写下 `void Cat(string n)`。翻译官喵当场拦下：

```text
error: return type specification for constructor invalid
```

念作：**「出生招式头上不许写叼回什么喵。」** 把脑袋上多出来的那一截（`void`、`int`，什么都一样）删掉，它就好了。

**错法二：`name = name;` 原地打转。**
把出生清单换成肚子里那几行，有人会这么写：

```cpp
#include <string>
using namespace std;

class Cat {
    string name;      // 名字格
public:
    Cat(string name) {
        name = name;     // 两边的 name 都指喂进来的料
    }
};
```

这一句里，**左右两边的 `name` 都指喂进来的那份料** —— 料自己给自己让了一圈，格子从头到尾没人管，名字格里最后是**空的**。两种解法：

- **走出生清单**：`Cat(string n) : name(n) {}` —— 本课主推，名字和料分开写，一眼分得清；
- **点名「这一只自己的」格子**：C++ 写 `this->name = name;`，Java 写 `this.name = name;`。

顺带说一个轻的：没有同名冲突的时候，`this.m(5);` 和 `m(5);` 跑的是同一件事 —— 带上 `this.` 只是啰嗦一点。它只在「料和格子同名」这种场合非写不可喵。

**错法三：忘了收尾招式。**
上一课说「`malloc` 租的仓库，`free` 不能忘」；这一课接上：仓库是在出生招式里租的，就得在收尾招式里还。漏了它，仓库和账一起飘在外面 —— 翻译官喵一声不响，这才是最咬人的地方喵。

## 最后一块路牌：复刻一只猫

临走前本喵立一块路牌，先别往前走：

```cpp
Cat a("小橘", 3);
Cat b = a;      // 照 a 的样子复刻一只 b：你写的那套出生招式一次都没跑
```

`b` 的名字是复制来的；可那张**猫爪指向牌也被复印了一份** —— 现在小橘和它的复刻，叼着**同一间仓库**。走的时候收尾招式各跑一次：**同一间仓库被还回去两遍**，程序当场翻脸（有时直接崩，有时是更隐蔽的坏账）。

这坑只咬「手里捏着租来东西」的猫 —— 两只各自租各自的仓库，什么事都没有。复刻这一族的事，往后 **C++ 那一线**有专门一课收它，今天把路牌立在这儿就够了喵。

## 四位翻译官喵，同一只猫

同一件事：生一只猫，喂进名字和零食数；**出生那一刻印一行，再报一报它的零食数**。四段跑下来，屏幕上都是同样两行喵。

```compare
c::
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char name[20];
    int* snacks;                    /* 一张猫爪指向牌：指着现租的仓库 */
} Cat;

void cat_init(Cat* c, const char* name, int s) {   /* 手写的「出生那一招」 */
    strcpy(c->name, name);
    c->snacks = (int*)malloc(sizeof(int));         /* 现租一间仓库 */
    *(c->snacks) = s;
}

void cat_destroy(Cat* c) {                         /* 手写的「收尾那一招」 */
    free(c->snacks);                               /* 把仓库还回去 */
}

int main(void) {
    Cat c;
    cat_init(&c, "小橘", 3);
    printf("%s 出生啦\n", c.name);                 /* 「出生啦」这一行也得自己喊 */
    printf("%s 的零食：%d 条\n", c.name, *(c.snacks));
    cat_destroy(&c);                               /* 忘了这一句，仓库就漏了 */
    return 0;
}

cpp::
#include <iostream>
#include <string>
using namespace std;

class Cat {
    string name;
    int* snacks;

public:
    Cat(string n, int s) : name(n), snacks(new int(s)) {
        cout << name << " 出生啦" << endl;
    }
    ~Cat() {
        delete snacks;              // 走的时候自己把仓库还回去（这一招没印字）
    }
    void show() const {
        cout << name << " 的零食：" << *snacks << " 条" << endl;
    }
};

int main() {
    Cat c("小橘", 3);
    c.show();
    return 0;
}

java::
class Cat {
    String name;
    int snacks;

    Cat(String name, int snacks) {          // 出生招式：跟图纸同名、不写返回
        this.name = name;
        this.snacks = snacks;
        System.out.println(this.name + " 出生啦");
    }

    void show() {
        System.out.println(this.name + " 的零食：" + this.snacks + " 条");
    }
}

public class Main {
    public static void main(String[] args) {
        Cat c = new Cat("小橘", 3);
        c.show();
    }
}

python::
class Cat:
    def __init__(self, name, snacks):
        self.name = name
        self.snacks = snacks
        print(f"{self.name} 出生啦")

cat = Cat("小橘", 3)
print(f"{cat.name} 的零食：{cat.snacks} 条")
```

```text
小橘 出生啦
小橘 的零食：3 条
```

看出来了吗喵：**同一件事，四位的手势差得可不小**。

- **C**：出生招式、收尾招式，**C 里一样都没有** —— 只好手写两招站在图纸外面：`cat_init` 管出生（抄名字、现租仓库），`cat_destroy` 管收尾（还仓库）。要命的一条：这两句**都得自己记得喊**，连「出生啦」那一行也是手写的；漏了 `cat_destroy`，仓库就漏在外面。
- **C++**：出生招式跟图纸同名、脑袋上光秃秃，生猫那一刻自己跑 —— 屏幕第一行就是它印的；收尾招式多个 `~`，走的时候自己把仓库还了。这段还多一手 C 没有的本事：出生招式能挂好几套、看料挑一套。
- **Java**：Java 管它叫**构造方法**，照样跟图纸同名、不写返回，`new` 那一刻自己跑；`this` 就是「这一只」（写 `this.name = name` 用的）。收尾那一招 Java **没有** —— 走的时候交给自动铲屎官（GC），不用谁写「还仓库」。
- **Python**：出生那一刻自动跑的是 `__init__`（前后各两条下划线，一共四个）；收尾同样不写，也归自动铲屎官管。

一句话总结：**出生那一招 —— C 手写，另外三位都画在图纸上；收尾那一招 —— 只有 C++ 会自己跑**，C 靠你记性，Java/Python 交给铲屎官喵。

::: tip 猫咪提示
今天记住三句话喵：

1. **出生招式（构造函数）**：跟图纸同名、脑袋上不写叼回什么，生猫那一刻**自己跑**；出生清单在大括号之前把格子装好，顺手要办的事（比如租仓库）也能在清单里一次办完。
2. **收尾招式（析构函数）**：名字是 `~` + 图纸名，走出大括号、或在 `delete` 那一刻**自己跑**，把借来的还回去；同一段里几只猫，倒着收。
3. **一句话分家**：出生那一招 —— C 手写、另外三位画在图纸上；收尾那一招 —— 只有 C++ 会自己跑，C 靠你记性，Java/Python 有自动铲屎官。
:::

::: warn 小心喵
三个坑，本喵标出来：

- **出生招式头上别写返回类型**：`void Cat(...)` 会被翻译官喵当场拦下，把脑袋上多出来的那截删掉就好。
- **`name = name;` 是原地打转**：料和格子同名时，要么走出生清单，要么点名「这一只」（`this->` / `this.`）。
- **复刻一只带仓库的猫会出事**：牌子被复印一份，两只猫叼着同一间仓库，还的时候还两遍 —— 本课只立了路牌，别急着往里走喵。
:::

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `Cat(string n, int s) : name(n), snacks(new int(s)) {}` | 出生招式（构造函数）：跟图纸同名、不写叼回什么，生猫那一刻自己跑，清单里顺手租好仓库 |
| `~Cat() { delete snacks; }` | 收尾招式（析构函数）：走出大括号、或 `delete` 那一刻自己跑，把租来的还回去 |
| `Cat c1("小橘", 3);` | 生一只小橘：料直接喂给出生招式，一个字都不用多写 |
| `cat_init` / `cat_destroy` | C 里出生、收尾这两招都没有 —— 手写之外，还得**记得手动喊**，漏一句就漏 |
| `name = name;` | 写坏的出生招式：两边都指喂进来的料，格子原地打转 |
| `Cat b = a;` | 复刻一只：牌子被复印，两只猫叼着同一间仓库（C++ 线专门一课收它） |
