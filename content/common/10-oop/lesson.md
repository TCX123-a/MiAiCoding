## 钩子：三十只仓库，本喵快记不住了

上一课本喵把一箱活摊成了三列卡片 —— 动手之前先问一句「这是谁的活」；它还答应过：把这一路上捡的三样 —— 带盖的小鱼干盒、图纸套图纸、一声开饭，各猫各样 —— 合成一张大图 —— 说好了，这一课不教新东西，就是把这三样拼到一起。可从哪儿起笔呢？本喵翻开自己记账的小本子：乱，还是从一只猫身上开始的喵。

十只猫，每只都要记「名字」和「今天吃了几条小鱼干」，加起来就是二十只仓库；要是再加上「爱不爱蹭人」，三十只。名字还得起成 `cat1name`、`cat1fish`、`cat2name`……本喵写到第五只就想掀桌子了。

更糟的是：本喵想写一招「给这只猫添一条小鱼干」，喂进去的得是两样东西 —— 哪只猫、添几条。喂错一次，橘猫的数就跑到狸花猫的头上了。

本喵要的不是三十只仓库，而是一张**图纸**：每只猫都长这几样东西，照图纸生出来的猫自己带着它们，走到哪儿跟到哪儿喵。

## 猫猫图纸（类）

本喵摊开一张纸，画上一只猫，旁边写上三行说明：

- 每只猫都有**名字**；
- 每只猫都有**今天吃了几条小鱼干**；
- 每只猫都会一招：**喵一声**。

这张纸上写的不是某一只猫，而是「**凡是照着这张图纸生出来的猫，都长这样**」。它不叫橘猫，也不叫狸花猫 —— 它就是一张**猫猫图纸**。

术语表里给这种图纸起的原名是**类（猫猫图纸）**：一张把「每只猫都有的东西、都会的招式」写在一起的纸。

可别把图纸当成猫喵：本喵在纸上画一百只猫的轮廓，碗边也还是一只活的都没有。

## 照着图纸生真猫（对象）

图纸画好了，本喵照着它生两只看看喵：

```python
class Cat:
    def __init__(self, name, fish):
        self.name = name
        self.fish = fish

    def meow(self):
        print(f"{self.name}：喵～本喵今天吃了 {self.fish} 条小鱼干")

cat1 = Cat("橘猫", 3)
cat2 = Cat("狸花猫", 1)
cat1.meow()
cat2.meow()
```

```text
橘猫：喵～本喵今天吃了 3 条小鱼干
狸花猫：喵～本喵今天吃了 1 条小鱼干
```

这一段不用背，跟着本喵看个大概就行喵：

- **`class Cat:`** —— 「本喵要画一张叫 `Cat` 的图纸」。`class` 就是**画图纸**的口令。
- **`def __init__(self, name, fish):`** —— 图纸上的第一条说明：**照这张图纸生猫的时候，先喂进来名字和小鱼干数**。`def` 是「本喵要写一招」的口令。
- **`self.name = name`** —— 把喂进来的名字，放进**这只猫自己**的仓库里。`self` 读作「本喵自己」：生的是哪只猫，它指的就是哪只。
- **`def meow(self):`** —— 图纸上写的招式：会「喵一声」。
- **`cat1 = Cat("橘猫", 3)`** —— 照着图纸**生出一只真猫**，名字叫橘猫。

生出来的那一只，术语表里叫**对象（根据图纸生出来的真猫）**。照图纸生两只就有两只，各带各的仓库：`cat1.fish` 是 3，`cat2.fish` 是 1，谁也不碰谁喵。

这张图纸怎么变成碗边的两只真猫，本喵把它拆成一步一步，走给你看：

想喊橘猫喵一声，就写 `cat1.meow()` —— **先说哪只猫，再喊招式名**。这一招由那一只猫来做，念出来的自然是它自己那份数。

## 带盖的小鱼干盒（封装）

本喵把「名字」和「小鱼干数」装进一只盒子里，再给盒子盖上一个盖子。

盖子不是不让人用，它的意思是：**里面那几样东西，别直接伸手去掏**。要添一条鱼干？走本喵留的口子 —— 比如一招「喂一条」，添完它自己顺手把数加上去。

这一手，术语表里叫**封装（带盖的小鱼干盒）**。盖子有三个好处喵：

1. **不怕掏坏**：谁也不能顺手把「小鱼干数」改成「三条半」。
2. **改起来只改一处**：以后想把「添一条」改成「添两条」，只改盖子里那一招，外面用它的地方一个字都不用动。
3. **外面的人只用记口子在哪儿**：橘猫会「喂一条」，本喵就喊「喂一条」，不用管盒子里面是怎么摆的。

## 图纸套图纸（继承）

本喵又想要一张「橘猫图纸」。可橘猫也是猫呀 —— 名字、小鱼干数、喵一声，它一样都不少，只是**多一条**：爱吃。

本喵才不想把猫图纸上的内容重抄一遍，于是本喵在橘猫图纸上写一句：**「照猫的图纸来，另外加一条：爱吃。」**

这一手，术语表里叫**继承（图纸套图纸）**：小图纸白捡大图纸的全部设定，自己只管新加的那部分喵。

好处一眼就看得见：往后本喵给猫图纸添一条「会打呼噜」，所有照着它画的小图纸**都会跟着有** —— 只改一处，全套更新。

## 一声开饭，各猫各样（多态）

最后一样最好玩。本喵站在鱼塘边喊一声：「**开饭啦 —— ！**」

- 橘猫「嗖」地冲过来；
- 狸花猫翻个身，慢悠悠地踱过来；
- 黑白花从猫爬架上探出半个脑袋。

同一句喊话，**各猫的应法不一样**。放到图纸上说：图纸上写着「会一招 `meow`」，可橘猫的 `meow` 是「喵呜——」，狸花猫的 `meow` 是「喵。」。本喵写 `cat.meow()` 的时候，根本不用管手里这只到底是哪只猫 —— **它自己知道该怎么应声**喵。

这一手，术语表里叫**多态（一声开饭，各猫各样）**：同一句喊话，各猫各样。

::: tip 猫咪提示
今天这五样，一样一句话喵：

1. **猫猫图纸（类）** —— 把「每只猫都有的东西」写在一张纸上；
2. **照图纸生出来的真猫（对象）** —— 真正在碗边吃饭的那一只，各带各的仓库；
3. **带盖的小鱼干盒（封装）** —— 里面的东西别乱掏，要改就走口子（招式）；
4. **图纸套图纸（继承）** —— 小图纸白捡大图纸的设定，只加自己新写的那条；
5. **一声开饭，各猫各样（多态）** —— 同一句喊话，各猫有各猫的应法。

图纸管「长什么样」，招式管「会什么」。往后学 C++、Java、Python 的时候，你会天天撞见它们喵。
:::

::: warn 小心喵
最容易搞混的一对是**图纸**和**真猫**：`class Cat:` 画出来的是图纸，`Cat("橘猫", 3)` 生出来的才是真猫。图纸只有一张，真猫想生几只生几只喵。

还有一个坑：图纸里写的仓库（比如 `self.name`），**每一只真猫都各自有一份**。橘猫改了名字，狸花猫那份一动也不动 —— 忘了这一条，就会出现「本喵明明只改了橘猫，狸花猫怎么也跟着变了」这种怪事喵。
:::

## 四位翻译官喵怎么画图纸

同一件事：画一张「猫」的图纸，照着它生出一只猫，让它报一报今天吃了几条小鱼干喵。

```compare
c::
#include <stdio.h>

typedef struct {
    int fish;
} Cat;

int main() {
    Cat cat;
    cat.fish = 3;
    printf("这只猫今天吃了 %d 条小鱼干喵\n", cat.fish);
    return 0;
}

cpp::
#include <iostream>

class Cat {
public:
    int fish;
};

int main() {
    Cat cat;
    cat.fish = 3;
    std::cout << "这只猫今天吃了 " << cat.fish << " 条小鱼干喵" << std::endl;
    return 0;
}

java::
public class Main {
    static class Cat {
        int fish;
    }

    public static void main(String[] args) {
        Cat cat = new Cat();
        cat.fish = 3;
        System.out.println("这只猫今天吃了 " + cat.fish + " 条小鱼干喵");
    }
}

python::
class Cat:
    def __init__(self, fish):
        self.fish = fish

cat = Cat(3)
print(f"这只猫今天吃了 {cat.fish} 条小鱼干喵")
```

```text
这只猫今天吃了 3 条小鱼干喵
```

看出来了吗喵：**四段说的是同一件事，写起来差得可远了**。

- **C**：C 里其实**没有图纸这回事**，只好用一个装数据的盒子（`struct`）凑出「一只猫该有的东西」，再单独写一招去报数 —— 盒子和招式是分开的两样。
- **C++**：`class Cat` 就是货真价实的图纸了，`public:` 下面的东西，外面的人伸手就能摸到。
- **Java**：图纸要写进 `Main` 里，生猫得喊 `new Cat()` —— `new` 就是「照图纸生一只」的口令。
- **Python**：`class Cat:` 开头，`__init__` 里把投喂进来的数记在自己身上，生猫就是喊一声 `Cat(3)`。

这就是本喵想让你先记住的那句话：**图纸这套想法，四门语言都有，只是喊法不一样**。等本喵带你学某一门语言的时候，你会发现自己早就懂了它的心思喵。
