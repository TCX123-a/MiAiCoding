## 钩子：路线图上那一站，今天到站

上一课的收尾，本喵撂下过一句话：想改外面的数，「递牌子」这门老手艺靠的是**递进去一张猫爪指向牌** —— 新来的这位，不写 `*` 也能把同一件活干成。墙上的路线图里，这一站也早就钉好了，就叫**猫爪指向牌的接班人**喵。

今天到站：先把老手艺请上台，看它把那件看家的活干得利利索索；再请出接班人。两位干完同一件活，你把两段代码并排一放 —— 会看见接班人手底下，老手艺的记号**一个接一个消失**。

## 老手艺：递牌子进去，改外面那只碗

要办的活叫「对调」：两只碗，一只装着 3、另一只装着 8，让它们换个位置住。老手艺在 C 里长这样：

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 3;
    int y = 8;
    swap(&x, &y);
    printf("%d %d\n", x, y);
    return 0;
}
```

```text
8 3
```

屏幕上是 `8 3` —— 外面的两只碗**真的换过位置**。凭什么？本喵把三处关键动作拆开看喵：

- **喊的地方写 `swap(&x, &y)`** —— 递进去的不是 3 和 8 这两个数，是这两只碗的**门牌号**，写在一张「指针（猫爪指向牌）」上；
- **招式头上写 `int *a, int *b`** —— 收下两块牌子，`a`、`b` 是两块牌子的名字；
- **招式里写 `*a`、`*b`** —— 星号读作「顺着牌子走」：跑到牌子指着的那只碗跟前去。

于是 `*a = *b;` 这一句，就是把 `b` 指着的那只碗里的数，倒进 `a` 指着的那只碗 —— 两块牌子都指着**外面**的碗。招式关上门、牌子还回去，外面的数已经换了地方。老手艺的本事，一句话：**本喵不搬碗，本喵隔着牌子摸到你的碗**。

`swap` 的 `a`、`b` 就是这样的料：递进去，专门把结果**写回外面** —— 这类料，书上有名字叫**输出参数（写回外面的料）**。今天接班人要接的，就是这类活。

## 接班人上台：牌子撤了，名字挂上

同样两只碗、同一件活。接班人写成这样：

```cpp
#include <iostream>
using namespace std;

void swap(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 3;
    int y = 8;
    swap(x, y);
    cout << x << " " << y << endl;
    return 0;
}
```

```text
8 3
```

屏幕上一模一样，也是 `8 3`。可你数一数记号 —— 三处全变了：

- **喊的地方**：`swap(x, y)` —— 光写名字，`&` 没了；
- **招式头上**：`int& a` —— 多出来一个 `&`，粘在**类型**后面、不在名字前面（`int&` 读作「int 碗的又一个名字」）；
- **招式里**：`a = b;` —— 星号没了。

它不是把牌子换个写法 —— 它是**把牌子整个撤了**。`int& a` 的意思：不摆新碗、不记门牌号 —— **外面那只碗，进了这招招式就叫 `a`**。

这门本事，术语表里跟老手艺挤在同一行，本喵就照它的大名喊它：**引用（猫爪指向牌的温柔版）** —— 给同一只碗**再挂一个名字**。

名字挂上去，有三条规矩，今天就得背下来喵：

1. **挂名字的时刻，是招式开张那一刻**：`swap(x, y)` 一喊，`a` 当场挂到 `x` 上、`b` 挂到 `y` 上；
2. **挂上就不换**：这条招式里，`a` 永远指 `x` —— 术语里叫「从一而终」；
3. **招式关上门，名字当场消失**：`a`、`b` 是招式里的名字；碗还是那两只碗，数留在碗里。

老手艺递的是牌子，接班人挂的是名字 —— 一条「指过去」，一条「叫它一声」。差别看着小，用起来差得远，往下看喵。

## 先在平地上走两步：给一只碗挂两个名字

先别忙着用它接活。本喵在平地上走两步给你看 —— 数数看：这段代码一共摆了几只碗？

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    int& other = fish;      // other 是 fish 的另一个名字
    other = 10;             // 改 other，就是改 fish
    cout << fish << endl;
    cout << other << endl;

    int cat = 7;
    other = cat;
    cout << fish << endl;
    cout << cat << endl;
    return 0;
}
```

```text
10
10
7
7
```

逐行过一遍喵：

- **`int fish = 3;`** —— 摆一只碗 `fish`，装 3；
- **`int& other = fish;`** —— 给 `fish` **再挂一个名字** `other`。没有新碗 —— 到这儿一共还是**一只**碗；
- **`other = 10;`** —— 往 `other` 里倒 10，倒的**就是** `fish`。两条 `cout` 全印 10 —— 不是巧合，是同一只碗；
- **`int cat = 7;`** —— 这时候才摆出**第二只**碗；
- **`other = cat;`** —— 这一句最容易看走眼：它**不是**让 `other` 改挂到 `cat` 上，而是把 `cat` 里的 7 **抄进** `other`（也就是 `fish`）。收工一数：`fish` 变成 7；`cat` 自己的 7，一动没动；
- 所以后两行印出来是 `7` 和 `7`。

`other = cat;` 这一句的教训记好：**名字挂上就摘不下来**。`=` 用在名字身上只有一个意思：把右边的数，倒进它挂着的那只碗。

## 像不像？拿四个问题量一量

接班人和老手艺，到底是像还是不像？本喵拿四个问题挨个量喵：

| 本喵问的 | 老手艺（猫爪指向牌） | 温柔版（引用） |
|---|---|---|
| 能不能先空着，回头再挂 | 能。牌子可以先不指任何碗（`int *p = NULL;`），找着碗再说 | 不能。名字挂不上就开不了张 —— `int& r;` 翻译官喵当场拦下 |
| 能不能半路改挂别的碗 | 能。牌子上的门牌号，说换就换 | 不能。从一而终，挂上就锁死 |
| 平时用着要记号吗 | 要。喊的地方写 `&`，招式头上、招式里写 `*` —— 缺一处都不行 | 不要。喊 `swap(x, y)`，招式里照常写名字 |
| 能不能沿着一排碗走过去 | 能。牌子加一，往后再跨**一整只碗**的身位 | 不能。名字只认挂上的那一只碗，挪不动 |

四个问题问完，接班人像不像，心里就有数了喵。

## 四位翻译官喵，同一件活

3 和 8 对调，四位翻译官喵各交一份答卷，摆一桌 —— 重点看**每段是怎么改到外面的**：

```compare
c::
#include <stdio.h>

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 3;
    int y = 8;
    swap(&x, &y);
    printf("%d %d\n", x, y);
    return 0;
}

cpp::
#include <iostream>
using namespace std;

void swap(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 3;
    int y = 8;
    swap(x, y);
    cout << x << " " << y << endl;
    return 0;
}

java::
public class Main {
    static void swap(int[] pair) {
        int t = pair[0];
        pair[0] = pair[1];
        pair[1] = t;
    }

    public static void main(String[] args) {
        int[] pair = {3, 8};
        swap(pair);
        System.out.println(pair[0] + " " + pair[1]);
    }
}

python::
def swap(pair):
    pair[0], pair[1] = pair[1], pair[0]

pair = [3, 8]
swap(pair)
print(pair[0], pair[1])
```

```text
8 3
```

四段屏幕上的数一模一样，都是 `8 3` 喵 —— 可「改到外面」的手法，四家四样：

- **C**：老手艺全套。递牌子（`&x`）、收牌子（`int *a`）、顺着走（`*a`）—— 三处记号，一处都不能少；
- **C++**：接班人上场。`int& a` 直接挂名字，喊的时候光写 `swap(x, y)` —— 记号一个不剩。顺带说一句：老手艺 C++ 也没扔，两套写法它都认；
- **Java**：**没有接班人**。Java 的招式收料，收的永远是**抄件** —— 递 `int x` 进去，招式里改的是抄件，外面那只碗纹丝不动。想改到外面，得递一份**本身就是一整排**的东西：这里递的是一排碗（数组），招式里改 `pair[0]`、`pair[1]`，改的是外面那一整排；
- **Python**：跟 Java 一个心思。名字递进去也是**转手一份**，招式里改名字本身，外面不动；递一排碗（数组）进去才改得动外面。Python 还备了一句现成的换碗写法：`x, y = y, x` —— 一行，两只碗就换过来了。

## 接班人这么顺手，老手艺还有用吗

有用，而且有大用。有三个场合，只有牌子办得到喵：

1. **先空着**：`int *p = NULL;` —— 牌子可以先不指任何碗，等找着目标再挂。名字办不到：挂不上就开不了张。往后的链子里，尾巴上那张牌子谁都不指 —— 空牌子是它的常态；
2. **半路换目标**：牌子上的门牌号说换就换 —— 在一排碗里找最大的那个，就得让牌子一只一只挪过去；
3. **沿着一排走**：牌子加一，往后再跨**一整只碗**的身位。走一排碗全靠这一手，往后会专门有一课数它。

接班人这边也常穿一件外套：**常引用（const int&）**。在料上写 `const int& x`，读作「只看、不碰」：招式拿着它，看得见外面那只碗、不复印（省事），可**不许改**（安全）—— 翻译官喵在一旁盯着呢。以后递大件东西的时候，你会天天用它喵。

::: tip 猫咪提示
今天三句话，装兜里带走喵：

1. **老手艺（指针）** —— 递**牌子**进去：喊的地方 `swap(&x, &y)`，招式里顺着走 `*a = *b;`。能空着、能换目标、能沿排走；
2. **接班人（引用）** —— 给同一只碗**再挂一个名字**：喊 `swap(x, y)`，招式里照常写名字。挂上不换（从一而终），挂不上就开不了张；
3. **两家都别丢**：`const int&` 只看不碰，递大件用它；要空、要换目标、要沿排走，还得请老手艺。
:::

::: warn 小心喵
两个坑，提前钉在墙上：

- **`&` 一枚词，两种地方两种读法。** 递料的地方（`swap(&x, &y)`）读作「取门牌号」；登记料的地方（`int& a`）读作「不复印，就是它本身」。撞见 `&` 先问一句：它站在**递**的地方，还是**登记**的地方？
- **名字挂上就摘不下来。** 别忘了那只 `other = cat;`：它抄的是**值**，不是改挂。要是以为挂上的名字还能换碗，你会得到「改了名字、碗却没换」的怪现场，还找不着原因。
:::

## 一句话对照表

| 本喵写下的 | 它是谁、在干什么 |
|---|---|
| `void swap(int *a, int *b)` | 老手艺：招式收下两块牌子 |
| `swap(&x, &y)` | 老手艺：把两只碗的门牌号递进去 |
| `*a = *b;` | 老手艺：顺着牌子走，改的是外面的碗 |
| `void swap(int& a, int& b)` | 接班人：不摆新碗 —— 外面那只碗，进来就叫 `a` |
| `swap(x, y)` | 接班人：光写名字，`a`、`b` 当场挂到外面的碗上 |
| `int& other = fish;` | 接班人：给 `fish` 再挂一个名字（别名） |
| `int& r;` | 挂不上就开不了张 —— 翻译官喵当场拦下 |
| `const int& x` | 只看不碰：不复印、不许改，递大件常用它 |
| `x, y = y, x` | Python 的现成写法：一行把两只碗换过来 |
| `int[] pair` + `swap(pair)` | Java：招式收的永远是抄件 —— 得递**一整排**才改得动外面 |

## 小任务

1. 本喵把两只碗里的数换成 5 和 9，其余一字不动。老手艺那段（C）印出来的两个数是什么？接班人那段（C++）呢？（先猜，再翻回去对着代码看喵）
2. 动手：把 C++ 那段的 `int& a, int& b` 改成 `int a, int b`（就删两个 `&`），再跑一遍 —— 屏幕上变成了 `3 8`，跟没换一样。这一趟你亲手摸到的，就是「抄件」和「名字」的分界。
3. 想一想：`int& r;` 会被翻译官喵当场拦下，`int *p;` 却放行。为什么牌子可以先空着、名字不行？（提示：有些活儿**必须**先有一张空牌子 —— 比如还没找着目标的链子尾巴。）
