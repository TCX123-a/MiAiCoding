## 钩子：一块地垫，两条路

上一课本喵刚学会「把一件事拆成一步步」：算最长尺子，就拆成「取余 → 短的顶上来 → 余数接上去」喵。

今天这件小事更小：本喵要给猫窝门口铺一块长方形的地垫，长 3、宽 4，算算要盖住多少面积。

就这么点事，本喵的桌上却摆着两条路。一条本喵闭着眼都能走，另一条是往后十几课要教你走的那条。两条路都能把 12 送出来 —— 可它们**拆事的手法**，从第一步起就不一样喵。

## 路一：把事拆成一条流水线

本喵先走熟路。在 C 里，这件事写成这样：

```c
#include <stdio.h>

float rect_area(float w, float h) {
    return w * h;
}

int main(void) {
    float w = 3;
    float h = 4;
    float area = rect_area(w, h);
    printf("面积是 %.0f\n", area);
    return 0;
}
```

```text
面积是 12
```

拆开看喵：

- **`float w = 3;` 和 `float h = 4;`** —— 先把两样料摆在桌上：长和宽。
- **`float rect_area(float w, float h)`** —— 旁边单独摆一招「算面积」：谁把长和宽喂进来，它就把谁算一算。
- **`float area = rect_area(w, h);`** —— 喊一声，把桌上那两样料喂进招式，算出的 12 叼回来，落进 `area` 这只碗。
- **`printf(...)`** —— 把碗里的结果印出去，交差。

看仔细一件事喵：**料和活是分开摆的**。长、宽、结果都是桌上的数；「相乘」是一招摆在外头的招式。招式头上只写着「要两样料」，**一个字都没写要谁家的料** —— 你喂什么，它就算什么。

这条路，是把一件事拆成一条**动作流水线**：一步接一步，谁先谁后排得明明白白，料在碗里递过来、递过去。

老前辈猫把这条路总结成一句顺口溜：**程序 ＝ 数据结构 ＋ 算法** —— 一边是料，一边是活，两摞摆好，顺序排好。

## 路二：把事拆出几个角色

本喵换个拆法。先别急着排步骤，先问一句：**这件事里有谁？**

有一块地垫。长和宽是**它自己带着的**；「算出自己的面积」是**它自己会的**。外头不用递料，只要点名喊一声就行喵：

```python
class Rect:
    def __init__(self, w, h):
        self.w = w
        self.h = h

    def area(self):
        return self.w * self.h

r = Rect(3, 4)
print(f"面积是 {r.area()}")
```

```text
面积是 12
```

一行一行看喵：

- **`class Rect:`** —— 摊开一张叫 `Rect` 的图纸，上面写清「照我生出来的每一块地垫，都长什么样、会什么」。
- **`def __init__(self, w, h):`** —— 图纸上的第一条说明：**照它生一块的时候，先把长和宽喂进来**。
- **`self.w = w` / `self.h = h`** —— 喂进来的两样，装进**这一块自己**身上（`self` 读作「本喵自己」）。
- **`def area(self):`** —— 图纸上写的本事：每一块照它生出来的，**自己会算自己的面积**。
- **`r = Rect(3, 4)`** —— 照着图纸生出一块地垫，起名叫 `r`；3 和 4 装进**它自己**身上，不摆在公共桌上。
- **`r.area()`** —— **先点名 `r`，再喊本事**。用哪份长和宽？它自己知道，不用你递。

同一件事换到 Java，是这个样子：`Rect r = new Rect(3, 4);` 先生一块 `r`，再 `r.area();` 点名让它算。

这条路，是把一件事拆出**几个角色**：每个角色带着自己那份料、自己会干的那件事，谁的事谁负责，互相喊话把活办完。

老前辈猫给这条路也配了句顺口溜：**程序 ＝ 一组互相协作的对象（一群角色）** —— 互相喊话，把活办完。

## 等一下——这不就是把招式塞进结构体里吗？

本喵猜你现在心里冒出一句：「路二……不就是**把函数（招式）塞进结构体里**吗？」

先别急着下这个结论喵。本喵当场给你一句判据，先记下它 —— 往后有一课，咱俩把两种写法并排摆出来，本喵再拿它一条一条跟你对账：

> **封装（带盖的小鱼干盒）＝藏数据、露行为。**

「藏数据」：料收进角色自己身上，别摊在桌上让谁都能伸手乱改；「露行为」：它会干的事亮出来，一个名字就喊得动。只把招式挪个地方、数据还摊在外面 —— 那连这条判据的第一半都没走到。这条路长什么样，急不得，后面一课一课兑现给你看。

还有一句本喵也替你先说了：**「可路二明明更长啊。」** 嗯，眼下确实更长 —— 多出来的那几行，是在摊一张图纸。先别急着比长短，本喵给你埋个悬念：等哪天需求改了，要看的不是谁写得短，而是**谁不用改** —— 到那时候，你再来找本喵算这笔账喵。

## 四位翻译官喵，同一件小事两条路

同一条地垫，长 3、宽 4。本喵把两条路都交给四位翻译官喵走一遍 —— 你会看到**两条路都走得通**，也看到**写法差得有多远**喵：

```compare
c::
#include <stdio.h>

float rect_area(float w, float h) {
    return w * h;
}

int main(void) {
    float w = 3;
    float h = 4;
    float area = rect_area(w, h);
    printf("面积是 %.0f\n", area);
    return 0;
}

cpp::
#include <iostream>

class Rect {
public:
    double w;
    double h;

    Rect(double a, double b) {
        w = a;
        h = b;
    }

    double area() {
        return w * h;
    }
};

int main() {
    Rect r(3, 4);
    std::cout << "面积是 " << r.area() << std::endl;
    return 0;
}

java::
public class Main {
    static class Rect {
        int w;
        int h;

        Rect(int w, int h) {
            this.w = w;
            this.h = h;
        }

        int area() {
            return w * h;
        }
    }

    public static void main(String[] args) {
        Rect r = new Rect(3, 4);
        System.out.println("面积是 " + r.area());
    }
}

python::
class Rect:
    def __init__(self, w, h):
        self.w = w
        self.h = h

    def area(self):
        return self.w * self.h

r = Rect(3, 4)
print(f"面积是 {r.area()}")
```

```text
面积是 12
```

- **C**：走的是路一。C 里能画的最像图纸的东西叫**结构体（`struct`）**，可它只装得住料；会干活的招式得单独摆在外头。这一手以后有一课专门把它用到极限喵。
- **C++**：是一座**桥**。`class` 把料和活收到一起，生一块写成 `Rect r(3, 4);`，再 `r.area();`；可路一那套「单独摆一招」的写法它一个字没扔 —— 两种拆法它都会。
- **Java**：走的是路二，照图纸生一块得喊 `new` 的口令：`Rect r = new Rect(3, 4);`，再点名 `r.area()`。
- **Python**：也是路二，生一块就是喊一声 `Rect(3, 4)`，算面积写 `r.area()`。

四段屏幕上的数**一模一样**，都是 12 喵。

## 本喵墙上的路线图

本喵在墙上钉了一张路线图 —— 今天这两条路里，路二会越走越宽。往后一站一件事，先认个脸熟喵：

- **起名字**：给重复出现的模式起个名字 —— 这是路二上一切本事的引擎；
- **分楼层**：让「用的人」和「造的人」分开站，里面随便换，用的人不用管；
- **半个对象（差半张图纸）**：先在 C 的地盘上把结构体用到极限，看缺的那半自己怎么冒出来；
- **同一本账，两种写法**：结构体版和图纸版并排摆，亲手改一遍；
- 再往后是**猫爪指向牌的接班人**、**从租仓库到请猫入住**、**图纸上的第一条说明**、**带盖的小鱼干盒**……
- 最后把图纸一层层叠起来：**图纸套图纸**、**一声开饭各吃各的**，再穿过语法看清**「一切皆对象（连 3 都有身份）」**；
- 这条路走到最后，会回到本喵最爱的那一课：**《猫猫图纸与真猫》**。

现在一个都不用记 —— 知道「这条路有站、一站只拆一件」就够喵。

::: tip 猫咪提示
今天这四句话，一串就够喵：

1. **路一**：把事拆成一条**动作流水线** —— 料摆一摊、活摆一摊，一步接一步；
2. **路二**：把事拆出几个**角色** —— 料长在自己身上，会干的事也长在自己身上，喊谁谁动；
3. 两条路**都能把活干完**（今天的 12 一模一样），差别在「料和活摆在哪」；
4. 想验「真走上路二没有」，判据先记这一句：**封装＝藏数据、露行为**。

往后十四课，本喵一站只拆一件，慢慢把路二摆到你面前喵。
:::

::: warn 小心喵
两个坑，提前打招呼喵：

- **输出一样，不等于两条路一样。** 别拿「都能印出 12」当证据说「那随便哪条都行」——「谁在负责」完全不同：路一里，是这条流水线在负责；路二里，是每一块地垫在负责自己的面积。这一点，等加需求的时候会狠狠显出来。
- **「把招式塞进结构体里」这句话，先别急着说。** 它只说了「招式挪了个地方」，压根没碰到路二的判据。要是数据还摊在外面谁都能改，那连一半都没走到 —— 记住判据：**封装＝藏数据、露行为**。
:::

|---|---|
