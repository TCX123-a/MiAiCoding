## 钩子：橘猫追着自己的尾巴

本喵趴在窗台上，看橘猫追自己的尾巴转圈——转着转着，它「嗷」一口咬到了尾巴尖。

这个傻乎乎的画面，跟编程里一招特别像的思维方式是同一个形状：**招式里再喊自己一次**。它的正式名字叫**递归（自己咬自己尾巴的招式）**。今天本喵就用三只盘子的老游戏，把这招拆给你看喵。

## 咬尾巴的两条规矩

追尾巴这游戏，想玩得成，得守两条规矩：

1. **什么时候停。** 追到尾巴尖就停下（咬一口、松嘴、收工）。要是没有这一条，橘猫会一直转下去，转到天荒地老、转到机器冒烟。
2. **每一口都比上一口小一点。** 每转一圈，离尾巴尖都更近一点——**问题在变小**。要是原地打转、问题一点也不变小，那照样停不下来。

咬尾巴这招，一字不差就是这两条：

- **停下来的规矩**，正式叫**基线条件**（就是 n 到 0 就收手那一句）。
- **把问题变小**：自己叫自己的时候，手上的问题必须比刚才小一圈。

::: warn 小心喵
两条规矩**少一条都不行**，而且坏起来是两种不同的坏法：

- 少了**停下来的规矩** → 招式一直喊自己，喊到机器撑不住（这叫「转到天荒地老」）。
- 少了**把问题变小** → 问题原地不动，照样停不下来，坏法一模一样。

写完一招咬尾巴的招式，先别急着跑——**先用爪爪指一遍：它在哪一步停？每一次自己叫自己，问题真的变小了吗？**
:::

## 三只盘子：老游戏

现在上硬菜。老游戏叫**汉诺塔**，本喵叫它「搬盘子」：

> 三根柱子 A、B、C。三只盘子从小到大摞在 A 上，要整摞搬到 C 上。规矩两条：**一次只搬一只**；**大盘子永远不许压在小盘子上**。B 柱是给你中转用的。

3 只盘子，最少 7 步。别看只有三只——**人脑硬想容易绕晕，可这招三句话就说清楚了**：

1. 想搬 **3 层**？先假装只要搬 2 层：把最上面那 **2 层**先挪到 B 柱。
2. 现在 A 柱上只剩最底下那只大盘子——它上头空了，**直接搬到 C**。
3. 再把 B 柱上那 **2 层**挪到 C 柱，完事。

看出来了吗喵：第 1 步和第 3 步里说的又是「搬 2 层」——**同一件事，盘子少了一层**。这不就是刚才那两条规矩吗：

- **问题变小**：3 层 → 2 层 → 1 层，一层一层减下去。
- **停下来的规矩**：减到「0 层」——没有盘子要搬了，当场收手。

## 落到代码上

招式写出来是这样，跑出来是 7 行（每一行是一步）：

```python
def move(n, start, end, other):
    if n == 0:
        return
    move(n - 1, start, other, end)
    print(f"{start} → {end}")
    move(n - 1, other, end, start)

move(3, "A", "C", "B")
```

```text
A → C
A → B
C → B
A → C
B → A
B → C
A → C
```

对着刚才那三句话看喵：

- `move(n - 1, start, other, end)` 就是「先把上面那几层挪到中转柱」。
- `print(...)` 是「把最底下那只大盘子搬过去」——**每一行输出都是一步真实的搬运**。
- 最后那句 `move(n - 1, other, end, start)` 是「把中转柱上那几层再挪过来」。

**三句话，三行代码，一模一样**。这招的漂亮就在这儿：它不把 7 步全写出来，只写「这事怎么拆成更小的事」。

盘子多了会怎样？本喵让机器算一算：

```python
for n in [3, 4, 10]:
    print(f"{n} 层要搬 {2 ** n - 1} 步")
```

```text
3 层要搬 7 步
4 层要搬 15 步
10 层要搬 1023 步
```

**每多一层，步数差不多翻一倍再加一**——这正是上一课说的那种「涨得比碗快得多」的坏苗头。所以咬尾巴虽漂亮，也不是白给的：**它把问题变小，代价是它自己会被叫很多次**喵。

## 四位翻译官喵，同一招咬尾巴

拿个最小的例子看四位翻译官喵怎么写这招咬尾巴——算「4 的阶乘」（1 × 2 × 3 × 4）：

```compare
c::
#include <stdio.h>

int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

int main() {
    printf("4 的阶乘是 %d\n", fact(4));
    return 0;
}

cpp::
#include <iostream>

int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

int main() {
    std::cout << "4 的阶乘是 " << fact(4) << std::endl;
    return 0;
}

java::
public class Main {
    static int fact(int n) {
        if (n <= 1) return 1;
        return n * fact(n - 1);
    }

    public static void main(String[] args) {
        System.out.println("4 的阶乘是 " + fact(4));
    }
}

python::
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

print(f"4 的阶乘是 {fact(4)}")
```

```text
4 的阶乘是 24
```

四段是同一个形状喵：**一句停下来的规矩**（n 到 1 就返回 1）+ **一句把问题变小**（`fact(n - 1)`）。别看只有两行——把 4 代进去，它自己会一层层咬到 1，再一层层把结果叼回来：4 × 3 × 2 × 1 = **24**。

::: tip 猫咪提示
写一招咬尾巴的招式，就按两条规矩来：

1. **先写停下来的规矩**（基线条件）——**先写它**，别留到最后。它是这招的地板，没地板就没底。
2. **再写「把问题变小」**：自己叫自己时，手上那个数必须真的变小（n - 1、少一只盘子、少一层）。

看不懂别人写的咬尾巴招式时，别顺着往下追——**先找它在哪里停**，从那句往回读，一下子就通了喵。
:::
