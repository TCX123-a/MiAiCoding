## 钩子：给罐子贴张纸条

本喵的储物架上原来摆着一排**空罐子**，一个贴纸都没贴。

要记「今天小鱼干还剩 3 条」，本喵就往一只罐子上贴张纸条，写上「今日鱼干」，再把 `3` 丢进去。第二天又吃了 1 条，本喵不用把整架罐子倒出来重数一遍——只要报出**罐子上那张纸条的名字**，它就把里面的数叼回来给本喵：

```text
今日鱼干 = 3
今日鱼干 = 今日鱼干 + 1      ← 报名字，取出 3，加 1，再放回去
现在罐子里是 4
```

这个贴了名字的罐子，就是本喵说的**小鱼干仓库**喵。

有了它，你才不用把每个数都死死记在脑子里——**电脑替你记**喵。

## 第一件事：先给罐子贴名字

罐子不能拿来就用，得先贴上名字、说清里面放什么，这个罐子才算存在。

在 Python 里，贴名字和放东西是**一步做完**的：

```python
fish = 3
```

这一行的意思是：**拿一只新罐子，贴上 `fish`，把 `3` 放进去**。中间的等号不是数学课上那个「相等」，读作「**把右边装进左边的罐子**」喵。

C、C++、Java 要啰嗦一点，得先声明罐子里装什么：

```text
C        int fish = 3;
C++      int fish = 3;
Java     int fish = 3;
Python   fish = 3           ← 不用写 int，电脑自己看
```

开头那个 `int` 是在说「这罐子只装整数」。Python 省了这一步，代价是它得自己猜——猜错了，报错的时候才告诉你喵。

## 第二件事：名字不能随便起

罐子上的名字要守几条规矩：

- 只能用**字母、数字、下划线**，不能有空格和中文
- 不能拿**数字开头**：`3fish` 不行，`fish3` 可以
- **大小写是两回事**：`fish` 和 `Fish` 是两只不同的罐子
- 不能用电脑自己留着用的词：`if`、`for`、`print` 这些

还有一条不是电脑的规矩，是**给未来的你看的**：名字要起得能看懂。`a`、`b`、`x1` 这种名字，过三天你自己都不记得是干嘛的；`fishLeft`、`catName` 一眼就明白喵。

## 第三件事：罐子分好几种

罐子不是只有一种。装整数的、装小数的、装一句话的，各是各的：

```python
count = 3
price = 2.5
catName = "大肥鱼"
print(count, price, catName)
```

```text
3 2.5 大肥鱼
```

三种最常见的罐子：

| 装什么 | 猫咪说法 | 长什么样 |
|---|---|---|
| 整数 | 整数罐 | `3`、`-7`、`100` |
| 小数 | 小数罐 | `2.5`、`3.14` |
| 一串文字 | 一串小鱼干的项链 | `"大肥鱼"`、`"你好"` |

最后那种要**用引号包起来**，这是它最要紧的特征。`3` 是数字，`"3"` 是文字——在电脑眼里，这两个东西**完全不一样**喵。

## 第四件事：往罐子里放新东西

罐子里的东西随时能换。**右边先算完，再整个装进左边的罐子**：

```compare
c::
#include <stdio.h>

int main() {
    int fish = 3;
    fish = fish + 1;
    printf("%d\n", fish);
    return 0;
}

cpp::
#include <iostream>

int main() {
    int fish = 3;
    fish = fish + 1;
    std::cout << fish << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int fish = 3;
        fish = fish + 1;
        System.out.println(fish);
    }
}

python::
fish = 3
fish = fish + 1
print(fish)
```

```text
4
```

四门语言写的是一模一样的三步：**给罐子起名装 3 → 取出加 1 再装回去 → 报出罐子里的数**。跑出来都是 `4` 喵。

注意 `fish = fish + 1`：右边的 `fish` 是**先取出来的旧值**，加完 1 才装回去。它不是数学方程，是**两步动作**喵。

「取出、算、放回」这三拍到底怎么走，本喵拆成一步一步给你看：

```demo
title: fish = fish + 1 这只罐子经历了什么
code:
| fish = 3
| fish = fish + 1
| print(fish)

step 罐子贴上名字，装进 3
at: 1
say: `fish = 3` 是两步并成一步：拿一只新罐子贴上 fish，再把 3 放进去。此刻罐子里装着 3。
meow: 喵～罐子贴好名字，装进 3 条！
pose: expect
fish 罐子里 = 3
本喵手上 = （空）
屏幕上 = 还没印

step 读右边：报名字，取出旧值
at: 2
say: 轮到 `fish = fish + 1` 了。电脑**先看等号右边**：右边那个 `fish` 是报名字，把罐子里的旧值叼出来 —— 取到的是 **3**。
meow: 报名字，叼出来的是 3！
pose: busy
fish 罐子里 = 3
本喵手上 = 3
屏幕上 = 还没印

step 右边算完：3 + 1 得 4
at: 2
say: 取出来的 3 加上 1，等号右边算完是 **4**。**注意：这一步罐子里还是 3，一点没变** —— 电脑还没往罐子里放东西。
meow: 3 加 1 等于 4，先捏在手上～
pose: busy
fish 罐子里 = 3
本喵手上 = 4
屏幕上 = 还没印

step 装回左边那只罐子
at: 2
say: 等号**右边全部算完**，才把结果整个装进左边那只罐子。fish 从 3 变成 4，手上的东西放下了 —— 这就是课文说的「两步动作」。
meow: 把 4 装回罐子，罐子满上喵！
pose: yay
fish 罐子里 = 4
本喵手上 = （空）
屏幕上 = 还没印

step 报出罐子里的数
at: 3
say: 最后一行 `print(fish)` 也是报名字，把罐子里的数叼出来印在屏幕上 —— **4**。上面四门语言的 compare 块跑出来都是这个 4。
meow: 罐子里是 4，印出来啦！
pose: proud
fish 罐子里 = 4
本喵手上 = （空）
屏幕上 = 4
```

**记住这一条就不会再绕晕**：等号右边永远**先全部算完**（报名字取的是**旧值**），算完了才装进左边。所以 `fish = fish + 1` 不是方程，是「取出、算、放回」三拍。

::: tip 猫咪提示
今天记住三步就够：**先贴名字、再定种类、然后把东西放进去**。`=` 读作「把右边装进左边」，不是数学上的相等——这一条理解对了，后面所有赋值都不会再绕晕喵～
:::

::: warn 小心喵
别贪多！今天记住「整数罐、小数罐、项链罐」三种就够了。电脑里的罐子种类还有十几种（长整数、单精度、双精度、布尔……），那是各语言开课时才细讲的东西，现在看只会晕喵。
:::
