## 钩子：上一课欠的账

上一课本喵撂下一句话：**「排好，是后面很多巧办法的地基」**——掐中间翻的前提就是那一排得先排好。

今天就把这笔账还上：**怎么把一排碗排好？** 前辈猫传下来三条路，都说自己好使。本喵把同一排碗 `[5, 2, 9, 1, 8, 6]` 摆出来，三条路各走一遍给你看喵。

## 路一：挨着比，大的往后冒

第一条路最好懂：**从最左边开始，挨着两两比一比——左边那只大，就把它俩换个个儿。**

比完一轮会怎样？最大的那只一路被换到最右边——**像气泡从水底冒上来一样**，所以这条路叫**冒泡排序（让大的冒到末尾）**。

拿本喵那排碗走一轮：

| 比哪两只 | 要换吗 | 换完这一排长这样 |
|---|---|---|
| 0 号和 1 号：5 和 2 | 5 大，换 | `[2, 5, 9, 1, 8, 6]` |
| 1 号和 2 号：5 和 9 | 9 大，不动 | `[2, 5, 9, 1, 8, 6]` |
| 2 号和 3 号：9 和 1 | 9 大，换 | `[2, 5, 1, 9, 8, 6]` |
| 3 号和 4 号：9 和 8 | 9 大，换 | `[2, 5, 1, 8, 9, 6]` |
| 4 号和 5 号：9 和 6 | 9 大，换 | `[2, 5, 1, 8, 6, 9]` |

一轮走完，**9 稳稳落在末尾**——它不用再比了。下一轮只比前 5 只，第二轮末尾定下第二大的……一轮比一轮短。

一轮要比 5 次，共 5 轮：5 + 4 + 3 + 2 + 1 = **15 次**。

## 路二：每轮挑出最小的那只

第二条路换个想法：**别挨着换了，一轮扫一遍，先找到最小的是哪只碗，再把它跟最前面那只换。**

这条路叫**选择排序（每轮挑最小的）**。好处是**换的次数少**——一轮只换一次，不像冒泡一路换过去。

同一排碗走一轮：扫一遍发现最小的是 **1**（在 3 号碗），跟 0 号碗换个位：

> `[5, 2, 9, 1, 8, 6]` → `[1, 2, 9, 5, 8, 6]`

第一只碗定下来了。下一轮在剩下的 2~5 号里挑最小、跟 1 号碗换……比法一轮比一轮短，6 只碗合起来也是 **15 次比较**，可**最多只换 5 次**。

## 路三：像抓牌那样，抓一张塞一张

第三条路最有生活气：**假装你在理一手牌**。牌是一张一张抓进来的，每抓一张，就把它往左边那半——**已经理好的那半**——里塞，塞到该在的位置上。

这条路叫**插入排序（像插队那样塞进去）**。

同一排碗走一轮：左边先看作「已理好」的一只碗 `5`，抓来第二只碗 `2`：

> `[5 | 2, 9, 1, 8, 6]` → `2` 比 `5` 小 → 塞到 `5` 前面 → `[2, 5 | 9, 1, 8, 6]`

像不像理牌喵：抓一张，塞一张，手里那半永远是有序的。

它有个独门本事：**那排本来就差不多排好了的时候，它快得离谱**。因为每抓一张，往左边比一下——位置正好对，塞都不用塞。已经排好的 6 只碗，它只要比 **5 次**（每一只跟前一只比一下，都不用挪）。

## 三条路的账

让机器把三笔账念一遍：

```python
n = 6
print(f"冒泡：比 {n * (n - 1) // 2} 次")
print(f"选择：比 {n * (n - 1) // 2} 次，最多换 {n - 1} 次")
print(f"插入：最差比 {n * (n - 1) // 2} 次，排好的那排只要 {n - 1} 次")
```

```text
冒泡：比 15 次
选择：比 15 次，最多换 5 次
插入：最差比 15 次，排好的那排只要 5 次
```

| 路 | 怎么走 | 最差要动多少下 | 独门本事 |
|---|---|---|---|
| 冒泡 | 挨着比，大的往后冒 | 15 次比较，换的次数也最多 | 一眼看懂，几乎不会写错 |
| 选择 | 每轮挑最小，跟最前面换 | 15 次比较，最多换 5 次 | 换得少（换一下的代价比看一眼贵的时候，它划算） |
| 插入 | 像抓牌，抓一张塞一张 | 最差 15 次比较 | **几乎排好的那排，它最快** |

6 只碗上三条路都要动 15 下左右——**又应了上一课那句老话：碗少的时候，谁也显不出本事**。可要记住的是：它们的动作次数都会跟着碗数「翻倍就翻四倍」（前面「哪个干法更省力」那一课算过的账）——碗一多，三条路就都开始喘了。真正快的排法（下一阶段才会遇到）靠的是另一手：**把大问题劈成两半**。

## 四位翻译官喵，各挑一遍最小的

选择这一路的核心是「扫一遍，挑出最小的那只碗」。四位翻译官喵各写一遍：

```compare
c::
#include <stdio.h>

int main() {
    int bowls[6] = {5, 2, 9, 1, 8, 6};
    int small = 0;
    for (int i = 1; i < 6; i++) {
        if (bowls[i] < bowls[small]) small = i;
    }
    printf("最小的在 %d 号碗，是 %d\n", small, bowls[small]);
    return 0;
}

cpp::
#include <iostream>

int main() {
    int bowls[6] = {5, 2, 9, 1, 8, 6};
    int small = 0;
    for (int i = 1; i < 6; i++) {
        if (bowls[i] < bowls[small]) small = i;
    }
    std::cout << "最小的在 " << small << " 号碗，是 " << bowls[small] << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int[] bowls = {5, 2, 9, 1, 8, 6};
        int small = 0;
        for (int i = 1; i < 6; i++) {
            if (bowls[i] < bowls[small]) small = i;
        }
        System.out.println("最小的在 " + small + " 号碗，是 " + bowls[small]);
    }
}

python::
bowls = [5, 2, 9, 1, 8, 6]
small = 0
for i in range(1, 6):
    if bowls[i] < bowls[small]:
        small = i
print(f"最小的在 {small} 号碗，是 {bowls[small]}")
```

```text
最小的在 3 号碗，是 1
```

四段说的是同一件事：**记下「到目前为止最小的那只在哪」**，一路扫到底。本喵扫到 3 号碗（里面是 1）之后，再没有哪只比它小，所以 `small` 停在 3。挑出最小的只是第一轮——下一轮要在 1~5 号里再挑一遍，如此往复喵。

::: tip 猫咪提示
三条路各有各的脾气，挑的时候问自己两句话：

1. **这堆东西本来有多乱？** 差不多已经排好了 → 插入最省事；乱成一团 → 三条路半斤八两。
2. **换一下贵不贵？** 换一下比看一眼贵得多（比如搬的是大箱子）→ 选择换得最少，划算。

三条路都不难写、也都好懂，代价却是一个量级的——**它们是排排坐的入门砖，不是终点**喵。
:::

::: warn 小心喵
换两只碗的时候，**别直接对着倒**：

```text
✗ bowls[j] = bowls[j + 1]
  bowls[j + 1] = bowls[j]     ← 这两行执行完，两只碗里是一样的数！
```

第一行已经把原来的值冲掉了，第二行拿到的就是刚倒进去的那个数，**两只碗变成一个味儿**。借个空碗 `temp` 倒一手（先存、再倒、再倒回），或者用 Python 的一行交换 `bowls[j], bowls[j + 1] = bowls[j + 1], bowls[j]`——就是不许直接对倒喵。
:::
