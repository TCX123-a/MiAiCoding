## 钩子：本喵只生了一只猫，爪子里却攥出两支遥控器

上一课《`main` 只是一扇门》里，本喵把「这活是谁的」捋清楚了一半：static 是画在**图纸上**的，每只真猫自己带的那份才是**实例成员**；`main` 只是一扇门，不是全部设计喵。

今天本喵在门口撞上一件更邪门的事。

本喵手里有一只小橘，是这么生出来的：

```java
Cat c1 = new Cat();
c1.fish = 3;
```

狸花来串门，本喵想跟它说「这只借你看看」，顺手写了一句：

```java
Cat c2 = c1;
```

本喵心里的算盘是：这一步就等于「**又拿了一只**」—— 给本喵自己也备一只，两边各喂各的。

于是本喵招待狸花，把 `c2` 的鱼干添到 99：`c2.fish = 99;`。

再回头看小橘 —— `c1.fish` 也变成 99 了。

本喵明明只写过**一次** `new Cat()`，就那一只。什么时候，爪子里悄悄攥出了**两支遥控器**的？

今天这张内存图，就是案发现场的第一张照片 —— 也是全课最值钱的一张喵。

## 一、第一张内存图：名字是遥控器，真猫是电视机

本喵一路都在说**变量（贴了名字的小鱼干仓库）**：`int fish = 3;` 就是摆一只碗装 3，碗里躺着 3 本身。这条规矩今天不变 —— 但要给它补上后半张图。

真猫和 3 不一样。3 小得能整个塞进格子；真猫是一整只：有名字、有鱼干数、会喵一声。这么大的家伙**不住在格子里**，它住在一间专门的**猫屋**里。格子里装的，是一支**对着它的遥控器**。

```text
   本喵手边的名册                猫屋（真猫住的地方）
   ─────────────────────        ──────────────────────
   c1 的格子：一支遥控器 ──▶   小橘：名字「小橘」、鱼干 3 条
```

这套规矩，行话里叫**引用语义（抄遥控器）**：**名字是遥控器，猫屋里那只真猫才是电视机**。抄一支遥控器，不会多出一台电视机；拿着任何一支对着它的遥控器动手，改的都是同一台。

老规矩也有它的名字，叫**值语义（整只复印）**：名字里装的就是**货本身**，抄一份就是又一份货 —— 你一路写的 `int`、`double`，走的全是这条道。

于是那句「案发台词」就该拆成两种命运来问：

> **`Cat c2 = c1;` —— 抄的是遥控器，还是电视机？**

- 抄的是**遥控器** → 名册上多一格，猫屋里还是**一只猫**；
- 抄的是**电视机** → 另起一间猫屋，住进**第二只猫**。

两张图长这样，先认下来喵：

```text
   图一：两个名字，一只猫
   c1 的格子：一支遥控器 ─┐
                          ├──▶ 小橘（鱼干 3 条）
   c2 的格子：一支遥控器 ─┘

   图二：两只猫，各管各的
   c1 的格子：一支遥控器 ──▶ 小橘（鱼干 3 条）
   c3 的格子：一支遥控器 ──▶ 狸花（鱼干 1 条）
```

哪门语言的等号抄的是哪一种，下一节本喵就带你分家喵。

## 二、C 的地盘：复印还是共享，你亲爪写下

先回 C 那门老手艺。C 里画一张 `Cat` 图纸（结构体），想生出第二只，写法只有一种：

```c
typedef struct {
    int fish;
} Cat;

Cat c1;
Cat c2;
Cat *p;

c1.fish = 3;
c2 = c1;          /* 整只复印：猫屋里多出第二只，往后改 c2 不动 c1 */
p = &c1;          /* 想共享：没有捷径，自己递一张猫爪指向牌 */
p->fish = 88;     /* 顺着牌子改 —— 改的是 c1 那一只猫本体 */
```

- **`c2 = c1;` 是整只复印（值语义）**：猫屋里真的站起了第二只猫，3 条鱼干原样搬过去。从此两只互不打扰。
- **`p = &c1;` 是亲手递牌**：那张猫爪指向牌（指针）看着的就是 `c1` 那一只；顺着 `p->fish` 改的，是猫屋里的本体。

一句话总结 C 的精神：**复制还是共享，永远是你亲手写下的** —— 写等号就是复印，递牌子才是共享，翻译官喵从不替你做主。

出了 C 的地盘，四位翻译官喵就分家了：

- **C++ 跟 C 站一边**：默认整只复印（值语义）。想共享，得把话亲手写清楚：`Cat& c2 = c1;` —— 那个 `&` 是前面几课认过的「别名」，定义即初始化、从一而终。
- **Java 和 Python 站另一边**：默认的等号抄的就是**遥控器**；想要真备份，得自己另造一只。

同一句话在这四位手里的四种下场，本喵一段一段摆给你看喵。

## 三、四位翻译官喵，同一句 `c2 = c1;`

同一条台词：手上有 3 条鱼干的 `c1`，把 `c1` 交给 `c2`，然后**只给 `c2` 喂到 99**，回头看看 `c1` 是多少喵。

```c
#include <stdio.h>

typedef struct {
    int fish;
} Cat;

int main(void) {
    Cat c1;
    Cat c2;
    c1.fish = 3;
    c2 = c1;              /* 整只复印：c2 是第二只猫 */
    c2.fish = 99;
    printf("c1 有 %d 条\n", c1.fish);
    printf("c2 有 %d 条\n", c2.fish);
    return 0;
}
```

```text
c1 有 3 条
c2 有 99 条
```

```cpp
#include <iostream>
using namespace std;

class Cat {
public:
    int fish;
};

int main() {
    Cat c1;
    c1.fish = 3;
    Cat c2 = c1;          // 默认整只复印（值语义）
    c2.fish = 99;
    cout << "c1 有 " << c1.fish << " 条" << endl;
    cout << "c2 有 " << c2.fish << " 条" << endl;
    return 0;
}
```

```text
c1 有 3 条
c2 有 99 条
```

```java
public class Main {
    static class Cat {
        int fish;
    }

    public static void main(String[] args) {
        Cat c1 = new Cat();
        c1.fish = 3;
        Cat c2 = c1;      // 抄的是一支遥控器
        c2.fish = 99;
        System.out.println("c1 有 " + c1.fish + " 条");
        System.out.println("c2 有 " + c2.fish + " 条");
    }
}
```

```text
c1 有 99 条
c2 有 99 条
```

```python
class Cat:
    def __init__(self, fish):
        self.fish = fish

c1 = Cat(3)
c2 = c1               # 两个名字，贴同一只猫
c2.fish = 99
print(f"c1 有 {c1.fish} 条")
print(f"c2 有 {c2.fish} 条")
```

```text
c1 有 99 条
c2 有 99 条
```

看明白了吗喵：**同一句「把 c1 交给 c2」，左边两位抄的是电视机，右边两位抄的是遥控器**。

- **C**：`c2 = c1;` 整只复印，猫屋里站着两只 —— 改了 c2 那只，c1 那只一根毛都没动。
- **C++**：默认和 C 同命，也是整只复印（值语义）。想共享，得把话**写明白**：`Cat& c2 = c1;` —— 「再挂一个名字，还是同一只」。写成这样再改 `c2.fish`，c1 立刻是 99，跟右边两位同款。
- **Java**：`Cat c2 = c1;` 抄的是**遥控器** —— 名册多一格，猫屋没多猫。`c2.fish = 99` 顺着遥控器走进猫屋，改的是小橘本体；c1 手里那支对着同一只，当然也看见 99。
- **Python**：和 Java 同命。`c2 = c1` 只是给同一只猫再贴一个名字；往后动谁，都是动这只猫。

把这四方摆成一张表（这课最值得抄进小本本的一张喵）：

| 语言 | `c2 = c1;` 这一句干了什么 | 改 `c2.fish` 之后 `c1.fish` |
|---|---|---|
| C | 整只复印（值语义）：猫屋里多一只 | 3（纹丝不动） |
| C++ | 整只复印（值语义，默认）；想共享另写 `Cat& c2 = c1;` | 3（纹丝不动） |
| Java | 抄遥控器（引用语义）：对着同一只猫 | 99（一起变） |
| Python | 抄遥控器（引用语义）：同一个名字贴同一只猫 | 99（一起变） |

一句话记牢：**C 和 C++ 默认「复印电视机」，Java 和 Python 默认「复印遥控器」**；C++ 想借道去共享那一边，一句 `Cat&` 就够了喵。

## 四、走一遍：两个名字，一只猫

C 和 C++ 想借道去共享那一边，得把话**写明白**：C 亲手递牌（`c2 = &c1;`），C++ 明写别名（`Cat& c2 = c1;`）。把话写明白之后，四位的下场一字不差喵：

```compare
c::
#include <stdio.h>

typedef struct {
    int fish;
} Cat;

int main(void) {
    Cat c1;
    Cat *c2;              /* 想共享：亲手递一张猫爪指向牌 */
    c1.fish = 3;
    c2 = &c1;
    c2->fish = 99;
    printf("顺着 c1 看：%d 条\n", c1.fish);
    printf("顺着 c2 看：%d 条\n", c2->fish);

cpp::
```

## 五、空遥控器：`null` 和 `None`，一按就崩

还有第三种遥控器：**谁也没对着**的空遥控器。Java 里它叫 `null`，Python 里它叫 `None`。

```java
Cat c2 = null;
c2.fish = 99;     // 啪 —— 当场崩
```

Java 这一按会给你一句 `NullPointerException`；Python 那边 `c3 = None` 之后再写 `c3.fish`，翻译官喵报的是 `AttributeError`（`'NoneType' object has no attribute 'fish'`）。这不是「空遥控器会自动变出一只猫」，是**一按就崩** —— 因为根本没有电视机给你按。

老熟人喵：这就是 C 段那张**空牌子**换了身行头。`Cat *p = NULL;` 谁也没指，你要是不检查就顺着它走（`p->fish`），同一个下场：当场栽。另外——C++ 里给同一只猫再挂的名字**不能空着**（定义即初始化、从一而终，前面几课立的规矩），所以 C++ 里想留一手「先不指向谁」，还得请猫爪指向牌出马：`Cat *p = nullptr;`。

一句话：**空遥控器是合法的，按它是非法的** —— 动手之前先问一句「这支遥控器真对着猫吗喵」。

## 六、带一句：`==` 比的是哪台电视机；复印的深浅

最后两句话，各带一句就够。

**第一句：比猫，比的是什么。** Java 里 `c1 == c2` 问的不是「两只猫长得一样吗」，而是「**两支遥控器是不是对着同一台电视机**」；比「内里一样不一样」要用 `.equals(...)` —— 两串字比一样一律用 `.equals`，这条是 Java 的规矩，今天先认一句，往后 Java 线里再细讲。Python 走的也是先问「是不是同一只」那道门：不自己写比较规矩，`==` 只认「同一个本体」。

**第二句：复印的深浅。** 今天说的「整只复印」，复印的是**格子里那点货**。要是这只猫身上装着一张**指向别处的牌子**，那「整份照抄」抄过去的照样是**同一张牌子** —— 两只猫会共用远处那间屋。这个坑本喵先埋一颗种子：往后 C++ 那一线会专门回来收拾它，那门手艺的名字叫**深拷贝**。

::: tip 猫咪提示
今天这一课，收进小本本的就三行喵：

1. **名字是遥控器，真猫是电视机** —— 猫屋里的才是本体；抄遥控器不会多出猫，改电视机两边都看得见。
2. **分水岭在语言**：C 和 C++ 默认复印电视机（值语义），Java 和 Python 默认复印遥控器（引用语义）；C++ 想共享就写 `Cat& c2 = c1;`，C 想共享自己递猫爪指向牌。
3. **空遥控器（`null` / `None`）合法，按它违法** —— 照旧是 C 段那张空牌子换了身行头。
:::

::: warn 小心喵
两个最容易踩的坑，本喵标出来：

- **从 C 带来的「赋值＝复印」直觉，到 Java / Python 会悄悄失效**：看着一模一样的一句 `c2 = c1;`，在 C 里是「又一只猫」，在 Java / Python 里是「又一支遥控器」。动手前先问：这门的等号，抄的是哪一样？
- **「我只改了备份」型事故**：想留个备份，抄的却是遥控器 —— 于是改备份，把原件也改了。真备份要**另造一只**（`new` / `Cat(...)` 再生一只，把数照搬过去），千万别抄遥控器。
:::

## 一句话对照表

| 本喵写下的 | 它的意思 |
|---|---|
| `Cat c1 = new Cat();`（Java） | 造一台新电视机，把对着它的遥控器装进 `c1` |
| `Cat *p = &c1;`（C） | 亲手递一张猫爪指向牌 —— 共享是**写出来的** |
| `c2 = c1;`（C / C++） | 整只复印：猫屋里多出第二只（值语义） |
| `c2 = c1;`（Java / Python） | 抄一支遥控器：两个名字一只猫（引用语义） |
| `Cat& c2 = c1;`（C++） | 明写「同一只的第二个名字」—— 借道去共享那一边 |
| `Cat c2 = null;` / `c3 = None` | 空遥控器：没对着任何一台，一按就崩 |
| `c1 == c2`（Java） | 问「两支遥控器是不是对着同一台电视机」，不是「长得一样吗」 |
