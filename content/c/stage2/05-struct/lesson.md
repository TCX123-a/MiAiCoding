## 钩子：本喵快被仓库淹死了

本喵要记账：鱼塘边有十只猫，每只都得记**名字**和**今天吃了几条小鱼干**。

照老办法，这是二十只仓库 —— `cat1name`、`cat1fish`、`cat2name`、`cat2fish`……写到第五只，本喵就想掀桌子了喵。更糟的是：本喵想写一招「给某只猫添一条小鱼干」，得同时喂进去两个东西（哪只猫、添几条），喂错一次，橘猫的数就跑到狸花猫头上了。

问题不在于仓库不够 —— 上一课刚学过「现要现租」，地方管够。问题是**这二十只仓库明明是同一个东西的两半，C 却不知道它俩是一伙的**。

顺手留个路标喵：这份「它俩明明一伙，C 却装作不认识」的别扭，通用课里有一整课正面讲 ——《半个对象——结构体+函数，还差的那半》。今天先把图纸画稳。

今天本喵要画一张**图纸**：把「一只猫该有什么」一次说清楚，以后照它生出来的每一只，都自带这两样东西喵。

## 一、先画一张图纸

图纸长这样：

```c
struct Cat {
    char name[20];
    int fish;
};
```

一句话读完：**「一只猫，有一个最多装得下 20 个字符的名字碗排，还有一个装整数的小碗。」**

拆开看喵：

- **`struct`** —— 一个记号，意思是「本喵要画图纸了」。这个词读作「结构体」。
- **`Cat`** —— 图纸的名字，随你起。
- **一对花括号 `{ }`** —— 图纸的框，里面一行一行写「这只猫有什么」。
- **`char name[20];`** —— 第一样：名字。名字是**一排字符碗**（一条项链的家），所以写成上一课那个摆碗的样子，20 是给它留的位置。
- **`int fish;`** —— 第二样：食量，一只普通的整数碗。
- **最后那个分号 `;`** —— 花括号闭合之后还**必须**有一个分号。少了它，翻译官喵会一直等着你往下写。

**图纸本身不是猫。** 它只说明「照它生出来的猫长什么样」，自己不占猫的位置，也不能往图纸上记「小橘今天吃了三条」—— 那是真猫的事喵。

## 二、照图纸生一只猫，用点号取用

有了图纸，生猫的写法是在图纸名字前面加一个 `struct`：

```c
#include <stdio.h>
#include <string.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat a;

    strcpy(a.name, "小橘");
    a.fish = 3;
    printf("%s 今天吃了 %d 条喵\n", a.name, a.fish);
    return 0;
}
```

```text
小橘 今天吃了 3 条喵
```

逐行看喵：

- **`struct Cat a;`** —— 照 `Cat` 这张图纸，生出一只名叫 `a` 的猫。它一生出来就**自带**两个碗：`a.name` 和 `a.fish`。
- **`strcpy(a.name, "小橘");`** —— 往名字里写东西。为什么不能直接写 `a.name = "小橘";`？因为**名字是一排碗（一条项链），不是一只碗**。上一课讲过，一排碗不能整个换掉，只能一颗一颗搬进去 —— `strcpy` 就是那位会干这个的档案管理员，它住在 `string.h` 家，所以文件头上要请它出场。
- **`a.fish = 3;`** —— `fish` 是一只普通的整数碗，直接写就行。
- **`a.name` / `a.fish`** —— 中间那个**点号**就是「这只猫的这一样」。念作「`a` 的 `name`」。

**图纸上的名字叫「成员」**，点号就是进门的钥匙：`a.name` 是「`a` 这只猫的名字那一格」。同一张图纸生出来的两只猫，各有各的 `a.name`、各有各的 `a.fish`，互不打扰喵。

图纸生猫、再一格一格填进去，这一整串动作本喵拆成一步一步走给你看喵：

## 三、出生的时候就填好

一只一只喂太啰嗦，可以在生出它的时候按**图纸上写的顺序**把值一起给：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat a = {"小橘", 3};

    printf("%s 今天吃了 %d 条喵\n", a.name, a.fish);
    return 0;
}
```

```text
小橘 今天吃了 3 条喵
```

花括号里两个值按顺序对上图纸里的两行：第一个 `"小橘"` 进 `name`，第二个 `3` 进 `fish`。**顺序不能反** —— 反了就成了「名字叫 3、食量是小橘」，翻译官喵会当场拦下（本喵真跑过，它报的是 `error: initialization of 'char' from 'char *'`），但这种错写起来一点也不难喵。

名字这一格是项链，所以这里可以直接拿双引号喂它，不用再喊 `strcpy` —— 出生的时候一次摆好，是允许的。

## 四、一排猫

有了图纸，一只猫就是**一样东西**，那自然也能摆成一排：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat cats[3] = {
        {"小橘", 3},
        {"狸花", 5},
        {"大肥鱼", 9}
    };
    int total = 0;

    for (int i = 0; i < 3; i++) {
        printf("%s 吃了 %d 条喵\n", cats[i].name, cats[i].fish);
        total = total + cats[i].fish;
    }
    printf("一共 %d 条喵\n", total);
    return 0;
}
```

```text
小橘 吃了 3 条喵
狸花 吃了 5 条喵
大肥鱼 吃了 9 条喵
一共 17 条喵
```

这一排叫**结构体数组（一排猫）**，写法和上一课的碗排**一模一样**：方括号里写几只，花括号里逐只把值列出来（每只自己再套一层花括号）。

取用的时候两层一叠：**`cats[i].name`** —— 先报编号拿到第 `i` 只猫，再用点号进它的 `name` 那一格。念作「第 `i` 只猫的名字」。

本喵一开始那二十只仓库的烦恼，到这里就没了：**一排猫，每只自带名字和食量**，跑圈一圈就把整排收拾干净。想写「给某只猫添一条小鱼干」的招式，也只需要喂**一只猫**进去了喵。

## 五、整只猫可以整个搬

这是一件让上一课的一排碗很羡慕的事：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat a = {"小橘", 3};
    struct Cat b;

    b = a;
    b.fish = 99;
    printf("%d\n", a.fish);
    printf("%d\n", b.fish);
    return 0;
}
```

```text
3
99
```

`b = a;` 这一句，把 `a` 这只猫身上的**每一格**都抄进了 `b`（名字也抄了 —— 是一颗一颗珠子搬过去的）。所以改 `b.fish` 的时候，`a.fish` 一动不动，还是 `3`。

**这和上一课的一排碗刚好相反**：一排碗写成 `a = b;` 会被翻译官喵当场拦下（「一整排不能整个换掉」），而图纸生出来的猫**可以整个搬**。因为猫是「一样东西」，不是「一排东西」喵。

## 六、忘了带 `struct` 记号

图纸画好了，生猫的时候手一滑，把前面的记号忘了：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    Cat a;

    a.fish = 3;
    printf("%d\n", a.fish);
    return 0;
}
```

```text
main.c:9:5: error: unknown type name 'Cat'; use 'struct' keyword to refer to the type
    9 |     Cat a;
```

翻译官喵的原话很有意思，它不光说「不认识」，还**顺手告诉你该怎么改**：**「`Cat` 这个名字本喵没见过 —— 要用它，前面得带上 `struct`。」**（后半句 `use 'struct' keyword to refer to the type` 就是这个意思。）

**在 C 里，图纸的名字前面永远要带 `struct`**：不管是生猫（`struct Cat a;`）、摆一排猫（`struct Cat cats[3];`），还是写在招式头上，都少不了这个记号。多打四个字母，换来翻译官喵一眼就认识，很划算喵。

::: warn 小心喵
两条最常摔的，本喵给你标出来：

- **名字那一格是项链，不是一只碗。** 想换它的内容，要用 `strcpy(a.name, "小橘");`；直接写 `a.name = "小橘";` 会被拦下（一排碗不能整个换掉）。出生时用花括号一次填好是例外，那种写法允许。
- **花括号后面那个分号别丢。** 图纸的结尾是 `};` —— 少了分号，翻译官喵会以为你还要往下写。
:::

::: tip 猫咪提示
今天四句话：

1. **`struct Cat { ... };` 是图纸**，说明「一只猫有什么」；图纸本身不是猫，结尾那个分号别丢。
2. **`struct Cat a;` 照图纸生一只**，用**点号**进门：`a.name`、`a.fish`。名字前面永远记得带 `struct`。
3. **名字那一格是一排碗**，要写东西得请 `strcpy` 出手；出生时用 `{"小橘", 3}` 一次填好也可以，顺序照图纸来。
4. **`struct Cat cats[3]` 是一排猫**，取用写 `cats[i].name`；整只猫可以 `b = a;` 整个搬，这一点比一排碗方便。
:::
