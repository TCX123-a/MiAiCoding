## 钩子：先摆碗，还是先租仓库喵？

本喵要开一场猫猫大会，来一只猫就发一条小鱼干。要是提前摆好**一排贴编号的猫粮碗（数组）**，就得先决定摆几只碗：只来 3 只猫却摆了 200 只碗，白占地方；来了 20 只猫却只有 5 只碗，多出来的猫只能干瞪眼喵。

能不能「来了几只猫，再租几间仓库」呢？当然可以！这就是**动态内存分配（现要现租的仓库）**：程序跑到那一步，才向系统伸手要地方，用完了再还回去。

## malloc 与 free：租一间，还一间

租仓库的招式叫 `malloc`，还仓库的招式叫 `free`，它们住在 `stdlib.h` 这位档案管理员家里，所以开头要请它出场。看一间仓库的完整一生：

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 4;                                    /* 这次要 4 间 */
    int *rooms = (int *)malloc(sizeof(int) * n);  /* 伸手租 n 间 */

    if (rooms == NULL) {                          /* 没租到怎么办？ */
        printf("仓库没租到喵\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        rooms[i] = (i + 1) * 10;                  /* 和猫粮碗一样按编号取用 */
    }

    for (int i = 0; i < n; i++) {
        printf("第 %d 间：%d\n", i, rooms[i]);
    }

    free(rooms);      /* 用完了，还回去 */
    rooms = NULL;     /* 把牌子擦干净，别留着 */
    return 0;
}
```

真跑起来是这样的喵：

```text
第 0 间：10
第 1 间：20
第 2 间：30
第 3 间：40
```

记住三件事：`malloc` 叼回来的是一张**猫爪指向牌（指针）**，牌子上写着第一间仓库的地址；租不到时它叼回 `NULL`，所以**每次都要看一眼是不是 NULL**；用完了必须 `free`，再把牌子擦成 `NULL`，免得下次误以为还能用喵。

一间仓库从租到还，整个过程是这样喵。留意 `rooms` 这一栏：它自始至终只是一块**牌子**，牌子上写的是第 0 间的门牌号 —— 租来的一排仓库本身，屏幕上只能看到「第 0 间在哪」和「这几间里装了什么」这两件事。

::: warn 为什么「还完要擦牌子」和第 3 步「先看 NULL」是同一件事
两处都在防同一个东西：**顺着一块指向「已经没有了的仓库」的牌子走。**
第 3 步防的是「压根没租到」，第 11 步防的是「已经还掉了」。
C 在这两处都**不会拦你**，它只会安安静静让你读到一堆莫名其妙的数 —— 所以这两句永远手写，别省喵。
:::

顺带认一个往后天天见面的省字写法：一句 `sum = sum + p[i];` 可以缩写成 `sum += p[i];`，读作「把右边**加进**左边那只仓库」。同类的还有 `-=`（减掉）、`*=`（乘进去），一个道理喵。它跟前面那种「取出来、算好、再装回去」是**完全同一件事**，只是少打几个字——读别人的 C 代码时认得它，就够用了。

## sizeof：随身带的小尺子

`sizeof` 是**运算符**，不是招式（函数）：它不用加括号投喂，也不必喊名字，写 `sizeof(int)` 和 `sizeof x` 都行，翻译官喵在翻译阶段就把它换成一个小数字了。

那为什么租仓库要写 `malloc(sizeof(int) * n)`？因为仓库是论**字节**租的，而一个 `int` 占几格要看机器、看类型。让翻译官喵自己拿尺子量一间（`sizeof(int)`），再乘上你要的间数 `n`——**先量一间、再乘间数**，顺序千万别记反。

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

printf("%d\n", (int)sizeof(arr));                   /* 20：整排的总格数 */
printf("%d\n", (int)sizeof(p));                     /* 8：牌子自己的大小 */
printf("%d\n", (int)(sizeof(arr) / sizeof(arr[0])));/* 5：一共有几只碗 */
```

分成两步看就懂了：量整排给的是**总格数**（20），量一张牌子给的是**牌子自己的大小**（8）——它可不是被指向那间仓库的大小！所以「总格数 ÷ 每只碗的格数」才是碗的只数，这个写法很常用，收下喵。

::: warn 小心喵
最大的坑在这：一旦一排碗交到招式手里，收到的只是**一张牌子**，招式再拿 `sizeof` 去量，量出来的就只有牌子自己（8）啦，那排碗到底有几只它根本问不出来。所以往后的招式要么额外收一个「几只」的投喂，要么像以后要学的「链子」那样用末尾的空爪子收尾——两种办法本喵都会教喵。
:::

## 内存泄漏：借了仓库不还

借了仓库不还，管理员就永远腾不出那一间。程序一边跑一边借，地方越占越多，最后会嗷一声被系统赶出去——这就是**内存泄漏（借了仓库不还）**。C 里没有**自动铲屎官（内存回收）**，租和还全凭你亲手来喵。

::: tip 猫咪提示
收好这三句：`malloc` 租、`free` 还、还完把牌子擦成 `NULL`；`sizeof` 是运算符不是招式，量碗给总格数、量牌子只给牌子大小；租完先看 `NULL`，用完必定还。
:::
