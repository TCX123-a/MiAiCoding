## 钩子：项链那一课欠你一个交代

上学期串项链的时候，本喵撞上过一件怪事：两条**看起来一模一样**的项链，拿 `==` 一比却说「不一样」。当时本喵说「因为比的是牌子，不是珠子」—— 然后拍拍尾巴就走了，牌子到底是什么，一个字没讲。

现在你手里有牌子了，这笔账该还了喵。

今天你会发现，上一课那套「名字就是第一颗珠子的门牌号」「牌子往后挪一格」的玩法，换到项链上不但照样成立，而且**比在碗排上还好使**。

## 一、项链的名字，也是一块牌子

先看最省事的写法：

```c
#include <stdio.h>

int main(void) {
    char *s = "cat";

    printf("%s\n", s);
    printf("%c\n", *s);
    return 0;
}
```

```text
cat
c
```

逐行看喵：

- **`char *s = "cat";`** —— 牌子 `s` 上写的是「指着一个字符碗的位置」，它出生就指着这条项链的**第一颗珠子**。和上一课 `int *p = bowls;` 是同一个道理：项链的名字，就是第一颗珠子的门牌号。
- **`printf("%s\n", s);`** —— `%s` 要的口子就是**一块牌子**，不是一整条项链。它顺着牌子一颗一颗往外念，念到暗号 `\0` 就闭嘴。所以印出来的正是 `cat`。
- **`printf("%c\n", *s);`** —— 顺着头一颗，`%c` 只念一颗，印出 `c`。

上一课那个「一排碗交出去是一块牌子」的谜底，在这里更直白：**`%s` 从头到尾拿的就是一块牌子**。项链这条规矩你早就用着了，只是今天才知道它叫什么喵。

## 二、牌子的加一，跨的是一颗珠子

本阶段第一课「指针深入」的提示框里，本喵埋过一句：写着字符的牌子，加一只跨 1 格。今天兑现：

```c
#include <stdio.h>

int main(void) {
    char *s = "cat";

    printf("%s\n", s);
    printf("%s\n", s + 1);
    printf("%s\n", s + 2);
    return 0;
}
```

```text
cat
at
t
```

- `s` 从第一颗珠子开始念：`cat`。
- `s + 1` 让牌子往后挪**一颗珠子**，从 `a` 开始念到暗号：`at`。
- `s + 2` 再挪一颗，从 `t` 开始：`t`。

和上一课一模一样：**加一是「挪牌子」，不是一个一个数珠子**。`*s` 是「拿当下这颗」，`s + 1` 是「挪到下一颗」—— 两件事，别混。

也正因为加一跨的是**一颗**，牌子在这条项链上特别好使：挪一格就正好是一颗珠子，不用像整数碗那样跨一大步喵。

## 三、牌子走一遍整串

既然挪一格就是下一颗，那整条项链走一遍只要一块牌子：

```c
#include <stdio.h>

int main(void) {
    char *s = "cat";

    for (char *p = s; *p != '\0'; p++) {
        printf("%c", *p);
    }
    printf("\n");
    return 0;
}
```

```text
cat
```

读法是：「**牌子从第一颗珠子出生；只要它当下那颗珠子不是暗号就进圈；每圈把牌子往后挪一颗。**」

眼色那句 `*p != '\0'` 就是项链的刹车：`\0` 是项链末尾那颗看不见的暗号，念到它就该停。这也是 `%s` 自己偷偷在干的事 —— 只不过它替你干了，所以你从来看不见喵。

**暗号在这门手艺里的角色，你该认准了**：它是**刹车**，是「到这儿为止」的意思。没有它，牌子会一路往下念，念到你根本没摆碗的地方去。

这块牌子一颗一颗走完项链、又是被谁叫停的，本喵拆成一步一步给你看：

## 四、亲手数一数珠子

`%s` 会自己停下，是因为它在替你找暗号。想知道这条项链到底有几颗珠子，你也可以自己拿牌子走一遍：

```c
#include <stdio.h>

int main(void) {
    char *s = "cat";
    int n = 0;

    while (*(s + n) != '\0') {
        n++;
    }
    printf("%d\n", n);
    return 0;
}
```

```text
3
```

`n` 从 `0` 开始，每数一颗加一，数到暗号就停 —— 所以它是**真正的珠子数**（暗号不算）。这也是 `strlen` 那位档案管理员的干活方式，只不过本喵今天让你亲手跑一遍，看看它到底在忙什么喵。

## 五、项链能不能动刀？

这个问题得分开答，因为它有两个完全不同的答案。

**第一种：把项链摆在**一排自己的碗**里，那就可以动刀。**

```c
#include <stdio.h>

int main(void) {
    char word[] = "cat";

    word[0] = 'C';
    printf("%s\n", word);
    return 0;
}
```

```text
Cat
```

`char word[] = "cat";` 是本喵亲手摆了四只碗（三颗珠子 + 一颗暗号），把珠子一颗颗放了进去。既然碗是自己的，当然想换就换：`word[0] = 'C';` 把第一颗珠子换成了大写的 `C`。上一课的方括号照样好使 —— 项链也是一排碗喵。

**第二种：只拿牌子指着一条**写死在程序里的**项链，那就千万别动它。**

要是你把那两句写成 `char *s = "cat";` 加上 `s[0] = 'C';`，也会发生一件很吓人的事：**翻译官喵一个字都不说**（本喵真跑过，连一句 `warning:` 都没有），程序照样生得出来。可一跑起来它会**当场断气** —— 屏幕上 stdout、stderr 都是空的，一个字都不印，进程就这么没了。

原因：`"cat"` 这种写死在程序里的项链，住在**只读**的地方，是给你**念**的，不是给你改的。牌子能指着它，但顺着牌子往里写，就是往墙上刻字喵。

::: warn 小心喵
这两句长得只差一对方括号，脾气却差着十万八千里：

- **`char word[] = "cat";`** —— 摆了四只碗、把珠子放进去，**可以改**。
- **`char *s = "cat";`** —— 只是一块牌子指着只读的地方，**不能改**。

而且第二种摔得特别隐蔽：翻译阶段**一声不吭**，编译的时候连嘀咕都没有，你压根看不出哪儿不对 —— 直到它当场断气。**所以本喵的死规矩是：想改的项链，一律用有方括号的那种写法摆出来。**

另外提一句：牌子本身倒是随便改 —— 让它改指另一条项链一点问题都没有：

```c
#include <stdio.h>

int main(void) {
    char *s = "cat";

    s = "dog";
    printf("%s\n", s);
    return 0;
}
```

```text
dog
```

牌子改指是「换一条项链念」，动的是牌子；`s[0] = 'C'` 是「往项链上刻字」，动的是那条项链。这两件事差着辈分喵。（还记得上一课吗？一排碗的名字**不能**挪，牌子**能**挪 —— 一条项链一个脾气。）
:::

## 六、一颗珠子的碗里塞不下整条项链

最后来一个一定能被拦下的错，让本喵听着翻译官喵说话：

```c
#include <stdio.h>

int main(void) {
    char c = "cat";

    printf("%c\n", c);
    return 0;
}
```

```text
main.c:4:14: error: initialization of 'char' from 'char *' makes integer from pointer without a cast [-Wint-conversion]
    4 |     char c = "cat";
```

翻译官喵的原话意思是：**「你把一整条项链塞进了一只只装一颗珠子的碗。」**

看出来了吗：`char c` 是一只**单颗珠子**的碗，而 `"cat"` 是**一整条项链**（真身是「第一颗珠子的门牌号」，也就是一块牌子）。拿牌子去填一只只装一颗珠子的碗，翻译官喵当场拦住。

**记号分清楚就不会摔**：`'c'` 是**单引号、一颗珠子**；`"cat"` 是**双引号、一整条项链**。差一层引号，差着一块牌子喵。

::: tip 猫咪提示
今天四句话：

1. **`char *s = "cat";`** 里的 `s` 是一块牌子，指着第一颗珠子；`%s` 要的就是这块牌子。
2. **牌子加一 = 挪一颗珠子**：`s + 1` 是从第二颗珠子开始念的整条尾巴 `at`。
3. **`*p != '\0'` 是项链的刹车** —— 暗号 `\0` 就写在末尾那颗看不见的珠子里；想自己数珠子也靠它。
4. **想改的项链，用 `char word[] = "cat";` 摆出来**；只拿牌子指着写死的项链还去刻字，翻译阶段一声不吭、跑起来当场断气。
:::

2. 写一条项链 `char word[] = "cat";`，用一块牌子走一遍、把每颗珠子印成一行（`%c` 加换行），再试试把珠子一颗颗改成大写。
3. 把第四节那段里的 `'\0'` 换成 `0`，跑一遍看看还能不能数出 `3` —— 想想为什么这两个写法是一回事喵。
4. 想一想（**别跑**）：本喵说「只拿牌子指着写死的项链还去刻字，会当场断气」。既然翻译阶段一个字都不说，那你写代码的时候靠什么**提前**避开它？
