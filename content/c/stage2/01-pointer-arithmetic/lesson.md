## 钩子：牌子其实是会挪的喵

上一课那台小鱼干计算器收工的时候，你手里已经捏着一块**猫爪指向牌（指针）**了：牌子上写着某一只碗的门牌号，顺着它就能拿、能放，想改原件就改原件。

那时候本喵把牌子介绍得像个老实孩子 —— 认准一只碗，一动不动。

可牌子其实是会**挪**的。而且它挪起来有个特别讨喜的脾气：**你让它加一，它不是把门牌号加一，而是整整往后跨一只碗。** 今天本喵就把这个脾气拆开给你看喵～

## 一、牌子加一，往后跨一只碗

先从上一课那个「整排碗」的例外讲起：一排碗的名字交出去的时候，交的正是**第一只碗的门牌号**。所以下面这块牌子一出生就指着第一只碗：

```c
#include <stdio.h>

int main(void) {
    int bowls[4] = {10, 20, 30, 40};
    int *p = bowls;

    printf("%d\n", *p);
    printf("%d\n", *(p + 1));
    printf("%d\n", *(p + 2));
    return 0;
}
```

```text
10
20
30
```

一行一行读喵：

- **`int *p = bowls;`** —— 牌子 `p` 指着第一只碗（`10` 那条）。
- **`*p`** —— 顺着牌子走到它指的那只碗前面，拿到 `10`。
- **`*(p + 1)`** —— 先把牌子**往后挪一只碗**，再顺着拿。拿到的是第二只碗里的 `20`。
- **`*(p + 2)`** —— 再往后挪一只碗，拿到 `30`。

看出来了吗：**`p + 1` 出来的东西还是块牌子**，只不过它指的是「下一只碗」。所以外面还得套一颗星，才轮到「顺着它拿东西」这一步。加号先干、星星后干 —— 本喵第四节专门讲这个排队规矩喵。

## 二、加一到底加了什么？

这是本课最要紧的一句话：

> **牌子加一，跨过的是「一整只碗」，不是「一格」。**

碗架上的位置是一格一格排下去的，可牌子不是按格走的，它是按**碗**走的。为什么？因为牌子上写得清清楚楚它指的是哪种碗 —— `int *` 就是「我指的是装整数的碗」。既然知道每只碗多大，它加一的时候自然就往后跨一整只碗的距离。

```c
#include <stdio.h>

int main(void) {
    int bowls[4] = {10, 20, 30, 40};
    int *p = bowls;

    printf("%d\n", (p + 1) == &bowls[1]);
    printf("%d\n", (p + 3) == &bowls[3]);
    printf("%d\n", (int)(&bowls[3] - &bowls[0]));
    return 0;
}
```

```text
1
1
3
```

- 前两行印 `1`，意思是**真的一样**：`p + 1` 这块牌子写的门牌号，和 `&bowls[1]` 问出来的门牌号**一字不差**。挪一只碗就是挪一只碗，不是约等于喵。
- 最后一行是**两块牌子相减**：从第一只碗的门牌号到第四只碗的门牌号，中间隔了 `3` 只碗。注意它数出来的还是**碗数**（3），不是格数（12）—— 牌子的加减从头到尾都用「碗」当单位喵。

::: tip 猫咪提示
记住这句就够用了：**牌子加一 = 往后跨一只碗；牌子减一 = 往前跨一只碗。** 跨多远由它指的是哪种碗说了算 —— 写着整数的牌子跨一整只整数碗（这台机器上是 4 格），写着字符的牌子就只跨 1 格。这门手艺等学到项链那一课，你会看到它有多顺手喵～
:::

## 三、往回挪：牌子减一

加得动，当然也减得动。往回挪一格，就是上一只碗：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {10, 20, 30};
    int *p = &bowls[2];

    printf("%d\n", *p);
    p = p - 1;
    printf("%d\n", *p);
    return 0;
}
```

```text
30
20
```

这次牌子不是从第一只碗出生，而是直接指着第三只碗 —— 写法就是**把那只碗的门牌号问过来**：`&bowls[2]`。然后 `p = p - 1;` 往前跨一只碗，就到 `20` 了。

挪牌子的写法有两种，随你挑：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {7, 8, 9};
    int *p = bowls;

    p = p + 1;
    printf("%d\n", *p);
    p++;
    printf("%d\n", *p);
    return 0;
}
```

```text
8
9
```

`p = p + 1;` 是「算出一块新牌子，再挂回 `p` 这个名字上」；`p++;` 是同一件事的省字写法，读作「牌子往后挪一只碗」。上一阶段「初识猫爪指向牌」那一课学的 `p = &b;` 是**换一只碗指**，今天的 `p++` 是**往后挪** —— 两件事都改牌子，但味道不一样喵。

## 四、星号和加号，谁先排队？

`*p + 1` 和 `*(p + 1)` 长得只差一对括号，干的事却完全不同：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {10, 20, 30};
    int *p = bowls;

    printf("%d\n", *p + 1);
    printf("%d\n", *(p + 1));
    return 0;
}
```

```text
11
20
```

- **`*p + 1`** —— 星星**先**干：顺着牌子把 `10` 拿出来，再给这个数加一，得 `11`。牌子一动没动。
- **`*(p + 1)`** —— 括号先把牌子往后挪一格，再顺着拿，得 `20`。

C 的排队规矩是「**星星比加号靠前**」，所以想先挪牌子，就得老老实实**加上一对括号**。少了那对括号，你会得到「碗里的数加一」而不是「下一只碗里的数」—— 结果差了十万八千里，可翻译官喵一声不吭，程序照跑不误。这是本课最容易摔的一跤，摔下去连个响声都没有喵。

## 五、牌子不是数字：拿 `%d` 印门牌号会怎样

上一阶段「初识猫爪指向牌」那一课提过，门牌号印出来是一串长得吓人的编号。要是你手一滑，把这块牌子直接喂给了 `%d`：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {1, 2, 3};
    int *p = bowls;

    printf("%d\n", p);
    return 0;
}
```

翻译官喵会嘀咕一句（本喵把原话抄在这儿）：

`warning: format '%d' expects argument of type 'int', but argument 2 has type 'int *' [-Wformat=]`

翻成猫话：**「`%d` 这口槽是给整数的，你塞进来的是块牌子呀。」** 但注意 —— 它只是**嘀咕**，不是拦人：程序照样生得出来，跑起来还会高高兴兴印出一串**没意义的数字**给你（本喵跑的时候印出来的是 `455080940`，你跑出来的一定和这串不一样，因为每次摆碗的位置都不同）。

**这就是 C 里最需要你留神的一类错**：翻译官喵嘴上说了，手却把你放过去了。程序看起来一切正常，印出来的东西却是垃圾。以后凡是看见 `warning:` 开头的嘀咕，都别当成「没事」喵。

::: warn 小心喵
牌子加减的时候，别让它挪出整排碗外面去。比如一排只有 3 只碗，你却写了 `int *p = bowls + 5;` 再去 `*p` —— **翻译官喵一个字都不说**（本喵真试过，连 warning 都没有），程序也照跑，只是顺手从碗架外面摸了个数回来（本喵那一次摸到的是 `828372976`，你摸到的一定是另一个数）。那格子里是什么，谁也说不准；要是你顺着它**往里写**，那就更没准头了 —— 碗架外面的东西会被一只只写坏，出问题的地方和写错的地方能隔出去老远，也可能压根等不到写坏别处、自己先当场断气（本喵试过，屏幕上一个字都没印出来），查起来极费眼神。

所以本喵的死规矩升级了：**牌子当场声明、当场指碗；挪的时候心里数着，绝不挪出整排之外。**
:::

## 六、两块牌子加不起来

那牌子加牌子呢？毕竟加号和减号是亲兄弟，减得动，加总该也加得动吧 —— 想得很美喵：

```c
#include <stdio.h>

int main(void) {
    int a = 1, b = 2;
    int *p = &a, *q = &b;

    printf("%d\n", p + q);
    return 0;
}
```

```text
main.c:7:22: error: invalid operands to binary + (have 'int *' and 'int *')
    7 |     printf("%d\n", p + q);
```

这句原话的意思是：**「`+` 左右两边都是牌子，这两样凑一块儿本喵不会算。」** 想想也对 —— 两块牌子的门牌号加起来，指的是哪只碗呢？碗架上没有这么一只碗。

**牌子只能跟数字加减，不能跟牌子加减。** 唯一能用两块牌子做的算术是**相减**（就是第二节最后那行，数出隔了几只碗）。

::: tip 猫咪提示
今天收四句话：

1. **牌子加一 = 往后跨一只碗**，减一 = 往前跨一只碗；跨多远由牌子指的是哪种碗说了算。
2. `p = p + 1;` 和 `p++;` 是同一件事，都是让牌子往后挪。
3. **`*p + 1` 是先拿出来再加一；`*(p + 1)` 是先挪牌子再拿。** 星星比加号靠前，想挪牌子得加括号。
4. **牌子只能跟数字加减**；两块牌子加不起来，减一减倒是能数出隔了几只碗。
:::
