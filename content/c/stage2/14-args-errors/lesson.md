## 钩子：本喵不想每次都回去改代码

上一课本喵学会了把数字存进档案室。可有一件事还挺别扭 —— 那几段程序里的「5」是**写在代码里**的：

```c
#include <stdio.h>

int main(void) {
    int n = 5;
    printf("本喵这次要数 %d 条\n", n);
    return 0;
}
```

```text
本喵这次要数 5 条
```

想改成 8 条怎么办？回去把 `5` 改成 `8`、重新翻译一遍。改一处两处还行，要是想**每次跑的时候顺口说一句**呢？

其实能办到：程序跑起来的时候，你在名字后面空一格、再说几样东西，**这些字都会原原本本递进程序里**。问题只剩一个 —— 程序该上哪儿接住它们？答案就藏在 `main` 头上的那对括号里喵。

## 一、`main` 头上的两样投喂

平时本喵都写 `int main(void)`，那个 `void` 的意思是「本喵不给它投喂任何东西」。今天这一对括号里要摆上两样 —— `int main(int argc, char *argv[])` —— 读法是：

| 头上的东西 | 是什么 |
|---|---|
| `argc` | **一共收到几条投喂**（含程序自己的名字），是个整数 |
| `argv` | **那一串投喂本身** —— 一排碗，每只碗里装着一条小鱼干的项链 |

`argc` 这个名字好记：**a**rgument **c**ount，数一数来了几样。`argv` 是 **a**rgument **v**ector，就是「那串投喂排成一排」。

为什么要说「含程序自己的名字」？因为**程序自己的名字也算一条**，它永远排在**第一颗**上：

- `argv[0]` —— 程序自己的名字
- `argv[1]` —— 你顺口说的**第一样**
- `argv[2]` —— 你顺口说的**第二样**
- ……

所以 `argc` 最少也是 1，不会比 1 更小 —— 不管你说没说，名字总在喵。

先看一段「什么都不说」的：

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("一共收到 %d 条投喂\n", argc);
    return 0;
}
```

```text
一共收到 1 条投喂
```

一次都没多说，于是只收到 1 条 —— 就是它自己的名字那一条喵。

## 二、一条条念出来

想把收到的投喂挨个念出来，就用前几课学过的绕圈：

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("一共收到 %d 条投喂\n", argc);
    for (int i = 1; i < argc; i++) {
        printf("第 %d 条：%s\n", i, argv[i]);
    }
    if (argc == 1) {
        printf("这次一条都没多给喵\n");
    }
    return 0;
}
```

```text
一共收到 1 条投喂
这次一条都没多给喵
```

两个地方值得盯一眼：

- **绕圈从 `i = 1` 起**，不是从 0 起 —— 第 0 条是程序自己的名字，本喵不念它；
- **`argv[i]` 是一条项链**（一串字），所以印它用 `%s`，不是 `%d`。

`if (argc == 1)` 那一段是问：**是不是一条多的都没给？** 是的话本喵提醒一句。

### 课文里的程序为什么总是「空着手」

你大概注意到了：课文里的程序跑起来，永远只有它自己的名字。

因为**跑台帮你跑的时候没法替你多说几样东西** —— 本喵没办法往命令行里加字。所以你看到的永远是这个「空着手」的分支。

那「有投喂的时候」长什么样？本喵用一个小花招演给你看：**自己捏一串投喂，递给同一个招式**。`argv` 没什么神秘的，它就是「一排装着项链的碗」，本喵自己也捏得出来：

```c
#include <stdio.h>

void show(int n, char *argv[]) {
    printf("一共收到 %d 条投喂\n", n);
    for (int i = 1; i < n; i++) {
        printf("第 %d 条：%s\n", i, argv[i]);
    }
}

int main(int argc, char *argv[]) {
    show(argc, argv);
    if (argc == 1) {
        printf("这次一条都没多给喵\n");
    }
    printf("--- 下面这趟是本喵自己捏的一串投喂 ---\n");
    char *demo[3] = {"benmiao", "3", "5"};
    show(3, demo);
    return 0;
}
```

```text
一共收到 1 条投喂
这次一条都没多给喵
--- 下面这趟是本喵自己捏的一串投喂 ---
一共收到 3 条投喂
第 1 条：3
第 2 条：5
```

同一段 `show`，第一趟收到的是**真投喂**（空手，只有名字），第二趟收到的是本喵捏出来的 `{"benmiao", "3", "5"}` —— 念出来也一模一样，第 1 条是 `3`、第 2 条是 `5`。

**这一手你以后真用得上**：只要是「一排装着项链的碗」，不管是你捏的还是外面递的，招式都照收不误喵。

::: warn 小心喵
你在自己电脑上跑的时候，就**真**能多说几样了：名字后面空一格，再一个个写上去就行。要是它们中间有空格（比如一句话），得拿引号把那一段**整个包起来**——不然外面的翻译官会把它拆成好几条投喂。

（怎么写、在哪儿敲？就是你平时跑程序的那一行命令，本课最后的小任务里会带你走一遍喵。）
:::

## 三、把那一串字念成数：`atoi`

接住了投喂，还有一个坑等着：**`argv[1]` 是一串字，不是数。**

`"3"` 和 `3` 在程序眼里是两回事：前者是一条项链，后者才是一只碗里的整数。想让 `"3"` 参加算账，得请翻译官喵把它**念成数**。干这活的招式叫 `atoi`，住在头文件 `stdlib.h` 家里：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    char *a = "35";
    char *b = "3个";
    char *c = "喵";
    printf("「%s」念出来是 %d\n", a, atoi(a));
    printf("「%s」念出来是 %d\n", b, atoi(b));
    printf("「%s」念出来是 %d\n", c, atoi(c));
    printf("%d + %d = %d\n", atoi(a), atoi(b), atoi(a) + atoi(b));
    return 0;
}
```

```text
「35」念出来是 35
「3个」念出来是 3
「喵」念出来是 0
35 + 3 = 38
```

三个结果连起来看，`atoi` 的脾气就清楚了：

- `atoi("35")` 念成 **35** —— 规规矩矩的数，照念不误；
- `atoi("3个")` 念成 **3** —— 后面那些它看不懂的字，**它眼都不眨就丢掉了**（它从**头**开始念，念到念不动为止）；
- `atoi("喵")` 念成 **0** —— 一个字都看不上，于是吐出个 0 交差。

要紧的正是这一条：**它不吭声，也不报错，只是把念不动的地方丢掉、念不出来就给你 0。**

::: warn 小心喵
`atoi` 这一手是双刃剑：方便，但它**不会告诉你「刚刚进来的根本不是数」**。

`atoi("喵")` 给 0、`atoi("0")` 也给 0 —— **两种完全不同的处境，落到你手里是同一个数**。所以光靠「念出来是 0」你分不清是「真的是 0」还是「一个字都没听懂」。想分清楚，只能自己**先检查、再干活** —— 这正是下面两节要干的事喵。
:::

## 四、退场的时候，带上一个数字

每段程序跑完，都会**带走一个数字**交给外面。

外面收到 **0**，就表示「这一趟顺顺当当」；收到**别的数**，就表示「这一趟没干成」。这个数字，就是 `main` 里那句 `return` 写的东西 —— 本喵一直写 `return 0`，意思正是「顺顺当当收工」。

想表达「没干成」呢？写别的数就行。本喵在跑台上真验过：写 `return 3` 的程序跑完，外面收到的确实是 3。

于是「该拿的东西没拿到」这一支，顺手就该这么收场：

```c
int check_args(int argc) {
    if (argc < 2) {
        printf("用法：本程序 一个整数\n");
        return 1;
    }
    return 0;
}
```

（这一截是**招式本身**，不是完整程序 —— 完整程序还得有个 `main` 去喊它。）

外面怎么看见这个数字？在你跑程序的那一行命令后面，紧接着打一句：

```text
echo $?
```

印出来的就是刚才那句 `return` 带走的数 —— 0 就是顺当，别的数就是出事了。

::: tip 猫咪提示
写小工具的时候，这个数字是给**别的程序**看的：脚本里跑完一句，看它带回 0 还是别的数，就知道该不该接着往下走。所以说「写程序要有个交代」——交代就交代在这一个数上喵。
:::

## 五、防御式检查：先看看手里的东西能不能用

「先检查、再干活」在命令行这里要检查三样东西，本喵一节一节来。

**第一样：投喂够不够。** `argc` 会告诉你。少了就当场收手，**别硬往下算**：

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
    if (argc < 2) {
        printf("用法：本程序 一个整数\n");
        printf("（本喵空着手来的，先退场了）\n");
        return 0;
    }
    int n = atoi(argv[1]);
    printf("%d 翻倍是 %d\n", n, n * 2);
    return 0;
}
```

```text
用法：本程序 一个整数
（本喵空着手来的，先退场了）
```

**第二样：念出来的数能不能用。** 上一节刚说过，`atoi` 会把看不懂的丢掉、念不出来就给 0。所以「念出来是 0」既可能是真的 0，也可能是**它压根没听懂**。要是这个数在你的程序里不能是 0 或负数（比如「要分几份」），那就得自己再挡一道：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    char *args[] = {"benmiao", "0", "5"};
    for (int i = 1; i < 3; i++) {
        int n = atoi(args[i]);
        if (n <= 0) {
            printf("「%s」不是个能用的数，本喵不收\n", args[i]);
        } else {
            printf("收到 %d 条，记下了\n", n);
        }
    }
    return 0;
}
```

```text
「0」不是个能用的数，本喵不收
收到 5 条，记下了
```

`"0"` 被挡在门外、`"5"` 放行 —— 这就是**防御式检查**：不指望进来的东西是对的，**先验一遍，不对就当场拦住**，而不是让它带着错往下跑。

::: tip 猫咪提示
为什么非要这么啰嗦？因为**程序跑到一半才炸**是最难看的下场：册子写了一半、账记了一半，外面还什么都不知道。

检查写在最前面，就有两个好处：一是坏东西**根本进不来**，二是出问题的时候你能**清楚地说出**是哪儿不对 —— 上面那句「用法：……」就是给用的人看的，比一句莫名其妙的报错强一百倍喵。
:::

## 六、一个会出声的坑：`char *argv` 少了那对方括号

本喵在跑台上真拿掉过一个方括号，写成 `char *argv`（后面还伸手去摸了 `argv[1]`）：

```text
#include <stdio.h>

int main(int argc, char *argv) {
    printf("第一条：%s\n", argv[1]);
    return 0;
}
```

（这一段本喵**故意写错**，所以只放在这里给你看，别照着敲。）

翻译官喵**出声了**，而且一口气说了两句：

```text
main.c:3:5: warning: second argument of 'main' should be 'char **' [-Wmain]
main.c:4:22: warning: format '%s' expects argument of type 'char *', but argument 2 has type 'int' [-Wformat=]
```

第一句说的正是本课那件事 —— 「**这一格该写的是 `char **`**」，也就是「**一排装着项链的碗**」；本喵少写的，就是那对方括号。

**可它只是出声，没把本喵拦下** —— 程序照样被编了出来。**「警告」不是「错误」**：错误是拦下的那只手，警告只是它顺口提醒的一句 —— 手一抖、眼一花，那两行就过去了。

真正翻车在后面那一下：**一跑起来，程序什么都没印就没了**（本喵这边收到的是一个「段错误」—— 它伸手摸去了一处根本不归它管的地方）。手上的东西长相不对，它照样让你编过，只在真去用的时候才出事 —— 这就是**这一类错最难缠的地方：警告容易看漏，出事却在最后一步**。

少了那一对方括号，**它就不是那串投喂了**。形状这东西，得写全喵。
