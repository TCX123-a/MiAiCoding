## 钩子：一间格子，两种用法喵

本喵的猫窝旁边有个小格子。早上放橘猫的饭盆，晚上放秤鱼的大秤 —— 这两样从来不同时用，那本喵为什么要预备两个格子呢？**留一间就够了**，谁住进去就用谁的名字喵。

C 里正好有一样东西是这个脾气，叫**共用体（union）**。它跟上一课的图纸长得几乎一模一样，只是把「每样各占一格」改成了「**所有成员共用同一间仓库**」。

今天还有第二位主角：**枚举（enum）** —— 一串**起好名字的编号**。它解决的是另一个烦恼：本喵记不住「3 号代表蓝色」，但记得住「蓝色」。

## 一、共用一间仓库的图纸

```c
union Num {
    int i;
    double d;
    char s[16];
};
```

读法跟上一课的图纸一样：`union` 是「本喵要画一张共用体的图纸」，`Num` 是图纸名字，花括号里一行一行写「这间仓库可能住谁」，**末尾那个分号一样不能丢**。

区别只在**地方怎么分**：

- **图纸（struct）**：每样东西**各占自己的一份**。三样就是三份加起来那么大。
- **共用体（union）**：所有成员**共用同一块地方**。一间仓库，门上挂了三个牌子。

那这间仓库到底多大？量一量就知道：

```c
#include <stdio.h>

union Num {
    int i;
    double d;
    char s[16];
};

int main(void) {
    printf("%d\n", (int)sizeof(union Num));
    printf("%d\n", (int)sizeof(int));
    printf("%d\n", (int)sizeof(double));
    return 0;
}
```

```text
16
4
8
```

三行数一读就明白了喵：`int` 要 4 格、`double` 要 8 格、那条 16 格的项链要 16 格。共用体的仓库**取了最大的那位**（16）—— 因为谁都有可能住进去，地方得按最胖的那位预备。

**共用体的仓库大小 = 最胖的那位成员。** 这句话是本课第一节的全部。

## 二、同一时刻，只住一位

那要是住了一位，又用另一位去读，会读到什么？先看正常用法：

```c
#include <stdio.h>

union Num {
    int i;
    double d;
};

int main(void) {
    union Num n;

    n.i = 42;
    printf("%d\n", n.i);
    n.d = 2.5;
    printf("%.1f\n", n.d);
    return 0;
}
```

```text
42
2.5
```

写法跟普通东西一模一样：`n.i = 42;` 把整数住进去，接着读 `n.i` 就是 `42`。然后 `n.d = 2.5;` —— 这位小数住进来了，**它把上一位挤走了**（地方只有一间）。因为地方是共用的，所以读 `n.d` 当然还是 `2.5`。

::: warn 小心喵
**写了谁，就读谁。** 这句话是共用体唯一的规矩。

要是你写完 `n.d = 2.5;` 之后去读 `n.i`，读到的不是「42」，也不是什么有意义的数 —— 那是把 `2.5` 那串字节**硬当成整数看**的结果。本喵不把这个数字印出来给你看，因为它在别的机器、别的编译器上可能完全不一样，**它不是能记住的知识**。

一句话收好：共用体里**睡下去的那位才认得**；要问别人，就先把别人重新写一遍喵。
:::

## 三、它真正的用法：带记号的柜子

既然共用体自己都不知道住的是谁，那用起来怎么保证不弄错？办法很朴素：**再配一张记号**，先说清今天住的是谁，读的时候先看记号。

```c
#include <stdio.h>

enum Kind { IS_INT, IS_DOUBLE };

struct Value {
    enum Kind kind;
    union {
        int i;
        double d;
    } num;
};

int main(void) {
    struct Value v;

    v.kind = IS_INT;
    v.num.i = 7;
    if (v.kind == IS_INT) {
        printf("整数 %d\n", v.num.i);
    } else {
        printf("小数 %.1f\n", v.num.d);
    }
    return 0;
}
```

```text
整数 7
```

这个柜子有两格：第一格 `kind` 是**记号**（今天住的是整数还是小数），第二格 `num` 是那间**共用的仓库**。写的时候两格一起写（记号写 `IS_INT`，仓库写 `v.num.i = 7`）；读的时候**先看记号，再进对的那扇门**。

这就是共用体最经典的用法 —— **图纸套共用体，外面再挂一张记号**。本章往后写「一只猫可能是猫、也可能是大肥鱼」这种「有好几种样子」的东西时，这个形状还会再见面喵。

## 四、枚举：一串起好名字的编号

第二位主角上场。本喵要是想表示「三种颜色」，老办法是记暗号：0 是红、1 是绿、2 是蓝。**记暗号太容易错了**，而且过两天回来看代码，谁也认不出那个 `2` 是什么意思。

于是有了**枚举（enum）**：

```c
enum Color { RED, GREEN, BLUE };
```

一句话读完：**「本喵要一串编号，分别叫 RED、GREEN、BLUE。」** 翻译官喵自动给它们编上号：**从 0 开始，一个比一个大 1** —— `RED` 是 0，`GREEN` 是 1，`BLUE` 是 2。

用起来跟普通东西一样：

```c
#include <stdio.h>

enum Color { RED, GREEN, BLUE };

int main(void) {
    enum Color c = GREEN;

    printf("%d\n", RED);
    printf("%d\n", c);
    printf("%d\n", BLUE);
    return 0;
}
```

```text
0
1
2
```

看第二行：`c` 里装的是 `GREEN`，印出来是 `1` —— 因为**这些名字在 C 里就是整数**，只是给编号起了外号。所以 `%d` 照样能印它。

### 编号也可以自己起

不写的话从 0 开始排；写了一个，就从那个数接着排：

```c
#include <stdio.h>

enum Level { LOW = 1, MID, HIGH };

int main(void) {
    printf("%d %d %d\n", LOW, MID, HIGH);

    enum Level lv = MID;
    lv = lv + 1;
    if (lv == HIGH) {
        printf("已经到 %d 档了喵\n", lv);
    }
    return 0;
}
```

```text
1 2 3
已经到 3 档了喵
```

`LOW = 1` 一句话，后面两位自动接上 2 和 3。而且 `lv = lv + 1;` 这种算法也照做不误 —— 还是那句话：**它们在 C 里就是整数**，只是有了好记的外号喵。

## 五、枚举最好的用法：当记号

有了好记的名字，最常干的活就是**当记号、当选项**：

```c
#include <stdio.h>

enum Color { RED, GREEN, BLUE };

void show(enum Color c) {
    if (c == RED) {
        printf("红色\n");
    } else if (c == GREEN) {
        printf("绿色\n");
    } else {
        printf("蓝色\n");
    }
}

int main(void) {
    show(RED);
    show(BLUE);
    return 0;
}
```

```text
红色
蓝色
```

招式头上写 `enum Color c`，喊的时候直接给名字：`show(RED)`、`show(BLUE)`。要是没有这串名字，你得写 `show(0)`、`show(2)`，过一星期就没人知道 `2` 是什么了喵。

**读代码的人能不能一眼看懂**，就是枚举存在的全部理由。

## 六、忘了带 `enum` 这个记号

跟上一课忘了 `struct` 是一模一样的毛病：

```c
#include <stdio.h>

enum Color { RED, GREEN, BLUE };

int main(void) {
    Color c = GREEN;
    printf("%d\n", c);
    return 0;
}
```

```text
main.c:6:5: error: unknown type name 'Color'; use 'enum' keyword to refer to the type
    6 |     Color c = GREEN;
```

翻译官喵的原话：「`Color` 这个名字本喵没见过 —— 要用它，前面得带上 `enum`。」（后半句 `use 'enum' keyword to refer to the type` 就是这个意思。）

::: tip 猫咪提示
今天收四句话：

1. **`union` 是几样东西共用一间仓库**，仓库大小 = 最胖的那位成员（`sizeof(union Num)` 一量就知道）。
2. **同一时刻只住一位，写了谁就读谁。** 去读写下去的那位以外的人，读到的是没意义的字节，不是知识。
3. **共用体自己不知道住的是谁**，所以真正的用法是**配一张记号**：记号说今天住谁，读的时候先看记号。
4. **`enum` 是一串起好名字的编号**：不写就从 0 开始一个比一个大 1，写了 `= 1` 就从那里接着排；名字前面永远带 `enum`。
:::
