## 钩子：整只猫搬来搬去，太费劲了喵

上一课收尾时，本喵留了个甜蜜的烦恼：整只猫可以 `b = a;` 整个搬走，连名字都一颗一颗珠子搬过去。方便是真方便 —— 可**每搬一次，就多出一只猫**。

要是本喵写一招「给某只猫添一条小鱼干」，收的是**一整只猫**，那改的只是搬进来的那只副本，外面那只原猫一动没动。想让招式改到**本人**，光有图纸不够，还得给猫配一块牌子喵。

今天本喵要把两样本事合起来用：上一课画的**图纸**说的是「一只猫有什么」，今天这块**指针（猫爪指向牌）**说的是「那只猫在哪儿」。牌子加上图纸，就能隔着一块小牌子直接摸到真猫。

## 一、给一只猫写一块牌子

牌子的写法是在图纸名字后面加一颗星，再给牌子起个名：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat a = {"小橘", 3};
    struct Cat *p = &a;

    printf("%s 吃了 %d 条喵\n", p->name, p->fish);
    p->fish = 9;
    printf("改完之后 a.fish = %d\n", a.fish);
    return 0;
}
```

```text
小橘 吃了 3 条喵
改完之后 a.fish = 9
```

一行一行读喵：

- **`struct Cat *p`** —— 一颗星，意思是「本喵要的是一块牌子，不是一只猫」。整句话念作：「`p` 是一块**指着一只猫**的牌子」。星号跟 `struct Cat` 绑在一起，说的是牌的**种类**：这只牌子只认猫。
- **`&a`** —— 问门牌号的动作。上一课 `a` 是那只真猫本身，`&a` 是「`a` 住在哪」这个信息。整句就是：生一只猫 `a`，再写一块牌子指着它。
- **`p->name`** —— 顺着牌子找到那只猫，再进它的 `name` 那一格。
- **`p->fish = 9;`** —— 顺着牌子进去**改**。改完立刻回头看看原猫：`a.fish` 印出来是 `9`。

这就是牌子最要紧的脾气：**顺着牌子改，改的是原来那只猫**。跟上一课 `b = a;` 那种「抄一份副本」完全不是一回事。

## 二、小箭头 `->`：点号的省字写法

同一格东西，下面两种写法**一模一样**：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat a = {"小橘", 3};
    struct Cat *p = &a;

    printf("%d\n", (*p).fish);
    printf("%d\n", p->fish);
    (*p).fish = 8;
    printf("%d\n", a.fish);
    return 0;
}
```

```text
3
3
8
```

`(*p).fish` 读作「先把牌子指向的那只猫拿出来，再进它的 `fish` 格」；`p->fish` 是它的省字版：**一根小箭头 `->`**，意思是「顺着牌子过去，进那一格」。两个都印 `3`，最后那行印 `8`，说明改的还是同一只猫 `a`。

### 那对括号为什么不能省

初学者最容易把 `(*p).fish` 写成 `*p.fish`（括号一丢，字少一半，看着还挺顺眼）。翻译官喵会当场拦下来，本喵把它的原话抄在这儿：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat a = {"小橘", 3};
    struct Cat *p = &a;

    printf("%d\n", *p.fish);
    return 0;
}
```

```text
main.c:12:22: error: 'p' is a pointer; did you mean to use '->'?
   12 |     printf("%d\n", *p.fish);
```

翻译官喵的原话很有意思：**「`p` 是一块牌子呀 —— 你是不是想用 `->`？」** 它不光拦下来，还在底下画了个小箭头指着 `->`，等于把答案写在卷子上了喵。

它为什么会这么想？因为 C 的排队规矩里，**点号 `.` 排在星星 `*` 前面**。你写的 `*p.fish` 会被它读成「先`p.fish`，再给结果加颗星」—— 可 `p` 是块牌子，牌子哪来的 `fish` 格？于是它猜：你其实是想顺着牌子进那一格吧。

记住这条就够了：**牌子上进门，用 `->`；真猫上进门，用 `.`**。写 `(*p).fish` 也对，两个是一个意思，只是多打三个字符喵。

## 三、把猫交给招式，改的是本人

现在回到钩子里那个烦恼。招式收一块牌子，就能改到外面那只猫：

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

void feed(struct Cat *c, int n) {
    c->fish = c->fish + n;
}

int main(void) {
    struct Cat a = {"小橘", 3};

    feed(&a, 5);
    printf("%s 吃了 %d 条喵\n", a.name, a.fish);
    return 0;
}
```

```text
小橘 吃了 8 条喵
```

`feed` 的头上写着 `struct Cat *c` —— 收的是**牌子**，不是猫。所以 `main` 里要递 `&a` 进去。招式里 `c->fish` 一改，外面那只 `a` 的食量就从 `3` 变成了 `8`。

对照一下上一课：招式要是收一整只猫，你在招式里怎么改，外面那只都不动 —— 因为招式拿到的是**副本**。**递牌子 = 改本人，递整只 = 改副本**，这一对差别往后天天要用，收下喵。

## 四、图纸也能现要现租

一只猫也是一样东西，所以上一课那套「现要现租的仓库」照样适用。尺子量一下一张图纸（`sizeof(struct Cat)`），乘上一只，就租到一块刚好放得下猫的地方：

```c
#include <stdio.h>
#include <stdlib.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat *p = (struct Cat *)malloc(sizeof(struct Cat));

    if (p == NULL) {
        printf("仓库没租到喵\n");
        return 1;
    }
    p->fish = 7;
    printf("%d\n", p->fish);
    free(p);
    p = NULL;
    return 0;
}
```

```text
7
```

三处值得盯一眼喵：

- **`malloc(sizeof(struct Cat))`** —— 先量一张图纸多大，再伸手租这么多格。租不租得到，看它叼回来的是不是 `NULL`。
- **`(struct Cat *)`** —— 租仓库的招式叼回来的牌子**不认种类**（它只说「这儿有一块地方」）。前面这一小段就是在牌子上补写一行字：「这块地方要按一只猫来读」。补好了以后，`p->fish` 这种写法才认得。
- **`free(p)` 之后还要 `p = NULL;`** —— 上一课学的规矩，原样照做，别把擦不干净的牌子留着。

要租一排猫也简单：**先量一只、再乘只数**，跟上一课一模一样。

```c
#include <stdio.h>
#include <stdlib.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat *cats = (struct Cat *)malloc(sizeof(struct Cat) * 2);

    if (cats == NULL) {
        printf("仓库没租到喵\n");
        return 1;
    }
    cats[0].fish = 4;
    cats[1].fish = 6;
    printf("%d\n", cats[0].fish + cats[1].fish);
    free(cats);
    cats = NULL;
    return 0;
}
```

```text
10
```

注意这里用的是**点号**：`cats[0]` 已经先把第一只猫拿出来了，拿出来的是一只真猫，进门当然用点号。**箭头配牌子，点号配真猫** —— 上面那句话又应验了一次喵。

## 五、一排猫 + 一块牌子

最后把这节课的两样东西拼起来：一排真猫摆好，再拿一块牌子从头走到尾。

```c
#include <stdio.h>

struct Cat {
    char name[20];
    int fish;
};

int main(void) {
    struct Cat cats[3] = {
        {"小橘", 3},
        {"狸花", 5},
        {"大肥鱼", 9}
    };
    struct Cat *p = cats;
    int total = 0;

    for (int i = 0; i < 3; i++) {
        printf("%s 吃了 %d 条喵\n", p->name, p->fish);
        total = total + p->fish;
        p++;
    }
    printf("一共 %d 条喵\n", total);
    return 0;
}
```

```text
小橘 吃了 3 条喵
狸花 吃了 5 条喵
大肥鱼 吃了 9 条喵
一共 17 条喵
```

三句关键的话喵：

- **`struct Cat *p = cats;`** —— 一排猫的名字交出来的时候，交的就是**第一只猫的门牌号**。所以这段话没说错，牌子一生出来就指着第一只。
- **`p->name`** —— 顺着牌子进第一只猫，念它的名字。
- **`p++`** —— 牌子往后挪。挪多远？上一课讲过：**牌子上写着它指的是哪种东西，就跨一整只那么多**。这里指着一只猫，所以 `p++` 跨的是一整只猫，正好落到第二只头上。三趟走完，三只猫一只不漏。

::: warn 小心喵
牌子**必须先指着真猫**，才能往它指的地方读写。要是你写了 `struct Cat *p;` 就紧接着来一句 `p->fish = 3;` —— 这块牌子上什么门牌号都没有，顺着它写进去，就是往不知道哪块地方乱写。

本喵真跑过这一段。翻译官喵其实**嘀咕了一句**（原话）：`warning: 'p' is used uninitialized [-Wuninitialized]` —— 它看得出这块牌子还没指地方。

但它只是**警告**，不是拦路虎：编译照样过，跑起来一个字都不印，直接断气（屏幕上一片空白，退出码是异常的那个）。这种「安安静静就没了」的毛病最难查，**而翻译官喵只负责出声、不负责拦住你** —— 往后看到 `warning:` 开头那几行，别当背景音划过去。本喵的规矩是：**牌子当场声明、当场指着某只猫**。

顺带一句：`->` 和 `.` 千万别用混。看到牌子的名字，就用箭头；看到真猫的名字，就用点号。用错了，翻译官喵一般都会拦你（像第二节那样），但别指望它每次都站在你这边喵。
:::

::: tip 猫咪提示
今天收四句话：

1. **`struct Cat *p = &a;`** 是给一只猫写牌子：星号说明「这是牌子」，`&a` 把门牌号问过来。
2. **`p->fish` 就是 `(*p).fish`** 的省字写法：**牌子用箭头，真猫用点号**。写成 `*p.fish` 会被拦下来，翻译官喵还会顺手提示你用 `->`。
3. **递牌子 = 改本人；递整只猫 = 改副本。** 招式想动到外面的猫，头上就写 `struct Cat *c`，调用时递 `&a`。
4. **图纸也能现要现租**：`malloc(sizeof(struct Cat))`，租一排就先量一只再乘只数；前面补一句 `(struct Cat *)`，用完 `free` 再把牌子擦成 `NULL`。
:::

## 小任务

1. 把第一节那段里的 `p->fish = 9;` 改成 `p->fish = p->fish + 1;`，跑一跑，看看 `a.fish` 印出来是几喵。
2. 把第二节里的 `p->fish` 换成 `(*p).fish`，再把 `(*p).fish = 8;` 换成 `p->fish = 8;` —— 两种写法互相换一换，输出应该一个字都不变。
3. 用第四节那句 `malloc` 现租一只猫，租到以后先看它是不是 `NULL`，然后给它填上 `p->fish`，跑完记得 `free` 再把牌子擦干净。
4. 想一想（**先猜再跑**）：第五节那段跑完以后，`p` 指着哪儿？要是紧接着再来一句 `p->name`，本喵能读到什么？
