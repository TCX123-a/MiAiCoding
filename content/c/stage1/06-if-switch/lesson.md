## 钩子：本喵出门前，先看一眼猫粮碗

本喵每天早上出门前，都要低头看一眼猫粮碗：

- 鱼干堆得冒尖 → 今天不慌，先回猫窝晒会儿太阳。
- 只剩两三根 → 得省着点吃，顺便盯着大肥鱼别偷拿。
- 碗底空空的 → 只好去鱼塘边找大肥鱼要点救济。

三条路，本喵看一眼就知道该走哪条。这一眼，术语表里叫**看鱼干眼色行事（条件判断）**。今天本喵教你用 C 把它写出来：先学一个眼色的 `if`，再学一串眼色的 `if` / `else if` / `else`，最后学一个「拿编号对号入座」的 `switch` 喵。

## `if`：眼色要用小括号圈起来

先看最小的形状。本喵只问一句：「碗里还有鱼干吗？」

```c
#include <stdio.h>

int main() {
    int fish = 3;

    if (fish > 0) {
        printf("碗里还有鱼干，开吃喵\n");
    }
    return 0;
}
```

```text
碗里还有鱼干，开吃喵
```

盯着 `if (fish > 0) {` 这一行看，它其实是三块拼起来的：

1. **`if`** —— 开场白，意思是「本喵要问一句眼色了」。
2. **一对小括号 `( )`** —— 眼色**必须**住在里面。这是 C 的硬规矩，漏了小括号，翻译官喵连门都不让你进。
3. **一对大括号 `{ }`** —— 圈住「归这条路管的话」。眼色答真，大括号里的话才上场；答假，整块跳过。

**这里正是 C 和 Python 气质不同的地方。** 你在通用课里见过的 Python，是用冒号加缩进来划分「哪句话归谁管」的；C 不认缩进，它只认**大括号**。所以本喵在 C 里把大括号写得齐齐整整，纯粹是为了好读 —— 就算把它们挤成一行，翻译官喵也照样认。

大括号里可以站**好几句**话，它们是一伙的：眼色答真，一起上场；答假，一起歇着。

## `else`：眼色答假时走的那条路

只有一条路要挑的时候，一个 `if` 就够了。可本喵还想说一句「要是碗空了呢」，那就请 `else` 出场：

```c
#include <stdio.h>

int main() {
    int fish = 0;

    if (fish > 0) {
        printf("有鱼干，开吃喵\n");
    } else {
        printf("碗空了，去找大肥鱼喵\n");
    }
    return 0;
}
```

```text
碗空了，去找大肥鱼喵
```

`else` 是这一串的**兜底**：上面每个眼色都答了假，才轮到它。它后面**不写眼色** —— 它不用问，它就是「剩下的全归我」。

**「先算答案、再挑路」这两拍**是怎么走的，本喵拆成一步一步，走给你看：

## `else if`：中间那些眼色

三条路的时候，把中间那些眼色写成 `else if`：

```c
#include <stdio.h>

int main() {
    int fish = 2;

    if (fish >= 5) {
        printf("鱼干满满，本喵先晒会儿太阳喵\n");
    } else if (fish > 0) {
        printf("快见底啦，省着点吃喵\n");
    } else {
        printf("碗空了，去找大肥鱼要点喵\n");
    }
    return 0;
}
```

```text
快见底啦，省着点吃喵
```

读法只有一句话：**从上往下一个一个问，谁先答「真」就走谁那条路，然后整串眼色到此结束。**

本喵把第一行换个数，三条路就都露一次脸：

| `fish` 是几 | 谁答了真 | 屏幕上印出 |
|---|---|---|
| `9` | `fish >= 5` | 鱼干满满，本喵先晒会儿太阳喵 |
| `2` | `else if (fish > 0)` | 快见底啦，省着点吃喵 |
| `0` | 前面全答假，轮到 `else` | 碗空了，去找大肥鱼要点喵 |

顺便交代两件事：

- 中间的候补（`else if`）**想排几个排几个**，一路往下排都行；但一串的末尾最多只站一个兜底。
- `else` **不是非写不可**。不写的话，前面全答假就**什么都不做** —— 这一串眼色整体跳过，程序接着往下跑喵。

::: tip 猫咪提示
`if (眼色) { 话 }` 这一行里，**小括号管眼色、大括号管话**。C 里这两对括号各有各的活，谁都不能省。看别人的 C 代码时，先找小括号 —— 里面那句就是他要问的眼色喵。
:::

## 第一个答了真，后面就不问了

这是 `else if` 最要紧的脾气，本喵单独拎出来。看这段：

```c
#include <stdio.h>

int main() {
    int fish = 3;

    if (fish > 0) {
        printf("有鱼干，开吃喵\n");
    }
    if (fish > 2) {
        printf("而且还挺多喵\n");
    }
    return 0;
}
```

```text
有鱼干，开吃喵
而且还挺多喵
```

两句话都印出来了 —— 因为这是**两个各自独立的眼色**，电脑会一个一个都问一遍，谁答真谁就上场。这跟上一段那种「一串眼色」是两回事：

- **两个独立的 `if`**：两个眼色都会被问，可能两条路一起走。
- **`if` 加 `else if`**：一串眼色，前面那个答了真，后面的**连问都不问**。

### 顺序反了，结果就变了

既然是「从上往下问」，那**谁排在前头谁说了算**：

```c
#include <stdio.h>

int main() {
    int score = 95;

    if (score >= 60) {
        printf("及格喵\n");
    } else if (score >= 90) {
        printf("优秀喵\n");
    }
    return 0;
}
```

```text
及格喵
```

95 分，屏幕上却只印出「及格喵」。因为第一个眼色「大于等于 60 吗」已经答了真，电脑高高兴兴走了这条路，**后面那句「90 以上吗」根本没被问出口**。这段代码一个错都不报 —— 它只是安安静静给出了不对的结果，这种最费眼神喵。

所以排眼色有一条规矩：**最严的条件放最上面**（先问「90 以上吗」，再问「60 以上吗」）。

## 一个等号，两个等号

这是新手最常摔的一跤，本喵单独拎出来：

- **一个等号 `=`**：把右边**装进**左边的仓库。`fish = 3` 是「把 3 装进 `fish`」。
- **两个等号 `==`**：问一句「两边一样吗」，答真或假。

而 C 在这里有一个**比 Python 更阴**的脾气：你把一个等号写进眼色里，翻译官喵**不会拦你**，程序照样生出来、照样跑。看：

```c
#include <stdio.h>

int main() {
    int fish = 0;

    if (fish = 3) {
        printf("本喵以为碗里有鱼干喵\n");
    }
    printf("fish 现在是 %d 喵\n", fish);
    return 0;
}
```

```text
本喵以为碗里有鱼干喵
fish 现在是 3 喵
```

碗明明是空的，屏幕上却说「碗里有鱼干」——因为 `fish = 3` 干的是「把 3 装进 `fish`」，这件事本身有个结果值 3。**C 里只有「是不是 0」这一条真假规矩：0 算假，别的都算真。** 3 不是 0，于是眼色答真，路就走进去了。

翻译官喵其实看见了，它会小声嘀咕一句 `warning: suggest parentheses around assignment used as truth value`（这句话的意思是「你是不是想写两个等号呀」）。

**但那只是一句警告，不是错误** —— 它不会拦下这份程序。这条和 Python 完全相反：Python 读到这句会当场甩你一个 `SyntaxError` 不让你跑，C 只是念叨一句就放你过去，然后给你一个不对的结果。

所以写眼色的时候，**永远回头检查一眼是不是两个等号**喵。

## `switch`：拿一个数去对号入座

眼色问的是「大不大、小不小、一样不一样」，可有些活儿要的是**对号入座**：本喵报一个编号，屏幕上就出一条对应的鱼。用一串 `else if` 也能写，但 C 给这种活儿准备了专座 —— `switch`：

```c
#include <stdio.h>

int main() {
    int choice = 2;

    switch (choice) {
        case 1:
            printf("本喵要一条三文鱼喵\n");
            break;
        case 2:
            printf("本喵要一条秋刀鱼喵\n");
            break;
        case 3:
            printf("本喵要一条鳕鱼喵\n");
            break;
        default:
            printf("这个编号本喵不认识喵\n");
            break;
    }
    return 0;
}
```

```text
本喵要一条秋刀鱼喵
```

拆开看，它有四样家当：

1. **`switch (要对的数)`** —— 小括号里放那个「用来对号」的数，这里放的是 `choice`。
2. **`case 值:`** —— 一个编号一张标签，末尾那个**冒号**一个都不能少。
3. **`break;`** —— 每段标签尾巴上的「出去吧」。它就是「这一条道走到底了，别再往下走」的意思。（`break` 这个词，本喵在「break 与 continue」那一课还要专门请出来讲，今天先认个脸：在 `switch` 里它的活就是**把路封住**。）
4. **`default:`** —— 兜底那张标签，前面所有 `case` 都对不上时才轮到它。它不用给值，因为它就是「剩下的全归我」。

有两件事要提醒你：

- **`switch` 只能问「等不等于某一个值」**，号码、编号、菜单上的数字都很合适。但「大于 60 吗」这种**范围**的问话它答不了，那还得请 `if` 出场。
- **对号的数和 `case` 后面的值必须是同一种形状**。本喵这里两边都是整数，对得上；换成别的形状翻译官喵就要跟你急了。

## 漏了 `break`，会一路滑下去

这是 `switch` 最经典的一跤，本喵真跑给你看。下面这段把 `case 1:` 尾巴上的 `break;` 拿掉了：

```c
#include <stdio.h>

int main() {
    int choice = 1;

    switch (choice) {
        case 1:
            printf("本喵要一条三文鱼喵\n");
        case 2:
            printf("本喵要一条秋刀鱼喵\n");
            break;
        case 3:
            printf("本喵要一条鳕鱼喵\n");
            break;
        default:
            printf("这个编号本喵不认识喵\n");
            break;
    }
    return 0;
}
```

```text
本喵要一条三文鱼喵
本喵要一条秋刀鱼喵
```

本喵只报了编号 1，屏幕上却冒出**两条**鱼。因为 `case` 干的事是「跳到这个标签这儿，然后**一路往下走**」，而 `break` 才是那个让路停下的东西。少了它，电脑跳进 `case 1` 之后不会自己回头看编号，而是顺顺当当滑进了 `case 2`，一直滑到遇见 `break` 才停。

翻译官喵**一个字都不会警告你**：这段程序语法上一点问题都没有，它只是在安安静静地干错事。

::: warn 小心喵
`switch` 里每一段标签的尾巴上，**`break;` 是必须自己记得写的**（`default` 那段通常也写上）。写完一串 `case`，回头把每一段的尾巴扫一遍，是写 `switch` 的固定动作喵。
:::

```demo
step 出门之后：后面的标签一行都没碰
at: 8
say: 出门以后回头看：第 8 行往下（`case 3`、`default`）**一行都没跑** —— 这才是 `break` 该有的样子。要是第 1 格的尾巴上本来就有 `break;`，电脑办完第 4 行就出门了，**第 5 行往后一个字都不会碰**。
meow: 后面那些标签，今天一个都没碰喵～
pose: proud
choice = 1
对号对中的标签 = 第 1 张标签（case 1）
现在跑到哪个标签 = 出门了
```

**记住这一条**：`switch` 只**对一次号**（「对号对中的标签」那一栏从头到尾没变过），对完就跳到那张标签往下**挨行跑**；想让路停下来，靠的是尾巴上那个 `break;` —— 它才是刹车喵。

## 嵌套判断：眼色里再看一眼

眼色也能一层套一层。比如本喵想问两件事：碗里有没有鱼干？今天有没有带客人来？

```c
#include <stdio.h>

int main() {
    int fish = 2;
    int guest = 1;

    if (fish > 0) {
        if (guest > 0) {
            printf("有鱼干，还带了大肥鱼一起来吃喵\n");
        } else {
            printf("有鱼干，本喵自己吃喵\n");
        }
    } else {
        printf("碗空了，去鱼塘边找大肥鱼喵\n");
    }
    return 0;
}
```

```text
有鱼干，还带了大肥鱼一起来吃喵
```

读法是**从外往里**：

- 外层先看 `fish > 0`，答真，才轮到它大括号里的东西上场。
- 里面那个 `if (guest > 0)` 再问第二句。它俩是**各自独立**的两对括号，别把它们看成一对。
- 外层要是答假，里面那一整套连问都不会被问到，直接跳到外层 `else` 那条路上。

写嵌套的时候，本喵的习惯是**每往里一层就多让 4 格**。C 不看缩进，可你的眼睛看 —— 缩得齐，才一眼看得出「哪句话归哪一对大括号管」喵。

::: tip 猫咪提示
今天四件事，各记一句：

1. **`if (眼色) { 话 }`** —— 小括号管眼色、大括号管话，两对括号都不能省。
2. **`else if` 是串起来问的** —— 谁先答真走谁；最严的条件排最上面，不然会被前面宽松的条件抢走。
3. **`=` 是装东西，`==` 才是问话** —— C 不会为这个错误拦你，只会给你一个不对的结果。
4. **`switch` 是对号入座** —— 只能对「等不等于某个值」；每段 `case` 的尾巴别忘了 `break;`。
:::

::: warn 小心喵
最坑的三处，写代码时在心里过一遍：

1. **眼色里写成一个等号**：C 不报错，`if (fish = 3)` 恒为真，你只能从结果里发现不对。
2. **`case` 后面漏了 `break;`**：会一路滑到下一段，屏幕上多印一条。
3. **`case 值:` 那个冒号漏了**、或者用成了中文冒号 `：`——这个翻译官喵会拦你，会指着那一行说它想要一个冒号。
:::
