## 钩子：分账的难题

鱼塘大丰收，捞上来 **12 条**小鱼干，要分给 **5 只**猫。大肥鱼拿爪子在地上划拉：

「12 除以 5……每只猫 2 条，还剩 2 条。」

本喵把这件事写成 C，跑出来跟它划拉的**一模一样**：

```c
#include <stdio.h>

int main(void) {
    int fish = 12;
    int cats = 5;
    printf("%d\n", fish + cats);
    printf("%d\n", fish - cats);
    printf("%d\n", fish * cats);
    printf("%d\n", fish / cats);
    return 0;
}
```

```text
17
7
60
2
```

前三行没什么稀奇：`+` 加、`-` 减、`*` 乘。可第四行要留神了喵——**12 除以 5 得 2**，不是 2.4。

这一课就讲仓库里的货能怎么算。你会在这一课撞见 C 最出名的一个脾气，也会知道 `=` 和 `==` 为什么能把新手坑得团团转。

## 整数除法：零头直接被砍掉

上一课你已经见过「整数货和小数货是两个世界」，这一课它们第一次打架：

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 5 / 2);
    printf("%d\n", 7 / 2);
    printf("%f\n", 5.0 / 2);
    printf("%d\n", 5 % 2);
    printf("%d\n", 7 % 2);
    return 0;
}
```

```text
2
3
2.500000
1
1
```

一行一行看喵：

- `5 / 2` 得 **2**，`7 / 2` 得 **3**——**两件整数货相除，结果还是整数，零头直接砍掉**，不是四舍五入；
- `5.0 / 2` 得 **2.500000**——只要有一件货是小数，结果就是小数。所以想让除法保留零头，就把其中一件写成 `5.0` 这样带小数点的样子；
- `%` 是**取余**：`5 % 2` 得 1、`7 % 2` 得 1，就是「分完还剩几条」。取余是整数货之间的本事——「分完还剩几条」这句话，本来就只有整条的小鱼干才有意义喵。

「12 条分给 5 只猫」用 C 写出来就是这两句：`12 / 5` 每只猫分到 2 条，`12 % 5` 还剩 2 条。

::: warn 小心喵
**拿 0 去做除数是 C 里最危险的动作之一。**

本喵真试过：`7 / 0` 或者 `7 % 0`，程序**当场断气**——屏幕上什么交代都没有，也没有一句「除数不能是 0」的提示。别的语言多半会停下来告诉你哪儿错了，C 不会：它照着你说的做，然后一头撞死。

所以往后写除法之前，先在心里问一句：**分母会不会是 0？** 尤其是它来自大肥鱼敲进来的数的时候喵。
:::

## 比大小：C 的「真」是 1，「假」是 0

`>` 大于、`<` 小于、`==` 等于、`!=` 不等于——比大小的结果也是一种货，只不过它只有两种：

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 3 > 2);
    printf("%d\n", 3 < 2);
    printf("%d\n", 3 == 3);
    printf("%d\n", 3 != 3);
    return 0;
}
```

```text
1
0
1
0
```

C 没有「真」「假」两个字，它用 **1 表示真、0 表示假**。所以 `3 > 2` 念出来是 1（这句话是真的），`3 < 2` 念出来是 0（这句话是假的）。换两个数也一样：`5 > 3` 是真的，念出 1；`5 < 3` 是假的，念出 0。

::: warn 小心喵
**`=` 和 `==` 是两回事，这是新手第一大坑。**

- `=` 是**装货**：把右边的货搬进左边那间屋（上一课讲过）；
- `==` 是**问一句「两边一样吗」**，回答 1 或者 0。

写岔了的后果很阴：`n = 5` 在 C 里是一句**合法**的句子（把 5 装进 `n`）。写成 `if (n = 5)` 的时候，翻译官喵**会**嘀咕一句 `warning: suggest parentheses around assignment used as truth value` —— 可它只是**警告**：编译照样过，5 照样被塞进 `n`、照样当条件用。你想问「是不是 5」，它却把 5 装了进去。所以往后看到 `=` 只有一个的时候，先问自己一句：**我这是要装货，还是要问话？**
:::

## 与、或、非：`&&`、`||`、`!`

比大小的结果能拼起来用：

```c
#include <stdio.h>

int main(void) {
    int a = 0;
    printf("%d\n", a && (1 / 0));
    printf("%d\n", 1 || (1 / 0));
    printf("%d\n", !a);
    printf("%d\n", !5);
    return 0;
}
```

```text
0
1
1
0
```

- `&&` 是**与**：「两边都得是真的」；
- `||` 是**或**：「有一边是真的就行」；
- `!` 是**非**：「把真变假、把假变真」——`a` 装的是 0（假），所以 `!a` 是 1；5 是真的，所以 `!5` 是 0。

前两行藏着 C 的一个聪明劲儿，本喵特意用 `1 / 0` 来试它：`a && (1 / 0)` 里 `a` 本来就是假的，右边那个「拿 0 做除数」**根本没被算**，所以程序平安念出 0；`1 || (1 / 0)` 里左边已经是真的了，右边同样没被碰。

（跑这两句的时候，翻译官喵会嘀咕一句 warning——它翻稿子时会先算算那个式子。别慌，那是它在审稿，不是说这句真被算了：真跑起来右边一个字都没碰喵。）

**左边一旦能定下结果，右边就不看了**——这叫作**短路**。往后你会靠它写出「先看看门牌号在不在，再去敲门」这种稳当的句子喵。

## 复合赋值：`+=`、`-=`、`*=`、`/=`

「把屋里的货拿出来算一算，再装回去」这件事太常干了，C 给它准备了缩写：

```c
#include <stdio.h>

int main(void) {
    int n = 10;
    n += 5;
    printf("%d\n", n);
    n -= 3;
    printf("%d\n", n);
    n *= 2;
    printf("%d\n", n);
    n /= 4;
    printf("%d\n", n);
    return 0;
}
```

```text
15
12
24
6
```

`n += 5` 就是 `n = n + 5` 的缩写，`-=`、`*=`、`/=` 同理。屋里原来的货是 10，加上 5 变成 15，减去 3 变成 12，乘 2 变成 24，除以 4 变成 6——一路装回同一间屋喵。

## 自增自减：`++` 站在前头和站在后头不一样

「加一」这件事也太常干了，C 直接给了一个符号。可它是 C 里最会藏猫腻的一个：

```c
#include <stdio.h>

int main(void) {
    int a = 3;
    printf("%d\n", a++);
    printf("%d\n", a);
    int b = 3;
    printf("%d\n", ++b);
    printf("%d\n", b);
    return 0;
}
```

```text
3
4
4
4
```

- `a++`（站在后头）：**先把屋里那件货念出去（3），再加一**——所以第一行是 3，第二行再看那间屋已经是 4 了；
- `++b`（站在前头）：**先加一，再把新的货念出去**——所以第三行直接就是 4。

两行念话看着一模一样，差别全在 `++` 站的位置上。本喵的建议是：**单独写一行用**（`a++;`），别把它塞进念话里——塞进去就得盯着它站在哪边，容易看走眼喵。

## 先算哪一步

一句里挤了好几个符号的时候，谁先算？

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 2 + 3 * 4);
    printf("%d\n", (2 + 3) * 4);
    printf("%d\n", 1 + 2 == 3);
    return 0;
}
```

```text
14
20
1
```

- `2 + 3 * 4` 得 14——**先乘除、后加减**，跟数学课本一样；
- 加一对括号就翻了天：`(2 + 3) * 4` 得 20——**括号最优先**；
- `1 + 2 == 3` 得 1——**先算加法（得 3），再拿 3 去比大小**，是真的所以念出 1。

规矩不算多，但本喵有个万能的笨办法：**拿不准就加括号**。多打两个字符，换来一眼就能看懂的句子，这笔买卖划算喵。

::: tip 猫咪提示
今天收五条：

1. **两件整数货相除，零头直接砍掉**：`5 / 2` 是 2；想留零头就把一件写成 `5.0`；
2. **`%` 取余**：`12 % 5` 是「分完还剩几条」；
3. **比大小给 1 或 0**：真就是 1，假就是 0；
4. **`=` 装货，`==` 问话**——别写岔；
5. **先乘除后加减、括号最优先**，短路只在需要时才看右边。
:::

## 小任务

1. 算一算 17 条小鱼干分给 4 只猫：每只几条、还剩几条？写 C 让它把两个数都念出来。
2. 把第 1 题的 17 改成 `17.0`，除法那行会念出什么？先猜，再跑。
3. 一间屋里装着 `6`，用三种写法让它变成 7（`+=`、`++`、`= n + 1`），每种念一遍。
4. 猜一猜 `2 + 3 * 4 == 14` 会念出什么，再跑一遍对答案。要是拿不准，就先给它加上括号。
