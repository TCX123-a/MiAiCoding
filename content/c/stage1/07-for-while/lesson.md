## 钩子：大肥鱼的一百圈

本喵的好朋友「大肥鱼」——那条圆滚滚的蓝色大鱼——今天要在鱼塘里游圈锻炼。它的规矩是：**游一圈，本喵喂一条小鱼干。** 一圈一条，一百圈就是一百条。

要是本喵老老实实写一百行「喂一条」，爪子都敲断啦。电脑最擅长「同一套动作重复很多遍」，本喵居然在替它干！

这种活儿，术语表里叫**绕鱼干跑圈（循环）**。今天本喵要教你 C 里的三兄弟：**`for`**（数着圈跑）、**`while`**（看着眼色跑）、**`do-while`**（先干一圈再问），最后再把它们的脾气摆在一起比一比喵。

## `for`：数得清圈数的时候

先看最省心的一种：本喵**明明白白知道**要跑 3 圈。

```c
#include <stdio.h>

int main() {
    for (int i = 0; i < 3; i++) {
        printf("绕一圈喵\n");
    }
    return 0;
}
```

```text
绕一圈喵
绕一圈喵
绕一圈喵
```

盯着 `for (int i = 0; i < 3; i++)` 这一行 —— **小括号里一共三件家当，用两个分号隔开**，一件都不能少：

1. **起点 `int i = 0`** —— 开盘前先摆一只叫 `i` 的小仓库，装上 0。这一件**只干一次**。
2. **眼色 `i < 3`** —— **每一圈开场前**都瞄一眼。答真才跑这一圈，答假就收工。
3. **收尾 `i++`** —— **每一圈跑完之后**做一下。`i++` 就是「把 `i` 加一」的简写。

三件家当各司其职，圈就这么一圈一圈转起来了：`i` 是 0 时进门、跑完加一；`i` 是 1 时进门、跑完加一；`i` 是 2 时进门、跑完加一；到 `i` 变成 3 的时候再瞄一眼眼色 —— 「3 比 3 小吗？」答假，圈停了。

这三件家当**谁先谁后**，光盯着代码是看不出来的 —— 本喵把它拆成一步一步，走给你看：

**把这三件事的时机记住，跑圈就再也没有秘密了**：起点只做一次、眼色每圈做一次（**在循环体之前**）、收尾每圈做一次（**在循环体之后**）。

### `i` 是从 0 开始数的

别急着往下看，先盯着 `i` 看它每圈领到了什么：

```c
#include <stdio.h>

int main() {
    for (int i = 0; i < 3; i++) {
        printf("%d\n", i);
    }
    printf("跑完啦\n");
    return 0;
}
```

```text
0
1
2
跑完啦
```

两个要紧的地方：

- **`i` 领到的是 0、1、2，不是 1、2、3。** 起点写的是 0，眼色写的是「比 3 小」，所以 3 这一圈压根进不来。想印「第 1 圈」，得自己写 `i + 1`。
- **最后那句 `printf("跑完啦\n");` 只印了一遍，没跟着跑三遍。** 因为它**站在大括号外面** —— 归跑圈管的只有大括号里的活儿。圈跑完了，才轮得到它。

### 三件家当随你改

想把 1 到 5 都印一遍，只要动一动起点和眼色：

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }
    return 0;
}
```

```text
1
2
3
4
5
```

起点改成 `1`，眼色改成 `i <= 5`（小于**或等于**），1 到 5 就一个不落地印出来了。

倒着数也不难 —— 把收尾那件家当换成减一：

```c
#include <stdio.h>

int main() {
    for (int i = 5; i > 0; i--) {
        printf("%d\n", i);
    }
    return 0;
}
```

```text
5
4
3
2
1
```

`i--` 是「把 `i` 减一」的简写。起点给 5、眼色是「比 0 大」、收尾一路往下减 —— 同一套三件家当，换个方向照样跑得起来喵。

### 小碗累加：跑圈最常干的活

跑圈最常干的一件事，是「把每一圈领到的东西攒起来」。攒东西得先备一只小碗：

```c
#include <stdio.h>

int main() {
    int total = 0;

    for (int i = 1; i <= 4; i++) {
        total = total + i;
    }
    printf("%d\n", total);
    return 0;
}
```

```text
10
```

跟着念一遍：小碗 `total` 先洗成 **0**；第一圈 `i` 是 1，碗里变成 0 加 1 得 1；第二圈领到 2，碗里 1 加 2 得 3；第三圈 3 加 3 得 6；第四圈 6 加 4 得 **10**。四圈跑完，把碗端出来印一下 —— 这就是「求 1 到 4 的和」喵。

::: tip 猫咪提示
**数得清圈数用 `for`，只能凭眼色停用 `while`**——这是本喵的小口诀。`for` 的圈数开盘前就定好了（起点、眼色、收尾三件家当摆在那儿，跑满自动收工）；`while` 不问圈数，每一圈都要重新瞄一眼眼色喵。
:::

## `while`：只能凭眼色停的时候

有些活儿事先数不清 —— 比如碗里还剩几条鱼干，本喵懒得数，只认一条规矩：**「碗里还有，就接着发。」**

```c
#include <stdio.h>

int main() {
    int fish = 3;

    while (fish > 0) {
        printf("碗里还有 %d 条喵\n", fish);
        fish = fish - 1;
    }
    printf("发完啦\n");
    return 0;
}
```

```text
碗里还有 3 条喵
碗里还有 2 条喵
碗里还有 1 条喵
发完啦
```

`while` 的读法是：**每跑一圈之前，先看一眼小括号里的眼色：答真才继续跑，答假就收工。**

跟着念一遍：`fish` 是 3 → 3 比 0 大，答真 → 发一条、`fish` 变成 2；2 比 0 大 → 又发一条、`fish` 变成 1；1 比 0 大 → 再发一条、`fish` 变成 0；第四次瞄一眼 —— 0 比 0 大吗？答假，圈停了。屏幕上正好三条喵。

和 `for` 比一比：`for` 把「起点、眼色、收尾」三件家当**挤在一行里**，所以它天生适合「数得清」的活；`while` 只留了**眼色**这一件在小括号里，起点得自己提前摆好（`int fish = 3;`），收尾得自己写在圈里（`fish = fish - 1;`）。

### 让眼色有机会变假

上面那段里最要紧的是哪一行？不是 `while`，也不是 `printf`，而是那句 **`fish = fish - 1;`** —— 它每跑一圈就把眼色往前挪一格，让 `fish` 早晚有一天变成 0。

漏了它会怎样？`fish` 永远是 3，眼色永远答真，圈就永远停不下来 —— 代码会一路跑到你硬把窗口按掉。本喵把这种停不下来的圈叫**卡死的圈**，它最典型的长相是 `while (1)` —— 括号里那个 1 永远不是 0，按 C 的规矩就是永远为真。

这一课**本喵故意不给能跑的示例**：它一跑起来界面就得强行关掉，没法演示喵。

::: warn 小心喵
写完任何一个 `while`，都停下来问自己一句：**圈里有没有一句代码，能让那个眼色早晚变成假？** 那个数要越跑越小（或者越跑越大），不能原地踏步。这一问，能救你一台电脑喵。
:::

## `do-while`：先干一圈，再问眼色

三兄弟里还有一位，脾气最特别：**它不先看眼色，而是先把圈里的活干一遍，干完了再问。**

```c
#include <stdio.h>

int main() {
    int fish = 0;

    do {
        printf("先发一条再说喵\n");
        fish = fish - 1;
    } while (fish > 0);

    printf("收工喵\n");
    return 0;
}
```

```text
先发一条再说喵
收工喵
```

明明 `fish` 一开头就是 0，眼色「比 0 大」第一次问就是假的，可屏幕上还是印出了「先发一条再说喵」。这就是 `do-while` 的脾气：**先干一圈，再拿眼色决定要不要来第二圈。** 所以它的圈**至少会跑一遍**，`while` 和 `for` 都可能一圈都不跑。

它有两个长相上的讲究：

- **`do` 的下面是大括号**，圈里的活儿写在里面。
- **收尾那一行是 `} while (fish > 0);`** —— **末尾那个分号千万不能丢**。`while` 那一行平时是独自开场的（不带分号），可在 `do-while` 里它是**结尾**，少了那个分号，翻译官喵会拦下你。

本喵真跑给看 —— 把那个分号拿掉，它当场就不干了：

```c
#include <stdio.h>

int main() {
    int fish = 0;
    do {
        fish = fish + 1;
    } while (fish < 3)
    printf("%d\n", fish);
    return 0;
}
```

```text
main.c:7:23: error: expected ';' before 'printf'
```

最后那句的意思是：**在本喵等着一个分号的地方，冒出来的是 `printf`。** 看到 `expected ';'`，先去前一行末尾找那个漏掉的分号喵。

## 三兄弟的小抄

| 招式 | 本喵的说法 | 什么时候用它 |
|---|---|---|
| `for` | 数着圈跑 | 圈数事先数得清：起点、眼色、收尾三件家当挤在一行 |
| `while` | 看着眼色跑 | 圈数数不清，每圈开场前先瞄一眼眼色 |
| `do-while` | 先干一圈再问 | 不管怎样都得先干一遍，干完再看眼色要不要继续 |

## 一个跟着跑圈来的坑：整数除法

跑圈时本喵常要算平均数：一共 10 条鱼干，分给 4 只猫。本喵想写「10 除以 4」，可 C 给出来的答案会让你愣一下：

```c
#include <stdio.h>

int main() {
    int total = 10;
    int n = 4;

    printf("%d\n", total / n);
    printf("%.2f\n", 10.0 / 4);
    return 0;
}
```

```text
2
2.50
```

第一行印出 `2`，不是 `2.5`。这是 C 的一个老实脾气：**两边都是整数，做出来的除法就叫整数除法 —— 结果的小数部分直接切掉，不四舍五入。** 10 除以 4 本来是 2.5，切掉小数就成了 2。

想让答案留小数，就得**让参与计算的两边里至少有一个是小数的形状**：第二行写的是 `10.0 / 4`，`10.0` 是带小数点的写法，C 就乖乖按小数除法算，印出 `2.50`（`%.2f` 的意思是「按小数印，留两位」）。

这一条和 Python 不一样 —— Python 里 `10 / 4` 直接给你 `2.5`。C 更「老实」，也更需要你留个心眼喵。

::: warn 小心喵
跑圈里的三个常见摔法：

1. **眼色永远不变假** —— 圈里的那句「让数往前挪一格」漏了，圈就停不下来。写完 `while` 必查这一句。
2. **`do-while` 收尾的分号丢了** —— 报 `expected ';'` 指着下面那一行，真正的漏点在它上面。
3. **整数除法切掉小数** —— 算平均、算比例的时候，记得让算式里至少有一个带小数点的数。
:::

::: tip 猫咪提示
今天记住三句话就够啦：

1. **`for (起点; 眼色; 收尾)`** —— 三件家当挤在小括号里，用两个分号隔开；`i` 从起点开始，每圈跑完做一次收尾。
2. **`while (眼色)`** —— 每圈开场前先瞄一眼；圈里必须有一句让眼色早晚变假的话。
3. **`do-while` 先干一圈再问** —— 圈至少跑一遍，收尾那个分号不能丢。
:::
