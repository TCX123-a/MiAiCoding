## 钩子：大肥鱼游到一半不想游了

大肥鱼今天在鱼塘里游圈，规矩还是「游一圈，喂一条」。可它游着游着，有时候会变卦：

- 游到第 4 圈，它「啪」地一下停住 —— 今天不想游了，剩下的圈数全不算数。
- 或者某几圈它偷懒：**这一圈不算**，从下一圈接着算。

上一课学的 `for` 和 `while` 都是「跑满就收工」，可本喵就是想半路变卦。C 给了两个词管这件事：**`break`** 和 **`continue`**。今天本喵把它们俩的脾气摆在一起，再带你看看「圈里套圈」的时候它们会怎么走喵。

## `break`：提前收工

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 4) {
            break;
        }
        printf("%d\n", i);
    }
    printf("收工喵\n");
    return 0;
}
```

```text
1
2
3
收工喵
```

小括号里写的是 `i <= 10`，本来要跑十圈。可跑到 `i` 是 4 的那一圈时，`if (i == 4)` 先问一句眼色（`==` 问的是「两边一样吗」），答真，就撞上了 `break` —— **`break` 一撞上就收工**：这一圈剩下的活儿不干了，后面的圈数**全部作废**，程序直接跳到圈外，接着往下跑。

所以屏幕上只印出 1、2、3，接着就是圈外那句「收工喵」喵。

**两个词的分岔就一句话**：`break` 是圈**停了** —— 这一圈剩下的活儿不干，后面的圈数全部作废，控制权直接落到圈外那一行；`continue` 是圈**没停** —— 只把这一圈剩下的活儿跳过去，马上回圈头开始下一圈。

## `continue`：这一圈不干了，跳下一圈

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;
        }
        printf("%d\n", i);
    }
    printf("跑完喵\n");
    return 0;
}
```

```text
1
2
4
5
跑完喵
```

同样是跑到 `i` 是 3 那一圈撞上了它，脾气却完全不同：**`continue` 只是「这一圈剩下的活儿不干了」**，圈本身还在跑。所以 3 没被印出来，4、5 照常跑完，最后是圈外那句「跑完喵」。

一句话分清它俩：

| 关键词 | 撞上以后会怎样 |
|---|---|
| `break` | 圈**停了**，这一圈剩下的活儿不干，后面的圈数全部作废，跳到圈外 |
| `continue` | 圈**没停**，只是这一圈剩下的活儿跳过去，马上开始下一圈 |

两个词多半都和 `if` 搭伙 —— 先问一句眼色，答真才变卦。所以它们总是和「if 与 switch」那一课学的「看鱼干眼色行事」一起出现喵。

::: tip 猫咪提示
把这两个词记成两个动作：`break` 是**掀桌子走人**（圈没了），`continue` 是**这道菜不吃了，下一道接着上**（圈还在）。拿不准的时候，问自己一句：本喵是想让圈**从此不再转**，还是只想让**这一圈**少干点活喵？
:::

## `while (1)` 配 `break`：先圈起来，里面再决定

上一课本喵提过，`while (1)` 是一句话就能写出来的卡死的圈。可它配上 `break`，立刻变成一件**很好用**的家当 —— 「本喵不知道要跑多少圈，先圈起来，跑到该停的地方自己停」。

```c
#include <stdio.h>

int main() {
    int fish = 0;

    while (1) {
        fish = fish + 1;
        printf("喂第 %d 条喵\n", fish);
        if (fish == 3) {
            break;
        }
    }
    printf("喂饱啦\n");
    return 0;
}
```

```text
喂第 1 条喵
喂第 2 条喵
喂第 3 条喵
喂饱啦
```

这份写法在真实的 C 程序里到处都是：`while (1)` 负责「一直跑」，`break` 负责「跑到什么条件就出来」。**圈能不能停下来，全押在圈里那个 `break` 上** —— 只要它有一条路能走到，圈就一定会停。

## 圈里的 `break`，和 `switch` 里的 `break` 是同一个词

「if 与 switch」那一课里，你在每段 `case` 的尾巴上写过 `break;`。今天你也见到了圈里的 `break`。**它是同一个词，干的是同一件事：把当前这一层「结构」跳出去。**

- 在 `switch` 里：跳出这一串标签，不再往下滑。
- 在圈里：跳出这个圈，后面的圈数不作数。

所以写代码时看到 `break;`，先抬头看看它**住在哪一层** —— 住在 `switch` 里就跳出 `switch`，住在圈里就跳出圈喵。

## 圈里套圈：内层的 `break` 只退内层

圈可以一层套一层。这时候 `break` 有个很要紧的脾气：**它只退掉它住的那一层，外面那层动都不动。**

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 5; j++) {
            if (j == 3) {
                break;
            }
            printf("%d-%d ", i, j);
        }
        printf("\n");
    }
    return 0;
}
```

```text
1-1 1-2
2-1 2-2
3-1 3-2
```

本喵一层一层拆给你看：

- 外层是 `i`，从 1 数到 3；内层是 `j`，从 1 数到 5。
- 每一轮外层里，内层的 `j` 从 1 开始跑；跑到 `j` 是 3 时撞上 `break`，**只把内层这个圈停掉**。
- 内层停了，程序接着跑内层圈外那句 `printf("\n");`（换到下一行），然后外层 `i` 加一，**下一轮照样进内层的圈**。

所以屏幕上整整三行，每行都是「两个数」—— 如果 `break` 把两层一起停掉，后面两行就不会有了。**内层的 `break` 只退内层，这是它的本分，不是它不听话喵。**

## 一个大坑：`continue` 把每圈的步进挡住了

`for` 的「收尾」是写在括号里的，`continue` 拦不住它。可 `while` 不一样 —— 收尾那句话（比如 `i = i + 1;`）是**你自己写在圈里**的，位置一放错，圈就卡死了。

本喵真跑给看。下面这段把「往前走一步」写在了 `continue` 的**后面**：

```c
#include <stdio.h>

int main() {
    int i = 0;
    int guard = 0;

    while (i < 5) {
        guard = guard + 1;
        if (guard > 10) {
            printf("卡住啦！i 一直是 %d 喵\n", i);
            break;
        }
        if (i == 3) {
            continue;
        }
        i = i + 1;
    }
    return 0;
}
```

```text
卡住啦！i 一直是 3 喵
```

（`guard` 是本喵放的一个「数圈不数过十圈就强行停下」的小哨兵 —— 不放它，这段代码会永远跑下去，没法演示喵。）

看清楚 `i` 卡在哪儿了：`i` 走到 3 的时候，`if (i == 3)` 答真，`continue` 一跳，**直接回到圈的开头**，那行 `i = i + 1;` 根本没轮到。于是下一圈 `i` 还是 3，`continue` 又跳一次……`i` 永远停在 3，圈永远走不完。

正确的写法是把「往前走一步」放在 `continue` **前面**：

```c
#include <stdio.h>

int main() {
    int i = 0;

    while (i < 5) {
        i = i + 1;
        if (i == 3) {
            continue;
        }
        printf("%d\n", i);
    }
    return 0;
}
```

```text
1
2
4
5
```

这次 `i` 每圈都老老实实加了 1，走到 3 时 `continue` 只是把那个 `printf` 跳过去了，圈照常往下跑喵。

::: warn 小心喵
`while` 里用 `continue`，一定回头看一眼：**让每圈往前走的那句话，在 `continue` 前面还是后面？** 在后面，圈就卡死了。`for` 没有这个烦恼 —— 它的收尾写在括号里，`continue` 跳不过去喵。
:::

## 嵌套圈里的 `continue`

`continue` 和 `break` 一样，也只管**它住的那一层**。内层的 `continue` 跳的是内层这一圈，外层那一圈该怎么走还怎么走。想「一口气跳出两层」，C 里没有现成的一个词 —— 常见做法是让外层也看一眼某个记号，或者把两层包进一个招式里（那是后面课的内容啦），今天就先记住：**这两个词，都只认自己住的那一层喵。**

::: tip 猫咪提示
今天四句话：

1. **`break` 掀桌子** —— 圈停了，后面的圈数全作废，跳到圈外。
2. **`continue` 跳过这一圈** —— 圈还在，只是这一圈剩下的活儿不干了。
3. **它俩都只认自己住的那一层** —— 内层的变卦退不掉外层的圈，`switch` 里的 `break` 也一样只跳 `switch`。
4. **`while (1)` 配 `break` 是常见搭法** —— 圈能不能停，全看那个 `break` 有没有路走得到。
:::
