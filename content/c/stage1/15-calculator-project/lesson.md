五课攒下来的零件都摆在桌上了：`printf` 会摆摊、`scanf` 会收数、`if` 会分岔、`while` 会绕圈、招式会算账、牌子会指路。

今天不学新东西 —— 今天把它们**拧成一台真能用的机器**：一台小鱼干计算器。你在终端里敲两个数，它当场算给你看，还能一直算下去，直到你说收工喵。

## 一、先摊开设计图

做机器先画图。这台机器只干三件事：

1. **四只招式** —— 加、减、乘、除，各管一件。
2. **一块菜单** —— 把五个选项印出来，让你挑。
3. **一圈一圈地问** —— 挑完了算，算完了接着挑，直到你说「收工」。

一句话：**招式管算、菜单管问、`while` 管绕圈。**

顺序也定死了：先立招式，再摆菜单，最后才接线。零件不齐就通电，机器只会乱转喵。

## 二、第一步：先把四招立起来

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int sub(int a, int b) {
    return a - b;
}

int mul(int a, int b) {
    return a * b;
}

int divide(int a, int b) {
    return a / b;
}

int main(void) {
    printf("%d\n", add(3, 5));
    printf("%d\n", sub(10, 4));
    printf("%d\n", mul(6, 7));
    printf("%d\n", divide(7, 2));
    return 0;
}
```

```text
8
6
42
3
```

四只招式长得一模一样，只是中间那个记号换了：`+`、`-`、`*`、`/`。这是招式最省事的地方 —— **身体换一个记号，就是另一招**。

前三行都平平无奇，**第四行你要盯住喵**：`7 / 2` 印出来的是 `3`，不是 `3.5`。

因为 `a` 和 `b` 两只碗里装的都是整数，**整数和整数算，结果还是整数** —— C 会把小数点后面那截直接砍掉，砍得干干净净，还不给你任何提示。这是 C 脾气里很硬的一条（第 5 课见过它，今天你在自己的机器上又撞见一次了喵）。

## 三、第二步：把菜单印出来

菜单不做计算，只管印。这么简单的事也值得单独写一招？**值得喵** —— 因为菜单要被印很多遍（每问一次印一遍），写成招式就只用写一次。

```c
#include <stdio.h>

void showMenu(void) {
    printf("=== 小鱼干计算器 ===\n");
    printf("1. 加法\n");
    printf("2. 减法\n");
    printf("3. 乘法\n");
    printf("4. 除法\n");
    printf("5. 收工\n");
    printf("选一个（1-5）：");
}

int main(void) {
    showMenu();
    return 0;
}
```

```text
=== 小鱼干计算器 ===
1. 加法
2. 减法
3. 乘法
4. 除法
5. 收工
选一个（1-5）：
```

注意最后那一行的**冒号后面没有换行** —— 它写的不是 `\n`。这是故意的喵：本喵想让用户敲的数字**紧挨着冒号**出现，看起来就像在回答它。

## 四、第三步：接上输入，让它转起来

零件齐了，组装：

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int sub(int a, int b) {
    return a - b;
}

int mul(int a, int b) {
    return a * b;
}

int divide(int a, int b) {
    return a / b;
}

void showMenu(void) {
    printf("=== 小鱼干计算器 ===\n");
    printf("1. 加法\n");
    printf("2. 减法\n");
    printf("3. 乘法\n");
    printf("4. 除法\n");
    printf("5. 收工\n");
    printf("选一个（1-5）：");
}

int main(void) {
    int choice = 0;

    while (choice != 5) {
        showMenu();
        if (scanf("%d", &choice) != 1) {
            printf("\n下次再来喵～\n");
            break;
        }
        if (choice == 5) {
            printf("收工啦喵～\n");
            break;
        }
        if (choice < 1 || choice > 5) {
            printf("没有这一项喵，再选一次～\n");
            continue;
        }

        int a, b;
        printf("第一条小鱼干：");
        if (scanf("%d", &a) != 1) {
            printf("\n下次再来喵～\n");
            break;
        }
        printf("第二条小鱼干：");
        if (scanf("%d", &b) != 1) {
            printf("\n下次再来喵～\n");
            break;
        }

        if (choice == 1) {
            printf("%d + %d = %d\n", a, b, add(a, b));
        } else if (choice == 2) {
            printf("%d - %d = %d\n", a, b, sub(a, b));
        } else if (choice == 3) {
            printf("%d * %d = %d\n", a, b, mul(a, b));
        } else {
            if (b == 0) {
                printf("0 不能当除数喵！\n");
            } else {
                printf("%d / %d = %d\n", a, b, divide(a, b));
            }
        }
    }
    return 0;
}
```

几处关键的地方，本喵逐条说明喵：

- **`while (choice != 5)`** —— 只要还没选「收工」，就再来一圈。
- **`if (scanf("%d", &choice) != 1)`** —— 收数字之前先问一句「收到了吗」。`scanf` 是有战利品的：**收到几个数就叼回几**。要是用户把输入掐断了，或者敲进来的根本不是数字，它叼回来的就不是 `1` —— 那就别硬算，印一句道别，收工。
- **`&choice`** —— 第 14 课那块牌子：把碗的门牌号交给 `scanf`，它才能把数放进你的碗里。
- **`continue`** —— 选项不对（比如敲了 `9`），印一句提醒就**跳回开头**，把菜单重新摆出来。
- **`if (b == 0)`** —— 除法那招的拦路虎。拿 `0` 当除数在 C 里是不许的，真出了事谁也说不准，所以必须先挡一道。

## 五、跑起来看看

下面这几段都是**本喵真敲进去跑出来的**。（本喵是把输入直接喂给它的，所以屏幕上看不到本喵敲的那些数字；你自己在终端里敲，会看见自己敲的数字紧挨在冒号后面，其余一模一样喵。）

**第一趟：选 `1`（加法），喂 `3` 和 `5`。**

```text
=== 小鱼干计算器 ===
1. 加法
2. 减法
3. 乘法
4. 除法
5. 收工
选一个（1-5）：第一条小鱼干：第二条小鱼干：3 + 5 = 8
```

**第二趟：选 `4`（除法），喂 `7` 和 `2`。**

```text
选一个（1-5）：第一条小鱼干：第二条小鱼干：7 / 2 = 3
```

还记得第一步里那个 `3` 吗？机器上跑出来一模一样 —— **整数相除，小数被砍掉**。

**第三趟：还是选 `4`，喂 `1` 和 `0`。**

```text
选一个（1-5）：第一条小鱼干：第二条小鱼干：0 不能当除数喵！
```

要是没写那句拦路虎，拿 `0` 当除数会出什么事谁也说不准 —— 所以这种地方**必须提前挡一道**，这是做机器的人该有的谨慎喵。

**第四趟：故意敲一个菜单上没有的数 `9`。**

```text
选一个（1-5）：没有这一项喵，再选一次～
```

它没崩、也没乱算，只是把菜单重新摆出来让你再挑 —— 这就是 `continue` 的功劳。

**第五趟：选 `5` 收工。**

```text
选一个（1-5）：收工啦喵～
```

::: tip 顺便试一个别的喵
你要是把输入直接掐断（让它读不到任何东西），机器也会印一句「下次再来喵～」然后乖乖退出，不会卡在那儿转圈。这就是那句「收到了吗」的功劳 —— **每读一次，都检查一次**，机器的脾气就稳了。
:::

## 六、这台机器的零件清单

| 机器上的零件 | 哪一课学的 |
|---|---|
| `printf` 摆菜单、印结果 | 投喂与叼回 |
| `scanf` 收数字 | 投喂与叼回 |
| `while` 一圈一圈地问 | 绕鱼干跑圈 |
| `if` / `else` 分岔 | 看鱼干眼色行事 |
| `continue` 跳回开头、`break` 跳出 | break 与 continue |
| 四只招式 + `return` | 招式（第 12 课） |
| 每只碗都自己写类型 | 第 12 课那条硬规矩 |
| 喂进去的是抄件 | 第 13 课 |
| `scanf` 里的 `&` 是门牌号 | 第 14 课 |

看明白了吗喵：这台机器里**没有一样新东西**。你从第 4 课一路攒到第 14 课，今天只是把它们摆到了该在的位置上。

## 小任务

1. 把整段程序敲进去跑一遍，按本喵的路线走：选 `1` 喂 `3` 和 `5`，选 `4` 喂 `7` 和 `2`，再敲一个 `9` 逗逗它，最后选 `5` 收工。对照第五段，看看你跑的跟本喵跑的是不是一模一样。
2. 试试减法那一趟反着喂：选 `2`，第一条喂 `4`、第二条喂 `10`。猜猜它印几？（剧透：会印一个带减号的数。）
3. 先把除法那招里的 `a / b` 改成 `a % b`（`%` 是**取余数**），再选 `4` 喂 `7` 和 `2`，看看印出来是几，想想为什么。
4. 把 `while (choice != 5)` 改成 `while (1)`，跑一次 —— 还转得动吗？为什么？（提示：里面那句 `if (choice == 5) { ... break; }` 还在不在？）
