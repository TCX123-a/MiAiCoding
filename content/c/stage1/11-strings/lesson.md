## 钩子：名牌上那两个字，存哪儿喵？

本喵想给鱼塘边的每只猫挂一块名牌，名牌上写「小橘」。可是前面学的仓库只会装数字：`int` 装整数、`double` 装小数。**两个字该往哪儿放？**

答案朴素又可爱：**一个字一颗小鱼干，拿一排碗摆出来，就成了一条项链。** 今天本喵就带你串这条项链喵～

## 一、一颗小鱼干：`char`

装单个字的碗叫 `char`。写法是拿**单引号**把那个字夹起来：

```c
#include <stdio.h>

int main(void) {
    char one = 'A';
    printf("这一颗是：%c\n", one);
    printf("它的编号是：%d\n", one);
    return 0;
}
```

```text
这一颗是：A
它的编号是：65
```

逐行拆开看：

- **`char one = 'A';`** —— 单引号里**只能夹一颗**珠子。写成 `'AB'`，翻译官喵会念两句警告（`multi-character character constant` 加一句「这个数装不进 `char`」），可它**照样放你过去**：本喵真跑过，屏幕上印出来的是 `B` 和 `66` —— 它把两颗珠子按一个数硬凑到一起（`'AB'` 当成 16706），再砍到只留最后一格（`66` 正好是 `B` 的编号）。**「不拦你、可结果不是你想要的」，这种写法比报错难查多了喵。**
- **`%c`** —— 打印**一颗**珠子专用的占位符。`%d` 打整数、`%f` 打小数，都是老熟人，`%c` 是今天新来的那位。
- **`%d` 打出来居然是 `65`** —— 电脑心里的珠子其实都是**编号**：`A` 是 65、`a` 是 97、`0` 是 48。`char` 碗里装的也是个小数字，只是 `%c` 会把它翻回成字给你看。

::: tip 猫咪提示
`char` 碗只有一格，装得下**一颗**珠子。想知道某颗珠子的编号，把 `%c` 换成 `%d` 打印出来看看就行 —— 这是本喵最爱用的小花招喵。
:::

## 二、穿成一串：一排碗连起来

一排 `char` 碗挨着摆好，就串成了一条**字符串（一串小鱼干的项链）**。写起来省事得让人不敢相信 —— 双引号一夹：

```c
#include <stdio.h>

int main(void) {
    char word[] = "cat";
    int i;

    printf("整串打出来：%s\n", word);
    printf("一颗一颗打：");
    for (i = 0; i < 3; i++) {
        printf("%c", word[i]);
    }
    printf("\n");
    printf("第四格里的东西，编号是 %d\n", word[3]);
    return 0;
}
```

```text
整串打出来：cat
一颗一颗打：cat
第四格里的东西，编号是 0
```

- **`char word[] = "cat";`** —— 方括号里**空着**。空着就是「你自己数吧」，翻译官喵会一个个把位置都安排好，省得本喵数错。
- **`%s`** —— 打印**整条项链**专用的占位符。它和 `%c` 的区别就一句话：**`%c` 一颗，`%s` 一串**。
- **`word[i]`** —— 项链也是一排贴编号的猫粮碗（数组），报编号取碗，规矩和你前面学的一模一样。
- **`第四格里的东西，编号是 0`** —— 这一行是本喵故意吊你胃口的：`cat` 只有三颗珠子呀，第四格里怎么会有东西？下一节就揭晓喵。

### 单引号和双引号，差一颗珠子

`'A'` 是一颗，`"A"` 是一串 —— 看着只差一层引号，其实 `"A"` 是**两颗珠子**：一颗 `A`，外加一颗**你看不见的暗号**。这颗暗号就是下一节的主角。

## 三、项链末尾的暗号：`\0`

项链有个别人不会主动告诉你的规矩：**末尾一定要多挂一颗看不见的珠子**，编号 0，写出来叫 `\0`。

`%s` 就是靠它干活的：从第一颗开始一颗颗往外念，**念到暗号就闭嘴**。要是没有暗号，它根本不知道念到哪一颗才算完。

刚才那句 `第四格里的东西，编号是 0` 就是它 —— 第四个碗里躺着的正是这颗编号为 0 的暗号。

这颗暗号到底怎么管着 `%s`，本喵从摆碗到念完，一步一步走给你看：

**这一串记牢**：暗号也占一只碗，`%s` 念到它才闭嘴 —— 所以项链占的格子数，永远比看得见的珠子**多一格**。摆碗的时候少算这一格，就是 C 里最常见的那个坑喵。

本喵再亲手把一条项链串一遍，这次暗号是明着写出来的：

```c
#include <stdio.h>

int main(void) {
    char word[4];

    word[0] = 'c';
    word[1] = 'a';
    word[2] = 't';
    word[3] = '\0';

    printf("%s\n", word);
    return 0;
}
```

```text
cat
```

- **`char word[4];`** —— 四个碗。`cat` 只占三颗珠子，**第四个碗是专门留给暗号的**。
- **`word[3] = '\0';`** —— 亲手挂上暗号。`'\0'` 也是一颗珠子，只不过它在屏幕上一个字都不显示。
- 用双引号写 `"cat"` 的时候，这颗暗号翻译官喵**会自动帮你挂好**，所以平时你根本看不见它 —— 但它一直在那儿站岗。

::: warn 小心喵
碗要**留够**，这是今天第一个大坑喵。

`char word[] = "cat";` 是**四只碗**（三颗珠子 + 一颗暗号）。你要是自己数着摆碗，写成 `char small[3] = "cat";`，暗号就没地方挂了。本喵真跑过：翻译官喵**一声不吭**就把程序生出来了，编译的时候一个字都不说 —— 可轮到 `%s` 上阵，它会一路往外念，念到你**根本没摆碗**的地方去，念出来的是什么每次都不一样。

**这一条本喵故意不给你演示**：它的结果不稳定，没法当例子。你只要记住 —— **暗号也要占一只碗**。
:::

## 四、常用的四招：数、抄、比、接

项链的活儿有四招常客：**数**珠子、**抄**一条、**比**一比、**接**一截。它们不住在打印那家，而是住在 `string.h` 这位档案管理员家里 —— 所以文件最上面要请它出场，就在 `stdio.h` 那一行的下面：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char word[] = "cat";
    char copy[10];

    printf("真珠子有几颗：%d\n", (int)strlen(word));

    strcpy(copy, word);
    printf("抄过来的：%s\n", copy);

    printf("cat 和 cat 比：%s\n", strcmp(word, "cat") == 0 ? "一样" : "不一样");
    printf("cat 和 dog 比：%s\n", strcmp(word, "dog") == 0 ? "一样" : "不一样");
    return 0;
}
```

```text
真珠子有几颗：3
抄过来的：cat
cat 和 cat 比：一样
cat 和 dog 比：不一样
```

四招一个一个认：

- **`strlen(word)`** —— **数**一数项链上有几颗真珠子。暗号不算数，所以是 `3` 不是 `4`。
  - 它叼回来的是一种特殊类型的数字，本喵用 `(int)` 把它转成普通的 `int` 再喂给 `%d`，翻译官喵就不啰嗦了。
- **`strcpy(copy, word)`** —— **抄**。把 `word` 这条项链上的珠子（连暗号一起）抄进 `copy` 那排碗里。
  - **顺序别记反**：抄到哪儿写在**前面**，从哪儿抄写在**后面** —— 跟倒水一个道理，先把接水的碗摆好。
  - `copy` 那排碗得**够大**。本喵给了 10 只碗装 4 颗珠子，宽宽敞敞的。
- **`strcmp(a, b)`** —— **比**。两条项链一颗一颗对着比，完全一样就叼回 `0`。所以「一样」要写成 `strcmp(a, b) == 0`。
- **`strcat(a, b)`** —— **接**。把后面那条项链的珠子接到前面那条的尾巴上，暗号会被自动挪到新的末尾去。接完的碗也得够大。

`strcat` 长什么样，跑一遍就记住了：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[20] = "小橘";
    strcat(name, "喵");
    printf("%s\n", name);
    printf("%d\n", (int)strlen(name));
    return 0;
}
```

```text
小橘喵
9
```

咦，`小橘喵` 才三个字，怎么数出来是 `9`？

因为 C 数的**不是「字」，是「格子」**。这台机器上一个汉字要占 **3** 格，所以 3 个字 × 3 格 = 9 格。用中文的时候心里得有数：`strlen` 报的是格子数，不是字数喵。

### 忘了请档案管理员出场会怎样

本喵故意把 `string.h` 那一行漏掉给你看：

```c
#include <stdio.h>

int main(void) {
    char word[] = "cat";
    printf("%d\n", (int)strlen(word));
    return 0;
}
```

翻译官喵当场翻脸，这是它的原话喵：

```text
main.c:5:25: error: implicit declaration of function 'strlen' [-Wimplicit-function-declaration]
    5 |     printf("%d\n", (int)strlen(word));
main.c:2:1: note: include '<string.h>' or provide a declaration of 'strlen'
```

翻成猫话：**「`strlen` 这个名字本喵没听说过 —— 你是不是忘了请哪家档案管理员出场？」** 末尾那句 `note` 更贴心，直接告诉你该补上哪一份。

这正是 C 让人安心的地方喵：这种错在**翻译阶段**就被拦下了，程序**根本生不出来**，绝不会跑到一半才炸。

### `==` 比不了项链（今天最扎心的坑）

两条项链明明长得一模一样，你要是拿 `==` 去比，它会说「不一样」——不信你跑：

```c
#include <stdio.h>

int main(void) {
    char a[] = "cat";
    char b[] = "cat";

    if (a == b) {
        printf("两张牌子一样喵\n");
    } else {
        printf("两张牌子不一样喵\n");
    }
    return 0;
}
```

```text
两张牌子不一样喵
```

原因：项链是**一排碗**，而 `a == b` 比的是**两张牌子**（牌子是什么，到「初识猫爪指向牌」那一课就讲），比的根本**不是碗里的珠子**。两条项链摆在不同的地方，牌子当然不一样。

翻译官喵其实发现了不对劲，嘀咕了一句警告 `comparison between two arrays` —— 可它**还是把程序生出来了**，因为它想着「你也许真的想比牌子吧」。警告它不拦人，所以这种错最容易漏过去。

**记住这一条就够：比项链只有一条路 —— `strcmp(a, b) == 0`。**

::: tip 猫咪提示
今天的话打包收好喵：

1. 一颗珠子用 `char`，**单引号**夹一颗（`'A'`）；一整条项链用**双引号**夹（`"cat"`）。
2. 项链末尾那颗看不见的暗号叫 `\0`，`%s` 靠它知道念到哪儿停；**暗号也要占一只碗**。
3. 数、抄、比、接 = `strlen` / `strcpy` / `strcmp` / `strcat`，四招都住在 `string.h` 家，**用之前先请它出场**。
4. 比项链**只有一条路**：`strcmp(a, b) == 0`。用 `a == b` 比的是牌子，不是珠子。
:::
