## 钩子：鱼塘底下那道老闸门

大肥鱼领着本喵潜到鱼塘最底下，指着一道又厚又旧的闸门：「这道门比你家猫爬架还老，可整座鱼塘的水位都听它的。」

「它是拿什么造出来的呀？」

「**C**。」

C 就是编程语言里的这位老前辈喵。它出世早、长得不花哨，说话还特别较真：一句话交代不清楚，它就不放你过去。可正因为这样，它快、它稳，而且**离机器特别近**——你写的每一句，它几乎原样转给电脑，中间没有别的猫替你做主。

你今天用的很多东西，底下都站着它：别的语言请的翻译官喵，有不少本身就是 C 造出来的；鱼塘的闸门、电脑里那些看不见的角落，也常常是它守着。学会它，你手里就多了一把管得住整座鱼塘的锅铲喵～ 🐟

## 第一份 C 程序：让电脑念一句话

先看成品。这段代码从头到尾一共七行，本喵真跑过：

```c
#include <stdio.h>

int main(void) {
    printf("你好，喵！\n");
    return 0;
}
```

```text
你好，喵！
```

比别的语言长不少吧？别慌，它不是难，是**规矩多**。一行一行拆开，每一行都有它的用处。

### 第一行：`#include` —— 请档案管理员出场

`stdio.h` 是鱼塘档案室的一位管理员，名字是「标准投喂与叼回」的缩写。

`#include` 的意思是「把它请出来」。不请它，`printf` 这一招就没人认得——这一点本喵下面会当面演示给你看喵。

### 第二行：`int main(void)` —— 主招式，也是大门

`main` 是**主招式**，也是整份程序的大门：电脑一跑你的程序，就直奔 `main` 的第一行，别的句子都得等它喊。

- `main` 前面那个 `int`，说的是这一招干完活要**叼回一个整数**给鱼塘；
- `(void)` 是一对空着的投喂口，意思是「这一招不用喂东西」；
- 后面那对**花括号 `{ }`** 是它的地盘：凡是属于这一招的句子，都得待在花括号里面。

### 第三行：`printf("你好，喵！\n");` —— 念话

`printf` 是 C 的念话招式：括号里那对引号围住的话，它会**原样念**出来。

末尾那个 `\n` 是**换行的暗号**——它自己不会被念出来，只负责让光标跳到下一行。所以屏幕上出现的是「你好，喵！」外加一个回车，而不是「你好，喵！\n」这七个怪字符。

顺带认一句：`printf` 里那个 `f` 是「格式」的头一个字母。今天先把它当成名字的一部分，等以后讲到占位符那一课，这个 `f` 才真的要干活喵。

### 末尾两行：报平安，然后收工

`return 0;` 是招式干完了向鱼塘报个平安：「一切顺利，零号状况」。最后那半个花括号 `}` 就是收工。

### 每条句子的句号：分号

数一数：`printf(...)` 和 `return 0` 后面，都跟着一个分号 `;`。

**C 的每一条指令都要用分号收尾**，它就像中文里的句号。少了它，翻译官喵读着读着会突然愣住：「你这一句说完了没呀？」然后把报错甩给你。

## 两句一起念：从上往下一句一句来

想让电脑多念一句，就多写一句 `printf`：

```c
#include <stdio.h>

int main(void) {
    printf("喂猫手册第一条：拿起小鱼干\n");
    printf("喂猫手册第二条：放进碗里\n");
    return 0;
}
```

```text
喂猫手册第一条：拿起小鱼干
喂猫手册第二条：放进碗里
```

顺序就是代码里的顺序：谁写在前面，谁先出声。这一条和你在别处学过的编程一模一样，不用重新记喵。

## 写坏了会怎样：翻译官喵的原话

C 有个脾气要提前告诉你：**句子翻不通，它一句都不肯让你跑**。

别的语言是「念到哪儿错在哪儿」——前面已经念过的句子照样念完了；C 不是这样，它先把**整份稿子**翻一遍，翻不过去就一份都不给你。本喵故意写坏三处，把翻译官喵的原话抄给你看喵。

### 一、忘了分号

```c
#include <stdio.h>

int main(void) {
    printf("开饭啦喵\n")
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:25: error: expected ';' before 'return'
```

`main.c` 是你这份文件的名字，`4:25` 是「第 4 行、第 25 个字符」——翻译官喵连你漏在哪儿都替你点出来了。

### 二、忘了请档案管理员

```c
int main(void) {
    printf("开饭啦喵\n");
    return 0;
}
```

```text
main.c: In function 'main':
main.c:2:5: error: implicit declaration of function 'printf' [-Wimplicit-function-declaration]
```

`implicit declaration` 这句话的意思就是「这一招本喵没见过」——因为 `printf` 的来历写在 `stdio.h` 里，而你没请它出场喵。

### 三、名字写错一个字母

```c
#include <stdio.h>

int main(void) {
    prntf("开饭啦喵\n");
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:5: error: implicit declaration of function 'prntf'; did you mean 'printf'? [-Wimplicit-function-declaration]
```

看最后那半句：`did you mean 'printf'?` ——翻译官喵还顺手猜了一下你想喊谁，是不是有点像大肥鱼挠你裤脚的样子喵。

::: warn 小心喵
上面三段都跑不起来，可这**不是坏事**：错误在开工之前就被拦住了，你不会遇到「程序跑到一半忽然炸掉」那种更难查的场面。

但请记住这个脾气的另一面：**C 拦的是「翻不通」的错，拦不住「翻得通但你想歪了」的错**。比如你把两句 `printf` 的顺序写反，它一句话都不会说，程序老老实实照着你的顺序念完。所以往后每次跑出不对劲的结果，第一件事是回头读自己的代码，别急着怪翻译官喵。
:::

::: tip 猫咪提示
今天记住四件事：

1. `#include` 是**请档案管理员出场**，请了它 `printf` 才有人认得；
2. `main` 是**大门**，程序从它的花括号里第一行开始跑；
3. `printf("...")` 是**念话**，引号里的字原样念，`\n` 是换行的暗号；
4. 每条指令末尾都要有**分号**，`return 0;` 是收工时报的平安。
:::

## 小任务

把第一段代码一字不差地敲进编辑器，跑一遍，看看屏幕上是不是那句「你好，喵！」。然后试着改三处，每改一处先猜结果、再跑：

1. 把引号里的字换成「本喵会写 C 啦」；
2. 在花括号里再加一句 `printf("第二句\n");`，看看两行是怎么排的；
3. 把末尾那个 `\n` 删掉，再跑一次——想想屏幕上会变成什么样，为什么。

改完这三处，你就摸到 C 的第一条规矩了。下一课，本喵要带你看看那句「翻不通就一句都不给你跑」到底是怎么发生的：从你敲下的字到屏幕上那句你好，中间要过四道工序喵～ 🐾
