## 钩子：两只招式，一喊一接

鱼塘边有一对搭档招式，缺了哪一只鱼塘就活不起来：

- **念话**（`printf`）：把仓库里的货念给屏幕听；
- **叼回**（`scanf`）：把大肥鱼敲进键盘的东西接回仓库。

C 里管这一对叫「投喂与叼回」。上一课你已经偷偷用过念话的钩子了——`%d`、`%f`、`%c`，今天要把它们**讲透**，再把「叼回」这只招式请出来喵。

## 念话的规矩：一个钩子对一件货

```c
#include <stdio.h>

int main(void) {
    printf("我是 %s，仓库里存着 %d 条\n", "大肥鱼", 3);
    printf("今天的价钱是 %.1f 元\n", 2.5);
    printf("等级是 %c\n", 'A');
    return 0;
}
```

```text
我是 大肥鱼，仓库里存着 3 条
今天的价钱是 2.5 元
等级是 A
```

念话这一招，括号里分两拨：

1. **引号里**是前半句，里面的钩子（`%d`、`%f`、`%c`、`%.1f`）**只占位子，不念**；
2. **引号后面**按顺序排着要念的货，一件一件填进前面的钩子。

钩子家族今天先认这四个：

| 钩子 | 接什么货 |
| --- | --- |
| `%d` | 整数 |
| `%f` / `%.2f` | 小数（`%.2f` 是留两位） |
| `%c` | 一个字符 |
| `%s` | 一串字（今天只当它是个钩子，后面专门讲） |

**位子有几个，后面就得递几件货；递的牌子也得对得上。** 这两条说起来像废话，可它们是 C 里最常让人栽跟头的地方——栽的时候，C **不一定**会拦你。下面两种情况本喵都真跑过喵。

## 占了位子，却不给货

```c
#include <stdio.h>

int main(void) {
    printf("%d 加 %d 等于 %d\n", 2, 3);
    return 0;
}
```

::: warn 小心喵
翻译官喵居然**翻得过去**，只在旁边嘀咕了一句：

```text
main.c: In function 'main':
main.c:4:28: warning: format '%d' expects a matching 'int' argument [-Wformat=]
```

`expects a matching 'int' argument` 就是「这个位子该有人坐，可你没派人来」。

程序照跑不误，可那第三个 `%d` 念出来的是什么，本喵**没法告诉你**——它去读了不该它读的地方，念出来一个毫无意义的数字。换个机器、换个日子，那个数就变一个。所以看到 `warning` 千万别当没看见：**编译能过，不代表结果能信**喵。
:::

## 递错了牌子

```c
#include <stdio.h>

int main(void) {
    double price = 2.5;
    printf("%d\n", price);
    return 0;
}
```

::: warn 小心喵
这一回翻译官喵也说得很明白：

```text
main.c: In function 'main':
main.c:5:14: warning: format '%d' expects argument of type 'int', but argument 2 has type 'double' [-Wformat=]
```

`expects ... 'int', but ... has type 'double'` 就是「位子上写着要整数，你递来的却是小数」。

价钱明明存着 `2.5`，本喵这台机器上念出来的是 `0`——可这个 `0` 同样**没有保证**，它不是 2.5，也不是「小数被砍掉了」，它只是两个不同大小的筐硬凑在一起的后果。**记住：牌子递错了，念出来的东西一个字都不算数。**
:::

## 叼回：把敲进去的东西接回仓库

现在请出第二只招式。它长这样：

```c
#include <stdio.h>

int main(void) {
    int n = 0;
    printf("请输入一个整数：\n");
    scanf("%d", &n);
    printf("你输入的是 %d\n", n);
    return 0;
}
```

### 本喵喂进去一个 5，屏幕上是这样

```text
请输入一个整数：
5
你输入的是 5
```

中间那个 `5` 是**本喵敲进去**的（敲完按回车，光标才往下走），上下两行才是程序念的。

本喵把大肥鱼喂进去一个 5 的过程拆成一步一步，走给你看：

盯住这两个时机喵：屏幕上**先**出现提示语，**然后**程序才停住等你敲 —— 中间那几秒它一步都不往前走；等你敲完回车，钩子才有东西顶上去、念出第二行。这两件事中间隔着「你敲键盘」这一步，谁也替不了谁。

`scanf` 的写法跟 `printf` 像是一对双胞胎：引号里同样写钩子，引号后面排着同样数量的货。可有**两处**不一样，这两处就是今天的正题喵。

### 不一样之一：每件货前面都要加一个 `&`

`&` 放在仓库名字前面，读作「这间屋的**门牌号**」。别急着往深处想，今天先把它当个记号：**`scanf` 伸手要的不是那件货，而是那间屋的门牌号**——它得照着门牌号，把叼回来的东西放进屋里去。

`printf` 是「取出来念」，所以给屋子名字就行；`scanf` 是「放进去」，所以得给门牌号。这一条本喵也真跑过，写出来是这样：

```c
#include <stdio.h>

int main(void) {
    int n = 0;
    scanf("%d", n);
    printf("%d\n", n);
    return 0;
}
```

::: warn 小心喵
翻了多久？一眨眼。翻译官喵还是只嘀咕了一句：

```text
main.c: In function 'main':
main.c:5:13: warning: format '%d' expects argument of type 'int *', but argument 2 has type 'int' [-Wformat=]
```

那个 `int *` 就是「门牌号」在 C 里的长相。

本喵还替它把胆子试大了：把仓库原来的货换成 `12345`（`int n = 12345;`），照样只有这么一句 warning——可这回一跑起来，**程序当场断气**，屏幕上什么都没剩下。

为什么呢？因为 `scanf` 拿不到门牌号，就**把仓库里装的那个数当成门牌号**拿去用了：里面装的是 0，它还能装作没事；装的是别的数，它就一脚踹到别人家去了。

所以这一条请写进肌肉记忆里：**`scanf` 的每件货前面，都要加 `&`。**
:::

### 不一样之二：小数的钩子要写 `%lf`

`printf` 里小数用 `%f`，可 `scanf` 里接小数的钩子长得不一样，多了一个字母：

```c
#include <stdio.h>

int main(void) {
    double price = 0;
    scanf("%lf", &price);
    printf("%.2f\n", price);
    return 0;
}
```

#### 本喵喂进去 2.5，屏幕上是这样

```text
2.5
2.50
```

要是顺手写成 `%f` 呢？C 不会拦你，读进来的却是一堆没用的东西：

::: warn 小心喵
```text
main.c: In function 'main':
main.c:5:13: warning: format '%f' expects argument of type 'float *', but argument 2 has type 'double *' [-Wformat=]
```

括号里念出来的还是 `0.000000`——**货根本没接住**，价钱那间屋从头到尾都是空的。

记忆口诀本喵给你编一个：**念的时候 `%f`，接的时候 `%lf`**——接的那只多长了一根小尾巴喵。
:::

### 没人喂的时候会怎样

在软件里点「运行」的时候，**没有人会去喂它数字**。这时候 `scanf` 叼不到东西，那间屋就**保持原样**——上面那份稿子里本喵先写了 `int n = 0;`，所以它会念出 `你输入的是 0`。

要是忘了给屋子装个初值呢？那就回到上一课那个警告了：屋里是不知道哪来的垃圾，念出来的数没法看。**要接货的屋子，先给它装个货垫底**，这是本喵的习惯喵。

## 一个更阴的坑：叼回一个数之后再叼一个字

`scanf` 读东西的时候有个脾气：**你按的那个回车，也老老实实被它算成「一个字符」。**

```c
#include <stdio.h>

int main(void) {
    int n = 0;
    char c = '?';
    scanf("%d", &n);
    scanf("%c", &c);
    printf("n=%d 捡到的字符编号是 %d\n", n, c);
    return 0;
}
```

#### 本喵敲了「5」再按回车，屏幕上是这样

```text
5
n=5 捡到的字符编号是 10
```

第二个 `scanf` 想叼一个字符，可它叼到的是本喵按下的那个**回车**。10 就是「回车」在电脑里的编号。

想避免这种事，办法很朴素喵：**两次叼回之间，先让程序把那口回车吃掉**。这一课先知道有这回事就行——撞见了，你会想起本喵这段话的。

## 还有一件事：两个一起喂

`scanf` 不只能叼一件货，一句话里想叼几件就写几个钩子，喂的时候用空格隔开：

```c
#include <stdio.h>

int main(void) {
    int a = 0;
    int b = 0;
    scanf("%d %d", &a, &b);
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}
```

#### 本喵喂进去「2 3」，屏幕上是这样

```text
2 3
2 + 3 = 5
```

钩子之间那个空格是「跳过空白」的意思——敲一个空格、敲十个空格、或者直接按回车分开，它都认喵。

::: tip 猫咪提示
今天收四条：

1. **念话** `printf`：引号里写钩子，引号后面按顺序递货，**一个钩子对一件**；
2. **叼回** `scanf`：钩子的写法一样，可**每件货前面都要加 `&`**；
3. **小数**：念用 `%f`、接用 `%lf`，接的那只多根尾巴；
4. **要接货的屋子先垫货**（`int n = 0;`），不然没人喂的时候屋里是垃圾。
:::
