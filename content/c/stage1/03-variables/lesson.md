## 钩子：鱼塘东边那排小屋

大肥鱼领本喵走到鱼塘东边，那儿排着一溜小屋子，每间门口都挂着一块木牌。

「这排屋，是给东西住的。」大肥鱼推开门，「你看，这间挂着 `int`，里面只准住整条的小鱼干；那间挂着 `double`，住的是称出来的重量；最边上那间挂着 `char`，小得只住得下一个字符。」

「为什么要挂牌子呀？」

「因为**电脑得先知道该准备多大的筐**。」

C 就是这么较真的语言喵。上一课那些念话念完就散了，什么也没留下；想让一样东西**留下来**，你就得先给它盖间屋、挂上牌子。这类能存东西的小屋，C 里正式的名字叫变量（本喵私下喊它小鱼干仓库）。

## 第一间屋：先说清装什么，再给屋子起名

```c
#include <stdio.h>

int main(void) {
    int fish = 3;
    printf("仓库里存着 %d 条小鱼干\n", fish);
    return 0;
}
```

```text
仓库里存着 3 条小鱼干
```

中间那一行 `int fish = 3;` 拆开看，是四件事：

- `int` —— 挂上的**货牌**：这间屋只装整数；
- `fish` —— 屋子的**名字**；
- `= 3` —— 把 3 这件货**装进去**；
- 末尾的分号 —— 一句话说完了。

### 这条是 C 和别人最不一样的地方

有些语言里，你写 `fish = 3` 就完事了——屋子会自己长出来，装什么它自己看着办。C 不行：

**在 C 里，你必须先申报「这间屋装什么」，它才肯给你盖子。** 这是 C 所有较真的源头喵——往后你写 C 时撞见的那些「翻译官喵不乐意」，多半都能追到这条规矩上。

上一课那两份稿子里，`printf` 括号里的东西念完就散了，一样都留不下来；从这一课起，你会发现东西能存住了，但每存一样，都得先交一份申报。

::: tip 猫咪提示
`=` 在这儿不是数学课本上那个「等于」。它是**装货口**：把右边那件货搬进左边那间屋。至于「两边一样不一样」，C 另有写法，等讲比大小那一课再细说喵。
:::

## 三张常用的货牌

| 货牌 | 装什么 | 长这样 | 印它用哪个钩子 |
| --- | --- | --- | --- |
| `int` | 整数（几条、几只） | `3`、`-5`、`0` | `%d` |
| `double` | 小数（几斤、几元） | `2.5`、`0.75` | `%f` |
| `char` | **一个**字符（一个字母、一个数字、一个符号） | `'A'`、`'7'` | `%c` |

三种屋子各住一批货，本喵真跑过：

```c
#include <stdio.h>

int main(void) {
    int fish = 3;
    double price = 2.5;
    char grade = 'A';
    printf("小鱼干 %d 条\n", fish);
    printf("价钱 %.1f 元\n", price);
    printf("等级 %c\n", grade);
    return 0;
}
```

```text
小鱼干 3 条
价钱 2.5 元
等级 A
```

请盯住那三句念话里引号**后面**的东西：`%d` 后面跟着 `fish`，`%.1f` 后面跟着 `price`，`%c` 后面跟着 `grade`。

**这就是 C 的念话规矩：引号里写钩子，引号外面按顺序把货递过去。** 一个钩子对一件货，而且得**牌对牌**——整数递 `%d`、小数递 `%f`、字符递 `%c`。递错了 C 当场不拦你（它翻得过去），可念出来的就是一堆没用的东西——这是 C 最容易让人栽跟头的地方，下一课专门讲它，今天先记住「要配对」这三个字。

`%.1f` 里那个 `.1` 是「留一位小数」。不写它，`%f` 会念出一串长尾巴：

```c
#include <stdio.h>

int main(void) {
    printf("%f\n", 2.5);
    printf("%.2f\n", 2.5);
    printf("%f\n", 10.0 / 3.0);
    printf("%.2f\n", 10.0 / 3.0);
    printf("%.0f\n", 10.0 / 3.0);
    return 0;
}
```

```text
2.500000
2.50
3.333333
3.33
3
```

第一行那个 `2.500000` 就是默认的**六位**小数——C 觉得「你没说留几位，那本喵留六位」。所以印价钱、印重量的时候，记得自己写上 `.2`、`.1` 这样的小尾巴喵。

## `char` 的两张脸

`char` 这间屋最容易被小看，可它有个别的语言里少见的脾气：**在 C 眼里，一个字符其实就是一个小整数。**

```c
#include <stdio.h>

int main(void) {
    char grade = 'A';
    printf("%c\n", grade);
    printf("%d\n", grade);
    printf("%c\n", 66);
    return 0;
}
```

```text
A
65
B
```

同一间屋、同一件货，换个钩子念出来就完全不一样：

- `%c` 是「按字符念」→ `A`；
- `%d` 是「按数字念」→ `65`——原来 `A` 在电脑里就是 65 这个数；
- 既然 65 就是 `A`，那 66 就是 `B`，所以最后一行拿 `%c` 去念 66，念出来是 `B`。

这条不用急着背，记住那个「哦——原来是这么回事」就够。今天真正要收下的是：**`char` 装的是单个字符，写它得用单引号 `'A'`。**

## 仓库名怎么起

本喵试了几种名字，都跑得通：

```c
#include <stdio.h>

int main(void) {
    int fish_2 = 3;
    int _cat = 5;
    int Fish = 7;
    int fish = 9;
    printf("%d %d %d %d\n", fish_2, _cat, Fish, fish);
    return 0;
}
```

```text
3 5 7 9
```

规矩就三条：

1. 名字只能用**字母、数字、下划线**；
2. **不能用数字开头**（`2fish` 不行，`fish2` 行）；
3. **大小写算两个名字**——`Fish` 和 `fish` 是两间不同的屋，上面那行能同时印出 `7` 和 `9` 就是这个道理。

还有一条本喵没写成代码：**C 自己留着用的名字，不能拿来当仓库名**（`int`、`char`、`return` 这些）。它们已经被 C 拿去挂牌子了，你再挂一块同名的，翻译官喵会迷路喵。

## 货装错了：翻译官喵的原话

### 一、拿装整数的屋子装一串字

```c
#include <stdio.h>

int main(void) {
    int fish = "三条小鱼干";
    printf("%d\n", fish);
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:16: error: initialization of 'int' from 'char *' makes integer from pointer without a cast [-Wint-conversion]
```

最后那个 `char *` 的意思是「一串字」。翻译官喵说得挺清楚：**你递过来的是「一串字」，可这间屋的牌子上写着整数**，它不干。

### 二、名字拿数字开了头

```c
#include <stdio.h>

int main(void) {
    int 2fish = 3;
    printf("%d\n", 2fish);
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:9: error: invalid suffix 'fish' on integer constant
main.c:4:9: error: expected identifier or '(' before numeric constant
```

`invalid suffix` 是「这个尾巴不对劲」：翻译官喵读到 `2` 就把它当数字收下了，后面跟着的 `fish` 它不认，只好认定是你多写了点东西。**想让名字里带数字，就把它放到后头去**——`fish2` 一点问题都没有喵。

### 三、没申报就直接拿来用

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", fish);
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:20: error: 'fish' undeclared (first use in this function)
```

`undeclared` 就是「这名字本喵没见你申报过」。看到它，往上翻翻：是忘了写 `int fish;` 那一行，还是名字拼错了一个字母？

### 四、`char` 用了双引号

```c
#include <stdio.h>

int main(void) {
    char grade = "A";
    printf("%c\n", grade);
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:18: error: initialization of 'char' from 'char *' makes integer from pointer without a cast [-Wint-conversion]
```

**单引号装的才是「一个字符」，双引号装的是「一串字」**——哪怕这串字只有一个字母，那也是一串。这一条今天先留个印象，等讲到双引号那一课你会恍然大悟喵。

## 一个不吭声的陷阱：`int` 装小数

刚才四段都大大方方地报错了，可 C 也有**一声不吭**的时候：

```c
#include <stdio.h>

int main(void) {
    int n = 2.9;
    printf("%d\n", n);
    return 0;
}
```

```text
2
```

本喵特意竖着耳朵听了：**翻译官喵一个字都没说**。翻得过去、跑得起来，只是那个 `0.9` 的零头被它**砍掉**了——不是四舍五入，是直接砍。

所以写 C 要记着：**货牌决定了能剩下多少货**。明明该留小数却挂了 `int` 的牌子，C 不会提醒你，只会安安静静地给你个错数。这种「不说话的错」比报错难查得多喵。

本喵把这一下「砍」拆成一步一步，走给你看：

```demo
title: 2.9 是怎么变成 2 的

| printf("%d\n", n);
```

**看第 3、第 4 步**：零头是在**装进屋的那一刻**就没的，不是等到印的时候才没的 —— 货牌一挂定，能剩下多少货就定了喵。

::: warn 小心喵
还有更阴的一种：**盖了屋子，却忘了装货**。

```c
#include <stdio.h>

int main(void) {
    int fish;
    printf("%d\n", fish);
    return 0;
}
```

这样的 `fish` 里不是 0，而是**上一次别的程序留在这儿的垃圾**。本喵真跑过好几遍：**每一遍印出来的是同一个数**（本机是 `32758`）。可这个「稳定」是**运气，不是规矩** —— 它读的是那块地方上一回剩下的东西，换台机器、换个跑法就变了，谁也没规定它该是几。所以别把印出来的数当答案喵。

（顺带说一句：这一处翻译官喵会念一句 `warning: 'fish' is used uninitialized`。它**看得出**你这样写不对，可**它拦不住你** —— 程序照跑，照样把那个数印出来。）

规矩是：**盖屋子的时候顺手把货装上**（`int fish = 0;` 也好）。C 不会替你打扫屋子，这是它「什么都要自己管」的另一面喵。
:::

::: tip 猫咪提示
今天收四条：

1. **先申报、再装货**：`int fish = 3;`
2. **货牌决定装什么**：`int` 整数、`double` 小数、`char` 一个字符；
3. **念话要牌对牌**：`%d` 配整数、`%f` 配小数、`%c` 配字符；
4. **`char` 是个小整数**：`%c` 念出 `A`，`%d` 念出 `65`。
:::

## 小任务

1. 盖一间装整数的屋，名字叫 `fish`，装上 5，让它念出「仓库里有 5 条小鱼干」。
2. 再盖一间 `double` 的屋装价钱 `2.5`，先用 `%.2f` 念一次、再用 `%f` 念一次，看看两行差在哪儿。
3. 盖一间 `char` 装 `'A'`，先用 `%c` 念、再用 `%d` 念；然后把 `'A'` 改成 `'C'`，先猜 `%d` 会念出几，再跑一遍对答案。
4. 把第 3 步那行的单引号改成双引号，跑一次，把翻译官喵的原话和课文里第四段比一比。
