## 钩子：鱼塘门口的一排牌子

本喵要在鱼塘门口办一场才艺会，入场处挂一排牌子：**一格一张，每张牌上只写一个门牌号**。牌子薄薄一张，可顺着它能摸到后头一大串东西 —— 书上的名字叫 **指针数组（一排指向牌）**。

它和「一排贴编号的猫粮碗」长得像、脾气差得远喵：碗里装的是**名字本身**，牌子上写的是**去哪儿找**。同样四格，一个占 64、一个只占 32，本喵量给你看。

今天讲两件事：**怎么挂这一排牌子**，以及**牌子坏掉之后会怎么样** —— 后者书上叫 **野指针（坏掉的牌子）**。它最坑的地方是：**不喊、不拦，只是照着你写的东西走。**

## 一、一格一张：先挂一排，再量一量

先看一个能跑的本子。四排猫粮碗里放着名字，本喵另挂一排牌子指过去：

```c
#include <stdio.h>

int main(void) {
    char names[4][16] = {"阿花", "大肥鱼", "小橘", "煤球"};
    char *row[4];

    for (int i = 0; i < 4; i++) {
        row[i] = names[i];
    }

    for (int i = 0; i < 4; i++) {
        printf("第 %d 张牌 -> %s\n", i, row[i]);
    }

    printf("牌子整排占多少格：%d\n", (int) sizeof(row));
    printf("猫粮碗整排占多少格：%d\n", (int) sizeof(names));
    printf("第 0 张牌上写的，就是 names[0] 的门牌号吗：%d\n", row[0] == names[0]);

    return 0;
}
```

```text
第 0 张牌 -> 阿花
第 1 张牌 -> 大肥鱼
第 2 张牌 -> 小橘
第 3 张牌 -> 煤球
牌子整排占多少格：32
猫粮碗整排占多少格：64
第 0 张牌上写的，就是 names[0] 的门牌号吗：1
```

（这几段数是本喵在这台机器上真跑出来的，命令就是本项目的标准那一条：`gcc -finput-charset=UTF-8 -fexec-charset=UTF-8 -Wall main.c -o a.exe && ./a.exe`。）

三个数，三句话：

- **32**：一整排牌子自己占的地方 —— 四张牌，一张 8 格，装的全是门牌号。
- **64**：那排猫粮碗占的地方 —— 四排、每排 16 格，装的是名字本身。**同样四格，一个 32、一个 64，装的东西压根不是一类。**
- **1**：第 0 张牌上写的，确实就是 `names[0]` 那排碗的门牌号 —— 所以 `row[0]` 顺过去拿到的，和 `names[0]` 是同一串名字。

再看一眼那一句关键的赋值喵：`row[i] = names[i];` —— **右边那排碗的名字一出现，自动变成那排碗的门牌号**（翻译官喵的老规矩，上一阶段「指针与数组」那一课见过）。所以这一句是把门牌号抄到牌子上，名字还好端端待在碗里。

一排牌子里第一张和「从第一张开始往前挪一格」是同一张：`row[1]` 和 `*(row + 1)` 说的是同一处。

## 二、先看右边、再看左边：两种写法别再串了

招牌上常并排挂着两个长得很像的写法。本喵教你一个读法，两步就够：

**从名字出发 —— 先看它右边，再看它左边。**

```text
char *row[4]      右边先来 [4]：row 是一排四格，每格里装一张牌子
char (*p)[16]     括号先把 p 和 * 绑死：p 是一张牌子，它指着一整排 16 格
```

第二行那对括号**不能省**：省掉就变成第一个形状了 —— `char *p[16]` 是「一排 16 张牌子」，和「一张指着整排的牌子」差着十万八千里。书上把前者叫 **数组指针（指着整排的牌子）**，把后者那排叫**一排指向牌**，两个名字里字的顺序换一下，东西就换了。

这两个形状量出来差多少？本喵换了个本子，一次量全：

```c
#include <stdio.h>

int main(void) {
    char *row[4];
    char (*p)[16];
    char *many[16];
    char names[4][16];

    p = names;

    printf("一整排牌子有多大：%d\n", (int) sizeof(row));
    printf("其中一张牌有多大：%d\n", (int) sizeof(row[0]));
    printf("单张的那张牌有多大：%d\n", (int) sizeof(p));
    printf("它指着的那一整块有多大：%d\n", (int) sizeof(*p));
    printf("一排牌子里，牌子往前挪一格挪多远：%d\n", (int) ((char *) (row + 1) - (char *) row));
    printf("指着整排的那张牌，往前挪一格挪多远：%d\n", (int) ((char *) (p + 1) - (char *) p));
    printf("一排 16 张牌子有多大：%d\n", (int) sizeof(many));

    return 0;
}
```

```text
一整排牌子有多大：32
其中一张牌有多大：8
单张的那张牌有多大：8
它指着的那一整块有多大：16
一排牌子里，牌子往前挪一格挪多远：8
指着整排的那张牌，往前挪一格挪多远：16
一排 16 张牌子有多大：128
```

一句一句读：

- **32**：一整排牌子（四张 × 8 格）。
- **8** 和 **8**：一张牌子的大小 —— 两种写法**一样大**。牌子本身没区别，区别在它后头站着什么。
- **16**：`*p` 是「它指着的那一整块」，也就是一整排 16 格。
- **8** 和 **16** 这两行最值钱：`row + 1` 往前挪**一张牌**（8 格），`p + 1` 往前挪**一整排**（16 格）—— 同样是 `+ 1`，走的距离差一倍。
- **128**：`char *p[16]`（一排 16 张牌子）比 `char (*p)[16]`（一张牌子）大了十六倍。

一句话收进兜里：**牌子往前挪一步走多远，看它指着的是什么。**

## 三、坏掉的牌子（一）：从来没插过的那张

牌子刚要来的时候，牌面上是**空的** —— 不是「空牌子」，是**一个字都没写过**：上面留着的是上一只猫用完这一格没擦干净的东西。照着它走，走到的是一处谁都不认识的地方。

这种牌子长这样（本喵故意把它放进文字框里，不给它编的机会 —— 理由马上讲）：

```text
int *p;
*p = 5;
printf("%d\n", *p);
```

`int *p;` 只说明「p 是一张牌子」，**牌面上什么都没写**。翻译官喵看得出苗头，会念你一句：

```text
main.c:5:8: warning: 'p' is used uninitialized [-Wuninitialized]
```

（这是本喵真跑出来的原话。它前面还有一行 `main.c: In function 'main':`，这里只抄要紧的一句。）

**念归念，它不拦你** —— 程序照样编得出来、照样跑得起来。跑起来会怎么样？本喵连跑 **10 次**：10 次都**当场断气**（屏幕上一个字都没印，进程被系统按掉）。可本喵**不敢说它一定断气** —— 同一个写法换台机器、换一份排布，它可能只是印出一串莫名其妙的大数。这就是它最坏的地方：

- 它可能**什么都没发生**，于是你以为自己写对了；
- 它可能**踩坏别人的东西**，当场看不出来，过很久以另一副面孔炸出来；
- 它也可能**当场断气**，让你对着空屏幕发懵。

三种都叫坏牌子。规矩只有一条：**牌子要来之后，先写上门牌号，再照着它走。**

## 四、坏掉的牌子（二）：窝还回去了，牌子还留着

第二种坏牌子更阴：**牌子插得好好的，可它指着的那间窝已经不归你了。**

前面学过「现要现租的仓库」：用 `malloc` 现租一间，用完 `free` 还回去。可还回去的是**窝**，牌子不在还的范围内 —— 本喵写了个本子量这件事：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *p = (int *) malloc(sizeof(int) * 4);

    if (p == NULL) {
        printf("没租到喵\n");
        return 1;
    }

    p[0] = 10;
    printf("租来的时候，第 0 间装的是：%d\n", p[0]);

    free(p);
    printf("还回去之后，牌上还写着门牌号吗：%d\n", p != NULL);

    p = NULL;
    printf("把牌子擦成空牌子之后，还有门牌号吗：%d\n", p != NULL);

    return 0;
}
```

```text
租来的时候，第 0 间装的是：10
还回去之后，牌上还写着门牌号吗：1
把牌子擦成空牌子之后，还有门牌号吗：0
```

看中间那个 **1**：`free(p)` 之后，牌上**照样写着门牌号**。照着这个门牌号走过去，走到的是**一间已经还给管理员、随时可能租给别人的窝**。

麻烦的是「随时可能」真的只是可能。本喵真跑过这么一段（窝还了、牌子没擦，然后照着旧牌子写）：

```text
int *p = (int *) malloc(sizeof(int) * 4);
free(p);
p[0] = 7;
```

它到底会出什么事，取决于**新租到的那间是不是刚还回去的那间**。本喵另写了个本子量这件事：租一间、还回去、**再租一间**，看新租到的是不是刚还回去的那间。跑了两轮，**结果对不上**：头一轮**五次**里**三次**落在同一间，第二轮**十次**里只有**两次**落在同一间，另外**八次**租到的是别处（后来再跑十次，又变成**三次**落在同一间 —— 连这个比例本身都不固定）。同一台机器、同一个本子，**两轮都出现两种结果** —— 落在同一间的那几次，「照着旧牌子写一笔」看着一切正常；落在别处的那几次，那一笔就写到别人家里去了。**「有时对、有时错」的毛病，比每次都错难查得多。**

顺着旧牌子过去用一用它，翻译官喵其实会念一句（同样是真跑出来的原话）：

```text
main.c:7:10: warning: pointer 'p' used after 'free' [-Wuse-after-free]
```

可**念归念，它不拦你**：上面那三行本喵连跑 **10 次**，10 次都**安安静静跑完**（退出码 `0`）、屏幕上一个字都没有。写进一间已经还回去的窝里的那一笔，**没有任何人告诉你它出了事** —— 这才是「窝还回去了、牌子还留着」最麻烦的地方。

所以还窝之后，**顺手把牌子擦成空牌子**：`p = NULL;`（上面那个本子的最后两行就是）。这是本课的门牌号规矩里最省事的一条。

## 五、空牌子：最省事的一道防线

`NULL` 就是一张**空牌子**：牌面上明明白白写着「不指向任何地方」。一排牌子里有几格暂时没东西可指，就先插一张空牌子，用之前看一眼：

```c
#include <stdio.h>

int main(void) {
    char *row[4] = {"阿花", NULL, "小橘", NULL};

    for (int i = 0; i < 4; i++) {
        if (row[i] == NULL) {
            printf("第 %d 张是空牌子，本喵跳过\n", i);
            continue;
        }
        printf("第 %d 张牌 -> %s\n", i, row[i]);
    }

    return 0;
}
```

```text
第 0 张牌 -> 阿花
第 1 张是空牌子，本喵跳过
第 2 张牌 -> 小橘
第 3 张是空牌子，本喵跳过
```

走一圈，有东西的照名字印出来，空牌子那格走另一条路。

::: warn 空牌子不等于好牌子
照着**空牌子**走，一样会当场断气。本喵真跑过一个「不先看、直接照着走」的本子：连跑 **5 次**，5 次都是一样的结果 —— 走到空牌子那一步，进程当场被系统按掉。

可它和「没插过的那张」有一处根本差别：**空牌子是一张把「不能走」写在牌面上的牌子**。它的坏是**一定响**的坏；一定响的错，你十分钟就能查出来。而没插过的那张，坏得**有时响、有时不响** —— 那才缠人。

所以两件事都要做：**牌子要来先写门牌号；窝还回去就把牌子擦成 `NULL`。**
:::

## 六、整排牌子不能一起搬家

牌子挂多了，本喵动过一个偷懒的念头：既然 `row` 和 `other` 都是「一排四张牌子」，那能不能一句话把 `other` 那四张**整排搬**到 `row` 里？

**不能。** 翻译官喵当场把本喵拦下：

```c
#include <stdio.h>

int main(void) {
    char *row[4] = {"阿花", "大肥鱼", "小橘", "煤球"};
    char *other[4] = {"甲", "乙", "丙", "丁"};

    row = other;

    printf("%s\n", row[0]);
    return 0;
}
```

```text
main.c:7:9: error: assignment to expression with array type
```

它的意思是「一排东西不能整个换掉」。为什么？因为 `row` 在翻译官喵眼里压根**不是一格** —— 它是**整排的门牌号**，认的是那一排本身。整排要换内容，只能**一格一格来**：

```text
row[0] = other[0];
row[1] = other[1];
row[2] = other[2];
row[3] = other[3];
```

要么一开始就别摆两排，让牌子直接指过去。记住这个小脾气：**一整排换不掉，单张的牌子随时能换** —— 小任务里就有一道「换两张牌子」。

::: tip 猫咪提示
今天收五句话：

1. **一排牌子，一格一张**：`char *row[4]` 是一排四张牌子，每张写一个门牌号。它和「一排猫粮碗」（碗里装名字本身）不是一类东西 —— 同样四格，牌子整排 32 格、碗整排 64 格。
2. **读写法从名字出发、先右后左**：`char *row[4]` 是一排牌子，`char (*p)[16]` 是一张指着整排的牌子。少写一对括号，形状就换了（一排 16 张牌子 = 128 格）。
3. **牌子往前挪一步走多远，看它指着的是什么**：`row + 1` 走 8 格，`p + 1` 走 16 格。
4. **坏牌子有三个来路**：没插过的（牌面是垃圾）、窝还了牌子没擦的、以及不先看就照着空牌子走的。前两种**不保证当场报错**。
5. **两道防线**：牌子要来先写门牌号（暂时没得指就插空牌子 `NULL`）；窝还回去顺手 `p = NULL;` 擦干净。
:::

## 小任务

1. **先猜再跑。** 把第一节那个本子里的第一行 `sizeof(row)` 改成 `sizeof(row[0])`，别的都不动 —— 先拿纸笔猜它会印出 8 还是 32，再真跑一次对照。为什么这一改就从「一整排」变成了「一张」？
2. **加空牌子。** 把第五节那个本子的牌子改成六张：`"阿花", NULL, "小橘", NULL, NULL, "煤球"`（圈数也要跟着改），先猜屏幕上会多出哪几行，再跑一遍对照。
