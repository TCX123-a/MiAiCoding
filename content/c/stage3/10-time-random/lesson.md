## 钩子：本喵是怎么数时间的

本喵脖子上挂着一块小怀表，表盘上一个格子也没有、一根针也不装 —— 它里头只装着一个数：**从很久很久以前那个古老时刻起，一共过了多少秒**。这个「很久很久以前」不是随便挑的，是**1970 年开年那一刻**，全世界的怀表都从那一刻起数，所以谁跟谁的秒数都能直接比大小喵。

翻到这一课，本喵要干两件事：**把秒数换成猫猫看得懂的日子**（`time.h`），**再摇出一串不听话的数字**（`stdlib.h` 的骰子）。听起来都不难，但这两样各有一个能把人绕晕的坑，本喵一个一个拆给你看喵 ✨

## 两箱新招式：`time.h` 和 `stdlib.h`

| 招式 | 它干的活 | 一句话记住 |
|---|---|---|
| `time(NULL)` | 问一下怀表：过了多少秒 | 答一个秒数（`time_t` 牌子） |
| `gmtime(&秒数)` | 把秒数换成人看的日子 | 答一张写着年月日的牌子 |
| `srand(种子)` | 给骰子定一个起点 | **种子一样，摇出来的就一样** |
| `rand()` | 摇一次骰子 | 答一个 0 到 `RAND_MAX` 之间的数 |

先说 `gmtime` 叼回来的那张牌子。牌子上有好几个格：`tm_year` 是年份、`tm_mon` 是月份、`tm_mday` 是几号、`tm_yday` 是「一年里的第几天」——**这四个格里头有三个不讲道理**：年份要从 1900 起数、月份从 0 起数（0 是一月）、「第几天」也从 0 起数。所以往外拿的时候得自己加回去喵。

```c
#include <stdio.h>
#include <time.h>

int main(void) {
    time_t now = time(NULL);
    printf("现在是从那个古老时刻起，过了好多好多秒喵\n");
    printf("比 2026 年开年那一刻更晚吗？%s\n", now > 1767225600L ? "是" : "不是");

    time_t fixed = 1700000000L;          /* 挑一个固定的秒数，好让每次跑都一样 */
    struct tm *t = gmtime(&fixed);
    printf("那个数换成日子是：%d-%02d-%02d，一年里的第 %d 天\n",
           t->tm_year + 1900, t->tm_mon + 1, t->tm_mday, t->tm_yday + 1);
    return 0;
}
```

```text
现在是从那个古老时刻起，过了好多好多秒喵
比 2026 年开年那一刻更晚吗？是
那个数换成日子是：2023-11-14，一年里的第 318 天
```

三处要注意的喵：

1. **秒数可以直接比大小**。`now > 1767225600L` 里那个数就是「2026 年开年那一刻」的秒数 —— 谁大谁就更晚，不用换成日子再比。本喵的怀表跑得比它快，所以答「是」。
2. **年份要加 1900，月份要加 1**。`t->tm_year` 里装的是 `123`（意思是 2023 减掉 1900），`t->tm_mon` 里装的是 `10`（意思是十一月）。忘了加，就会印出「1900 年的日子」或者差一个月的日子。
3. **「一年里的第几天」是从 0 起数的**，所以往外拿的时候加了 1 —— 11 月 14 日是一年里的第 318 天。这三个「起数点」都不在同一个地方，是这一课最容易咬人的地方喵。

## 骰子：种子定乾坤

`stdlib.h` 里住着摇骰子的两招：`srand(种子)` 先给骰子定一个**起点**，`rand()` 才摇一次。规矩是死板的、也是救命的：**种子一样，摇出来的那一串就一模一样**。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    srand(7);
    for (int i = 0; i < 3; i++) {
        printf("%d\n", rand() % 100 + 1);
    }
    return 0;
}
```

```text
62
23
16
```

`rand() % 100 + 1` 就是「要 1 到 100 之间的整数」：先拿总数除 100 取**余数**（只会是 0 到 99），再加 1 把 0 赶走。本喵把种子给成 7，摇出来是 `62 23 16`；**换个种子就是另一串** —— 比如种子给成 3，本喵那支骰子就成了掷骰子的模样：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    srand(3);
    printf("掷 5 把骰子：");
    for (int i = 0; i < 5; i++) {
        printf("%d ", rand() % 6 + 1);
    }
    printf("\n");
    return 0;
}
```

```text
掷 5 把骰子：1 3 1 2 6
```

「要 1 到 6」还是同一个道理：`rand() % 6 + 1`。摇出来的 `1 3 1 2 6` 看着挺随性吧？可你把这支骰子搬回家跑一百遍，**每一遍都还是这一串** —— 这就是下一节要说的坑喵。

## 忘了给种子：每次都从头开始

种子要是压根不给，骰子不会「随便摇」，它会**默认从种子 1 起跑**。本喵真跑过这么一段，两行摆在一起给你看：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    printf("不给种子：");
    for (int i = 0; i < 3; i++) {
        printf("%d ", rand() % 100 + 1);
    }
    printf("\n");

    srand(1);
    printf("种子给 1：");
    for (int i = 0; i < 3; i++) {
        printf("%d ", rand() % 100 + 1);
    }
    printf("\n");
    return 0;
}
```

```text
不给种子：42 68 35
种子给 1：42 68 35
```

两行**一个数都不差**。所以「不给种子」不是「每次都随机」，而是「每次都从同一个起点重来」：程序跑一百遍，吐出来的永远是同一串。想让每一把都不一样，得给骰子塞一个**会变的起点** —— 准头就在本喵那块怀表上：`srand((unsigned)time(NULL));` 把「当下的秒数」当种子喵。

⚠️ 这一句要用上，**两箱招式都得请进门**：`srand` / `rand` 住 `stdlib.h`，`time` 住 `time.h`。本喵把 `time.h` 那行删掉试过，翻译官喵**当场就拦**（`error: implicit declaration of function 'time'`），还顺手提示该补哪一行。另外，种子只精确到**秒**：本喵在同一秒里连跑五遍，五遍的秘密**全是同一个数**；隔两秒再跑才换了一个。想让每把都不一样，得**隔开时间**跑喵。

## 猜数字：把骰子和比较凑起来

本喵最拿手的玩具就是把这几样凑一块儿：骰子先想一个 1 到 100 的秘密数，本喵一句一句往上猜，猜大了猜小了全看骰子的脾气。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    srand(5);
    int secret = rand() % 100 + 1;         /* 骰子想好的秘密 */
    int guesses[5] = {50, 75, 62, 56, 55}; /* 本喵猜的数，一个一个来 */
    int times = 0;

    for (int i = 0; i < 5; i++) {
        int g = guesses[i];
        times++;
        if (g < secret) {
            printf("猜 %d：小了\n", g);
        } else if (g > secret) {
            printf("猜 %d：大了\n", g);
        } else {
            printf("猜 %d：猜中啦，一共猜了 %d 次\n", g, times);
            return 0;
        }
    }
    printf("5 次都没猜中\n");
    return 0;
}
```

```text
猜 50：小了
猜 75：大了
猜 62：大了
猜 56：大了
猜 55：猜中啦，一共猜了 5 次
```

秘密是 55：头一句猜 50 小了，本喵就往上抬；75 大了就往回收；收着收着踩到 55，第 5 句猜中。这个「猜大就往小收、猜小就往大抬」的路数，跟前面「砍一半」是同一门功夫 —— 只是这里每一句都得靠骰子点头才行喵。

::: tip 猫咪提示
今天记住三件事：**秒数是「从 1970 年开年那一刻起过了多少秒」**，比早晚直接比秒数就行；**把秒数换成人看的日子时，年份加 1900、月份加 1、「第几天」加 1**，这三个起数点都不一样；**骰子的规矩是「种子一样，摇出来的就一样」** —— 种子能重复，反倒让本喵的好玩意儿每次跑都能复现。
:::

::: warn 小心喵
两个坑：① 忘了给种子（或者种子写死成一个常数），骰子每次都给你**同一串**，看着像随机其实一点都不随机 —— 本喵真跑过，不给种子和种子给 1 印出来一模一样；② 拿 `rand()` 直接当范围用（不问一声就当成 1 到 100），摇出来的数可能比你想的大得多 —— 想要什么范围，自己去取余数再加，`% 100 + 1` 这样写清楚。
:::

## 小任务

把「猜数字」那一段末尾的 `printf("5 次都没猜中\n");` 改一改：别让骰子想好了，改成**让本喵自己从门外喂进来**（提示：用 `scanf` 收一个数当秘密，或者干脆把种子换成 `(unsigned)time(NULL)` —— 记得先补上 `#include <time.h>` 和 `#include <stdlib.h>`，**隔一两秒再跑一遍**，看每次的秘密是不是都不一样）；跑上三遍，把三次的答案摆在一起，看看哪一遍最像真的随机喵。🐾

多留一句：**同一秒里连敲两遍，你会看到一模一样的秘密** —— 那不是它坏了，是种子只精确到秒。本喵真跑过，同一秒五遍全是同一个数，隔两秒才换。这也正是「种子决定一切」的另一副面孔：**「看起来在变」和「真的在变」是两件事**喵。
