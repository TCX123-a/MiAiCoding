## 钩子：一串串珠子

本喵脖子上这条项链，是一颗一颗珠子穿起来的 —— 每颗珠子上刻着一个字母，一颗挨着一颗，最后还挂着一颗**特别的收尾珠子**，刻着「到此为止」。这一串东西，术语表里管它叫**字符串（一串小鱼干的项链）**喵。

它和前面几课那些「一排碗」最大的不同是：碗是**按编号**数的，想知道第 5 只碗里装着什么，报个 5 就行；而这串珠子是一颗颗挨着挂的，想说「第 5 颗」，得从头上那颗开始**一颗一颗数过去**。整串多长、两串一不一样、里头有没有一小段对得上 —— 这些活儿全得顺着珠子走，所以本喵收集了一箱子专门的**招式**来伺候它。今天先把箱子打开，再讲讲「在一串里找另一小段」这件活得怎么干喵 ✨

## 箱子里的常用招式

先说清楚一件事：这些招式住在**借书条 `string.h`** 里，用它之前得先把这张条子交上去（`#include <string.h>`），不然翻译官喵不认识这几个名字喵。

| 招式 | 它干的活 | 一句话记住 |
|---|---|---|
| `strlen(s)` | 数这串有**几颗珠子** | 数到收尾那颗之前为止 |
| `strcpy(dst, src)` | 把 `src` 那一串**抄**到 `dst` 里去 | 抄整串，连收尾珠子一起抄 |
| `strcat(dst, src)` | 把 `src` 那一串**接在** `dst` 屁股后面 | 接完 `dst` 变长了 |
| `strcmp(a, b)` | 两串比一比 | **答 0 才是「一样」** |
| `strchr(s, c)` | 在这一串里找**一颗**珠子 | 找着就把它的位子（牌子）叼回来 |
| `strstr(s, sub)` | 在这一串里找**一小段** | 找着就把它开头那颗的位子叼回来 |

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char bowl[32] = "fish";
    char tail[] = "cake";

    printf("碗里这串有 %d 颗珠子\n", (int)strlen(bowl));
    strcat(bowl, tail);                  /* 把 tail 接在 bowl 屁股后面 */
    printf("接起来：%s，现在 %d 颗\n", bowl, (int)strlen(bowl));
    printf("这两串一样吗？%s\n", strcmp(bowl, "fishcake") == 0 ? "一样" : "不一样");
    printf("找珠子 'c'：%s\n", strchr(bowl, 'c') == NULL ? "没找着" : "找着了");
    printf("找一小段 'shk'：%s\n", strstr(bowl, "shk") == NULL ? "没找着" : "找着了");
    return 0;
}
```

```text
碗里这串有 4 颗珠子
接起来：fishcake，现在 8 颗
这两串一样吗？一样
找珠子 'c'：找着了
找一小段 'shk'：没找着
```

三处最容易咬人的地方，本喵一次说清喵：

1. **`strlen` 数的是「几颗珠子」，不是「碗有多大」**。例子里的碗是 `char bowl[32]`，能装 32 颗，可 `strlen` 答的 4 是**实际装着**的颗数。碗大小和串长是两件事，别混。
2. **比两串一定要用 `strcmp`，而且答 0 才算一样**。因为它是「比大小」的招式：前面那串排在后面那串**前面**就答负数、后面就答正数、**一模一样才答 0**。所以判断「一样」写的是 `strcmp(a, b) == 0`。要是拿 `==` 去比两串，比的不是珠子内容，而是两个牌子的地址 —— 十有八九答「不一样」。**可它偶尔会碰巧答「一样」**（两处字号一样、内容也一样的字面量，翻译官喵可能只留一份，两个牌子就指到同一块地方了）——**这个「偶尔」才是最坏的**，它让你以为这么写能行，换一处调用就翻车。
3. **`strcat` 会改掉 `dst`，而且它得装得下**。`bowl` 原来装着 4 颗，接上 4 颗变成 8 颗，碗里得留够地方。碗不够大，多出来的珠子会跑到不属于你的地方去 —— 这一处翻译官喵**会念一句**（`-Wstringop-overflow=`，意思是「这一写要比碗宽了」），可**它只念不拦**：程序照样编得过，跑起来更没保证 —— 本喵真跑过，当场就摔了，一个字都没印出来。

## 在一串里找另一小段：最直白的办法

`strstr` 这一招省事，但它是怎么干活的？本喵拆给你看 —— **从一个起点开始，一颗一颗对**：对上了就一起往后挪一颗，对不上就**整体挪一个起点、从头再来**。

```c
#include <stdio.h>
#include <string.h>

/* 朴素对法：每个起点都从头对一遍，答「比了几次」 */
int naive(const char *text, const char *pat) {
    int n = (int)strlen(text);
    int m = (int)strlen(pat);
    int tries = 0;

    for (int i = 0; i + m <= n; i++) {
        int j = 0;
        while (j < m) {
            tries++;
            if (text[i + j] != pat[j]) {
                break;                 /* 对不上，这个起点作废 */
            }
            j++;
        }
        if (j == m) {
            return tries;              /* 整段都对上了 */
        }
    }
    return -tries;                     /* 所有起点都试过了，没有 */
}

int main(void) {
    int a = naive("aaaaaab", "aaab");
    printf("朴素对法比了 %d 次\n", a < 0 ? -a : a);
    return 0;
}
```

```text
朴素对法比了 16 次
```

16 次是怎么来的？挨个起点试一遍：第 0 个起点上对到第 4 颗才崩、第 1 个起点又对到第 4 颗才崩…… 前面那串里全是一样的 `a`，每一个起点都要**白白重对好几颗**才肯认输。这就是它的毛病：**刚对上的那一段，下次一点都不记得，每次都从头来**喵。

## 小本本：把「已经对上的那一段」记下来

前辈猫想了个办法：**准备一个小本本**，记下「已经对上的这一段里头，**头上那几颗和尾巴那几颗能对上**」，这样下次崩了就不用回到起点。

拿 `aaab` 这一小段举例喵。规矩是：**每一颗都回头看自己这一截，头上那几颗和尾巴那几颗能对上、最长能对上几颗**（整截自己不算，得留出至少一颗）：

- 第 0 颗是 `a`：就一颗，头上和尾巴是同一颗，不算 → 记 `0`；
- 第 1 颗是 `a`，连起来是 `aa`：头上那颗 `a` 和尾巴那颗 `a` 对得上 → 记 `1`；
- 第 2 颗是 `a`，连起来是 `aaa`：头上两颗 `aa` 和尾巴两颗 `aa` 对得上（三颗就是整截自己，不算）→ 记 `2`；
- 第 3 颗是 `b`，连起来是 `aaab`：尾巴上那颗是 `b`、头上那颗是 `a`，一颗都对不上 → 记 `0`。

小本本上就是这么一串数：`0 1 2 0`。它的意思很直白：**「走到第几颗崩了，就往回退到小本本上那个长度」**。本喵们不是丢掉已经对上的部分，而是**把其中确实能用的那一截留下来接着用**。

```c
#include <stdio.h>
#include <string.h>

/* 小本本：记下「已经对上的这一段」里，头上能对上的最长一段有多长 */
void build_book(const char *pat, int *book) {
    int m = (int)strlen(pat);
    book[0] = 0;
    for (int i = 1; i < m; i++) {
        int k = book[i - 1];
        while (k > 0 && pat[i] != pat[k]) {
            k = book[k - 1];          /* 这个长度也不行，退回更短的那个 */
        }
        if (pat[i] == pat[k]) {
            k++;
        }
        book[i] = k;
    }
}

/* 带着小本本对：崩了不回起点，退到小本本上记的那个长度接着对 */
int kmp(const char *text, const char *pat) {
    int n = (int)strlen(text);
    int m = (int)strlen(pat);
    int book[64];
    build_book(pat, book);

    int tries = 0;
    int k = 0;                        /* 已经对上了几颗 */
    for (int i = 0; i < n; i++) {
        while (k > 0 && text[i] != pat[k]) {
            k = book[k - 1];          /* 崩了：退到小本本记的那个长度 */
        }
        tries++;
        if (text[i] == pat[k]) {
            k++;
        }
        if (k == m) {
            return tries;             /* 整段都对上了 */
        }
    }
    return -tries;
}

int main(void) {
    const char *text = "aaaaaab";
    const char *pat = "aaab";

    int book[64];
    build_book(pat, book);
    printf("小本本：");
    for (int i = 0; i < (int)strlen(pat); i++) {
        printf("%d ", book[i]);
    }
    printf("\n");

    int b = kmp(text, pat);
    printf("小本本只比了 %d 次\n", b < 0 ? -b : b);
    return 0;
}
```

```text
小本本：0 1 2 0
小本本只比了 7 次
```

同样这一对（`aaaaaab` 里找 `aaab`），上面那招答 **16 次**，带着小本本只要 **7 次**。省下来的就是那些**白对**的珠子：崩在第 4 颗的时候，本喵已经知道前面三颗都是 `a`，而小段头上也是 `a` —— 那就退到「已经对上 2 颗」的位置接着比，不用回到起点重来喵。

::: tip 猫咪提示
今天记住三件事：**珠串是一颗颗挨着数的**（`strlen` 数颗数、`strcpy` 抄整串、`strcat` 接屁股、`strcmp` 答 0 才算一样）；**最直白的找法是「一个起点一个起点地试」**，崩了就整体挪一格、从头再来；**小本本记的是「已经对上的那一段里，头上那几颗和尾巴那几颗能对上」**，有了它，崩了不用回起点。
:::

::: warn 小心喵
两个坑：① 用 `==` 去比两串，比的是牌子的地址，几乎永远答「不一样」—— 要它答「一样」，得写 `strcmp(a, b) == 0`；② `strcat` 把珠子接到 `dst` 后面之前，先数清楚 `dst` 里还剩多少地方 —— 本喵真拿一个只装得下 4 颗的碗去接 5 颗试过：翻译官喵编译时**只念一句警告**（`-Wstringop-overflow=`），**不报错、也不拦**，可跑起来当场就摔了，屏幕上**连一个字都没有**，只有退出码知道它出了事。这两个坑都不会给你一句「你写错了」：一个悄悄给你错结果，一个悄悄摔掉喵。
:::
