## 钩子：猫窝里天天发生的两件事

猫窝里有两件事天天都在发生喵。

第一件：**洗好的碗摞起来**。本喵把猫粮碗一只只往上摞，要拿碗的时候只能从**最上面**那只开始拿 —— 最后摞上去的，最先被拿走。

第二件：**开饭排队**。猫猫们排成一条队伍领小鱼干 —— 最先来的先领到，后来的老老实实排在后面。最先来的，最先被伺候。

同样是「一排东西」，规矩却正好相反。这两位就是今天的主角：**一摞叠起来的猫粮碗（堆栈）** 和 **排队领小鱼干（队列）**。上一课我们串过一条用猫爪指向牌连起来的链子，今天这两样更简单 —— 它们只要**一排现成的碗**当底座就够喵 ✨

## 一、一摞碗：最后进来的最先出去

关键词是「**最后进去的最先出来**」。本喵用一排贴了编号的猫粮碗当底座（地方一开始就摆好，本喵只记「用到哪儿了」），再配两招：放一只碗上去、从最上面拿走一只。

```c
#include <stdio.h>

#define MAX_BOWLS 5

int bowls[MAX_BOWLS];   /* 一排 5 只碗当底座 */
int top = 0;            /* 已经摞了几只碗 */

int is_empty(void) { return top == 0; }
int is_full(void) { return top == MAX_BOWLS; }

int push(int value) {
    if (is_full()) {
        return 0;
    }
    bowls[top] = value;
    top++;
    return 1;
}

int pop(int *value) {
    if (is_empty()) {
        return 0;
    }
    top--;
    *value = bowls[top];
    return 1;
}

int main(void) {
    push(1);
    push(2);
    push(3);
    int v = 0;
    while (pop(&v)) {
        printf("取到 %d\n", v);
    }
    printf("空了吗？%s\n", is_empty() ? "空了" : "还有");
    return 0;
}
```

```text
取到 3
取到 2
取到 1
空了吗？空了
```

放进去的顺序是 1、2、3，拿出来的顺序却是 3、2、1 —— 这就是「最后进去的最先出来」喵。诀窍全在那个 `top`：它既是「已经摞了几只」，也正好是「下一只碗该放在哪儿」。

- 放一只碗：`bowls[top] = value;` 放好之后 `top++`，碗摞长高一层。
- 拿一只碗：先 `top--` 退到「最上面那只」的位置，再把它叼出来（`*value = bowls[top];`）。

注意 `push` 和 `pop` 都**先问边界**：满了（`top == MAX_BOWLS`）就放不下，空了（`top == 0`）就拿不出。这两句话看着啰嗦，可省掉它们的代价是「碗摞塌了」：继续往满碗摞上放，会踩到不属于自己的地方；从空碗摞上拿，会读到一堆莫名其妙的数字喵。

放进去的是 1、2、3，拿出来的却是 3、2、1 —— 这件事光看输出想不明白。下面把 `top` 和碗摞**每一步都摆出来**，盯着 `top` 那一栏：它既是「已经摞了几只」，也正好是「下一只碗该放在哪儿」喵。

## 二、一条队伍：最先来的最先出去

队伍的关键词正好相反：「**最先进去的最先出来**」。这次要记**两个**位置：队头在哪儿（谁先来的）、下一个空位在哪儿（新来的站哪儿）。

```c
#include <stdio.h>

#define MAX_CATS 5

int line[MAX_CATS];
int head = 0;   /* 队头在哪儿 */
int tail = 0;   /* 下一个空位在哪儿 */

int is_empty(void) { return head == tail; }
int is_full(void) { return tail == MAX_CATS; }

int enqueue(int value) {
    if (is_full()) {
        return 0;
    }
    line[tail] = value;
    tail++;
    return 1;
}

int dequeue(int *value) {
    if (is_empty()) {
        return 0;
    }
    *value = line[head];
    head++;
    return 1;
}

int main(void) {
    enqueue(10);
    enqueue(20);
    enqueue(30);
    int v = 0;
    while (dequeue(&v)) {
        printf("领到 %d\n", v);
    }
    printf("队空了吗？%s，可 head 已经走到 %d\n", is_empty() ? "空了" : "还有", head);
    return 0;
}
```

```text
领到 10
领到 20
领到 30
队空了吗？空了，可 head 已经走到 3
```

进队的顺序是 10、20、30，出来的顺序也是 10、20、30 —— 先来的先领到喵。这里两个下标各有分工：

- `tail` 负责**接客**：新来的站在 `line[tail]`，站好之后 `tail++`，指向下一个空位。
- `head` 负责**送客**：队头那位先领走（`*value = line[head];`），然后 `head++`，指向队伍里新的第一位。

怎么知道队伍空了？`head == tail` —— 接客的和送客的走到同一个地方，说明中间的猫都领完了喵。

::: warn 小心喵
队伍这个写法有个小毛病，值得你现在就看到：**`head` 只会往前走，前面空出来的格子再也回不来。** 上面那个程序跑完之后，三只猫都领完了，`head` 已经走到 3，可前三个格子明明空着 —— 要是再排两只猫进来，`tail` 就到 5 了，新来的猫会被判「满了」，而它面前还空着三格呢。这个现象叫「假满」—— 本喵先透一句：把这一排碗在脑子里接成一个圈（走到头就绕回 0），这个坑就填上了，有兴趣可以自己先试试喵。
:::

::: tip 猫咪提示
两样法宝的规矩，一句话就能分清喵：**一摞碗**只记一个 `top`，**最后放上去的最先被拿走**；**一条队伍**记 `head` 和 `tail` 两个下标，**最先来的最先被伺候**。两样都靠一排现成的碗当底座，动手之前都必须先问一句「空了吗 / 满了吗」—— 边界没问清，越界就在门口等着你喵。
:::

## 小任务
