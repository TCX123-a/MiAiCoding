## 钩子：一摊乱糟糟的小鱼干

本喵的鱼塘边摊着一堆小鱼干，长短不一。大肥鱼要本喵把它们**从最短到最长**排排坐，一条一条摆整齐。本喵数了数：六只。一只一只挑着看，倒也不难 —— 可要是有一百只呢？

今天本喵教你三个前辈猫传下来的老办法，都能把一摊乱的排整齐。它们仨的目标一模一样，**干活的方式**完全不同 —— 这也是为什么本喵要一次讲三个：看懂它们干活的差别，你以后拿到一摊东西，就知道该喊哪一招喵 ✨

这三种排法在术语表里合起来叫**给小鱼干排排坐（排序）**。下面本喵一个一个说。

## 冒泡法：两两比一比，慢慢浮上去

第一招最憨，也最好懂：**从头到尾，挨着的两只比一比**——左边那只比右边长，就换个个儿。这样走完一趟，最长的那只一定被一路换到了最末尾。

```c
#include <stdio.h>

/* 冒泡：挨着的两只比一比，左边比右边长的就换个个儿 */
void bubble_sort(int fish[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (fish[j] > fish[j + 1]) {
                int t = fish[j];
                fish[j] = fish[j + 1];
                fish[j + 1] = t;
            }
        }
    }
}

int main(void) {
    int fish[6] = {5, 2, 9, 1, 8, 6};
    bubble_sort(fish, 6);
    printf("排排坐：");
    for (int i = 0; i < 6; i++) {
        printf("%d ", fish[i]);
    }
    printf("\n");
    return 0;
}
```

```text
排排坐：1 2 5 6 8 9
```

三句要念清楚喵：

1. **外层那一圈管「走几趟」**：一趟只能把一只送到它该在的位子上，所以最多走 `n - 1` 趟。
2. **内层那一圈管「这一趟里比到哪儿」**：写的是 `j < n - 1 - i`，那个 `- i` 是因为**末尾的 `i` 只已经站好了**，不用再比。
3. **换位子要用一只手**：`int t = fish[j];` 先把这只捧在手上，再挪、再放回去。少了这只手，两只都会变成同一个值。

下面把**第一趟**完整走一遍喵。这一趟最值得看的是第 4~6 步：换一次位子为什么要写成三行。盯着 `这排鱼干` 那一栏，它每一步都是当前真实的摊位。

::: warn 第 5 步那半秒的「两只都是 2」不是笔误
`fish[j] = fish[j + 1];` 执行完的那一瞬间，摊位上是 `2 2 9 1 8 6` ——
**原来的 5 只活在爪子上**。要是把三行写成
`fish[j] = fish[j+1]; fish[j+1] = fish[j];`（忘了先捧住），
第二句读到的 `fish[j]` 已经是挪过来的 2 了，两只就都变成 2，5 凭空消失。
这个错**不报错、不崩**，只是排出来的结果少了一个数 —— 所以「先捧住」这三个字永远手写喵。
:::

## 这一招要跑多少圈？

数一数就知道它有多累。六只鱼干，第一趟比 5 次、第二趟比 4 次……加起来是 15 次：

```c
#include <stdio.h>

int main(void) {
    int n = 6;
    int times = 0;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            times++;
        }
    }
    printf("6 只鱼干，两两比一比要 %d 次\n", times);
    return 0;
}
```

```text
6 只鱼干，两两比一比要 15 次
```

15 就是 6 乘 5 再除以 2。记住这个形状：**鱼干变成 n 只，比一比的次数大约就是 n 乘 n 再除以 2** —— 鱼干翻一倍，次数翻**四倍**。十只鱼干比 45 次，一百只鱼干就要比 4950 次，一千只鱼干是 499500 次。这就是为什么鱼干一多，憨办法就吃不消了：本喵的爪子再快，也架不住次数这么涨喵。

## 挑最短法：每一轮先选出最短的一只

第二招改了个思路：**不再两两换着走，而是每一轮先扫一遍，找出剩下这些里最短的那只**，然后请它和最前面那只换个位子。一轮只换一次，但一轮能定下一只。

```c
#include <stdio.h>

/* 每一轮先挑出最短的一只，和最前面那只换个位子 */
void selection_sort(int fish[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int shortest = i;                 /* 先假定最前面那只最短 */
        for (int j = i + 1; j < n; j++) {
            if (fish[j] < fish[shortest]) {
                shortest = j;             /* 遇到更短的，记下它的位子 */
            }
        }
        if (shortest != i) {
            int t = fish[i];
            fish[i] = fish[shortest];
            fish[shortest] = t;
        }
    }
}

int main(void) {
    int fish[5] = {7, 3, 9, 1, 4};
    selection_sort(fish, 5);
    printf("挑最短：");
    for (int i = 0; i < 5; i++) {
        printf("%d ", fish[i]);
    }
    printf("\n");
    return 0;
}
```

```text
挑最短：1 3 4 7 9
```

它和冒泡最大的差别在**换位子的次数**：挑最短法一轮只换一次（或者一次都不换），冒泡一趟可能换好几次。要是「换一次」很贵（比如鱼干特别大，搬起来费劲），挑最短法就划算喵。

## 理牌法：摸一张，插进已经理好的一小段

第三招最像本喵理牌：手里已经理好一小叠，新摸起一张，就**从后往前比**，比它长的都往后挪一格，腾出来的位子就是它的。第一张牌不用理（一张牌本来就整齐），所以从第二张开始。

```c
#include <stdio.h>

/* 摸起一张往前比，比它长的都往后挪一格，腾出的位子就是它的 */
void insertion_sort(int fish[], int n) {
    for (int i = 1; i < n; i++) {
        int hold = fish[i];               /* 摸起来捧在手上 */
        int j = i - 1;
        while (j >= 0 && fish[j] > hold) {
            fish[j + 1] = fish[j];        /* 比它长的往后挪一格 */
            j--;
        }
        fish[j + 1] = hold;               /* 腾出来的位子，放下 */
    }
}

int main(void) {
    int fish[5] = {6, 1, 8, 2, 5};
    insertion_sort(fish, 5);
    printf("理牌式：");
    for (int i = 0; i < 5; i++) {
        printf("%d ", fish[i]);
    }
    printf("\n");
    return 0;
}
```

```text
理牌式：1 2 5 6 8
```

⚠️ 那个 `j >= 0` 是**收手条件**：一路比到最前面（`j` 退到 -1）就得停，不然爪子会伸到摊子外面去。它的前半句 `fish[j] > hold` 是「还没找到该停的位子」，两半缺一不可喵。

## 什么时候用哪一招

三招的「比一比的次数」其实**差不多**，都是 n 乘 n 那个形状。真正让它们分高下的是别的东西：

| 办法 | 最擅长的事 | 什么时候喊它 |
|---|---|---|
| 冒泡 | 一眼看懂、代码最短 | 鱼干很少，或者本喵只是想给你讲清楚「排排坐是怎么回事」 |
| 挑最短 | 换位子的次数特别少 | 搬一只鱼干很贵、比一比很便宜的时候 |
| 理牌 | **摊子本来就差不多整齐**的时候 | 只添了一两只新的，前面那一叠早就理好了 |

理牌法最后那一格值得多念两遍：如果一摊鱼干**本来就挺整齐**，它真的快得惊人 —— 本喵量过，六只已经排好的鱼干，理牌只比了 `5` 次，另两招都得比 `15` 次。

可要是**完全倒着摆**（最长的那只在最前面），名次就跟直觉不一样了喵 —— 同样六只，本喵量出来是：挨着比、慢慢挪的那招**挪了 `15` 次**；挑最短只挪 `3` 次；理牌**也要挪 `15` 次**（三招「比一比」的次数都是 `15`，一样多）。**所以「理牌最慢」这话是错的**：倒着摆的时候，费爪子的是**挪得多**的那两招，省爪子的是挑最短。所以「哪一招好」这个问题，得先看**你的鱼干长什么样**喵。

::: tip 猫咪提示
今天记住三句话：**冒泡**是「挨着比、慢慢挪」；**挑最短**是「每轮选冠军、只换一次」；**理牌**是「摸一张、往前插」。三招的目标都是「从短到长」，比一比的次数都是 n 乘 n 那个形状 —— 差别在它们怎么动爪子喵。
:::

::: warn 小心喵
两个坑，本喵盯着屏幕见过好几次：① 内层那一圈写到 `j < n` 就**伸到摊子外面**去了：`fish[j + 1]` 在 `j` 是最后一只时会碰到不属于你的地方，读出来是个莫名其妙的数；② 换位子的那三句**顺序写反**，比如先 `fish[j] = fish[j + 1];` 再想救回原来的值 —— 一执行完，原来的值就没了，两只变成同一只。要换位子，先捧在手上喵。
:::

## 小任务

把冒泡法改一改：如果**这一趟一次都没换过**，说明摊子已经整整齐齐了，那就别再白跑剩下的趟数，直接收工（提示：多加一个数记「这趟换过没有」，外层每趟开头把它清零）。拿一摊本来就排好的鱼干试试，看看它是不是只跑了一趟就停手了。🐾
