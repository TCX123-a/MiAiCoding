## 钩子：跑得对，可它「读得下去」吗

代码越写越多，本喵回头翻自己半个月前写的稿子，居然看不懂 —— 不是跑不通，是**读不懂**：`a`、`x1`、`tmp2` 一堆，缩进忽深忽浅，一行里塞着三件事。三天后的本喵看着它，只想挠桌子。

更吓人的是另一类：稿子在**递对东西**的时候漂漂亮亮，一递错就出洋相 —— 空的一排碗、只有一只碗、全是欠账…… 这些「边上」的情形，主人总会撞上。

这一课就干两件事喵：**让稿子读得下去**（起名、格式、注释）、**让稿子扛得住**（防御检查、边界条件）。

## 起名与格式：让别人一眼看懂

```c
#include <stdio.h>

int main(void) {
    int fish[3] = {2, 3, 4};
    int total = 0;
    int biggest = fish[0];
    for (int i = 0; i < 3; i++) {
        total += fish[i];
        if (fish[i] > biggest) {
            biggest = fish[i];
        }
    }
    printf("一共 %d 条，最多的一碗 %d 条\n", total, biggest);
    return 0;
}
```

```text
一共 9 条，最多的一碗 4 条
```

这段没什么花招，可它**读得下去**喵。起名三条口诀：

1. **名字要说清里头装的是什么**：`total` 是「合计」、`fish` 是「那一排碗」、`i` 是「这一圈的编号」。写成 `a`、`b`、`x1` 省不了几个字，三天后连你自己都不认识。
2. **一个名字只担一件事**：`total` 就一直当合计用，别一会儿又拿它去装别的数 —— 那是最容易出「看着对、其实错」的地方。
3. **别起只差一两个字母的名字**：`total` 和 `totals`、`fish` 和 `fisn`，读起来像双胞胎，认错只是迟早。

格式是同一件事的另一面：缩进**一个样**、一行**只干一件事**、该空行的地方空一行。翻译官喵不看格式脸色，可**读的人**会 —— 格式乱的地方，虫最爱躲。

## 防御检查：进门先验货

先看这一段**没验货**的稿子：

```c
#include <stdio.h>

int biggest(int fish[], int count) {
    int best = fish[0];
    for (int i = 1; i < count; i++) {
        if (fish[i] > best) {
            best = fish[i];
        }
    }
    return best;
}

int main(void) {
    int fish[3] = {7, 2, 5};
    printf("三碗：%d\n", biggest(fish, 3));
    printf("一碗都没有：%d\n", biggest(fish, 0));
    return 0;
}
```

```text
三碗：7
一碗都没有：7
```

看第二行喵：「一碗都没有」的时候，它印的是 `7` —— 那是**第一碗里的数**（这一格确实存在，上面刚放进去 `7`），可**这一排按说压根是空的**哇！问题不在「读坏了地方」：招式开头写的是 `int m = fish[0];`，**它压根没问 `count` 是几**，张嘴就掏第一格。所以这不是内存脏了，是**招式自己没把规矩讲清楚**：「一只都没有的时候，答案该是什么？」它没答，就顺手把第一格端出来了。

（这种错比印错更吓人：它不报错、不崩，**换台机器也照样印 `7`** —— 稳定地给你一个没人规定过的答案。规矩得自己立：进门先验货喵。）

改法就是**进门先验货**：

```c
#include <stdio.h>

int biggest(int fish[], int count) {
    if (count <= 0) {
        return -1;
    }
    int best = fish[0];
    for (int i = 1; i < count; i++) {
        if (fish[i] > best) {
            best = fish[i];
        }
    }
    return best;
}

int main(void) {
    int fish[3] = {-2, -3, -4};
    printf("三碗全是负数：%d\n", biggest(fish, 3));
    printf("只有一碗：%d\n", biggest(fish, 1));
    printf("一碗都没有：%d\n", biggest(fish, 0));
    return 0;
}
```

```text
三碗全是负数：-2
只有一碗：-2
一碗都没有：-1
```

门口那三行是**守卫**喵：`count <= 0` 的时候，压根不往后走。`-1` 是本喵跟喊它的人约好的暗号 —— **条数不可能是负数**，所以看见 `-1` 就是「这活儿干不了」。有了守卫，空的一排碗也印得出话，而且印的是**约好的那句话**。

守卫就摆在招式**刚进门的地方**，一眼能看见。摆在中间、藏在跑圈里，读的人不知道你到底验没验。

## 边界条件：空、一只、还有「全是最边上的值」

「边界」就是**最边上那几种情形**喵：一排碗是空的（`0` 只）、只有一只、全是最边上的数（比如全是欠账）。这些情形平时不出现，写稿子的人最容易想不到 —— 一出现就出洋相。

本喵的必查清单：

- **一个都没有**：空的时候该印什么、该叼什么回去？（先验货，再干活）
- **只有一只**：跑圈从第二碗起（`i = 1`）的写法，遇上一只碗会不会一圈都不跑、把结果漏了？
- **全是最边上的值**：这条最阴。求「最多的一碗」时，本喵一开始把王座上的**初始值写成了 `0`**：

```c
#include <stdio.h>

int main(void) {
    int fish[3] = {-2, -3, -4};
    int best = 0;
    for (int i = 0; i < 3; i++) {
        if (fish[i] > best) {
            best = fish[i];
        }
    }
    printf("最多的一碗：%d\n", best);
    return 0;
}
```

```text
最多的一碗：0
```

这一排里压根**没有 `0`** 这位客人，它却坐了整场喵。改法是：初始值就取这一排里**真实存在的第一碗**（上面守卫版里那句 `int best = fish[0];` 就是这一手），再从第二碗开始比。记住这句：**初始值要从真实存在的数里挑**，别凭空写一个「觉得差不多」的。

## 可读性：出了问题要「说得出话」

```c
#include <stdio.h>

int average(int total, int count) {
    if (count <= 0) {
        return -1;
    }
    return total / count;
}

int main(void) {
    int total = 9;
    int avg = average(total, 3);
    printf("平均一碗 %d 条\n", avg);
    avg = average(total, 0);
    if (avg < 0) {
        printf("这组数不对，本喵算不出来喵\n");
    }
    return 0;
}
```

```text
平均一碗 3 条
这组数不对，本喵算不出来喵
```

注意分工喵：

- **招式**：干不了就叼暗号回去（`-1`），别自作主张印一堆东西 —— 万一喊它的人正指望着印在别处呢；
- **门口**：看见暗号，负责**跟主人说一句话**。上面那句「这组数不对，本喵算不出来喵」是 `main` 说的。

注释也照这个分工写：写**为什么**这么办（「条数不可能是负数，所以拿 `-1` 当暗号」），别写「这是一行加法」—— 那行代码自己会说。

还有一条容易忘的：**临时的打印**、试完不用的旧写法，交稿之前收走。它们不吭声，可下一个读稿子的猫会被绊一跤。

::: tip 猫咪提示
交稿之前，本喵会挨着问自己这四句喵：

1. **名字**能不能让三天后的自己看懂？（`total`、`fish`、`i` 这种，比 `a`、`x1` 省下的时间多得多）
2. 进门**验货**了吗？（投喂不合法、仓库租不到、一排碗是空的 —— 不合格就别往下走）
3. **边上**的情形试过了吗？（`0` 只、`1` 只、全是负数、比预想的多一只）
4. 出了岔子，**谁负责说话**？（招式叼暗号、门口跟主人交代）

四条全过，这份稿子就不只是「跑得对」，而是**别人也敢动**喵。
:::

## 小任务

1. 把课文里那段「没验货」的稿子敲进去跑一遍，亲眼看看空的一排碗印出了什么；再加上守卫，看它变成 `-1`；
2. 给守卫版加一句门口的报信（跟 `average` 那段一样的分工），让空碗的时候主人也知道出了什么事；
3. 把「全是欠账」那段改对，要求它对 `0` 只、`1` 只、全负三种情形都印得出话；
4. 回头翻一节你自己写过的稿子，只做两件事：把 `a`、`b`、`x1` 换成说得清的名字，把缩进摆齐 —— 别的都不动，看看读起来差多少喵。
