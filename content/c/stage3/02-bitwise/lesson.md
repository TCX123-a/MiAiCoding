## 钩子：猫窝墙上那排小开关

本喵的猫窝墙上装了一排小开关，每个只有两档：**灭**（0）和**亮**（1）。要开哪盏灯，就把对应的开关拨上去；要看哪盏灯亮着，就挨个瞄一眼。

你多半没想到：C 里的整数，在机器里就是这么一排开关喵。平时你写 `6`，翻译官喵把它记成 `00000110`（本喵只画最低的 8 位）—— 从右往左数，第 2 位和第 1 位亮着，加起来正好是 4 + 2 = 6。**整数只是这排开关的读数，开关本身才是它的样子。**

而位运算干的事，是**跳过「这个数是多少」，直接去拨那一排开关**。这是最底层、也最省力的一层功夫，今天本喵教你五种拨法喵 ✨

## 五种拨法

- `&`（按位与）：两边**都亮**的那一位才亮。像「两个都点头才算数」。
- `|`（按位或）：任意一边亮就亮。像「有一个点头就行」。
- `^`（按位异或）：两边**不一样**才亮。像「意见不同才举手」。
- `~`（按位取反）：亮变灭、灭变亮，整排翻个面。注意它是**单目**的，写成 `~a`。
- `<<`（左移）：整排往左挪 n 格，右边空出来的补 0 —— 相当于乘 2 的 n 次方。
- `>>`（右移）：整排往右挪 n 格，左边空出来的补 0（**无符号数**是这样）—— 相当于整除 2 的 n 次方。

光背这几行记不牢，跑一遍就忘不掉了。下面这个程序把每一行的结果都用开关画出来：

```c
#include <stdio.h>

void show(const char *label, int value) {
    unsigned char x = (unsigned char)value;
    printf("%-9s= ", label);
    for (int i = 7; i >= 0; i--) {
        printf("%d", (x >> i) & 1);
    }
    printf("\n");
}

int main(void) {
    show("6", 6);
    show("3", 3);
    show("6 & 3", 6 & 3);
    show("6 | 3", 6 | 3);
    show("6 ^ 3", 6 ^ 3);
    show("~6", ~6);
    show("1 << 4", 1 << 4);
    show("32 >> 3", 32 >> 3);
    return 0;
}
```

```text
6        = 00000110
3        = 00000011
6 & 3    = 00000010
6 | 3    = 00000111
6 ^ 3    = 00000101
~6       = 11111001
1 << 4   = 00010000
32 >> 3  = 00000100
```

对着看一遍就通了喵：`6 & 3` 只留下两边都亮的那一位（00000010 就是 2）；`6 | 3` 把两边亮着的都拢过来（00000111 就是 7）；`6 ^ 3` 专挑两边不一样的位置（00000101 就是 5）；`~6` 把整排翻了个面；`1 << 4` 让最低位那盏灯往左跳了 4 格，落到 16；`32 >> 3` 往右退了 3 格，变成 4。

上面那个 `show` 招式里的绕鱼干跑圈，就是本喵用来念开关的：从第 7 位一路数到第 0 位，`(x >> i) & 1` 的意思是「把那一位挪到最低位，再看它亮不亮」喵。

**看位运算只看一件事**：`&`、`|`、`^` 都是**一位一位地对着改**，每个位置各按各的规矩算，谁也不串门 —— 6 和 3 的同一个第 1 位是「亮和亮」，`&` 让它留亮、`^` 却让它灭；`<<` 不按位比，它把**整排**往左挪、右边补 0，挪 n 格就是乘 2 的 n 次方。课文那五种拨法里的 `~` 和 `>>`，就是同一排开关上的另外两种拨法喵。

## 拿它干什么：一排开关当权限牌

位运算最常用的场景，是**用一排开关记好几件事**。比如猫猫乐园的三样权限：能不能领小鱼干、能不能晒太阳、能不能睡猫窝。给每样分一盏灯，就不会互相打架：

```c
#include <stdio.h>

/* 三盏灯各占一个开关：1、2、4 */
#define CAN_FISH (1 << 0)
#define CAN_SUN  (1 << 1)
#define CAN_NAP  (1 << 2)

int main(void) {
    int cat = CAN_FISH | CAN_NAP;   /* 先给它两样权限 */

    printf("能领小鱼干吗？%s\n", (cat & CAN_FISH) ? "能" : "不能");
    printf("能晒太阳吗？%s\n", (cat & CAN_SUN) ? "能" : "不能");
    printf("能睡猫窝吗？%s\n", (cat & CAN_NAP) ? "能" : "不能");

    cat = cat | CAN_SUN;            /* 把晒太阳这盏灯拨开 */
    printf("拨开晒太阳之后：%s\n", (cat & CAN_SUN) ? "能" : "不能");

    cat = cat & ~CAN_NAP;           /* 把睡猫窝这盏灯按灭 */
    printf("按灭睡猫窝之后：%s\n", (cat & CAN_NAP) ? "能" : "不能");

    return 0;
}
```

```text
能领小鱼干吗？能
能晒太阳吗？不能
能睡猫窝吗？能
拨开晒太阳之后：能
按灭睡猫窝之后：不能
```

三样权限各占一盏灯（第 0、1、2 位），`3` 就是「能领小鱼干 + 能睡猫窝」。想**加一样**权限，用 `|` 把那盏灯拨开；想**查有没有**，用 `&` 拿对应那盏灯问一问（结果非 0 就是有）；想**收回一样**，用 `& ~那盏灯` 把它按灭。一个整数就装下了整张权限牌，比记三个 `int` 省事多了喵。

## 场景二：一眼看出奇偶

一盏灯就能顶大用：任何整数的最低那一位，正好代表它是不是奇数。

```c
#include <stdio.h>

int main(void) {
    for (int i = 0; i <= 4; i++) {
        printf("%d 是%s\n", i, (i & 1) ? "奇数" : "偶数");
    }
    return 0;
}
```

```text
0 是偶数
1 是奇数
2 是偶数
3 是奇数
4 是偶数
```

为什么 `i & 1` 就够了喵？因为最低位是「1」这一档 —— 二进制里其他位都是 2 的整数倍，只有最低位代表那个 1，所以最低位亮着就说明它是个奇数。`& 1` 正好只留下这一位，比用除法取余数还快。

::: tip 猫咪提示
今天记住三件事：**整数就是一排开关**；`&` 看两边都亮、`|` 有一个亮就亮、`^` 不一样才亮、`~` 整排翻面、`<<` `>>` 整排平移；**一排开关能当好几张权限牌用**（`1`、`2`、`4`、`8` 各占一盏灯）。左移 n 格等于乘 2 的 n 次方，这个直觉往后天天用得上喵。
:::

## 小心喵：`&` 和 `==` 挤在一起会咬人

这是本喵最想让你记住的一个坑。看这段代码：

```c
#include <stdio.h>

int main(void) {
    int x = 4;
    if (x & 1 == 0) {
        printf("x 是偶数\n");
    } else {
        printf("x 是奇数\n");
    }
    return 0;
}
```

```text
x 是奇数
```

4 明明是偶数，它却印「x 是奇数」！因为 `==` 的优先级比 `&` **高**，这一行被翻译官喵读成了 `x & (1 == 0)`：先算 `1 == 0` 得 0（灭），再算 `x & 0` 得 0，于是走了 `else` 那一支。想让它干正事，括号必须自己加上：`(x & 1) == 0`。

⚠️ 更要命的是：翻译官喵**其实会嘀咕一句** —— 原话是 `warning: suggest parentheses around comparison in operand of '&' [-Wparentheses]`。本喵把这段真跑了一遍，两个形状（当 `if` 的条件、存进变量再算）它都警告了。

可它只是**警告**：编译照样过，程序照跑不误，跑出来的还是**你没想要的那个结果**。所以别指望「编译器会拦我」—— 它只负责出声，不负责拦住你。请把这条当规矩背下来：**位运算和比较混在一行时，永远自己给位运算加括号。**

::: warn 小心喵
另外三条也顺便记住喵：① `^` 是「不一样才亮」，**不是幂运算**，别拿它当 `2 ^ 3 = 8` 用；② 只有**无符号数**的右移才老实（左补 0），带符号的负数往右挪的结果由机器自己定，别依赖它；③ 左移也不是随便挪的，把 1 挪到超出这排开关宽度的位置上，结果同样由机器自己定。要玩开关，优先用 `unsigned` 喵。
:::
