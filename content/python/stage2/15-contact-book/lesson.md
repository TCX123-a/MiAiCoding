## 钩子：朋友越来越多，本喵记不住了

本喵认识的朋友从三条涨到了三十条：每位都要记名字和「鱼干电话」。用一排东西按顺序装，本喵得记住「第 5 个是咪爱」——太费脑子了。

本喵想要的是一本**喊名字就说话**的本子：说「咪爱」，它把号码报出来；说「小狸」，它说「没见过」。更贪心一点：这本子**关掉程序也还在**，下次打开照样能用。

这一课就是这一阶段的收官作品 —— 把前面学过的几样本事拼成一本**能存下来的通讯录**：一对一的抽屉、读写档案、命令分派，还有接住毛病。

## 一对一的抽屉：字典

```python
通讯录 = {"咪爱": "123-456", "大肥鱼": "888-888"}
print(通讯录["咪爱"])
print(通讯录.get("小狸", "查不到喵"))
通讯录["小狸"] = "555-555"
print(len(通讯录))
print("咪爱" in 通讯录)
```

```text
123-456
查不到喵
3
True
```

- **`{名字: 号码}`** 这种一对一的柜子，用大括号写，每对中间是冒号。它不是按「第几个」找东西，而是**喊名字找** —— `通讯录["咪爱"]` 一喊，号码就叼回来了。
- **`通讯录["小狸"] = "555-555"`** —— 名字不在柜子里就是**添一对**；名字已经在就是**改掉那一对**。同一句干两件事，全看名字在不在。
- **`.get(名字, 默认)`** —— 喊名字找东西的**不翻脸版**：找着了给号码，找不着就给你写好的那句「查不到喵」。直接 `通讯录["小狸"]` 是会当场翻脸的（甩一张 `KeyError` 的纸条），所以**查不到有可能是常事的时候，用 `.get`**。
- **`len(通讯录)`** 数的是**有几对**；**`名字 in 通讯录`** 问的是「有没有这位朋友」。

## 存进档案：每行一条，竖线分开

要让本子关掉程序还在，就得写进档案里：

```python
通讯录 = {"咪爱": "123-456", "大肥鱼": "888-888"}

with open("通讯录.txt", "w", encoding="utf-8") as 档案:
    for 名字, 号码 in 通讯录.items():
        档案.write(f"{名字}|{号码}\n")

with open("通讯录.txt", encoding="utf-8") as 档案:
    print(档案.read(), end="")
```

```text
咪爱|123-456
大肥鱼|888-888
```

本喵给自己定了**三条约定**（往后每次读写都照这个来）：

1. **一对比一行。**
2. **名字和号码中间用一根竖线 `|` 隔开**。选它是因为名字里一般不会出现竖线，切开会很省事。
3. **每行末尾要有换行**，不然两条会粘成一条。

看代码：

- **`通讯录.items()`** 交出的是**一对一对**：每一次转一圈，`名字` 和 `号码` 两样同时接到手里（和上一课 `splitext` 那种「一次接两样」是一个脾气）。
- **`档案.write(...)`** 是「**往档案里写**」。注意它**不会自己加换行** —— 本喵在每一条末尾自己写了 `\n`。这一点和 `print` 不一样，`print` 是会自动换行的。
- `with open(路径, "w", encoding="utf-8")` 里的 `"w"` 是**写模式**：每次都会把档案里的旧内容清掉重写。带上 `encoding="utf-8"` 是怕中文在某些机器上变成乱码，**读写两头写一样的**才认得出。
- 读的时候 `print(档案.read(), end="")`：`read()` 把整份档案一口吞下来（末尾本来就带换行，所以本喵让 `print` 别再补一个）。

## 读回来：把每一行拆回一对

```python
with open("通讯录.txt", "w", encoding="utf-8") as 档案:
    档案.write("咪爱|123-456\n大肥鱼|888-888\n")

通讯录 = {}
with open("通讯录.txt", encoding="utf-8") as 档案:
    for 行 in 档案:
        行 = 行.strip()
        if not 行:
            continue
        名字, 号码 = 行.split("|")
        通讯录[名字] = 号码

print(通讯录["大肥鱼"])
print(len(通讯录))
```

```text
888-888
2
```

- **`for 行 in 档案:`** —— 档案可以**一行一行**地转圈读，这是读档案最省心的写法（不用一口气全吞下来）。
- **`行.strip()`** —— 把两端看不见的空白削掉，**主要是削掉行尾那个换行**。不削的话，号码末尾会拖着一个换行，本喵写回去的时候就会越来越长。
- **`行.split("|")`** —— 按竖线把这一行切成两段，用逗号一次接住两样。切出来的是**两段字**，本喵再把它们当成一对塞进空柜子：`通讯录[名字] = 号码`。
- **`if not 行: continue`** —— 空行（比如档案末尾多出来的一行）跳过，不然 `split` 切出一段空的东西，本喵又得措手不及。

## 分派命令：菜单是怎么转起来的

真机上的菜单是一个 `while True` 绕圈，每一圈用 `input()` 读你按的键。可本喵在这篇课文里没法真的等你敲键盘 —— 所以本喵把要按的键**先录成一排**（`按键表`），代码照着按就行。逻辑一模一样喵：

```python
通讯录 = {"咪爱": "123-456"}
按键表 = ["1", "2", "0"]

for 命令 in 按键表:
    if 命令 == "1":
        print("查到：", 通讯录.get("咪爱", "查不到喵"))
    elif 命令 == "2":
        通讯录["大肥鱼"] = "888-888"
        print("记好啦")
    elif 命令 == "0":
        print("下次见喵")
        break
    else:
        print("没有这个键喵")
```

```text
查到： 123-456
记好啦
下次见喵
```

- 每一圈拿到一个命令，就用 `if` / `elif` **一条条比过去**：比中了哪条就走哪条。
- **`break`** 是「**这一圈跳出去，绕圈到此为止**」—— 按下退出键就靠它收摊。
- 最后那条 `else` 是**兜底**：按了菜单上没有的键，就客客气气说一句，而不是默默什么都不干。
- 真机上把「从按键表里取一个」换成 `input("请按键：")` 就成，其余一模一样。

## 遇到不老实的一行

档案是外面的东西，里面可能混进坏行。本喵写一个小招式专门拆行，坏的就**主动翻脸**：

```python
def 拆一行(行):
    行 = 行.strip()
    if "|" not in 行:
        raise ValueError(f"这行不老实：{行}")
    名字, 号码 = 行.split("|", 1)
    return 名字, 号码

try:
    print(拆一行("咪爱|123-456"))
    print(拆一行("坏掉的一行"))
except ValueError as e:
    print("跳过：", e)
```

```text
('咪爱', '123-456')
跳过： 这行不老实：坏掉的一行
```

- **`if "|" not in 行: raise ValueError(...)`** —— 缺了竖线就是坏行，**当场甩纸条**，而不是硬着头皮往下切。这样出毛病的地方离原因最近（第 13 课的规矩）。
- `行.split("|", 1)` 里那个 `1` 是「**最多切一刀**」：名字或号码里万一还有个竖线，多出来的部分会整段留在后半截，不会被切碎。养成带上它的习惯不吃亏喵。
- 外面用 `try` / `except ValueError as e` 接住：好行照常过，坏行**跳过并说清为什么**，程序不断气。

## 档案不在的时候

第一次用这本通讯录时，档案还没有：

```python
路径 = "不存在的通讯录.txt"
try:
    with open(路径, encoding="utf-8") as 档案:
        print(档案.read())
except FileNotFoundError:
    print("档案还没有，本喵先建一个空的喵")
```

```text
档案还没有，本喵先建一个空的喵
```

`open` 一个不存在的档案，会甩出 `FileNotFoundError` 这张纸条。本喵接住它 —— 这不是「出错了」，这是**第一次用**，该做的是「从空本子开始」，不是让程序断气喵。

## 兜底也可以兜在菜单里

菜单转圈的时候，任何一条命令翻了脸，都可以就地接住，**转圈照旧继续**：

```python
通讯录 = {"咪爱": "123-456", "大肥鱼": "888-888"}
按键表 = ["3", "0"]

for 命令 in 按键表:
    try:
        if 命令 == "1":
            print("查到：", 通讯录["咪爱"])
        elif 命令 == "3":
            print("本喵认识", len(通讯录), "位朋友")
        else:
            print("下次见喵")
            break
    except KeyError as e:
        print("没有这位朋友喵：", e)
```

```text
本喵认识 2 位朋友
下次见喵
```

注意 `try` 是**写在绕圈里面**的：一条命令出事，接住它、转下一圈，**而不是整个程序断气**。这就是菜单这类程序最要紧的一条 —— **用户的每一次按键都不该把程序弄死**喵。

::: tip 猫咪提示
- **一对一的抽屉**：`{名字: 号码}`；喊名字取值、赋值添改、`len` 数几对、`in` 问有没有。
- **查不到有可能是常事 → 用 `.get(名字, 默认)`**，别用直接取值。
- **存档案三条约定**：一对比一行、中间一根竖线、每行末尾换行（`write` 自己不换行，得本喵补）。
- **读回来三件事**：`行.strip()` 削换行、空行 `continue` 跳过、`行.split("|", 1)` 切两段。
- **菜单靠 `if` / `elif` 一条条比 + `break` 收摊 + 最后的 `else` 兜底**。
- **`try` 写在绕圈里**，一条命令出事不影响下一圈。
:::

::: warn 小心喵
- **读写两头 `encoding` 不一致** —— 中文会变成乱码，而且**看着像内容存坏了**，其实只是两头没对上。两头都写 `encoding="utf-8"` 最省心。
- **忘了 `行.strip()`** —— 号码末尾拖着一个换行，越存越长、越长越乱。
- **`write` 以为会自己换行** —— 不会。少了那个 `\n`，两条记录会粘成一行。
- **什么都用直接取值** —— 查不到就翻脸。查名字这种**天天会查不到**的场合，`.get` 才是对的。
- **`except` 里什么都不写** —— 坏行被悄悄吞掉，本喵还以为存进去过。至少 `print` 一句说清跳过了哪一行喵。
:::

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `通讯录[名字] = 号码` | 添一对；名字已在就改那一对 |
| `通讯录.get(名字, "查不到喵")` | 不翻脸地取值，查不到给你默认 |
| `通讯录.items()` | 一对一对交出来，转圈时接进两个名字 |
| `with open(路径, "w", encoding="utf-8")` | 写模式开档案（旧内容会被清掉） |
| `档案.write(f"{名字}\|{号码}\n")` | 写一条，换行要自己补 |
| `for 行 in 档案:` | 一行一行读 |
| `行.strip().split("\|", 1)` | 削空白、按竖线切一刀 |
| `except FileNotFoundError:` | 档案还没建，从空本子开始 |
| `except KeyError as e:` | 没这位朋友，说一声别断气 |

## 小任务

本喵把「存」和「读」串成一个来回，顺便给每位朋友说句话：

```python
通讯录 = {"咪爱": "123-456", "大肥鱼": "888-888"}

with open("通讯录.txt", "w", encoding="utf-8") as 档案:
    for 名字, 号码 in 通讯录.items():
        档案.write(f"{名字}|{号码}\n")

with open("通讯录.txt", encoding="utf-8") as 档案:
    for 行 in 档案:
        行 = 行.strip()
        if not 行:
            continue
        名字, 号码 = 行.split("|", 1)
        print(f"{名字} 的号码是 {号码}")
```

```text
咪爱 的号码是 123-456
大肥鱼 的号码是 888-888
```

**试着改一改**：

1. 在写档案那一段的前面加一句 `通讯录["小狸"] = "555-555"`，跑一遍 —— 新朋友会不会一起存进去？为什么？
2. 故意往档案里加一行没有竖线的坏行（比如 `档案.write("坏掉的一行\n")`），再用 `拆一行` 那一段去读 —— 坏行会被怎么处理？
