## 钩子：凭什么 `+` 只认数字，不认本喵的碗

本喵有两只猫粮碗：一只装了 3 条小鱼干，一只装了 4 条。本喵想在纸上写一句 `a + b`，让 Python 直接把两只碗**并成一只装 7 条的**。

结果翻译官喵一脸茫然。「数 + 数」它会，「项链接项链」它也会，可「碗 + 碗」是个什么东西？它翻遍了自己的规矩册，**压根没有这一条**。

那本喵就**自己把这条规矩写给它**。

Python 早就留好了口子：在图纸上写几招**名字被两条下划线前后夹着**的招式，就等于告诉翻译官喵「**遇上这种时刻，你来喊本喵这一招**」。像这样的一批招式，本喵们叫它**魔法方法**。

它们平时安安静静躺着，**不会自己开演** —— 只有当某个特定的时刻真的发生了，Python 才替你把它们喊起来。上一课你已经悄悄用过一招了：`__init__` 就是「**照图纸生一只真猫的时候**」这个时刻的魔法方法喵。

## 魔法方法的三条规矩

1. **名字前后各是两条下划线**：`__str__`、`__add__`、`__len__`、`__eq__`。少一条都不行 —— 写成 `_str_` 就只是个普通名字，Python 永远不会替你喊它。
2. **写在图纸里面**，缩进照旧，和别的招式一起排好队。
3. **你不主动喊它们**，是 Python 在特定时刻替你喊。本喵写代码时从来不写 `a.__add__(b)`，只写 `a + b`，剩下的是 Python 的事。

下面本喵把四个最常用的时刻挨个走一遍。

## `__str__`：这只碗被打印的时候，该长什么样

本喵直接用 `print(a)` 打印一只碗，屏幕上冒出来的是一串谁也不认识的怪字（里面夹着图纸名和一串十六进制地址）。那是给电脑看的**住址**，不是给猫看的名字。

想让 `print(a)` 印出本喵想要的样子，就在图纸里加一招 `__str__`：

```python
class Bowl:
    def __init__(self, n):
        self.n = n

    def __str__(self):
        return f"装了 {self.n} 条小鱼干"

a = Bowl(3)
print(a)
```

```text
装了 3 条小鱼干
```

- **时刻**：`print(a)` 的时候，Python 会先悄悄喊一遍 `a.__str__()`，拿它叼回来的那句话去印。
- **必须用 `return` 把话叼回来**，不能只在里面 `print`。要是写成 `print(f"...")` 而不叼回来，Python 拿不到话，会当场翻脸说「叼回来的不是一句话」。
- 名字里那个 `str` 是「**话**」的意思：这一招回答的问题是「**这只碗该被说成什么样**」。

## `__add__`：`+` 遇上这只碗的时候，该干什么

```python
class Bowl:
    def __init__(self, n):
        self.n = n

    def __str__(self):
        return f"装了 {self.n} 条小鱼干"

    def __add__(self, other):
        return Bowl(self.n + other.n)

a = Bowl(3)
b = Bowl(4)
print(a + b)
```

```text
装了 7 条小鱼干
```

- **时刻**：`+` 的**左边**摆着这只碗的时候。本喵写 `a + b`，Python 背地里喊的是 `a.__add__(b)`。
- **`self` 是 `+` 左边那只**（`a`），**`other` 是右边那只**（`b`）。记不住就把这两个名字念一遍：自己、另一个。
- **它叼回来的是一只新碗**：`Bowl(self.n + other.n)` 照着图纸**新生成**一只装了 7 条的。原来那两只碗**一点没被动过** —— 这和数字的加法一个脾气，`3 + 4` 也不会把 3 改成 7。
- 少了这一招会怎样？`a + b` 上一课那种「翻遍规矩册没这一条」的错就会冒出来。**`__add__` 就是本喵给 `+` 补的那条规矩。**

## `__len__` 和 `__eq__`：`len(...)` 和 `==` 的时刻

```python
class Bowl:
    def __init__(self, n):
        self.n = n

    def __len__(self):
        return self.n

    def __eq__(self, other):
        return self.n == other.n

print(len(Bowl(5)))
print(Bowl(5) == Bowl(5))
```

```text
5
True
```

- **`__len__` 的时刻**是 `len(...)` 套在这只碗上的时候。它叼回来的必须是**一个不小于 0 的整数**（Python 拿这个数去数「有几样」），叼回别的东西它会翻脸。
- **`__eq__` 的时刻**是 `==` 两边摆着两只碗的时候。它得叼回 `True` 或 `False`。
- **不写 `__eq__` 会怎样？** Python 默认只比「**是不是同一只碗**」。两只碗是分别生出来的，哪怕装的都是 3 条，`Bowl(3) == Bowl(3)` 也会是 `False` —— 这个结果常常不是本喵想要的，所以想让「装的数一样就算相等」，就得自己把 `__eq__` 写上。
- `__eq__` 里的 `self.n == other.n` 比的是**两个数字**，不是两只碗 —— 数字的 `==` Python 天生就认，不会再回头去喊 `__eq__`，所以这里不会转圈圈。

::: tip 猫咪提示
魔法方法就记一句话：**名字被两条下划线夹住，Python 在特定时刻替你喊**。

| 时刻 | 被喊的招式 |
|---|---|
| 照图纸生一只真猫 | `__init__` |
| 这只猫被 `print` | `__str__` |
| `+` 的左边摆着这只猫 | `__add__` |
| `len(这只猫)` | `__len__` |
| `==` 两边摆着两只猫 | `__eq__` |

写的时候只管写 `a + b`、`len(a)`、`print(a)` —— **本喵从来不手写 `a.__add__(b)`**，那是 Python 的活喵。
:::

::: warn 小心喵
三个最容易踩的坑：

- **数错下划线**。前后**各两条**，一共四条。写成 `_str_`、`__str_`、`_str__` 都不算数 —— 那只是一个普通名字，Python 永远不会替你喊，而程序**不报错**，本喵只会百思不得其解「怎么没生效」。
- **`__str__` 里忘了 `return`**。它的任务是**把话叼回来**，不是自己印。只印不叼，Python 拿不到话，当场翻脸。
- **以为 `__add__` 会改原来那只碗**。它叼回来的是**一只新碗**，原来那两只好好的。想让 `a` 自己变，得自己写 `a = a + b` 重新接住喵。
:::

## 一句话对照表

| 写下的这一招 | Python 什么时候替你喊它 | 它得叼回来什么 |
|---|---|---|
| `def __init__(self, n):` | 照图纸生一只真猫的时候 | 不用叼（它只管把仓库建好） |
| `def __str__(self):` | 这只猫被 `print` 的时候 | 一句话 |
| `def __add__(self, other):` | `+` 的左边摆着这只猫的时候 | 一只新猫（或一个结果） |
| `def __len__(self):` | `len(这只猫)` 的时候 | 一个不小于 0 的整数 |
| `def __eq__(self, other):` | `==` 两边摆着两只的时候 | `True` 或 `False` |

## 小任务

本喵把今天四招全装进同一张图纸里了：

```python
class Bowl:
    def __init__(self, n):
        self.n = n

    def __str__(self):
        return f"装了 {self.n} 条小鱼干"

    def __add__(self, other):
        return Bowl(self.n + other.n)

    def __eq__(self, other):
        return self.n == other.n

a = Bowl(3)
b = Bowl(4)
print(a)
print(a + b)
print(a == b)
print(a == Bowl(3))
```

```text
装了 3 条小鱼干
装了 7 条小鱼干
False
True
```

**试着改一改**：

1. 把 `__str__` 里那句 `return` 换成 `print`，跑一遍看看报的是什么错 —— 就知道「叼回来」为什么少不得了。
2. 给图纸补一招 `__sub__`，让两只碗能用 `-` 相减（提示：`return Bowl(self.n - other.n)` 照着 `__add__` 抄）。然后写一句 `print(a - b)` 试试。
3. 把 `__eq__` 整招**删掉**再跑最后两行 —— 看 `True` 会不会变成 `False`，想想为什么喵。
