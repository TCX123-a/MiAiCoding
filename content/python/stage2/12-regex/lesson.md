## 钩子：本喵不记得是哪一条，只记得它长什么样

鱼塘边晾着一大排小鱼干，每条上面都刻了字。本喵现在想找的不是**某一条**，而是「**所有刻着数字的那种**」，或者「**以喵开头、后面跟着数字的那种**」。

一条一条翻太累了。本喵想要的是一句口诀：**给本喵一个花纹，本喵把对得上的全叼回来**。

Python 里就有这么一套本事 —— 它有个正式名字：正则表达式（按花纹找小鱼干）。名字念着绕口，用起来其实就四步：请出家伙、写下花纹、说出要找的那串字、拿结果喵。

## 先请出找花纹的招式：`re`

```python
import re

项链 = "小鱼干3条，猫粮12袋"
print(re.findall(r"\d+", 项链))
```

```text
['3', '12']
```

- `import re` 是把装着这套本事的**工具箱**搬进来（和前面搬 `os`、`math` 是一个动作）。
- `re.findall(花纹, 一串字)` 读作「**照着花纹，把对得上的全收进柜子**」。收回来的是一个储物柜，里面装着每一块对上的原文。
- 这里的花纹是 `r"\d+"`。拆开看就两段：`\d` 是「**一个数字**」（0 到 9 都算），`+` 是「**前面那样东西可以来一个、也可以来很多个**」。合起来：**一连串的数字**。所以「3」和「12」都被叼走了，「小鱼干」和「猫粮」这些字一个都没动。
- 花纹前面那个小 `r` 是**原始写法的记号**：告诉 Python「这段字里的反斜杠原样留着，别当我是在写字」。花纹里常有反斜杠，养成加 `r` 的习惯最省心喵。

## 只要第一块：`re.search`

`findall` 是「全都要」，`search` 是「**只要第一块对上的**」：

```python
import re

print(re.search(r"猫粮\d+", "小鱼干3条，猫粮12袋").group())
```

```text
猫粮12
```

- `search` 从这串字的开头一路往右找，**碰上第一块对上的就停下**，把那一块交出来。
- 交出来的不是一段字，而是一张**「对上的那一块」的小卡片**，要喊一声 `.group()` 才把卡上的原文取出来。
- 花纹 `r"猫粮\d+"` 读作「先是『猫粮』两个字，后面紧跟一串数字」—— 对上的是「猫粮12」，所以 `findall` 会给你 `['3', '12']`，而 `search().group()` 只给你 `猫粮12`。

## 找不到的时候

```python
import re

结果 = re.search(r"冻干\d+", "小鱼干3条")
print(结果)
print(结果 is None)
```

```text
None
True
```

`search` 一块都没对上时，**不会报错**，它会叼回来一个叫 `None` 的东西——就是本喵前面说过的「这里什么都没有」的那个空记号。上面用 `is None` 去比，比出来是 `True`，正说明它叼回来的是空。

这件事有个**很扎人的后果**：直接写 `re.search(...).group()`，一旦没找着，`.group()` 是在**对着一个空记号喊招式**，当场翻脸报错。所以：

- 想知道「找没找着」，就先接住结果、比一比 `is None`；
- 想直接取内容，最稳的写法是先用 `if` 挡一道，或者干脆用**找不到也不发火**的 `findall` —— 它没找着只会给你一个空柜子 `[]`。

## 花纹速查：符号各自的意思

```python
import re

print(re.findall(r"[猫鱼]", "猫粮鱼干猫窝"))
print(re.findall(r"^喵\d+", "喵1 喵2"))
```

```text
['猫', '鱼', '猫']
['喵1']
```

- **`[猫鱼]`** —— 一对方括号叫**挑一个**：里面的字随便哪个都算对。所以「猫粮鱼干猫窝」里，`猫`、`鱼`、`猫` 三处被叼走，各算一块。
- **`^`** —— 「**打头的必须是它**」。`r"^喵\d+"` 要求整串字的**最开头**就是「喵」，后面跟一串数字；第二块「喵2」前面还有别的字，就不作数了。

```python
import re

print(re.findall(r"猫.", "猫粮 猫咪 猫"))
print(re.findall(r"猫粮\d*", "猫粮 猫粮3袋"))
```

```text
['猫粮', '猫咪']
['猫粮', '猫粮3']
```

- **`.`** —— 「**任意一个字**」（换行不算）。`r"猫."` 就是「猫 + 后面紧跟的随便一个字」，所以最后一根光秃秃的「猫」不入选（它后面没字了）。
- **`*`** —— 「前面那样东西**来零个也行、来很多个也行**」。`r"猫粮\d*"` 碰上「猫粮」（后面没数字）照样算对，碰上「猫粮3」也把 3 带上。这就是它和 `+` 的分别：**`+` 至少要有一个，`*` 一个都不要也行**。

常见的几个本喵都列在这儿，眼熟就好，不用背喵：

| 花纹里的一段 | 它的意思 |
|---|---|
| `\d` | 一个数字 |
| `\w` | 一个「字」：字母、数字、下划线 |
| `.` | 任意一个字（换行除外） |
| `+` | 前面那样东西来一个或更多 |
| `*` | 前面那样东西来零个或更多 |
| `?` | 前面那样东西来零个或一个 |
| `[猫鱼]` | 方括号里随便挑一个 |
| `^` | 打头必须是它 |
| `$` | 收尾必须是它 |

## 查找替换：`re.sub`

```python
import re

print(re.sub(r"\d+", "N", "小鱼干3条，猫粮12袋"))
print(re.sub(r"\s+", " ", "小鱼干   3   条"))
```

```text
小鱼干N条，猫粮N袋
小鱼干 3 条
```

- `re.sub(花纹, 换成什么, 一串字)` 读作「**把对上的地方全换成新的**」。三个投喂口按顺序：花纹、新内容、要动的那串字。
- 第一条把每一串数字都换成了 `N`，两处都换掉了（`sub` 默认**全换**）。
- 第二条里的 `\s` 是「空白」（空格、制表符这些都算），`\s+` 就是「一连串空白」，换成一个空格 —— 这样歪歪扭扭的句子就收拾齐整了。这条最常用来清理抄来的脏数据喵。

::: tip 猫咪提示
- **`import re`** 先搬工具箱，四步走：请家伙、写花纹、给那串字、拿结果。
- **`re.findall(花纹, 一串字)`** —— 对得上的**全**收进储物柜；一块都没对上就给你空柜子 `[]`，不发火。
- **`re.search(花纹, 一串字)`** —— 只要**第一块**，交出来的是张小卡片，得喊 `.group()` 取原文；没找着给 `None`。
- **`re.sub(花纹, 换成什么, 一串字)`** —— 对上的地方**全换成**新的。
- **花纹前面加 `r`** —— 原始写法，反斜杠原样留着，省心。
- 常记的几个：`\d` 数字、`.` 任意一个字、`+` 一个或更多、`*` 零个或更多、`[猫鱼]` 挑一个、`^` 打头。
:::

::: warn 小心喵
- **`. + *` 在花纹里都是「有特殊意思的符号」**。想找**真的句点**，得写成 `\.`（加个反斜杠把它按住）—— 直接写 `.` 会变成「任意一个字」，那就什么都能对上了。
- **`re.search(...).group()` 中间不加防护** —— 没找着的时候 `search` 给的是 `None`，对着空记号喊 `.group()` 会当场报错。先比 `is None`，或者改用 `findall`。
- **以为 `findall` 会发火** —— 它不会。没找着就是空柜子 `[]`，本喵可别把「空柜子」当成「程序坏了」喵。
- **花纹里的括号、方括号没配对** —— 少一个符号，翻译官喵会直接告诉你花纹写坏了。写长了就拆开一小段一小段试。
:::

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `import re` | 搬出找花纹的工具箱 |
| `re.findall(r"\d+", 项链)` | 对得上的全收进柜子 |
| `re.search(r"猫粮\d+", 项链)` | 只要第一块，给一张小卡片 |
| `.group()` | 把小卡片上的原文取出来 |
| `re.sub(r"\d+", "N", 项链)` | 对上的地方全换成新的 |
| `r"..."` | 原始写法的花纹，反斜杠原样留着 |

## 小任务

本喵这里有一串刻得乱糟糟的字：

```python
import re

留言 = "订单 1024 号，共 3 条小鱼干，合计 45 元"
print(re.findall(r"\d+", 留言))
print(re.sub(r"\d+", "?", 留言))
```

```text
['1024', '3', '45']
订单 ? 号，共 ? 条小鱼干，合计 ? 元
```

**试着改一改**：

1. 把花纹从 `r"\d+"` 换成 `r"\d"`（去掉那个加号），看看柜子里会多出多少东西 —— 多出来的都是什么？
2. 用 `r"订单 \d+"` 去 `search` 一下，再喊 `.group()`，看看能不能只挑出「订单 1024」。
3. 把 `re.sub` 里的 `"?"` 换成本喵喜欢的东西（比如 `"小鱼干"`），看看留言变成什么样。

往后本喵要带你去认一套「**出毛病了怎么接住**」的本事：撒出去的招式翻了脸，本喵怎么不慌不忙把它接住，再自己画出**只属于本喵这一摊**的毛病来喵～ 🐾
