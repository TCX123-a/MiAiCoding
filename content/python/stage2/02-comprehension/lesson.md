## 钩子：一条一条做，太啰嗦啦

本喵的储物柜里躺着三条鱼，今天要把它们全都做成鱼干。老实巴交的做法是这样的：摆一个空柜子，绕鱼干跑圈，一条一条加工好了再塞进去——三行代码。三条鱼还好说，可要是柜子里躺着三百条呢？跑圈当然也跑得完，但本喵总觉得这三行写起来有点啰嗦喵。

Python 早就替这种「把一柜子东西挨个加工、再攒成新的一柜子」的活，准备了**一行就能写完**的写法。今天就教你这一招，外加一个更省地方的好东西喵 🐟

## 一行造出新柜子：推导式

先看两段代码，它们干的是同一件事：

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
新柜子 = []
for 鱼 in 柜子:
    新柜子.append(鱼 + "干")
print(新柜子)
```

```text
['三文鱼干', '秋刀鱼干', '鳕鱼干']
```

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
新柜子 = [鱼 + "干" for 鱼 in 柜子]
print(新柜子)
```

```text
['三文鱼干', '秋刀鱼干', '鳕鱼干']
```

第二段的第二行就是今天的主角——**推导式**。本喵在**列表（会自己长大的储物柜）**那一课里说过：柜子是一排贴着编号的格子，想塞多少就自己长大。推导式干的事，就是把「摆空柜子、绕圈、塞进去」这三步压成一行喵。读法是：

> **「把柜子里的每一样东西，依次叫它一声 `鱼`，再把 `鱼 + "干"` 放进新柜子里。」**

拆开这一行 `[鱼 + "干" for 鱼 in 柜子]`，它是三截拼起来的：

1. **最外面那对**方括号 `[ ]` —— 说的是「结果要攒成一个**新柜子**」。
2. **`鱼 + "干"`** —— **加工的样子**：每样东西要变成什么样。这里是给名字后面接一个「干」字。
3. **`for 鱼 in 柜子`** —— **从哪儿拿、拿到的东西叫什么**。这一截和跑圈那句长得一模一样：`鱼` 是这一圈拿到的那件东西的名字（随你起），`in` 后面跟着原来的柜子。

顺序要记牢：**加工的样子在前，从哪儿拿在后**。别和跑圈那三行弄混——跑圈是先写 `for`、再写圈里做什么，推导式是反过来的喵。

再换个数字的例子，把每样都乘二：

```python
编号 = [1, 2, 3, 4]
双倍 = [n * 2 for n in 编号]
print(双倍)
```

```text
[2, 4, 6, 8]
```

`n` 就是「这一圈拿到的那件东西」：第一圈它是 1，第二圈是 2……每一圈都拿当圈这件东西去算，算出来的结果挨个塞进新柜子。柜子有几格就转几圈，`编号` 里有四个数，新柜子里就正好有四样东西喵。

这一行到底是一笔一笔怎么走完的？本喵把它拆成一步一步给你看：

## 只挑想要的：末尾补一句 if

有时候不是每样都要。假设柜子里躺着一排分数，本喵只想要及格的那些：

```python
分数 = [58, 92, 75, 41, 88]
及格 = [n for n in 分数 if n >= 60]
print(及格)
```

```text
[92, 75, 88]
```

比刚才多出来的那一截 `if n >= 60`，挂在**整条配方的最后面**，它干的是**筛选**的活：

- 每从柜子里拿出一件东西，先问它一句：「你大于等于 60 吗？」
- 答「是」—— 收进新柜子；答「不是」—— 这一件跳过，配方接着往下走。

所以 58 和 41 被筛掉了，新柜子里只剩 92、75、88 喵。注意前面那截写的是 `n`，意思是「收进来的东西原样放着」——所以我们拿到的还是原来的分数本身，没有被改动过。

**加工和筛选可以一起用**：前面的部分负责加工，末尾的 `if` 负责挑选。

```python
分数 = [58, 92, 75, 41, 88]
加分后 = [n + 5 for n in 分数 if n >= 60]
print(加分后)
```

```text
[97, 80, 93]
```

::: warn 小心喵
`if` 一定要挂在**尾巴上**。把它顶到最前面，写成 `[if n >= 60 for n in 分数]` 这种样子，翻译官喵读不懂这句配方，会当场甩一句语法错误给你，一行都跑不起来喵。把形状记牢：**加工在前、`for` 在中间、挑不挑在最后**。
:::

## 生成器：现做现出的传送带

接下来是今天最奇妙的一步。把方括号换成**圆括号**看看：

```python
分数 = [58, 92, 75, 41, 88]
传送带 = (n * 2 for n in 分数)
print(sum(传送带))
```

```text
708
```

一模一样的配方，只差最外面那对括号，造出来的东西却**完全不同**：

- **方括号 `[ ]`**：一口气把整柜子都做出来摆在那儿。柜子里有几个数，它当场就做几个。
- **圆括号 `( )`**：造出来的是一条**传送带**（Python 里管它叫**生成器**）。它**不预先做**——你伸手要一条，它才现做一条递给你，递出去就撒手忘了。

所以同一句配方 `n * 2 for n in 分数`，套上方括号的 `[n * 2 for n in 分数]` 会当场造出一整个柜子，而套上圆括号的 `(n * 2 for n in 分数)` 只是把传送带搭好，一条都还没做喵。

`sum` 是个外援招式，喊法和数格数的 `len` 一样，名字写在括号外面：它把拿到的东西挨个加起来。它伸手从传送带上一条一条拿——116、184、150、82、176，加起来是 708 喵。

那要传送带干嘛？**省地方**。柜子得把每样结果都摆出来：配方跑完的时候，一百万个格子全堆在那儿等着。传送带只做当前这一条，做完递出去就撒手了。数据多起来的时候，这个差别很实在喵。

传送带上照样能挂 `if`，写法和方括号里一样；而且传送带可以直接喂给 `sum` 这样的外援招式——`sum` 自己带着一对小括号，所以里面的传送带不用再套一层：

```python
分数 = [58, 92, 75, 41, 88]
print(sum(n * 2 for n in 分数 if n >= 60))
```

```text
510
```

想把传送带上的东西一条一条**拿出来看**，用跑圈最顺手：

```python
传送带 = (n * n for n in [1, 2, 3])
for 东西 in 传送带:
    print(东西)
```

```text
1
4
9
```

走一圈拿一条：第一圈拿到 1，第二圈拿到 4，第三圈拿到 9，三条拿完它手里就空了。

### 传送带只走一趟

这是传送带和柜子脾气上最大的差别，一定要亲眼看一遍：

```python
传送带 = (n for n in [1, 2, 3])
for 东西 in 传送带:
    print(东西)
print("第一趟走完啦")
for 东西 in 传送带:
    print(东西)
```

```text
1
2
3
第一趟走完啦
```

看最后那几行：第二趟**一个字都没打印出来**。传送带上的东西是**走过就没**的——第一趟已经把三条全递出去了，第二趟它手里空空，跑圈发现没东西可拿，就安安静静结束了（不报错，也不打印任何东西）。

**传送带只有一条规矩**：谁伸手才现做，做一条递一条、**递出去就撒手**。所以它**只走一趟** —— 第二趟手里空空，圈安安静静就结束了；柜子里的东西却一直摆在格子里，想走几趟走几趟喵。

柜子就不会这样：柜子里的东西一直躺在格子里，你想走几趟就走几趟。所以记住一句话：**柜子能反复看，传送带只能走一趟。**

::: tip 猫咪提示
今天三件事，各记一句：
1. **推导式**：`[加工的样子 for 东西 in 柜子]` —— 一行造出一个新柜子，方括号管着「攒成柜子」。
2. **条件推导**：末尾补一句 `if`，负责挑「哪些能进来」；前面的部分负责「进来的变成什么样」。
3. **生成器**：把方括号换成圆括号，造出来的就是一条**现做现出**的传送带；它省地方，但**只能走一趟**。
:::

::: warn 小心喵
三个最容易踩的坑：
- **方括号还是圆括号**：只差一个括号，一个是整柜子、一个是传送带。动手前先想清楚「我到底要不要一次全做出来」喵。
- 传送带**不能报编号**（`传送带[0]` 拿不出来），也**不能用 `len` 量格数**——它压根没把东西摆出来，哪来的编号和格数。要按编号拿，就老老实实造个柜子。
- 传送带**走一趟就空**。打算拿它算两遍的话，第二遍会给你一个空结果；先造个柜子存好，再走两趟。
:::

## 小任务

把这几行敲进去，**一行一行猜、一行一行跑**：

```python
分数 = [58, 92, 75, 41, 88]
print([n for n in 分数 if n >= 60])
print([n + 5 for n in 分数 if n >= 60])
print(sum(n for n in 分数))
```

```text
[92, 75, 88]
[97, 80, 93]
354
```

猜对了吗？最后那行 `sum(n for n in 分数)` 是把整个柜子里的分数全加起来——传送带上一条一条递给 `sum`，正好 354 喵。

然后**试着改一改**：把末尾的条件换成「挑不及格的」，再把加工换成乘十：

```python
分数 = [58, 92, 75, 41, 88]
print([n * 10 for n in 分数 if n < 60])
print(sum(n * 2 for n in 分数 if n >= 60))
```

跑出来的样子和你猜的一样吗？再把 `<` 换成 `>`、把 `* 10` 换成 `+ 1`，多改几次，你就摸到推导式的脾气了喵 ✨
