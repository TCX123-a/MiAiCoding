## 钩子：一关灯，账本就不见了

本喵在鱼塘边支了个小摊，每天收摊前都要数一数今天收了几条小鱼干。本喵写了段小程序记上：

```python
shouhuo = 3
print("今天收了", shouhuo, "条小鱼干")
```

```text
今天收了 3 条小鱼干
```

第二天本喵再打开这段程序，傻眼了 —— 昨天那 3 条**不见了**。因为 `shouhuo` 这个**小鱼干仓库**是**用完就拆的**：程序一关灯，仓库里装着的东西跟着一起没了。想让数字活过今晚，得把它写进**档案室**。

档案室里放着一本本**册子**，每一本都有名字，比如 `dangan.txt`。册子上的字是真真切切**写在硬盘上**的：关灯、关机、明天再来，它都还在。册子的正规叫法是**文件**。这一课，本喵就教你怎么把小鱼干存进档案室，又怎么把它们一条条取回来喵。

## 一、`open` 与 `close`：拉开抽屉，关上抽屉

要让翻译官喵帮你动某一本册子，先得**把它拉开**：

```python
f = open("dangan.txt", "w", encoding="utf-8")
f.write("小鱼干 3 条\n")
f.close()
```

一行一行拆开看：

- **`open("dangan.txt", "w", encoding="utf-8")`** —— 「拉开抽屉」这个动作。括号里喂三样东西：
  1. **册子的名字**：`"dangan.txt"`。名字要**加引号**，因为它是一串字，不是本喵要用的名字。（册子和程序放在同一个地方时，直接写名字就行，不用写一长串路径。名字你自己取 —— 本喵这里叫 `dangan.txt`，你叫 `zhangben.txt`、叫 `猫粮账.txt` 都行，只要同一本册子前后写的一模一样、一个字母都不差。）
  2. **打开方式**：`"w"` 的意思是「本喵要往上面写字」。后面还会见到 `"r"`（读）和 `"a"`（接着写）。
  3. **`encoding="utf-8"`** —— 「这本册子用的是什么字」。带上它，中文才不会读成一堆乱码。往后本喵**每一回 `open` 都把它带上**，不再重复解释喵。
- **`f = ...`** —— `open` 干完这件事，会把**这本拉开的册子**叼回来，本喵给它起个名字叫 `f`。你叫它 `dangan`、叫它 `benzi` 都行，前后一致就好。
- **`f.write("小鱼干 3 条\n")`** —— 往册子上**写字**。末尾那个 `\n` 是**换行符**，意思是「这句写完，另起一行」。**不写它，下一句就会接着写在同一行上。**
- **`f.close()`** —— **关上抽屉**。

写完还得会读。把上面那段改一改，用 `f.read()` 把册子上的字**一口气全叼回来**。本喵故意把「写」和「读」放在同一段里，你一次跑完就能看见效果（真用起来的时候，这两件事常常隔得很远，甚至隔着一次关机喵）：

```python
f = open("dangan.txt", "w", encoding="utf-8")
f.write("小鱼干 3 条\n")
f.close()

f = open("dangan.txt", encoding="utf-8")
neirong = f.read()
f.close()
print(neirong, end="")
```

```text
小鱼干 3 条
```

- 第二个 `open` 里**只喂了一样东西** —— 不写打开方式，就是默认的 `"r"`（读）。
- `f.read()` 把册子上所有的字**一次全叼回来**，交给本喵起的名字 `neirong`。
- `print(neirong, end="")` 里那个 `end=""` 是「印完别再自己换一行」的意思（`print` 默认会自己换一行的）。为什么这里要拦住它？因为 `neirong` **末尾本来就带着一个换行符**，不拦的话，屏幕上会多出一个空行。

`close()` 别忘了喵。抽屉一直开着有两个麻烦：一是**写进去的字可能还揣在翻译官喵兜里**，没真的落进册子（程序半路翻车时最容易吃这个亏）；二是抽屉开得太多，翻译官喵会忙不过来。

### 三种打开方式

| 打开方式 | 意思 |
|---|---|
| `"r"` | **只读**。册子上的字一个字都不动。册子要是不在，翻译官喵会当场犯难 |
| `"w"` | **写**。拉开抽屉的那一刻，**册子上原来写的字全被撕掉**，从头写起。册子不在，就新建一本 |
| `"a"` | **接着写**。保留原来的字，在本喵上次停笔的地方往下写。册子不在，就新建一本 |

::: warn 小心喵
三个新手上路最容易摔的地方喵：

1. **`"w"` 是「撕掉重写」**，不是「打开来改改」。用 `"w"` 拉开一本写了一下午的册子，一拉开它就空了 —— 想留住原来的字，用 `"a"`。
2. **忘了 `close()`**（或者干脆忘了 `with`，下一节就教）—— 写进去的字可能还揣在兜里，没落进册子。
3. **`write` 只肯收一串字**。想写数字，得先把它变成字（`str(3)`）；直接写 `f.write(3)` 会当场翻车。
:::

## 二、`with`：进门自动开灯，出门自动关灯

抽屉要开、要关，写起来啰嗦，忘一次就出事。翻译官喵给了一个省心的写法：

```python
with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("小鱼干 3 条\n猫粮 1 碗\n")

with open("dangan.txt", encoding="utf-8") as f:
    print(f.read(), end="")
```

```text
小鱼干 3 条
猫粮 1 碗
```

这句 `with open(...) as f:` 拆开看是三层意思：

- **拉开抽屉**（`open(...)`）；
- **接下来的活都在这本册子上干**（缩进的那几行）；
- **给它起名叫 `f`**（`as f`）。

它最贴心的脾气在最后：**这一段做完，或者半路翻了个车，翻译官喵都会自动帮你把抽屉关上。** `close()` 一个字都不用写，想忘也忘不掉。

`with` 就像猫窝门口的**感应灯**：一进门灯自己亮，一出门灯自己灭，不用你记着按开关喵。上一节那两只 `open` / `close` 的写法，和这一段干的是同一件事 —— 只是 `with` 把「关灯」这件小事替你焊死了。

骨架就长这样，往里填你要干的事：

```text
with open("册子名", "打开方式", encoding="utf-8") as f:
    缩进的身体：在这里用 f 读或者写
```

两处要留神：**冒号**在 `as f` 后面，别丢；缩进的身体和 `if`、`for` 的规矩一样，是 4 个空格。

::: tip 猫咪提示
从今天起，**动册子一律用 `with` 的写法**喵。它把「拉开 → 干活 → 关上」三件事一次说完，中间那句「关上」你既不用写、也忘不掉 —— 少一个能摔的地方，就是这个写法最大的好处。
:::

这三步的先后为什么一步都不能乱、`with` 又到底替本喵省了哪一下 —— 本喵拆成一步一步，走给你看：

## 三、一行一行地读

`read()` 是「一口气全叼回来」。册子要是几百行，本喵更想**一行一行看**。直接拿 `for` 绕着它一把一把地取就行：

```python
with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("小鱼干 3 条\n猫粮 1 碗\n")

with open("dangan.txt", encoding="utf-8") as f:
    for hang in f:
        print(hang)
```

```text
小鱼干 3 条

猫粮 1 碗

```

咦，每一行后面都多出一个空行！这**不是档案里存了空行**，是两个换行叠在了一起：

- 档案里**每一行的末尾都藏着一个换行符**，`for` 取出来的 `hang` 是**带着它的**（也就是 `"小鱼干 3 条\n"`）；
- 而 `print` 印完，还会**自己再换一行**。

一个换行变两个，屏幕上就空出一行。想让印出来的干净，用 `.strip()` 把**两头看不见的空白**（空格、换行符）剃掉：

```python
with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("小鱼干 3 条\n猫粮 1 碗\n")

with open("dangan.txt", encoding="utf-8") as f:
    for hang in f:
        print(hang.strip())
```

```text
小鱼干 3 条
猫粮 1 碗
```

`.strip()` 剃的是**两头**，所以「小鱼干 3 条」中间那个空格一点都没动。往后记住一条：**从档案里读出来的每一行，几乎都要先 `strip()` 一下**再用喵。

### 一次全装进储物柜：`readlines()`

除了 `read()` 和 `for`，还有一招 `f.readlines()`：把册子上每一行**一起装进一个会自己长大的储物柜**，一行就是柜子里的一个格子。

```python
with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("小鱼干 3 条\n猫粮 1 碗\n")

with open("dangan.txt", encoding="utf-8") as f:
    hangs = f.readlines()
print(hangs)
print(hangs[0].strip())
```

```text
['小鱼干 3 条\n', '猫粮 1 碗\n']
小鱼干 3 条
```

第一行印出来的是那个储物柜本身：两个格子，**每个格子里的字都还拖着那个换行符**（屏幕上的 `\n` 是两个字符：反斜杠加 n；它是**藏起来**的换行，不是真的换了行）。第二行本喵把 0 号格子 `strip()` 了一下，才变回干干净净的 `小鱼干 3 条`。

三种读法的挑法很朴素：册子小、想一次拿到全部 → `read()`；想一行一行顺手处理 → `for`；想先把所有行收进储物柜、后面再慢慢翻 → `readlines()`。

## 四、`"a"` 接着写，`"w"` 撕掉重写

账本是天天要添的，本喵肯定不想每添一笔就把前面的全撕掉。这时候用 `"a"`：

```python
with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("第一天：3 条\n")

with open("dangan.txt", "a", encoding="utf-8") as f:
    f.write("第二天：5 条\n")

with open("dangan.txt", encoding="utf-8") as f:
    print(f.read(), end="")
```

```text
第一天：3 条
第二天：5 条
```

第一次用 `"w"` 写下第一天，第二次改用 `"a"`，第二天就**接着**写在后面了，第一天那条稳稳还在。

那要是第二次也用 `"w"` 呢？

```python
with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("第一天：3 条\n")

with open("dangan.txt", "w", encoding="utf-8") as f:
    f.write("第二天：5 条\n")

with open("dangan.txt", encoding="utf-8") as f:
    print(f.read(), end="")
```

```text
第二天：5 条
```

第一天那条**没了** —— 第二回拉开抽屉的那一刻，第一回写的字就被撕掉了。记住这条分界线喵：**想留住原来的字，用 `"a"`；想重新开始写，才用 `"w"`。**

（顺带说一句：那本册子并没有被删掉，只是被**擦干净**了。册子本来就不在的时候，`"w"` 和 `"a"` 都会顺手新建一本。）

## 五、常见模式：一排小鱼干存进去，再一条条取回来

把前面学的拼起来，就是最常用的一套：**存的时候一行一条，取的时候一行一条。**

```python
richeng = ["小鱼干 3 条", "猫粮 1 碗", "猫条 2 根"]

with open("dangan.txt", "w", encoding="utf-8") as f:
    for hang in richeng:
        f.write(hang + "\n")

with open("dangan.txt", encoding="utf-8") as f:
    for hang in f:
        print("档案里有：" + hang.strip())
```

```text
档案里有：小鱼干 3 条
档案里有：猫粮 1 碗
档案里有：猫条 2 根
```

这段值得多盯两眼：

- **存**的时候，本喵用 `for` 把储物柜里的东西一条条写进去，**每一条都自己补上 `\n`**。这一点和 `print` 不一样：**`print` 印完会自动换行，`write` 不会** —— 换行得你自己写。
- **取**的时候，用 `for` 一行一行读，每行 `strip()` 一下，就变回原来那一条条了。
- 还有一件事要记牢：**档案里存下来的只有字。** 写进去时是「小鱼干 3 条」这么一串字，取回来还是这串字 —— 想拿它当数字算，得自己把它变回数字（`int(...)`）。

::: tip 猫咪提示
这一课的四件事，一句话串起来喵：

1. **`open`** 拉开抽屉，**`close`** 关上抽屉；
2. 套上 **`with`**，抽屉就不用自己关了；
3. **`read()`** 一口气全读，**`for` 行 in 册子**一行一行读，每行 **`strip()`** 一下；
4. **`"w"` 是撕掉重写，`"a"` 是接着写。**
:::
