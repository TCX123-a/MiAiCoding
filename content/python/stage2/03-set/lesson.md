## 钩子：小橘今天来了三趟

本喵在猫窝门口摆了一本「今天来过的猫」登记簿。小橘早上来蹭了一顿，中午又来，傍晚还来 —— 三趟，本喵就老老实实写了三个「小橘」。晚上一翻本子，本喵想问的其实只有一句话：**今天一共来了几只猫？** 可簿子上写着一串重名字，还得一只一只对着划。

太累了。本喵想要一本**天生就不记重样**的簿子：同一只猫，不管来多少趟，只占一行。

Python 里真有这么一位，它叫**集合**（`set`）。今天本喵就把它请出来喵～

## 一、集合：不记重样的名单

集合的写法是一对**花括号**，里面的东西用逗号隔开：

```python
fish = {1, 2, 3}
names = {"小橘", "小橘", "狸花"}
print(len(fish))
print(len(names))
```

```text
3
2
```

一行行看：

- **一对花括号 `{ }`** 把东西圈起来，这就是集合。`fish` 那份里放了 `1`、`2`、`3` 三样，`len(fish)` 数出来 `3`。
- 第二份本喵是**故意**把「小橘」写了两个的 —— 数出来只有 `2` 喵！集合接东西的时候，看见重样的就悄悄扔掉，所以「小橘」和「狸花」各占一行，就这么两位。这就是它「天生不记重样」的脾气。

### 花括号里有没有冒号，是一条分界线

第一阶段「元组与字典」那一课的名牌格子柜（字典）也用花括号，怎么分？**就看冒号**：

- `{"小橘": 3}` —— 里面有个冒号，一位名牌配一样东西，这是**字典**。
- `{"小橘", "狸花"}` —— 只有逗号、没有冒号，这就是**集合**。

一句话记牢：**花括号里有冒号 = 名牌格子柜；只有逗号 = 集合。**

### 重样的东西，交给 `set(...)` 就好

手上有一长串东西、只想知道「到底有哪几种」，这是集合最常被派去的活：

```python
names = ["小橘", "狸花", "小橘", "三花", "狸花", "小橘"]
print(len(names))
print(len(set(names)))
```

```text
6
3
```

- 上面那本簿子是本喵手抄的，六行里小橘一个人占了三行。
- `set(names)` 是把簿子上的东西**倒进集合里**：集合一边接、一边把重样的扔掉，最后剩下小橘、狸花、三花这三位。
- 两边各数一数：`6` 和 `3`。

这一手叫**去重** —— 把「重」的那些去掉。以后再碰上「这一大堆里到底有几种」这样的问题，先想到它喵。

### 想要一个空集合，得写 `set()`

这是集合最扎人的一个坑，本喵单独拎出来讲。本喵想从一份空名单开始，一只一只往里加，随手写了 `{}`：

```text
fish = {}
fish.add(1)
```

翻译官喵当场不认账：

```text
Traceback (most recent call last):
  File "...\main.py", line 2, in <module>
    fish.add(1)
AttributeError: 'dict' object has no attribute 'add'
```

最后那句话的意思是：**这个家伙身上没有叫 `add` 的招式。**（`add` 是往集合里塞东西的招式，后面细讲。）

为什么？因为 `{}` 这个写法**早就被名牌格子柜占走了** —— 花括号在字典那边是同一个形状；空的时候里面连冒号都没有，翻译官喵只好按更老的那一位来认，于是一个空花括号就是**空的名牌柜**。

想要空集合，必须喊全名：

```python
fish = set()
print(len(fish))
```

```text
0
```

`set()` 就是「什么也没装的集合」，`len` 数出来 `0`。记住这一句：**空集合写 `set()`，`{}` 是空字典**喵。

## 二、它不记顺序，也不能报编号

本喵试过用老办法取东西 —— 报个编号：

```text
fish = {1, 2, 3}
print(fish[0])
```

```text
Traceback (most recent call last):
  File "...\main.py", line 2, in <module>
    print(fish[0])
TypeError: 'set' object is not subscriptable
```

报错那句话的意思是：**这个东西不支持用中括号报编号。**

原因很朴素：集合里**压根没有「第几格」这回事**。放进去的时候它就没打算记住谁先谁后 —— 就像本喵把三只猫赶进猫窝，它们在窝里怎么趴是它们自己的事，本喵没法喊「第 0 只猫出来」喵。

所以有一条规矩你必须记住：**集合不承诺顺序。**

::: warn 小心喵
既然不承诺顺序，就**别拿 `print(fish)` 印出来的排列当依据**喵！你在自己电脑上跑出来的先后，和本喵这里的可能不一样 —— 那不是你写错了，是这一位本来就不保证。想看清楚它里面到底有哪几样，用下面那招。
:::

### 看清结果：借 `sorted(...)` 兜一眼

集合不承诺顺序，那本喵怎么知道它里面到底有哪几样？本喵有个固定习惯 —— 把它交给 `sorted(...)`：

```python
fish = {9, 1, 5}
print(sorted(fish))
```

```text
[1, 5, 9]
```

`sorted(...)` 会把里面的东西**按大小排好队**，再交回来一份**排好队的储物柜**（外面的方括号就是储物柜的形状）。本喵写进去的先后是 `9`、`1`、`5`，它交回来的是 `[1, 5, 9]` —— 谁大谁小一目了然，不会再被顺序晃到眼睛。

这一招本喵今天只借来当放大镜，往后有专门一课讲它，先记住「**看集合里有什么，就 `sorted` 一下**」喵。

## 三、交并差：两份名单怎么合

本喵手上常备两份名单：小橘爱吃的菜、狸花爱吃的菜。要回答的问题无非三种 —— 两张单子合起来能端出什么、两猫都爱吃的是什么、小橘爱吃而狸花不爱的有哪些。这三件事集合天生就会，用的还是算术里那些眼熟的符号：

```python
a = {1, 2, 3}
b = {3, 4, 5}
print(sorted(a | b))
print(sorted(a & b))
print(sorted(a - b))
print(sorted(b - a))
```

```text
[1, 2, 3, 4, 5]
[3]
[1, 2]
[4, 5]
```

- **`a | b`（并集）**：一根竖线，念「或者」—— **两边的东西都算一份**，重样的只留一份。结果是 `[1, 2, 3, 4, 5]`：两张单子合起来能端出的全部。
- **`a & b`（交集）**：一个 `&`，念「并且」—— **两边都有**的那些。结果是 `[3]`：两猫都爱吃的。
- **`a - b`（差集）**：一个减号，念「去掉」—— **左边有、右边没有**的。结果是 `[1, 2]`。
- **`b - a`** 把两边掉个个儿：`[4, 5]`。

::: warn 小心喵
差集是**有方向**的喵！`a - b` 问的是「**`a` 这份名单里**，有哪些是 `b` 没有的」，所以 `a - b` 和 `b - a` 常常是两份完全不同的东西（上面那两行就是）。写之前先在心里念一遍：「我要的是**谁**的名单里**没有**的？」
:::

顺带认个脸：这三招还有长名字的写法 —— `a.union(b)`、`a.intersection(b)`、`a.difference(b)`，做的是一模一样的事。见到认识就行，本喵自己更爱写符号，短喵。

## 四、成员判断：问一句「在不在」

「今天小橘来了没？」—— 这是本喵每天都要问的一句话。集合回答这个问题的招式是 `in`：

```python
names = {"小橘", "狸花", "三花"}
print("小橘" in names)
print("大肥鱼" in names)
print(len(names))
```

```text
True
False
3
```

- **`"小橘" in names`** 是问一句：小橘在名单上吗？回你 `True`（在）或者 `False`（不在）。
- 这一招你在项链和储物柜身上都用过，写法一模一样，集合照样吃。它只管回答在不在，**不会顺手把东西叼回来** —— 所以 `"大肥鱼" in names` 就回一个 `False`。
- 最后那行是个提醒：问完一圈，名单上还是三位 —— `in` 只回答，不改动任何东西。

### 为什么这一句问得特别快

既然讲了 `in`，本喵就把它值钱的地方说明白：在**会自己长大的储物柜**上问「在不在」，翻译官喵得从第一格开始一格一格翻过去；在**集合**上问，它是**直接算出这样东西该落在哪个格位**，一伸手就摸到。

所以名单上有十样还是一万样，对集合来说都是差不多的功夫。凡是要反复问「这个在不在」的活 —— 比如「这只猫今天来过没」要查上几百遍 —— 请集合出场最划算喵。

## 五、随身几招：塞、拿、数

集合的日常就这么几招，本喵从一份三样东西的名单开始，一样一样试给你看：

```python
fish = {1, 2, 3}
fish.add(4)
print(len(fish))
fish.add(1)
print(len(fish))
fish.remove(4)
print(len(fish))
fish.discard(9)
print(len(fish))
```

```text
4
4
3
3
```

- **`fish.add(4)`** 是往集合里**塞**一样东西。塞完数一数，四样。
- **`fish.add(1)`** 又塞了一个 `1` —— 里面本来就有它。集合**当没听见**：不报错、也不多出一行，所以还是四样。这就是「天生不记重样」在动作上的样子。
- **`fish.remove(4)`** 是把一样东西**拿掉**，拿完剩三样。
- **`fish.discard(9)`** 也是拿掉 —— 可 `9` 本来就不在里面，它**一声不吭**，数一数还是三样。

`remove` 和 `discard` 的差别就在这儿：**`remove` 拿不到东西会当场炸毛**（甩你一个 `KeyError`），**`discard` 拿不到就当没这回事**。拿不准那样东西在不在的时候，用 `discard` 稳当；确定它一定在里面、还想让翻译官喵替你盯着，就用 `remove`。

### 什么样的东西放得进集合

```text
fish = {1, 2, [3, 4]}
```

```text
Traceback (most recent call last):
  File "...\main.py", line 1, in <module>
    fish = {1, 2, [3, 4]}
TypeError: unhashable type: 'list'
```

最后那句的意思是：**这个东西「定不下来」，放不进集合。**

集合和第一阶段那课的名牌柜有一条一模一样的规矩：**放进去的东西必须「定得下来」**。数字、项链、元组（焊死的小盒子）都行；**会自己长大的储物柜不行** —— 它里面的东西随时在变，集合算不出该把它放在哪个格位。想往集合里塞一组数，用元组 `(3, 4)` 包一下，别用储物柜喵。

::: tip 猫咪提示
集合这四件事记牢，就够用啦喵：

1. **写法**：一对花括号 `{1, 2, 3}`；**空集合必须写 `set()`**（`{}` 是空字典）。
2. **脾气**：天生去重、不承诺顺序、不能报编号。
3. **三招算术**：`|` 并集（都算一份）、`&` 交集（两边都有）、`-` 差集（左边有右边没有，**有方向**）。
4. **随身招**：`add` 塞、`remove` 拿（没有会炸毛）、`discard` 拿（没有也不吭声）、`in` 问在不在。
:::
