## 钩子：本喵想给每一招都加一句「开演啦」

本喵的鱼塘小工具里存着几十招。最近本喵起了个新念头：每一招开演之前，先印一句「**第几招、几点开始**」，收工之后再印一句。这样跑一遍就知道哪一招最慢。

最笨的法子本喵一眼就看出来了：**把这几十招全都改一遍**，每招头上加两行 `print`。可这么干有个大毛病 —— 招式本身被本喵改了。以后本喵不想看了，还得再改回去；几十招改两遍，手一抖就漏一处喵。

本喵想要的其实是：**招式一个字都不动，只在它外面套一层壳**。喊招式的时候，壳先开演，壳再替本喵喊里面那一招，喊完了壳再收个尾。

这个「**在外面套一层、不改造招式本身**」的东西，就是今天的主角 —— 术语表里叫**装饰器（给招式加特效）**，本喵们平时就直接喊它「**给招式加特效**」喵。

## 先看两件事：招式能被当小鱼干传来传去

要搞懂特效，得先接受一个有点反直觉的事实：**招式本身也是一样东西，能被投喂、能被叼回来**。

```python
def 打招呼():
    print("喵～")

def 喊三遍(fn):
    fn()
    fn()
    fn()

喊三遍(打招呼)
```

```text
喵～
喵～
喵～
```

- **`def 打招呼():`** —— 这一句干完，`打招呼` 这个名字底下就**挂着一招**了。
- **`喊三遍(打招呼)`** —— 注意括号里那个 `打招呼` **后面没有小括号**！本喵投喂进去的是**这一招本身**，不是它的结果。`喊三遍` 把这样东西接进 `fn` 这个名字里。
- **`fn()`** —— 一加上小括号，就是「**现在把它喊起来**」。喊三次，印三行。
- 反过来，要是本喵写成 `喊三遍(打招呼())`，那就是**先把 `打招呼` 喊一遍**，再把它叼回来的东西投喂过去 —— 那是完全另一回事了喵。

## `@`：给招式加一层特效

现在本喵把「套壳」这件事写成一招：

```python
def 加特效(fn):
    def 包装():
        print("【特效：开始】")
        fn()
        print("【特效：结束】")
    return 包装

@加特效
def 打招呼():
    print("喵～")

打招呼()
```

```text
【特效：开始】
喵～
【特效：结束】
```

一步步拆喵：

- **`加特效` 是一招「吃一招、吐一招」的招式**：投喂进来一招 `fn`，它在自己肚子里**新写一招 `包装`**，把 `fn()` 夹在前后两行 `print` 中间，最后把 `包装` **叼回去**。
- **里面那一招 `包装` 记得外面喂进来的 `fn`** —— 哪怕 `加特效` 早就跑完了，`包装` 一被喊起来还认得出 `fn` 是谁。这个「招式把外面喂进来的东西随身带着走」的本事，本喵们叫它**闭包**。
- **`@加特效`** 写在 `def 打招呼():` 的**正上方**，这一行的意思是「**把下面这一招整个塞进 `加特效` 里过一遍，再拿回来的那份，重新挂回 `打招呼` 这个名字底下**」。它和在下面补一句 `打招呼 = 加特效(打招呼)` 是**一模一样**的两件事，`@` 只是写起来更顺眼。
- **`@` 这一行念作「给下面这一招加一层特效」**。本喵只加了这一行，`打招呼` 里面那行 `print("喵～")` **一个字都没改**。

## 特效里想投喂进来东西怎么办：`*args, **kwargs`

上面那招 `打招呼` 是空的（不收小鱼干），所以 `包装` 也写成空的。可本喵的招式多半要收东西 —— 套上壳之后，外面喂进来的小鱼干得有人接住才行：

```python
import functools

def 记一笔(fn):
    @functools.wraps(fn)
    def 包装(*args, **kwargs):
        print(f"要施展的是 {fn.__name__}")
        return fn(*args, **kwargs)
    return 包装

@记一笔
def double(n):
    return n * 2

print(double(3))
print(double.__name__)
```

```text
要施展的是 double
6
double
```

- **`*args, **kwargs`** 读作「**把外面喂进来的东西，原封不动全都接住**」。星号那两位一个收「按位置排好的」，一个收「按标签点名的」，合起来就是「来多少收多少」。有了它，壳后面的招式想收几个小鱼干都行，本喵不用挨个改壳。
- **`return fn(*args, **kwargs)`** —— 把接住的东西**原样投喂**给里面那一招，再把它**叼回来的战利品原样叼回去**。这个 `return` 千万不能丢：丢了的话，`double(3)` 算出 6 也没人接着，外面只会收到一个空空的 `None`。
- **`@functools.wraps(fn)`** —— 特效盖上去之后，`double` 这个名字底下其实已经是 `包装` 了。`functools.wraps` 干的事是**给 `包装` 贴一张「本喵其实是 `double`」的标签**，把原来那一招的名字抄过去。
- 看最后两行：`print(double(3))` 印出 `6`，说明**战利品一点没丢**；`print(double.__name__)` 印出 `double`，说明**标签贴对了**。要是把 `@functools.wraps(fn)` 那一行删掉，第二个 `print` 印出来的会是 `包装` —— 名字被特效盖住了。

`fn.__name__` 里那个 `__name__` 也是魔法方法那一挂的：它不用小括号，因为**它就是一个摆着的东西**，直接点出来就是「**这一招叫什么名字**」。

## 特效最常见的三种用法

| 特效 | 它干什么 |
|---|---|
| **报时** | 招式开演前后各记一次时间，把中间差了多少秒报出来 |
| **记账** | 每次喊招式都往档案里写一行「谁在什么时候喊了哪一招」 |
| **把门** | 招式开演前先看鱼干眼色：条件不满足就直接拦下，里面那招**喊都不喊** |

看出来了吗？这三种活都是**同一个形状**：开演前做点什么、开演后做点什么，中间照样把原招式喊起来。**形状一样，内容随本喵换** —— 这正是特效最划算的地方喵。

::: tip 猫咪提示
- **招式也是东西**：`打招呼` 不带小括号 = **这一招本身**，可以被投喂、被叼回来；`打招呼()` 带小括号 = **现在把它喊起来**。
- **`@加特效`** 写在 `def` 的正上方，等于 `打招呼 = 加特效(打招呼)`：把招式塞进壳里过一遍，再挂回原来的名字底下。
- **壳里要接住小鱼干**，就写 `def 包装(*args, **kwargs):`，再用 `return fn(*args, **kwargs)` 把战利品原样叼回去。
- **`@functools.wraps(fn)`** 给壳贴标签，别让原来的名字被盖掉。它不是必须的，但**不写就会把原名弄丢**。
:::

::: warn 小心喵
三个最容易踩的坑：

- **`@` 那一行和 `def` 之间不能有别的东西**。空行能忍，但要是中间插了一句别的代码，`@` 就不认下面那一招了。
- **忘了把战利品叼回去**。壳里只写 `fn(*args, **kwargs)` 不写 `return`，外面收到的就是 `None` —— 而程序**一声不吭**，本喵只会觉得「怎么算出来的结果不见了」。
- **忘了 `*args, **kwargs`**。壳写成了空括号 `def 包装():`，可里面那一招要收小鱼干，一喊就报错说「本喵这儿怎么多出来一个东西」喵。
:::

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `喊三遍(打招呼)` | 把**招式本身**投喂进去（注意没有小括号） |
| `fn()` | 现在把 `fn` 这一招喊起来 |
| `@加特效` | 把下面那一招塞进 `加特效` 里过一遍，再挂回原名 |
| `def 包装():` | 壳：开演前做点什么、替本喵喊原招式、收个尾 |
| `return 包装` | 把做好的壳叼回去 |
| `def 包装(*args, **kwargs):` | 壳把外面喂进来的东西**原封不动全都接住** |
| `return fn(*args, **kwargs)` | 原样投喂进去，再把战利品原样叼回来 |
| `@functools.wraps(fn)` | 给壳贴标签，保住原来那一招的名字 |
| `fn.__name__` | 这一招叫什么名字 |

## 小任务

本喵给「加小鱼干」这一招套上了一层报时特效：

```python
import functools

def 报时(fn):
    @functools.wraps(fn)
    def 包装(*args, **kwargs):
        print("……计时开始")
        result = fn(*args, **kwargs)
        print("……计时结束")
        return result
    return 包装

@报时
def 加小鱼干(a, b):
    return a + b

print(加小鱼干(2, 3))
```

```text
……计时开始
……计时结束
5
```

注意壳里那个 `result` 这个名字：它先把原招式的战利品**接住**，等印完「计时结束」，再原样叼回去。**顺序很讲究** —— 要是写成 `return fn(...)` 再想印「计时结束」，那行字就没机会印了喵。

**试着改一改**：

1. 在这个壳里再加一句 `print(f"喂进来的是 {args}")`，看看 `args` 里装的是什么。
2. 把 `@functools.wraps(fn)` 那一行删掉，在文件最后补一句 `print(加小鱼干.__name__)` —— 看看印出来的是 `加小鱼干` 还是 `包装`。
3. 自己写一层新特效 `@把门`：壳里先看 `if args[0] < 0:` 成立就印「不许喂负的」并**直接返回**，不成立才喊里面那一招。然后给一招套上它试试喵。
