## 钩子：点单铺的价目牌歪歪扭扭

本喵的「猫猫点单铺」今天重新开张，本喵想在门口挂一块**价目牌**：左边写货名，右边写价格，一列一列对齐，看着才像个正经铺子喵。

本喵照着第一阶段的手艺先拼了一版：

```python
name = "小鱼干"
price = 3.14159
print(name, price)
```

```text
小鱼干 3.14159
```

能印出来，可它丑：价格后面拖着一长串小数尾巴，两行货名之间的缝也对不齐。

**字符串（一串小鱼干的项链）**你已经会串了——引号一围、报编号取一颗、切片剪一段，这些第一阶段都练过。今天本喵要教的是**进阶手艺**，一共三样：

1. **打扮**——把数字印成你想要的样子（两位小数、补零、对齐成列）。
2. **拆开**——把一条长项链剪成好几段。
3. **粘回去**——把好几段重新拼成一条。

学完这三样，门口那块价目牌就能挂出去啦。

## 一、花括号里的小旋钮

先请出今天的主角。你在「投喂与叼回」那一课见过它：**引号前面加一个小写的 `f`**，花括号里写仓库的名字，程序念到那儿，就会把名字换成仓库里装的东西。

今天本喵要往花括号里**再加一个小旋钮**：名字后面跟一个**冒号**，冒号后面写「怎么打扮」。

（记住是冒号喵！不是逗号，也不是句号。写错了翻译官喵当场翻脸，后面本喵专门讲。）

### 小数尾巴留几位

```python
name = "小鱼干"
price = 3.14159
print(f"{name} {price:.2f} 元喵")
print(f"三条就是 {price * 3:.2f} 元喵")
```

```text
小鱼干 3.14 元喵
三条就是 9.42 元喵
```

花括号里写的是「`price` 冒号 `.2f`」，分三段读：

- **冒号**是分界线：左边写「谁」，右边写「怎么打扮」。
- **`.2`** 是说「小数点后面留两位」，多出来的尾巴按四舍五入收掉。（要是正好卡在中间、或者那个数本来就存得不够精确，Python 的规矩会绕一点点——那是往后的课，今天先记住「留两位」就够啦。）
- **`f`** 是说「按小数的样子印」。

于是拖了五位小数的 `3.14159`，一下子就变成 `3.14` 啦。

第二行顺手多教一件事：**冒号左边不一定是名字，也可以是一整条算式**（那里写的是 `price * 3`）——先算出 `9.42477`，再打扮成两位小数。这一点你在「投喂与叼回」那一课见过影子，今天照旧好使喵。

### 占几格、往哪靠

```python
name = "小鱼干"
print(f"[{name:<6}]")
print(f"[{name:>6}]")
print(f"[{name:^6}]")
```

```text
[小鱼干   ]
[   小鱼干]
[ 小鱼干  ]
```

三行看下来，规矩就出来了：

- 冒号后面那个**数字** = 「一共占几格」。
- 数字前面那个**小箭头** = 往哪边靠：`<` 靠左、`>` 靠右、`^` 居中。记法：**箭头指哪边，字就贴哪边**。
- 不够的格子**拿空格补**。所以 `[` 和 `]` 这两只括号才能站到同一列上——对齐这件事，说穿了就是「拿空格占位」。
- 还有个小地方：**一个汉字也算一格**。上面「小鱼干」是三个汉字，就占掉三格，剩下三格才是空格。

### 号码牌要三位：补零

```python
n = 7
print(f"第 {n:03d} 号猫粮碗")
print(f"第 {n:3d} 号猫粮碗")
```

```text
第 007 号猫粮碗
第   7 号猫粮碗
```

- **`d`** = 「按整数印」（d 是 decimal 的头一个字母）。
- **`3`** = 占三格。
- 前面多出来的那个 **`0`** = 空着的格子**拿 0 填**；不写这个 `0`，空着的格子就填空格。

写的顺序也有讲究：**先说要拿什么填、再说占几格、最后说印成什么样**。所以是 `03d`，不是 `d30`，也不是 `3d0` 喵。

### 千分位和百分号

```python
big = 1234567
rate = 0.856
print(f"本月流水 {big:,} 元喵")
print(f"命中率 {rate:.1%}")
```

```text
本月流水 1,234,567 元喵
命中率 85.6%
```

- **`,`** 一个人站在冒号后面 = 「每三位垫一个逗号」。数字一长，眼睛就靠它分段。
- **`.1%`** = 「按百分数印，小数点后留一位」：程序会先把 `0.856` 乘上一百，再补个百分号。

### 想印真的花括号

花括号在 f-string 里是**记号**，不是标点。那本喵要是真想印一对花括号出来呢？

```python
fish = 3
print(f"{{{fish}}}")
```

```text
{3}
```

**写两遍**就行了：两个左花括号印出一个左花括号，右边的同理。里外一分清楚，记号就变回了普通符号喵。

::: tip 猫咪提示
花括号里那串规矩，本喵给你一句口诀：**先冒号，再打扮；填什么、占几格、印成什么样，一路排下去。**

| 想干的事 | 冒号后面写什么 | 印出来 |
|---|---|---|
| 小数点后留两位 | `.2f` | `3.14` |
| 占 6 格、靠左 | `<6` | 空格垫在右边 |
| 占 6 格、靠右 | `>6` | 空格垫在左边 |
| 占 6 格、居中 | `^6` | 两边各垫一半 |
| 占 3 格、空位补零 | `03d` | `007` |
| 每三位垫个逗号 | `,` | `1,234,567` |
| 按百分数印、留一位 | `.1%` | `85.6%` |
:::

::: warn 小心喵
**丢了冒号**是今天最容易摔的一跤。

花括号里要是直接写「`price` 点 `2f`」（中间没有冒号），翻译官喵念到那个点就卡住了，它的原话是：

```text
SyntaxError: invalid decimal literal
```

程序**压根跑不起来**——比印错还严重喵。所以每次写完都回头看一眼：**名字和打扮之间，那个冒号在不在？**

还有一件事要记牢：**打扮只管印出来的样子**。`price` 印成 `3.14` 了，可仓库里装的还是那个长长的 `3.14159`；真要让它变成两位小数，得另外动手（那是往后的课）喵。
:::

## 二、项链的剪刀和胶水

打扮讲完了，换第二样手艺：**把一条项链拆成几段**。

### `split`：拿剪刀剪开

```python
line = "小橘,3,小鱼干"
parts = line.split(",")
print(parts)
print(parts[0])
print(parts[1])
```

```text
['小橘', '3', '小鱼干']
小橘
3
```

三行拆开看：

- 喊法是**项链的名字 + 点 + `split` + 一对括号**，括号里放「拿什么当剪刀」。这里用逗号当剪刀，一刀下去，整条成了三段。
- 它叼回来的是一只**储物柜**，一格装一段。第一行印出来的 `['小橘', '3', '小鱼干']` 就是这只柜子本来的样子：方括号是柜子的边框，每一格都用引号圈着。
- **引号还在，说明每一段都还是一条项链**，不是数字——这一条最要紧，本喵单独拎出来讲。

### 拆出来的每一段还是项链

```python
line = "3 5"
parts = line.split()
print(parts[0] + parts[0])
print(int(parts[0]) + int(parts[0]))
```

```text
33
6
```

同一个 `parts[0]`，两种命运：

- 第一行 `parts[0] + parts[0]`：两串项链之间的 `+` 是**接起来**，`"3"` 接上 `"3"`，成了 `"33"`。
- 第二行套了一层 `int(...)`，把珠子上的数字**摘下来**，才真的做加法，得 `6`。

`split` 只负责**拆**，它不会顺手帮你把数字摘成整数罐。想算数，**自己动手套 `int(...)`**——这一招你在「投喂与叼回」那一课用过喵。

这两行只差一层 `int(...)`，为什么印出来的东西完全不一样？本喵拆成一步一步走给你看：

### 不写剪刀：按空白剪

```python
line = "  小橘   3   小鱼干  "
parts = line.split()
print(parts)
print(len(parts))
```

```text
['小橘', '3', '小鱼干']
3
```

括号**空着**的时候，`split` 按「空白」剪——空格、制表符、换行都算空白。而且它还有两件贴心的小动作：

- **两头的空白直接扔掉**，不给你留空段。
- **连着好几个空白只当成一把剪刀**，不切成一堆空段。

所以上面那条前后带空格、中间挤了三个空格的项链，剪出来干干净净三段。这就是本喵最爱不带剪刀的 `split()` 的原因：**别人敲进来的字，你永远不知道他多按了几个空格**。

### `join`：拿胶水粘回去

```python
parts = ["小橘", "3", "小鱼干"]
print(",".join(parts))
print("".join(parts))
print(" + ".join(parts))
```

```text
小橘,3,小鱼干
小橘3小鱼干
小橘 + 3 + 小鱼干
```

- 喊法**跟 `split` 反着来**：先写**胶水**（一对引号，里面放要垫在中间的东西），再点 `join`，最后把储物柜放进括号里。
- 胶水写逗号，就垫逗号；胶水写一对空引号，就什么都不垫，三段直接贴紧；胶水写「加号两边各一个空格」，粘出来就带空格。**看，空格也能当胶水**。
- 写反了（写成柜子点 `join`）会挨骂：储物柜身上根本没长这一招，翻译官喵甩你一句 `AttributeError`——意思是「这只柜子不会这招」喵。

### 数一数、问一句

```python
s = "小鱼干小鱼干小鱼干"
print(s.count("小鱼干"))
print(s.count("大肥鱼"))
```

```text
3
0
```

```python
file = "小橘的笔记.txt"
print(file.startswith("小橘"))
print(file.endswith(".txt"))
print(file.endswith(".md"))
```

```text
True
True
False
```

- **`count`**：数一数这一段在项链里出现了几次。一次都没有就老实报 `0`，不会报错。
- **`startswith` / `endswith`**：问一句「开头是不是这一段」「结尾是不是这一段」，叼回 `True` 或 `False`。
- 请注意这两个名字里都藏着一个 `s`（读作「start s」「end s」），写成 `startwith` 翻译官喵就不认识了。
- 它俩叼回来的是判断结果，正好能直接塞进 `if` 里看眼色——「看鱼干眼色行事」你第一阶段学过，今天这两招算是给它配了副好眼镜喵。

## 三、常用技巧：把一行字拆成好几样

### 技巧一：一行报进来三样东西

客人进门常常一口气全报出来：

```python
line = "小橘 3 12.5"
parts = line.split()
name = parts[0]
fish = int(parts[1])
money = float(parts[2])
print(f"{name} 要了 {fish} 条，花了 {money:.1f} 元喵")
```

```text
小橘 要了 3 条，花了 12.5 元喵
```

- 这条 `line` 就是「客人报的那一行字」：名字、条数、钱数，中间拿空格隔开。
- 真玩的时候，第一行会写成 `line = input("报名字、条数、钱数喵：")`——**`input` 叼回来的永远是一串项链**，所以后面拆开、摘数字这两步一步都不能少。
- 三步的口诀：**先 `split()` 拆开 → 再按格子取 → 该算数的套 `int(...)` 或 `float(...)`**。
- 最后那句里的 `:.1f` 顺手把价格收拾成一位小数，印出来才好看——**打扮和拆分，是可以叠在一起用的**。

### 技巧二：先洗个澡，再下刀

```python
raw = "  小橘,3,小鱼干  "
clean = raw.strip()
parts = clean.split(",")
print(f"客人 {parts[0]} 要了 {parts[1]} 条{parts[2]}")
```

```text
客人 小橘 要了 3 条小鱼干
```

- `strip()` 是第一阶段学过的那把**掸子**：只掸**两头**的空白，中间的不动。
- 要是不掸就直接下刀呢？第一段会变成前面挂着空格的 `"  小橘"`，印出来就是「客人   小橘」——多了几格，你还看不出来。
- 所以本喵的顺序是：**先 `strip()` 掸干净，再 `split()` 下刀**。脏东西清在开头，后面每一段都干净。

### 技巧三：价目牌终于对齐了

```python
items = ["小鱼干", "猫粮"]
prices = [3, 12]
for i in range(2):
    print(f"{items[i]:<8}{prices[i]:>4} 元")
```

```text
小鱼干        3 元
猫粮        12 元
```

- 左边那半 `:<8` = 「货名占 8 格、往左靠」；右边那半 `:>4` = 「价格占 4 格、往右靠」。
- 于是不管货名是两个汉字还是三个汉字，**价格那一位都乖乖站在同一列上**，牌子一下子就齐了。
- 中间那串空格全是一格一格**垫**出来的——对齐这件事，说到底就是「拿空格占位」。
- 段里的绕鱼干跑圈和储物柜取格都是第一阶段的老朋友，今天真正的新东西，只有那两串格式规格喵。

## 本课小抄

| 招式 | 干什么用的 |
|---|---|
| `:.2f` | 小数点后留两位 |
| `:<8` / `:>8` / `:^8` | 占 8 格，靠左 / 靠右 / 居中（数字改成几就占几格） |
| `:03d` 这种写法 | 占几格、空位补零（整数） |
| `:,` | 每三位垫一个逗号 |
| `:.1%` | 按百分数印，留一位小数 |
| 花括号写两遍 | 印出一个真的花括号 |
| `split(",")` | 拿逗号当剪刀拆开，叼回一只储物柜 |
| `split()` | 按空白剪，顺手扔掉两头的空白 |
| `"胶水".join(柜子)` | 拿胶水把几段粘回一条项链 |
| `count("小鱼干")` | 数一数出现了几次 |
| `startswith(...)` / `endswith(...)` | 问开头 / 问结尾 |

::: tip 猫咪提示
今天三样手艺，各记一句喵：

1. **打扮**：名字后面跟**冒号**，冒号后面写格式规格——`.2f` 留两位小数、`<` `>` `^` 管靠哪边、`03d` 补零、`,` 垫千分位。
2. **拆开**：`split(",")` 括号里写什么，就拿什么当剪刀；`split()` 空着写，按空白剪，还顺手扔掉两头的空白。
3. **粘回**：`"胶水".join(柜子)`——胶水写前面，柜子放括号里。
:::

::: warn 小心喵
三个最容易摔的地方：

- **拆出来的还是项链**：`parts[1]` 里是 `"3"` 不是 `3`，想算数先套 `int(...)` 喵。
- **`join` 的写法是反的**：胶水在前、柜子在后。写成柜子点 `join` 会挨 `AttributeError`。
- **打扮只管印相**：`:.2f` 印出两位小数，仓库里那个数一位都没少。
:::
