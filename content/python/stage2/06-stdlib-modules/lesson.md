## 钩子：本喵的柜子里，全是别人写好的招式

上一课本喵学会了「请手册进门」：一句 `import math`，Python 出厂自带的那本 `math` 手册就搬进来了。当时本喵只顾着高兴，没细想一件事 —— **Python 出厂就带了一大柜子手册**。

这个大柜子叫**标准库**。它是猫猫协会替所有学员备好的一整柜现成招式：管鱼塘和路径的、管程序自己的、管钟表的、摇随机数的、算数最较真的……**统统不用自己写，请进来就能用**喵。

今天本喵带你翻最常用的五本：`os`、`sys`、`time`、`random`、`math`。

请法还是上一课那三种：`import 手册名` 整本请、`import 手册名 as 短名` 改名请、`from 手册名 import 招式名` 只挑一招。下面本喵一律用最简单的「整本请」，用的时候老老实实写 `手册名.招式名`。

## `os`：管本喵脚下这台电脑

`os` 这本手册管的是**电脑本身**：文件、文件夹、路径。本喵最常用的是它里面 `path` 那一小格：

```python
import os

print(os.path.basename("D:/鱼塘/小鱼干.txt"))
print(os.path.splitext("小鱼干.txt"))
```

```text
小鱼干.txt
('小鱼干', '.txt')
```

- **`os.path.basename(...)`** —— 读作「**这一长串里，最后那截文件名是什么**」。喂进去一整条路径，叼回来 `小鱼干.txt`。路径前面那一长串文件夹名，它替你扔掉了。
- **`os.path.splitext(...)`** —— 读作「**把尾巴上的后缀切下来**」。它一次叼回来**两样**，包在一对小括号里：前面是名字 `小鱼干`，后面是后缀 `.txt`。

光会看还不够，本喵还想要真的动一动鱼塘：

```python
import os

os.makedirs("鱼塘/小鱼干", exist_ok=True)
print(os.path.exists("鱼塘/小鱼干"))
print(os.listdir("鱼塘"))
```

```text
True
['小鱼干']
```

- **`os.makedirs("鱼塘/小鱼干", exist_ok=True)`** —— 「**把这条路上缺的文件夹都建出来**」。斜杠一层层写下去，中间缺的它会一路补齐。尾巴上那个 `exist_ok=True` 是句保险话：「**要是它已经在了，别翻脸，安安静静过去**」—— 少了它，同一个文件夹建第二次会当场报错。
- **`os.path.exists(...)`** —— 「**这个地方到底有没有东西**」，有就叼回 `True`，没有就是 `False`。
- **`os.listdir("鱼塘")`** —— 「**把这个文件夹里的东西，一样一样报出来**」。刚才建进去的那一格叫 `小鱼干`，所以它一口气全报给你。

## `sys`：管本喵正在跑的这份程序自己

`os` 管电脑，`sys` 管的是**这份程序本身**：它是被怎么喊起来的、用的是哪个 Python、什么时候该收摊。

```python
import sys

if len(sys.argv) == 1:
    print("没有带吃的来喵")
else:
    print(f"带来了 {len(sys.argv) - 1} 样东西")
```

```text
没有带吃的来喵
```

**`sys.argv`** 读作「**本喵被喊起来的时候，跟在后面的那串东西**」。它是一个排好队的储物柜，**第一格**永远装着这份程序自己的名字；**从第二格开始**，才是你启动时额外跟在后头的东西。

上面这段本喵启动时什么都没跟，所以 `len(sys.argv)` 是 `1`，走的是「没有带吃的来」那一支喵。

要是启动时这么写（命令行里，本喵在程序名后面跟了三个词）：

```text
python main.py 小鱼干 猫粮 冻干
```

那么 `sys.argv` 里就是四格：`main.py`、`小鱼干`、`猫粮`、`冻干`；`len(sys.argv) - 1` 正好是跟进去的**三样**。

第二招更威风：

```python
import sys

print("开饭啦")
sys.exit()
print("这一句永远不会跑")
```

```text
开饭啦
```

**`sys.exit()`** 读作「**本喵收摊了**」。喊出这一句，程序**当场结束**，后面还有多少行都不管了 —— 所以第三行那句 `print` 永远没机会开演。以后程序走到「再往下跑就不对劲了」的地方，就可以用它直接收摊喵。

## `time`：管钟表

```python
import time

start = time.time()
time.sleep(0.1)
end = time.time()
print(end > start)
print(round(end - start, 1) >= 0.1)
```

```text
True
True
```

- **`time.time()`** —— 表面上是「现在几点」，但它叼回来的**不是** `14:30` 这种给人看的字，而是一个**秒数**：从 1970 年元旦零点整到此刻，一共过了多少秒。所以本喵前后各取一次、**一减**，就是中间到底耗了多久。
- **`time.sleep(0.1)`** —— 「**本喵打个盹**」：让程序**停住** 0.1 秒再往下走。代码里想「等一会儿再说」，靠的就是它。

那要给人看的钟点怎么办？`time` 里还有一招 `strftime`：

```python
import time

print(time.strftime("%H:%M", time.localtime()))
```

它叼回来的是一句像 `14:30` 这样的钟点喵 —— 当然，真跑起来印出来的是你电脑的**当下时间**，每次都不一样，所以本喵这里不敢写死输出。

`"%H:%M"` 那串引号里的东西是**花样**：`%H` 表示「小时（24 小时制）」，`%M` 表示「分钟」，中间那个冒号照原样印出来。想看日期就把花样换成 `"%Y-%m-%d"`。

## `random`：摇骰子的猫爪

```python
import random

random.seed(7)
bowls = ["小鱼干", "猫粮", "冻干"]
random.shuffle(bowls)
print(bowls[0])
print(random.randint(1, 6))
```

```text
冻干
4
```

- **`random.seed(7)`** —— 「**给随机定个起点**」。听着别扭，但很有用：起点定成同样的数字，往后摇出来的那一串**每次都一模一样**。本喵写课文要给你看确定的输出，就靠这一句；你自己写正经程序时**千万别写它**，让它真随机去喵。
- **`random.shuffle(bowls)`** —— 「**把这一排碗打乱**」。注意它是**原地**打乱：还是那几只碗、还是那么多个，只是顺序变了。所以它**不用你去接**，本喵写完这一行就当它已经乱了。
- **`random.randint(1, 6)`** —— 「**闭着眼睛**从 1 到 6 里挑一个整数」。摇骰子、猜数字游戏全靠它。
- **`random.choice(一排东西)`** —— 「**从那里面随便挑一样**」出来。挑完那排东西本身一点都不动。

## `math`：算数最较真的那一本

```python
import math

print(math.gcd(12, 18))
print(math.factorial(4))
print(round(math.pi, 2))
print(math.ceil(2.1))
print(math.floor(2.9))
```

```text
6
24
3.14
3
2
```

- **`math.gcd(12, 18)`** —— `gcd` 是「**最大公约数**」：能同时把 12 和 18 都除干净的最大的那个数，是 `6`。
- **`math.factorial(4)`** —— 「**阶乘**」：1 × 2 × 3 × 4 = `24`。注意 `factorial(0)` 是 `1`（这是规矩定死的，不是本喵瞎说）。
- **`math.pi`** —— 圆周率。它**不是一个招式**：后面**没有小括号**，因为它就是手册里**直接摆着的一个数**。写 `math.pi` 就能取到它。外面套的 `round(数, 2)` 是「四舍五入到两位小数」，所以是 `3.14`。
- **`math.ceil(2.1)`** —— 「**往上取整**」：2.1 往上抬一格，是 `3`。（`ceil` 读作「天花板」，东西顶到天花板就是往上抬。）
- **`math.floor(2.9)`** —— 「**往下取整**」：2.9 往下落一格，是 `2`。（`floor` 是「地板」，掉到地板上就是往下落。）

`ceil` 和 `floor` 正好是一对：**一个往上顶、一个往下落**。2 到 3 之间的数，`ceil` 一定给 3，`floor` 一定给 2，中间的小数部分怎么都保不住。

::: tip 猫咪提示
五本手册各自管什么，一句话记牢喵：

- **`os`** —— 管电脑上的**文件和文件夹**（建目录、看路径、列目录）。
- **`sys`** —— 管**这份程序自己**（启动时带了什么、什么时候收摊）。
- **`time`** —— 管**钟表**（现在多少秒、打个盹、捏给人看的时间）。
- **`random`** —— 管**随机**（摇骰子、挑一样、打乱一排）。
- **`math`** —— 管**算数**（开方、阶乘、圆周率、取整）。

用的时候一律写全 `手册名.招式名`，小圆点一个都不能省喵。
:::

::: warn 小心喵
三个最容易踩的坑：

- **`math.pi` 不加小括号**。它是手册里摆着的一个数，不是招式。写成 `math.pi()` 翻译官喵会翻脸：数怎么能拿来喊？反过来，招式写成 `math.sqrt` 而不带括号，只是「把这一招本身拿出来」，**不会真的替你算**。
- **别把 `random.seed(...)` 写进正式程序**。它会让「随机」变回固定的，本喵写课文用它只是为了让输出每次都一样，好跟书上对得上。你自己写的时候要是也留了一句，那一整串数就被钉死了：本喵量过，种子给 1 摇一百次，里头有 **66 个不同的数**（不是同一个数重复一百遍）—— 可你把这一百次记下来，**下次跑还是这一百次，连顺序都不差**。被钉死的是**整串**，不是单个数喵。
- **`sys.exit()` 之后的行全是废纸**。程序当场就收摊了，后面的代码**一行都不会跑**——排错了地方，你会以为「明明写了怎么没生效」。
:::

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `os.path.basename(...)` | 从一整条路径里，只留下最后那截文件名 |
| `os.path.splitext(...)` | 把后缀切下来，一次叼回来两样 |
| `os.makedirs("鱼塘/小鱼干", exist_ok=True)` | 把这条路上缺的文件夹都建出来；已经在了也不翻脸 |
| `os.path.exists(...)` | 这个地方到底有没有东西 |
| `os.listdir(...)` | 把文件夹里的东西一样一样报出来 |
| `sys.argv` | 本喵被喊起来时，跟在后面的那一串（第一格是程序自己的名字） |
| `sys.exit()` | 本喵收摊了：程序当场结束，后面的行不再跑 |
| `time.time()` | 从 1970 年元旦零点到此刻，一共过了多少秒 |
| `time.sleep(n)` | 打个盹：停住 n 秒再往下走 |
| `time.strftime("%H:%M", ...)` | 把时间捏成给人看的钟点 |
| `random.randint(1, 6)` | 闭着眼睛从 1 到 6 挑一个整数 |
| `random.choice(...)` | 从一排东西里随便挑一样 |
| `random.shuffle(...)` | 把一排东西**原地**打乱 |
| `random.seed(n)` | 给随机定个起点（本喵演示用，你写程序别写） |
| `math.gcd(a, b)` | 最大公约数 |
| `math.factorial(n)` | 阶乘 |
| `math.pi` | 圆周率，是个数，**不加括号** |
| `math.ceil(x)` / `math.floor(x)` | 往上取整 / 往下取整 |
