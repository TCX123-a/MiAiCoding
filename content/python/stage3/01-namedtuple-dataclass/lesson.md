## 钩子：本喵记档案记糊涂了

本喵要给猫窝里的每位朋友各记一份小档案，三样东西：**名字、年龄、毛色**。

最省事的办法是拿个元组一兜：`("咪爱", 3, "橘")`。可取的时候就得**数格子** ——「第 0 格是名字，第 1 格是年龄……」本喵数着数着就糊涂了：`档案[2]` 里装的到底是年龄还是毛色？三天不碰，准数错喵。

换成喊名字的柜子（字典）倒是好使，可每个名字都得用引号包起来敲一遍 —— 敲成 `档案["年纪"]`，它**当下什么都不说**，要等你真去取的那一刻，才甩一张 `KeyError` 的纸条给你，本喵还得回头找是哪个字打歪了。

本喵想要的是：**像元组一样轻巧，又能喊名字取**。Python 的百宝箱里正好躺着两样东西 —— **`namedtuple`** 和 **`dataclass`**。今天本喵把这两样一次认全，最后再教你怎么挑喵。

## 老办法：一个靠数格子，一个靠敲引号

先把元组看仔细：

```python
档案 = ("咪爱", 3, "橘")
print(档案[1])
```

```text
3
```

`档案[1]` 读作「第 2 格」（格子是从 0 数起的）。它**不会告诉你这格里装的是什么**，全靠本喵自己把顺序背下来 —— 换一只猫、换一个顺序，就全乱了。

字典是这样的：

```python
档案 = {"名字": "咪爱", "年龄": 3}
print(档案["年龄"])
```

```text
3
```

喊名字就好多了喵。可那串名字是**本喵一个字母一个字母敲出来的**：敲歪一个，程序不多说一个字，等你真去取的时候才翻脸。

## namedtuple：给每一格贴上名牌

本喵请出第一位帮手 —— 做一张**贴好名牌**的图纸：

```python
from collections import namedtuple

猫档案 = namedtuple("猫档案", ["名字", "年龄", "毛色"])
咪爱 = 猫档案("咪爱", 3, "橘")
print(咪爱.名字)
print(咪爱.年龄)
print(咪爱[1])
```

```text
咪爱
3
3
```

一行一行看喵：

- **`from collections import namedtuple`** —— 从 Python 自带的 `collections` 工具箱里，把 `namedtuple` 这件工具请出来。（`import` 就是「要用工具箱里的东西，先请一声」。）
- **`namedtuple("猫档案", ["名字", "年龄", "毛色"])`** —— 这一句**做出一张新图纸**，要交给它两样东西：
  - 第一样是这张新图纸的名字（`"猫档案"`）；
  - 第二样是**一排名牌**，一件东西贴一张。**名牌的先后，就是以后喂东西的先后**，写反了后面就全反。
  - 名牌也可以写成一串用空格隔开的字：`namedtuple("猫档案", "名字 年龄 毛色")`，一个意思。本喵这里用方括号那种，一眼看得出里面有几件东西。
- **`咪爱 = 猫档案("咪爱", 3, "橘")`** —— 照着图纸**生一只真猫**，按名牌的顺序喂三样进去。
- **`咪爱.名字` / `咪爱.年龄`** —— **点一下名牌，东西就出来了**。再也不用数「这是第几格」。
- **`咪爱[1]`** 印出来还是 `3` —— 它骨子里**仍然是元组**：按格子数的老办法照样能用，连「一次拆几样」的老写法也没丢：

```python
from collections import namedtuple

猫档案 = namedtuple("猫档案", ["名字", "年龄"])
咪爱 = 猫档案("咪爱", 3)
名字, 年龄 = 咪爱
print(名字, 年龄)
```

```text
咪爱 3
```

**一句话记住：`namedtuple` 就是「每一格都贴了名牌的元组」。**

## 名牌有个脾气：贴上就改不动了

本喵想给咪爱过个生日，顺手把年龄改掉 —— 结果撞了一鼻子灰：

```python
from collections import namedtuple

猫档案 = namedtuple("猫档案", ["名字", "年龄"])
咪爱 = 猫档案("咪爱", 3)
长大的 = 咪爱._replace(年龄=4)
print(咪爱.年龄)
print(长大的.年龄)
print(咪爱 == 猫档案("咪爱", 3))
```

```text
3
4
True
```

- **直接写 `咪爱.年龄 = 4` 会当场翻脸**：它甩你一张 `AttributeError` 的纸条，说这儿的名字动不得。原因不神秘 —— 它骨子里是元组，而元组**一出生就是钉死的**。
- 要改，就用 **`_replace(名牌=新东西)`**：它**不碰原来那一只**，而是照样子另做一只，只把点名的那个名牌换掉。
- 所以第一行印的还是 `3`（`咪爱` 一动没动），第二行才是 `4`（那是新做的 `长大的`）。两只都在，谁也不碍谁。
- **`_replace` 前头那条下划线是名字的一部分**，不是「不许碰」的意思，照打就对了喵。
- 最后一行 `True`：两只**内容一样**的真猫用 `==` 比，判的是 `True` —— 骨子里比的就是那几格里的东西。

## dataclass：给图纸头上贴一层特效

`namedtuple` 轻巧是轻巧，可它有两处不够用喵：

1. **改不动** —— 想改一处，就得整只另做一只。
2. **只能装东西** —— 想让它自己带一招（比如「报一句自我介绍」），没地方写。

于是本喵请出第二位帮手：

```python
from dataclasses import dataclass

@dataclass
class 猫档案:
    名字: str
    年龄: int
    毛色: str = "橘"

咪爱 = 猫档案("咪爱", 3)
print(咪爱.名字, 咪爱.年龄, 咪爱.毛色)
咪爱.年龄 = 4
print(咪爱.年龄)
```

```text
咪爱 3 橘
4
```

- **`from dataclasses import dataclass`** —— 这回请的是 `dataclasses` 工具箱里的 `dataclass`。
- **`@dataclass`** —— **贴在图纸头上的一层特效**。上一阶段画图纸时，本喵得亲手写一段 `def __init__(self, ...)`，把每件东西一样一样存进 `self`；这回**一段都不用写**，这层特效替本喵把「开门收货」那套活全铺好了。
- **`class 猫档案:`** —— 画图纸的老口令，和上一阶段一模一样，图纸里的东西照样要缩进。
- **`名字: str`** —— **名牌，冒号，再来一个它是什么类型**（`str` 是一串字，`int` 是整数）。
  ⚠️ 这一行**不是写给本喵自己看的备注**：那层特效全靠「冒号后面有东西」才认出**这行算一件东西**。冒号一丢，它就把这行当成图纸上一句闲话，压根不认你。
- **`毛色: str = "橘"`** —— 等号后面是**默认值**：生猫的时候不喂毛色，它自动填上 `橘`。所以 `猫档案("咪爱", 3)` 只喂两样也成。
- **`咪爱.年龄 = 4`** —— 这回**真的能改**了。生出来的真猫，身上的东西是可以重新给的；`namedtuple` 那种「改一处得另做一只」的麻烦，这里没有。

它顺手还替本喵办了两件小事：

```python
from dataclasses import dataclass

@dataclass
class 猫档案:
    名字: str
    年龄: int
    毛色: str = "橘"

咪爱 = 猫档案("咪爱", 3)
print(咪爱)
print(咪爱 == 猫档案("咪爱", 3))
```

```text
猫档案(名字='咪爱', 年龄=3, 毛色='橘')
True
```

- **`print(咪爱)`** 印出来的不是上一阶段那种谁也看不懂的一串住址，而是 `猫档案(名字='咪爱', 年龄=3, 毛色='橘')` —— 里面装了什么，一眼看得清（这层特效顺手把「怎么介绍自己」也写好了）。
- **`==`** 也顺手管了：两只内容一样的真猫，判 `True`。

### 图纸上还能添自己的招式

这一点是 `namedtuple` 做不到的：

```python
from dataclasses import dataclass

@dataclass
class 猫档案:
    名字: str
    年龄: int

    def 打招呼(self):
        print(f"本喵是{self.名字}，今年{self.年龄}岁喵")

咪爱 = 猫档案("咪爱", 3)
咪爱.打招呼()
```

```text
本喵是咪爱，今年3岁喵
```

- 招式照老规矩画在图纸里、**要缩进**；`self` 还是「本喵自己」，指的是正在打招呼的那一只。
- 为什么 `namedtuple` 不行？它是本喵用**一句口令临时做出来**的图纸，做出来就是个装东西的壳子，没地方添招式。`dataclass` 画的是**一张真图纸** —— 图纸上想画多少招，就画多少招喵。

## 何时请谁出场

三样东西摆在一起比一比：

| 本喵手上要干的事 | 请谁出场 | 为什么 |
|---|---|---|
| 几件东西捆成一份，**生出来就不改了**（一个坐标、一行记录） | `namedtuple` | 轻巧、改不动，按格子取和拆包的老本事也都留着 |
| 要**改**、要有**默认值**、要让它**带自己的招式** | `dataclass` | 冒号一写就成，能改能加，写得也短 |
| 只是手上临时凑一凑、用完就丢 | 元组 / 字典 | 没必要为它专门画一张图纸 |

再补一句：想要「生出来就改不动」的 `dataclass`，在特效上多写一笔就行 —— `@dataclass(frozen=True)`（`frozen` 是「冻住」的意思）。这样生出来的真猫一改就翻脸，脾气和 `namedtuple` 一样喵。

**一句话分清楚**：`namedtuple` 是「**贴了名牌的元组**」；`dataclass` 是「**自带铺床叠被的图纸**」。

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `from collections import namedtuple` | 请出做名牌元组的帮手 |
| `namedtuple("猫档案", ["名字", "年龄"])` | 做一张贴好名牌的新图纸 |
| `咪爱 = 猫档案("咪爱", 3)` | 照图纸生一只，按名牌顺序喂进去 |
| `咪爱.名字` | 点名牌取东西（`咪爱[0]` 那种老办法也行） |
| `咪爱._replace(年龄=4)` | 另做一只，只换点名的那个名牌 |
| `from dataclasses import dataclass` | 请出画数据图纸的帮手 |
| `@dataclass` | 贴在图纸头上，替本喵铺床叠被 |
| `名字: str` | 名牌加类型，冒号后面有东西才算一件东西 |
| `毛色: str = "橘"` | 带默认值，不喂就用它 |
| `@dataclass(frozen=True)` | 生出来就改不得（和 `namedtuple` 一个脾气） |

::: tip 猫咪提示
- 两样都是「**给几件东西贴名牌**」，区别在脾气：`namedtuple` 贴完**改不得**，`dataclass` 生出来**能改**。
- **`namedtuple` 三步**：请帮手 → 做图纸（第一样图纸名，第二样一排名牌）→ 按名牌顺序喂。
- **`dataclass` 三步**：`@dataclass` 贴头上 → 每件东西写成 `名牌: 类型` → 想要默认值就补上 `= 值`。
- **要改就用 `_replace`**（另做一只）；**要添招式、要默认值，就用 `dataclass`**。
- **挑谁**：不改、图轻巧 → `namedtuple`；要改、要默认值、要招式 → `dataclass`。
:::

::: warn 小心喵
- **`dataclass` 里每件东西都得有冒号和类型。** 写成 `名字 = "咪爱"` 就只是图纸上一句闲话，特效不认它 —— 喂东西给它的时候它会说「用不着」，甩你一张 `TypeError` 的纸条。
- **喂进去的顺序不能反。** `猫档案(3, "咪爱")` **不会当场报错**：它安安静静把 `3` 塞进「名字」、把 `"咪爱"` 塞进「年龄」，生出一只名字叫 `3` 的猫。冒号后面那个类型**只管认出「这算一件东西」，不替本喵检查**，喂错了得自己盯出来喵。
- **`_replace` 不会动原来那一只。** 跑完不接住，`咪爱` 还是 3 岁 —— 新做的那只得起个名字接住才算数。
:::

## 小任务

先照着这段敲一遍，把两只猫都生出来：

```python
from dataclasses import dataclass

@dataclass
class 猫档案:
    名字: str
    年龄: int

咪爱 = 猫档案("咪爱", 3)
大肥鱼 = 猫档案("大肥鱼", 8)
print(咪爱)
print(大肥鱼)
print(咪爱 == 大肥鱼)
```

```text
猫档案(名字='咪爱', 年龄=3)
猫档案(名字='大肥鱼', 年龄=8)
False
```

**试着改一改**：

1. 给图纸添一件东西 `毛色: str = "橘"`，再跑一遍 —— 只喂两样的那两处，毛色会变成什么？
2. 把做图纸那一句里的 `["名字", "年龄"]` 换成 `"名字 年龄"`（一串用空格隔开的字），跑跑看有没有区别。
3. 给 `dataclass` 那张图纸添一招 `过生日(self)`：把年龄加一，再印一句「本喵 X 岁啦」。
