## 钩子：三件「自己造很费劲」的事

本喵最近想干三件事：

1. 跟**远处另一只猫**说句话——她在别的鱼塘那边，中间隔着好几道水。
2. 画一面**自己的小旗子**：蓝底，中间一块金色的方块。
3. 把一摞小账**摆成一张表**，按项目合起来看。

这三件事，自己从头造都很费劲：头一件得懂水路上的规矩，第二件要一格一格地涂色，第三件要一本一本地翻。

好消息是：**这三件事前辈猫早就干过**，而且干完以后把成品打成了窝，摆在外面一个公共的窝库里。你只要**把它请进来**，就能直接用。

这种「别人打好、请进来就能用」的工具窝，叫**第三方库（别人打好的工具窝）**。「第三方」是说它既不是你写的，也不是 Python 自带的那一套，而是**外边**的猫写的。往后本喵只说「工具窝」喵。

## 地图上的三只窝

| 名字 | 它是干什么的 |
|---|---|
| `requests` | 隔着鱼塘传小鱼干：替你去把远处那一页纸要回来 |
| `Pillow` | 画图的能手：给你一块画布、一支笔、一盒颜色 |
| `pandas` | 摆弄表格的能手：把一摞账摆成一张表，一栏一栏地算 |

地图上只有三只，因为它们**用得最勤**；外面那个公共窝库里还躺着好多好多只，等你哪天需要了再去找。这一课的任务不是背名字，是**认清「工具窝」这种东西怎么请、怎么用**——认清了规矩，往后遇到没见过的窝你也不慌喵。

## 请回来之前，喊它是不应的

本喵先让你看一眼「没请过」是什么样子。下面这个名字（`猫粮统计`）是本喵瞎编的，世上压根没有这只窝，所以它正好是标准的「喊不应」：

```python
import 猫粮统计

print("平均每只", 猫粮统计.平均(3, 4), "条")
```

```text
Traceback (most recent call last):
ModuleNotFoundError: No module named '猫粮统计'
```

念作「**没有叫 猫粮统计 的盒子**」：翻译官喵把该找的地方都翻了一遍，没找到这个名字。

这就是规矩：**工具窝不是 Python 自带的**，不请进来就喊不应。请它进来的口令只有一句话——

```text
pip install requests
```

`pip` 是专门跑腿的猫，`install` 就是「装进来」。这条命令会去外面那个公共窝库（pip 一出生就认准的那家）把 `requests` 请回来。真跑出来是这样（挑要紧的几行抄）：

```text
Collecting requests
  Using cached requests-2.34.2-py3-none-any.whl.metadata (4.8 kB)
Installing collected packages: urllib3, idna, charset_normalizer, certifi, requests
Successfully installed certifi-2026.7.22 charset_normalizer-3.5.1 idna-3.19 requests-2.34.2 urllib3-2.8.0
```

最后一行认 `Successfully installed` 四个字，意思是「请回来了」。

请回来之后想确认一下、顺便看看请的是哪一版，可以喊：

```text
pip show requests
```

```text
Name: requests
Version: 2.34.2
```

（那些「有新版本 pip 可用」的提示不用管，跟你请的窝没关系。）

## requests：替本喵去要一页纸

请进来就能用了。本喵让它去要两页纸——一页是存在的，一页是本喵编的：

```python 需要联网
import requests

回应 = requests.get("https://example.com", timeout=15)
print("有那一页的时候：", 回应.status_code)

没有的 = requests.get("https://example.com/喵喵喵", timeout=15)
print("没那一页的时候：", 没有的.status_code)
```

> ⚠️ **这一段要联网才跑得起来**，是本课唯一一段这样的代码。
> 断网（或者网络被挡）的时候它会甩一大串 `urllib3` 的红字 ——
> **那不是你写错了**，是它真的没要到那页纸。
> 看别人报错时先分清这两件事：**「我的代码错了」和「外面的世界没给我东西」**，
> 处理方式完全不同 —— 前者改代码，后者改环境或者等一等喵。

```text
有那一页的时候： 200
没那一页的时候： 404
```

拆开看：

- **`requests.get(地址, timeout=15)`** 念作「去把这一页要回来」。第一个投喂是那一页的地址；`timeout=15` 是「**最多等 15 秒**」——对方要是装死，到点就当场撂挑子，不干等。本喵习惯**每次要纸都写上它**。
- **`回应`** 是一只装满对方回话的口袋。`回应.status_code` 里那声**状态码**是最简短的一句答复：`200` 是「好，给你」，`404` 是「你要的那页我这儿没有」。
- 这两声在所有水路里都是同一个意思，所以看别人写的窝时你也认得出：**2 打头是顺利，4 打头是你这边要错了，5 打头是对面自己坏了**。
- 要是想直接看那页纸的**内容**（不是你手边这段正文，是程序里拿到的那一串字），那是 `回应.text`——本喵这次没印它，因为它可能很长，印出来会淹没重点喵。

## Pillow：给自己画一面小旗子

第二件：画图。请的时候叫 `pip install Pillow`，可爱用的时候写的是**另一个名字** `PIL`。别慌，这不是你打错了，是这只窝的**老名字**留下的习惯——你两个都认下来就行喵。

```python
from PIL import Image, ImageDraw

画布 = Image.new("RGB", (120, 60), "skyblue")
笔 = ImageDraw.Draw(画布)
笔.rectangle([10, 10, 110, 50], fill="gold")
print("尺寸：", 画布.size)
print("色彩模式：", 画布.mode)
print("左上角那一格的颜色：", 画布.getpixel((15, 15)))
```

```text
尺寸： (120, 60)
色彩模式： RGB
左上角那一格的颜色： (255, 215, 0)
```

一行一行讲：

- **`Image.new("RGB", (120, 60), "skyblue")`** —— 造一块**画布**：`(120, 60)` 是宽 120、高 60；`"skyblue"` 是底色（天空蓝）；`"RGB"` 叫**色彩模式**，三个字母是红、绿、蓝三盏灯——屏幕上任何一个颜色，都是这三盏灯各调到多亮配出来的。
- **`ImageDraw.Draw(画布)`** —— 在画布上按一支**笔**。后面想画什么，都喊这支笔。
- **`笔.rectangle([10, 10, 110, 50], fill="gold")`** —— 画一个方块。那组数念作「左上角的横竖、右下角的横竖」；`fill="gold"` 是里面填什么颜色。你按本喵这几行跑一遍，就是那面蓝底金块的小旗子喵。
- **`画布.size`** 是「多宽多高」的一对儿，**`画布.mode`** 是色彩模式。
- **`画布.getpixel((15, 15))`** 念作「**横着数第 15 格、竖着数第 15 格，那一格是什么颜色**」。它印出 `(255, 215, 0)`——这正是金色的三盏灯亮度。
- 想改某一格，用 **`画布.putpixel((横, 竖), (颜色))`**。比如把最左上角那一格刷成纯红：

```python
from PIL import Image

画布 = Image.new("RGB", (3, 2), "gold")
画布.putpixel((0, 0), (255, 0, 0))
print(画布.size)
print(画布.getpixel((0, 0)))
print(画布.getpixel((2, 1)))
```

```text
(3, 2)
(255, 0, 0)
(255, 215, 0)
```

（`(0, 0)` 是**第一个**格子——本喵这门手艺的规矩是**从 0 开始数**，跟上一课那些屋里的编号一个脾气喵。第三行读的是最右下角那格，本喵没动过它，所以还是金色。）

## pandas：一摞账摆成一张表

第三件：摆表格。这只窝本喵**平时那只柜子里没请**——本课要跑它，所以本喵是在自己一只装了它的**工作柜**里跑的。你要是也想跑一遍，照上一课的口令把它请进你的柜子就行喵。

先把脚本原样抄给你看（它没法在这儿当普通代码块跑，因为你手边这只柜子里多半也还没请它）：

```text
import pandas as pd

表 = pd.DataFrame({
    "项目": ["小鱼干", "猫砂", "小鱼干"],
    "金额": [12.5, 30.0, 7.5],
})

print("一共", len(表), "行")
print("金额合计：", 表["金额"].sum())
print("小鱼干花了：", 表[表["项目"] == "小鱼干"]["金额"].sum())
```

本喵那只工作柜里真跑出来的结果：

```text
一共 3 行
金额合计： 50.0
小鱼干花了： 20.0
```

拆开看：

- **摆一张表**就是给每一栏起个名字（`项目` 一栏、`金额` 一栏），再把每一行的值按顺序排好。`pd` 是这只窝的**小名**——`import pandas as pd` 就是「请进来的时候顺便起个小名，往后喊 `pd` 就行」。
- 表造好以后是**整栏一起算**：`表["金额"].sum()` 一句话把一栏加起来；`表[表["项目"] == "小鱼干"]` 是「把项目写着 小鱼干 的那几行挑出来」，挑完再取 `["金额"]` 那一栏。
- 这和「一本一本地翻、绕圈一行行加」是两种活法。账少的时候手写几行更快；**账一多、还要按项目分组看**，就轮到它上场了喵。

::: tip 猫咪提示
今天记住四件事：① 工具窝**先请才能用**：`pip install 名字`；② 想看请没请、请的哪一版：`pip show 名字`；③ 请的时候和用的时候名字可能不一样（`Pillow` 请回来、`PIL` 喊出来）；④ `requests` 每次都要写 `timeout`，别干等。
:::

::: warn 小心喵
两个坑，本喵都踩过：

1. **别把柜子塞满。** 请得越多，将来换机器、或者请别的猫一起跑的时候，要照单子重装的东西就越多。**不用的就别请**——先写起来，真发现手上缺家伙事，再去请那一只。
2. **别看见报错就以为是自己拼错了名字。** 上面 `import Pillow` 这行字看着天经地义，本喵真敲下去却是 `ModuleNotFoundError: No module named 'Pillow'`——这只窝请回来了，但它**不认自己这个外号**，得用 `PIL` 喊它。遇到这种情况先去翻它的说明，别在那儿反复改自己写的名字喵。
:::
