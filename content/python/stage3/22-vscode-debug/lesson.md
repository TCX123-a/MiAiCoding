## 钩子：给代码按个暂停键

本喵上几课抓虫，靠的是一招笨功夫：`print` 大法 —— 想知道哪儿不对，就在半路印一句。小本子还行，本子一长就露怯了：想知道三个仓库的数，印三遍；换一个地方想问，再改一遍、再跑一遍。今天本喵给代码装一个**暂停键**：让它跑着跑着停在半路，那一刻**所有仓库都摊在面前**，想看谁看谁，代码一个字都不用改。

考试卷子上，这件事的正式名字叫调试（抓虫）—— 抓的就是那只看不见的捣乱小虫。工具用 VS Code，本喵带你认它抓虫档里最值钱的几样。

## 一、print 大法的三个尴尬

先把老功臣摆好。`print` 大法不是不行，是真有三处尴尬喵：

1. **想得好，才问得对**：print 只能印你**提前猜到**的那个名字。猜歪了，印一屏废话，想要的那个数还是没露面；
2. **改一次问一次**：每换一个问题，就得改本子、重跑一遍。问题一多，本子被改得花花绿绿；
3. **印完还得记得擦**：抓完虫，那些 print 得一根一根拔掉，漏拔一行，正式出结果的时候它就给你添乱。

断点把这三样一次摆平：**停在半路，问在当场** —— 不用提前想、不用改本子、不用事后擦。

## 二、开工前的两件准备

1. **装 Python 扩展**：VS Code 刚装好时只认识它自己的界面，不认识蟒蛇。打开左边边栏的 Extensions（扩展）面板，搜 `Python`，认准发布者那栏写着 **Microsoft** 的那个，装上。
2. **用「打开文件夹」的方式打开窝**：别把单个本子拖进去。VS Code 得知道「整个窝在哪儿」，抓虫档才找得到能用的翻译官喵。（窝里那间 `.venv` 屋它会顺手认出来，替你选屋里那台 —— 上一课刚学的屋，在这儿派上用场了。）

第一次按 F5 开跑时，它会停下来问「用哪种方式跑」：选 **Python File**。它顺手在窝里放一份 `.vscode/launch.json` —— 那是它记下的出发姿势，以后就不问了。

## 三、第一颗红点：断点

想按暂停键，就在行号左边点一下：**冒出一颗红色小圆点 = 断点**（键盘党：光标停在那一行按 F9，一样的效果）。

- **F5 开跑**：程序不会一路冲到底 —— 走到红点这一行就**停下**，等你；
- 停下那一刻最要紧的一条：**红点那一行还没执行**。想让它在执行前把家底亮出来，就是现在；
- 跑起来以后菜单上冒出一小排按钮：继续、单步、重启、停。**F5 = 继续**，冲下一个红点（没有下一个，就跑到底）；
- **Shift+F5 = 收工**，不跑了；
- 红点可以下好几颗、下在不同的行；不想要了，行号左边再点一下，红点就没了。

停下的时候，左边那栏会变成三块小地方，本喵最常翻的是：

| 小地方 | 里面装的 |
|---|---|
| Variables | **此刻所有仓库的名字和它们的值** —— 不用提前想好看哪个，全摆着 |
| Watch | 你**自己贴上去**的名字 —— 盯住不放的那几个，每走一步都跟着更新 |
| Call Stack | 「谁把谁喊进来的」那一串 —— 现在停在哪一招里、它是被谁喊来的 |

（Variables 里那条黄箭头，指着「就要执行的那一行」—— 跟红点那颗还没走到的行，是同一行。）

## 四、单步的三种走法

停下来只是开始，**一行一行往前走**才是抓虫的正戏。停住之后：

| 按键 | 名字 | 干什么 |
|---|---|---|
| F10 | Step Over（跨过去） | **整行一次走完** —— 这行里喊了别的招式，也不钻进去看 |
| F11 | Step Into（钻进去） | 钻进这行喊的那招里，**从它的第一行接着走** |
| Shift+F11 | Step Out（跳出来） | 这招看够了，**一把跳回喊它的地方** |
| F5 | 继续 | 不一行一行看了，直接冲下一个红点／跑到头 |

口诀八个字：**跨过去、钻进去、跳出来。** 大多数时候用 F10 一行行过；怀疑小虫藏在某招里面，就 F11 钻进去看一眼。

## 五、现场：一只少算了一只的小虫

本喵的小机器猫开始卖鱼干套餐了：**第 1 只装记 10 分、第 2 只记 20 分、第 3 只记 30 分**……4 只装该收 100 分，账上却只有 60 分。先上 print 大法：

```python
def 算总价(几个):
    总 = 0
    for 几号 in range(1, 几个):
        总 = 总 + 几号 * 10
        print(" 几号是", 几号, "总变成", 总)
    return 总


print("4 个装的总价：", 算总价(4))
```

```text
 几号是 1 总变成 10
 几号是 2 总变成 30
 几号是 3 总变成 60
4 个装的总价： 60
```

信息是有了：几号 走的是 1、2、3 —— **4 压根没轮到**。可是等等喵：这是本喵**提前猜到「该盯 几号」**，才加的那句 print。要是想知道的偏偏是「总 每一圈怎么爬的」「几个 是不是真的 4」呢？每换一个问法，就得改一遍本子、再跑一遍 —— print 大法是问一句答一句，问题得自己先猜对。

逮住病根，改一个地方：

```python

    for 几号 in range(1, 几个 + 1):

```

::: tip 猫咪提示
print 和断点不是对手，是**分工**喵：

- **确认一句小问题**（「走到这儿了吗」「这个数是几」）：print 最快，一行搞定，用完即擦；
- **话说不清的问题**（「它为什么少算一只」「这一串到底怎么走的」）：上断点。停在半路，问在当场，想问几个问几个。

一句话记：**print 是喊一嗓子，断点是按暂停键。** 喊嗓子方便，暂停键能看清。
:::

## 小任务

1. 把第五节那段「算总价」的坏版本抄进自己的屋，在第 3 行下一颗红点，按 F5 停住，再连按 F10，盯着 Variables 里 几号／总 怎么走 —— 走完数一数：到它跳去 return，一共按了几下？
2. 给同一段再下第二颗红点（下在 `return 总` 那行），跑一遍：看看两次停下时，仓库里的数各是什么。
3. 试一试 Watch：暂停时把 总 贴进 Watch 名单，接着按 F10 —— 它是不是每一步都跟着更新？（再想想：这跟「改一句 print 再跑一遍」比，省了哪几步？）
4. 想一个问题：为什么「断点停下时，红点那一行还没执行」这件事很要紧？（提示：要是它先执行了，你想看的「执行前那个数」还在不在？）

这一课给代码装上了暂停键：断点停、F10 一行行过、F5 冲下一个、Variables 里仓库全摊开。跟 print 大法搭着用，抓虫这件事就从「猜着问」变成了「看得见」喵。🐾
