## 钩子：招式都会了，可本喵要的是一本账本

这几个月本喵攒了一窝招式：分鱼干的、记时间的、隔着鱼塘说话的、写体检单的……单拎出哪一样都会用。

可本喵真正想要的，是**一样东西**：一本能用的记账本。

要求说清楚就是四条：

1. 一笔账得有个**确定的样子**（项目、金额）。
2. 记下来的账**不能程序一关就没了**。
3. 能按项目把账**合起来看**。
4. 能印一张清清爽爽的**报表**出来。

今天**不学新招式**——今天学的是怎么把已经会的招，摆成一件干活的家伙事喵。

## 第一块砖：一笔账长什么样

先给「一笔账」定个样子：

```python
from dataclasses import dataclass

@dataclass
class 一笔账:
    项目: str
    金额: float

a = 一笔账("小鱼干", 12.5)
b = 一笔账("猫砂", 30.0)
print(a)
print(a == 一笔账("小鱼干", 12.5))
print(a.金额 + b.金额)
```

```text
一笔账(项目='小鱼干', 金额=12.5)
True
42.5
```

拆开看：

- **图纸上只写了两栏**：`项目` 和 `金额`。一笔账就这两样，多一样都没有。
- **`@dataclass`** 是挂在图纸头上的一层**特效**。你只管把两栏写上，剩下的它替你办：造的时候把两样收好、**印出来是好看的样子**、**两笔内容一样的账能比出「相等」**。
- 这三件事真是它办的吗？本喵**把特效摘掉又跑了一遍**做对照：不挂 `@dataclass` 的时候，`print(a)` 印出来的是一串带着地址的怪样子（那串地址每次都不同，本喵就不抄了），`a == 一笔账("小鱼干", 12.5)` 答的是 `False`——**内容一模一样，却判「不相等」**。所以上面那三行输出，全是这层特效挣来的喵。
- 这层特效有个正式名字叫**装饰器（给招式加特效）**。往后你看见谁家本子头上顶着 `@` 开头的字，那就是在上特效。

## 第二块砖：把账留在磁盘上

**这是本课最要紧的一块砖。**

程序跑着的时候，收好的账住在临时屋里；程序一停，那间屋就拆了，账全没。想让账**留下**，就得把它写到你磁盘上的一个**真文件**里。

两条路，本喵都跑给你看。

**第一条：写成一页纸。**

```python
import json, os, tempfile

账本 = [{"项目": "小鱼干", "金额": 12.5}, {"项目": "猫砂", "金额": 30.0}]
路径 = os.path.join(tempfile.mkdtemp(), "账本.json")
with open(路径, "w", encoding="utf-8") as f:
    json.dump(账本, f, ensure_ascii=False)

with open(路径, encoding="utf-8") as f:
    读回来 = json.load(f)
print("一共", len(读回来), "笔")
print("第一笔是", 读回来[0]["项目"], 读回来[0]["金额"], "元")
```

```text
一共 2 笔
第一笔是 小鱼干 12.5 元
```

- **`json.dump(东西, f)`** 是「把这摞东西**摆成能写进纸里的样子**，写进去」；**`json.load(f)`** 是反过来，把纸上的字**读回成东西**。一写一读之间，程序就算关掉再开，账也还在。
- **`ensure_ascii=False` 千万别漏。** 本喵真跑过对照：漏了它，写进纸里的中文会变成一串「反斜杠 u 后面跟四个数字」的记号——读回来照样没错，可你用记事本打开那页纸，就一个字都认不出来了喵。
- `open(路径, "w", encoding="utf-8")` 里那个 `"w"` 是「**写**」；读的时候用 `"r"`（不写也行，默认就是它）。`encoding="utf-8"` 是让中文照原样进出，别乱码。

**第二条：塞进小账柜。**

```python
import sqlite3

连接 = sqlite3.connect(":memory:")
连接.execute("CREATE TABLE 账本 (项目 TEXT, 金额 REAL)")
连接.executemany("INSERT INTO 账本 VALUES (?, ?)", [("小鱼干", 12.5), ("猫砂", 30.0), ("小鱼干", 7.5)])
连接.commit()

几笔 = 连接.execute("SELECT COUNT(*) FROM 账本").fetchone()[0]
总数 = 连接.execute("SELECT SUM(金额) FROM 账本").fetchone()[0]
print("一共记了", 几笔, "笔")
print("总共花了", 总数, "元")
连接.close()
```

```text
一共记了 3 笔
总共花了 50.0 元
```

- **`sqlite3`** 是 Python 自带的**小账柜**，不用请。`sqlite3.connect(":memory:")` 是「开一只只在程序跑着时存在的柜子」——本喵这儿只是为了跑给你看；真用的时候把那句换成 `sqlite3.connect("账本.db")`，它就是一个**磁盘上的真文件**了。
- **`连接.execute("CREATE TABLE 账本 (项目 TEXT, 金额 REAL)")`** 是**先给柜子立好格子**：一格叫「项目」放字，一格叫「金额」放小数。格子立好了才能往里放东西。
- **`INSERT INTO 账本 VALUES (?, ?)`** 念作「**往里塞一行**」。那两个问号是**留的空位**，后面那摞值按顺序填进去——用空位比把值直接拼进句子里安全得多，本喵习惯一律这么写喵。
- **`连接.commit()`** 是**拍板**：到这一句，前面塞的东西才真的落定。
- **`execute("SELECT ...")`** 是**问柜子要东西**：`COUNT(*)` 问「一共几笔」，`SUM(金额)` 问「加起来多少」，`fetchone()[0]` 是把答复里那一格取出来。

**挑哪条？** 本喵的用法是：账少、还想用记事本打开看看、或者要发给别的猫，就写成一页纸；账会**越记越多**、还要随时挑着看和合计，就立一只账柜。这一课的账本，本喵挑了账柜喵。

## 第三块砖：印一张报表

最后一块：把账**念成人看得懂的样子**。

```python
记录 = [("小鱼干", 12.5), ("猫砂", 30.0), ("小鱼干", 7.5)]

按项目 = {}
for 项目, 金额 in 记录:
    按项目[项目] = 按项目.get(项目, 0) + 金额

for 项目, 小计 in sorted(按项目.items()):
    print(f"{项目}：{小计:.2f} 元")
print(f"合计：{sum(按项目.values()):.2f} 元")
```

```text
小鱼干：20.00 元
猫砂：30.00 元
合计：50.00 元
```

- 头几行是把同一个项目的账**并到一起**：`按项目.get(项目, 0)` 念作「**有就拿出来，没有就当 0**」——所以第一次见到某个项目也不用先打招呼，直接加就行。
- `sorted(按项目.items())` 是**按项目名字排好队**再印，所以每次跑出来的顺序都一样，看着不会跳。
- `f"{项目}：{小计:.2f} 元"` 里，`f` 开头的一串字**花括号里可以放东西**，翻译官喵会把它们算好、塞进那句话里；`:.2f` 是「**留两位小数**」——`20.0` 会印成 `20.00`，这是钱的写法，看着才像账喵。

## 拼起来：一本能用的记账本

三块砖凑齐了。本喵把它们拼成一本真的账本——**一段完整的、能直接跑的程序**：

```python
import os, sqlite3, tempfile
from dataclasses import dataclass

@dataclass
class 一笔账:
    项目: str
    金额: float

class 账本:
    def __init__(self, 路径):
        self.连接 = sqlite3.connect(路径)
        self.连接.execute("CREATE TABLE IF NOT EXISTS 账本 (项目 TEXT, 金额 REAL)")

    def 记一笔(self, 账):
        self.连接.execute("INSERT INTO 账本 VALUES (?, ?)", (账.项目, 账.金额))
        self.连接.commit()

    def 全部(self):
        return [一笔账(项目, 金额) for 项目, 金额 in self.连接.execute("SELECT 项目, 金额 FROM 账本")]

    def 按项目合计(self):
        小计 = {}
        for 账 in self.全部():
            小计[账.项目] = 小计.get(账.项目, 0) + 账.金额
        return 小计

路径 = os.path.join(tempfile.mkdtemp(), "账本.db")
本子 = 账本(路径)
本子.记一笔(一笔账("小鱼干", 12.5))
本子.记一笔(一笔账("猫砂", 30.0))
本子.记一笔(一笔账("小鱼干", 7.5))
本子.连接.close()

本子2 = 账本(路径)
print("重新打开，一共", len(本子2.全部()), "笔")
for 项目, 小计 in sorted(本子2.按项目合计().items()):
    print(f"{项目}：{小计:.2f} 元")
print(f"合计：{sum(本子2.按项目合计().values()):.2f} 元")
```

```text
重新打开，一共 3 笔
小鱼干：20.00 元
猫砂：30.00 元
合计：50.00 元
```

两处值得你多看两眼：

- **`本子.连接.close()` 之后又开了一本新的（`本子2`），账还是三笔。** 这就是「把账留在磁盘上」的样子——本喵这儿是在同一段程序里演示的；真用的时候，程序退出、第二天再打开，走的就是这一步。
  （`CREATE TABLE IF NOT EXISTS` 那句里的 `IF NOT EXISTS` 念作「**没有才立**」：第二回连同一个文件时，格子已经立过了，这句就轻轻放过，不会报错喵。）
- **报表和账本互不认识。** 账本只管收账、记账、算合计；报表只管拿到一摞账、念给人听。将来你想把报表改成印在网页上，改的只是报表那一块，账本一个字都不用动。

::: tip 猫咪提示
今天记住四件事：① 一笔账先**定个样子**（`@dataclass` 那张图纸上只写两栏），样子定下来，别处才好用它；② 想让账留下，就得**写进磁盘上的真文件**——一页纸（`json`）或者小账柜（`sqlite3`）都行；③ 钱印出来要**留两位小数**（`:.2f`），看着才像账；④ 拼装的时候让每块砖**只管一件事**，将来改一处才不用动十处。
:::

::: warn 小心喵
两个坑，本喵都替你标出来：

1. **`commit()` 别漏。** 账塞进去了却没拍板，程序一关，那几笔就白塞了——而且**它不会报错**，你只会觉得「本喵明明记过啊」。这类不声不响的坑最费时间。
2. **别把「读回来」当成「原样」**。写进纸里的是**字**，读回来的是照着那些字重新摆出来的东西；数字还是数字、字还是字，可要是你塞进去的是别的东西（比如一张图纸生出来的真猫），一页纸会当场撂挑子。本喵真跑过：把一笔账直接递给 `json.dumps`，它当场回一句 `TypeError: Object of type 一笔账 is not JSON serializable`——念作「**这种东西本喵摆不进纸里**」。**存简简单单、一笔一笔的账最稳**喵。
:::

本喵给你留两个：

1. 给这账本加一个本事：**把最后一笔删掉**。（提示：小账柜那边有 `DELETE`；写完别忘了拍板。）
2. 把**报表那一块**改一改：多印一行「一共几笔」，合计那行的说法也换成你喜欢的。改完跑一遍，看看是不是**只动了报表这一块**，别的都没碰——这就是「每块砖只管一件事」挣来的舒服。
