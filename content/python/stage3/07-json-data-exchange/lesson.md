## 钩子：这份清单，鱼塘那头的猫读得懂吗？

本喵的名牌格子柜里记着一份清单：小橘 2 条、狸花 1 条、三花 3 条。本喵自己看当然方便。

可要是本喵想把这份清单**寄给鱼塘那头的猫**，或者**存进抽屉里**、明天再拿出来呢？

麻烦来了：本喵这套「名牌格子柜」的摆法，是 Python 才认的。鱼塘那头的猫可能用的是别的语言、别的软件，人家看到本喵的格子柜只会歪着头 —— 就像你把猫粮碗端给一条鱼，它不知道那是干什么用的喵。

所以猫猫们开会，定了一份**通用快递单**：不管你是哪门语言、哪只猫写的，照着这份格式写的纸条，**谁都读得懂**。它的名字叫 **JSON**。本喵今天要教你的，就是怎么在 Python 里**装箱**、**拆箱**这张纸条。

## JSON：一张所有猫都认的快递单

JSON 的规矩少得可怜，一只手数得过来：

- 一盒**贴了名牌的格子**，用一对**大括号**括起来：`{"小橘": 2}`。左边是名牌，右边是东西，中间一个冒号。
- 名牌**必须**用**双引号**包起来 —— 单引号它不认，这一点等会儿你会亲眼看到它翻脸。
- 好几格之间用**逗号**隔开：`{"小橘": 2, "狸花": 1}`。
- 格子里的东西可以是数字（`2`）、真假（`true` / `false`）、空（`null`）、一句话（`"小鱼干"`，也用双引号包着）、一盒更小的格子（`{"名字": "小鱼干"}`），或者一排贴了编号的猫粮碗（`[1, 2, 3]` 这种用方括号括起来的一排格子）。

就这些。它简单到这个地步，正是因为**越简单的东西，越是谁都读得懂** —— 这就是「数据交换」四个字的意思：两样不同的东西之间递话，得挑一种**双方都认**的说法喵。

## 装箱：`json.dumps`

Python 里管快递单的那盒工具就叫 `json`，请它进屋只写一句 `import json`。

「把格子柜里的东西搬进一张纸条」这个动作，书上叫**序列化**，本喵喜欢叫它「**装箱**」。装箱的招式叫 `dumps`：

```python
import json

零食 = {"名字": "小鱼干", "数量": 3}
print(json.dumps(零食))
print(json.dumps(零食, ensure_ascii=False))
```

```text
{"\u540d\u5b57": "\u5c0f\u9c7c\u5e72", "\u6570\u91cf": 3}
{"名字": "小鱼干", "数量": 3}
```

两行只差一个小开关，印出来的东西却完全不一样：

- **第一行**：`json.dumps(零食)` 把格子柜变成了一张纸条，可「名字」两个字变成了 `\u540d\u5b57`、「小鱼干」变成了 `\u5c0f\u9c7c\u5e72`。这是**转义写法**：每个中文字都被记成了它自己的编号，写成 `\u` 加四位十六进制。纸条本身没错，只是**人看着费劲**。
- **第二行**：多喂了一个 `ensure_ascii=False`，中文就原样印出来了。`ensure_ascii` 读作「保证只用 ASCII 那一小撮英文符号」，把它关掉（写成 `False`），它就不再把中文换成编号。

✨ **这一点本喵要重重画一道线**：`ensure_ascii=False` 写不写，**屏幕上的字长得完全不一样**。以后你照着课文对答案，或者打开别人给的 JSON 文件看到满屏 `\u` 开头的密码，都是这一个小开关在起作用 —— 那不是坏了，是**默认就这么办**喵。

::: tip 猫咪提示
`json.dumps` 交回来的东西，是**一张纸条**（一串小鱼干穿成的项链），不是格子柜了。你可以 `print` 它、可以把它写进抽屉、可以顺着网线寄出去 —— 但**不能**再拿它当格子柜使：纸条不认名牌，`纸条["名字"]` 会当场出错。想再按名牌取东西，得先**拆箱**喵。
:::

## 拆箱：`json.loads`

反过来，把纸条搬回格子柜，叫**反序列化**，本喵叫它「**拆箱**」。招式是 `loads`：

```python
import json

纸条 = '{"名字": "小鱼干", "数量": 3}'
零食 = json.loads(纸条)
print(零食["名字"])
print(零食["数量"])
```

```text
小鱼干
3
```

拆开看喵：

- 第一行，纸条在 Python 里是一串字符，本喵用**单引号**把它包起来 —— 这样里面那些**双引号**才能原样留着当内容。要是外面也用双引号，两对引号会打起来，这句话写到一半就断了。
- `json.loads(纸条)` 把这张纸条**读回成格子柜**：`零食` 又变回一个能按名牌喊名字的格子柜了。
- 所以 `零食["名字"]` 能喊出「小鱼干」，`零食["数量"]` 能喊出 `3`。**拆箱之后，它跟本喵从头建一个格子柜没有半点区别。**

到这儿，装箱（`dumps`）、拆箱（`loads`）一对就齐了。这里的 **`s` 是对纸条的** —— 记住这句，下面的抽屉那一对就好记了。

## 纸条上写着小写的真假与 null

有一件事容易看花眼。本喵亲手写一张纸条交给 Python 拆：

```python
import json

纸条 = '{"全屏": false, "音量": 8, "备注": null}'
设置 = json.loads(纸条)
print(设置)
print(设置["全屏"])
print(设置["备注"])
```

```text
{'全屏': False, '音量': 8, '备注': None}
False
None
```

- 纸条（JSON）上写的是**小写**的 `false` 和 `null`；拆箱回到 Python，它们就变成我们熟悉的大写 `False` 和 `None`。反过来也一样：Python 的 `True` / `False` / `None` 出门上纸条，一律写成小写的 `true` / `false` / `null`。
- 顺带盯一眼第一行输出：`print(设置)` 印出来的是**格子柜本来的样子** —— 名牌没包引号、每一项之间是**单引号**。而 `dumps` 印出来的是**纸条的样子**，一律**双引号**。两个东西都摆在屏幕上时，一眼就能分清手里拿的是哪一个喵。

## 取出来的顺序：放入顺序

```python
import json

清单 = {"小橘": 2, "狸花": 1, "三花": 3}
print(json.dumps(清单, ensure_ascii=False))
print(json.dumps(清单, ensure_ascii=False, sort_keys=True))
```

```text
{"小橘": 2, "狸花": 1, "三花": 3}
{"三花": 3, "小橘": 2, "狸花": 1}
```

- **第一行**：按本喵**放进去的顺序**印 —— 先放小橘就印小橘，再放狸花就印狸花。Python 3.7 起，格子柜的「放入顺序」是**写在语言保证里的**：你按什么次序放，它就按什么次序取，不会时灵时不灵。
- **第二行**：多写了 `sort_keys=True`（给名牌**排排坐**），名牌就按**它们自己的字符编号**重排，于是「三花」跑到了最前面。注意它比的是字符的编号，跟拼音、跟笔画都没关系 —— 别拿拼音去猜它的次序喵。

这两条路都是**确定的**：不写 `sort_keys` 就是放入顺序，写了就照字符编号排，跑一百遍都一样。所以你照着课文对答案，一定对得上喵。

## 存进抽屉：配置文件

JSON 最日常的用处，是**把设置存进一个文件里**，下次打开软件再读回来 —— 这种文件就叫**配置文件**。一个 `{"音量": 8}` 存进去，就是一个最简单的配置文件了。

先看「给人读」的写法，多喂一个 `indent=2`，纸条就一格一行、缩进两格，整整齐齐：

```python
import json

设置 = {"音量": 8, "主题": "鱼塘蓝", "全屏": False}
print(json.dumps(设置, ensure_ascii=False, indent=2))
```

```text
{
  "音量": 8,
  "主题": "鱼塘蓝",
  "全屏": false
}
```

再看真正存进抽屉、再读回来的整套动作：

```python
import json

设置 = {"音量": 8, "主题": "鱼塘蓝"}

with open("设置.json", "w", encoding="utf-8") as 文件:
    json.dump(设置, 文件, ensure_ascii=False)

with open("设置.json", encoding="utf-8") as 文件:
    读回来的 = json.load(文件)

print(读回来的)
print(读回来的["主题"])
```

```text
{'音量': 8, '主题': '鱼塘蓝'}
鱼塘蓝
```

逐句拆：

- `with open("设置.json", "w", encoding="utf-8") as 文件:` —— 打开（没有就新建）一个叫 `设置.json` 的抽屉。`"w"` 是「我要往里**写**」，`encoding="utf-8"` 是「按能装中文的写法存」。`as 文件` 给这个抽屉起个名字，缩进里那几行都对着它干活，出了这一段它自己会关好 —— 这一招你以前见过，今天照抄就行。
- `json.dump(设置, 文件, ensure_ascii=False)` —— 注意这里**没有 s**！`dump` 要两样东西：一个格子柜、一个抽屉。它把格子柜直接装进抽屉，**不把纸条交给你**。
- `json.load(文件)` —— 从抽屉里拆箱回来，同样**没有 s**。

一句话记牢：**带 s 的对纸条，不带 s 的对抽屉。**

::: warn 小心喵
三个最容易踩的坑：

- **忘了 `ensure_ascii=False`**：中文全变成 `\u5c0f\u9c7c\u5e72` 这种密码。它不是坏了，是默认就这么办。
- **`dump` 和 `dumps` 写反**：`dumps` 只要一个格子柜，`dump` 还要你再给一个抽屉。写成 `json.dump(零食)` 少给一个抽屉，翻译官喵会说你少喂了它一样东西。
- **纸条上拿单引号包名牌**：`{'小橘': 2}` 在 Python 里是个合法的格子柜，但它**不是**一张合法纸条 —— 纸条上的名牌必须用双引号。
:::

## 坏纸条会长什么样

要是纸条上写的根本不是一张合法快递单，`loads` 会当场犯难。本喵这儿有两张坏纸条。

第一张：光秃秃三个中文字。

```python
import json

零食 = json.loads("小鱼干")
```

翻译官喵当场犯难：

```text
Traceback (most recent call last):
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```

一张合法纸条，要么是 `{...}`、要么是 `4`、要么是 `"小鱼干"`（**自己带上双引号**）—— 光秃秃三个字什么都不算，它只好说自己「Expecting value」：**在等一个值**。

第二张：名牌用单引号包着。

```python
import json

零食 = json.loads("{'小橘': 2}")
```

```text
Traceback (most recent call last):
json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
```

这句话翻译过来很直白：「**名牌要用双引号包起来**」。它没有生气，只是不认单引号喵。

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `import json` | 请出管纸条的那盒工具 |
| `json.dumps(格子柜)` | **装箱**：格子柜 → 一张纸条 |
| `json.dumps(格子柜, ensure_ascii=False)` | 装箱，中文原样印，不变 `\u` 密码 |
| `json.dumps(格子柜, sort_keys=True)` | 装箱，名牌按字符编号排排坐 |
| `json.dumps(格子柜, indent=2)` | 装箱，一格一行、缩进两格，给人读 |
| `json.loads(纸条)` | **拆箱**：一张纸条 → 格子柜 |
| `json.dump(格子柜, 抽屉)` | 装箱，直接装进抽屉（不带 s） |
| `json.load(抽屉)` | 拆箱，直接从抽屉里读（不带 s） |
