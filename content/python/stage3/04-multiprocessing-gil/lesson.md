## 钩子：鱼塘里摆着两条鱼，本喵却只能抓一条

今天的鱼塘里摆了两条肥美的大肥鱼，一手一条，多痛快喵！本喵伸出爪子才发现：**爪子上拴着一根看不见的绳，绳的另一头只有一枚金铃铛**。谁摇到铃铛，谁才能下水抓鱼 —— 铃铛只有一枚，所以同一时刻，**只有一只猫抓得到**。

上一课本喵叫来了好几只猫一起干活，场面挺热闹。可奇怪的是：**让它们一起算鱼干的时候，一点都没变快**。它们排着队摇铃铛，摇到的那只算一条，没摇到的只能干瞪眼喵。

今天本喵就把这件事讲透：这枚铃铛到底是什么规矩、它什么时候会松手、以及**真想同时抓两条鱼，该怎么办**。

## 一、金铃铛：同一时刻只有一只猫拿得到

Python 的代码不是直接喂给电脑的，中间站着**翻译官喵**：你写的每一句，都由它一句一句翻着往下执行。

这位翻译官喵脖子上挂着一枚**金铃铛**，它有个死规矩：

> **同一时刻，只允许一只猫摇着铃铛执行 Python 代码。**

这枚铃铛的正式名字叫 **GIL**，本喵平时就叫它「翻译官喵脖子上的金铃铛」，更好记喵。

那么问题来了：上一课叫来的那好几只猫，岂不是白叫了？**不是的喵** —— 因为铃铛会**松手**：

| 猫正在干什么 | 手上有铃铛吗 | 叫上一队猫有用吗 |
|---|---|---|
| 算鱼干（纯 Python 的加加减减、拼字、绕鱼干跑圈） | 一直攥着不放 | 没用，只是排更长的队 |
| 等外面回话（等鱼塘回信、等文件读完、等你敲键盘） | 主动放下 | 有用，别的猫正好接手 |

所以一句话记住：**好几只猫一起干活，擅长「等」，不擅长「算」。** 你要下载十张图、要同时问十个网站，叫上一队猫正合适；你要把十亿条鱼干的重量加起来，叫再多猫也只是排更长的队喵。

::: tip 猫咪提示
铃铛只有一枚 = 同一时刻只有一只猫在跑 Python 代码。所以「叫了猫却还是在排队」**不是你写错了**，是规矩本来就长这样。真想同时算，得换一招 —— 多开几只猫。
:::

## 二、多开一只猫：进程是什么

「多开一只猫」的正式名字叫**进程**。它不是「叫原来那只猫多干一份活」，而是**重新养出一只全新的猫**：

- 它有**自己的小鱼干仓库**（内存）—— 你仓库里的东西它看不见，它仓库里的你也看不见；
- 它有**自己的翻译官喵、自己的金铃铛** —— 所以两只猫能**真正同时**跑代码，谁也不用排队；
- 但它出生**要花时间**：在 Windows 上，新猫是「照着你的剧本重新出生一次」。

Python 给这招配了一整个工具箱：`multiprocessing`。最朴素的用法是 `Process`：把要干的活（招式）和要喂进去的小鱼干（写在 `args` 里）交给它，再喊一声 `start()`，新猫就出发了。

### 先看一件事：新猫的仓库是它自己的

```python
from multiprocessing import Process, Queue

fish = ["大肥鱼"]


def add_one(queue):
    fish.append("小鱼干")
    queue.put(len(fish))


if __name__ == '__main__':
    queue = Queue()
    p = Process(target=add_one, args=(queue,))
    p.start()
    p.join()
    print(f"新猫的仓库里有 {queue.get()} 条")
    print(f"本喵的仓库里有 {len(fish)} 条")
```

```text
新猫的仓库里有 2 条
本喵的仓库里有 1 条
```

新猫往它自己那间仓库里塞了一条小鱼干，塞完数出来是 2 条；而本喵这边还是孤零零的 1 条大肥鱼 —— **两间仓库，各数各的**。

这就带出一个要紧的后果：新猫算出来的东西，父猫**拿不到**。想拿，就得让新猫**主动递出来**：这里用的是「排队领小鱼干」的那个筐（`Queue`）—— 新猫把成果 `put` 进筐里，父猫伸手 `get` 出来。这个筐，就是两只猫之间最常用的那条通道喵。

### 保护罩：`if __name__ == '__main__':`

上面那段代码里，开猫的台词被关在一层保护罩里。**这层保护罩在 Windows 上是必须的**：

新猫是「照着你的剧本重新出生」的 —— 它一出生，会**把剧本从头念一遍**。要是「开一只新猫」的台词留在保护罩**外面**，新猫念到那一句，就会**再开一只**；翻译官喵只好当场拦住你，甩你一句 `RuntimeError`，告诉你「还没准备好就又要开新猫」。

::: warn 小心喵
凡是多开猫的代码，**开猫的台词一律放进 `if __name__ == '__main__':` 里面**。这不是客套话，是硬规矩 —— 漏了它，程序在 Windows 上一跑就翻脸喵。
:::

## 三、三只猫一起剥鱼，父猫统一报数

来把三只猫派出去干同一件活，再让父猫把成果收回来：

```python
from multiprocessing import Process, Queue


def peel(queue, index, count):
    queue.put((index, f"第 {index} 条鱼，剥了 {count} 片"))


if __name__ == '__main__':
    queue = Queue()
    jobs = []
    for i in range(1, 4):
        p = Process(target=peel, args=(queue, i, i * 2))
        jobs.append(p)
        p.start()
    for p in jobs:
        p.join()
    results = [queue.get() for _ in jobs]
    for index, line in sorted(results):
        print(line)
```

```text
第 1 条鱼，剥了 2 片
第 2 条鱼，剥了 4 片
第 3 条鱼，剥了 6 片
```

一句一句看：

- `jobs.append(p)`：把派出去的每只猫都记在名单上，等会儿好挨个等它回家；
- `p.start()`：新猫出发，去干自己的那一份；
- `p.join()`：父猫**在这里等**这只猫干完。名单上有几只，就等几次；
- `results = [queue.get() for _ in jobs]`：从筐里把三份成果挨个接出来；
- `sorted(results)` 再 `print`：**最要紧的一句**。三只猫谁先剥完谁先扔筐，**到达的先后每次都不一样**；父猫把它们按编号排好队再统一印，所以这段程序**跑到哪儿都是这三行**。

::: tip 猫咪提示
多开猫的程序，**让父猫负责印**：新猫只把成果递出来，别让它们自己 `print`。谁先印谁后印，是猫手快慢的运气；而你想要的，是一份**每次都一样**的输出喵。
:::

## 四、一池子猫：`Pool` 更省事

每只猫都亲手 `start`、再亲手 `join`，养十只就要写十条，累不累喵？`multiprocessing` 里有个更省事的家伙：**猫池 `Pool`**。你先告诉它「本喵要几只猫」，它一次养好，有活就派一只去，派完回来接着用。

```python
from multiprocessing import Pool


def square(n):
    return n * n


if __name__ == '__main__':
    pool = Pool(3)
    results = pool.map(square, [1, 2, 3, 4])
    pool.close()
    pool.join()
    for value in results:
        print(value)
```

```text
1
4
9
16
```

`pool.map(招式, 一筐活)` 的意思是：把筐里的东西挨个喂给这只招式跑一遍，**结果按你给进去的顺序原样还给你**。哪怕池子里三只猫是同时开工的，交回来照样整整齐齐 —— 第 1 个进去的，永远是第 1 个出来。

最后那两句是收工：`close()` 告诉池子「活派完了，不再接新活」，`join()` 等所有猫回窝。**别漏了它们** —— 不过漏了的下场，和本喵原先写的不一样，真量过才知道：

- 父猫**不会一直等**。把这两句删掉跑这段，程序 **435 毫秒**就收工了（现代翻译官喵给池子挂了个「收摊」的钩子，程序一结束就把池子整个掀掉）。那要是活儿正干到一半呢？本喵又量了一遍：派一只猫去干两秒的活、不等结果、也不写这两句 —— 进程 **286 毫秒**就走人，那只猫**被一起带走**，干的活全白费（本喵让它把结果写进一个文件，跑完去看，**文件压根没出现**）。
- 所以真正该记的是：**不写 `close()` / `join()`，程序不会等你，它是把正干活的猫连窝一起端走。** 眼下这段看不出毛病，只因为 `pool.map(...)` 那一句自己会等到结果齐了才往下走；等哪天你不等结果、让猫在后台慢慢干，这笔账就找上来了喵。

## 五、进程 vs 好几只猫一起干活（线程）

把两种「多叫帮手」的路子摆在一起看个明白：

| 比一比 | 好几只猫一起干活（线程） | 多开几只猫（进程） |
|---|---|---|
| 小鱼干仓库 | 挤在同一间，谁都能伸手（要抢，得加锁） | 每只一间，互不打扰 |
| 能真同时算吗 | 不能，金铃铛只有一枚 | 能，每只猫有自己的铃铛 |
| 出生开销 | 轻，喊一嗓子就来 | 重，得照着剧本重新养一只 |
| 成果怎么回去 | 不用递，同一间仓库里放着就行 | 得打包递（用筐 `Queue`，或写进战利品里叼回来） |
| 一只猫栽了 | 整屋都遭殃 | 只倒那一只 |
| 最擅长 | 等回信：下载、问网站、读文件 | 算鱼干：一大坨纯计算 |

一句话选法：**等得多 → 多叫猫；算得多 → 多开猫。** 看你的活儿是「等」还是「算」，就知道该喊哪一路帮手了喵。

## 六、小任务

2. 再把 `sorted(results)` 去掉，直接印 `results`：**多跑几次**，看看输出的顺序是不是开始飘了。这就是「让父猫统一报数」的价值喵。

下一课，本喵要换个完全不同的思路：**只养一只猫**，让它在等回信的空档里来回忙活 —— 这就是异步喵。🐾
