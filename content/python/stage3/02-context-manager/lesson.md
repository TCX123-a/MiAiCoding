## 钩子：谁在替本喵关门？

本喵在鱼塘边支了个小摊。每天收摊前有一串事要做：把猫粮碗收好、关灯、盖紧鱼干桶、锁门。哪一步漏了，第二天就得踩着满地的鱼干渣渣开工。

写程序也一样。上一阶段学「档案室」那一课的时候，本喵给过你一个偷懒的写法：

```python
with open("yugang.txt", "w", encoding="utf-8") as f:
    f.write("小鱼干 3 条\n")

with open("yugang.txt", encoding="utf-8") as f:
    print(f.read(), end="")
```

```text
小鱼干 3 条
```

那时候本喵打了个比方：`with` 像猫窝门口的**感应灯** —— 一进门灯自己亮，一出门灯自己灭。今天本喵把这盏灯**拆开**看看：它凭什么能自己灭？咱们能不能也造一盏？

## 一、感应灯的秘密：进门一招，出门一招

翻译官喵看到 `with 某某 as 名字:` 这行字，会照着一张**写死的流程单**干活：

1. 先冲 `某某` 喊一声 **`__enter__`**（进门那招）—— 它最后叼回来的东西，装进 `as` 后面的名字里；
2. 再把缩进的身体一句句念完；
3. 身体念完（或者半路翻车），回头冲 `某某` 喊一声 **`__exit__`**（出门那招）。

这就是「自动收拾」的全部秘密：**不是灯自己会灭，是翻译官喵替你记着去关灯喵。** 光听本喵说太干巴，自己画一张图纸试试：

```python
class Jiezhang:
    def __enter__(self):
        print("进门：开灯、摆好猫粮碗")
        return "猫粮碗"

    def __exit__(self, exc_type, exc_value, tb):
        print("出门：关灯、收碗、锁门")

with Jiezhang() as wan:
    print("本喵在屋里干活，手里拿着：", wan)
```

```text
进门：开灯、摆好猫粮碗
本喵在屋里干活，手里拿着： 猫粮碗
出门：关灯、收碗、锁门
```

三行打印的顺序值得盯两眼：**进门那句在最前，出门那句在最后**，中间那句是缩进身体里的活。翻译官喵真的一句不多、一句不少。

再把这张图纸拆开看：

- **`class Jiezhang:`** —— 画一张**猫猫图纸**（以前学过，忘了也不打紧，今天只需要照这个形状画）。
- **`def __enter__(self):`** —— 图纸上的**进门那招**。它没有别的投喂口（`self` 不算投喂），进门时被喊一次；它 `return` 的东西，就是 `as wan` 里那个 `wan`。
- **`def __exit__(self, exc_type, exc_value, tb):`** —— 图纸上的**出门那招**。出门时被喊一次，不管屋里刚才顺不顺利。
- **两招的名字是写死的规矩**：前后各两条下划线（`__` + 名字 + `__`），一个字母都不能差。翻译官喵不认识别的叫法。

::: tip 猫咪提示
把 `with` 念成一句话就记住了喵：**「进门喊一声，干活，出门再喊一声。」** 你画的图纸只要备好这两招，剩下的顺序翻译官喵全包了。
:::

## 二、出门那招的三样投喂：刚才发生了什么

`__exit__(self, exc_type, exc_value, tb)` 里，`self` 后面跟着**三样投喂的小鱼干**。它们不是让你填的，是翻译官喵**主动喂进来的消息** —— 告诉你刚才在屋里发生了什么：

| 投喂 | 顺利干完时 | 半路翻车时 |
|---|---|---|
| `exc_type` | `None` | **翻的是哪种车**（比如 `ValueError`） |
| `exc_value` | `None` | 那辆车上的货物（那句报错话） |
| `tb` | `None` | 一路开过来的**车辙**（出错位置的线索） |

名字你随便起（叫 `a`、`b`、`c` 都行），但**个数和先后位置不能动** —— 第一位是「哪种车」、第二位是「车上的货」，这是翻译官喵和图纸之间的死规矩。

一切顺利的时候三样都是 `None`（意思是「什么事都没有」）。那本喵能不能偷个懒，把三样砍成一样、只留一个投喂口？翻译官喵当场翻脸：

```python
class Shouhuo:
    def __enter__(self):
        print("进门：开灯")
        return self

    def __exit__(self):
        print("出门：关灯")

with Shouhuo():
    print("本喵在屋里干活")
```

```text
进门：开灯
本喵在屋里干活
Traceback (most recent call last):
    with Shouhuo():
TypeError: Shouhuo.__exit__() takes 1 positional argument but 4 were given
```

（报错单中间那行「File …」本喵省掉了喵 —— 那里面是一串又长又随机的临时路径，跟你要学的东西没关系。）

盯住它倒下的位置：**进门那招跑了、屋里那句也印出来了** —— 它是倒在**「出门」这一步**的。翻译官喵手里揣着三样投喂去喊出门那招，那招只肯接一个，两边对不上，当场 `TypeError`。

所以这条记死：**个数照抄，名字随你。**（名字真能随便起吗？能 —— 把三样改名叫 `a`、`b`、`c`，一切顺利的时候它们照样收到三个 `None`。名字只是本喵自己喊的代号，翻译官喵认的是**位置**。）

## 三、翻车了也照样收拾

`with` 最值钱的地方在这儿：屋里翻了车，**出门那招照样跑**。

```python
class Jiezhang:
    def __enter__(self):
        print("进门：开灯")
        return self

    def __exit__(self, exc_type, exc_value, tb):
        print("出门：关灯（翻没翻车都要关）")

try:
    with Jiezhang():
        print("本喵在屋里干活……")
        raise ValueError("小鱼干掉地上了")
except ValueError as e:
    print("屋外接住了：", e)
```

```text
进门：开灯
本喵在屋里干活……
出门：关灯（翻没翻车都要关）
屋外接住了： 小鱼干掉地上了
```

顺序是关键：`出门：关灯` 印在 `屋外接住了` **前面**。翻译官喵跑的是这个先后：身体里刚翻车 → **先喊出门那招收拾屋子** → 再把车的残骸交给外面的 `except`。

这就是 `with` 比「自己手动开关」强的地方：**哪怕中间炸了，收拾这一步也跑不掉。** 手动写法里，「翻了车还得记得收拾」得自己拿 `try` 包一层才做得到；`with` 直接把它焊死在流程单上。

## 四、出门那招叼回 `True`：这摊事本喵自己兜了

出门那招还有个特别的脾气。它要是最后 `return True`，意思就变了，变成一句话：

> 「这儿的事本喵自己兜了，外面不用知道。」

翻译官喵收到这个 `True`，就会把刚翻的车**咽下去**，不再往外交给外面的 `try`：

```python
class Yantun:
    def __enter__(self):
        print("进门")
        return self

    def __exit__(self, exc_type, exc_value, tb):
        print("出门：这摊事本喵自己兜了")
        return True

with Yantun():
    print("先干正事")
    raise ValueError("小鱼干掉地上了")
print("结界外面接着干活")
```

```text
进门
先干正事
出门：这摊事本喵自己兜了
结界外面接着干活
```

仔细看最后一行：`raise` 那句明明翻了车，程序**没有断气**，`print("结界外面接着干活")` 老老实实印出来了 —— 车被出门那招咽掉了。

要是出门那招最后没叼回 `True`（比如什么都没写，那它就是叼回了「什么都没有」的 `None`），车就**原样送到外面**；外面没人接，程序当场停下。

::: warn 小心喵
`return True` 是把异常**咽下去**，不是把它「修好」了喵。屋里那件事**已经办砸了**，只是外面不知道而已 —— 所以只在「本喵确实已经收拾干净、外面不必操心」的时候用它。拿它把该报的错藏起来，将来真出事时你会找不到那辆车。
:::

## 五、一次管好几样

要同时用两样东西，不用一层层往里缩，逗号一列就行：

```python
class Wan:
    def __init__(self, mingzi):
        self.mingzi = mingzi

    def __enter__(self):
        print(self.mingzi + "进门")
        return self

    def __exit__(self, exc_type, exc_value, tb):
        print(self.mingzi + "出门")

with Wan("一号窝") as a, Wan("二号窝") as b:
    print("两个窝一起用")
```

```text
一号窝进门
二号窝进门
两个窝一起用
二号窝出门
一号窝出门
```

进门**从左到右**（一号先进），出门**从右到左**（二号先出）。为什么倒着来？因为东西是**一层层叠上去**的：后放上去的压在上面，就得先拿走。想让几样东西同进同出，记住这个顺序就好喵。

（这一版的图纸里多了一招 `__init__`：它负责把「本喵叫什么名字」存进自己的小鱼干仓库 —— `self.mingzi = mingzi` 就是「把喂进来的名字收好」。后面两招靠它才知道自己是几号窝。）

## 六、更省事的写法：半截招式

每次都画一张图纸、写两招，其实啰嗦。翻译官喵的工具箱里备了一件工具，专门给你省这道手续：

```python
from contextlib import contextmanager

@contextmanager
def jiezhang():
    print("进门：开灯")
    yield "猫粮碗"
    print("出门：关灯")

with jiezhang() as wan:
    print("拿着", wan, "干活")
```

```text
进门：开灯
拿着 猫粮碗 干活
出门：关灯
```

咦，这次没有图纸、也没有 `__enter__` / `__exit__`，照样跑出了三条打印。拆开看：

- **`from contextlib import contextmanager`** —— 从翻译官喵自带的一箱工具（`contextlib`）里，借出叫 `contextmanager` 的那一件。`import` 的写法以前学过。
- **`@contextmanager`** —— 挂在招式头上的一行小字，意思是「**给这招加特效**」：告诉翻译官喵，这招是个**半截招式**，不能直接喊，要按 `with` 的规矩来用。
- **`yield "猫粮碗"`** —— 这行是**门槛**。踩到它，招式先停在这儿、把 `"猫粮碗"` 交出去（这就是 `as wan` 拿到的战利品）；等屋里的活干完，翻译官喵再把它叫回来，从这一行**往下**接着念。

所以规矩特别顺口：**`yield` 之前是进门，`yield` 之后是出门。**

### 半截招式要自己兜住翻车

`yield` 后面那半截，只有屋里**顺利**干完才会走到。要是半路翻了车，招式就被打断在那儿 —— 后面那半截轮不到念了。空口无凭，跑一遍看看：

```python
from contextlib import contextmanager

@contextmanager
def jiezhang():
    print("进门：开灯")
    yield "猫粮碗"
    print("出门：关灯")

with jiezhang() as wan:
    print("拿着", wan, "翻了个车")
    raise RuntimeError("翻车了")
```

```text
进门：开灯
拿着 猫粮碗 翻了个车
Traceback (most recent call last):
    raise RuntimeError("翻车了")
RuntimeError: 翻车了
```

盯住这几行里**缺了什么**：`进门：开灯` 印了、`翻车了` 也印了，**`出门：关灯` 一个字都没出来** —— 屋里那辆车把招式劈成两半，后半截那扇门压根没走到。

想让出门那半截**雷打不动地跑**，就得用 `finally` 把它包住：

```python
from contextlib import contextmanager

@contextmanager
def jiezhang():
    print("进门：开灯")
    try:
        yield "猫粮碗"
    finally:
        print("出门：关灯")

try:
    with jiezhang() as wan:
        print("拿着", wan, "翻了个车")
        raise RuntimeError("翻车了")
except RuntimeError as e:
    print("外面接住了：", e)
```

```text
进门：开灯
拿着 猫粮碗 翻了个车
出门：关灯
外面接住了： 翻车了
```

`finally:` 的意思是：**不管前面出什么事，它下面那几句最后一定要跑。** 有了它，屋里翻了车也照样关灯，跟前面图纸里的出门那招效果一模一样喵。上面那一段就是半截招式最容易摔的一跤：**别把出门那句直接摞在 `yield` 后面**。

## 七、什么时候该套一层 `with`

一张表看明白：凡是「**先要一样东西，用完必须还回去 / 收起来**」的场景，都该套一层。

| 场景 | 进门那一招 | 出门那一招 |
|---|---|---|
| 档案室（册子） | 拉开册子 | 关上册子 |
| 借了鱼塘的渔网 | 把网撒下去 | 收网、晾起来 |
| 给招式计时 | 摁下秒表 | 停表、记下圈数 |
| 临时改一个开关 | 拨到另一边 | 拨回原位 |

共同点：**「出门」这件事忘不得，而它每次长得都一样。** 忘不得又重复的事，就交给 `with` 喵。

::: tip 猫咪提示
这一课就记三句：

1. `with` 的自动收拾 = 翻译官喵替你喊**进门那招 `__enter__`**、再喊**出门那招 `__exit__`**；
2. `as` 后面的名字，装的是 `__enter__` 叼回来的战利品；出门那招会收到**三样投喂**（顺利时全是 `None`）；
3. **翻车也照收拾**；出门那招叼回 `True` = 这摊事它自己兜了。

1. 画一张自己的图纸（名字随你，比如 `Shouhuo`）：进门那招打印「本喵进屋啦」，出门那招打印「本喵收拾好啦」。
2. 在 `with` 的身体里故意写一句 `raise ValueError("试试看")`，**先不要**在外面套 `try`，跑一遍 —— 亲眼看一眼「先收拾、再翻车」这个顺序（屏幕上会先出现「本喵收拾好啦」，然后才是那张报错单）。
3. 给出门那招加上 `return True` 再跑一遍，看看那句 `raise` 是不是被咽掉了、程序有没有接着往下走。
4. 把第 1 步的图纸用 `@contextmanager` + 半截招式重写一遍，比比哪种写法顺手。
