## 钩子：同一个坑，前辈猫早就踩过

本喵最近收拾旧本子，翻出一段半年前写的账：当时为了「全窝只用一只猫粮碗」折腾了一整个下午，改了七八处，改完还漏了两处。

结果上礼拜本喵在隔壁猫的本子里，看见了**一模一样的麻烦**——她也改了七八处，也漏了两处。

这事让本喵琢磨明白了一件事：**有些麻烦不是本喵一个人的**，是所有猫都会撞上的。前辈猫们撞完、疼完，把管用的摆法记了下来，还各自起了名字。

这种「记下来的摆法」，叫**设计模式（前辈猫的套路）**。往后本喵只说「套路」两个字喵。

先说清楚一件事，免得你走岔路：**套路不是代码，是摆法**。它讲的是「这块该谁管、那块该谁管、谁该不认识谁」——同样一个套路，可以写在十行里，也可以写在两百行里，长得完全不一样。

## 套路一：全窝只有一只的那件东西

**麻烦长这样：** 本喵的窝里其实只有**一只**猫粮碗。可谁想用碗，就在自己那儿写一句「造一只碗」——三处写了三句，就造出三只碗。三只碗各记各的存量，本喵往里添了五条鱼干，另一处去看还是空的。

**摆法：** 让「造一只碗」这件事**怎么喊都只给同一只**。

```python
class 猫粮碗:
    _唯一的一只 = None

    def __new__(cls):
        if cls._唯一的一只 is None:
            cls._唯一的一只 = super().__new__(cls)
            cls._唯一的一只.存量 = 0
        return cls._唯一的一只

碗1 = 猫粮碗()
碗2 = 猫粮碗()
碗1.存量 += 5
print("是同一只碗吗？", 碗1 is 碗2)
print("碗2 里的存量：", 碗2.存量)
```

```text
是同一只碗吗？ True
碗2 里的存量： 5
```

拆开看：

- **`_唯一的一只 = None`** 是写在**图纸上**的一个记号（本喵给它头上加了条下划线，意思是「这是图纸自己的小本子，别乱碰」）。它不归任何一只真猫所有——它是**图纸那一层**记着的：本喵已经把唯一那只生出来了没有。
- **`__new__`** 是「**生一只新猫**」那道工序。平常你喊 `猫粮碗()`，翻译官喵自动就把这道工序跑一遍，谁也不注意它。本喵在这儿把它**拦下来**：先看图纸上记着了没有——**记着了就直接把那一只递出去**，没记着才动手生一只，生完顺手记在图纸上。
- 所以 `碗1` 和 `碗2` 拿到的是**同一只**：往里添五条鱼干，两处看都是五条。`is` 那句问的就是「是不是同一个东西」，答「真」。
- 这个套路的正式名字叫**单例**——一窝只有一例。什么时候值得这么摆：全窝**真的只有一份**的东西——一份全窝共用的设置、一个连着远处鱼塘的口子、一本日志。什么时候**别**这么摆：只要你自己也说不清「为什么只能有一只」，那就别硬凑，造两只碗不会塌天喵。

## 套路二：领养处

**麻烦长这样：** 来领猫的猫，其实**不关心**自己领的是橘猫还是狸花猫——她只想知道「我要一只猫」。可她得亲手写下品种的名字、还得知道新品种是怎么造的。哪天窝里多了一个品种，她那段代码就得跟着改。

**摆法：** 开一间**领养处**。来领猫的只报一句「要什么样的」，剩下的事领养处自己掂量。

```python
class 橘猫:
    def 叫声(self):
        return "喵～"

class 狸花猫:
    def 叫声(self):
        return "喵嗷"

def 领养一只(花色):
    if 花色 == "橘":
        return 橘猫()
    return 狸花猫()

for 花色 in ["橘", "狸花", "花"]:
    print(花色, "->", 领养一只(花色).叫声())
```

```text
橘 -> 喵～
狸花 -> 喵嗷
花 -> 喵嗷
```

拆开看：

- **`领养一只(花色)`** 就是门口那间领养处。你报花色，它去后面挑一只递给你；你拿到手就能喊 `叫声`，**从头到尾不知道**它是照哪张图纸生出来的。
- 好处落在**改一处**上：将来窝里添一个「三花猫」的品种，改动只发生在**领养处这一处**；所有来领猫的地方一个字都不用动。
  （上面第三行「花」拿到的是狸花猫——因为领养处只认「橘」这个字，别的都走最后那条兜底的路。这也是领养处的脾气之一：兜底给谁，你说了算喵。）
- 这个套路的正式名字叫**工厂**——造东西的地方。别人不自己造，来这儿领。

## 套路三：摇铃与听众

**麻烦长这样：** 开饭要通知全窝的猫。要是摇铃的那位手上**攥着一份名单**、还得挨个知道「小橘听见了会冲向碗、狸花听见了会先翻个身」，那每加一只猫，她手里那份名单和那一串「谁听见了会怎样」都得改。

**摆法：** 摇铃的**只管摇**，猫自己**订**上来的。

```python
class 开饭铃:
    def __init__(self):
        self.听众 = []
    def 订上(self, 猫):
        self.听众.append(猫)
    def 摇铃(self, 菜名):
        for 猫 in self.听众:
            猫.听见了(菜名)

class 猫:
    def __init__(self, 名字):
        self.名字 = 名字
    def 听见了(self, 菜名):
        print(self.名字, "冲向", 菜名)

铃 = 开饭铃()
铃.订上(猫("小橘"))
铃.订上(猫("狸花"))
铃.摇铃("小鱼干")
铃.摇铃("猫粮")
```

```text
小橘 冲向 小鱼干
狸花 冲向 小鱼干
小橘 冲向 猫粮
狸花 冲向 猫粮
```

拆开看：

- **`开饭铃` 只管两件事**：谁能订上（`订上`）、摇的时候挨个通知（`摇铃`）。它**不知道**每只猫听见了会做什么——它只负责挨个喊一句 `听见了`，剩下的是每只猫自己的事。
- 这正是前辈猫那句「**一声开饭，各猫各样**」：同一句 `听见了` 喊出去，橘猫冲过来了、狸花猫翻个身——**说好的那句话一样，各猫按自己的性子接**。你只管在每只猫自己的图纸上写它的接法。
- 好处还是**改一处**：明天要加一只三花猫，**铃那边一个字都不用改**，只要她自己也订上来就行。
- 这个套路的正式名字叫**观察者**——一件东西动了，所有订上来的都跟着动。什么时候值得：一件事发生了，**有一个以上的地方要跟着动**，而且这些地方**将来还会增减**。人少又固定的时候，直接挨个喊名字反而更清楚喵。

## 套路怎么认、怎么用

三个套路长得差得远，可它们仨身上有个共同点：**都在把「改一处」变成现实**。

- 单例：全窝共用一件东西，省掉「你有三只碗」的混乱。
- 领养处：来领猫的不认识品种，添品种只改一处。
- 开饭铃：摇铃的不认识听众，添听众只改一处。

所以你在自己的代码里，只要发现「**改一处得动十处**」，那儿多半就住着某个套路能治的病。反过来，你背下来十个套路的名字，却找不到那个病，那一个也用不上喵。

本喵把判断的三条写在这儿：

1. **先有麻烦，再找套路。** 为了用套路而用套路，等于往窝里摆一堆没人用的柜子——占地还挡路。
2. **套路不是必须的。** 上面三段都是十几行；很多时候不用它，直接写反而更好看、更好懂。
3. **名字只是拿来聊天的。** 记不住「单例」「工厂」这些名字一点关系都没有，记住**「有这么个摆法」**才管用——哪天你翻别人的窝，看见一个眼熟的结构，那才有用喵。

::: tip 猫咪提示
今天记住三条：① 套路是**摆法**不是代码，讲的是「谁该管什么、谁该不认识谁」；② 三段套路的共同点都是**把「改一处」做实**——发现「改一处得动十处」，那儿就是病；③ 别为了用而用，**先有麻烦，再找套路**。
:::

::: warn 小心喵
本喵最想拦你的一件事：**别背名字**。

「单例」「工厂」「观察者」这些名字，是前辈猫们事后给老方子起的称呼，**不是学套路的入口**。你要是先把名字背下来，再满世界找地方套，最后大概率会写出——「本来只要三行的东西，被拆成三个图纸、绕了两道，跑起来一点毛病没有，可读起来谁也不认识」。那叫为了套路而套路，是本喵见过最费时间的自坑喵。
:::

## 小任务

本喵给你留两个：

1. 给上面那口开饭铃**添一只新猫**（比如「三花」），要求：**铃那边一个字都不改**。改完摇一次铃，看看是不是三只猫都有自己的反应——这一条做到了，你就摸到这个套路的脾气了喵。
2. 对着自己以前写的本子找找，有没有这两样东西：一样是「全窝真的只能有一份」的，一样是「改一处得动十处」的。找到以后**先别急着改**——把「麻烦」用一句话写清楚，再回头看这一课，看看哪一段对得上。

下一课本喵带你把这些日子学的本事**揉成一个真家伙**：一本记账本。它会认项目、会算账、会把记下的东西**留在磁盘上**（关掉程序再打开，账还在），最后还能给你印一张清清爽爽的报表。这一课不教新招式，教的是**怎么把学过的招摆成一件干活的家伙事**喵～ 🐾
