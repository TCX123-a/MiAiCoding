## 钩子：一排八格水，本喵一格一格拨

`common-03` 那节课里，本喵带你看过那口奇怪的鱼塘：**每一格水只有两档 —— 满和空**，写成数字就是 `1` 和 `0`。

那回本喵干的是**数**水格：一格一格数出这个数是几。这回换个玩法 —— **本喵拿一根猫爪棍，直接去拨水格**：

- 想知道某一格是满还是空 —— 拨开旁边那些格子，只盯它一个看；
- 想把某一格灌满 —— 不管它原来是什么样，进去就是一满格；
- 想把某一格舀空 —— 也不管它原来是什么样，舀干净就是了；
- 想把某一格反过来 —— 满的舀空、空的灌满。

这四个动作，在 Python 里各有一个记号。它们**不是**加减乘除，而是直接作用在那一排 0 和 1 上，所以合起来叫 **位运算**。听着玄，学完你会发现它比加减乘除还好懂喵。

## 一、先回头看一眼：`0b` 开头的那串字

想把水格拨明白，先得能**看见**它们。Python 里看一个数长什么样，用 `bin()`：

```python
n = 0b1011
print(n)
print(bin(n))
print(len(bin(n)) - 2)
```

```text
11
0b1011
4
```

三行看下来：

- 第一行：`0b1011` 这个写法**它本身就是个普通的数**，等于十进制的 `11`（`0b` 只是在告诉翻译官喵「后面这段是二进制写法」，跟十进制里写 `11` 是一回事）；
- 第二行：`bin(11)` 又把它变回 `0b1011` 这串字给你看；
- 第三行：数它的长度 —— `0b1011` 一共 6 个字符，掐头去尾还剩 **4**，说明 4 格就能装下这个数。

数水格的方向是有讲究的：**从右往左数**，最右边那一格叫「第 0 位」，往左依次是第 1 位、第 2 位……

| 第几位 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|
| `0b1011` 这格里是 | 1 | 0 | 1 | 1 |
| 这一格的「分量」 | 8 | 4 | 2 | 1 |

每一格的分量都是它右边那一格的 **2 倍** —— 1、2、4、8 一路翻上去。`0b1011` 里有三个 1，分别坐在第 3 格、第 1 格、第 0 格上，把它们的分量加起来就是 `8 + 2 + 1 = 11` 喵。

::: tip 猫咪提示
`bin()` 叼回来的**是一串字**（`0b1011` 是六个字符），**不是数** —— 它能拿来看，不能拿来做手脚。本喵真拿它试过一次：`bin(11) >> 1` 换回来的是 `TypeError: unsupported operand type(s) for >>: 'str' and 'int'`，意思是「**一串字和一个数，挪不动**」—— 连 `>>` 都不认。想在数上做手脚，就写 `n` 本身：`n >> 1` 才对喵。
:::

## 二、四个动作：与、或、异或、取反

先摆两个数：`a` 是 `12`（`0b1100`），`b` 是 `10`（`0b1010`）。本喵把它们从右边对齐排好，然后一格一格地比：

```python
a = 12
b = 10

print("a 是", a, bin(a))
print("b 是", b, bin(b))
print("都亮才算亮", a & b, bin(a & b))
print("有一个亮就算亮", a | b, bin(a | b))
print("不一样才算亮", a ^ b, bin(a ^ b))
print("全部翻过来", ~a)
```

```text
a 是 12 0b1100
b 是 10 0b1010
都亮才算亮 8 0b1000
有一个亮就算亮 14 0b1110
不一样才算亮 6 0b110
全部翻过来 -13
```

四个动作一个个说：

| 写法 | 一句话 | 它是怎么比的 |
|---|---|---|
| `a & b` | **都亮才算亮** | 第 3 格两边都是 1 → 亮；第 2、0 格一边亮一边暗 → 暗；第 1 格两边都暗 → 暗 |
| `a \| b` | **有一个亮就算亮** | 只有第 2 格两边都暗 → 暗，其余都亮 |
| `a ^ b` | **不一样才算亮** | 第 3、0 格两边一样 → 暗；第 2、1 格不一样 → 亮 |
| `~a` | **每一格都翻过来** | 满的舀空、空的灌满 |

所以：

- `a & b` 剩 `0b1000`，是 **8**；
- `a | b` 剩 `0b1110`，是 **14**；
- `a ^ b` 剩 `0b110`（头一格是 0，印出来就是三位），是 **6**；
- `~a` 是 **-13** —— 这个最反直觉，第五节专门讲它。

顺口记一个词的读法：`&` 叫**按位与**，`|` 叫**按位或**，`^` 叫**按位异或**，`~` 叫**按位取反**。四个都不难，**难的是记住哪一个干哪件事** —— 本喵自己的口诀是「**与要两个都点头、或只要一个点头、异或专挑不同意的**」喵。

::: tip 猫咪提示
`^` 这个记号在别的地方常被当成「几次方」，**Python 里不是**：想算「2 的 3 次方」要写 `2 ** 3`，写成 `2 ^ 3` 得到的是按位异或的结果 **1**。这两个记号长得像、意思差着十万八千里，写之前先停半秒喵。
:::

## 三、往左挪、往右挪：移位

还有两个动作不是「比」，而是**整排一起挪**：

```python
a = 12

print("往左挪一格", a << 1)
print("往左挪两格", a << 2)
print("往右挪一格", a >> 1)
print("往右挪两格", a >> 2)
print("往右挪三格", a >> 3)
```

```text
往左挪一格 24
往左挪两格 48
往右挪一格 6
往右挪两格 3
往右挪三格 1
```

- **往左挪**（`<<`）：每一格往左挪一格，**最右边空出来的那格灌 0**。`0b1100` 挪一格变 `0b11000`（24），挪两格变 `0b110000`（48）—— 挪一格就是**乘 2**，挪两格就是**乘 4**；
- **往右挪**（`>>`）：每一格往右挪一格，**最右边那格被挤出去、直接丢掉**。`0b1100` 挪一格变 `0b110`（6），挪两格变 `0b11`（3），挪三格变 `0b1`（1）—— 挪一格就是**除以 2、尾巴不要**。

记法很省事：**挪几格就是乘（除）2 的几次方**。所以 `a << 3` 和 `a * 8` 是一码事，`a >> 3` 和 `a // 8` 是一码事。

那挪一个**负数格**行不行？本喵真试过：

```python
n = 5
print(n << -1)
```

翻译官喵当场犯难：

```text
Traceback (most recent call last):
ValueError: negative shift count
```

最后那句意思是「**挪的次数是负数**」。它拦得有道理：往左挪 `-1` 格，是往右挪一格还是一格都不挪？说不清。所以记一条：**挪的次数只能是非负的整数**（`0` 可以，一格都不挪；负数不行）喵。

## 四、掩码：拿一张挖了洞的卡片盖上去

现在四个动作都齐了，可以干正事了：**只对某一格动手脚，别的一格都不许碰**。

办法是：先拿一张卡片，**只在自己想要的那一格上挖个洞**，别的地方都挡住，再拿它去跟那排格子比对。这张卡片，本喵管它叫**掩码**。

下面这段是本节的正菜，你逐行看它怎么拨：

```python
n = 0b10110100

print("原来的数", n, bin(n))
print("第 1 位是", (n >> 1) & 1)
print("第 2 位是", (n >> 2) & 1)
print("点亮第 1 位", n | (1 << 1), bin(n | (1 << 1)))
print("熄灭第 2 位", n & ~(1 << 2), bin(n & ~(1 << 2)))
print("翻转第 1 位", n ^ (1 << 1), bin(n ^ (1 << 1)))
print("翻转第 2 位", n ^ (1 << 2), bin(n ^ (1 << 2)))
print("是奇数吗", n & 1)
```

```text
原来的数 180 0b10110100
第 1 位是 0
第 2 位是 1
点亮第 1 位 182 0b10110110
熄灭第 2 位 176 0b10110000
翻转第 1 位 182 0b10110110
翻转第 2 位 176 0b10110000
是奇数吗 0
```

`n` 是 `0b10110100`。第 1 格是暗的、第 2 格是亮的，后面几行就围着它俩做手脚：

| 想干什么 | 写法 | 拿这个数试的结果 |
|---|---|---|
| 只看第 k 格 | `(n >> k) & 1` | 第 1 格是 `0`，第 2 格是 `1` |
| 把第 k 格点亮 | `n \| (1 << k)` | 第 1 格点亮 → `182`（`0b10110110`） |
| 把第 k 格熄灭 | `n & ~(1 << k)` | 第 2 格熄灭 → `176`（`0b10110000`） |
| 把第 k 格翻过来 | `n ^ (1 << k)` | 第 1 格翻 → `182`；第 2 格翻 → `176` |
| 看它是奇数吗 | `n & 1` | 最低位是 0 → 偶数 |

一行一行拆开看：

- **`(n >> k) & 1`** 是两件事叠起来：先 `n >> k` 把第 k 格挪到最右边，再用 `& 1` 把左边那些格**全挡住**，于是剩下的只有 0 或 1。少了后面那一半，叼回来的就是「第 k 格以及它左边的所有格」，那可不是 0 或 1 了；
- **`1 << k`** 就是那张卡片本身：只有一个 1，站在第 k 格上，别处全是 0；
- **点亮**用它去「或」—— 有一边亮就算亮，所以那一格一定亮起来，别的格子两边同暗同亮、一个都没动；
- **熄灭**用它**翻过来**再「与」：`~(1 << k)` 是「除了第 k 格是 0，别处全是 1」，跟它「与」一遍，那格被挡住（无论原来是啥都变 0），别处原样通过；
- **翻转**用它去「异或」—— 那一格跟 1 比一定「不一样」，于是翻过来；别的格子跟 0 比一定「一样」，原地不动。

::: warn 小心喵
熄灭那一句里的 `~` **最容易漏**：写成 `n & (1 << k)` 就变成了「**只留下**第 k 格，别处全抹掉」—— 跟你想干的事正好差一个方向。两句跑出来长得都挺正经，屏幕上不会报错，只有数不对。写完顺手问自己一句：「**这张卡片上，该亮的是那一格，还是除了那一格之外的所有格？**」
:::

## 五、Python 的特别处：格子会自己长，负数看补码

这一节讲三件 Python 独有的事。别的语言（比如 `c-stage3-02` 里的 C）不一定是这么办的，所以分开说喵。

### 1. 格子不够，它会自己长

```python
print(1 << 33)
print(1 << 100)
```

```text
8589934592
1267650600228229401496703205376
```

挪 33 格、挪 100 格，Python 一声不响地印出这么长的数 —— **它根本不怕装不下**。因为 Python 的整数是**任意精度**的：格子不够，它自己再长几格出来。

换成格子**钉死在 32 格**的语言（比如 `c-stage3-02` 里的 C），同一件事就惨了：本喵拿一个 32 位的格子从 1 开始往左挪 35 格，真跑过一遍，最后印出来的是 **0** —— 1 早就把 32 格甩在身后了，多出来的全漏光。**不是它算错了，是它的格子只有那么多**；Python 这边同样的动作，印出来的是 8589934592 那么长的数，因为它会自己长格子喵。

所以那句「整数装不下会溢出」，**在 Python 里基本听不到** —— 只有格子钉死的语言才天天念叨这个。

### 2. 负数：前面排着一眼望不到头的 1

`~12` 为什么是 `-13`？因为 Python 的负数用**补码**看：把负数写成一排 0 和 1 的时候，**前面不是空的，而是一眼望不到头的 1**。`~a` 把每一格都翻个个儿，头上那些 1 就全变成 0 了，于是：

> `~a` 永远等于 `-a - 1`。

`~12` 是 `-13`，`~0` 是 `-1`，`~(-1)` 是 `0` —— 这三对数字本喵都真跑过，一个不差。记不住的时候不用背，把 `-a - 1` 代进去算一遍就知道了。

### 3. 负数也能跟 0 和 1 做手脚

既然负数是「前面排着一眼望不到头的 1」，那拿它去做位运算，得到的往往是**另一串凭空多出来的 1**：

```python
print(bin(-5))
print(-5 & 0xFF)
print(-5 >> 1)
```

```text
-0b101
251
-3
```

三行看下来：

- `bin(-5)` 是 `-0b101` —— **负号被单独拎出来写在最前面**，后面才是那几位。这也是 `bin()` 只给你看、不能拿来做手脚的另一个理由；
- `-5 & 0xFF` 是 **251**。`0xFF` 是「只留下最右边 8 格」的卡片，跟它「与」一遍，前面那些望不到头的 1 全被挡住，剩下的 `11111011` 读成普通数就是 251；
- `-5 >> 1` 是 **-3**。往右挪一格本该是「除以 2」，可 `-5` 除以 2 是 `-2.5` —— Python 不四舍五入，而是**往下取整**，所以是 `-3`。

::: warn 小心喵
「往右挪一格 = 除以 2」这句话，**在正数上是对的，在负数上是「往下取整」**。`-5 >> 1` 得到 `-3` 而不是 `-2`，差的就是这半格。写「折半」这类程序时，如果数可能是负的，先想清楚你要的是「丢掉尾巴」还是「往小的那头靠」——这两件事在负数上不是一回事喵。
:::

::: tip 猫咪提示
今天收五句话：

1. **位运算就是拿猫爪棍去拨那一排水格** —— `&` 都亮才算亮、`|` 一个亮就算亮、`^` 不一样才算亮、`~` 每格都翻过来。
2. **移位是整排一起挪**：`<<` 往左（右边灌 0，等于乘 2 的几次方），`>>` 往右（挤出去的丢掉，等于除以 2 的几次方）。
3. **掩码就是那张挖了洞的卡片**：`1 << k` 只有第 k 格是 1；取出某位用 `(n >> k) & 1`，点亮用 `n \| (1 << k)`，熄灭用 `n & ~(1 << k)`（`~` 别漏！），翻转用 `n ^ (1 << k)`。
4. **Python 的整数是任意精度的**：格子不够它自己长，`1 << 100` 照样装得下；C 的格子是钉死的，装满了就往外漏。
5. **负数是补码**：前面排着一眼望不到头的 1，所以 `~a` 等于 `-a - 1`，`~12` 是 `-13`，`-5 & 0xFF` 是 251。
:::
