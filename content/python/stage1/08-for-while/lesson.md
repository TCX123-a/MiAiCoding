## 钩子：大肥鱼的一百圈

本喵的好朋友「大肥鱼」——那条圆滚滚的蓝色大鱼——今天要在鱼塘里游圈锻炼。它的规矩是：**游一圈，本喵喂一条小鱼干。** 一圈一条，一百圈就是一百条。

要是本喵老老实实写一百行「喂一条」，爪子都敲断啦。电脑最擅长「同一套动作重复很多遍」，本喵居然在替它干！

这种活儿，术语表里叫**循环（绕鱼干跑圈）**。今天本喵要把它在 Python 里学扎实，一共四件事：

1. **`for` 加 `range`** —— 圈数数得清的时候，让电脑自己数圈；
2. **`while`** —— 数不清圈数，只能凭眼色停；
3. **`break` 和 `continue`** —— 跑到一半想变卦的两招；
4. **缩进** —— Python 独有的一条铁规矩：谁在圈里、谁在圈外，全看缩进。

## `for`：数得清圈数的时候

先看最省心的一种：本喵**明明白白知道**要发 3 条。

```python
for i in range(3):
    print("绕一圈喵")
```

```text
绕一圈喵
绕一圈喵
绕一圈喵
```

一句话里藏着四个部件，本喵挨个点给你看：

- **`for`** —— 开场白，意思是「下面这活儿要重复做」。
- **`i`** —— 一只小鱼干仓库，专门装「现在是第几圈」。每跑一圈，它就从 `range` 那里领走一个数。
- **`range(3)`** —— 数数的招式，数出 **0、1、2** 三个数（为什么从 0 起，下一小节就说）。
- **冒号 `:` 加缩进** —— 「缩进里的那几行，才是要重复的活儿」。这条本喵后面专门开一节讲。

这四件是怎么配合的？本喵把它拆成一步一步走给你看：

**跑圈的节奏就这四拍**：range 排队 → 每圈领一个数装进 i → 跑缩进行 → 队空了就收工。

### `i` 是从 0 开始数的

别急着往下看，先盯着 `i` 看它每圈领到了什么：

```python
for i in range(3):
    print(i)
print("跑完啦")
```

```text
0
1
2
跑完啦
```

两个要紧的地方：

- **`i` 领到的是 0、1、2，不是 1、2、3。** `range(3)` 的脾气是「数三个数」，而它数数**从 0 起**——报编号从 0 开始这件事，你在项链那一课已经领教过一回了，跑圈这儿一模一样喵。所以想印「第 1 圈」，得自己写 `i + 1`。
- **最后那句 `print("跑完啦")` 只印了一遍，没跟着跑三遍。** 因为它**顶在行首、没有缩进**，是圈外的活儿——圈里的活儿跑完了，才轮得到它。

### `range` 的两种写法

`range` 括号里放一个数，是「从 0 数到它前面」；放两个数，才是「从哪儿数到哪儿前面」：

```python
for i in range(1, 4):
    print(i)
```

```text
1
2
3
```

`range(1, 4)` 数出 1、2、3——**含头不含尾**：起点 1 要，终点 4 不要。这规矩跟项链切片是一家的，记住「终点那个数永远吃不到」，就不会数错喵。

（顺带提一句：`range` 里还能放第三个数，管「每一步迈多大」，比如 `range(2, 7, 2)` 数出 2、4、6。今天先眼熟，用不着背。）

### 小碗累加：跑圈最常干的活

跑圈最常干的一件事，是「把每一圈领到的东西攒起来」。攒东西得先备一只小碗：

```python
total = 0
for i in range(1, 5):
    total = total + i
print(total)
```

```text
10
```

跟着念一遍：小碗 `total` 先洗成 **0**；第一圈 `i` 领到 1，碗里变成 0＋1＝1；第二圈领到 2，碗里 1＋2＝3；第三圈 3＋3＝6；第四圈 6＋4＝**10**。四圈跑完，把碗端出来印一下——这就是「求 1 到 4 的和」喵。

（再提一句：第 05 课学的那只耳朵 `input` 也能放进圈里——`int(input())` 配上今天的圈，就能**一圈读一个数**、读满一整串。练习场上你马上就会用到这个组合喵。）

::: tip 猫咪提示
**数得清圈数用 `for`，只能凭眼色停用 `while`**——这是本喵的小口诀。`for` 的圈数开跑前就定好了（`range` 数出几个数就跑几圈），跑满自动收工；`while` 不问圈数，每一圈都要重新瞄一眼眼色。
:::

## `while`：只能凭眼色停的时候

有些活儿事先数不清——比如碗里还剩几条鱼干，本喵懒得数，只认一条规矩：**「碗里还有，就接着发。」**

```python
fish = 3
while fish > 0:
    print("碗里还有", fish, "条喵")
    fish = fish - 1
print("发完啦")
```

```text
碗里还有 3 条喵
碗里还有 2 条喵
碗里还有 1 条喵
发完啦
```

`while` 的读法是：**每跑一圈之前，先看一眼眼色（`while` 后面那个式子）：答「真」才继续跑，答「假」就收工。**

跟着念一遍：`fish` 是 3 → 3 比 0 大，答真 → 发一条、`fish` 变成 2；2 比 0 大 → 又发一条、`fish` 变成 1；1 比 0 大 → 再发一条、`fish` 变成 0；第四次瞄一眼——0 比 0 大吗？答假，圈停了。屏幕上正好三条喵。

### 让眼色有机会变假

上面那段里最要紧的是哪一行？不是 `while`，也不是 `print`，而是那句 **`fish = fish - 1`**——它每跑一圈就把眼色往前挪一格，让 `fish` 早晚有一天变成 0。

漏了它会怎样？`fish` 永远是 3，眼色永远答真，圈就永远停不下来——代码会一路跑到你硬把窗口按掉。这种停不下来的圈，本喵管它叫**死循环（停不下来的圈）**。

最典型的一种长相是 `while True:`——「真」是个永远不变的字面值，眼色永远是真。所以本喵**故意不给能跑的示例**：它一跑起来就得强行关窗口，界面会卡死喵。

::: warn 小心喵
写完任何一个 `while`，都停下来问自己一句：**圈里有没有一句代码，能让那个眼色早晚变成假？** 那个数要越跑越小（或者越跑越大），不能原地踏步。这一问，能救你一台电脑喵。
:::

## `break` 与 `continue`：跑到一半变卦

`for` 和 `while` 都是「跑满就收工」。可有时候本喵想半路变卦：要么**提前收工**，要么**这一圈不干了、直接跳下一圈**。Python 给了两个词管这件事。

### `break`：提前收工

```python
for i in range(1, 11):
    if i == 4:
        break
    print(i)
print("收工喵")
```

```text
1
2
3
收工喵
```

`range(1, 11)` 本来要跑十圈。可跑到 `i` 是 4 那一圈时，`if i == 4:` 先问一句眼色（`==` 问的是「两边一样吗」），答真，就撞上了 `break`——**`break` 一撞上就收工**：剩下的圈数全部作废，程序跳到圈外，接着往下跑。所以只印出 1、2、3，然后直接轮到圈外那句「收工喵」喵。

### `continue`：这一圈不干了，直接跳下一圈

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
print("跑完喵")
```

```text
1
2
4
5
跑完喵
```

同样是跑到 `i` 是 3 那一圈撞上 `continue`，脾气却完全不同：**`continue` 只是「这一圈剩下的活儿不干了」，圈本身还在跑。** 所以 3 没被印出来，4、5 照常跑完，最后是圈外那句「跑完喵」。

一句话分清它俩：

| 关键词 | 撞上以后会怎样 |
|---|---|
| `break` | 圈**停了**，剩下的圈数全部作废，跳到圈外 |
| `continue` | 圈**没停**，只是这一圈剩下的活儿跳过去，马上开始下一圈 |

两个词多半都和 `if` 搭伙——先问一句眼色，答真才变卦。所以它们总是和「看鱼干眼色行事」一起出现喵。

## 缩进：谁在圈里，谁在圈外

Python 有一条别的语言没有的规矩：**谁属于这个圈，不看大括号，看缩进。**

冒号 `:` 是在说「本喵要开一个圈了」，**紧接着缩进的那几行，才是圈里的活儿**；一旦某一行顶回行首（不再缩进），就表示「圈里到这儿结束，下面归圈外管」。

```python
for i in range(2):
    print("圈里喵")
print("圈外喵")
```

```text
圈里喵
圈里喵
圈外喵
```

两圈里印了两遍「圈里喵」，圈外那句只印一遍——差别全在它们有没有缩进喵。

### 缩进错了会怎样

```text
for i in range(3):
print("喵")
```

翻译官喵当场犯难——它读到冒号，正准备收下「圈里的活儿」，结果下面那行顶在行首，一句都没给它：

```text
  File "...\main.py", line 2
    print("喵")
    ^^^^^
IndentationError: expected an indented block after 'for' statement on line 1
```

**一行都没跑。** 最后那句 `IndentationError: expected an indented block` 翻成人话就是：**「本喵在等一段缩进的活儿，没等到。」** 看到它，回到冒号下面那一行，把它往右推一推就好啦。

::: warn 小心喵
新手最容易摔的两跤：

1. **冒号后面忘了缩进**——就是上面那个报错，程序一行都不跑。
2. **同一层的活儿缩得不一样多**——同一层的活儿要缩**一样多**。本喵的习惯是一次缩 4 个空格，也别用 Tab 和空格混着来：肉眼看着一样齐，翻译官喵数得清清楚楚。

缩进不是「排版好看」，它**是代码本身**——少一格、多一格，说的就是另一件事喵。
:::

## 跑圈小抄

| 关键词 | 本喵的说法 | 什么时候用它 |
|---|---|---|
| `for` | 数着圈跑 | 圈数事先数得清：`for i in range(3):` |
| `while` | 看着眼色跑 | 圈数数不清，只能凭眼色停 |
| `break` | 提前收工 | 圈跑到一半不干了，剩下的圈数全作废 |
| `continue` | 这圈跳过 | 这一圈剩下的活儿不干，马上开始下一圈 |

::: tip 猫咪提示
今天记住四句话就够啦：

1. **`for i in range(3):`** —— `range` 从 0 数起、含头不含尾；`i` 每圈领一个数。
2. **`while` 先看眼色再跑** —— 圈里必须有一句代码让眼色早晚变假，否则圈停不下来。
3. **`break` 收工、`continue` 跳一圈** —— 两个都常和 `if` 搭伙。
4. **冒号后面必须缩进** —— 缩进决定谁在圈里；同一层缩一样多。
:::
