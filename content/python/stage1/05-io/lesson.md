## 钩子：只会念稿子、不会听话的点单机

本喵的「猫猫点单铺」开张啦 —— 门口摆了一台会自动回话的点单机：客人进门报个名字，它就问一声好。

本喵写的第一版长这样：

```python
print("你好，小橘喵")
```

```text
你好，小橘喵
```

跑是能跑，可它只认得「小橘」这一只猫。来的要是狸花猫呢？要是**每一只**进门的猫都想听见自己的名字呢？本喵总不能把全世界的猫名都提前写进代码里喵。

毛病出在：这台点单机**只有一张嘴**（会念），**没有一只耳朵**（会听）。今天本喵就给它装上一只耳朵，顺手把那张嘴也练利索 —— 这两件事合起来，就是术语表里的「投喂与叼回」喵。

## 叼回这一边：`print` 能一次塞好几样

`print` 这个名字你早就见过了：它把东西**叼回**屏幕上给你看。今天先练它的一个小本事 —— **括号里可以一次塞好几样东西**，中间用逗号隔开。

```python
print("你好")
print("你好", "小橘")
print("你好", "小橘", "喵")
```

```text
你好
你好 小橘
你好 小橘 喵
```

数一数屏幕上的空格，规矩就出来了：**逗号不只是把东西分开，它还会在原地垫上一个空格。**

- 一个逗号 → 垫一份空格：`你好 小橘`
- 两个逗号 → 垫两份空格：`你好 小橘 喵`

还有一件小事：**一句 `print` 管一行**。上面三句 `print` 印出三行，本喵一个字都没写「换行」，行却自己分好了 —— 因为 `print` 念完一句，会自动在结尾换行。

### 两个小旋钮：`sep` 和 `end`

上面那两条是 `print` 的**默认**脾气。想改也行，括号里可以再放两个小旋钮：

- **`sep`** —— 管逗号的位置垫什么（默认垫一个空格）。
- **`end`** —— 管这一句的结尾放什么（默认放一个换行）。

```python
print("你好", "小橘", sep="")
print("本喵", end="")
print("在等你喵")
```

```text
你好小橘
本喵在等你喵
```

- 第一句把 `sep` 拧成一对空引号，逗号的位置就**什么都不垫**，两串项链贴紧了：`你好小橘`。
- 第二句把 `end` 拧成一对空引号，念完**不换行**；第三句紧接着往下印，两句话就挤在同一行了。

::: tip 猫咪提示
**逗号垫空格，`sep` 拧它；念完换行，`end` 拧它。** 拿不准的时候什么都别加 —— 默认的「垫一个空格、念完换行」是最不容易写错的那一种喵。
:::

## f-string：把仓库里的东西嵌进句子

前面几段 `print` 塞进去的都是**写死的字**。可本喵想让句子里出现**客人报的名字** —— 那个名字跑起来才知道，正躺在 `name` 这只小鱼干仓库里。

办法是：在引号**前面加一个小写的 `f`**，再用一对**花括号**把仓库的名字圈起来。

```python
name = "小橘"
fish = 3
print(f"{name}今天要了{fish}条小鱼干")
print(f"再来 2 条就是 {fish + 2} 条啦")
```

```text
小橘今天要了3条小鱼干
再来 2 条就是 5 条啦
```

规矩就一句话：

- 引号前**没有 `f`**：引号里就是一句话，一个字都不许动。
- 引号前**有 `f`**：程序念到花括号就**停下来看一眼** —— 里面写的是谁的名字，就把仓库里装的东西**换进去**，接着往下念。两片花括号本身**不念**。

`f` 是英文里「格式化」的头一个字母，本喵管它叫**「填空模式」** —— 引号是印好的句子，花括号是留好的空。

第二句还试了另一件事：花括号里能直接放**算式**，`{fish + 2}` 会先算出 `5`，再把 `5` 嵌进句子里。

### 逗号法，还是 f-string？

同样一句话，两种写法摆在一起看：

```python
name = "小橘"
print(name, "今天要了", "3", "条小鱼干")
print(f"{name}今天要了3条小鱼干")
```

```text
小橘 今天要了 3 条小鱼干
小橘今天要了3条小鱼干
```

- **逗号法**：空格是 `print` 自己垫的，你**想去掉也去不掉**（除非拧 `sep`）。
- **f-string**：缝有多宽由你写，想贴紧就贴紧；要往句子里插好几个仓库，也是它最清爽。

### 忘了那个 `f` 会怎样？

```python
name = "小橘"
print("{name}，你好喵")
```

```text
{name}，你好喵
```

屏幕上冒出一对花括号，程序却觉得自己一切正常 —— 它**不报错**。这种「不报错的错」最费眼神，所以本喵念一遍口诀：**先写 `f`，再写花括号**喵。

::: warn 小心喵
f-string 最常见的坑就是**漏掉引号前面那个 `f`**。漏了它，花括号不是被换掉，而是被当成两个普通符号原样念出来；程序不吭声，你会盯着屏幕想半天「名字怎么没进来」。这是「不报错的错」里最典型的那一个喵。
:::

## 投喂这一边：`input` 给程序装一只耳朵

轮到另一只耳朵了。Python 里把东西**收进来**的招式叫 `input`（英文里就是「送进去」的意思）：

```python
try:
    name = input("你是谁喵？")
except EOFError:
    name = "大肥鱼"

print(f"你好，{name}喵")
```

```text
你是谁喵？你好，大肥鱼喵
```

一行行拆开看：

- 括号里的 `"你是谁喵？"` 是**提示词** —— 程序先把这句话喊出来，好让你知道它在问什么。
- 喊完它**不换行**，就蹲在那儿一动不动地等：你敲字、按回车，这一行才被叼进程序。
- `name =` 那一半是**把叼回来的东西装进小鱼干仓库** —— 右边问，左边收。

一句 `input` 只吃**一行**。程序里写了两处 `input`，它就会问你两遍，你得准备两行来喂它。

### 程序会停下来等你

这件事新手最容易误会，本喵把节奏画出来：

```text
【程序】你是谁喵？          ← 先把提示词喊出来
（然后蹲下不动，等你）
你喂进去：大肥鱼            ← 敲一行、按回车
【程序】你好，大肥鱼喵       ← 才接着往下跑，把话叼回屏幕上
```

屏幕上半天没动静，不等于程序坏了 —— 它是**在等你**喵。所以在练习场里点运行之前，本喵会先数一数：这段代码里有几处 `input`？就往输入框里填几行。

::: warn 小心喵
课文里那段代码外面套着 `try:` 和 `except EOFError:` 两行 —— 别怕，那是本喵系的**保险绳**。

翻译官喵有个脾气：**投喂口空着、没人喂的时候，它一个字都读不到，会当场炸毛**，甩出一段 `EOFError`，程序就断在半路。保险绳的意思是：`try:` 先试着做下面那件事，万一炸毛了，`except EOFError:` 就改走备用路线（本喵提前备好一只大肥鱼）。系上它，这段代码**有没有人喂都能平安跑完** —— 上面那段输出就是这么来的。

来龙去脉，等本喵讲到抓虫那一课再细说，今天照着抄就行喵。**你自己写的时候不系也没关系**：练习场里先把输入框填好，再点运行就好啦。
:::

### 它叼回来的是一串项链，不是数

这是零基础最容易摔的一跤，本喵单独拎出来讲。

不管你敲进去的是名字、是数字，还是一串乱七八糟的符号，`input` **一律当成一串小鱼干的项链**叼回来 —— 就是**带引号的一串字**。你敲的 `3`，装进仓库的时候是 `"3"` 这条项链，**不是整数罐**。

本喵试给你看。下面那个 `n`，就相当于「写了 `n = input()`、然后你在输入框里敲了 `3`」之后的样子：

```python
n = "3"
m = "3.5"
print(n + n)
print(int(n) + int(n))
print(float(m) + float(m))
```

```text
33
6
7.0
```

- 第一行 `n + n`：两串项链之间的 `+` 是**接起来**，不是加起来 —— `"3"` 接上 `"3"`，成了一串更长的 `"33"`。
- 第二行在 `n` 外面套了一层 `int(...)`，才真的做加法：`3 + 3 = 6`。
- 第三行是带小数点的情况：`float(...)` 把这串项链摘成小数罐，`3.5 + 3.5` 就是 `7.0`。

`int` 是英文 integer（整数）的头三个字母，`float` 是 floating point（小数）的头五个字母。它俩干的活是同一件事：**把项链上写着的数字摘下来，换成能算数的罐子** —— 这个动作，术语里叫**类型转换**。

## 小任务

1. 在练习场里敲两句：`name = input("你是谁喵？")` 和 `print(f"你好，{name}喵")`。**点运行之前，先把输入框填上你自己的名字** —— 看看它是不是把你喂进去的名字嵌进了那句话里。
2. 再跑一次，这回**输入框故意留空**。你会亲眼见到那段 `EOFError` —— 看一眼就好，这样你就明白课文里那两行为什么要系保险绳喵。
3. 让点单机问两句：先问名字，再问「要几条小鱼干」。第二条项链用 `int(...)` 摘成整数罐，再把「两只猫一共要几条」算出来念给大家听。
4. 最后一问：把 `print(f"你好，{name}喵")` 里的 `f` 删掉再跑一遍 —— 屏幕上会变成什么样子喵？
