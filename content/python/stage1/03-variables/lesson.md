## 钩子：大肥鱼的鱼干越攒越多

本喵的好朋友大肥鱼——那条圆滚滚的蓝色大鱼——最近开始记账了：今天吃了 3 条小鱼干，明天想吃 5 条，后天还剩几条也要记……

要是它把每一笔都死死记在脑子里，用不了三天就会「咕噜咕噜」冒泡泡，全忘光啦。

本喵给它出了个主意：**在架子上摆一只仓库，贴上名字，把数丢进去**。以后要用，喊一声名字，东西就自己出来了。

这只贴了名字的仓库，就是今天的主角喵。术语表里给它登记的名字是**变量（小鱼干仓库）**，往后本喵就用「仓库」两个字喊它。

## 第一步：贴名字 + 放东西，一行搞定

在 Python 里，开一间仓库和往里放东西是**一步做完**的：

```python
fish = 3
```

这一行拆开看，只有三样东西：

| 部分 | 是什么 | 干什么 |
|---|---|---|
| `fish` | 仓库的名字 | 以后喊这个名字，就能找到它 |
| `=` | 装东西的动作 | **把右边装进左边** |
| `3` | 要装进去的内容 | 这一次装的是数字 3 |

请把这一条刻在脑子里：这个 `=` **不是数学课上那个「相等」**。它是一句**动作**——「把右边的东西装进左边的仓库」。念的时候念成「fish 装上 3」，念对了，往后所有跟赋值有关的写法都不会再绕晕喵。

名字起好之后，喊一声就能把里面的东西取出来用：

```python
fish = 3
print(fish)
```

```text
3
```

想装新东西也简单——**再写一遍 `=` 就行，旧的会被顶掉**：

```python
fish = 3
fish = fish + 1
print(fish)
```

```text
4
```

第二行 `fish = fish + 1`，零基础最容易在这儿看懵，本喵给你慢放一遍：

1. **先算右边**：把仓库里的旧值 `3` 取出来，加 1，算出 `4`
2. **再装左边**：把算出来的 `4` 装回 `fish` 这间仓库

所以它不是「fish 等于 fish 加 1」这种绕口令，而是**两步干干净净的动作**：先取旧值去算，再把结果放回去喵。

## 换东西不用打招呼：Python 的动态类型

现在本喵要告诉你 Python 一个很省心的脾气。

假设某天本喵把这间 `fish` 仓库改了用途：不装数字了，改装一句话——

```python
fish = 3
fish = "三条小鱼干"
print(fish)
```

```text
三条小鱼干
```

**它不生气，也不报错**，直接就装进去了。

本喵把这一下装进去拆成一步一步，走给你看：

```demo
title: 同一间仓库，先后装着两样不同的东西
code:
| fish = 3
| fish = "三条小鱼干"
| print(fish)

step 先看东西，再定种类
at: 1
say: `fish = 3`：Python 的规矩是**先看你装的是什么，再决定这间仓库算什么种类**。装进来的是整数，仓库当下就算**整数**。
meow: 装了 3，它的种类就是整数喵～
pose: expect
fish 仓库里 = 3
它现在算哪种 = 整数（int）
屏幕上 = 还没印

step 第二行右边：一串带引号的文字
at: 2
say: 换到第二行，等号右边写的是 `"三条小鱼干"` —— 带引号的**一串文字**，和 `3` 根本不是一类东西。
meow: 右边换成一串字啦，还带引号！
pose: busy
fish 仓库里 = 3
它现在算哪种 = 整数（int）
屏幕上 = 还没印

step 到这儿为止，仓库一点没动
at: 2
say: 此刻 Python 只是看清了右边是什么。**仓库里仍旧是 3，种类也仍旧是整数** —— 装进去这个动作还没发生。
meow: 仓库里还是 3，一点没动喵～
pose: busy
fish 仓库里 = 3
它现在算哪种 = 整数（int）
屏幕上 = 还没印

step 不查牌子、不比对种类，直接装
at: 2
say: 关键就在这一下：换在别的语言里，到这儿是要被拦下来的；**Python 不拦** —— 那串文字直接进了仓库，旧值 `3` 被顶掉。**而且种类不用谁去改**：东西换成什么，它当下跌跟着算什么 —— 这就是「种类跟着东西走」。
meow: 它不生气、不报错，一口吞下！
pose: busy
fish 仓库里 = 三条小鱼干
它现在算哪种 = 一串文字（str）
屏幕上 = 还没印

step print：叼出来的是仓库当下的东西
at: 3
say: `print(fish)` 喊的还是同一个名字 `fish`，叼出来的却是仓库**当下**装着的东西 —— **三条小鱼干**。名字没换、仓库没换，里面装的却换了个样。
meow: 同一个名字，叼出来是一串字～
pose: proud
fish 仓库里 = 三条小鱼干

```

**分水岭在第 3 步和第 4 步之间**：那串文字还没进仓库之前，仓库里和种类都还是老样子；一进去，两样**同一拍**跟着换 —— 种类从来不是谁去改的，它是跟着东西走的喵。

换在别的语言里，这件事是要被翻译官喵拦下来的：C、C++、Java 开仓库之前得先写明「这间只准放整数」（写成 `int fish = 3;` 这样），以后想改装一句话，翻译官喵会气鼓鼓地告诉你「不行喵」。

Python 不写这一行。它**先看你装的是什么，再决定这间仓库算什么种类**——你装数字，它就当数字用；你换一句话，它就当文字用。同一间仓库，前后换着装不同的东西完全可以，这件事就叫**动态类型**：种类是**跟着东西走的**，不是你提前写死的喵。

不过省心是要交学费的。正因为 Python 不提前拦你，**装错了它当时也不吭声**——要等到后面真的用到那个东西、出了岔子，它才回头告诉你。所以本喵提醒你一句：仓库里装的是什么，你自己心里要有数喵。

## 四个最常见的种类：`int` / `float` / `str` / `bool`

既然种类是跟着东西走的，那 Python 认识哪几种东西呢？今天先认最常见的四个：

| 装什么 | Python 里叫什么 | 长什么样 |
|---|---|---|
| 整数 | `int` | `3`、`-7`、`100` |
| 小数 | `float` | `2.5`、`3.14` |
| 一串文字 | `str` | `"三条小鱼干"`、`"大肥鱼"` |
| 真 / 假 | `bool` | `True`、`False` |

一行一行看过来喵。

### `int` 和 `float`：整数和小数

`int` 装的是不带小数点的整数：`3`、`-7`、`100`。`float` 装的是带小数点的数：`2.5`、`3.14`。

写数字**不用加引号**，直接写就行：

```python
count = 3
price = 2.5
```

这里有个小地方要留意：`3` 和 `3.0` 在 Python 眼里是**两种不同的东西**——前者是 `int`，后者是 `float`。只要带上了小数点，它就是小数，哪怕小数点后面跟的是 0 喵。

### `str`：一串小鱼干的项链

`str` 装的是一串文字，术语表里叫**字符串（一串小鱼干的项链）**：一颗一颗小鱼干穿成一条项链，排好队，一颗都不能乱。

它最要紧的特征只有一条：**写的时候必须用引号包起来**。

```python
catName = "大肥鱼"
```

引号圈出的是这串文字的**边界**：引号里的内容有用，**引号本身不算内容**。所以 `str` 装进去的其实是「大肥鱼」这三个字，前后那对引号只是在告诉 Python「从这里开始，到这里结束，中间是一串文字」。

那要是忘了加引号呢？比方说写成 `catName = 大肥鱼` 这个样子——Python 会把 `大肥鱼` 当成**一间仓库的名字**去找，架子上压根没有哪间仓库叫这个名字，它只好报错。

**加不加引号，就是「一串文字」和「一个名字」的分界**。这一条分清楚了，`str` 就基本拿下喵。

还有一件事别搞混：数字和文字长得再像也是两回事。`3` 是数字，`"3"` 是文字——`"3"` 里面那颗 `3` 只是一颗小鱼干，它不参与计算，你要是拿它去和别的数相加，Python 会告诉你这两种东西不能这么凑一起喵。

### `bool`：真与假

最后一种叫 `bool`，它只装**两个值**：`True`（真的）和 `False`（假的）。

```python
isFish = True
```

以后学「看鱼干眼色行事」那一课的时候，程序就是靠这两个值拿主意的：条件成立就是 `True`，不成立就是 `False`。

`bool` 有个**特别容易踩的坑**：这两个词的**第一个字母必须大写**。

- `True` / `False` —— 正确，这是 Python 认的两个值
- `true` / `false` —— 错！Python 会把它们当成**仓库的名字**去找，架子上没有叫这个名字的仓库，于是报错
- `"True"` —— 加上引号就变了样，它成了 `str`（一串文字），不再是那个真假值了
- `真` / `假` —— 也不行喵。Python 只认得 `True` 和 `False` 这两个**英文**写法，中文的「真」在它眼里就是一串不认识的字，同样会被当成仓库的名字去找

::: warn 小心喵
`True` 和 `False` 是 Python 里**唯二**要用大写开头的东西，前面认过的数字、文字都没这个规矩。记住这句话能省下你不少抓耳挠腮：**大写开头的是真假值，小写的是名字喵**。
:::

## 喊一声 `type()`，看看里面装的是什么

说了这么多，可东西装进去之后，怎么知道它到底是哪一种呢？

Python 给了本喵一个招式：`type()`。**把仓库名喂进它的括号里**，它就把这间仓库当前装着的东西的种类叼回来给你看：

```python
print(type(3))
print(type(2.5))
print(type("大肥鱼"))
print(type(True))
```

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

四行输出，每一行里最后那个词就是种类名：`int`、`float`、`str`、`bool`。前面那一截是 Python 打招呼的方式，今天不用管它，**眼睛盯住最后那三个字母**就够喵。

`type()` 还有个用处：仓库里换了东西，它报出来的种类也会跟着变。这正是「动态类型」的现场证据：

```python
fish = 3
print(type(fish))
fish = "三条小鱼干"
print(type(fish))
```

```text
<class 'int'>
<class 'str'>
```

同一间叫 `fish` 的仓库，第一行报的还是 `int`，换成一句话之后摇身一变成了 `str`——**种类跟着东西走**，说的就是这件事喵。

::: tip 猫咪提示
今天记住四件事就够：

1. `fish = 3` 是一次**动作**：把右边装进左边，不是数学上的「相等」
2. Python 是**动态类型**：同一间仓库换着装不同的东西没关系，种类跟着东西走
3. 四个常见种类：整数 `int`、小数 `float`、一串文字 `str`（**要加引号**）、真假 `bool`（`True` / `False`，**首字母大写**）
4. 拿不准就喊 `type()` 看一眼，它会把这个东西的种类报给你
:::
