## 钩子：一格只装一样的仓库，不够用了

前面几课，本喵的小鱼干仓库有一个老实巴交的毛病：**一格只能装一样东西**。装了一条三文鱼，想再塞一条秋刀鱼进去，就得另开一个仓库、另起一个名字。可本喵的储藏室里躺着一整箱鱼啊——照这个算法，得开一百个仓库，喊名字都喊不过来喵 🐟。

于是本喵搬来一个**储物柜** 📦：一排格子，从上到下整整齐齐，每格装一样东西，而且**想塞多少就自己长大**，不用提前说好要几格。

Python 里管它叫**列表（会自己长大的储物柜）**。今天本喵教你四件事：**造柜子、报编号取东西、往里塞和往外拿、让柜子自己走一遍**喵～

## 造一个柜子：一对方括号

造柜子用的是**方括号 `[ ]`**——把要装的东西一样样写进去，中间用**逗号**隔开：

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
print(柜子)
print(len(柜子))
```

```text
['三文鱼', '秋刀鱼', '鳕鱼']
3
```

拆开看这一行：

1. **`["三文鱼", "秋刀鱼", "鳕鱼"]`** —— 方括号围起来的就是一个柜子，里面装着三样东西。
2. 每样东西**各自带着自己的引号**。这和前面认识的项链不一样喵：项链是「引号围住的一整串字符」，柜子是「一对方括号围住的**好几样**东西」——外面是方括号，每一样各自带引号。
3. **`柜子 = ...`** —— 把这个柜子放进叫 `柜子` 的仓库里存着。名字随你起，本喵这里图个眼熟。

**打印一整个柜子**的时候，Python 会把方括号和每样东西的引号一起打印出来：`['三文鱼', '秋刀鱼', '鳕鱼']`。那对方括号和那些引号是它给你的「这是个柜子」的记号，**不是内容本身**——里面真正的东西还是三文鱼、秋刀鱼、鳕鱼喵。

柜子可以是空的，也可以先造再塞：

```python
空柜子 = []
空柜子.append("大肥鱼")
print(空柜子)
```

```text
['大肥鱼']
```

`[]` 就是一个**一格都没有的空柜子**。它很常见——「先造个空柜子，等下再慢慢往里装」是很顺手的写法，先记住它喵。

## 报编号取一格：编号从 0 开始

柜子最贴心的地方和项链一样：**每一格都有编号，而且从 0 开始数**。看这个四格的柜子：

| 编号 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 那一格 | 三文鱼 | 秋刀鱼 | 鳕鱼 | 鲷鱼 |

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼", "鲷鱼"]
print(柜子[0])
print(柜子[-1])
print(柜子[1:3])
```

```text
三文鱼
鲷鱼
['秋刀鱼', '鳕鱼']
```

- `柜子[0]`：方括号里写编号，读作「柜子的第 0 格」。**0 号是第一格**，不是 1 号——这条规矩和项链的报编号一模一样，第一格永远是 0，往后依次加一。
- `柜子[-1]`：从尾巴往回数，`-1` 就是**最后一格**。这个四格的柜子里，`柜子[3]` 和 `柜子[-1]` 拿到的是同一样东西。
- `柜子[1:3]`：切片也照样好使，**含头不含尾**——拿的是编号 1 和 2 这两格，编号 3 那格不要。注意切出来的**还是一个柜子**（所以打印出来还带着方括号和引号），不是零散的一样东西喵。

::: warn 小心喵
编号报到柜子外面去，Python 会当场翻脸。一个三格的柜子，编号只有 0、1、2 三个；你要是写 `柜子[3]`，它会甩给你一句 `IndexError: list index out of range`——意思是「编号跑到柜子外面去啦」。这和项链越界挨的是同一句骂，看到它先掰手指数一数柜子有几格，别硬猜喵。
:::

## 换一格：`柜子[编号] = 新东西`

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
柜子[1] = "大肥鱼"
print(柜子)
```

```text
['三文鱼', '大肥鱼', '鳕鱼']
```

`柜子[1] = "大肥鱼"` 的意思是「把 1 号格里的东西拿出来，换成大肥鱼」——秋刀鱼就这么被换走了。这里要和「`柜子 = 新柜子`」分清楚：后者是**整个柜子换掉**，前面那句**只动一格**，别的格子原封不动喵。

## 往柜子里塞：`append` 和 `insert`

柜子会自己长大，靠的是它自带的招式。喊法和项链的招式一样：**先写柜子的名字，点一个点，再写招式名，最后跟一对小括号**。

```python
柜子 = ["三文鱼", "秋刀鱼"]
柜子.append("鳕鱼")
print(柜子)
柜子.insert(0, "大肥鱼")
print(柜子)
```

```text
['三文鱼', '秋刀鱼', '鳕鱼']
['大肥鱼', '三文鱼', '秋刀鱼', '鳕鱼']
```

- `柜子.append("鳕鱼")`：往**末尾**再加一格，装进鳕鱼。柜子从 2 格长到 3 格。
- `柜子.insert(0, "大肥鱼")`：往**指定编号**那里插进去，原来那一格连同它后面的全往后挪一格。`insert` 要投喂两样东西：**先给编号，再给要装的东西**。这里是插在 0 号，于是大肥鱼当了第一格，三文鱼被挤到了 1 号。

「往中间插一格，后面的全往后挪」这件事在屏幕上**看不见**，本喵把它放慢给你看 —— 盯着「柜子」那一栏，数一数挪了几格喵。

有一件事要提前说清：`append` 干完活就完了，**不叼东西回来**。

```python
柜子 = ["三文鱼"]
结果 = 柜子.append("秋刀鱼")
print(柜子)
print(结果)
```

```text
['三文鱼', '秋刀鱼']
None
```

看，柜子确实长大了一格，可 `结果` 拿到的是一口「什么都没有」（Python 管它叫 `None`）。所以往柜子里塞东西，写成 `柜子.append(...)` 这一句就够了——**别伸手去接它叼回来的那口空气**，那口空气顶替不了你的柜子喵。

::: warn 小心喵
千万别写 `柜子 = 柜子.append("鳕鱼")` 这种句子。它干的事是：先把鳕鱼塞进柜子（这一步没问题），**然后把 `append` 叼回来的那口「什么都没有」存回叫 `柜子` 的仓库里**——柜子就这么被弄丢了，往后喊 `柜子` 喊出来的是一口空气喵。
:::

## 从柜子里拿走：`remove`、`pop` 和 `del`

有进就有出。三招各有各的脾气：

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
柜子.remove("秋刀鱼")
print(柜子)
叼走的 = 柜子.pop()
print(叼走的)
print(柜子)
```

```text
['三文鱼', '鳕鱼']
鳕鱼
['三文鱼']
```

- `柜子.remove("秋刀鱼")`：**按内容**找——从前往后找那样东西，找到哪一格就把那一格抽走。这里秋刀鱼没了。
- `柜子.pop()`：**从末尾**抽走一格，而且**把抽走的那样东西叼回来**给你，所以能存进 `叼走的` 里。小括号里什么都不写就是末尾那格；写个编号 `柜子.pop(0)` 就是抽走 0 号格。

还有一招按编号直接抹掉，不用喊招式名：

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
del 柜子[0]
print(柜子)
```

```text
['秋刀鱼', '鳕鱼']
```

`del 柜子[0]` 读作「把 0 号格删掉」，后面的格子会自动往前挪，补上那个空位。它和 `pop` 的区别只有一条：**`pop` 会把拿走的东西叼回来，`del` 就直接扔了**——反正你也不打算再用它的时候，`del` 更省事喵。

## 问柜子几个问题：`len` 和 `in`

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
print(len(柜子))
print("鳕鱼" in 柜子)
print("猫粮" in 柜子)
```

```text
3
True
False
```

- `len(柜子)`：数一数柜子有几格。它是**外援招式**——把柜子放进括号里、前面不点。这个写法和数项链有几颗时的 `len` 是同一招，只是括号里换成了柜子喵。
- `"鳕鱼" in 柜子`：问一句「柜子里有没有鳕鱼」，叼回来 `True`；`"猫粮" in 柜子` 问的是柜子里没有的东西，叼回来 `False`。

⚠️ 别把编号和格数搞混：三格的柜子，编号是 0、1、2，`len(柜子)` 数出来却是 3。所以**最大编号永远是格数减一**，也就是 `len(柜子) - 1`——这条差一位最容易踩喵。

## 让柜子自己走一遍：遍历

柜子里塞了几十样东西的时候，一格一格报编号太累了。上一课学的**跑圈招式 `for`** 正好派上用场——把它用在柜子上，它会**一格一格自己走一遍**：

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
for 小鱼干 in 柜子:
    print(小鱼干)
```

```text
三文鱼
秋刀鱼
鳕鱼
```

读法：「**对柜子里的每一样东西，都叫它一声 `小鱼干`，然后做下面缩进着的那件事**」。

- `for 小鱼干 in 柜子:` —— `小鱼干` 是你随便起的名字，它会**依次**装上柜子里的每一样东西。
- 第一圈它装着三文鱼，第二圈装着秋刀鱼，第三圈装着鳕鱼——**柜子里有几格，就跑几圈**，格子走完了它自己停下来。
- 下面那行 `print(小鱼干)` 前面有**四个空格的缩进**，那是「圈里要做的事」。缩进是跑圈招式的命根子，丢了它会报错，这一点上一课就强调过喵。

如果**边走边想知道现在走到第几格**，就把 `range` 请出来，配上 `len` 造出一串编号：

```python
柜子 = ["三文鱼", "秋刀鱼", "鳕鱼"]
for i in range(len(柜子)):
    print(i, 柜子[i])
```

```text
0 三文鱼
1 秋刀鱼
2 鳕鱼
```

`len(柜子)` 数出 3，`range(3)` 造出 `0`、`1`、`2` 三个编号，于是 `i` 一圈一圈地变成 0、1、2，`柜子[i]` 就挨个报编号拿到东西。顺便记住一个小细节：`print(i, 柜子[i])` 括号里用逗号隔开的两样东西，打印出来中间**会自动隔一个空格**，所以是 `0 三文鱼` 这个样子喵。

```demo
at: 5

meow: 一共 100 条！跑圈跑对啦～
pose: milestone
小鱼干 = 40
总共 = 100
柜子 = [10, 20, 30, 40]
印出来 = 100
```

::: tip 猫咪提示
今天这四件事，各记一句：
1. **造**：方括号 `[ ]` 围起来，逗号隔开，每样各自带引号；`[]` 是空柜子。
2. **取**：`柜子[0]` 第一格、`柜子[-1]` 最后一格，**编号从 0 开始**；切片 `柜子[1:3]` 含头不含尾，切出来还是个柜子。
3. **改增删**：改一格用 `柜子[1] = 新的`；增用 `append`（末尾加）和 `insert`（插在某个编号处，先给编号再给东西）；删用 `remove`（按内容找）、`pop`（末尾抽走并叼回来）、`del 柜子[编号]`（按编号直接抹掉）。
4. **走**：`for 东西 in 柜子:` 一格一格走一遍，缩进不能丢；想知道走到第几格，就用 `for i in range(len(柜子)):`。
:::

::: warn 小心喵
三个最容易踩的坑：
- 编号越界会挨 `IndexError`，报编号之前先数清柜子有几格（最大编号是格数减一）。
- `append` 不叼东西回来，写成 `柜子 = 柜子.append(...)` 会把柜子弄丢。
- 造柜子用的是**方括号**，别和小括号、花括号搞混；柜子里每样东西各自要带引号才对，不过混着装也没关系——`["三文鱼", 3]` 这样一半项链一半数字，Python 也收喵。
:::

## 小任务

把下面这几行敲进去，**一行一行猜、一行一行跑**：

```python
柜子 = ["三文鱼", "秋刀鱼"]
柜子.append("鳕鱼")
柜子[0] = "大肥鱼"
柜子.remove("秋刀鱼")
print(柜子)
print(len(柜子))
for 小鱼干 in 柜子:
    print(小鱼干, "好吃喵")
```

猜对了吗？然后**试着改一改**：把最后那个跑圈换成今天学的「边走边报编号」的写法——

```python
柜子 = ["大肥鱼", "鳕鱼"]
for i in range(len(柜子)):
    print(i, 柜子[i], "好吃喵")
```

看看打印出来的样子和刚才有什么不同喵～
