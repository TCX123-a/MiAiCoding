## 钩子：大肥鱼心里那个数

本喵的好朋友大肥鱼——那条圆滚滚的蓝色大鱼——今天想玩个游戏：它在心里默念一个 **1 到 100 之间的整数**，你只管猜。本喵蹲在旁边当裁判，每次只回三句话之一：

- **「太小啦喵」**
- **「太大啦喵」**
- **「猜中啦喵！」**

规则听着简单，可要把它写成程序，得把你学过的零件几乎全用上：**抽一个数、反复猜、比大小、再把活儿拆成招式**。所以这一课是本阶段的**综合项目**——本喵不再一口气塞给你一堆新概念，只补一个最小的新零件（让电脑自己抽数），剩下全是组装喵。

顺序是这样的：**先让电脑想一个数 → 再学怎么反复猜 → 再学怎么比大小 → 最后把一坨逻辑拆成两个招式。** 跟着本喵一步一步来。

## 第一步：让电脑自己想一个数

大肥鱼想数靠的是鱼脑子，电脑想数得靠**随机数**：让它在某个范围里随便挑一个，本喵和它事先都不知道会挑中谁。

Python 自带一个随机工具箱，名字叫 `random`。用之前得先把它**搬进工作台**：

```python
import random

print(random.randint(1, 100))
```

每次跑出来的数都不一样喵：可能是 7，也可能是 93——全看运气。这里有两个新面孔：

- **`import random`** —— 「把一整个工具箱搬进来」的意思。搬完之后，工具箱里的招式就都能喊了，喊法是 **`random.招式名`**：先报工具箱的名字，加一个点 `.`，再报招式名。
- **`random.randint(1, 100)`** —— 请随机工具箱在 **1 到 100 之间**抽一个整数。`randint` 这个名字是「random integer（随机整数）」的缩写，念作「兰德因特」，意思是「在两头之间随便挑一个整数」。

::: tip 猫咪提示
`randint` 和 `range` 只差一个词，脾气却**正好相反**喵：

| 招式 | 两头怎么算 |
|---|---|
| `range(1, 100)` | **含头不含尾**——1 要，100 吃不到 |
| `random.randint(1, 100)` | **两头都含**——1 和 100 都可能被抽到 |

本喵的小口诀是：「**range 的尾巴咬不动，randint 的两头都能舔**」。大肥鱼说 1 到 100，那 1 和 100 都得算数，所以这里只能用 `randint` 喵。
:::

### 让随机「钉死」：本喵的课堂小把戏

随机数的麻烦在于：本喵没法在课文里写死它的输出，你跑出来的数跟本喵跑出来的永远不一样。想让它每次跑都给出**同一串数**，可以在前面钉一颗**种子**：

```python
import random

random.seed(1)
print(random.randint(1, 100))
print(random.randint(1, 100))
```

```text
18
73
```

`random.seed(1)` 的读法是「**从第 1 号种子开始长**」。同一颗种子，长出来的随机串永远一模一样——本喵写课文时钉种子，就是为了让你看到的两个数和本喵写的**一字不差**喵。

不过记好了：**真玩游戏的时候要把这颗种子删掉**。留着它，大肥鱼每次想的都是同一个数，猜第二遍就没有悬念啦。

接下来本喵就借这颗种子往下讲：**大肥鱼想的数是 18**，你先把 18 记在脑子里。

## 第二步：一次不中，就接着猜

数有了，就该让你猜了。可你猜一次大概率中不了——真玩起来要猜好多次，而且**事先不知道要猜几次**：有人一发命中，有人磨十几回。数不清圈数的活儿该请谁出马？你在「绕鱼干跑圈」那一课学过一句口诀：**数得清用 `for`，只能凭眼色停用 `while`。**

这一局要停的条件是「**猜中了没有**」——可它得等圈转起来、比过一次才知道。与其在 `while` 后面写一句现在算不出来的式子，不如换个思路：**`while True:` 配一句 `break`。**

::: warn 小心喵
那一课本喵特意提醒过：`while True:` 是**停不下来的圈**，所以当时**故意不给能跑的示例**——它一跑起来就得硬关窗口，界面会卡死喵。

今天要给它平反：**光一个 `while True:` 当然停不下来，可只要圈里有一句真的会被走到的 `break`，它就成了「不知道要跑几圈」最顺手的写法。** 光有 `while True:` 是坑，`while True:` 加 `break` 是工具，差别全在那一句 `break` 上喵。
:::

```python
target = 18
guesses = [10, 50, 25, 18]

while True:
    guess = guesses.pop(0)
    print("本喵报", guess)
    if guess == target:
        print("猜中啦喵！")
        break
```

```text
本喵报 10
本喵报 50
本喵报 25
本喵报 18
猜中啦喵！
```

圈里有三处新东西，本喵一处一处讲：

- **`guesses`** 是一只储物柜，里面预存了四个数。**它是你的替身**：真人玩的时候，这四个数由你敲键盘一个一个报进来。本喵先用一串写好的数把机器空转起来，这样课文里的输出才能写死喵。
- **`guesses.pop(0)`** —— 从储物柜的**头上**取走一条：取出来的同时，它就从柜子里没了。第一圈取走 10，第二圈取走 50，后面的数也照样一条一条往外拿。真玩游戏时，这一行换成 `guess = int(input("猜一个数喵："))`，柜子就换成你的键盘啦。
- **`break`** —— **提前收工**。猜中那一圈撞上它，圈立刻停，柜子里剩下的数一条都不再取。

还有那句 **`if guess == target:`** 里的 **`==`**：它是「**问一句两边一样吗**」，你在「绕鱼干跑圈」那一课见过它（`if i == 4:` 就是那时候学的）。答真，说明这一圈报的数正好是答案。

::: warn 小心喵
`while True:` 能放心用，**唯一的理由是圈里有一句一定会被走到的 `break`**。写完一定要回头问自己一句：**猜中了真的会走到那句 `break` 吗？** 要是 `break` 缩错了位置，或者干脆忘了写，这个圈就永远停不下来，你只能硬关窗口。

顺便说清一个容易混的：`continue` 在这里**帮不上忙**。它的意思是「这一圈剩下的活儿不干了，马上开下一圈」——圈本身照转，一句 `continue` 是收不了工的喵。
:::

## 第三步：比大小，报个信

上面的圈会转了，可它只会干巴巴地报数——**玩家还是不知道自己离答案有多远**。得让它多回一句话：偏大还是偏小。

这是「看鱼干眼色行事」（`if` / `elif` / `else`）最拿手的活儿。先撇开圈，单看这三条岔路：

```python
target = 18
guess = 10

if guess < target:
    print("太小啦喵")
elif guess > target:
    print("太大啦喵")
else:
    print("猜中啦喵！")
```

```text
太小啦喵
```

三条岔路本喵一条一条给你点开：

1. **`if guess < target:`** —— 你报的数比答案**小**，走这条，印「太小啦喵」。
2. **`elif guess > target:`** —— 头一条不成立、而且你报的数比答案**大**，走这条，印「太大啦喵」。
3. **`else:`** —— 前面两条都不成立，那就只剩一种可能：**你报的数和答案一样大**，印「猜中啦喵！」。

把 `guess` 改成 50 再跑一遍，屏幕上就换成「太大啦喵」；改成 18，就是「猜中啦喵！」。**三条岔路每次只走一条**，走进一条，后面两条连带问都不问。

所以 `else` 里那句不用再写一遍比较——它是「前面全不成立」的兜底，兜住的正好是「猜中了」这一种情况。往后你看别人写的猜数字程序，`else` 里面十有八九就是「猜中」喵。

### 把三句话塞进圈里

现在把这三条岔路搬进上一节的圈，顺手做一件小事：**原来那句 `if guess == target:` 的收工机关可以退休了**——因为「猜中」正好就是 `else` 那条岔路，把 `break` 挪进去就行：

```python
target = 18
guesses = [10, 50, 25, 18]

while True:
    guess = guesses.pop(0)
    if guess < target:
        print(guess, "太小啦喵")
    elif guess > target:
        print(guess, "太大啦喵")
    else:
        print(guess, "猜中啦喵！")
        break
```

```text
10 太小啦喵
50 太大啦喵
25 太大啦喵
18 猜中啦喵！
```

跟上一节比，圈里少了一次单独的比较、多了两条岔路——**省下来的那次比较，正是「三条岔路每次只走一条」帮的忙**：能走到 `else`，就已经说明「不小也不大」，只剩「相等」这一种可能了喵。

还有一处值得盯一眼：**`break` 是缩在 `else:` 里面的**。报「太大」「太小」的那两圈只是印一句话，圈照样往下转；**只有猜中那一圈才会收工**。

## 第四步：把活儿拆成招式

上面那段能跑，可它有点「一坨」：取数、比大小、印话、收工，全挤在一个圈里。

更要紧的是——**「比大小、报个信」这段活儿，一局里每猜一次就要用一次**，是典型的「反复用的那步」。真正写项目的时候，本喵会给它起个名字、包成一个招式：

```python
def check_guess(guess, target):
    if guess < target:
        return "太小啦喵"
    elif guess > target:
        return "太大啦喵"
    else:
        return "猜中啦喵！"

print(check_guess(50, 18))
```

```text
太大啦喵
```

（`def` 这个开场白你在「第一个自创招式」那一课见过：`def` 后面跟**招式名**和一对括号，冒号下面缩进的那几行，就是招式里的活儿。）

本喵把三处细节点给你看：

1. **括号里的 `guess` 和 `target`** 是**投喂进招式的小鱼干**。喊招式的时候按顺序塞进去，招式里就用这两个名字使唤它们。所以 `check_guess(50, 18)` 的意思是「按 `guess` 是 50、`target` 是 18 来比一比」。
2. **`return` 是「把战利品叼回来」**：招式算完，把「该印哪句话」这条项链交给外面。谁喊它，谁就拿到这句提示——所以最后那句 `print(check_guess(50, 18))` 才能把「太大啦喵」印出来。
3. **招式里一句 `print` 都没有，它只报信、不印字**。印不印、什么时候印，交给外面决定。

第 3 点正是「拆」的意义所在喵：**一个招式只干一件事**，它才好用、好改、好读。比大小的活儿归 `check_guess`，印字和收工归主流程，谁也不越界。

### 把一整局也包成招式

比大小拆出去了，主流程还剩「取数、印话、判断要不要收工」。这三件是**一整局**的活儿，本喵干脆把它们也包起来，顺手把「一共猜了几次」当战利品叼回来：

```python
import random

def check_guess(guess, target):
    if guess < target:
        return "太小啦喵"
    elif guess > target:
        return "太大啦喵"
    else:
        return "猜中啦喵！"

def play(target, guesses):
    step = 0
    while True:
        guess = guesses.pop(0)
        step = step + 1
        print(guess, check_guess(guess, target))
        if guess == target:
            return step

random.seed(1)
target = random.randint(1, 100)
picks = [10, 50, 25, 18]

used = play(target, picks)
print("答案是", target, "一共猜了", used, "次喵")
```

```text
10 太小啦喵
50 太大啦喵
25 太大啦喵
18 猜中啦喵！
答案是 18 一共猜了 4 次喵
```

这就是**完整的一局**了，从上往下读一遍：

1. **`import random` + `random.seed(1)`** —— 搬进随机工具箱，钉死种子。真玩的时候把 `seed` 那行删掉，大肥鱼每次想的数才不一样。
2. **`check_guess`** —— 只管比一比、叼回该印哪句话。
3. **`play(target, guesses)`** —— 管一整局：每取一个数就 `step = step + 1` 数一次，印一行；一旦猜中就 **`return step`**，把「猜了几次」当战利品叼出来。**注意 `return` 一执行，招式当场结束**，圈也跟着停——所以这里不用再单独写一句 `break` 喵。
4. **最后三行**是主流程：抽数、把替身储物柜交给 `play`、把叼回来的次数印出来。外面这只柜子叫 `picks`，招式里管它叫 `guesses`——**名字各论各的**，靠的是塞进去的顺序对上号。

真机上把它变成能玩的游戏，只要改**两行**：删掉 `random.seed(1)`，再把 `guess = guesses.pop(0)` 换成 `guess = int(input("猜一个数喵："))`。`input` 带回来的是一串字符，得先用 `int(...)` 变成整数，才能跟大肥鱼比大小——这一招你在「投喂与叼回」那一课用过喵。

## 本课零件小抄

| 零件 | 干什么用的 |
|---|---|
| `import random` | 把随机工具箱搬进来 |
| `random.randint(1, 100)` | 两头都含地抽一个整数 |
| `random.seed(1)` | 钉一颗种子，让随机每次跑都长同一串数 |
| `while True:` | 不知道要跑几圈的圈 |
| `break` | 提前收工，圈立刻停 |
| `if` / `elif` / `else` | 太小 / 太大 / 猜中，三条岔路 |
| `def` / `return` | 把活儿包成招式、把战利品叼回来 |

::: tip 猫咪提示
整课就记一句话：**「随机抽一个数 → 圈里反复比 → 猜中就收工 → 把反复用的判断包成招式。」**

这是你第一次写「像样的小程序」，它和你以后要写的大程序**结构上是一样的**——先想清楚有哪几步，再把反复用的那步包成招式喵。
:::

## 小任务

1. **换个范围**：把 `random.randint(1, 100)` 改成 `random.randint(1, 10)`，再把 `picks` 里的数换成三四个 1 到 10 之间的数——猜起来快多了，一眼就能看出哪条岔路在干活。
2. **给机会设个上限**：改成「只准猜 5 次」。提示：在 `play` 里备一只数数的仓库，比如先写 `left = 5`，每猜一次就 `left = left - 1`，然后把 `while True:` 换成 `while left > 0:`——这就从「凭 `break` 收工」变成「凭眼色收工」了喵。
3. **把范围报给玩家**：在最前面加一句 `print("本喵想了一个 1 到 100 的数，来猜猜看喵～")`，让游戏一开头就有个招呼。

改完记得跑一遍看看，猜中的时候屏幕上会多一句「答案是……一共猜了……次喵」——那是 `play` 叼回来的战利品喵。 🐾
