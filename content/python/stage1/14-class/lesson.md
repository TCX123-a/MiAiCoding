## 钩子：三十只猫，本喵抄不动了

猫窝里住着三十只猫。本喵想记下每只猫今天吃了几条小鱼干 —— 前面学过的**会自己长大的储物柜**倒是装得下，可本喵得摆三十个柜子，还得自己死死记住「这个柜子是橘猫的、那个是狸花猫的」。猫一多，准记混喵。

更让本喵泄气的是：本喵还想让每只猫都会一招「喵一声，报今天的数」。三十只猫，就得写三十招长得几乎一样的招式；以后想改一句话，三十处都得改。这哪是写程序，这是抄书喵！

本喵盯着白纸想了半天，忽然想通了：**本喵缺的不是三十个仓库，而是一张图纸**。

图纸上只写一遍：凡是照着这张图纸生出来的猫，都有名字、都有今天吃了几条，都会喵一声。要用猫的时候，照着图纸生一只 —— 生出来的猫自己带着这两样东西，走到哪儿跟到哪儿。

画这张图纸的口令，在 Python 里就是 `class`。

## 画一张图纸：`class` 和 `__init__`

本喵摊开纸笔，画下第一张猫猫图纸，顺手照着它生了一只猫：

```python
class Cat:
    def __init__(self, name, fish):
        self.name = name
        self.fish = fish

cat1 = Cat("橘猫", 3)
print(cat1.name)
print(cat1.fish)
```

```text
橘猫
3
```

这一小块干了**两件事**：先**画图纸**，再**照着图纸生一只真猫**。一行一行看喵：

- **`class Cat:`** —— 画图纸的口令。`class` 的意思是「本喵要画一张图纸」，后面的 `Cat` 是这张图纸的名字（首字母大写是本喵们的习惯，这样一眼就能认出「这是个图纸名」）。行尾的冒号不能丢，丢了翻译官喵当场犯难。
- **`def __init__(self, name, fish):`** —— 图纸上的第一条说明。`def` 你前面就认识了，是「本喵要写一招」；`__init__` 是**每只猫出生时都会自动跑一次的那一招**：照这张图纸生猫的时候，先把名字和鱼干数喂进来。`__init__` 前后各是**两条下划线**，一共四个，少一个都不行喵。
- **`self.name = name`** —— 把喂进来的名字，放进**这只猫自己**的仓库，标签写 `name`。
- **`self.fish = fish`** —— 同理，鱼干数也放进这只猫自己的仓库，标签写 `fish`。
- **`cat1 = Cat("橘猫", 3)`** —— 照着图纸**生出一只真猫**：喂进去名字 `"橘猫"` 和数字 `3`，生出来的这只猫就自带这两样东西，本喵给它起了个名字叫 `cat1`。
- **`cat1.name` / `cat1.fish`** —— 报标签，取这只猫自己仓库里的东西。

于是屏幕上先冒出 `橘猫`，再冒出 `3` 喵。

这张纸，术语表里给它的原名是**类（猫猫图纸）**：一张写清了「凡是照它生出来的猫，都长什么样、都会什么」的纸。

本喵得提醒一句最要紧的：**图纸上写的字，不会自己变成猫**。`class Cat:` 画完，碗边一只活的都没有 —— 真正让猫出现的是 `Cat("橘猫", 3)` 那一句。照这张图纸生出来的每一只，术语表里叫**对象（根据图纸生出来的真猫）**。图纸只有一张，真猫想生几只生几只。

## `self` 是谁？——「本喵自己」

图纸中间那个 `self`，最让新学员犯迷糊。本喵把它说破：**`self` 读作「本喵自己」**。

它不是什么固定的东西，而是**照这张图纸生出来的那一只**：生的是橘猫，`self` 就指橘猫；生的是狸花猫，`self` 就指狸花猫。

所以 `self.name = name` 整句读出来是：「**把喂进来的名字，放进本喵自己的仓库里，标签写 `name`**」。等号右边那个光秃秃的 `name`，才是外面喂进来的那一份 —— 同一行里，**带 `self.` 的和不带 `self.` 的是两样东西**，看仔细喵，看漏了就会写出「喂进来的东西原地打转」这种怪代码。

还有一个新手总踩的坑：`def __init__(self, name, fish):` 括号里的**第一个位置永远是 `self`，生猫的时候不用喂它** —— 本喵写的是 `Cat("橘猫", 3)`，只喂了两个，`self` 是 Python 自己替本喵塞进去的。

## 图纸上画的招式：方法

图纸上还能画招式。本喵给猫加一招「喵一声」：

```python
class Cat:
    def __init__(self, name, fish):
        self.name = name
        self.fish = fish

    def meow(self):
        print(f"{self.name}：喵～本喵今天吃了 {self.fish} 条小鱼干")

cat1 = Cat("橘猫", 3)
cat2 = Cat("狸花猫", 1)
cat1.meow()
cat2.meow()
```

```text
橘猫：喵～本喵今天吃了 3 条小鱼干
狸花猫：喵～本喵今天吃了 1 条小鱼干
```

- **`def meow(self):`** 的画法和前面学的招式一模一样，只是它**画在图纸里面**，所以要和别的说明一样**缩进**。缩进丢了，它就从图纸里掉出去，图纸也不认得它了。
- 写在图纸里的招式，Python 里叫**方法** —— 它和前面学的招数是同一回事，只是**归某一只猫所有**。
- 招式里照样能用 `self`：`f"{self.name}：……"` 里那个 `self.name`，取的是**正在喵的这一只**的名字。
- 喊招式也有讲究：要写 `cat1.meow()` —— **先说哪只猫，再喊招式名**。这一招由 `cat1` 来做，`self` 就指向 `cat1`，念出来的自然是它自己那份数。
- `cat2.meow()` 是另一只猫在做同一招，念的是它自己的数。**同一张图纸上的一招，两只猫各喊各的。**

## 生两只：各带各的仓库

本喵再问一个最要紧的问题：两只猫都有自己的 `name` 和 `fish`，它们会不会**共用同一个仓库**？改了一只，另一只会不会跟着变？

```python
class Cat:
    def __init__(self, name, fish):
        self.name = name
        self.fish = fish

cat1 = Cat("橘猫", 3)
cat2 = Cat("狸花猫", 1)
print(cat1.name, cat1.fish)
print(cat2.name, cat2.fish)
cat1.fish = 5
print(cat1.fish, cat2.fish)
```

```text
橘猫 3
狸花猫 1
5 1
```

看最后一行：本喵只把 `cat1.fish` 改成 `5`，`cat2.fish` **纹丝不动**，还是 `1`。

- **图纸只有一张**。`class Cat:` 画完之后它就那么一张，本喵在纸上画再多轮廓，碗边也不会多出一只猫来。
- **仓库是每只猫各带一份的**。照图纸生一只，它就带着自己的一套 `name` 和 `fish`，和别的猫谁也不碰谁。

所以 `cat1.fish = 5` 是给 `cat1` 这只猫的仓库换个数，跟 `cat2` 一点关系都没有喵。

顺便记个小细节：`print(cat1.name, cat1.fish)` 括号里用逗号隔开的两样，打印出来中间**自动隔一个空格**，所以是 `橘猫 3` 这个样子。

## 让真猫打印得好看：`__str__`

本喵试着**直接打印一只真猫**，结果屏幕上冒出一行谁也不认识的怪字：里面夹着 `__main__`、`Cat`、`object`，最后跟着 `0x` 和一串十六进制地址。那串地址**每跑一次都不一样**，它说的是「这只猫现在住在电脑的哪个角落」—— 那是给电脑看的住址，不是给猫看的名字喵。

想让 `print(cat1)` 打印出好看的样子，就在图纸里再写一招 `__str__`：

```python
class Cat:
    def __init__(self, name, fish):
        self.name = name
        self.fish = fish

    def __str__(self):
        return f"猫猫 {self.name}，今天吃了 {self.fish} 条小鱼干"

cat1 = Cat("橘猫", 3)
print(cat1)
```

```text
猫猫 橘猫，今天吃了 3 条小鱼干
```

`__str__` 是「**这只猫该怎么被打印成一句话**」的那一招：它自己不打印，而是把要说的话**叼回来**（`return`）。以后谁把这只猫交给 `print`，Python 就先把这一招跑一遍，拿它叼回来的那句话去印 —— 打印出来就是本喵写好的样子了喵。

::: tip 猫咪提示
- **画图纸**：`class 图纸名:`，图纸里的说明和招式都要缩进。
- **生猫前先喂**：`def __init__(self, name, fish):` 是每只猫出生时自动跑一次的那一招。
- **`self` 就是「本喵自己」**：指正在被生的那一只；带 `self.` 的是它自己的仓库。
- **生真猫**：`cat1 = Cat("橘猫", 3)`，图纸只有一张，真猫想生几只生几只。
- **喊招式**：`cat1.meow()`，先说哪只猫、再喊招式名。
- **打印得好看**：在图纸里写一招 `__str__`，把要印的话叼回来。
:::

::: warn 小心喵
三个最容易踩的坑：
- **图纸不是猫**。只写了 `class Cat:` 而没有写 `Cat(...)`，碗边一只猫都不会有。
- **`self` 别漏**。`def __init__(self, name, fish):` 括号里第一个位置一定是 `self`；仓库要写成 `self.name`，写成光秃秃的 `name` 就只是喂进来那个东西，猫身上什么都没留下。
- **别把别人的仓库当成自己的**。`cat2.name` 和 `cat1.name` 是两份东西，改一只不会动另一只。
:::

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `class Cat:` | 画一张叫 `Cat` 的猫猫图纸 |
| `def __init__(self, name, fish):` | 图纸上的第一条说明：生猫时先喂进名字和鱼干数 |
| `self.name = name` | 把喂进来的名字放进**这只猫自己**的仓库 |
| `def meow(self):` | 在图纸上画一招（方法） |
| `cat1 = Cat("橘猫", 3)` | 照着图纸生出一只真猫 |
| `cat1.meow()` | 让 `cat1` 这只猫施展 `meow` 这一招 |
| `cat1.fish = 5` | 只改 `cat1` 自己仓库里的鱼干数 |
| `def __str__(self):` | 决定这只猫被 `print` 时打印成什么样 |
