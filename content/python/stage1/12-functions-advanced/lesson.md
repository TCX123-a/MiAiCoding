## 钩子：招式会写了，投喂还只会一种姿势

上一课，本喵打造出了自己的第一个**招式（函数）**：`def` 起手，喂进小鱼干，`return` 把战利品叼回来。招式是好招式，可练了几天，本喵撞上三件别扭事：

1. **少喂一条就炸毛。** 有些小鱼干几乎每次都是同一个值，本喵却每次都得原样再写一遍。
2. **顺序记岔了就串味。** 招式里的小鱼干一多，谁排第几就记不清了 —— 手一滑塞错位置，它**不报错**，只是安安静静地把两份东西换了个位置。
3. **一趟只能叼回一样。** 本喵明明想让它一次把「几条」和「一共多少钱」都带回来。

今天这一课就是**投喂方式大全**：三种新姿势，一件一件解决喵。

## 一、默认参数（自带的小鱼干）：不喂就用招式自己那份

本喵的招式里，有一条小鱼干几乎每次都是同一个值 —— 比如打招呼的开场白，十次里有九次都是「你好」。每次都要把它重新喂一遍，太啰嗦了。

解法很朴素：**在招式头上，本喵先给这条小鱼干配好一份。** 你喂了，就用你喂的；你不喂，招式就端出自己带的这份。

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}喵～")

greet("小橘")
greet("狸花", "早上好")
```

```text
你好，小橘喵～
早上好，狸花喵～
```

拆开看这一行行：

- **`greeting="你好"`** —— 招式头上直接写「名字 `=` 一份值」，意思就是「这条小鱼干本喵自己带了一份」。带等号的那一条，就是**自带的小鱼干**。
- **第一次 `greet("小橘")`** 只喂了一条，`greeting` 那一格**空着**。空着不要紧，招式把它自己带的 `"你好"` 端了出来，于是印出「你好，小橘喵～」。
- **第二次 `greet("狸花", "早上好")`** 喂了两条，自带的那份**被顶掉**，改用你喂的 —— 印出「早上好，狸花喵～」。

一句话：**喂了就听你的，不喂就听招式的。**

### 自带的那份必须排在最后

有自带小鱼干的那条，**必须排在没自带的后面**。要是排反了，翻译官喵连跑都不跑：

```text
def greet(greeting="你好", name):
    print(name)
```

```text
  File "...\main.py", line 1
    def greet(greeting="你好", name):
                             ^^^^
SyntaxError: parameter without a default follows parameter with a default
```

最后那句翻成猫话就是：**没自带存货的那条，排到了自带存货的后面。**

为什么 Python 要立这条规矩？因为喂的时候是**按顺序对号入座**的：第一条进第一个位置，第二条进第二个位置……要是自带的排在前面，你只喂一条的时候，翻译官喵就不知道这一条到底是给谁的 —— 是补上自带那个缺，还是跳过它喂给后面那个？**它分不清，索性不许你写。**

规矩记成一句话：**自带存货的排最后** —— 前头那些必须喂，后头那些可以偷懒。

::: tip 猫咪提示
自带的小鱼干就记三件事喵：**写法**是 `名字=值`；**脾气**是你喂了就顶掉、不喂就用它带的；**排位**是必须排在没自带的后面。三件事都记住，这一节就通关了。
:::

## 二、关键字参数（点名投喂）：报上名字再喂

第一节解决的是「懒得喂」，这一节解决的是**喂错位置**。

老办法投喂，是**排队对号入座**：你只管往队里塞，塞第几个它就是第几个。姿势记岔一位，两份东西就换了个位置 —— 而且它**不报错**，只是安安静静地把城市当成了年龄。这种错最难找喵。

第二种姿势是**点名投喂**：每份小鱼干先报上名字，再喂进去：

```python
def intro(name, age, city):
    print(f"{name}今年{age}岁，住在{city}")

intro("小橘", 3, "猫窝")
intro(city="猫窝", age=3, name="小橘")
intro("狸花", age=5, city="鱼塘")
```

```text
小橘今年3岁，住在猫窝
小橘今年3岁，住在猫窝
狸花今年5岁，住在鱼塘
```

- **第一句**是**排队投喂**（老办法）：按位置一个一个塞进去。
- **第二句**是**点名投喂**：写法是 `名字=要喂的东西`。三条都点了名，所以**顺序随便你怎么颠**，翻译官喵照样对号入座 —— 印出来的和第一句一模一样。
- **第三句**是**混着来**：前面没点名的照旧排队，后面点名的就能随便放。

点名投喂有两个好处：

1. **不怕记岔顺序。** 三个位置连排在一起，写到第三天就忘了第三个是年龄还是城市；点名写出来，一眼就读得懂。
2. **可以只喂想改的那几条。** 剩下的位置不写，它们照旧按排队或者用自带的那份（上一节学的）补上。

### 没点名的必须排在前面

这条规矩和上一节是一家人：**没点名的一定要排在点了名的前面。**

```text
def intro(name, age, city):
    print(name)

intro(age=3, "小橘", "猫窝")
```

```text
  File "...\main.py", line 4
    intro(age=3, "小橘", "猫窝")
                           ^
SyntaxError: positional argument follows keyword argument
```

翻成猫话：**点名环节开始之后，又冒出一个没点名的。**

为什么也拦？因为 `age=3` 一出现，翻译官喵就当「从这儿起改成点名」了。后面再冒出来一个没点名的，它不知道该把你排在哪个位置 —— 排在 `age` 前面吗？可 `age` 已经被点走了呀。分不清，就照样不许写。

::: warn 小心喵
两条排位规矩，一口气记下来喵：

- **自带存货的排最后** —— `def f(a, b=3):` 对，`def f(a=1, b):` 错。
- **没点名的排前面** —— `f(1, 2, c=3)` 对，`f(c=3, 1, 2)` 错。

这两条错法都是**还没开跑就报错**（`SyntaxError`）：翻译官喵读一眼招式头就把单子退回来了，你写的代码**一个字都不会执行**。报错听起来吓人，其实是好事 —— 它把你从「喂错了位置却安安静静跑完」那种更深的坑里拽了出来喵。
:::

## 三、多返回值（一趟叼回好几样）：逗号是关键

前两节说的都是**喂进去**的姿势，这一节说**叼回来**。

本喵的招式干完活，`return` 后面可以**排一串**，用逗号隔开 —— 一趟全叼回来：

```python
def 报账(条数, 单价):
    total = 条数 * 单价
    return 条数, total

条数, 总价 = 报账(4, 3)
print(条数)
print(总价)
```

```text
4
12
```

- **`return 条数, total`** —— 逗号是关键。写 `return 条数` 只叼回一样；写成 `return 条数, total`，就一趟叼回**两样**。
- **左边摆几个小鱼干仓库，它就按顺序一份一份倒给你。** `条数` 接到 `4`，`总价` 接到 `12`。这一手第 10 课在**元组（焊死的小盒子）**身上见过，叫**解包** —— 按顺序倒出来。
- 顺序是**从左到右**对着来的：左边第一个仓库接第一样，第二个接第二样。

### 其实叼回来的是一整盒

要是左边**只摆一个仓库**去接，那它接到的就是**一整盒**：

```python
def 报账(条数, 单价):
    total = 条数 * 单价
    return 条数, total

结果 = 报账(4, 3)
print(结果)
print(结果[0])
```

```text
(4, 12)
4
```

- **`print(结果)` 把整盒端出来给你看**：`(4, 12)` —— 圆括号和逗号都印出来了。这不是巧合，`return 条数, total` 叼回来的真身就是一个**元组**，第 10 课那个焊死的小盒子。
- **既然是盒子，就能报编号取**：`结果[0]` 拿到 `4`，`结果[1]` 拿到 `12`。

所以「一趟叼回好几样」的真相是：**招式叼回一整盒，左边摆几个仓库，它就当着你的面拆成几份。**

### 仓库个数对不上就炸毛

```text
def 报账(条数, 单价):
    total = 条数 * 单价
    return 条数, total

a, b, c = 报账(4, 3)
```

```text
Traceback (most recent call last):
  File "...\main.py", line 5, in <module>
    a, b, c = 报账(4, 3)
    ^^^^^^^
ValueError: not enough values to unpack (expected 3, got 2)
```

最后那句翻成猫话：**要拆的东西不够，说好给三个，实际只有两个。**

注意它和上一节那两条错的**脾气不一样**：

- `SyntaxError` 那两条，是翻译官喵**读一眼就退单**，代码一个字都不跑。
- 这一条是**跑到那一行才炸**的 —— 前面的招式都好好干完活了，到拆盒子这一步才发现仓库多摆了一个。

::: tip 猫咪提示
三种姿势收口喵：

- **自带的小鱼干**（`def f(a, b=3):`）—— 这条小鱼干几乎每次都一样，懒得喂时用。
- **点名投喂**（`f(b=5, a=1)`）—— 位置记不住、或者只想改其中一两条时用。
- **一趟叼回好几样**（`return a, b`）—— 干完活有好几样成果要带回来时用。

三条排位规矩再念一遍：**自带存货的排最后，没点名的排前面。**
:::

## 四、三样一起上：把姿势叠起来

最后把三种姿势叠在一段代码里，看一眼它们怎么配合：

```python
def 报账(条数, 单价=3):
    total = 条数 * 单价
    return 条数, total

print(报账(4))
print(报账(2, 5))
print(报账(6, 单价=2))
```

```text
(4, 12)
(2, 10)
(6, 12)
```

- **`print(报账(4))`** —— 单价没喂，用自带的 `3`，`4 × 3 = 12`，叼回 `(4, 12)`。
- **`print(报账(2, 5))`** —— 单价喂了 `5`，自带的那份被顶掉，`2 × 5 = 10`，叼回 `(2, 10)`。
- **`print(报账(6, 单价=2))`** —— 条数排队喂、单价点名喂，混着来也行，`6 × 2 = 12`，叼回 `(6, 12)`。

三种姿势谁也不碍着谁：**自己带的负责偷懒，点名的负责不记岔，逗号负责一次多带几样。**
