## 钩子：散着的小鱼干，串起来才好拿

本喵的储藏室里有一整箱小鱼干 🐟。散着放的时候，想拿「第三颗」得把整箱翻个底朝天；本喵干脆抽出一根线，把它们**按顺序一颗一颗穿起来**——这就成了一条项链：有头有尾，每一颗都**站在固定的位置上**，报个编号就能拿到。

Python 里管这种「一颗颗按顺序串起来的东西」叫**字符串（一串小鱼干的项链）**。项链上的一颗可以是一个汉字、一个字母、一个数字、一个标点——**一颗就是一颗**，全都算数。

你在上一课已经跟它打过照面了（还记得用引号围起来的那串东西吗）。今天本喵要教你四件事：**怎么串、怎么按编号拿、怎么剪一段、怎么让它自己变**喵～

## 串项链：引号就是那根线

串一条项链的办法简单到不像话：**拿引号把内容围起来**。单引号 `'` 和双引号 `"` 都行，只要左右配成对：

```python
a = "小鱼干项链"
b = '小鱼干项链'
print(a)
print(b)
```

```text
小鱼干项链
小鱼干项链
```

两次打印一模一样，说明在 Python 眼里 `"` 和 `'` 是**同一根线**，你喜欢哪根就用哪根。串好的项链照样可以放进一个叫 `a` 的小鱼干仓库里存着，往后喊名字就能取——这件事你上一课已经会了喵。

### 引号划出来的那条界线

引号还管着一件大事：**分清「数字」和「长得像数字的字符」**。

```python
print(3 + 5)
print("3" + "5")
```

```text
8
35
```

同样是 3 和 5，一个得 `8`、一个得 `35`，差别全在引号上：不带引号的 `3` 是**真正的数字**，`+` 老老实实做加法；带引号的 `"3"` 则是**两颗字符穿成的项链**，而项链加项链就是把两条接成一条更长的——`"3" + "5"` 得到的是 `"35"` 喵。

### 接头与复印

`+` 能把两条项链接起来，`*` 能把同一条项链复印好几遍：

```python
print("一口" + "一口")
print("喵" * 3)
```

```text
一口一口
喵喵喵
```

`"喵" * 3` 就是「把这一颗复印三份、再串成一串」喵。

## 报编号取一颗：索引

项链最贴心的地方是：**每一颗都有编号**，而且编号从 `0` 开始。

```python
s = "小鱼干项链"
print(s[0])
print(s[1])
print(s[2])
print(s[4])
```

```text
小
鱼
干
链
```

把 `s = "小鱼干项链"` 摊在桌上，编号和那一颗的对应关系长这样：

| 编号 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 那一颗 | 小 | 鱼 | 干 | 项 | 链 |

所以 `s[0]` 是第一颗「小」，`s[4]` 是第五颗「链」——**方括号里写编号**，读作「项链 `s` 的第几颗」。规律只有一条：**从 0 开始数**，第一颗永远是 0 号，往后依次加一。

### 倒着数：负数编号

想拿最后一颗的时候，从 0 数到 4 太累了。Python 允许你**从尾巴往回数**，用负数：

```python
s = "小鱼干项链"
print(s[-1])
print(s[-2])
```

```text
链
项
```

`s[-1]` 是倒数第一颗，`s[-2]` 是倒数第二颗——**`-1` 就是最后一颗**，往后你会天天用到它喵。项链不长的时候，`s[4]` 和 `s[-1]` 指的是同一颗。

::: warn 小心喵
报了一个不存在的编号，Python 会当场翻脸。这条项链只有 5 颗（编号 0~4），你要是写 `s[5]`，它会甩给你一句 `IndexError: string index out of range`——意思是「编号跑到项链外面去啦」。看到这句，先掰手指数一数项链有几颗，别硬猜喵。
:::

## 剪一段：切片

光拿一颗不够用的时候，把编号写成 `起点:终点` 的样子（中间是**冒号**，不是逗号），就能剪下**连着的一段**：

```python
s = "小鱼干项链"
print(s[1:3])
print(s[:2])
print(s[3:])
```

```text
鱼干
小鱼
项链
```

规则只有一句，请你念三遍：**含头不含尾**。`s[1:3]` 拿的是编号 1 和 2 这两颗，**编号 3 那颗不要**——所以剪下来是「鱼干」，不是「鱼干项」。刚开始学的人十有八九会把这个记反，多写两遍就顺了喵。

两头都可以偷懒：
- `s[:2]` 省略了起点 → 从**最开头**开始剪（等于 `s[0:2]`，得到「小鱼」）
- `s[3:]` 省略了终点 → 一路剪到**末尾**（得到「项链」）

## 项链自带的招式：常用方法

项链自己会不少本事。喊它们的写法和报编号不一样：**先写项链的名字，中间点一个点，再写招式的名字，最后跟一对小括号**。

```python
name = "MiAi"
print(name.lower())
print(name.upper())
print(len(name))
```

```text
miai
MIAI
4
```

- `name.lower()`：整条变成小写，`MiAi` 变成 `miai`
- `name.upper()`：整条变成大写，`MiAi` 变成 `MIAI`
- `len(name)`：数一数有几颗，得到 `4`

注意 `len` 的写法和前两个**不一样**：它是外面请来的外援招式，项链得**放进括号里**、前面**不点**——写成 `len(name)` 才对。而 `lower`、`upper` 是项链**自带的**招式，要点着它的名字喊：`name.lower()`。

（顺带一提：`lower` 和 `upper` 拿中文项链没辙——中文本来就不分大小写，它俩只会原样还给你，别以为是坏了喵。）

还有一条铁规矩：**招式的名字要照着抄**。Python 认大小写——`upper` 写成 `Upper`，它就不认得这一招了喵。

另外两个每天都要用上的：

```python
s = "小鱼干项链"
g = "  小鱼干  "
print(g.strip())
print(s.replace("干", "骨头"))
```

```text
小鱼干
小鱼骨头项链
```

- `g.strip()`：把**两头的空格**掐掉。`"  小鱼干  "` 前后各挂着两个空格，`strip()` 之后干干净净只剩「小鱼干」。别人递过来的文字常常带着看不见的空格，`strip()` 就是那把掸子喵。
- `s.replace("干", "骨头")`：要投喂两颗小鱼干——第一颗是**要被换掉的**，第二颗是**换成什么**。于是「小鱼干项链」摇身变成「小鱼骨头项链」。

还有一件常常要问的事：「这条项链里有没有某一段？」用 `in` 去问它，它叼回来 `True` 或者 `False`：

```python
s = "小鱼干项链"
print("项链" in s)
print("猫粮" in s)
```

```text
True
False
```

::: tip 猫咪提示
今天这四件事，各记一句喵：
1. **串**：引号一围就是项链；`+` 是接头，`*` 是复印。
2. **数**：`s[0]` 第一颗、`s[-1]` 最后一颗，编号**从 0 开始**。
3. **剪**：`s[起点:终点]`，**含头不含尾**；起点终点都可以不写，不写就取到头/尾。
4. **用**：自带的招式点着喊 `name.upper()`；外援招式 `len(name)` 把项链放进括号里。
:::

::: warn 小心喵
三个最容易踩的坑：
- 编号越界会挨 `IndexError` 的骂，报编号之前先数清项链有几颗。
- `"3"` 和 `3` 不是一回事——写成 `"3" + 5` 会报错，Python 一时分不清你是要做加法还是接项链。
- 招式后面那对小括号不能丢：`name.upper` 只是把招式本身拿出来（没施展），`name.upper()` 才会给你大写的结果。
:::
