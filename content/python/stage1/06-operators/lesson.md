## 钩子：只会复读、不会算账的点单机

上一课，本喵给猫猫点单铺那台点单机装上了一只耳朵（`input`）和一张嘴（`print`）：客人报个名字，它就回一句「你好，XX 喵」。

可昨天大肥鱼来买小鱼干，出事了。它晃着圆滚滚的身子说：「小鱼干一条 3 元，本鱼要 5 条。」点单机张嘴就念：「3」「5」—— 然后就没了下文。**它不会算账**喵。

要算账，就得教它今天这两样东西：**运算符**和**表达式**。学完这一课，点单机就从「复读机」升级成「会算账的猫猫掌柜」啦 🐟。

## 表达式：一张能算出结果的单子

先认最大方的那个词：**表达式**。它就是**一段能算出结果的式子** —— 比如 `3 + 5`。

Python 见到表达式，会**当场把它算出来**。算出来的结果和数字、和项链一样能用：能喂给 `print` 印出来，也能装进仓库里存着。所以下面这两行都是成立的：

```python
print(3 + 5)
total = 3 + 5
```

第一行把算式的结果直接印出来，第二行把结果装进 `total` 这间仓库。**算式不是摆设，它是会出结果的**喵。

那算式里那个**动作符号**叫什么呢？就叫**运算符**。`3 + 5` 里，`3` 和 `5` 是原料，中间的 `+` 是动作 —— 本喵管它叫**锅铲**：原料下锅，锅铲一翻，出来一道菜。今天要认的锅铲有五大把：算术、比较、逻辑、整除取余、还有管排队次序的优先级喵。

## 算术：`+` `-` `*` `/` `**`

| 运算符 | 干什么 | 例子 |
|---|---|---|
| `+` | 加起来 | `3 + 5` 得 `8` |
| `-` | 减去 | `10 - 4` 得 `6` |
| `*` | 乘起来 | `6 * 7` 得 `42` |
| `/` | 除（老实的那种） | `10 / 4` 得 `2.5` |
| `**` | 乘方 | `2 ** 3` 得 `8` |

前四个你都眼熟，只提醒一句：**乘号是键盘上的星号 `*`，不是 `×`**，除号是**斜杠 `/`，不是 `÷`**。翻译官喵只认键盘上那两个符号喵。

`**` 是今天新认的，它管**乘方**：`2 ** 3` 读作「2 的三次方」，也就是 2 自己乘三遍（2 × 2 × 2），得 `8`。

跑一段看看：

```python
print(3 + 5)
print(10 - 4)
print(6 * 7)
print(10 / 4)
print(2 ** 3)
```

```text
8
6
42
2.5
8
```

### `/` 有个怪脾气：结果一定带小数点

这是零基础最容易看走眼的一处，本喵单独拎出来讲：**只要用了 `/`，算出来的结果一定带小数点**，哪怕除得干干净净。

```python
print(10 / 2)
print(2 + 3.0)
```

```text
5.0
5.0
```

- 第一行：`10` 除以 `2` 明明是整的，结果却是 `5.0` 而不是 `5` —— `/` 出来的答案一律是**小数罐**。
- 第二行：算式里只要**混进一个带小数点的数**（`3.0`），算出来也跟着变成带小数点的 `5.0`。

记成一句话：**带小数点的数会「传染」**，一锅菜里放一个，整锅都是那个味道喵。

::: warn 小心喵
`+` 在 Python 里有个兼职：**两边都是项链的时候，它是「接头」不是加法**（上一课认得的那条）。所以 `"3" + "5"` 得的是 `"35"` 这条更长的项链，而 `"3" + 3` 会当场报错 —— 翻译官喵分不清你是要做加法还是接项链。

写算式之前先看一眼：**两边是数字罐，还是项链？** 数字罐才能加减乘除喵。
:::

## 比较：结果只有两块牌子

接下来这把锅铲不忙着做加减，它专门**问问题**。

就像本喵拿天平称两堆小鱼干，称完只有一个答案：左边多、右边多、还是一样多。Python 里比较出来的答案也只有两块牌子 —— `True`（真）和 `False`（假），就是你第 4 课见过的那对真假值。

| 运算符 | 问的是什么 |
|---|---|
| `>` | 左边比右边大吗 |
| `<` | 左边比右边小吗 |
| `>=` | 左边大于**或等于**右边吗 |
| `<=` | 左边小于**或等于**右边吗 |
| `==` | 两边**一样**吗 |
| `!=` | 两边**不一样**吗 |

```python
print(3 > 2)
print(3 < 2)
print(5 >= 5)
print(5 == 5)
print(5 != 5)
```

```text
True
False
True
True
False
```

一眼看下来，输出里只有 `True` 和 `False` 轮流出现 —— 这就是比较运算符的脾气：**它不问出「几」，只问出「成不成立」**。

比较还能用在项链上，看两条项链是不是一模一样：

```python
print("3" == 3)
print("3" == "3")
```

```text
False
True
```

第一行印出 `False`：左边是一串**项链**，右边是一个**数字罐**，两样东西根本不是一路，当然谈不上「一样」。第二行两条项链都是 `"3"`，一模一样，于是印出 `True` 喵。

::: warn 小心喵
`=` 和 `==` 是**两个完全不同的动作**，新手十有八九在这儿摔一跤：

- **一个等号 `=`** 是**动作**：把右边的东西装进左边的仓库。`fish = 3` 是「把 3 装进去」。
- **两个等号 `==`** 是**发问**：问一句「两边一样吗」，问出来的答案是一块真假牌子。`fish == 3` 会得到 `True` 或 `False`。

念的时候就有区别：一个等号念「装上」，两个等号念「是不是」。**数一数等号有几个**，这是写算式前最值得花的一秒钟喵。
:::

## 逻辑：把好几块牌子拼起来

一块牌子只回答一个问题，那「**鱼干够** 而且 **客人带够了钱**」这种规矩怎么写？

Python 给了三把**逻辑**锅铲，它们不跟数字打交道，专门**把真假牌子拼起来**：

- **`and`**（而且）：两边**都**是真，结果才是真。只要有一只猫没点头，就是假。
- **`or`**（或者）：两边**有一个**是真，结果就是真。有一边点头就成。
- **`not`**（不）：把牌子**翻个面** —— 真的变假，假的变真。

本喵把点单铺的规矩写成代码：

```python
hasFish = True
hasMoney = False
print(hasFish and hasMoney)
print(hasFish or hasMoney)
print(not hasMoney)
```

```text
False
True
True
```

一行行看：鱼干有（`True`），钱没带够（`False`）。

- `hasFish and hasMoney`：一个真一个假，「而且」要求两边都真，所以是 `False` —— 今天不卖。
- `hasFish or hasMoney`：有一边是真，「或者」就满足了，所以是 `True`。
- `not hasMoney`：把 `False` 翻个面，得到 `True`（「**没**带钱」这件事是真的）。

逻辑锅铲的两边，最常放的是**比较算出来的牌子**，这样一句话就能问两件事：

```python
print(3 > 2 and 5 > 4)
print(3 > 2 and 5 < 4)
```

```text
True
False
```

第一行：`3 > 2` 是真，`5 > 4` 也是真，「而且」要两边都真 —— 成了，`True`。
第二行：`3 > 2` 是真，可 `5 < 4` 是假，一边没点头，`False` 喵。

## 整除 `//` 与取余 `%`：分鱼干的一对好搭档

现在到本课最实用的一对了。

本喵有一袋小鱼干，一共 **7 条**，要按**每袋 3 条**分装。分完之后有两条信息你最想知道：**能装满几袋**？**还剩几条**？

Python 给这两件事各配了一把锅铲：

- **`//`** 叫**整除** —— 它只回答「装满几**整份**」，零头**直接扔掉**。
- **`%`** 叫**取余** —— 它只回答「**剩下多少零头**」。

```python
print(7 // 3)
print(7 % 3)
```

```text
2
1
```

7 条鱼干，每袋 3 条：装满 `2` 袋，还剩 `1` 条。

把两个答案合起来看：**2 袋 × 每袋 3 条 + 剩 1 条 = 7 条**。一条都没丢，也一条都没多 —— **`//` 管「几整份」，`%` 管「剩多少」，两个一起用，账目永远对得上**喵。

### 和 `/` 摆在一起比一比

```python
print(7 / 3)
print(7 // 3)
```

```text
2.3333333333333335
2
```

同样一句「7 除以 3」：

- `/` 是老实的除法，它把答案**算到底**，给你一长串小数（`2.3333333333333335`）。
- `//` 只回答「装满几份」这一个问题，答案是整数 `2` —— 小数点后面那一截被它扔掉了。

想分清它俩，就记一句话：**`/` 管「算得准」，`//` 管「装了几份」**喵。

### 这对搭档能干什么

```python
print(125 // 60)
print(125 % 60)
print(8 % 2)
print(9 % 2)
```

```text
2
5
0
1
```

- 前两行：**125 分钟是几小时几分钟**。`125 // 60` 得 `2` 小时，`125 % 60` 得剩 `5` 分钟 —— 报时间、算零钱，全靠这一对。
- 后两行：**判单双数**。`8 % 2` 得 `0`，说明 8 能被 2 分干净，是双数；`9 % 2` 得 `1`，说明分完还剩一条，是单数。以后学到「看鱼干眼色行事」那一课，程序就是靠 `% 2` 是不是等于 `0` 来分单双的喵。

::: warn 小心喵
两个坑先说在前面：

1. **`/` 和 `//` 别看漏了一个斜杠**。`7 / 3` 得 `2.3333333333333335`、`7 // 3` 得 `2`，写法只差一个符号，答案差很远。
2. **别拿 0 去做除数**。`7 // 0`、`7 % 0`、`7 / 0` 都会让翻译官喵当场炸毛，甩一句 `ZeroDivisionError` —— 因为「每袋装 0 条」这件事本来就没法分。

另外，本喵上面举的例子全是**正数**。哪天你拿负数去 `//` 和 `%`，方向会和你想的不一样（`-7 // 2` 得的是 `-4`）—— 那是另一课要单独讲的坑，今天先记一笔就行喵。
:::

## 优先级：谁先动手

最后一把锅铲，管的不是计算，是**次序**。

厨房里做菜有先后：先切菜、再下锅，顺序乱了菜就毁了。算式里也一样 —— Python 不是从左到右傻算，它按**优先级**排队，谁级别高谁先动手。

今天认的规矩，从高到低：

1. **括号 `( )`** —— 级别最高，谁被括号围起来谁先算。
2. **`**`**
3. **`*` `/` `//` `%`** —— 乘除这一档
4. **`+` `-`** —— 加减这一档
5. **比较**：`>` `<` `>=` `<=` `==` `!=`
6. **`not` → `and` → `or`** —— 逻辑这一档，`not` 排在最紧的位置

**同一档里，从左往右排队**喵。

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

```text
14
20
```

一模一样的数字，只因为多了一对括号，答案就从 `14` 变成 `20`：

- 第一行：乘除排在加减前面，所以先算 `3 * 4` 得 `12`，再算 `2 + 12` 得 `14`。
- 第二行：括号级别最高，先把 `2 + 3` 算成 `5`，再乘 `4` 得 `20`。

这两行的先后次序，本喵一步一步摆给你看：

比较排在加减后面，所以「先算完数、再问问题」：

```python
print(3 > 2 + 5)
print(2 + 5 > 3)
```

```text
False

```

两边都是先算出 `2 + 5 = 7`，再拿 7 去比：`3 > 7` 是假（`False`），`7 > 3` 是真（`True`）喵。

逻辑这一档也有先后：`and` 比 `or` 紧，`not` 比 `and` 还紧。所以下面两行结果不一样：

```python
print(True or False and False)
print((True or False) and False)
```

```text
True
False
```

第一行没有括号，`and` 级别高，先算 `False and False` 得 `False`，再算 `True or False` 得 `True`。
第二行本喵用括号把 `or` 顶了上去，先算 `True or False` 得 `True`，再算 `True and False` 得 `False`。

::: tip 猫咪提示
今天记住这五句话，运算符就拿下大半啦：

1. **表达式 = 会算出结果的式子；运算符 = 中间的锅铲。**
2. **算术**：`+` `-` `*` `/` `**`；`/` 的结果**一定带小数点**。
3. **比较**：`>` `<` `>=` `<=` `==` `!=`，答案只有 `True` / `False` 两块牌子（`=` 是动作，`==` 才是发问）。
4. **逻辑**：`and` 要两边都真、`or` 有一边真就行、`not` 翻个面。
5. **`//` 管「装满几份」、`%` 管「剩多少零头」**；优先级**拿不准就加括号** —— 括号不花钱，还能让读代码的猫一眼看懂你想先算哪一步喵。
:::

## 小任务

先别急着跑，**每一行都先在心里猜一个数**，再去 Python 里对答案 —— 猜错了才是最赚的，那说明有个地方你还没想清楚喵～

```python
print(137 // 10)
print(137 % 10)
print(8 % 2)
print(8 % 3)
print(1 + 2 == 3)
```

1. 前两行：本喵有 137 条小鱼干，按每袋 10 条分装 —— 能装满几袋、还剩几条？
2. 中间两行：`8 % 2` 和 `8 % 3` 各是几？哪一个是单数？
3. 最后一行 `1 + 2 == 3`：先算谁、后算谁？它会印出一个数，还是印出一块牌子？
4. 试着改一改：把 `print(2 + 3 * 4)` 加一对括号变成 `print((2 + 3) * 4)`，猜猜答案从几变成几，再跑一遍看看猜对没有。

这些小算式跑顺了，点单机就真的会算账了。下一课，本喵教它**拿主意** —— 余额够不够、要不要打折，让程序自己看鱼干眼色行事。去「if 与 elif」探险喵～ 🐾
