## 钩子：电脑听不懂「你好喵」

本喵凑到电脑跟前，清清嗓子，认认真真地打了个招呼：「你好喵～」

屏幕一点反应都没有。

大肥鱼在旁边甩着尾巴笑：「它哪听得懂猫话呀——它连人话都听不懂，它只认得 0 和 1。」

可要本喵写一串 0101 给它看，那还不如让本喵去学倒立喵。好在人类早就替猫猫们想好了办法：造一门**编程语言**——写得像英语一样好读，再由翻译官喵负责把它翻给电脑听。今天本喵要认识的就是其中最好上手的那个：**Python**。

## Python 是什么喵

Python 是一门**编程语言**。它有两个特别讨猫喜欢的性子：

- **短**。同样是「让电脑念一句话」，有的语言要铺床叠被写上好几行，Python 一行就够。
- **随和**。它不逼你先背一大堆规矩，想到什么就写什么，特别适合第一次碰编程的你。

顺便说个冷知识：Python 这个词本来有「蟒蛇」的意思，可它跟蛇一点关系都没有——它这名字是照着人类一个爱讲笑话的喜剧团体起的。所以别怕它咬你喵～ 🐟

## 第一个程序：让电脑念一句「你好」

写代码不用什么特别的工具，一行就能开工：

```python
print("你好")
```

```text
你好
```

恭喜喵！这就是你的第一个程序。别看它只有一行，拆开来看，它是三样东西拼起来的：

1. **`print`** —— 这是**招式的名字**，意思是「把东西念出来给本喵看」。这个名字要**一个字母都不差**地写对：写成 `prnt`，或者写成中文的「打印」，翻译官喵都不认得。
2. **一对小括号 `( )`** —— 这是**投喂的口子**。想让电脑念什么，就把它塞进这对括号里。
3. **一对双引号 `" "`** —— 这是那句话的**边界**。引号里的内容电脑原样念出来，而**引号本身不念**。

所以 `print("你好")` 打出来的就是 `你好` 这两个字，前后没有引号喵。

顺便说一句：光有引号还不行哦——不喊 `print` 这个名字，电脑是不会主动开口念给你听的。**引号负责圈出内容，招式负责开口**，两样缺一不可喵。

### 漏了引号会怎样

要是写成 `print(你好)`，电脑就不念「你好」了：它会以为 `你好` 是个**名字**，扭头去找「有没有叫这个名字的东西呀」，找了一圈没找着，翻译官喵只好报错给你看。

**加不加引号，就是「一句话」和「一个名字」的分界**——引号里面的是内容，引号本身不是内容。这一条往后天天要用，先记牢喵。

## 让它念两句：一行一行往下念

想一次念两句，就写两行：

```python
print("你好")
print("我是本喵")
```

```text
你好
我是本喵
```

电脑是**从上往下一行一行念**的：谁写在前面，谁先出声。把两行的顺序调换一下，念出来的顺序也跟着调换。

::: tip 猫咪提示
今天记住三件事：**Python 是一门像英语一样好读的编程语言**；**`print("...")` = 让电脑念一念引号里的内容**；**代码一行一行、从上往下执行**。
:::

::: warn 小心喵
引号里写什么，电脑就原样念什么——哪怕你写的是 `print("1 + 1")`，它也会老老实实念出 `1 + 1` 这几个字，不会替你算成 2 喵。引号里的是**一句话**，不是一道算式。
:::

## 翻译官喵是怎么干活的：念一句、做一句

电脑只认得 0 和 1，你写的每一行都得由**翻译官喵**翻给它听。这位翻译官有两种性子：

- 一种是**先把整本翻完再开演**：把整份代码一口气翻成机器语言，翻完了才交给电脑跑。好处是跑起来快，麻烦是**只要有一个字写错，它一句都不肯跑**，你得整份改完再来。
- 另一种是**念一句、做一句**：读进来一行，翻一行，电脑马上把这一行做掉，再读下一行。

**Python 的翻译官喵属于后面这种**。它的正式名字叫**解释器（翻译官喵）**，而这种「念一句、做一句」的干活方式，本喵叫它**解释执行**。

解释执行对新手特别友好：你写一行，它念一行，哪儿出错也是**当场**告诉你，你能一眼看出是哪一句惹的祸；不像「整本翻完再开演」那样，得等整份查完了才有结果。它还有个脾气要提前知道——它是**一路念下去**的，念到哪一行卡住了，就在那一行停下来，后面的句子就不念了。

