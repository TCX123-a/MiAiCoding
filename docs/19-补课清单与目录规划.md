### 1.3 三条硬事实（都会左右方案，不是背景知识）

**① common 只有一个模块，而且 UI 把 stage 写死。** 要走「单开一个新模块」那条路，得同时改这 5 处：

| 位置 | 现状 |
|---|---|
| [content.ts:47](../src/renderer/src/stores/content.ts#L47) | `const stage = activeLang.value === 'common' ? 0 : activeStage.value` —— common 永远找 stage 0 |
| [content.ts:44](../src/renderer/src/stores/content.ts#L44) | `activeStage = ref<1 \| 2 \| 3>(1)` —— 类型里没有 0，也没有第二个 common 阶段 |
| [Sidebar.vue:94](../src/renderer/src/components/domain/Sidebar.vue#L94) | `v-if="content.activeLang !== 'common'"` —— **common 连阶段选择器都不显示** |
| [Sidebar.vue:28](../src/renderer/src/components/domain/Sidebar.vue#L28) | `STAGES` 写死 `[1, 2, 3]` |
| [LearnView.vue:29](../src/renderer/src/views/LearnView.vue#L29) | common 的标题后缀写死返回空串 |

而且 `activeModule` 用的是 `.find()`（取第一个命中）—— 两个 `{lang:'common', stage:0}` 模块里，
第二个**永远不可达**。所以「新模块」不是纯内容活，「追加课」才是。

**② `order` = 在 `syllabus.json` 数组里的位置；目录名 = 课号数字 + slug。**
例：`c-stage3-16` 在 `content/c/stage3/16-complexity/`，它的 `order: 1`（排在该 stage 首位）。
插课 ≠ 只加文件，要连带改数组与 `order`。校验器对「标题/stage 与大纲不一致」是 **err**。

**③ 09-22 那轮已经插过课，两条先例都在**：

- **插在段首**：`xx-stage3-16 算法复杂度` 的 id 是 16（当时的新号），`order` 却是 **1** —— 因为它是地基。
- **插在中间**：`common-13` 排在 `order 7`，`required=[common-06]`，而原本接在 common-06 后面的
  `common-07` 的 `required` 被改成了 `["common-13"]`。**这就是「往 common 中间插课」的完整成本：改 1 个 `required` + 重排后面的 `order`。**

## 3. 对表 → 三级缺口

把 §2 的三路基准并起来，去撞 §1.2 的矩阵，缺口的**优先级**就自己浮出来了：

| 级别 | 定义 | 缺口 |
|---|---|---|
| **甲** | 课标明确要求 **或** 5/5 教材共识 **或** 6/6 高校大纲必讲 —— 且本项目 0 课 | **① 伪代码/流程图描述算法**（课标点名）<br>**② 经典算法（欧几里得等）**（课标点名）<br>**③ 图与遍历 BFS/DFS**（5/5 书 + 6/6 校）<br>**④ 树与二叉树**（5/5 书 + 6/6 校；cpp/java/python **全无**）<br>**⑤ 分治/动态规划/贪心/回溯**（课标选修1 明确要求）<br>**⑥ C++/Java 的排序原理与查找原理**（本方案已批） |
| **乙** | 408 要求，但高校大纲覆盖 <半数 | 堆/优先队列（1/6）、KMP（3/6，本项目**只有 C 有**）、B 树（3/6）、拓扑排序·关键路径（6/6 但有向图基础课缺失）、最小生成树/最短路径 |
| **丙** | 权威要求但普及极低，或超出入门定位 | 红黑树、B+ 树、并查集、外部排序、广义表、文件、线索二叉树、十字链表、静态链表 —— **本次明确不做** |

**两句话结论**：

1. 你要的「common 算法思维 + C++/Java 排序查找」**是对的，但只覆盖了甲级的一半**——
   课标点名的**伪代码/流程图**和**经典算法**、以及 5/5 教材共识的**图与树**，目前是整个项目的空白。
2. 真正「冷门」的（红黑树/B+树/并查集）反而**不该做**：六份大学大纲一份都没讲，
   硬塞进零基础入门课是超纲。
