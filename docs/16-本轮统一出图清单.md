## 3. 出图参数（一字不改地沿用）

| 部件 | 文件 | 节点 | 备注 |
|---|---|---|---|
| 主模型 | `anima-preview.safetensors` | `UNETLoader` | Anima 是 Qwen-Image 架构，**用 `CheckpointLoader` 会失败** |
| 文本编码器 | `qwen_3_06b_base.safetensors` | `CLIPLoader` | type 选 **`stable_diffusion`**（不是 `qwen_image`） |
| VAE | `qwen_image_vae.safetensors` | `VAELoader` | |
| LoRA | **`ds_whalemaid.safetensors` @ 0.9** | `LoraLoader` | 触发词 `ds_whalemaid` **必须写进正面**，否则 LoRA 白加载、角色完全不出现 |

**采样**：`euler` / `simple` / cfg **4.0** / 20 步 / 分辨率 **1024×1024**。

**透明底链**：`RemoveBackground(BiRefNet)` → **`InvertMask`** → `JoinImageWithAlpha`。
> ⚠️ 那个 `InvertMask` **不是多余的**：`JoinImageWithAlpha` 内部算的是 `alpha = 1 - mask`，
> 少了它得到的是一张**反过来的抠图**。

**速度**：8G 显存实测 **约 24 秒/张**（含抠图），121 张 ≈ 50 分钟，全程不爆显存。

**正面提示词的出处**（照抄，不重新发明）：角色块 + 姿态块 + 质量块三段拼法、
以及全部姿态块，都来自出过现有 62 张的那三个脚本（`<workspace>\_anima_run\run_mascots*.py`）。
本轮只有三处是新写的，逐条记在 §4。

## 5. 每张都过了一遍「透明底体检」

脚本对**每一张**跑四项判据，任一条不过就在日志里标出来（**不静默放过**）：

| 判据 | 拦住的坏法 |
|---|---|
| 中心像素 alpha > 200 | **极性反了**（抠图取反）/ 主体没画在中间 |
| 全图不透明比例 < 2% | 几乎全透明 —— 什么都没画出来 |
| 全图不透明比例 > 85% | **背景没抠掉** —— 整张是不透明的方块 |
| 外框一圈不透明比例 > 25% | **边缘没抠干净**（残留白边/方块） |

> ⚠️ 这套体检**只拦机械故障，不判「好不好看」**。「四角透明」那种粗判据会两头判错
> （主体占满角落时漏判、主体偏移时误判），所以量的是整张比例 + 外框一圈。
> **好不好看、有没有复耳复尾、手指画没画好 —— 仍然是主人自己看。**

**每张图的随机种子都记在各自文件夹的 `seeds.json` 里**（含用的哪条提示词、哪条负面），
看得上哪张都能用同一个种子原样重跑。
