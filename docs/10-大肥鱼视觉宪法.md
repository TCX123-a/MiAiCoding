## 1. 角色核心特征定义

### 1.1 比例与画风
- **2.5 头身**：头部约占全身 1/2～2/5；**眼睛占面部约 40%**（超大圆形）。
- 高精度日系 Q版二次元插画（Chibi Anime Illustration，手游立绘精细度）；赛璐璐多层光影 + 柔和渐变晕染 + 明暗交界线与投影；纤细深色描边约 1px、有粗细变化。
- **禁止**：极简/扁平/图标/简笔画/儿童画/3D/黏土/像素/写实。

### 1.2 头发
- **长而蓬松的波浪卷发，及腰**（发量丰盈）；齐刘海带碎发层次；发梢末端呈波浪下摆。
- 主色 `#3B5998`（深蓝）→ 发梢渐变 `#5DADE2`（天蓝）；**多条发丝高光带 `#85C1E9`** 沿发流分布。
- 头顶必须有**环状呆毛（"6"字形）**。
- **禁止短发或波波头**。

### 1.3 眼睛与面部
- 虹膜三段式渐变：外圈 `#1A5276` → 中圈 `#3498DB` → 瞳孔 `#1B4F72`；高光两点式：**左上大圆 + 右下小点**。
- 上眼睑**黑色睫毛线微上翘**；**细细的深蓝色眉毛位于刘海下方**（`#3B5998`）。
- 肤色 `#FFE0BD`，面部有**柔和阴影过渡**（禁止纯色块）；双颊粉色 `#F1948A` 圆形渐变腮红。
- 嘴为**小猫嘴 "ω" 形**或微张小嘴，颜色偏粉（如 `#C9708B`）。

### 1.4 种族特征
- 头部两侧**鱼鳍状耳朵**（外 `#2E4053` 内白/浅粉，锯齿或波浪边缘，向外后方伸展）。
- 身后下方延伸**深蓝鱼尾**，**尾鳍末端分叉有弧度**，颜色与裙一致 `#2E4053`（替代双腿或从裙摆后方露出）。

### 1.5 女仆装
- 头饰：白色 `#FDFEFE` 荷叶边发箍（细密半圆褶皱）+ **发箍后方白布延伸覆盖部分后脑**。
- 裙装：**深蓝连衣裙 `#2E4053` 长袖**；领口白色荷叶边立领 + **领口中央深蓝大蝴蝶结 + 金色圆形宝石 `#F39C12`**；**胸前白布拼接 + 金色纽扣垂直排列**；白围裙覆盖前胸至膝盖、荷叶边边缘，**围裙下部中央有小鲸鱼图案**；裙摆底部白色荷叶边；**袖口白色荷叶边**。
- 右侧发饰：蓝色蝴蝶结 `#3498DB` + 金色心形扣 `#F39C12`。
- 手部必须有细节（手指结构准确，避免畸形）。

## 2. UI 组件与排版规范（对话气泡）

- **边框**：深蓝色 `#1C2833` 实线，粗细约 **2px**。
- **填充**：纯白 `#FFFFFF`。
- **语义符号**：思考气泡为**云朵形**（上方圆润突起），左下角带**三个递减空心圆**；惊讶/说话气泡可带**黄色放射线 `#F4D03F`**；说话气泡带指向尖角。
- **文字渲染**：无衬线黑体风格；颜色深蓝色 `#1C2833`；字重 Bold/Heavy。
- **背景处理**：默认纯白 `#FFFFFF` 或极浅灰 `#F5F5F5`，无复杂纹理，确保主体突出。

## 3. 生成执行指令

1. 严格保持上述色值与特征比例，**禁止随意更改角色瞳色、发色或发饰位置**。
2. 文字内容需根据用户输入动态替换，但字体样式必须保持统一。
3. 若涉及手部动作（如端碗、指人），需注意手指结构的准确性，避免畸形。
