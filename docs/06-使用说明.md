# 咪爱编程 · 使用说明（写给零基础的你喵～）

> 本说明随软件一起发布。软件正式完成前，先看这里了解它将来长什么样、怎么用。

## 一、这是什么软件喵？

**咪爱编程**是一款**离线优先**的编程学习软件：一位猫娘老师住在你的电脑里，用「小鱼干」「猫猫图纸」这样的比喻，手把手教你学编程。**不联网也能完整使用**——所有课程和题目都是软件自带的；只有填了 AI Key 之后，每日挑战的题目才会由 AI 现场出，更丰富多变。里面装着：

- **通用知识**：学任何语言之前先搞懂的底层逻辑（变量、循环、函数这些到底是怎么回事）
- **四门语言**：C、C++、Java、Python，每门分「0基础入门 → 中级进阶 → 高级精通」三个阶段
- **代码练习场**：软件里直接敲代码、点运行、看结果，不用自己装任何开发环境
- **练习题 + 错题本 + 收藏 + 每日复习**：学完就练，练错自动收进错题本（可标漏洞、可延展练习）；喜欢的题收进「收藏」攒成册；每天可以来一卷「每日复习」，**全对有大肥鱼图片奖励**

## 二、安装（超简单版）

1. 双击 `咪爱编程-Setup-*.exe`，点「安装」→ 完成。**不需要管理员权限**。
2. 桌面出现「咪爱编程」图标，双击打开。
3. 如果你的电脑弹出蓝色警告「Windows 已保护你的电脑」：点**「更多信息」→「仍要运行」**即可（这是因为软件还没有购买数字签名，属于正常现象）。

**绿色便携版**：下载 `咪爱编程-Portable-*.exe`，放到任何文件夹（U 盘也行）双击就能用，学习记录跟着它走。

## 三、第一次打开软件

1. 会出现一张**新手引导卡**：猫娘自我介绍 + 界面地图，看完点「开始学习喵」。
2. 第一次打开时会自动检查电脑里有没有装「翻译官喵」（编译器/解释器）：
   - 没装的话，环境页会出现**「一键安装」**按钮，点一下等着就行，装完自动生效，不用重启软件。
   - 一键安装失败（比如网络不好），跟着弹出的**图文指引**手动下载安装，装完点「重新检测」。
3. **不装环境也能学**：看课文、做练习完全不受影响，只是不能运行代码而已。

## 四、主界面怎么逛

- **左边竖条**：从上到下是 软件名 → 学习总进度（圈圈）→ 阶段选择（基础/进阶/精通）→ 模块切换（通用知识/C/C++/Java/Python）→ 知识点列表 → 底部「设置」。
- **中间大块**：点左边列表里的知识点，课文就显示在这里；课文最下面是**运行代码区**。
- **右边竖条**：练习入口、复习状态、相关知识点跳转；右上角的 `›` 小按钮可以把它收起来。
- **搜索**：按键盘 `Ctrl+K`，输入任何词（中文/英文/代码都行）回车，就能搜到所有相关课文。

## 五、怎么学习

1. 新同学请先学**通用知识模块**的第一课《什么是编程》：它会告诉你「小鱼干仓库」「技能」「翻译官喵」这些黑话是什么意思喵～
2. 课文按顺序解锁：灰锁的知识点要先学完它前面的课。
3. 课文里会有**四语言对比块**：同一件事（比如循环）四种语言各自怎么写，并排给你看；每段代码都能一键「运行试试」。
4. 学完一课，点底部**「标记为已学」**。学过的课都进「每日复习」的题库——想复习随时去（页面在左边侧栏），不用等提醒。

## 六、敲代码和运行

1. 课文下方有代码编辑框：可以直接改示例代码，也可以自己写。
2. 点**「运行」**：结果（输出内容）显示在右侧输出面板。
3. 如果代码有错：下面会出现**猫娘解释卡**，告诉你错哪了、怎么修（常见错误的解释内置在软件里，不联网也能看）。
4. 注意：程序跑太久（超过 10 秒）会被猫娘掐断，这是保护你电脑的喵～

## 七、练习、错题本、收藏、每日复习

- **练习**：每课底部有「进入练习」；也可以做「随机组卷」跨课综合复习；一个阶段（或整门语言）学完后，**练习页的「阶段练习」页签**（或侧栏课程列表当前阶段的末尾）会出现**「综合练习」**入口，专挑有分量的硬题考你。每道题都有难度记号（简单 / 中等 / 困难 / 挑战）。
- **错题本**：答错的题自动进错题本，随时回来重做；答对了它就完成使命（历史记录还在）。列表里还能：给一道题**标记漏洞**（提醒自己这块薄弱）、暂时**删掉**（5 秒内可撤销，删掉的进「已移除」，随时恢复）、对薄弱题发起**「延展练习」**——系统会再找几道同类的题陪你练。
- **收藏**：题面旁边的 ⭐ 随手一收（练习中、挑战回顾里都有）。「收藏的题目」页可以建文件夹、写笔记、勾选多道直接开练。
- **每日复习**：侧栏进「📖 每日复习」，选 5~20 道开卷。出题会**偏向你不熟的题**（错得多的多出）。**一整卷全对**会奖励一张大肥鱼图片，奖励弹窗里可以直接把它存到电脑上；图库发完了猫娘会如实告诉你「待扩充」。
- **搜索也能练**：Ctrl+K 搜到课程后，如果下面有「相关题目练习 · N 道」，点一下就开练。

## 八、设置页能干什么

| 设置项 | 作用 |
|---|---|
| 字体大小 | 正文文字大小（默认 14px） |
| 运行超时 | 代码最长跑多久被掐断（默认 10 秒） |
| 每日复习 | 总开关：关掉后侧栏不显示「每日复习」入口 |
| 收藏练习答错 | 收藏里开的练习答错时，也照常收进错题本（不想要就关掉） |
| 音效 | 点击、切换课程、学完一课的提示音。拨到「开」时会当场响一声让你听听 |
| AI 助手 | 填 DeepSeek API Key（可选）：每日挑战题目更多样、延展练习不够时自动补几道；「测试连接」可验证 Key 对不对 |
| 联网与 AI | 软件只在**每日挑战出题**和**延展练习补题**两处用网络（都要自己填 Key）。断网或没填 Key 时自动回退自带题库，**不会报错** |
| 备份/恢复 | 把学习进度、错题本导出一份，换电脑时导入 |

**隐私说明**：AI 助手开启后，只有你当前跑的代码和报错内容会发给 AI 分析，**学习记录不会上传**。**不填 Key 时软件完全不会联网**——所有课程和题目都来自软件自带的内容，一个字都不会发出去喵～

### 8.1 三处「手感」

这三样都不影响功能，纯粹是让用起来舒服一点。**都不喜欢的话也没有开关 —— 它们是纯装饰，改起来是几行 CSS。**

| 位置 | 什么感觉 |
|---|---|
| **鼠标指针** | 是一只猫爪 🐾。**按下去会收拢，松开又铺开** |
| **代码框里的光标** | 是一根小鱼干 🐟，不是普通的竖线 |
| **声音** | 点按钮「嗒」一声、换课有一小段上行音、学完一课是一小段琶音。**学完一课的、做完一章的、完成每日挑战的是同一首曲子越来越长** —— 听一遍就知道哪个更大 |

三处**刻意没做**：**滚动不出声**（滚一下响一下会很烦）、**打字不出声**（打一百个字响一百下）、**鼠标在正文上还是普通箭头**（大段文字上放猫爪会碍眼）。

> 音效是**现场合成**的，没有附带任何音频文件 —— 所以它不占体积、也不会因为找不到文件而哑掉。

## 九、常见问题（FAQ）

| 问题 | 答案 |
|---|---|
| 打开软件被 Windows 拦了 | 点「更多信息」→「仍要运行」（未签名正常现象） |
| 一键安装环境失败 | 按图文指引手动装；装完点「重新检测」；还不行就重启电脑再检测 |
| 运行代码输出乱码 | 极少见；在设置里确认语言环境路径正确，重新检测一次 |
| 学习进度丢了 | 软件有自动备份（.bak 文件）；「设置→备份/恢复」可手动导出/导入 |
| 能联网干什么 | 只有两件事需要网络，而且**都必须你自己填 AI Key**：每日挑战出题、延展练习补题。**不联网 / 不填 Key 也完全能用**，会自动回退到软件自带的题库 |
| 猫娘说话我听不懂 | 打开通用知识第一课，所有「黑话」对照表都在那里喵～ |
