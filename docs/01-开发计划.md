# 咪爱编程 · 开发计划

> 本文档回答三个问题：**做什么、分几步做、每步要多久**。任务明细见 [02-任务列表.md](./02-任务列表.md)，验收方式见 [03-测试计划.md](./03-测试计划.md)。

## 1. 项目简介

**咪爱编程**是一个离线优先的 Windows 桌面编程学习伴侣：内置猫娘风格的编程知识库（通用知识 + C/C++/Java/Python 四语言 × 三阶段）+ 轻量代码练习器（本地编译运行代码、练习题、错题本、收藏、每日复习、全局搜索、学习进度总览）。

**技术栈**：Electron + Vue 3 + electron-vite（三进程全 TypeScript），electron-builder 打包（NSIS 安装包 + 绿色便携版）。全栈零原生依赖。

## 2. 总体原则

1. **稳定优先**：宁可简单可靠，不为炫技加复杂度；不引入原生依赖。
2. **离线优先 + 零服务器**：核心功能断网完整可用（194 课内容全部内置于软件）；联网能力**只有两处**——报错解释与每日挑战出题，且**都需要用户自填 DeepSeek Key**。**绝不搭自建服务器、不做任何第三方内容托管**，一切网络能力都是客户端直连第三方 API + 用户自带 Key。**不填 Key 时软件完全不联网。**
   - ⚠️ **「离线优先」是软件属性，不是内容禁令**（2026-09-16 主人澄清，此前被我误读过一次）：它管的是**软件断网时还能不能打开、能不能看课、能不能用本地编译器跑代码**；**不是**「课程内容里不许出现联网」。网络编程（socket / `requests`）、多线程、多进程、asyncio 这些课**该讲真联网就讲真联网**，不许为了迁就「离线」改成模拟沙盒或纯理论。需要联网才能跑的样例，**在开发机的联网环境里真跑**，不许因此降低验证标准。
3. **内容与代码解耦**：课程内容（194 个知识点）是纯数据文件，代码是通用"内容播放器"；内容分批生成、独立校验、独立版本管理。
4. **猫娘口吻铁律**：所有面向用户的文字（除代码本身）必须是猫娘口吻；术语映射以 `content/glossary.json` 为唯一真源。
5. **先文档后代码**：9 份文档是第一批交付物，后续所有开发对照文档推进；每步做完即验收。

## 4. 里程碑依赖关系

```
M0 ──► M1 ──► M2 ──► M3 ──► M4 ──► M5 ──► M6 ──► M8 ──► M9
                 │
                 └──► M7（内容批量生成，与 M3-M6 并行）
```

- M1 之后即可开始 M7 的 common 批次（黄金样例就位后）。
- M7 的 C/C++/Java 样例「编译运行校验」依赖 M5 的工具链就位；此前批次只做结构与人工审查，工具链就位后统一补校验。
- M9 打包依赖 M8 通过；发布手册在 M0 起草、M9 定稿。
