## 1. 日常开发操作

```bash
cd miai-biancheng
npm run dev        # 启动开发模式（改代码自动热更新，Electron 窗口随之刷新）
npm run typecheck  # 类型检查（每次改完代码跑一遍，必须 0 错误）
npm test           # Vitest 单测（M2 之后使用）
npm run validate:content   # 内容校验（M1 之后使用，内容改动必跑）
npm run build:content      # 内容打包（M1 之后使用，改完 content/ 必跑再启动应用）
```

**开发顺序铁律**：改类型 → `src/shared/types.ts`；加 IPC → `src/shared/ipc-channels.ts` + `src/preload/index.ts` + `src/main/`；纯逻辑 → `src/shared/`（配单测）；界面 → `src/renderer/src/`。

## 7. Git 提交习惯

- 每完成一个里程碑、验收通过后提交一次：`git add -A && git commit -m "M2: 应用框架与主界面"`
- 内容批次入库随功能提交或单独提交：`git commit -m "M7: python-stage1 批 1-3 入库"`
- 提交前必跑 `npm run typecheck`（+ 有内容改动时 `npm run validate:content`）

## 8. 出问题时的排查顺序

1. 看终端报错信息全文（不要只看第一行）
2. 查 docs/08-技术方案 对应章节是否有已知限制
3. 常见问题速查：
   - `Electron uninstall` 报错 → Electron 二进制没下载 → `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js`
   - 报错 `Cannot read properties of undefined (reading 'isPackaged')` 或 electron 以 Node 方式运行 → 当前 shell 会话里有 `ELECTRON_RUN_AS_NODE=1`（本机已确认存在，来自父进程环境、非系统级）→ 启动命令改为 `unset ELECTRON_RUN_AS_NODE && npm run dev`；双击安装包启动的应用不受影响
   - npm 下载慢/失败 → 检查 .npmrc 三镜像是否齐全
   - 窗口白屏 → 看 dev 终端 renderer 报错 + 检查 CSP 是否拦了资源
   - 中文乱码 → 对照 docs/08 §5.2 编码方案逐项核对
4. 仍解决不了 → 把完整报错贴给 AI（用 deepseek-v4-pro）
